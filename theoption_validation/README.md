# ザオプション v4.0 採用20戦略 追加監査 — G3順列検定・G5年抜きJackknife (2026-07-23)

2026-05-25 の1000パターン検証（Bonferroni + Wilson + サブサンプル）で採用された
Tier S/A 20戦略に対し、当時未実施だった2つの検定と多重性の再補正を実施した記録。
フォワード検証（実機ペイアウト・実Edge測定）は本監査の対象外。

## 実施内容

| 検定 | 内容 | 基準 |
|---|---|---|
| G3相当 | ポジション循環シフト順列検定200本（曜日選択マスクを取引系列上でシフトし、シグナル↔リターン整合を破壊） | perm_p < 0.05 |
| G5相当 | 年抜きJackknife（2016-2026の各年を1年ずつ除外し補正後Edgeを再計算） | 最低Edge > 0 |
| 多重性再補正 | Phase16でペアを16に拡張した実効探索数 M=3200 で Bonferroni を引き直し | p < 1.56e-05 |

- データ: Dukascopy 1時間足10年（Drive `forex_ml/dukascopy_hourly/` と同一）、UTC→JST変換
- 取引抽出はオリジナル実装（Notion「1000パターン検証 実装コード」）を忠実に再現し、
  **全20戦略で n・WR が当時のCSVと完全一致**（再現性確認済み）
- Edgeは当時と同じ補正（スプレッド-1.0pp + 減衰-1.0pp）適用後、BEはペイアウト1.90/1.95に応じて52.63%/51.28%

## 結果サマリー

- **G5（年抜き）: 20戦略すべて合格。** どの1年を除外しても補正後Edgeは正（最低でも+3.24pp）。
  円安イヤーなど特定年に依存したエッジは1本もない。
- **G3（順列）: 12/20合格。** 不合格8本のうちEURGBP/USDCHFの火・水・金系は
  「曜日固有性がない」だけで、**親アノマリー（全曜日版）が超強力**なため実質問題なし（下記）。
- **Bonferroni M=3200: 上位12本合格、下位8本（Edge +5〜6.8pp帯）は不合格。**

## 追補7 (2026-07-24): 1時間判定探索が暴いたBID気配アーティファクト — ポートフォリオの重大再評価

「約1時間先の判定が1.90倍で取れる」提供条件を受け、1時間判定の全数探索(Family C)を実施した結果、
**既存採用戦略の根幹に関わるデータアーティファクトを発見**した。ASK足を追加取得し、
mid=(BID+ASK)/2(ブローカーの提示・判定レートに近い)で全面再監査した記録。

### 1. 1時間判定探索(Family C)とアーティファクトの発見

- 16ペア×24時×(曜日+ALL)×H/L、M=4608・α=1.1e-05で探索 → BIDベースでは94本が全ゲート合格。
- しかし合格は**全てエントリー5〜8時(NYクローズ/ロールオーバー周辺)に集中**し、
  「5時LOW」が全ペア一斉に出る=USDが同時に強く・弱くなる、という価格としてあり得ない構成だった。
- 時刻別スプレッド(Close時点, 対価格bp): 通常時間帯 0.5〜1.3bp に対し **5時 2.7〜5.2bp / 6時 3.5〜6.6bp / 7時 1.6〜3.4bp**。
  ロールオーバーのBID押し下げが「LOWの勝ち」「翌時間のHIGHの勝ち」を機械的に生成していた。
- **mid再判定で生き残ったのは2本のみ**: 月曜7→8時 EURJPY HIGH(mid WR 64.31%、補正後Edge+9.7pp、p=2.8e-08)と
  USDJPY HIGH(62.52%、+7.9pp、p=2.3e-06)。いずれも既知の月曜アノマリーの初動1時間であり、mid判定でもM=4608のBonferroniを通過。
  → **「1時間・1.90倍」で優位性があるのは月曜朝のこの2本だけ。他の曜日・時間帯に1時間エッジは存在しない。**
  (`explore_1h.py` / `famC_1h_final.csv` / `famC_mid_audit.csv`)

### 制約

- mid=(Dukascopy BID+ASK)/2はブローカーレートの近似にすぎない。特にロールオーバー時間帯は
  どのレートにも±スプレッド/2の不確実性がある。実機レート突合が最終判定。
- 月曜7時エントリー自体もスプレッド拡大時間帯での約定であり、実機ではさらに不利方向の乖離があり得る
  (mid監査はこれを織り込み済みだが、-2pp補正の妥当性も実弾で再確認すること)。
