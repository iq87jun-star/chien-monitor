# ザオプション v4.0 採用20戦略 追加監査 — G3順列検定・G5年抜きJackknife (2026-07-23)

2026-05-25 の1000パターン検証（Bonferroni + Wilson + サブサンプル）で採用された
Tier S/A 20戦略に対し、当時未実施だった2つの検定と多重性の再補正を実施した記録。
フォワード検証（実機ペイアウト・実Edge測定）は本監査の対象外。

## 実施内容

| 検定 | 内容 | 基準 |
|---|---|---|
| G3相当 | ポジション循環シフト順列検定200本（曜日選択マスクを取引系列上でシフトし、シグナル↔リターン整合を破壊） | perm_p < 0.05 |
| G5相当 | 年抜きJackknife（2016-2026の各年を1年ずつ除外し補正後Edgeを再計算） | 最低Edge > 0 |
| 多重性再補正 | Phase16でペアを16に拡張した実効探索数 M=3200 で Bonferroni を引き直し | p < 1.56e-05 |

- データ: Dukascopy 1時間足10年（Drive `forex_ml/dukascopy_hourly/` と同一）、UTC→JST変換
- 取引抽出はオリジナル実装（Notion「1000パターン検証 実装コード」）を忠実に再現し、
  **全20戦略で n・WR が当時のCSVと完全一致**（再現性確認済み）
- Edgeは当時と同じ補正（スプレッド-1.0pp + 減衰-1.0pp）適用後、BEはペイアウト1.90/1.95に応じて52.63%/51.28%

## 結果サマリー

- **G5（年抜き）: 20戦略すべて合格。** どの1年を除外しても補正後Edgeは正（最低でも+3.24pp）。
  円安イヤーなど特定年に依存したエッジは1本もない。
- **G3（順列）: 12/20合格。** 不合格8本のうちEURGBP/USDCHFの火・水・金系は
  「曜日固有性がない」だけで、**親アノマリー（全曜日版）が超強力**なため実質問題なし（下記）。
- **Bonferroni M=3200: 上位12本合格、下位8本（Edge +5〜6.8pp帯）は不合格。**

### 重要な発見: エッジは2種類に分解できる

1. **曜日固有型（月曜アノマリー）**: 月曜7時系8本は全曜日ベースライン比で+5〜8pp上乗せがあり、
   順列検定でも有意。「月曜朝のリスク通貨上昇」は曜日固有の本物。
2. **セッションドリフト型（EURGBP/USDCHF朝）**: EURGBP 7→11時HIGHは**全曜日でWR 64.86%**
   （n=2701、p=5.2e-38、年抜き最低Edge+9.15pp）。曜日を選ぶ意味がほぼなく、
   毎日エントリーできる親アノマリーとして扱う方が強い。

## 運用への示唆

- **コア採用（フォワード対象の優先枠）**: STRONG 8本 + 親アノマリー2系統（EURGBP朝・USDCHF朝）。
  EURGBP/USDCHFは曜日別5本に分けず「毎日型」として集計する方が統計的に堅い。

  探索数を正直に数えると統計的裏付けが弱い帯。ロットを落とすか、フォワードで実Edgeが
  出るまで見送りが妥当。

- 月曜朝の同時ベット合計 158,000円(資産の約4割が同一朝に露出)

### リスク警告(重要)
資産40万円に対しDD予算40万円=「過去最大DD時に資金ゼロ」の設計。ブートストラップ5000パスでは:

| 配分 | 月平均 | 10年内DD30万到達 | 10年内DD40万到達(=枯渇) |
|---|---|---|---|
| 現行(30万設計) | +147,712 | 13.0% | 4.2% |
| 形状制約30万 | +179,838 | 21.3% | 7.3% |
| 形状制約40万 | +241,815 | 88.7% | **23.6%** |

さらに実際にはDDの途中で掛け金原資が細り計画通り張れなくなるため、理論より早く行き詰まる。
**実質資産40万円ならDD予算は25〜30万円(資産の6〜7割)に留めるのが妥当**で、
その場合の期待は形状制約30万案の月+179,838円。40万円予算はフォワードで実Edgeを確認し
資産が60万円程度に増えてからの引き上げを推奨。
