## 1. 定義(事前固定どおり)
- 基準 = 金の保有(XAUUSD・終値 → 終値の連続保有・月初 5 bps・スワップなし。Q236 と同じ系列で、0.61 / 0.89 / 1.16 を再現)。
- G1 = 前営業日の終値が 200 日単純移動平均より上の日だけ 1.0 倍、下は 0。G2 = 上 1.0 倍・下 0.5 倍。持ち高を変える日に 5 bps × 変化量の費用。
- 判定 = 基準に対して 前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しない。成立した形だけ口座モデルへ進む。

## 2. 判定
値 = Sharpe / 最悪月 % / 累積 %。

| 形 | 前窓(2016-01〜2021-09) | 探索(2021-10〜2024-12) | OOS(2025-01〜2026-07) | 最大下落 | 判定 |
|---|---|---|---|--:|---|
| 金の保有(基準) | 0.61 / −8.16 / +52.0 | 0.89 / −5.22 / +42.3 | 1.16 / −12.53 / +46.7 | −27.2% | — |
| G1 線の上だけ持つ | 0.33 / −6.96 / +24.0 | 0.60 / −4.91 / +24.9 | 1.42 / −11.55 / +54.0 | −35.7% | 不成立(前窓・探索で低下) |

- 線の下にいた日は全体の 26%、切り替えは 10 年で 74 回。
- 成立なしのため、口座モデル(第 2 段)は行っていない。

## 3. 数値化(参照・セル外)
- 線の上 / 下の金の日次平均: 前窓 +2.7 / +5.6 bps、探索 +4.2 / +8.3 bps、OOS +15.1 / −20.6 bps(下は 36 日)、全期間 +5.4 / +5.0 bps。差の t は −0.6 / −0.5 / +1.3 / +0.1。**2016〜24 年は線の下の日のほうが利益が大きい。** Q196 の「金は線の上のほうが良い」は木曜の金だけの結果で、保有には当てはまらない。
- 日数を変えても同じ: 100 日 0.30 / 0.71 / 1.62、250 日 0.38 / 0.57 / 1.23(G1・前窓 / 探索 / OOS)。
- スワップ込み(−52 bps/月): 基準 0.19 / 0.46 / 0.92、G1 −0.00 / 0.22 / 1.18、G2 0.11 / 0.36 / 1.06。持たない日はスワップを払わないが、それでも前窓・探索は基準より低い。−76 bps/月でも同じ並び。
- 長期(Dukascopy 日足): 2004〜2011 年は 基準 0.87・G1 0.67。2012〜2015 年(下落期)は 基準 −0.55(最大下落 −50.8%)・G1 −0.75(−29.9%)。2004〜2015 年は 基準 0.46(−55.5%)・G1 0.42(−38.9%)・G2 0.47(−47.2%)。**線で絞ると下落期の落ち込みは浅くなるが、Sharpe は上がらない。**

## 4. 読み方
- 金は 200 日線を割ったあとに戻すことが多く、線の下で持たない形は戻りを取り逃がす。切り替えの費用も 74 回分かかる。
- 落ち込みを浅くする効果(2012〜15 年で −51% → −30%)はあるが、利益も同じだけ減る。保険としての値段が見合うかは、口座の損失枠しだい。成立していないので口座モデルには進めていない。
- 金の保有に対する絞り込みは、VIX(Q236)・SKEW(Q174・木曜)・200 日線(本件)とも不成立。金は「持つか、持たないか、どの大きさで持つか」の判断になる(docs/493・494)。
