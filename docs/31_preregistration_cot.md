## 0. 背景・機構の独立性
価格パターン（FXカレンダー/MR/モメンタム/キャリー/コインテグレーション/横断）と多資産トレンドは
全滅済み（docs/14–30, 経緯ブランチ edge2–6）。本第3弾は**価格でなく「建玉＝フロー/ポジショニング」**
という直交データを使う。投機筋（CFTC TFF の Leveraged Money）の**ポジション極値は反転に先行する**
（コントラリアン）という確立した仮説。機構が価格パターンと別なので独立性が期待できる。

## 1. 多重検定の負債（正直な記録）
本プログラムは累積で多数試行済み（本セッション E3A–D + B1–3 + 経緯 edge2–6 ＝ 13候補 ADOPT 0）。
よって **Deflated Sharpe の N_trials は控えめに ≥ 50** で割り引く。甘く数えない。当たりを急がない。

## 2. 事前登録パラメータ（★固定）
- **候補数 N = 2**（C1/C2）。当たるまで増やさない。
- **α = 0.05 / 2 = 0.025**（順列p・残差alpha t の閾値）。
- **期間 = 2016-01..2025-12（10年・週次）**。
- **データ**: CFTC TFF（Traders in Financial Futures, Futures-Only, dataset gpe5-46if）の
  **Leveraged Money** long/short。対象 CME 7通貨先物: EUR/GBP/JPY/AUD/CAD/CHF/NZD。
  指標 = spec_net% = (lev_long − lev_short) / open_interest。
- **先読み回避（重要）**: COT は火曜時点の建玉が金曜公表。**週W(火)のデータ → 翌週W+1で建てる**
  （公表ラグを織り込む）。z スコアは過去窓のみ（shift 済）。
- 通貨対USDリターンは既存 FX H1（週次）。

## 3. 候補ルール（完全固定）
### C1 — 横断ポジショニング・コントラリアン（ドル中立）
- 各週、spec_net% の**3年(156週)ローリング z**（shift 済）を7通貨で算出。
- **z 最低3通貨をロング（投機筋が売り込み過ぎ→反発）、最高3通貨をショート（買い込み過ぎ→反落）**、
  ドル中立、保有1週。設計でベータ相殺。
### C2 — 時系列ポジショニング極値コントラリアン
- 各通貨、spec_net% z > +2（買い過熱）→翌週 SHORT、z < −2（売り過熱）→翌週 LONG。
  z が ±0.5 内に戻る or 4週で決済。7通貨を等加重合算。各々は方向性だが平均は中立寄り＋ゲート④で
  ベータ控除して評価。

## 4. 判定ゲート（強化版・全通過のみ ADOPT）
① 純益>0 ② 順列p(月次ブロック符号)<0.025 ③ ジャックナイフ最大p≤0.10
④ **ベータ中立化**: 対USD要因で回帰した残差alphaの **t>2.5** ⑤ コスト後生存
⑥ v7独立性 |ρ|≤0.30 ⑦ **Deflated Sharpe ≥0.95（N_trials≥50）** ⑧ **PBO≤0.20**
- 1つも通らねば「COTも無し」と正直に結論。
