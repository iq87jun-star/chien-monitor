|---|---|---|---|

## 2. 方法(実行前固定)

1. **LOYO選別**: 各年y(2016-2025の10フォールド)について、y以外の9年の**月次Sharpe**で銘柄を順位付け、
   下位Kを除外 → 除外年yのOOS月次リターンを記録 → 10年分を連結してOOS成績とする。
   フルバスケットの同一OOS窓と比較。
2. **合成**: v4/v7は残存銘柄の等重み(既存実装と同じ合成方法)。E5は**残存資産でリスクパリティを再構築**
   (単純平均ではない・既存 `e5_daily` と同一ロジック)。
3. **比較尺度**: 主=月次Sharpe(スケール不変)。副=フルバスケットと月次σを一致させた**vol-matched net**。
4. **ブラインドプラセボ**: 同スリーブから同数Kを**無作為に固定除外**する全組合せ
   (v4: C(9,3)=84 / v7: C(3,1)=3 / E5: C(4,2)=6)のOOS Sharpe分布を全数計算。
5. **安定性**: 10フォールドのうち、除外セットが「全期間で選ばれるセット」と一致した回数。

## 3. 決定規則(機械適用・実行前固定)

採用(=EA変更の提案に進む)は以下**全て**成立した仮説のみ:

- **c1 OOS改善**: LOYO-OOSで Sharpe(間引き) > Sharpe(フル) かつ vol-matched net も改善
- **c2 プラセボ**: LOYO-OOS Sharpeがブラインド間引き分布の**80パーセンタイル以上**
  (訓練で選ぶ価値がなければ、どの銘柄を捨てても同じ=選別に情報なし)
- **c3 安定性**: 除外セットの一致 ≥ **8/10フォールド**(年によって「負け銘柄」が入れ替わるなら
  それはノイズであり、除外は将来の当たり銘柄を捨てるリスクだけを増やす)
- **c4 相関(E5のみ)**: 間引き後E5と v7/E-Mon の月次|ρ| ≤ 0.4(指数集中による重複露出の防止)

不成立 → **現行バスケット維持**(間引きなし)。

## 5. 事前の期待(盛らない)

  入れ替わる公算が大きい。次点 = c2不合格(どのKを捨ててもOOSは同等=選別に情報なし)。
