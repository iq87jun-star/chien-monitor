## A. v7 予算リサイズ確定 — `research/colab_v7_budget_resize.py`
**目的**: 旧予算1.5%が10年でmaxDD~14.8%(失格)だったのを受け、予算を {1.5/1.0/0.75/0.60/0.50/0.40}%
と振り、安全(maxDD<=7%)かつ失格率<=5%の中で最速(MC合格率最大)の予算を確定する。

**使い方(Colab)**:
1. ノート冒頭の設定を確認: `USE_DRIVE=True`, `DRIVE_BASE`, `H1_DIR`(あなたのv7ノートと同じパス)。
2. スクリプト全体を1セルに貼って実行(自己完結。あなたのCell群への依存なし)。
3. 出力の表を読む。各予算で `純益% / maxDD% / 年次最悪% / 通しPhase1 / MC合格% / 失格% / 未決%`。

**読み方(重要)**:
- `maxDD%` は予算にほぼ厳密に線形(初期残高基準の固定%サイジングのため)。
  → 10年で 1.5%→~14.8% なら 0.60%→~5.9% を実測で確認できるはず。
- **`未決%` は失格ではない**。FundedNextは時間無制限なので「horizon(既定156週)内に+8%未到達」=
  「もっと時間をかければ到達」。**本当の不合格は `失格%`(DD抵触)だけ**。
- 推奨は「maxDD<=7% かつ 失格率<=5% の中で合格率最大」。**0.60%付近が選ばれる想定**。
  選ばれた予算を EA `InpWeeklyRiskPct` に設定(現EA既定=0.60)。

**スモーク結果(2.8年・MC短縮300×80週・参考)**: maxDDは完全線形(1.5%→5.72%, 0.60%→2.37%)。
2.8年では1.5%でもmaxDD5.72%と穏やか=**「2.8年の罠」を再現**。10年では同じ1.5%が膨らむはず。
→ 本スクリプトが「期間でDDが激変する」ことを可視化する。

## B. v8(USDCHF木曜午後SHORT)10年追認 — `research/colab_edge2_chf_validation.py`
**目的**: 2本目衛星v8(docs/17, LEAD・2.8年でp=0.136)を10年で追認。2.8年好績が楽観でないか。

**5ゲート(全て10年で)**:
| ゲート | 合格基準 | 2.8年での値 |
|---|---|---|
| G1 曜日プラセボ | 木曜だけ正・他曜日非有意 | 木+5.6%/他全マイナス ✅ |
| G3 順列 p | p<=0.05(Bonferroniは参考) | **0.136 ❌** |
| **G4 ジャックナイフ** | **max_p<=0.05(年依存解消)** | **0.483 ❌** |
| G6 円月曜相関 | <=0.4(独立) | 0.06 ✅ |
| 純益 | >0 | +5.6% ✅ |

**判定**: 5ゲート全通過 → v8を極小サイズ衛星として採用。1つでも崩れたら **v8破棄**(docs/14/15規律)。
**スモーク(2.8年)では 2/5 通過=未達**。10年でG3/G4が締まるかが全て。締まらなければ捨てる。

**使い方**: Aと同様、設定確認して1セル実行。出力の `>>> 10年判定: 5ゲート中 N 通過` を見る。

## C. 実行後の流れ
1. **A の結果**で予算確定 → EA `InpWeeklyRiskPct` を設定(0.60が外れたら表に従い調整)。
2. **B の結果**で v8 採否決定(通れば極小サイズ、ダメなら破棄)。
3. スワップ符号をブローカーで確認(docs/18 §3。−なら予算をさらに下げる)。
4. **デモ前進検証**: 確定予算でEURJPY/GBPJPY/USDJPYデモを数ヶ月。実DDが10年想定の内側か監視。
5. 想定内なら funded へ。逸脱したら予算を下げて再検証。

> 規律(docs/18 §7): DD・最悪値は『最も荒れた期間を含む最長データ』で測るまで暫定。
> 短期サンプルの良績は"上限"でなく"楽観側"。EA既定/推奨には必ず期間を併記する。
