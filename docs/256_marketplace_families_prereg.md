## 5. 見込みと注意

- 出品上位は「売れている」のであって「エッジがある」証拠ではない。GogoJungle のフォワードは公開口座の実績だが、生存者(残った商品)しか見えない。

- 想定打率は 5 族で 0〜1。過去 3 週間の 6,120 セルで通過 0 なので、ここで出なくても正常。
- M1〜M15 スキャルとグリッド系は本キューでは扱わない。前者はデータが揃えば(Dukascopy の bid/ask 2024-01〜が完了後)別途登録する。
