## 3. 読み方

1. **4 族とも棄却。** p < 0.05 が偶然期待の 1/28 しか出ないのは、往復 3pip のコストが条件付き短期セルの粗利(数 bps)を上回っているため。第 3 段の Sess が「見えた」のは同じコストが加算されていたからで(docs/249)、正しい符号では H1 の条件付き短期セルに 3pip を超えるエッジは無い。
2. F3(日中継続)は追随・逆行の両側で 5 割を切る = 最初の 4h の方向にその後の 8h は無関係で、コストだけが残る。
3. F4(クロスアセット先行)は機構が最も明確だったが、AUDJPY で IS のみ 0.667・前窓 0.24。2022〜2024 のリスクオン一方向の射影。
4. **H1 での「新規探索」はこれで一巡**(曜日・時間帯・保有・イベント・レンジ・ギャップ・継続・先行)。残る余地は ①M15 以下(bid/ask 両方)のデータ ②新しい銘柄クラス ③既存レグの改良・実口座との突合 の 3 つで、①②はデータの用意が要る。
