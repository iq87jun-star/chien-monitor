# 104.【事前登録】季節合成の最適化 — 構成ルール族のLOYO比較(結果を見る前に固定)

> ユーザー依頼「合成するなら合成も最適化したものを作りたい」(FN 2-Step $200k・季節EA稼働中)。
> 位置づけ: docs/80 §4 (b)「確証済みエッジの配分・サイズ最適化」= **新エッジ探索ではない**。
> ⚠ 本docは `research/seasonal_optimize_loyo.py` の**実行前**にコミットする(docs/72の流儀)。
> 結果は docs/105 に実出力JSONの転記のみで記載する。

## 1. 何を最適化し、何を最適化しないか

- **最適化しない**: 月別重みの数値そのもの(12ヶ月×7スリーブの自由最適化はパラメータ数>データで
  in-sample深化。docs/87がYEARROUND_05を「最もin-sampleバイアスの重い構成」と警告済み)。
- **最適化する**: 「月別ランキング→配分」の**構成ルール族**(少数・下記に固定)の選択。
  採点は全期間成績ではなく**LOYO(leave-one-year-out)のOOS成績のみ**。

## 2. 候補ルール族(これで固定・追加は再登録)

| ID | ルール | パラメータ |
|---|---|---|
| **R0** | 年間固定配分(月別選択なし)= v4 30 / v7 25 / E-Mon 25 / E5 20 | なし(対照=「月別性に価値がなければこれで良い」) |
| **R1** | 現行YEARROUND_05: 訓練年で平均月利≥0.5%のスリーブを平均比例 | 閾値0.5%固定 |
| R2a | 訓練年の月別 top-1 を100% | なし |
| R2b | 訓練年の月別 top-2 を平均比例 | なし |
| R3a/b/c | 収縮: w = λ·R1 + (1−λ)·R0 | λ = 0.25 / 0.50 / 0.75 |
| R4 | R1の重みを訓練年の月別volで割って再正規化(リスク調整比例) | なし |

- スリーブ候補(7・季節EAの実装と同一): v4 / v7 / v7横(4クロス) / E-Mon / E-Mon横(3指数) / E5 / S-Jul(US500+NAS100買持ち)。
- 月別成績が全候補0.5%未満の月にR1が無配分となる場合、その月はノーポジ(現行EAと同じ)。

## 3. 手順(固定)

1. データ: Yahoo日足 固定窓 **2015-01-01〜2026-06-30**(E5の12ヶ月ルックバック確保)。SHA-256記録。
   スリーブ月次系列は既存ロジック(parallel_vs_existing_compare 等)を逐語流用。コストも既存と同一
   (円ペア2pip・指数3bps・月次系0.5bps/月)。
2. **LOYO**: テスト年Y∈{2016..2025}について、訓練=残り9年で月別ランキング作成→Yで成績。
   120ヶ月(欠損月は全ルール共通で除外)のOOS系列で 平均月利 / Sharpe / maxDD / Calmar / 最悪月。
   2026H1はLOYOに入れず参考表示のみ。
3. **プラセボ(月ラベルシャッフル)**: 勝者ルール(R1含む月別選択系)について、各フォールドの
   「月→重みベクトル」対応をランダム置換×200。実OOS Sharpeが置換分布の**上位5%に入らなければ
   「月別性はノイズ」と判定**しR0/R3側を推す。
4. **コスト感応**: 全コスト2倍で上位ルールを再計測(順位逆転・符号反転がないか)。

## 4. 採否の決定規則(事前固定)

- 候補CをR1(現行)より優先するのは、**LOYO OOSで Sharpe(C) ≥ 1.1×Sharpe(R1) かつ Calmar(C) ≥ Calmar(R1)
  かつ コスト2倍でも同順位** の全てを満たす時のみ。
- R1がプラセボ不合格(月別性ノイズ)なら、上式に関わらず**R0/R3系を推奨**する。
- どの候補も基準を満たさなければ**「現行YEARROUND_05のまま」が結論**(それも価値ある確認)。
- 合格ルールが出ても実装は: ユーザー承認 → FNガード(+8%/−10%/日次−4%)込みの倍率校正
  (docs/87と同じ「最悪単日逆算×0.8」) → EAに**新シナリオとして追加**(既存は残す) → **デモ並走**の後のみ。
  $200k実チャレンジの走行中EAは本検証の結果では**変更しない**。

## 5. 既知の限界(先に書く)

- Yahoo日足近似(配当除く・v4はSL/TP簡易再現)。絶対値でなく**ルール間の相対比較**に使う。
- LOYOでも「スリーブ7本の候補集合自体」は全期間の知見で選ばれている(この選択バイアスは消せない)。
  ゆえに合格でも級は上がらず、**デモ前進検証が最終判定**である事実は変わらない。
- 月次解像度: 日次ガードの非線形は倍率校正段階(最悪単日)でのみ考慮。
