## 3. 読み

- **3 本目以降は OOS リターンを足していない**(+14.1 → +14.2 → +14.4 → +13.1)。増えているのは**倍率**(3.48 → 4.80)と**窓内累積**(+97 → +152%)だけ。個別の OOS は WedS CADCHF +0.1% / TueS CADCHF +0.2% / Thu XAUUSD −2.1%。
- 仕組み: 相関の低いセルを足すと合成の裾が薄くなり、校正倍率が上がる。**足したセル自体が稼がなくても倍率が上がる**ので、窓内の数字は必ず良くなる。サンプル外で確かめない限り「拡張 = 改善」には見えてしまう。
- WedS/TueS CADCHF は同じ銘柄の別曜日(相関 0.5 以下で規則は通る)。実質「CADCHF を週半ばに売る」1 本で、2 本に見えているだけ。
- Thu XAUUSD は最悪月・DD・MC を全部悪化させる。

## 4. 帰結

| | 判断 |
|---|---|
| 拡張できるか | **規則上は 5 本まで**。ただしサンプル外で効いたのは **2 本目まで**で、3〜5 本目は倍率を上げるだけ |
| 扱い | 5 本すべてを月次定例の「(候補)」行に入れる(紙上なので費用ゼロ)。**LEAD 判定は docs/229 §4 の基準を個別に当てる**(6 ヶ月・+月 ≥ 4/6・累積 > 0) |
| 採用の順序 | LEAD になった順に 5 年版へ。ただし **3 本目以降を足すときは、足す前後で OOS が改善していることを条件**にする(窓内の改善は根拠にしない) |
| 倍率 | 拡張で校正倍率が上がっても、**docs/228 §2 の 3.3〜3.6 を上限**に据え置く。倍率増は「サンプル内で薄くなった裾」の反映であって、実力ではない |
