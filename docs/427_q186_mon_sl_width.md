## 1. 結論
- **(A) 改良系 0 / 20。** 3.0 倍より広い幅・SL なしは、どの構成でも「IS・OOS とも Sharpe 改善かつ最悪月が悪化しない」を満たさない。累積 10,096 → **10,116**。
- **レグ単体(ガード無し)で平均が最大なのは SL なし。** ただし 3.5〜5.0 倍は 3.0 倍とほぼ同じか僅かに低く、増えるのは 6.0 倍と「なし」だけ(Mon4: 7.49 → 8.05 bps = +7%、Mon2: 8.81 → 9.45 = +7%)。代わりに IS の Sharpe と最悪月が悪化する。
- **(B) 口座の日次ガードを入れると、広げても利益は増えない。** SL を広げると損切りの代わりにガード(全決済)が先に動くだけで、平均・到達率とも 2.5〜3.0 倍が最良。**現行 3.0 倍は変更不要。**
- 指数の月曜レグ(NAS100・US500)は 3.0 倍で 45% が SL にかかり、平均は SL なしの 3 分の 1(2.16 対 6.80 bps)。広げると IS・OOS の Sharpe は上がるが最悪月が −1.2 → −3.8%(OOS)と悪化するため不通過。重みが小さく(0.75〜2.0 倍)口座の結果にはほぼ効かない。
