## 3. 読み
- **A1(SQ 週の前半 L)は「2021 年以降だけ」の型。** IS・OOS では他の週を 40〜115 bps 上回るが、前窓(2018〜2021-09)では SQ 週の方が他の週より弱い(+2.2 vs +8.3)。Mon 円クロス(docs/250)・水曜の円買い(docs/272)と同じく、2022 年以降の円安・日本株高の局面に乗っているだけで、10 年のエッジではない。
- **B1(3・9 月の権利取り L)は 3 窓とも他の月を上回る**(+100 / +255 / +35 bps)唯一の型。ただし n = 17、1 回の振れが ±800 bps(2022-03 +1,133・2022-09 −839)で t 1.69、OOS の上乗せは +35 bps と小さい。配当再投資の先物買い(権利落ち日前後の指数ファンド)という機構の説明はあるが、統計的には区別できない。
- C(期末・期初の円)は前窓と IS で同符号でも OOS で消える(C1 L: +44 / +42 / +5)。
- SQ 当日・前夜・SQ 後に系統的な動きは無い(A2〜A4 の t は ±1 以内)。

## 4. 判定・次
- **通過 0 / 18。紙上候補の追加なし。配備・EA・先物ボットは不変。** 累積 **9,710**。
- 日本系で「10 年でエッジ」と言える新規セルは今回も出なかった。日本系の候補は、引き続き Mon 円クロス(CFD)と Mon 指数日中版 JP225/NIY(先物 1 枚)の 2 つ。
- B1 は機構があり 3 窓とも同符号なので、**イベント数が増えるまで年 2 回の観測を記録するだけにする**(次は 2027-03・2027-09。紙上候補には入れない。基準は変えない)。
