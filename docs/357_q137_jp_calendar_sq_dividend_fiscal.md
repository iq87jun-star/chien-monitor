## 1. 事前登録(結果を見る前に固定)
共通: Dukascopy H1 bid、価格は各時刻の H1 バー始値(欠けたら 3 時間以内の次のバー)。東京の寄り = 00 UTC、東京の引け ≈ 06 UTC。JP 営業日は `q_jp`(祝日 + 12/31〜1/3)。コスト JP225 4 bps・USDJPY 3pip(`q_common.cost`)。方向は L / S を両方セルとして数える(事前に方向を決める理論が無いため)。

- SQ 日 = 毎月の第 2 金曜(JP 休場なら前営業日)。全月を対象(メジャー SQ の 3・6・9・12 月に限らない)。
- 権利確定日 = 3・9 月の最終 JP 営業日。権利付最終日 = 確定日の 2 営業日前(2019-07-16 の T+2 移行前は 3 営業日前)、権利落ち日 = その翌営業日。**JP225 の期末最終週は配当落ちの値下がり(CFD では調整額で相殺)を含むため、C1 は USDJPY のみ**、B は落ちをまたがない形にした。
- 判定: §1 標準(IS 二項 p < 0.05/9,710 = 5.15e-6・IS 月数 ≥ 24・OOS 平均 > 0・前窓 +月率 ≥ 50%)。JP225 の H1 は 2018-01 開始なので前窓は 2018-01〜2021-09。
- **B・C は年 2 回のイベントで IS が 6〜7 か月しかなく、設計上「判定不能」**。参照として 2016(JP225 は 2018)〜2026 のイベント単位の平均・t 値・勝率を出すが、通過扱いにはしない(紙上候補に上げる条件は「全期間 t > 3 かつ 3 窓とも同符号」)。
- 先物プロップ(MFFU: 16:10 ET フラット)で持てるのは A3 と C の場中部分だけ。A1・A2・A4・B・C は日をまたぐので CFD のスイング口座(Fintokei スイング・FN の週末可)向け。
