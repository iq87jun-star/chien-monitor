# docs/177: プロップファーム運営のM&A市場調査 — 売り案件は存在する

日付: 2026-07-29
関連: docs/174(運営収支)、docs/175(難易度・段階ルート)、docs/176(データの帰属)
問い: サイトM&A系マーケットにプロップ運営類の売り案件はあるか。

---

## 1. 結論

**ある。ただし国内サイトM&A(ラッコM&A/TRANBI等)ではなく、海外の専門マーケットに。**
プロップファーム専門のM&Aマーケット「YourPropFirm Marketplace」が2024年末から稼働しており、
2026年7月時点で ¥700万〜1.4億円のレンジで現物の売り案件が並んでいる。
国内サイトM&Aにあるのは周辺資産(EA配布ブログ、海外FXのIB/LPサイト)のみ = docs/175 の段階0〜1相当。

## 3. docs/174/175 との接続 — M&Aルートの意味

- **買収 = docs/175 の段階3へのショートカット**。S課題のうち、法人(①の一部)と決済(②: 稼働中PSP契約)とテック(⑥)が「実績付きで」手に入るのが本質的価値。新規法人が最も審査に落ちやすい②を、稼働実績ごと買えるのは大きい。
- **ただし買収 = 「資金化済みトレーダーの負債帳簿」も買う**ということ(docs/174 の核心)。
  売り手が値下げしている理由が「sharp比率の上昇に気づいたから」である可能性は常にある。
  → 逆選択は顧客だけでなく**売り案件そのものにも働く**。

## 4. DD(買収監査)チェックリスト — docs/174 を武器にする

1. **生取引データの開示を DD 条件にする**(docs/176 と同じ急所)。全口座の取引履歴から
   sharp 比率 s を自分のモデル(sim/operator_economics.py)で実測 → 妥当な買収価格が逆算できる。
2. 登録ユーザー数ではなく**課金アクティブ数と月次購入数**(49,000+ユーザー等の数字は虚栄指標)。
3. **ペイアウト履歴と未払い残高**(支払い遅延はThe Funded Trader型崩壊の前兆)。
4. **PSP契約の譲渡可能性とチャージバック率**(契約が買収で失効するなら②の価値は消える)。
5. ブローカー/テックベンダー契約の譲渡条項、法人の許認可・所在地の維持コスト。
6. $200k超の案件は専門アドバイザー推奨(業界記事の一致した助言)。

## 5. 含意

- 「運営に回る」選択肢は理論上の話ではなく、**¥710万(シェル)〜¥5,000万前後(稼働中堅)で現に買える市場がある**。
- 自分の優位は買収局面でも同じ: sim/operator_economics.py は**買収価格の妥当性検証ツール**としてそのまま使える(DDで生データを取得し s を実測 → 24ヶ月キャッシュフローと破綻確率を推計 → 価格と比較)。
- 法務(①の日本居住者向け販売の適法性)は買収しても消えない。セントルシア法人を買っても
  「日本から日本人に売る」構造のリスクは残る点は docs/175 と同じ。
