## 0. 一行結論

**v7の現行執行設定は実測で正しかった。** ①エントリー時刻セット{04,06,08,10}UTCは代替2セットに
3ブロック全勝されず**変更なし**(決定規則どおり) ②スプレッド上限3.0pipsは実測p95×1.2(2.8-2.9)とほぼ一致=
**据え置き** ③実測往復コスト≈1.0-1.3pips は検証仮定(2pips)の**約6割=検証済みnetはコスト面で保守側**だった
ことを確認。おまけとして、実ブローカーデータ2.5年でv7が**全3ブロック正**(B1+27.3%/B2+0.7%/B3+4.4%,
EURJPY素リターン)というフォワード寄りの生存証拠が得られた。

## 4. コスト再解釈(決定規則3)

検証(research系)の円ペア往復コスト仮定=2pips に対し、実測往復(スプレッド1回横断)は**中央1.0-1.3pips**。
**実コストは仮定の約6割** → v7/v9の検証済みnetはコスト面で**保守側に立っていた**ことが確定
(下方修正は不要。上方修正も行わない=数字は盛らない)。
