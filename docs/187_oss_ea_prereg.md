## 2. 再実装仕様の凍結(原典パラメータ非公開分)

C1 の原典は骨格のみ開示でパラメータ値は非公開。以下を**検証前に凍結**する:
- N ∈ {20, 55} の2案のみ(ドンチャンの古典値。探索しない)
- SL = 2.0×ATR(14), トレール = 2.5×ATR(14), timeout = 48本, リスク0.5%/取引
- コスト: USDJPY spread 1.2pips + slip 0.5pips(リポ慣例値)、XAUUSD spread 0.35 + slip 0.10

C2 は README 記載のデフォルト値をそのまま使用(SL400pt/TP1200pt/トレール700pt起動100pt刻み/リスク1%)。

## 3. 合否ゲート(全通過で「デモ前進検証候補」。1つでも不合格なら REJECT)

| ゲート | 基準 |
|---|---|
| G1 | PF ≥ 1.30(コスト込・10年) |
| G2 | equity最大DD ≤ 8%(プロップ-10%規則へのマージン) |
| G3 | LOYO: 負け年 ≤ 2 |
| G4 | コスト2倍で PF > 1.10 |
| G5 | プラセボ(符号シャッフル2000回)p < 0.05 |
| G6 | 自ポートフォリオ月次との相関 \|ρ\| < 0.30(データ無ければ保留=ADOPT禁止維持) |

**多重検定の申告**: 本登録の試行数は3(C1×N2案+C2×1)。G5 の実効αは 0.05/3 ≈ 0.0167 を
併記判定する。パラメータを登録外で動かした場合、その結果は無効(docs/165)。

## 4. 合格後の扱い

- 合格=ADOPT ではない。次段はデモ前進検証(docs/29 の慣例)3ヶ月。
