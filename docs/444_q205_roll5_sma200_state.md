- ベース = 配備形の Roll5: 水曜 20:00 UTC 始値で USDJPY・EURJPY・GBPJPY・AUDJPY・CADJPY を SHORT → 木曜 00:00 UTC 始値で決済。5 本等分・通貨別の政策金利差 2.0pp 未満の本は 0・コスト往復 3pip。

## 4. 読み方
- 200 日線の状態は、ロールでは「どちらに寄せても改善」にならない。下に寄せる(A)と Sharpe が下がり、上に寄せる(B)と利益が減る。
- 月曜の買い(Q195)と水曜の売り(本稿)の両方で、200 日線の下のほうが 1 回の平均が大きい。売買の向きが逆なのに同じ状態で大きくなるので、200 日線の下 = 値動きの大きい局面、と読むのが自然。月曜で縮小が効いたのは(docs/436・437)、ガードに掛かりにくくなる経路の話で、同じ理屈はロールにも当てはまる可能性があるが、ロールは 1 回の動きが小さく(標準偏差 9〜27 bps)ガードには遠い。
- 門なしの前窓で「上」が −3.56 bps と負なのは、金利差が小さい時期に上の状態で売ると負ける、ということ。金利差の門(配備済み)がこの負けを除いている。

- (A) 下で売る = 不成立。
