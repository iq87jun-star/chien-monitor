## 0. 先に読む注意
- **30 という線は、Q267 の帯の表を見て出てきた区切り(後づけ)。** 今回の「成立」は、事前に立てた仮説の確認ではなく、同じデータの中で見つけた区切りを同じデータで測った結果。規則上は成立だが、確からしさは事前に登録した案より一段低い。

## 1. 定義(事前固定どおり)
- 夜の指数 = 月曜 20 UTC に 5 本(NAS100・US500・US30・JP225・UK100)を買い、火曜 13 UTC に決済。
- A = 前金曜の VIX が 25〜30 の週は合計 0.25(いまと同じ)・30 超の週は合計 0.50。
- B = 25〜30 の週は合計 0.125・30 超の週は合計 0.50。
- 判定 = 「配備形 + いまの夜の指数(一律 0.25)」に対する 3 窓(Sharpe が 3 窓とも上・最悪月が悪化しない)。

## 4. 読み方と限界
- 登録した条件(3 窓で成立・口座モデルで一律の形より悪くなる場面が無い)は A・B とも満たした。**採用の検討に進める候補**になる。
- ただし §0 のとおり、30 の線は後づけ。「30 超を 2 倍」が効くのは、過去の 28 週がそうだったからで、その 28 週を見てから線を引いている。線を 28 や 32 に置いても似た結果になるはずだが、それも同じデータの中の話。
- 30 超の週は月曜の円クロスも荒れる。口座モデルは同じ週の円クロス・指数・夜の指数を重ねて日次のガードを数えており、その上で失格が増えていない。
- 実行前の読み: 「Sharpe は上がる見込みが高い」は当たり。「最悪月と口座モデルの失格は五分五分」は通った。

## 5. 提案(EA への含意。採用はユーザーの「切替」の後)
- 入れる場合は、宝くじの EA に「30 超の週の倍率」を 1 つ足す(v1.16)。いまの 4 分の 1 の大きさのまま A にすると、25〜30 の週は名目 0.5(いまと同じ)・30 超の週は名目 1.0。
- A を勧める理由: いま承認済みの形から何も減らさず、30 超の週だけ足す形で、足す設定が 1 つで済む。B(25〜30 を半分)との差は小さい。
- 紙の候補 `MonNightIdxHot` は一律のまま。荒れた週が来たら、帯ごとの結果を記録する。
