# 64. 規約準拠の【新銘柄】探索 — 金/銀/WTI 単独 10年バッテリー（誠実な結果）

> ユーザー要望「規約を準拠しながら、新たなポートフォリオ or ポートフォリオに組込む銘柄＆手法を考案」。
> 確定構成 **v4(FX合議) : E-Mon(株価指数 月曜LONG) = 55:45**（docs/59/61）に対し、**規約に抵触しない新レッグ**を
> 探索した。出所: `research/edge10_gold_standalone_10y.py` → `research/results/edge10_gold_standalone_10y.json`
> （Yahoo日足 約11年・2015–2026）。⚠ 数字は盛らない。出なければ「出ない」と書く（docs/07/08の規律）。

## 0. なぜ「金/銀/WTI を単独で」なのか（規約からの逆算）

FTMO/FundedNext の核心禁止 = **同一/高相関銘柄の反対両建て（口座間も対象）**。
∴ 新レッグは **v4 が触る FX** とも **E-Mon が触る株価指数** とも別の資産でなければ衝突しうる。

| 候補 | v4(FX)と衝突? | E-Mon(指数)と衝突? | 既検証 |
|---|---|---|---|
| FX 追加ペア | ◯衝突しうる | — | docs/14 で全滅（曜日/ToM・非JPY） |
| 株価指数の別手法 | — | ◯衝突（E-Mon=指数LONG, 反対SHORTは違反） | E5指数=E-Monと衝突(docs/59) |
| **金/銀/WTI 単独** | **×非該当** | **×非該当** | **未検証**（doc27は"金+指数"のTSMOM/RP/回転バスケット内のみ） |

→ **金/銀/WTI は構造的にヘッジ衝突ゼロ＝規約クリーン**。かつ「これらを**単独で** day-of-week /
turn-of-month / **日足**トレンド / **日足**平均回帰」で検定したことは無い（doc27のE5は金を**月次TSMOMの
バスケット成分**として使っただけ。E5cで指数を外すと月次TSMOMは死亡 Calmar0.01, docs/59）。
本書は docs/14 の進路②「データ宇宙の拡張（金）」を、**プロジェクトと同一の厳格ハーネス**で実行する。

## 1. 事前登録バッテリー（42セル）と判定基準

- 銘柄: **XAUUSD(金) / XAGUSD(銀) / WTI(原油)**（Yahoo: GC=F/SI=F/CL=F、約11年日足）。
- 手法×方向: 各銘柄に〔曜日5×{L,S}=10〕＋〔turn-of-month×{L,S}=2〕＋〔日足TSMOM(20/60/120日合議)〕
  ＋〔日足平均回帰(RSI<35 L / >65 S)〕= **14セル × 3銘柄 = 42検定**。
- ノールックアヘッド（確定足→翌足始値約定）。往復コスト基準 **5bps**、感応 2/5/10/20bps。
- ゲート（docs/14/27と同一）: **G_perm** 順列p(月次集約=自己相関頑健) ≤ Bonferroni(0.05/42=**0.00119**) /
  **G_jk** 年次ジャックナイフ max_p ≤ 0.10 / **G_oos** IS・OOS両方+ / **G_indep** E-Mon proxy・株指数β・
  対象自身buy&hold との月次相関 |ρ|≤0.4 / **G_plac** ランダム方向プラセボが非有意かつ本物>プラセボ /
  **G_cost** 2–20bpsで純益+。**ADOPT=主要6ゲート全通過**。LEAD=net>0 かつ 順列p≤0.10 かつ OOS+。

## 2. 結果（実行値・誇張なし）

> **ADOPT=0件。Bonferroni(0.00119)生存=0件。順列p≤0.05(生)=1件のみ**（XAGUSD火曜L, p0.0397）。
> 42検定で偶然期待される p≤0.05 は約2件 ⇒ **観測1件は偶然と区別がつかない**。
> 弱いLEAD(3/6)が2件出たが、両方とも Bonferroni・ジャックナイフ・高コストで脱落。

### 構造的に重要な NEGATIVE（＝確定構成の正しさの裏付け）

- **v4の平均回帰機構(RSI逆張り)を商品に適用すると壊滅**: XAUUSD MRd **−97.1%** / XAGUSD MRd −99.4% /
  WTI MRd −100%。**商品はトレンド資産・FXメジャーは平均回帰**という非対称が10年で明白。
  → **v4をそのまま金属/原油へ拡張してはいけない**（確定構成が v4=FX に限定しているのは正しい）。
- **日足TSMOMも陰性・巨大DD**（XAUUSD +21.9%/−42.5%・WTI +16.2%/**−90.8%**）。月次TSMOM(E5c)が死んだのと
  同型で、商品トレンドは素サイズではプロップ枠に収まらない。
- 曜日アノマリーは金/銀/WTIでもほぼノイズ（多数が順列p=1.0）。docs/14の「曜日エッジはJPYクロス固有」を商品でも再確認。

## 3. ∴ 誠実な結論

> **厳格ハーネスは新しい"コア脚"を1本も認めない。これはプロジェクト全史と整合する**
> （市場が頑健に与えたカレンダーエッジは円月曜＝v7と指数月曜＝E-Mon系だけ。docs/14）。
> **したがって本線の推奨は変わらず確定構成 v4:E-Mon = 55:45（暗号は任意衛星≤8%）。**

ただし**ユーザー要望（新銘柄＆手法の考案）に正直に応えるなら**、42検定で唯一「**新規・規約クリーン・
無相関・プロップ許容DD・プラセボ死・IS/OOS非減衰**」を同時に満たす近接候補が1つだけある:

### ★ 唯一の前向き候補 = 金(XAUUSD) turn-of-month LONG（**小衛星・デモ先行のみ**）

「月末最終営業日＋月初3営業日に金をLONG保有」という、機関のリバランス／月末フロー仮説に基づく**新規**エッジ。

| 観点 | 金ToM-L | 既存の暗号衛星(参考) |
|---|---|---|
| 規約 | **完全クリーン**（金はどの業者でも可・FX/指数と非衝突） | 暗号可業者のみ |
| 相関 | E-Mon −0.11 / 指数β +0.12 / **無相関** | v4 −0.10 / 概ね無相関 |
| maxDD(素) | **−13.1%** | **−54.8%**（docs/54） |
| プラセボ | 完全に死(p1.0)＝方向に価値 | — |
| IS/OOS | +22.9/+16.0（**減衰なし**） | — |
| 弱点 | **順列p0.057(p≤0.05未達)・JKmax0.179(1年依存)・20bpsで−**＝**コア脚不可** | 高DDテール |

**位置づけ**: コア脚の基準（Bonferroni/JK）は満たさない**弱いLEAD(3/6)**。だが **DDプロファイルは暗号衛星より
明確に良く（−13% vs −55%）、規約も完全クリーン**。∴「**暗号と同格 or それ以上に妥当な、≤5–8%のデモ先行
小衛星**」として提示できる。**本資金のコア配分にはしない。**

## 4. 組込み方（採用する場合の構成・規約準拠）

> 既存の確定構成は一切変えず、**金ToMを薄い衛星として上から被せる**だけ（最小の手間・最小のリスク）。

| 構成 | v4 | E-Mon | 金ToM衛星 | 規約 | 用途 |
|---|--:|--:|--:|:--:|---|
| **確定（本線）** | 55% | 45% | — | ✅ | 推奨（変更不要） |
| **+金ToM衛星** | 53% | 42% | **5%** | ✅ | 無相関を1本足して滑らかさ微増を**デモで検証** |
| （攻め）| 50% | 42% | 8% | ✅ | 衛星上限。素maxDD−13%×0.08≈寄与−1%枠 |

- **規約チェック**: 金 = FX(v4)・指数(E-Mon)と別資産＝**同一/高相関の反対両建ては構造的に発生しない**。金SHORTは作らない（LONGのみ）。
- **分散効果は"緩やか"**（無相関1本追加でSharpe微増）。**劇的ではない点を誇張しない**（docs/55の教訓: 儲けの源は重み調整でなく分散だが、弱LEADの寄与は控えめ）。
- **最低取引日数**: 金ToMは月4営業日相当を1ポジで保有。v4/E-Monと併せればFundedNext最低5日は容易に満たす。
