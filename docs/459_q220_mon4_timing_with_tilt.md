# 459.【Q220】月曜の時間帯の案を、線による縮小(EMA50・SMA200)を掛けた形でやり直す(改良系・セル 8)→ 棄却 0 / 8。縮小を掛けても時間帯の結論は変わらない。短く持つ形は 2016〜21 年に負け、前倒しは Sharpe が 3 つの期間で上がるが最悪月がわずかに悪化して基準に届かない

2026-11-15 登録・実行(ユーザー「Ema50では如何でしょうか」→ 確認の回答「時間帯の案を EMA50 でやり直す」)。docs/244 Q220。スクリプト `research/queue/q220_mon4_timing_with_tilt.py`、結果 `research/results/q220_mon4_timing_with_tilt.csv`。累積セル 10,177 → **10,185**。EA・マニフェスト・config・紙上フォワードは変更なし。

## 1. 方法(事前固定)
- 月曜の円クロス 4 通貨(各 0.25・往復 3 pip)に「線の下 1.0 倍・上 0.5 倍」の縮小を掛けた形で、時間帯だけを替える。線 = 日足 EMA50 / 日足 SMA200。
- 時間帯: 配備形 = 4 / 6 / 8 / 10 UTC 建て × 24 時間。T1 = 建てを {0, 2, 4, 6} UTC に前倒し。T2 = ロンドン時間だけ(07 → 16 UTC)。T3 = 4 / 6 / 8 / 10 UTC 建て → 同日 20 UTC 決済。T4 = 同 → 12 時間後に決済。
- 判定 = 同じ線の縮小を掛けた配備形の時間帯に対して、前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しない。

## 3. 読み取れること
- **縮小を掛けても時間帯の結論は変わらない**(0 / 8)。EMA50 でも SMA200 でも、どの時間帯の案も配備形を 3 つの期間すべてでは上回らない。
- **短く持つ形(T2・T3・T4)は 2021 年以降だけ良い**。探索・OOS の Sharpe は高い(2.0 前後)が、2016〜21 年は配備形より悪く、ロンドン時間だけの形はマイナス。弱い時期は 1 回あたりの利益が薄く、短く持つと往復のコストが残らない。24 時間持つ形が弱い時期に一番耐える。
- **前倒し(T1)は惜しい形**。Sharpe は縮小なし・EMA50・SMA200 のどれでも 3 つの期間すべてで上がり(SMA200: 0.46 → 0.51・1.51 → 1.89・1.20 → 1.42)、累積も増える。ただし探索と OOS の最悪月が 0.01〜0.04 ポイント悪化して基準に届かない。Q60(docs/305)でも Mon4 の前倒しは同じ理由(最悪月)で不成立だった。
- 基準は事前に決めたものなので緩めない。前倒しは棄却として扱う。

## 4. 判定
- **棄却 0 / 8**。配備(SMA200・4 / 6 / 8 / 10 UTC × 24 時間)を変えない。紙上フォワードにも入れない。
