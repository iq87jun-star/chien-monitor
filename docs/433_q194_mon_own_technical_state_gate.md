## 3. 読み取れること(判定外)
- 「弱い状態」の 4 条件は、見送った建ての平均(+11〜73 bps)が残した建て(+5〜6 bps)の 2〜10 倍。月曜の円クロスの上昇は、直前に下げていた通貨・週で大きい。
- 通貨別・窓別でもほぼ同じ向き(`_bypair.csv`): 「終値 < SMA200」は 4 通貨 × IS / OOS の 8 区分すべてで見送った側が高い。「終値 < SMA20」は 7 / 8、「前週下落」は 7 / 8。
- つまり逆向きの使い方(弱い状態の通貨を厚く、強い状態を薄く)が候補になる。ただしこれは本検証の数字を見た後の着想で、同じ IS / OOS で検定し直しても独立の確認にならない。確認に使えるのは、今回の改良判定に使っていない前窓(2016-01〜2021-09)と、今後の紙上フォワード。
