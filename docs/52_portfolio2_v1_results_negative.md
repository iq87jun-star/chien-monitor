## 3. 診断 — なぜ転移しなかったか

- **MR(v4機構)**: v4の平均回帰エッジは **メジャー9本に固有**だった。クロスへ移すと **net+2.3%(ほぼフラット)・
  IS前半がマイナス**＝統計的に「エッジ無し」。FX平均回帰がそもそも脆い（docs/21 で MR系は全滅）ことの再確認。
  - クロスにはトレンド性の強い銘柄（GBPAUD/AUDCAD等）が混じり、平均回帰と逆。低ボラのEUR系（EURCHF等）は
    そもそも値動きが小さく取れない。**"メジャーの平均回帰"という特異点**だけが効いていた。
- **RP(E5機構)**: E5のトレンドエッジは **金＋米独株指数の2016-25上昇相場**が源泉。代替バスケットは:
  - **原油(USOIL)**: 2020年マイナス価格・whipsawでTSMOMが刈られる典型（docs/22の「FXトレンド死」と同類）。
  - **銀(XAGUSD)**: 方向感に乏しくトレンド追随が空振り。
  - **FTSE(UK100)**: 10年ほぼ横ばい。**日経(JP225)**のみ多少トレンド。
  - → バスケット全体で **net −16.9% / maxDD −41.7%** の**負のエッジ**。docs/27 で MA1-6 を試して
    **E5(metals_idx)だけが生存**したのと整合——**トレンドが乗る別バスケットは見つかっていない**。

## 4. 意味（プロジェクト標準結論の再確認）

docs/40・42 の正直な結論「**9ゲートを通った無相関エッジは v7/v4/E5 の3つだけ**」は、
**「機構を別ユニバースへ移す」最有力アプローチでも覆らなかった**。
- エッジは**ユニバース固有**（v4=メジャーMR・E5=金+米独株トレンド）で、汎化しなかった。
- **"真に独立した第2の検証済みエッジ"は、この相場データには無い**——という結論がより強固になった。

## 7. 最終結論・推奨

- **第2ポートを"新しい独立エッジ"で作るのは、この相場データでは不可**（v1＋スイープで実証）。
- **実利的な並走は B案＝実証済みエッジ(v7/v4/E5)を第2口座で運用し、設定で脱相関**:
  - 円レッグを **v9(同日決済・swap防御)** に差し替え（v7と同エッジだが約定時刻/オーバーナイトが別）
  - v4 の**ペアを2口座で分割**（口座1=メジャー前半／口座2=後半 等）で建玉の重複を減らす
  - E5 は片方のみ、または legRisk を口座間で変える
  - → エッジは確証済みゆえ「同レベル検証」は自明に満たし、**取引の重なりを減らして口座分散**を得る
    （プロップで複数口座を回す実務の定石）。相関は完全ゼロにはならないが、共倒れ確率は下げられる。
- **C案(新フレームワーク探索)** は研究投資大・期待中。やるなら別プロジェクトとして。
