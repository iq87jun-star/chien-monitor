## 1. 定義
- M = 月曜の円クロス 4 本・E1(11/18 に切り替える形)。I = NAS100・US500 等分の月曜 13 UTC 建て 24 時間。R = 水曜のロール(円クロス 5 本の売り・金利差の門 2.0pp)。いずれもコスト込み・週次(月曜の日付)にそろえた。
- 期間は指数の H1 がそろう 2018-01-08〜2026-08-24(449 週)。前窓は 2018-01〜2021-09。
- NAS100 の H1 は月曜 13 UTC の足が無い週が 2〜3 割あり、その週は US500 だけの値で代用した。
- 合成の比率: (a) トパーズの EA の入力値から読んだ比率 = 円クロスの束 8.0・指数 各 1.0(等分の束で 2.0)・ロール 4.5。(b) 等リスク = 3 つの週次のばらつきをそろえる比率(M 0.79・I 0.19・R 2.02)。
- 口座のガード(1 日の損失上限・数量の自動調整)は入れていない、単純な足し算。口座の合否を見るものではない。

|---|--:|--:|--:|

- 指数は、静かな週は円クロスとほぼ無相関(0.09)。E1 で静かな週の夜を持たなくなった分、常に 24 時間のとき(0.24)より下がる。
- 荒れた週は 0.45 まで上がる。E1 は荒れた週だけ夜を持つので、円クロスと指数が同じ夜を持つのは、相関が高い週に限られる。

## 3. 単独と合成の成績
値 = Sharpe / 最悪月 % / 最大の下げ幅 %(前窓 / 探索 / OOS。下げ幅は全期間)。
| 形 | Sharpe | 最悪月 | 最大の下げ幅 |
|---|---|---|--:|
| トパーズの比率: 円クロスだけ(×8.0) | 1.06 / 2.31 / 1.65 | −7.70 / −4.93 / −1.63 | −13.2 |
| + ロール | 1.06 / 2.80 / 1.91 | −7.67 / −4.93 / −1.28 | −12.9 |
| + 指数 | 1.29 / 2.13 / 1.37 | −13.81 / −7.01 / −2.31 | −25.6 |
| + 指数 + ロール | 1.29 / 2.49 / 1.58 | −13.81 / −6.02 / −2.63 | −25.8 |
| 参考: 円クロスが常に 24 時間 + 指数 + ロール | 1.24 / 1.84 / 1.32 | −16.66 / −9.20 / −5.11 | −27.7 |
| 等リスク: 円クロスだけ(×0.79) | 1.06 / 2.31 / 1.65 | −0.77 / −0.49 / −0.15 | −1.35 |
| 等リスク: 3 つ | 1.30 / 2.98 / 1.84 | −1.34 / −0.76 / −0.59 | −2.83 |

- **ロールは分散になる。** 足すと探索・OOS の Sharpe が上がり(2.31 → 2.80・1.65 → 1.91)、最悪月と下げ幅は深くならない。前窓は門がほぼ閉じていて変化なし。
- **指数は、トパーズの比率では量が大きい。** 週次のばらつきは円クロス 209 bps・指数 219 bps・ロール 46 bps で、指数が全体の約半分を占める。足すと最悪月が −7.70 → −13.81%、下げ幅が −13.2 → −25.6% に深くなり、Sharpe は前窓で上がるが探索・OOS では下がる(指数単独の Sharpe が 0.90 で、円クロスの 1.58 より低いため)。
- **ばらつきの減り方:** トパーズの比率で、3 つの単純合計 474 bps に対して合成は 345 bps(0.73 倍)。完全に無相関なら 306 bps。
- **等リスクなら 3 窓とも Sharpe が上がる**(1.06 → 1.30・2.31 → 2.98・1.65 → 1.84)。ばらつきは 3 つ足して約 1.95 倍(無相関なら 1.73 倍・完全に連動なら 3 倍)、最悪月は 1.74 倍、下げ幅は 2.1 倍。分散は効いているが、下げ幅は効きが弱い。
- **E1 は合成でも効く。** 円クロスが常に 24 時間のときと比べ、3 つの合成の Sharpe が 1.24 / 1.84 / 1.32 → 1.29 / 2.49 / 1.58、最悪月が −16.66 / −9.20 / −5.11 → −13.81 / −6.02 / −2.63 に改善する。

## 4. 悪い週の重なり(全期間・×1 の平均 bps)
| 条件(45 週ずつ) | 円クロス | 指数 | ロール |
|---|--:|--:|--:|
| 円クロスが悪い週(下位 10%) | −34.8 | −14.9(マイナスの週 53%) | +2.9 |
| 指数が悪い週(下位 10%) | +0.6(マイナスの週 58%) | −175.0 | −0.3 |
| ロールが悪い週(下位 10%) | +12.3 | +19.7 | −9.8 |
| 全週の平均 | +5.7(43%) | +13.7(44%) | +2.0(25%) |

- 円クロスが悪い週は、指数も平均でマイナス(−14.9 bps)。指数が悪い週は、円クロスは 0 近く(+0.6)で、助けにはならないが一緒に大きく崩れてもいない。
- ロールは、他の 2 つが悪い週でも普段どおり。ロールが悪い週は、他の 2 つはむしろ良い。

## 5. 読み
- 分散の効き方は「ロール > 指数」。ロールは曜日も向きも違う(水曜の売り)ので重ならない。指数は同じ月曜の買いで、荒れた週に同じ夜を持つため、いちばん効いてほしい週に重なる。
- 指数を足すこと自体が悪いのではなく、比率の問題。トパーズの比率は指数のばらつきが円クロスと同じ大きさになっている。
- 限界: 口座のガードを入れていない。荒れた週は 69 週(OOS は 7 週)で、荒れた週の相関は少ない本数に乗っている。比率は EA の入力値から読んだもので、実際の建玉は数量の自動調整で変わる。
- 未登録の確認事項: 指数の比率を下げた形を口座モデルで比べること(Q196 では「指数を足す形」は口座で効かなかった)。
