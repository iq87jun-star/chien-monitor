# 307 JP 祝日週の水曜ロールに倍率を上乗せした場合(サイズ配分の検討・2026-09-26)

ユーザー「(祝日週だけロール倍率を上げる案を)別途で」。Q58 / Q67 の診断(祝日週の水曜ロールが 2〜3 倍強い)を、実運用の系列(ロール 5 本合成・金利差門 ≥1pp・往復 3pip・2022-01〜)で確かめ、倍率配分を比較した。`research/roll_holiday_week_sizing.py`。プロトコル外(サイズ配分は検定対象にしない)。

## 1. 祝日週(週内に JP 祝日あり・水曜の 23%)vs 通常週
| 窓 | 祝日週 n / 平均 bps / 勝率 / Sharpe(週) | 通常週 n / 平均 / 勝率 / Sharpe |
|---|---|---|
| IS 2022-01〜2024-12 | 32 / **+5.7** / 53% / 2.00 | 109 / +3.9 / 63% / 2.34 |
| OOS 2025-01〜 | 21 / **+2.5** / 57% / 2.13 | 64 / +3.8 / 63% / 1.62 |
| 全期間 | 53 / +4.5 / 55% / 1.91 | 173 / +3.8 / 63% / 1.99 |

Q67 の「2〜3 倍」は 2016 年からのペア別平均(門なし)で見た値で、実運用系列(2022〜・門あり)では IS +1.8 bps の差に縮み、**OOS では逆転**(+2.5 vs +3.8)。勝率は祝日週の方が低く、平均が高いのは少数の大きい週による。

## 3. 判定
- 祝日週に倍率を上乗せすると、全期間の Sharpe は k=1 の 1.96 から単調に下がる(k=2 で 1.78、k=3 で 1.60)。年率は上がるが DD と最悪週がそれ以上に増える = 単に祝日週だけレバレッジを上げているのと同じ。
- 等露出(通常週を減らして祝日週に回す)は IS でも Sharpe 低下。祝日週の優位は OOS で消えており、配分を変える根拠にならない。
- **結論: ロール倍率は全週同一のまま。** 祝日週の「強さ」は 2016〜2021 の門なし系列に偏った観測で、稼働中の系列では再現しない。docs/306 §2 の Q67 の読み方に「配分の材料」と書いた部分はこの結果で撤回。
