# docs/189: 外部にプロップ用の優位は存在するか — 「買える優位」は無く、優位の源泉はほぼ無料

日付: 2026-07-29
前提: docs/184(ランキング=ほぼ運)、docs/185(良い戦略≠規則適合)、docs/186(勝てるEAは売られない)、docs/188(開示骨格に優位なし)

---

## 1. 結論

**「買える完成品の優位」は、無料・有料を問わず存在しない。**
今回のシリーズで経験的に(184/188)かつ構造的に(186)確認済み。
むしろ**価格と優位は逆相関**する: 本当に勝てるものは売る合理性がなく
(FTMO の戦略別$400k上限、クラスタ検出)、売られているものは売ることが収益源。
「有料ですか?」への答え: **有料であるほど疑わしい。**

## 2. 外部に実在する優位の「源泉」3種(ほぼ無料)

| 源泉 | 実体 | 費用 | 評価 |
|---|---|---|---|
| ① ルール・制度の優位 | ファーム選定(balance/equity基準差=docs/170 の実証)、スケーリング条件、返金規定、割引、規約の予見可能性 | 無料(調査労力のみ) | **最も確実**。本リポの docs/97(インスタント安全性ランキング)/173(Fintokei書面回答)がまさにこれ。EAの優位より減衰しにくい |
| ② 仮説の源泉 | 学術公開研究(SSRN等のカレンダーアノマリー/モメンタム文献)、検証済み公開データ(Darwinex 等の勝ちフロー観察=docs/183) | 無料 | 自EAの季節性エッジ自体がこの系譜。**仮説は外部から、検証と規則適合は自前で**が正しい分業 |
| ③ デモ環境の歪み | ニュース時のデモスプレッド、フィード遅延、ギャップ | 無料〜有料EA | 実在するが規約抵触・短命(運営が塞ぐ)・没収リスク。**REJECT**(docs/186 形態b) |

## 3. 有料で買う価値があるもの(=優位そのものではなくインフラ)

- ティック/ヒストリカルデータ(Dukascopy は無料枠で足りている)
- VPS・約定環境
- 実装の外注(ロジックは自分が保有、実装労働だけ買う)
- 法務・税務の専門家(運営検討時)

## 4. 判定規則(今後のオファー評価の恒久ルール)

「優位を売る」オファーは価格に関係なく次の3問で棄却判定:
1. 売り手はなぜ自分で使わない?(戦略資本上限で説明できるか)
2. ロジックは全文開示か?(非開示なら Tier B 止まり=購入前検証不能)
3. 開示部分だけで docs/187 型ゲートを通るか?(通らないなら価値は非開示部分=検証不能)
→ 3問を通過するオファーは構造的にほぼ存在しない。存在したら docs/183→187 パイプラインへ。
