# 77. 2社2口座プラン — FN $300-400k + FTMO で 本番後 期待手取り ¥10M を狙う

> ユーザー要望「現状=FN $300k(分散案D・同EA)。新規=FTMO $200k(別EA・リスク分散)。本番後 期待手取り
> 合計 ¥10,000,000 を、FTMO規定準拠で確保するプラン」。
> 出所: `/tmp/plan10m*.py`(=portfolio_D_deploy / pstar_funded_income の収益式を2口座へ拡張)を
> **Yahoo日足10年で実行**（保守側・¥155・FN分配95%/FTMO分配80-90%）。月次解像度=失格は楽観。
> 規律: 数字は盛らない。¥10M可否を率直に判定。絶対値はDrive+デモで確定。

## 0. 一行結論
**現状の $500k(FN$300k+FTMO$200k)では ¥10M は安全圏で不可能(最大 安全¥7.6M / 破滅リスクでも¥9.7M)。
¥10M を“確保”するには 総資金 ~$700k(例: FN$400k + FTMO$300k)を 攻め−10%(各 年失格~5%)で回す**＝期待 ≈ ¥10.6M。

## 1. なぜ $500k では届かないか（実データ）
本番後 期待手取り＝資金×年率×分配×¥155×(1−年失格)。両口座のサイズ別合計:
| サイズ(両口座) | 合計期待手取り | 各 年失格 | 評価 |
|---|--:|--:|---|
| 両 攻め −10% | ¥7.6M | ~5% | 安全だが¥10M未達 |
| 両 ×1.5 | ¥9.3M | ~22% | 未達＋毎年口座喪失級 |
| 両 ×2.0 | ¥9.7M | ~38-41% | 未達＋破滅的 |

→ **リスクを上げても $500k では ¥10M に構造的に届かない**(年失格が期待値を食う)。

## 2. ★推奨プラン（¥10M 確保・FTMO規定準拠）
| 口座 | 業者・サイズ | EA / 構成 | リスク | 期待手取り/年 | 年失格 |
|---|---|---|---|--:|--:|
| **口座1** | FN **$400k**(上限) | 分散案D(同EA・`Prop3`系) | 攻め −10% | **¥6.60M** | ~5% |
| **口座2** | FTMO **$300k** | v4主軸(別EA・指数を避けFXメイン) | 攻め −10% | **¥3.97M** | ~5% |
| **合計** | **$700k** | | | **≈ ¥10.57M** | |

- per $100k 期待手取り(攻め−10%): FN分散案D **¥1,649k**(95%) / FTMO v4主軸 **¥1,323k**(90%)。
- **攻め−10%は年失格~5%＝生存可能**。¥10M を「確保」と呼べる唯一の現実解は**資金スケール**(docs/58 と整合)。

### 2.1 もし資金を $500k に据え置くなら（非推奨）
- ¥10M は**×1.5〜×2.0の高リスクでも未達(¥9.3〜9.7M)**、しかも年失格22〜41%＝**毎年〜数年で口座喪失→買い直し**。
  買い直しコストと精神的負担で**実効リターンはさらに低下**。「確保」にはならない。
- 現実的妥協: **$500kなら目標を ¥7.5M 前後（両 攻め−10%・年失格5%）に置く**のが安全。

## 3. 分散の現実（正直な評価）
- FNが**分散案D=4スリーブ全部入り**を回す以上、FTMO側を何にしても**Dとの相関は高め**:
  | FTMO候補(別EA) | Dとの相関 | −10%年率 |
  |---|--:|--:|
  | v4単独 | **+0.57**(最低) | 4.8% |
  | E-Mon:E5(指数) | +0.77 | 6.6% |
  | v4:v7(FX) | +0.83 | 8.9% |
  | v4:v7:E5(v4主軸) | +0.90 | 10.0% |
  → **低相関ほど低収益**のジレンマ。¥10M狙いなら収益側(v4主軸)、分散優先なら v4単独寄り。
- **真の分散(相関0.37)が欲しいなら**: FNを「**v4主軸(A)**」、FTMOを「**E-Mon[RG3]主軸(B)**」に分割(docs/70)。
  ただしFNを分散案Dから変える必要があり、単口座の失格最小(4.9%)は手放す。**トレードオフ**。

## 4. FTMO 規定準拠（資金化後）
- 最大損失 **−10%**(初期残高基準)・日次 **−5%**・分配 **80%→スケールで90%**・**時間無制限**・出金オンデマンド(初回14日)。
- 本EAのガード(静的−10% / 日次−4%(<−5%) / フロア−9% / 利確停止) は **FTMO準拠**。
- ⚠ **審査目標が違う**: FTMO P1 **+10%** / P2 +5%(FNは+8%)。**FTMO用に median-3 を +10%目標で再校正**した
  別プリセットが必要(本docのサイズは資金化後＝審査通過後の運用サイズ)。

## 5. 推奨アクション
1. **FN を上限$400kへ拡張**(分散案D・攻め−10%)＝期待 ¥6.6M。
2. **FTMO $300k を v4主軸の別EA**(`Chien_Portfolio3_AllInOne` v4厚 or 専用ワンクリック版)で・攻め−10%＝期待 ¥4.0M。
3. **合計 ≈ ¥10.6M(年失格 各~5%)**。資金化後は両口座とも生存優先、出金は早めに(口座に大金を置かない)。
4. FTMO審査は**+10%目標の median-3 プリセット**を別途用意(要・Drive再校正)。

## 6. 正直な但し書き
- **¥金額は Yahoo近似(保守側)・¥155・分配仮定**。為替が円安なら増、円高なら減(感応度大)。Driveで確定可。
- **月次解像度ゆえ年失格は楽観側**＝実際の口座喪失はこれより高い。攻め−10%でも「数年に1回の喪失」は織り込む。
- 「必ず¥10M」は存在しない。本プランは**期待値**。最終はデモ＋実運用で確定。資金上限・複数口座・コピー可否は
  **FN/FTMO 各社の現行規約で要確認**。
