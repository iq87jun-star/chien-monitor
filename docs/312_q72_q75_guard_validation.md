## 2. 結果
### Q72(6): 0
条件に該当する月曜は 199 / 550(36%)と広すぎる(2022〜25 年はほぼ常時 52 週高値圏)。該当週の Mon7 平均 +3.9 bps 対 非該当 +4.8、最悪日は非該当週の方が大きい(−1.41% 対 −1.21%)。除外は IS Sharpe を上げるが OOS で下がり最悪月も悪化。SHORT は IS −8〜−10 bps。**介入リスクは月曜レグの損失源ではない**(最悪日は 2022 年以外の週)。

## 3. 判定
- 通過: Mon の年末年始フィルター(既存)の正当性が確認できた。ロールの年末年始は逆(該当 13 本・+14.5 bps)だが n が少なく、フィルター解除は紙上フォワードの候補に留める(`RollYearEnd`)。
- 介入リスク・スプレッド・口座ガード・ロール最終時間: いずれも現行設定を変える根拠なし。
- ガード系の探索はこれで一巡(Q53〜Q75、累積 9,207)。EA の設定は「祝日系 4 本 + 年末年始(Mon)」で確定。
