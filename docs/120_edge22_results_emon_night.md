# 120. edge22 結果: E-Mon夜間限定(HNO)は不採用 — **現行H24維持**(6条件中5不合格)

## 1. 結論

**H24(現行: 月曜open→火曜open)維持。** 夜間限定(HNO: 月曜close→火曜open)は
リスクプロファイルは大きく改善する(最悪週−5.44→−2.51%・maxDD−14.9→−7.5%・mult 0.43→0.85)が、
**絶対リターンを半分以上捨て(net 36.7% vs 74.8%)、スコア改善も+8.8%で基準(+10%)未達**。
さらに直近2年の夜間パートはマイナス(H1実測−2.5%・2026H1も−2.62%)で、6条件中5つ不合格。

## 4. 誠実な読み方

- **「月曜の夜」が特別なのは本物**(プラセボで月曜だけ突出・他曜日の夜はほぼゼロ)。
  edge21の分解と合わせ、E-Monエッジの機序理解としては価値ある確認。
- しかし夜間だけ切り出すと: ①o2oを2区間に割ると**取引コストを二重払い**する構造で
  netが痩せる ②直近2年は夜間パートが逆風(edge21で直近だけHDC>H24だったのと同じ現象の裏面)。
  現行H24は「日中+夜間を1回のコストで丸ごと持つ」ことで両方の弱点を回避している。
- IS/OOSも不安定(IS: HNO 0.128 > H24 0.049 / OOS: HNO **−0.024** < H24 0.141)=
  夜間集中はレジーム依存が強い。事後仮説に厳しい決定規則を課した意義がそのまま出た。
