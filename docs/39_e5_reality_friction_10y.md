## 0. 一行結論

**E5のエッジは10年・実フリクション下でも“消えはしない”が極めて薄い**（legRisk0.55%でCAGR
2.5% → baseキャリーで1.1% → pessで0.2%）。**かつ単独では−10%枠に収まらない**（最小legRisk0.30%でも
MC p95最悪DD ≈ −11%）。→ **E5は単独運用不可。v9と月次相関0.114の“小サイズ衛星”としてのみ意味を持つ**
（docs/36の25〜35%配分と整合）。本資金前にデモで実スワップ/配当/ロールを実測必須。

## 1. R1 — CFDキャリー感応（legRisk 0.55%/月固定）

方向別の年率キャリー（配当受取＝＋／金利・配当支払＝−）を与えた3シナリオ:

| シナリオ | idxL/idxS/goldL/goldS | net | CAGR | maxDD | Sharpe | Calmar |
|---|---|--:|--:|--:|--:|--:|
| none（=従来BTの前提） | 0/0/0/0 | +24.9% | 2.5% | −10.0% | 0.44 | 0.25 |
| **base**（指数ロング金利>配当） | −3/−1.5/−4/−1.5 | **+10.1%** | **1.1%** | −15.9% | 0.21 | 0.07 |
| pess | −5/−2.5/−5.5/−2.5 | +2.1% | 0.2% | −19.2% | 0.07 | 0.01 |

- **キャリー未計上は楽観**: 現実的(base)で**CAGRが2.5%→1.1%へ半減以下**、Sharpeも0.44→0.21。
  E5は指数ロング寄り＝**金利支払＞配当受取**で純キャリーがマイナスになりやすい。これが本丸の欠落だった。
- エッジは（net>0の意味で）pessでも生存。だが**収益の大半はフリクションで消える**＝薄いLEAD。

## 2. R2 — legRisk → 口座maxDD / Phase1合格率（累積−10%/+8%, 月次ブロックBT）

| legRisk | none: histDD / p95DD / pass | base: histDD / p95DD / pass |
|--:|---|---|
| 0.30% | −5.5% / −10.5% / 84% | −8.8% / −11.0% / 63% |
| 0.46% | −8.4% / −11.4% / 81% | −13.4% / −12.1% / 66% |
| 0.55% | −10.0% / −11.7% / 76% | −15.9% / −12.5% / 64% |
| 0.75%+ | −13.7%〜 / −13.6%〜 | −21%〜 / −14%〜 |

- **どのlegRiskでもMC p95最悪DDが−10%超**（最小0.30%でも none −10.5% / base −11.0%）。
  実現10年maxDD（0.30%で−5.5%）より**MCテール側が悪い**＝docs/18の「短期実現値はDDを過小評価」が
  E5でも成立。**E5単独では−10%枠に安全に収まるサイズが無い**（要 legRisk<0.30% か 衛星化）。
- → E5は**単独EAとして本資金不可**。v7/v9を主力に、E5は**小サイズ衛星**でのみ運用すべき（docs/36準拠）。

E5(base) と v9(12h月次集約) の相関 = **+0.114**（非常に低い）。
→ v7–v9 の0.685と対照的に、**E5は v9 と強く分散が効く**。小サイズでもポートフォリオSharpe改善に寄与

## 5. 判定と推奨

- **E5単独 = 本資金不可**（薄い純益＋単独で−10%枠に収まらない）。
- **E5 = v9主力に対する小サイズ衛星（相関0.114）としてのみ採用**。配分は docs/36 の v9:E5 = 75:25〜65:35、
  legRisk は **0.30%以下**から（p95DDを実測で−10%内に収めるサイズへ）。
- 本資金前に必須:
  1. **実CFDのスワップ/配当調整/ロールを業者で確認しデモ実測**（R1の base/pess のどこに居るか確定）。
