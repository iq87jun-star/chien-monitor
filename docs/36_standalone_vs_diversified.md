# 36. 単独（v7）vs 分散（v7+MA2）の比較

> 実装: `research/blend_v7_ma2.py`。データ: v7週次（→月次集約）＋ MA2月次TSMOM。
> 公正化のため**全戦略を年率ボラ10%に正規化**（サイズの恣意性を排除, docs/23の作法）。
> 共通期間: 107ヶ月（2017-01..2025-11, MA2の12ヶ月ルックバック分で開始が後ろ倒し）。

## 結果（年率ボラ10%正規化）
v7×MA2 月次相関 = **−0.21**（負＝分散が有効）

| 配分 v7:MA2 | Sharpe | CAGR | maxDD |
|---|--:|--:|--:|
| **100:0（v7単独）** | 1.17 | 11.8% | 8.0% |
| 90:10 | 1.25 | 12.7% | 8.5% |
| 80:20 | 1.34 | 13.7% | 9.0% |
| 70:30 | 1.41 | 14.5% | 9.4% |
| **60:40（Sharpe最大）** | **1.43** | 14.7% | 9.4% |
| 50:50 | 1.38 | 14.1% | 9.1% |
| 0:100（MA2単独） | 0.57 | 5.3% | 18.2% |

生（非正規化）単独: v7 = Sharpe1.17 / 年率+3.7% / vol3.2% / maxDD2.6%、
MA2 = Sharpe0.57 / 年率+5.7% / vol10.0% / maxDD18.2%。

## 解釈（正直に）
- **分散は明確にプラス**: MA2を足すと Sharpe 1.17→最大1.43（≈+22%）。**駆動因は負相関−0.21**。
  同一リスク（vol10%）での CAGR も 11.8%→14.7% へ。
- **ただしDDはむしろ微増**（8.0%→9.4%）: MA2はトレンド追随で**ドローダウンが深く長い**性質。
  同一ボラに揃えると、ブレンドの**最悪DD深度は少し増す**。便益は「リターン/Sharpe」であって
  「DD縮小」ではない点に注意（プロップの−10%枠では、サイズで吸収する設計＝docs/35の衛星化が前提）。
- **v7単独 Sharpe=1.17 は docs/23 の 1.47 より低い**: あちらは局所2.8年（直近の好レジーム）。本表は
  **フル~9年**（弱い2017-19を含む）でより保守的・公正。誇張しない。

## 推奨配分（重要）
- 数字上の最適は 60:40 だが、これは**インサンプルのブレンド**であり、**MA2は有意水準未達のLEAD**。
  未検証の部品に40%も賭けるのは過剰最適化。
- **実務推奨: まず v7:MA2 = 90:10〜80:20（衛星）**。Sharpe 1.25〜1.34 と単独1.17を明確に上回りつつ、
  MA2への依存を小さく保つ。**docs/35 のデモ前進検証を通過してから**段階的に 70:30 方向へ。
- v7 は常に主力（検証済み）。MA2 は負相関の保険＋上乗せとして小さく。
