## 2. 採点ゲート(docs/100 と同一のはしご)

- G-dir / G-p(ドリフト保存プラセボ, 2000draw, p≤0.05・Bonferroni α=0.025)/ G-split(中央2分割両半+)/
  G-cost(2×)/ G-hold(3%/年)/ G-beta(対ベータ超過+; H23bはSHORTなのでベータは逆風=通過しやすい
  ことに留意して解釈)/ G-dd(≥−20%)
- **判定**: 全通過=STRONG-LEAD(Bonf未達は1段下げ)/ G-p含む過半=LEAD / dir+p≤0.10=参考 / 他REJECT。
- STRONG-LEADの場合のみEA化検討(US500はプロップ可搬)。デモ前進必須は他エッジと同一。
