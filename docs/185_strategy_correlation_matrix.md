## 4. 読み取り

1. **現有体制は実質1.5ベット**: v7・A・B・C・Dが1つのクラスタ(ρ .52〜.85)=
   「月曜アジア時間の円安・リスクオン継続」への集中ベット。独立なのはEMon(弱)とE5のみ。
2. **C+Dの追加はエクスポージャの倍積みだった**: C↔D .79。2口座の失格イベントも相関する
   ため、「失格したら買い直し」予算(docs/180 §2)は**悪い月曜の連鎖で同時に燃える**
   設計になっている。これは購入時に数字で見えていなかった事実。
3. **E候補(TH1.0)の分散価値は本物**: 全手法とρ≈0。docs/184のEV(FN悲観+$287)は
   C/D比で見劣りするが、「ポートフォリオの2本目の軸」としての価値はEV単体比較より上。
4. E5が最大の既存分散源(全手法と≈0)だが、単日テールが太い(2025-04-09 −5%)。
5. 相関の「実測値」はレジーム依存(TSMOM ADA↔LTC: 月次.16 vs 直近日次.78)。
   **今後の構成追加時は本スクリプトで日次12m・月次全期間の両方を見るのを標準とする**。
