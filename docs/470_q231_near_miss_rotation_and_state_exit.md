## 4. 留意
- 指数 5 本のうち通った 2 本を選んでいる(事後の選択)。US30・JP225 は Q114(月曜 13 → 20 UTC の日中版)でも通った 2 本で、同じ傾向の再確認であり独立の証拠ではない。
- 指数の H1 は 2018 年から。前窓は 36 か月、口座モデルの 2016-11〜2018 年は指数レグなしで計算している(現行・差し替えとも同じ)。
- JP225 は常時建てると 2025〜26 年がマイナス。F で残るのは線の下の週と日中の部分だけで、土台は強くない。
- FN の Instant 口座で US30・JP225 が取引できるか(銘柄名・最小数量・取引時間)は未確認。スワップは入っていない(Instant はスワップなしの実績)。
