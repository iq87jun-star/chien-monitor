## 2. 読み方

1. **どのロジックに足しても年率が約 +6pp 上がり、最大 DD と最悪日はほぼ変わらない。** ロールの露出は水曜 4 時間だけで、他ロジックの DD 局面と重ならないため、上乗せは「加算」として効く。Sharpe は 0.3〜0.5 上がる。
2. **資金化率が上がり失格率が下がる**(Mon4: 65 → 85%、BROAD_IV ×0.6: 62 → 83%)。年率 6pp の底上げが +10% 到達を速め、失格前に届く確率が上がる。ただし MC のブロック・ブートストラップはロールの「ほぼ確実な小さな増分」をそのまま複製するので、前提が崩れる(手数料・規約・金利差縮小)場合の下振れは MC に入っていない。
3. **NonFX ×1.48(FN #14166201)は単独で年率 5.5%・最大 DD −28%** と弱い。これは直近 12/6 ヶ月で選抜した構成を 5 年窓で評価しているためで(docs/174 の「賞味期限つき」の設計どおり)、ロールを足しても DD −26% は変わらない。**FN #14166201 でロールを使うなら、NonFX の Hold レグの重みを見直す方が先**。
4. 前提の順序は変わらない: ① 各社の書面回答(docs/273 §3)→ ② 該当口座があれば Q28 として事前登録(名目 3 倍上限)→ ③ EA にレグとして内蔵(FN は 1 口座 1 EA)→ ④ 紙上 1 ヶ月 → 採用判断。FTMO の口座(Mon4・BROAD_IV 予定)は swap-free でない限り上乗せは効かない。
