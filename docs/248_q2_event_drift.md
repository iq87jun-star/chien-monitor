## 2. 読み方

1. **棄却(正常な結果)。** 事前登録の閾値 1.37e-5 に対し最小 p は 0.027 で、Bonferroni 前の 0.05 でも 3 セルしか残らない。
2. 上位に「CPI 前日 LONG(円クロス)」が並ぶが、前窓(2016–2021)は 0.43〜0.46 で**逆符号**。2022 年以降の円安局面の射影で、イベント固有の効果ではない。
3. 「FOMC 当日 USDJPY SHORT」(IS 17/26・前窓 0.62・OOS 7/13)は符号が 3 窓で揃う唯一のセルだが p = 0.084。Sess 16-20 窓が FOMC 日を `InpSessSkipDates` で外している現状の扱いを変える根拠にはならない。
4. 雇用統計の当日・翌日(36 セル)は金曜発表 → 24h 後が土曜で市場が閉じるため構造的に空。**有効セルは 204**。累積には事前登録どおり 240 を加算する(空セルを引いて閾値を甘くしない)。
5. BoJ の「翌日」は金曜決定が多く月数 14 と少ない。検出力不足であり「効果なし」の証明ではないが、再検定は累積を増やすだけなので行わない。
