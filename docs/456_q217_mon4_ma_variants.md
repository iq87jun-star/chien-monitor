# 456.【Q217】月曜の円クロスの 200 日線の縮小を性格の違う 3 本の線で(改良系・セル 3)→ 棄却 0 / 3。SMA200 を 3 つの期間すべてで上回る線は無い。ゆっくりした線(中央値・適応型)は SMA とほぼ同じ結果、速い線(ハル)は効果が薄れる

## 1. 方法(事前固定)
- 形 = 配備形 Mon4(4 通貨各 0.25・EA 実時刻・コスト後)の「減らすだけ」: 金曜終値が線の下の通貨 1.0 倍・上の通貨 0.5 倍。
- 線: H = ハル移動平均 HMA(200)。K = カウフマン適応型 KAMA(効率比の窓 200 日・速い定数 2・遅い定数 30・最初の 200 日は助走)。M = 終値の 200 日中央値。
- 読み方: (1) 縮小なしに対して前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しないか。3 本とも満たせば「線の種類は関係ない」。(2) SMA200 に対して同じ条件を満たせば改良成立。

## 3. 判定と含意
- **棄却 0 / 3**(正常な結果)。配備中の SMA200 を変えない。紙上フォワードにも入れない。
- 線の種類は「ゆっくりした線」の中では関係ない: 中央値(一致 96%)・適応型(93%)・EMA(94%・Q216)は SMA200 とほぼ同じ週を選び、結果も同じ範囲。
- 速く反応する線は別物になる: ハル移動平均は SMA200 との一致が 61%、切り替わりが約 2 倍で、弱い時期(2016〜21 年)には効果が出ない。この縮小が効いているのは「数か月〜1 年の単位で下げた位置にいるか」で、直近の細かい上下ではない。Q214 の 50 日線が前窓で弱め(0.34)だったことと同じ向き。
- 200 日線まわりの検証(Q194〜Q198・Q213〜Q217)は、定義・深さ・日数・重なり・線の種類のすべてで配備中の形を上回るものが無く、ここで打ち切る。
