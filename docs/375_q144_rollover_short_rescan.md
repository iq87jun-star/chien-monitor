2026-10-22(平日夕の定例・order 17.1・週次アイデア束 #1)。スクリプト `research/queue/q144_rollover_short_rescan.py`、結果 `research/results/q144_rollover_short_rescan.csv`(判定)・`q144_rollover_short_compare.csv`(現実価格 2024〜26 との比較)。累積セル 9,925 → **10,039**(閾値 0.05 / 10,039 = 4.98e-6)。

## 1. 仮説とセル
- docs/367: 21〜23 UTC の bid 始値はロールオーバーのスプレッド拡大で沈む。bid→bid で測った「この帯で建てる LONG」は有利に、「SHORT」は不利に見えていた。ならば SHORT セルは現実価格(売り建て = bid 始値・買い戻し = ask 始値)で測り直すと見かけより良いはず、という仮説。
- セル: 銘柄 19 × 建て {21,22,23} UTC × 保有 {1,2}h の SHORT・月〜金プール = **114**(登録は 20 銘柄 120 セル。ask のある 22 銘柄のうち USDTRY / USDMXN / USDZAR は前窓が 2018〜で、スプレッド数十 pip に §1 のコスト模型が当てはまらないため除外。実走セル数で累積に加算)。
- 判定: docs/244 §1(IS 2021-10〜2024-12 の +月二項 p < 閾値・OOS 平均 > 0・前窓 +月率 ≥ 50%)。ask 2016〜 のある 12 ペア(docs/372・USDJPY は d2919e3e)は全窓を現実価格で判定。ask 2024〜 の 7 銘柄(EURUSD / GBPAUD / GER40 / NAS100 / NZDUSD / US500 / XAUUSD)は登録どおり bid−3pip で判定し、2024〜26 の現実価格を併記。

## 2. 結果
- **合格 0 / 114。IS で p < 0.05 のセルも 0(期待 6)。IS +月率の最大は USDJPY h22 2h の 43.6%(= 50% 未満)。**
- 2024〜26 の現実価格でも **1 取引平均が正のセルは 0**。最良は EURUSD h23 2h の −0.24 bps、USDJPY h21 2h の −0.38 bps。bid−3pip から現実価格への改善は中央 +0.9 bps・最大 +3.3 bps で、売り建て側の不利(沈んだ bid で売る)が消える分より、実効往復スプレッドの方が大きい。
- 時刻別(現実価格・12 ペア・IS 平均 bps): h21 −0.8〜−2.5、h22 −0.3〜−2.1、h23 −0.1〜−1.8。保有 1h と 2h の差は小さい。

## 3. 判定と含意
1. **棄却**。docs/367 のアーティファクトは「LONG が良く見える」方向にしか働かず、逆向きに取れる価格の歪みは無い(bid の沈みはスプレッドの片側で、売り手はその沈んだ bid で建てるので得をしない)。これで 20〜23 UTC 帯の方向性セルは LONG(Q140・Q139 で棄却)・SHORT(本書)とも閉じる。
2. 残るのはこの帯の「決済」側(docs/233 の 21 UTC 帯回避)で、既存 EA の決済時刻規則は変えない。
3. 11 月の改訂への含意: なし。紙上フォワードへの追加なし。
