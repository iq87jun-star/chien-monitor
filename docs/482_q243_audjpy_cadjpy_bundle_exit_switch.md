- AUDJPY・CADJPY の月曜の買い(4/6/8/10 UTC 建て・200 日線の下 1.0 倍・上 0.5 倍)を 2 分の 1 ずつ。倍率を掛ける前・コスト込み。
- E1 = 前金曜の VIX 25 超の週だけ 24 時間・それ以外は同日 20 UTC。G1 = 週末の窓が自分の過去の下位 20% の通貨だけ 24 時間。G3 = VIX 25 超 または G1。
- 判定 = 束の「常に 24 時間」に対して 3 窓すべてで Sharpe 改善 かつ 最悪月が悪化しない。
- 期間は 2016-01-04〜2025-12-29(CADJPY の H1 の末尾)。OOS は 52 週・12 か月。

## 3. 判定と読み
- **成立 3 / 3**(3 形とも、Sharpe が 3 窓で上がり、最悪月も 3 窓で浅くなる)。
- ただし、通貨別に成立した 2 本を後から選んで束ねた結果で、成立するのは当然に近い。「この 2 本が特別」という根拠にはならない。
- 採用 4 本の束と比べると低い: E1 の Sharpe は 0.47 / 1.94 / 1.08 対 0.67 / 2.31 / 1.65。土台(常に 24 時間)が 0.36 / 0.87 / 0.38 対 0.46 / 1.51 / 1.20 と弱いため。
- OOS は 52 週・12 か月で、E1 が夜を持ったのは 3 週(6 本)だけ。OOS の E1 の改善は、ほぼ「夜を持たなかった」ことによるもの。
- AUDJPY は採用 4 本に入っている。この束を使うことは、GBPJPY・EURJPY・USDJPY を外して CADJPY を入れることに当たるが、その入れ替えを支える結果ではない。
- 紙上フォワードに 3 本追加(`MonAudCadE1`・`MonAudCadG1`・`MonAudCadG3`・紙上のみ・計 48 本)。配備の提案なし。
