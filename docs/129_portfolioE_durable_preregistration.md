## 2. 校正・シミュレーション(全て既存機械の再利用・実行前固定)

1. **推奨倍率** = ガード逆算×0.8(docs/87の規律): max{m: 最悪単日×m ≥ −4% かつ 最悪月中DD×m ≥ −8%}×0.8。
   G3オーバーレイは倍率適用後に重畳(`calibrate(base, g3)` と同一)。機械決定・裁量なし。
2. **チャレンジMC** = `median3_calibrate_compare.simulate` と同一(日次ブロックMC・月単位ブートストラップ・
   2万パス・36ヶ月上限・fail優先・楽観/悲観2バウンド)。シードは同スクリプトと同じ7。
   - パネルFN: 目標+8% / フロア−8%(楽観) / 日次−5%(悲観バウンド)
   - パネルFTMO近似: 目標+10% / フロア−10% / 日次−5%(E5は週跨ぎ保有のため実装先は**FTMO Swing**前提)
   - 倍率格子(固定): 推奨×{1.0, 1.5, 2.0}
3. **相関**: PE1月次 vs ①PortfolioD合成(v4 30/v7 25/E-Mon 25/E5 20・通年固定) ②季節M3合成。窓2016-2025。
4. 窓: 2016-01〜2025-12(凍結・既存検証と同一)。データ=Yahoo日足(`fetch_data/fetch_multiasset` 凍結窓)。

## 3. 決定規則(実行前固定・機械適用)

- **D1(G3採用)**: PE1がPE0に対し ①平均月利改善 ②月次maxDD悪化なし ③最悪単日の悪化 ≤ 0.2pt、
  の3条件全成立 → PortfolioE = PE1。不成立 → PortfolioE = PE0(E5単独)。
- **D2**: PE2はD1合格かつPE1をさらに改善し最悪単日が−4%以内の場合に「代替」として記録のみ(既定は1%)。
- **D3(倍率)**: 推奨倍率は§2-1の機械決定値。チャレンジ増し倍率(×1.5/×2.0)は表の提示のみ=採用はユーザー判断。
- **D4(分散価値の判定)**: |ρ(PE, PD)| > 0.6 なら「第3ポートフォリオとしての分散価値は限定的」と結果docに明記
  (採否には使わない=器の政策判断材料)。
- **D5**: 本資金投入なし。**デモ前進検証必須**(docs/53 §5)。EA化は既存2 EA(`Chien_E5_RP_Trend_EA` /
  `Chien_FOMC_Drift_EA`)のMagic分離同居を第一案とし、統合EAは必要が確認されてから。
- 事前の期待(盛らない): E5のSharpe 0.58(docs/107)ゆえ**通過速度はPD(中央3ヶ月)より大幅に遅い**見込み。
  本ポートフォリオの目的は速度ではなく「現行レジーム終了時にも生き残る口座」であり、
  遅さは欠陥ではなく仕様として記録する。
