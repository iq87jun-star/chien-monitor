## 4. 判定
**棄却(配備構成は変更しない)。** 主セル(ex8)は IS・OOS とも Sharpe が +0.04 改善するが、最悪月が IS −0.6 bps・OOS −4.5 bps 悪化し、改良系の 2 条件目を満たさない。参照 3 セルも不成立。Q7(docs/250・「4 ショット均等・24h の代替は無い」)と同じ結論で、実口座起点でも覆らない。基準は緩めない。
累積セル: 9,613 + 4 = **9,617**(Bonferroni 閾値 0.05 / 9,617 = 5.2e-6)。
