## 4. 読み方
1. **毎年プラスに近いのは Mon 円クロス 4 本(GBPJPY・AUDJPY・EURJPY・USDJPY)とロール 5 ペアだけ。** Mon GBPJPY は 5 年 +35%・最大 DD −2.8%、ロール GBPJPY は 2022〜 +11.5%・最大 DD −0.5%。ただし Mon USDJPY は 2025〜26 がマイナス(−2.2 / −0.5)、Mon EURJPY は 2024 以降 +0.4 / +1.7 / +1.9 と細っている。
2. **RF5 の 5 スリーブは S2(Mon GBPJPY)以外が 5 年でマイナス**: S1 Mon GBPUSD +13%(2021〜24 はほぼゼロ)、S3 木曜 USDCHF −0.4%、S4 RSI2 GBPUSD −8.5%、S5 RSI2 GBPJPY −8.0%。RF5 の 2025〜26 の好成績は S4/S5 の逆張りが 2025 に +4.7 / +4.8 と当たった分で、docs/289 の「直近フィット」の中身がこれ。
3. **v4 は全ペアで 5 年 −1〜+14%・Sharpe 0〜0.7 と薄い。** B 案/Instant の v4 USDJPY は −0.7%(2022 −5.6%)。C 案の v4 NZDUSD/AUDUSD は 2023 が良かっただけ。
4. **Hold はベータそのもの**: UK100 +50%(2025 +20.8)、GER40 +62%(2022 −12.9・DD −27%)、WTI +9%(DD −56%)。非 FX の弱さは WTI と v4nfx BTCUSD(5 年 −44%・DD −68%)が原因。
5. **Mon 指数(BROAD_IV)は NAS100 +50% が例外で、UK100・FR40 はマイナス。** TSMOM は XAUUSD +60% 以外は 5 年でほぼゼロ、ETHUSD は −89%。BROAD_IV の成績はウォークフォワードの選抜と逆ボラ加重がこれらを避けて出来ている。
