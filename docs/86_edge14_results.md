# 86.【結果】edge14 — v7の機構確認のみ合格。v4も「現行レジーム現象」と判明(重要)

> **出所**: `python3 research/edge14_breadth_durability.py` ローカル実行

## 0. 一行結論

**合格は H14c(v7横展開)のみ**: 未検定のJPYクロス4本(AUD/NZD/CAD/CHF JPY)で円月曜が独立に再現
(+26.8% / p=0.0083 / DD−7.3%)＝**v7の機構(JPY共通フロー)は本物**。一方 **H14a で v4 の長期耐久なし**が
判明＝ポートフォリオ主力レッグも現行レジーム現象(E5だけが長期構造)。G3は日足近似が弱く判定保留。

## 2. H14a — v4の正直な解剖(本バッチ最重要の発見)

- サニティ完全合格: 同一実装・同一Yahoo OHLCで2016+は**+80.2%**(docs/53 §7の+144%と同方向・
  OHLC品質差で控えめ)= 近似は有効。にもかかわらず**pre-2016は19年で+5.9%・p=0.33**。
  5年ブロック: 1995-99 +3.1 / 2000-04 +2.5 / 2005-09 −8.8 / 2010-14 +20.3。
- **∴ v4(k≥4逆張り合議)もv7/E-Monと同じ「2016年以降のレジーム現象」**。ADOPT級(10年Dukascopy 6/6)は
  不変だが、「100年級の構造」ではない。
- **運用への含意(docs/78に反映すべき)**: PortfolioD のリスクの75%(v4 30+v7 25+E-Mon 20)は
  **同一の「現行レジーム」前提に乗っている**(機序は別でも耐久クラスが同じ)。
  → 年次生存確認(docs/78 フェーズ5-21)は「形式的な儀式」ではなく**本質的な生命線**。
  レジーム転換の早期検知(直近24ヶ月ローリングnetの符号監視)を運用カードに追加することを推奨。

## 3. H14b — G3は「判定保留」(不合格と書かない理由・正直に)

日足近似(T-2終値→T-1終値)はサニティで+3.6%(2016+)しか再現できず、**H1実測+16.1%の約2割**しか
捕捉していない(ドリフトの本体は声明前日14:00ET以降=日足の外)。この弱い物差しでも pre-2016 は
**+17.3%・1イベント平均+10bps(2016+近似の2倍強)**=方向は文献(Lucca-Moench 1994-2011が最強期)と
一致するが、p=0.18で有意主張は不可。**正しい検定はH1データが要る** → Dukascopy US500 H1 が
2011年頃まで遡れるなら、edge12ハーネスで2011-2015(約40イベント)を追加実行可能(ユーザーColab・任意)。
