## 5. 読み

1. **最悪日だけで枠を揃える D 案は採らない。** Hold の危険は 1 日ではなく連日の下落に出るため、最悪日を揃えると Hold 名目が口座額面の 1.3〜1.8 倍まで膨らみ、5 年 DD が −33〜−39%、帳簿全体の日次 DD も −14 → −21% に深くなる。期待出金は増える(トパーズ 3,990 → 7,726 万)が、評価中 4 口座の失格が 2 倍前後(1-Step 20 → 43%・トパーズ 19 → 39%)になり、偏りの訂正の目的(同時失格の回避)に反する。
2. **DD も揃える E7 が現実的な落とし所。** Mon 寄与 89 → 60%、月曜の分散 92 → 71%、口座間相関 0.63 → 0.60。合計月利 3.2 → 3.0%、最悪月 −7.4 → −8.0%、日次 DD は同じ(−14.5%)、30 か月期待は 8,131 → 8,322 万で同等。各口座の失格は +2〜16pt(1-Step 20 → 24・トパーズ 19 → 35・ルビー 28 → 38・パール 7 → 13)で、到達の中央値は 1〜2 か月遅れる。Hold を増やすと「月曜 1 日の失格」は減るが「連日下落での失格」が増えるため、失格の総数では改善しない。
3. **Mon 偏りの本当の緩和は、Hold 以外の曜日の柱が要る。** 通過済みで週末不要・スワップ不問のレグが Mon 以外に無い(Roll は swap-free 口座専用、Hold は週末持ち越しと金融費用)。Thu XAUUSD(紙上候補)と Q161 の XAU 金曜窓(11/9 実行)が通れば、E 案に木・金の柱を足せる。
4. 口座間相関は E5 でも 0.55 までしか下がらない。これは Hold UK100/WTI 自体が 5 口座で同じ建玉になるため。口座ごとに別のレグを持たせる「役割分け」は、通過レグの数が増えてからの課題。

## 6. 提案(すべて「切替」待ち・配備は変更していない)

- **E7 を基本線として提示**: 1-Step Hold UK100 0.31 / WTI 0.10 を追加し Mon ×0.7、ルビー UK100 0.96 / WTI 0.30、トパーズ UK100 0.99 / WTI 0.31、パール UK100 0.64 / WTI 0.20。宝くじは Hold 追加の余地が小さく(E7 で 0.12 / 0.04)、評価通過を優先して据え置きが妥当。
- 採用する場合、各 EA の `InpHoldLegs` と `InpMult`(Mon ×0.7)の変更になる。Fintokei 3 口座は週末持ち越し可だが、UK100/WTI のスワップ・金融費用は未計測(FN swap-free 口座の帳簿を流用)なので、docs/398 と同じ手順で実測してから倍率を最終化する。
- 研究 spec(config/portfolio_current.json)への反映は docs/400 候補 E と同じで「登録」事項。
