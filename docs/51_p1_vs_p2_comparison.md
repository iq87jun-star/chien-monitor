## 0. 一行結論

> **同じリスクなら、単体は P1(現運用) が P2 に全項目で勝る**（P1が主力なのは不変）。
> **だが P2 は P1 と相関 0.014（ほぼゼロ）の独立エンジン**で、**併用すると同リスクで P1 単体を安全側で上回る**
> （PROP 失格 1.1%→0.6%・DD −8.3%→−7.3%、INSTANT 年率 5.3%→5.8%・最悪 −3.1%→−2.2%）。
> P2の価値は「2本目の独立分散源／2口座目の弾」であり、「単体でP1を超える弾」ではない。

## 6. 結論（どう使うか）

1. **主力は P1 のまま**（v4=ADOPT を含み、単体の質が上）。P2 は置き換えではない。
2. **P2 の使いどころ＝独立分散**:
   - **同口座で併用**するなら、同リスクで失格率・DD・最悪ケースが下がり年率も微増（§5）。
   - **2口座目を独立に回す**弾（P1の不調月と無相関ゆえ同時失格しにくい）。
3. **どちらも本資金前にデモ前進検証**（P2は特に株指数CFDの実スプレッド/オーバーナイトスワップ/配当を実測）。
4. P2 サイズは保守(L≈0.5相当=INSTAN既定 週次0.50%)から。攻めはP1優先・P2は薄く。

> 免責: シミュレーション・確率であり保証ではない。指数=配当抜き、CFD実コスト未計上。最終確証はユーザーの
> 実データ・デモで。「必ず通る手法」は存在しない。リスクを誇張も過小評価もしない。
