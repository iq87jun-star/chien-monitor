2026-11-20 登録・実行(ユーザー「1ステップの金は外せますか」→ 回答と案を提示 →「登録して実行」)。スクリプト `research/queue/q271_one_step_gold_from_current_state.py`・結果 `research/results/q271_one_step_gold.csv`。EA・マニフェスト・config は変えていない。

## 1. 仮説と型(docs/244 に先に固定)
- きっかけ: 1-Step は 11/16 と 11/20 に日次ガード(−2.4%)が発動した。2 回目は建玉が金 0.09 ロットだけで、金の含み損だけで届いた。Q253・Q254(docs/493・494)は 1 回目の直後(残高 +0.2%・発動 0 回から)の計算で「金を残す」だった。
- 開始: 残高 97,826.72(初期比 −2.17%)・金の建玉なし・EOD の最高 102,813.25(追随の床 −7.19%・EA の全停止 −6.19%)・11 月の発動 2 回。
- 型: 現状 = 週明けに金 0.36 倍を建て直す(判定の基準)/ 金なし / 建て直しを半分(0.18 倍)。
- 場面(Q254 と同じ作り方 = 金の日々の上下はそのまま、期間の平均の上昇分だけ入れ替える): 実績のまま・横ばい(年率 0%)・下落(年率 −6%)。参照(判定しない): 急落(年率 −20%)。スワップ(月 −52 bps)はどの場面でも引く。
- 口座モデルは Q253 と同じ(開始週をずらした実際の並び・52 週・金は日足・金の含み損を日次ガードに入れる)。変えた点: (1) 開始時の最高値 (2) 開始月の発動 2 回 (3) 月の区切りは 2026-11-23 からの実際の暦 (4) 月内の停止は EA の実装どおり 3 回目の発動から。
- 判定: Q233 の ev_ok(2 つの開始期間の両方で 到達 −1.0 以内・失格 +1.0 以内、かつどちらかで 到達 +2.0 以上 または 失格 −2.0 以上)。基準はその場面の「現状」。セル = 2 型 × 3 場面 = 6。

## 2. 照合
旧設定(開始 100,225.64・最高値なし・発動 0 回・過去の暦・2 回で停止)で Q254 の 1-Step の行を再現した: 現状 100.0 / 0.0・36.2 / 30.1、金なし 81.4 / 0.0・35.2 / 34.7(Q254 と一致)。

## 4. 判定(基準 = その場面の現状)

| 場面 | 金なし | 半分 |
|---|---|---|
| 実績のまま | 現行どおり(到達 93 → 61%・失格 7 → 15%) | 現行どおり(到達 93 → 91%・2016-11〜 の到達 −2.0) |
| 横ばい | 現行どおり(到達 76 → 61%) | 現行どおり(到達 76.2 → 74.8% = 基準の −1.0 に 0.4 届かず。失格は 16 → 11%) |
| 下落(−6%) | **変更候補**(到達 62 → 61%・失格 23 / 71 → 15 / 53%) | **変更候補**(到達 62 → 66%・失格 23 / 71 → 12 / 63%) |

変更候補は 6 件中 2 件で、どちらも下落の場面。実績・横ばいでは 0 件。

## 5. 読み方
- **結論は金の向きの仮定で決まる。** 金が過去のように上がれば残す方が良く、年 6% 下がるなら外す・半分のどちらも良い。境目は「横ばい〜やや下落」のあたりにある。どの場面が今後に当てはまるかは、このデータからは決められない(金は 2026-01 の高値から 2 割以上下げていて、11/17〜20 の 3 日で約 5% 下げた)。
- **半分は、3 つの場面のどれでも最良から大きく離れない。** 2021-08 以降の開始では、失格が 8・11・12% で、現状(7・16・23%)と金なし(15%)のどちらよりも低いか同じ水準。到達は 91・75・66% で現状(93・76・62%)とほぼ同じ。2016-11〜2020-07 の開始では、失格は金なし(53%)が最も低く、半分は 53・61・63%。これは結果を見てからの読みで、事前の判定で通ったのは下落の場面だけ。
- **金なしは、2021-08 以降の開始で失格が 15% と高い。** 金を外すと到達までが 35 週に延び、床に近い位置にいる期間が長くなるため。
- **口座の見通しは、状態の変化で全体に下がった。** 1 回目の直後は現状で 100 / 0(2021-08 以降)だったのが、いまは 93 / 7。主な理由は床が近いこと(開始 −2.17% に対して全停止 −6.19% = 余裕 4.0%。EOD の最高が +2.81% まで上がっていたため)。発動 0 回・最高値なしに戻した参照では 99.5 / 0.5。2016-11〜2020-07 の開始では、どの型でも失格が 5 割を超える。
- 急落(年 −20%)では、金を残すと到達 18%・失格 57% まで悪化する。金なしは場面によらない。

## 6. 見つかった違い(以前のモデル)
- Q253・Q254・Q256 の口座モデルは「暦の月内 2 回の発動で月末まで新規停止」としていた。EA の実装は `g_balFires > InpBalGuardMaxMonth`(= 2)で、**3 回目の発動から停止**する(11/20 の 2 回目のログにも「月末まで停止」は付いていない)。旧い約束での参照(§3 と同じ形)は 到達が 0〜7 ポイント低く、判定は「下落 × 金なし」だけが 変更候補 → 現行どおり に変わる(到達 58.6 → 55.7 が −1.0 を超えるため)。Q253・Q254 の結論(宝くじ・FN 4882 は金なしが変更候補・1-Step は残す)を出した時点の数字は 1 回分厳しい約束だった。再計算は行っていない(宝くじ・FN 4882 の金はすでに無い)。

## 7. 限界
- 開始週は 1 週ずつ重なる(独立な試行の数ではない)。金は日足の近似。発動時の損は −g × 1.1 の約束。
- 夜の指数(v1.10 で追加・荒れた週だけ)と、11/23 の祝日の見送りは入れていない。NAS100 の 1 時間足に欠けがある(docs/487)。
- 場面の傾き(0%・−6%・−20%)は仮定。−6% は 2012〜2015 年の実績の年率。

## 8. 提案(採用はユーザーの「切替」の後)
- 事前の判定では、金が下落する前提のときだけ「金なし」「半分」が変更候補。実績・横ばいの前提では現行どおり。
- 3 つの場面を通して見ると、**半分(名目 0.18 倍 = 約 0.04〜0.05 ロット)**が、到達を現状の水準に保ったまま失格を下げる(2021-08 以降の開始で 7・16・23% → 8・11・12%)。金の向きを決め打ちしないなら半分、金は当面下がると見るなら金なし。
- どちらも EA の入力 1 つの変更(半分 = `InpHoldLegs` の重み 0.12 → 0.06、金なし = `InpHoldEnable=false`)。いまは金の建玉が無いので手動の決済は不要。EA は 11/23(月)08:05 JST ごろに金を建て直す見込みなので、変える場合はそれまでに切り替える。
- 累積セル 10,511 + 6 = **10,517**。
