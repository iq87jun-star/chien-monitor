### Q58(15 セル): 0 通過・改良 0/5・仮説は否定
値日シフト週(木/金に USD・JP 祝日)の火曜 20-00 S は 5 ペアとも 0 前後(+1.9〜−0.5 bps)。逆に同じ週の**水曜はいつもより強い**(USDJPY 9.1 vs 通常 2.5 bps、CADJPY 7.2 vs 2.3)。多日分スワップが火曜に移るという値日仮説は否定。水曜要因は祝日週に強まる = 通常口座のスワップ計算とは別のフロー(docs/279 の「JPY 固有の水曜要因」を補強)。除外は IS Sharpe を上げるが OOS で下がるので改良にならない。

### Q59(5 セル): 0 通過・改良 0/1
金曜陽線 / 陰線、週末ギャップ正 / 負のどの条件でも Mon7 の IS 平均は +5〜+8 bps で差が無い。月曜効果は前週末の値動きへの反応ではなく、月曜固有のフロー。

## 3. 判定と扱い
- 改良系通過 3: **豪 NZ 祝日月曜の除外(AUDJPY / NZDJPY)**、**翌火曜が JP 祝日の月曜の除外(7 ペア)**、ゴトー日の月曜の除外(Mon7・確信度低)。プロトコル通り紙上フォワードの候補に登録(`paper_forward.py` の `MonExAUNZ` / `MonExJpTue` / `MonExGotobi`)。EA 反映は保留(祝日月曜と違い、n が小さいか機構が弱い)。
- パリティ修正の提案: Instant G の指数レッグに NYSE 祝日月曜(2027: 1/18・2/15・5/31・9/6)を `InpMonSkipDates` で入れる(既定の `InpMonSkipIdxOnly=true` で指数のみ)。研究系列がそもそも建てていない日なので、入れないと EA が研究より多く取引する。
- 累積 **9,079**。新規通過 0。この家族(参加者フィルター)で残るのは「豪 NZ 祝日 → EA 反映」の判断のみ。

読み方:
1. 祝日月曜 + 豪NZ祝日 + 翌火曜祝日の 3 つで、Mon4 の年率 +4.9 → +5.7%(+0.8 ポイント、倍率 3.3 なら +2.6 ポイント)、Sharpe 3.47 → 4.90、+月 42 → 44/58。DD と最悪月は不変。年別では 2024 年(+1.9 → +3.5)と 2025 年(+2.0 → +3.1)の弱い年ほど効く。

3. GBPJPY 主体の構成(A 案)では祝日スキップの効果はゼロ(GBPJPY の祝日月曜は 5 年窓ではほぼ中立)。効果は EURJPY / NZDJPY / CHFJPY / CADJPY / AUDJPY から来る。
4. 翌火曜祝日は 5 年で 24 本、豪NZ祝日は AUD/NZD で 80 本。EA 反映するなら豪NZ祝日を先に(n が多く機構が明確)。
