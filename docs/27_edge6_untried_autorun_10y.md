## 3. 各候補の正直な評価
- **E5 RP_TREND（本命）**: 純+70.9% / DD−17.8% / **OOS減衰なし(IS+32.3≒OOS+29.1)** / v7相関+0.07 /
  プラセボ完全に死(−3.5%,p0.49)＝方向シグナルに価値あり / コスト堅牢。**質はMA2より上**
  (DD −19.9%→−17.8%、純益↑、OOS非減衰)。ただし**頑健p0.042はBonferroni0.0083に未達・JKmax0.171は
  ≤0.10未達**＝LEAD。本質は「多資産トレンドを逆ボラ加重でDD改善した版」で、新エッジというより
  MA2の改良。→ **3本目候補として最有力。デモ追検＋縮小サイズでDD実測する価値が最も高い。**
- **E2 株→円リードラグ**: 純+30.6%だが**IS+0.7と弱く利益はOOS(近年)に偏在**、かつ**プラセボも+15.5%**
  =「円クロスLONGの素のドリフト」を拾っているだけで、株の先行情報の付加価値が薄い。採用見送り。
- **E6 相対強さ回転**: 純+3179%・p0.004・JK0.072は通るが、**プラセボ(ランダム選択)が+328%(p0.042)**
  ＝利益の大半は**BTCの上昇トレンドへのベータ**で「回転スキル」ではない。**maxDD−66%で実用不可**。
  プラセボゲート不合格＝正しくLEAD扱い不可。

## 4. 結論・次アクション
- **3本目のクリーン採用は無い**（v7が引き続き唯一の検証済み）。だが**E5は追検する価値のある最良LEAD**
  （MA2の上位互換）。多資産トレンド系が一貫して「正だが有意水準未達・DD過大」で出るのは、
  **エッジは実在するがプロップ−10%枠に素では収まらない**という10年で安定した描像。
- 推奨順:
  1. **E5を主対象**にデモ前進検証＋足内エンジンで**−10%口座に収まる縮小サイズ**のDD/合格率を実測。
  2. E5とMA2は同族＝**逆ボラ加重バスケット**として統合し、v7と低相関(+0.07)の衛星に育てる検討。
  3. **4本目**は本バッチで尽きた多資産トレンド/MR/リードラグ系を離れ、**足内(H1)解像度の別構造**
     (例: イベント前後の定型反応、セッション・ブレイクアウトのコスト厳格版)を、**10年H1が要るので
     ユーザーのDrive実行前提**で事前登録して探索する。
- 規律: LEADを「有意」と誇張しない。E6の派手な数字に飛びつかない(プラセボで露見)。本資金は足内+デモ後。
