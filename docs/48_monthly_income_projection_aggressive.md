## 4. 注意（誠実に）

- **EV(期待値)＝多数試行の平均**。攻めゆえ実現は荒い: INSTANT 2.0xは5年失格31.8%、PROP 3.0xは資金化後
  9.2%/年失格。**口座を失う年は当月収益が落ち再構築**（曲線は平均で、個別は上下に大きく振れる）。
- **出金規律が前提**: 利益は毎サイクル即出金（口座残高を小さく保つ＝破綻・リセット損を最小化, docs/47）。
- **数値はエッジ持続前提**（v4=ADOPT/E5=STRONG-LEAD・過去エッジ）。**本資金前にデモ前進検証必須**。
- 1口座のみ運用なら該当プランの表を見る。再現/期間変更は `python3 sim/monthly_income_projection.py`。

> 免責: シミュレーション・確率であり将来を保証しない。掛け金/規約/スプレッド/スワップは業者・時期で変動。

### 立ち上がり・リスクの違い
- **守り**: 6月¥51k(INSTANTのみ)→PROPは中央9-10ヶ月で資金化ゆえ初年は薄い。5年失格は最小(INSTANT0.5%/PROP≈0%)。
- **標準**: 中央6ヶ月で資金化。12ヶ月¥1.72M。INSTANT5年失格8.8%・PROP≈4%＝バランス型。
- **攻め**: 中央3ヶ月で資金化＝立ち上がり最速・EV最大(12ヶ月¥3.73M)。代償はINSTANT5年失格31.8%/PROP資金化後9.2%/年。

### 一言
- **EVは 攻め>標準>守り**（12ヶ月で約4.0倍 / 1.9倍 / 1.0倍）。攻めは立ち上がりも最速。
- ただし**攻めは失格(口座喪失→再構築)が頻発**＝平均(EV)は高いが各年の実現は荒い。守りは安定だが低い。
- 破綻リスク前提なら**攻め＋出金規律＋業者分散**が docs/47 のEV結論と整合。**中庸が欲しいなら標準**。
