# 455.【Q216】月曜の円クロスの 200 日線の縮小を EMA で(改良系・セル 5)→ 棄却 0 / 5。EMA でも同じ現象を拾うが、SMA とほぼ同じ週を選ぶ(一致 94%)ので差は誤差の範囲。配備中の SMA200 を 3 つの期間すべてで上回る EMA は無い

2026-11-15 登録・実行(ユーザー「EMAでも試してください」)。docs/244 Q216。スクリプト `research/queue/q216_mon4_ema_state.py`、結果 `research/results/q216_mon4_ema_state.csv`・`_diag.csv`。累積セル 10,166 → **10,171**。EA・マニフェスト・config・紙上フォワードは変更なし。

## 1. 方法(事前固定)
- 形 = 配備形 Mon4(4 通貨各 0.25・EA 実時刻・コスト後)の「減らすだけ」: 金曜終値が EMA(N) の下の通貨 1.0 倍・上の通貨 0.5 倍。N ∈ {50, 100, 150, 200, 250}・α = 2 ÷ (N + 1)・N 日分たまるまでは 1.0 倍。
- 読み方: (1) 縮小なしに対して前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しないか。(2) 配備中の形(SMA200)に対して同じ条件を満たせば改良成立。

## 2. 結果(Sharpe。カッコ内は同じ期間の SMA)
| 期間 | SMA との判定の一致 | 前窓 2016-01〜2021-09 | 探索 2021-10〜2024-12 | OOS 2025-01〜2026-08 | 縮小なしより 3 期間とも良いか | SMA200 より 3 期間とも良いか |
|---|---|---|---|---|---|---|
| 縮小なし | — | 0.28 | 1.38 | 1.10 | — | — |

- **SMA200 を 3 つの期間すべてで上回る EMA は無い**(改良成立 0 / 5)。どの EMA も前窓で SMA200(0.46)に届かない。
- EMA と同じ期間の SMA の差は、Sharpe で ±0.09 以内。上回る期間と下回る期間が混ざり、一定の向きは無い。
- 診断: EMA の下 / 上の平均の差は、5 期間 × 3 窓の 15 区分すべてで正(+5.3〜+23.4 bps)。「線の下にいる通貨のほうが月曜は強い」は EMA でも同じ。

## 3. 判定と含意
- **棄却 0 / 5**(正常な結果)。配備中の SMA200 を変えない。紙上フォワードにも入れない。
- 線の種類(SMA / EMA)は結果をほとんど変えない。判定が 94% 一致しており、違うのは線をまたぐ前後の数週間だけ。
- Q214(日数)と合わせて、この縮小は「長めの移動平均の下にいるか」という大づかみな状態に効いており、線の細かい作り方には依存しない。
