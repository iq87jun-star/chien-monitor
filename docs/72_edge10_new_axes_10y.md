## 0. 一行結論

> **N5「52週高値近接の指数ロング」が自走バッチ史上初の ADOPT（6/6ゲート通過・Bonferroni生存 p=0.0017）。**
> 価値の正体は**リターンではなくリスクタイミング**（純益はランダム同数ロングと同等だが、maxDD −12.8% は
> ランダム分布の p98.8 で浅い＝高値圏だけ乗ることでクラッシュを構造的に避ける）。
> 次点で **N2「米10年金利の週次変化→翌週USDJPY同方向」が強LEAD**（p=0.0107でBonferroni僅差未達、
> IS/OOS均衡 +34.8/+39.6、既存エッジと無相関、L/Sゆえベータ非依存）。
> N1(VIX期間構造)・N4(銅/金比)は**タイミング・プラセボでベータと区別できず**＝見かけのLEADを採用しない。

## 2. ★新設ゲート: タイミング・プラセボ（E6の教訓の制度化）

ロング限定・指数系候補（N1/N4/N5/N6）は、**ランダム方向プラセボでは強気相場ベータを殺せない**
（E6 が +3179% を出してプラセボで露見したのと同じ罠）。そこで:

- **同じ資産・同じ建て回数で「ランダムな期間にロング」する分布（500抽選）**を作り、
  候補の純益とmaxDDがその分布の**どのパーセンタイルか**を採点。
- **採用条件: 純益またはmaxDDのどちらかで p95 超**（=ランダムなタイミングでは95%再現できない何か）。
- これを `G_beta` とし、**ADOPT には G_beta 通過を必須**とする。

## 4. 各候補の正直な評価

- **N5 NEARHIGH_52W（ADOPT・本バッチの収穫）**: US500/NAS100/GER40 を「前月末終値が52週高値の95%以上」の
  銘柄だけ翌月LONG（月次リバランス・等加重）。**頑健p 0.0017 は本リポジトリの自走バッチで初の Bonferroni 生存**。
  JKmax 0.013（どの1年を抜いても有意）・IS+59.1/OOS+49.6 の均衡・コスト20bpsでも+110%。
  **価値の正体を盛らずに言うと「リターンのタイミング・スキルではなくリスクのタイミング・スキル」**:
  純益はランダム同数ロング(中央値+128%)と同等(pct 57.2)だが、**maxDD −12.8% はランダム分布(中央値−23.7%)の
  p98.8** ＝「高値圏にいる間だけ乗る」ことで暴落月（2020/3, 2022年弱気相場）を構造的に回避している。
  これは**プロップ(−10%枠)に最も欲しい性質**。E-Mon 相関 0.16・v7 相関 −0.05 で既存と独立。
  系譜としては MA2/E5（多資産トレンド）と同族の「トレンド系」だが、**SMA合成ではなく52週高値近接という
  別シグナルで、JK/Bonferroni を通った点が質的に新しい**（MA2/E5 はどちらも未達だった）。
- **N2 RATES2JPY（強LEAD・追検最優先）**: 米10年金利の週次変化符号→翌週USDJPY同方向。+88.2% /
  maxDD−13.6% / **IS+34.8 vs OOS+39.6 の理想的均衡** / 既存エッジと完全無相関 / L/S ゆえベータ問題なし /
  コスト3倍でも+53%。頑健p 0.0107 は Bonferroni 0.0083 に**僅差未達**（v7 が docs/14 で直面した壁と同型）。
  **金利データ(^TNX)は MT5 内で参照できないため EA 単体実装は不可**＝運用するなら外部シグナル
  （週次の金利変化を見て手動/スクリプトでON）になる。まず**デモ前進検証の記録対象**として最有力。
- **N1 VIXTS**: 数字は派手(+145.8%)だが**週の94%でON＝ほぼバイ&ホールド**。タイミング・プラセボで
  純益pct 5.6（ランダム同数ロングの方が儲かる）＝**シグナル価値なし**。maxDD−30.9%も実用不可。不採用。
- **N4 COPPERGOLD**: 純益pct 55.2 / DDpct 85.0 でベータ識別未達。銅/金比に弱い選別価値の兆候はある
  （DD回避が中央値−19%→−12.4%）が、N5 の下位互換。不採用。
- **N3 FXXS_MOM**: FXの横断モメンタムも死んでいた（FX内は docs/14/20/21 と合わせ完全に焼け野原）。
- **N6 VIXSPIKE_MR**: 方向性は面白い（純益pct 93.4）が **n=26 では何も言えない**。棄却。

## 5. 採用の形 — N5 を第4スリーブ候補「NH52」としてEA化

- **EA**: `mql5/Chien_NearHigh52_EA.mq5`（新規）。月初第1営業日に各指数の「前月末終値 ≥ 52週高値×0.95」を
  判定し、満たす銘柄だけ等加重LONG・翌月初に再判定（満たさなくなったら決済）。ガードは全EA共通
  （equityフロア−8%/日次−4%/災害SL=2.5ATR）。プリセット: `mql5/presets/nearhigh52_default.set`。
- **位置づけ**: 既存確定ポート（v4 55 : E-Mon(RG3) 45, docs/61/68）への**追加は本書では決めない**。
  ポート再構成は等ボラ標準化での畳み込み比較（docs/67 の手順）を経てから。**まずデモで建玉・決済・
  スワップ実測**（1ヶ月保有のスワップ累積は S-Jul と同じ注意点）。
- **再現**: `python3 research/edge10_newaxes_10y.py`（固定窓・キャッシュは research/data/*_yd.csv）。
