# 186.【事前登録】選抜価値のウォークフォワード検証 — 「選抜しない版」との対照実験

> 2026-09-01作成。docs/185 §5「9月は追加投資ゼロの回収観測月」に適合する**費用ゼロの研究**。
> 動機: docs/184でD案の12ヶ月バウンドが 62.2% → **9.5%** に劣化した。これは事故ではなく
> 「13活動日の窓で選んで同じ窓で倍率を校正する」という設計の帰結である。
> ならば問うべきは**「そもそもTop-4選抜は価値を生んでいるのか」**。
> 本docは`research/selection_value_walkforward.py`の実行**前**にルールを凍結する。実行後の変更禁止。

## 0. なぜ既存の3バウンドでは答えが出ないか

docs/175/181/184が併記してきた3バウンドは、いずれも本問いに答えられない:

| バウンド | 何を測っているか | 本問いへの適性 |
|---|---|---|
| 楽観(選抜窓) | 選んだ窓で選んだ構成を測った値 | ✗ 定義上ほぼ最良。docs/181 §2が自ら「無意味に近い」と記載 |
| 中間(直近12ヶ月) | 選抜窓を含む期間の成績 | ✗ 選抜窓と重複するため独立でない |
| 悲観(全期間) | **その構成**を10年前から持っていたら | ✗ 「選抜という行為」を一切評価していない。選抜されなかった過去の構成が無視されている |

**欠けているのは「選抜規則を毎月適用し続けたら実際どうなったか」**= ウォークフォワード。
本実験はこれを初めて測る。

## 1. 帰無仮説

> **H0: 直近窓スコアによるTop-4選抜は、同一セル母集団のブロード配分に対して、
> 真のアウトオブサンプル(選抜時点で未知の期間)で優位を生まない。**

H0が棄却できない場合、A/B/C/D案・Instant・速攻プロの設計思想(=選抜)そのものが
価値を生んでいないことになり、10月の無償再スクリーニング2件(非FX 10/31・Instant 10/31)の
設計を変更する根拠になる。

## 2. 共通条件(全アーム同一・実行前固定)

- データ: Yahoo日足・凍結窓 **2016-01-01..2026-08-31**(docs/184と同一凍結・同一キャッシュ方式)
- セル母集団: **34セル**(Mon 13 / Hold 6 / TSMOM 6 / v4 9)。`recentfit_screen.py`と同一構築式・同一コスト。
  新しいセル型は追加しない(本実験は「選抜の価値」のみを測る。手法の優劣を混ぜない)
- セル系列は全期間で一度だけ構築する。全構築式がcausal(時点iの値はc[0..i]のみに依存)であることを
  実装レビューで確認済みのため、全期間構築と逐次構築は同値
- **倍率規則は全アーム共通**: `mult = min( 0.8 × min(m*_ruleWindow, m*_12m), 6.0 )`。
  `m* = max{m: 最悪単日×m ≥ −4% ∧ 月中DD×m ≥ −8%}`。docs/180 §1と同一
- コスト・スリッページ: セル構築式に内包(追加調整なし)

## 3. アーム定義(6本・実行前固定)

| アーム | 選抜 | フィルタ | 加重 |
|---|---|---|---|
| `SEL12` | 直近12ヶ月スコアTop-4(B案=docs/174規則) | 活動日≥15・12m累積>0・6m累積>0 | 12m逆ボラ・cap40%・銘柄1/族2 |
| `SEL6` | 直近6ヶ月スコアTop-4(C案=docs/180規則) | 活動日≥8・SEL>0・直近3m>0 | SEL窓逆ボラ・cap40%・銘柄1/族2 |
| `SEL3` | 直近3ヶ月スコアTop-4(D案=docs/180規則) | 活動日≥5・SEL>0・直近6週>0 | SEL窓逆ボラ・cap40%・銘柄1/族2 |
| `BROAD_FILT` | **なし**(Top-Kを課さない) | SEL12と同一フィルタのみ | 12m逆ボラ・cap40% |
| `BROAD_IV` | **なし** | **なし**(34セル全部) | 12m逆ボラ・cap40% |
| `BROAD_EW` | **なし** | **なし**(34セル全部) | 等加重 |

- `BROAD_FILT`は「符号フィルタだけの価値」を分離する中間アーム。
  SEL12 > BROAD_FILT > BROAD_IV なら**順位付けに価値がある**。
  SEL12 ≈ BROAD_FILT > BROAD_IV なら**価値があるのは符号フィルタだけでTop-4は無駄**。
  差が無いなら**選抜行為全体が無価値**(H0棄却できず)。
- `BROAD_EW`は逆ボラ加重自体も推定であるため、その依存度を測る対照。
- スコア定義は全SELアームで `mean/std×√n`(活動日ベース)。docs/174/180と同一。

## 4. ウォークフォワード手順(実行前固定)

1. リバランス日 t = **2019-01-31 以降の各月末**(2026-07-31まで)。
   2016-2018はウォームアップ(最長12ヶ月窓+セル構築の助走)に充て、評価に含めない。
2. 各tで、**t以前のデータのみ**を使って加重と倍率を決定する。
3. 決定した加重・倍率を **t より後**の日次リターンに適用する(t当日は含めない)。
4. 保有期間は2種類を併記:
   - **(a) 月次入替**: 保有1ヶ月。統計力が最大でアーム間比較の主系列とする
   - **(b) 配備ケイデンス**: 保有 = 窓長/3(SEL12→3ヶ月・SEL6→2ヶ月・SEL3→1ヶ月・
     BROAD群→3ヶ月)。docs/174の期限比率に一致させた実運用相当
5. フィルタを通るセルが0本の月は**ノーポジション(その月は0%)**として記録する
   (規則が「配備しない」と言っている状態を勝手に埋めない)。
6. 各アームのOOS日次系列を連結する。

## 5. 評価指標(実行前固定)

1. OOS累積・年率・年率ボラ・シャープ・最悪単日・最悪月中DD・最大DD
2. **OOS系列に対するMC**(これが本実験の主たる成果物 = 初めての正直なバウンド):
   - FTMO 2-Step(P1+10%→P2+5%)と FN Stellar(P1+8%→P2+5%)の両土俵
   - 静的−10%・EAガード−4%クリップ・5日ブロックブートストラップ・シード7・1万パス
3. アーム間差の検定: 月次リターン差の対応ありt検定 + 月次ブロックブートストラップ95%CI
   (SEL12−BROAD_IV / SEL6−BROAD_IV / SEL3−BROAD_IV / SEL12−BROAD_FILT)
4. アーム間相関行列(OOS)
5. SELアームの**回転率**(月次の構成入替率)— 選抜ノイズの直接的な代理指標

## 6. 事前に宣言する解釈規則(後知恵の禁止)

結果を見てから解釈を決めないため、判定基準を先に固定する:

| 結果 | 判定 | 帰結する行動 |
|---|---|---|
| SEL群のOOS年率が BROAD_IV を**95%CIで有意に上回る** | 選抜に価値あり | 現行設計を維持。窓長別の優劣で10月の窓選択を決める |
| 有意差なし(CIが0を跨ぐ) | **H0棄却できず** | 10月の再スクリーニングは**ブロード配分版も同時に事前登録**し、両者を並べてユーザー決定に付す |
| SEL群が BROAD_IV を有意に**下回る** | 選抜は有害 | 既存トラックの次回入替をブロード配分へ切替える提案を出す(既存稼働口座の途中変更はしない) |

- **どの結果でも、稼働中の8口座の構成は本実験を理由に途中変更しない**(docs/174 §1・
  docs/179 §4の「直近が悪いから入れ替える」混線防止規律を継承)。
  反映先は**期限到来時の再スクリーニング設計のみ**。
- 本実験は費用ゼロであり、docs/185 §5の「9月は新規チケット購入なし」に抵触しない。
