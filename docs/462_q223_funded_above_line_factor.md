## 1. 方法(事前固定)
- モデルは Q221 と同じ。本口座後の決定済みの構成(docs/241 §1bc〜§1be: 倍率・ロール・縮小の下限 0.25・停止線は現行)で、200 日線より上にいる円クロスの倍率を {0.5, 0.25, 0} に変える。月曜の倍率は決定済みの {1.0, 1.25, 1.5, 2.0} 倍(SL リスク上限のある 1-Step・FN 2 口座は {1.0, 1.5} 倍)。決定済みの行は Q221 の「縮小の下限 0.25」の行と一致(FTMO 50k: 100 / 99 / 96%・96%・+37 / +70%)。
- 推奨の規則: 決定済みの行に対し、10 年存続 −1 ポイント以内・2016〜21 年のみの 5 年存続 −1 ポイント以内・10 年累計出金 +3 ポイント以上、を満たす行のうち累計出金が最大のもの。

## 3. 読み取れること
1. **線の上の倍率を下げると、弱い時期の出金は増える。** 同じ倍率のまま 0.5 → 0 にすると、2016〜21 年のみ 5 年の累計出金は FTMO 50k +30 → +35%・宝くじ +26 → +31%・ルビー / パール +21 → +27%・1-Step +21 → +28%。存続も少し上がる。
2. **ただし 10 年の累計出金は減る。** 同じ倍率では FTMO 50k +70 → +64%・宝くじ +70 → +59%・トパーズ +108 → +99%。2020 年以降は線の上にいる通貨でも月曜はプラス(平均 +4.5 bps)なので、そこを捨てる分が効く。
3. **倍率を上げて補っても、総額はほぼ同じ。** FTMO 50k で線の上 0 倍・4.69 倍にすると 10 年存続 95%・累計 +68%・弱い時期 +38%(決定済みは 96%・+70%・+30%)。総額を保ったまま弱い時期の取り分を厚くする「入れ替え」にはなるが、上積みにはならない。
4. 形式判定の候補は 2 口座。どちらも SL リスク上限のある口座で、倍率の格子が 2 点(1.0・1.5 倍)しかなく、選ばれたのは格子の端。1-Step は線の上 0.25 倍・3.65 倍で累計 +58 → +64%・弱い時期 +21 → +33%・存続は同じ。FN 14166201 は線の上 0 倍・4.5 倍で +100 → +110%・+25 → +38%・10 年存続 100 → 99%。
5. 評価中の配備には当てはめない(線の上を 0 にすると建てる通貨 × 週が 3〜4 割に減り、到達が遅れる)。

## 4. 判定と提案(「切替」事項)
- FTMO 50k ×2・宝くじ・トパーズ・ルビー / パール・FN 14074882 は**現行どおり**(線の上 0.5 倍のまま)。
- 1-Step と FN 14166201 は形式上の変更候補。採用するかはユーザーの判断(本口座後の予定の書き換え)。
- 「弱い時期に戻ることを重く見る」なら、総額を少し譲って線の上を 0.25〜0 倍にし、倍率を 1.25 倍に上げる形が全口座で取れる(存続はほぼ同じ・10 年累計 −0〜3 ポイント・弱い時期の出金 +3〜8 ポイント)。これは規則の候補ではなく、好みの問題として記録する。
