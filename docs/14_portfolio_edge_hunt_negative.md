# 14. ポートフォリオ用「無相関エッジ」探索 — 誠実な NEGATIVE 結果

> **出所**: `research/edge_search_seasonality.py`(committed 10年日足×9ペア)の実出力。
> `python3 research/edge_search_seasonality.py` → `research/results/edge_search_seasonality.json`。
> 数値は実行結果のみ転記(docs/07/08/11の仮数値errorを繰り返さない規律)。

## 0. 目的と一行結論
ユーザー方針: 「先に**無相関の新エッジ**を探索し、全候補に厳格ハーネスを課す」。
→ 最も引用されるFXカレンダー・アノマリー2系統(**曜日**・**ターン・オブ・マンス**)を
全9ペア×両方向で全数検定した。

**一行結論: 新しい無相関エッジは見つからなかった。この市場で統計的に頑健な
カレンダー・エッジは『円の月曜シーズナリティ』ただ1つ。** ポートフォリオを組むだけの
独立エッジ群はデータに存在しない。

## 1. 探索設計(全候補に厳格ハーネス)
- データ: `research/data/<PAIR>_d.csv` = EUR/GBP/AUD/NZD/USD系9ペア, 2016-2026 日足10年。
- 取引日正規化: 日足は23:00/00:00混在(セッション境界)。`trade_date=(t+2h).floor('D')`で
  取引日に揃えた。**sanity gate 合格**(EURUSD曜日件数 Mon521/Tue521/Wed520/Thu519/Fri520,
  週末0 → 正規化は正しい)。
- トレード: trade_date の open でエントリ、翌営業日 open で決済(1営業日保有)、往復2pip控除。
- 候補空間: 曜日5×9ペア×方向2 = 90、+ ターン・オブ・マンス(月末1+月初3営業日)9ペア×方向2 = 18。
  **計108検定** → Bonferroni α = 0.05/108 = **0.00046**。
- ハーネス: 順列検定(4000回・符号シャッフル) / IS-OOS / 全年ジャックナイフ / Bonferroni /
  コスト感応 / **v6基準(EURJPY月曜LONG)との相関**。

## 2. 結果 — 順列 p≤0.05 はわずか2件、いずれも既存の円月曜エッジ
| label | family | 純益 | 勝率 | maxDD | n | 順列p | **v6相関** |
|---|---|--:|--:|--:|--:|--:|--:|
| EURJPY_Mon_L | 曜日 | +31.4% | 54% | −5.9% | 521 | 0.0055 | **1.00** |
| GBPJPY_Mon_L | 曜日 | +30.0% | 55% | −10.2% | 521 | 0.0175 | **0.75** |

- **Bonferroni 生存(p≤0.00046): 0件。** 日足解像度では円月曜すら補正を通らない
  (H1の08UTC版=v6の方が強い。docs/12-13)。
- 上位2件は **v6そのもの**(相関1.00 / 0.75)。新規性ゼロ。
- **非JPY全ペア(EUR/GBP/AUD/NZD USD, USDCAD, USDCHF)に有意な曜日エッジは皆無。**
  → 曜日アノマリーは汎FX現象ではなく**JPYクロス固有**と確定。
- **ターン・オブ・マンスは全9ペア・両方向で p≤0.05 にすら到達せず**(機序が違っても
  この期間のFXでは有意な月末月初フロー・エッジは検出されない)。

## 3. これが意味すること(v1〜v6 + 本探索の総メタ結論)
本プロジェクトで検定し**棄却**してきたもの:
- v1-v5: 平均回帰 / RSI逆張り / ORB / 合議 / 極値モメンタム / TSMOM(価格方向予測)→ 全滅
- 本探索: 曜日(非JPY)/ ターン・オブ・マンス → 全滅

**生き残った唯一のエッジ = 円の月曜シーズナリティ(v6)。** しかも3JPYクロスは相関
0.5-0.76の1現象。**∴ 現データから「無相関エッジを並べた分散ポートフォリオ」は組めない。**
これは失敗ではなく、過剰最適化を拒否し続けた規律の当然の帰結 ── 市場は1つしかエッジを
くれなかった、という事実の確定。

## 4. ∴ 現実的な選択肢(ユーザー判断)
無相関エッジが無い以上、進路は3つ:
1. **現実を受容 → v6を「正しくリスク予算化した1本」に仕上げる**(EURJPY主軸、合算DDを
   10%の十分内側<6%に抑制)。これが今出せる唯一の「利益の出るEA」。分散は諦め、
   単一エッジを器に最適化する。
2. **データ宇宙を拡張**してエッジを探す: 金(XAUUSD)・株価指数・暗号資産・より多くの
   通貨ペア、または10年H1(時刻系の再探索)。未検証の市場には別エッジがあるかもしれない。
3. **非カレンダー系の別フレームワーク**: ペアトレード(相対価値)・キャリー・ボラ売り等、
   方向予測でもカレンダーでもない系統を厳格ハーネスで検定。

> 免責: 本探索もシミュレーション。NEGATIVE結果は「この期間・このデータで検出されない」で
> あり、将来や別データでの存在を否定しない。最終判定は前進検証で行う。
