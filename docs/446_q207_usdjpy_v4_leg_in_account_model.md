## 1. 前提
- 月曜レグ = Q198 の H1 経路(全決済ガード 2.8%・月内 2 回停止)。2 つの縮小は月曜レグだけに掛かる(EA の実装どおり)。
- USDJPY の逆張り v4 = 日足の系列(account_cards.S)を Q190 の方法で重ねる。日中の経路は無いので、日次の損益 ≤ −2.8% で全決済(−3.08%)とみなす。水曜ロールはモデル外。
- 構成: (a) 現行、(b) v4 半分、(c) v4 なし、(d) v4 なし・その分を月曜へ振り替え(月曜 1.437 倍)。
- 窓 W1 = 2021-08〜2026-07、W2 = 2016-11〜2021-07。安値判定(終値判定は CSV)。

## 4. 本口座 10 年(合意済みの月曜倍率・2 つの縮小・4 週ごとに全額出金)
値 = 5 年存続 / 10 年存続 / 10 年の累計出金の平均(額面比・分配前)/ W2 のみの 5 年存続。
| 口座 | (a) 現行(逆張りを同じ比で残す) | (b) 半分 | (c) なし | (d) 月曜へ振り替え |
|---|---|---|---|---|
| ルビー(月曜 3.13 倍・逆張り 1.37 倍) | 68 / 43 / +51 / 66 | 86 / 72 / +55 / 78 | **91 / 81 / +57 / 72** | 67 / 42 / +59 / 41 |
| パール(月曜 2.78 倍・逆張り 1.22 倍) | 78 / 57 / +51 / 77 | 94 / 87 / +54 / 88 | **96 / 91 / +57 / 85** | 77 / 57 / +60 / 52 |

- **規則の判定: 両口座とも「(c) v4 なし」が変更候補**(10 年存続 +38 / +34 ポイント・累計出金 +6 ポイント)。(b) 半分も条件を満たす(+29 / +30 ポイント・+4 / +3 ポイント)。
- 本口座では利益を毎回出金するので緩衝が積み上がらない。平均がほぼゼロの逆張りは振れだけを足し、失格を早める。評価中と違い「目標に早く届く」効用も無い。
- W2 のみの 5 年存続は (b) 半分が最良(ルビー 78・パール 88)。W2 は逆張りの平均がプラスだったため。全期間では (c) が最良。
- **docs/442(Q203)の本口座の数字(ルビー 3.1 倍: 81 / 72 / +56、パール 2.8 倍: 91 / 85 / +57)は月曜レグのみのモデルで、本稿の (c) と一致する**。逆張りを同じ比で残した場合(docs/241 §1ax の「全体 4.5 倍 / 4.0 倍相当」の目安)は、10 年存続が 43% / 57% まで下がる。今朝の数字を実現するには、本口座では逆張りを外す必要がある。

## 5. 判定と提案
- **評価中(いまの段階・次の段階): 現行維持**。
- **本口座: USDJPY の逆張りを外す = 変更候補**(ルビー・パールとも)。採用は「切替」事項で、資金化の時点の EA に反映する(月曜の倍率は合意済みのまま・振り替えはしない)。
- 同じ注意は他の口座にも当てはまる: docs/442 の本口座の数字は全口座とも月曜レグのみで、GER40 ブレイクアウト(FTMO 50k 0397・宝くじ)・金の保有(宝くじ・1-Step)・水曜ロール(Fintokei)は入っていない。これらは逆張りと違って平均がプラスのレグだが、本口座に残した場合の存続率は未計測(別途登録)。
