# 33. 7本目探索の【事前登録 第4弾】(pre-registration) — 残余の土俵

> 第1〜3弾（E3-E6, F1-F3, H1-H3）は本資金採用ゼロ。主要な独立土俵はほぼ否定済み。
> 本ドキュメントは**残余**の3土俵：株式のフロー・カレンダー／金のボラ点火／実質金利→金。
> 事前確率は高くないが、N 固定・Bonferroni 補正で正直に検定する。

## 固定パラメータ（検定前に確定）

- **候補数 N = 3**（I1/I2/I3）。**増やさない。**
- **有意水準 α = 0.05 / 3 = 0.0167**（Bonferroni）。
- **期間**: 2016-2025 の10年実データ。
- **本資金 ADOPT 条件** = 6 ゲート ∧ 分割標本 both_significant（前後半とも p≤0.10）。
- 本資金即投入禁止。ADOPT かつ頑健でも縮小サイズ実測 → デモ前進検証。

## 候補（各々 事前仮説つき）

| ID | 土俵 | 事前仮説（方向つき） | v7 と別な駆動因子 | 既検との違い |
|----|------|---------------------|------------------|-------------|
| **I1** | 株式のターン・オブ・マンス | SPX。**月末最終営業日〜翌月第3営業日に LONG 保有**（機関のリバランス・フロー）。 | 株式の月末資金フロー | docs14/20 は FX のカレンダー。これは**株式**の月末効果。 |
| **I2** | 金のボラ点火モメンタム | XAUUSD。**当日レンジ>1.5×ATR20 かつ陽線→翌日 LONG / 陰線→翌日 SHORT**（ボラ拡大の継続）。 | レンジ拡大の継続性 | docs22/23 は緩慢な TSMOM。これは**日次ボラ点火の翌日継続**。 |
| **I3** | 実質金利→金 | XAUUSD。**US10Y が20日で低下→翌日 LONG / 上昇→翌日 SHORT**（金の実質金利感応）。 | 米長期金利（実質金利の代理） | E4/H2 は金利→**円**。これは金利→**金**のクロスアセット。 |

※ いずれも v7（円）と資産/駆動因子が別で低相関を期待（G6 で判定）。
