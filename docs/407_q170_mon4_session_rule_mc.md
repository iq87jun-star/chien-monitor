## 4. 読み
1. **3pip 仮定の Q165 は全 9 口座で改善**(同倍率: 失格 −2〜22pt・30 か月出金 1.5〜2.0 倍)。「IS/OOS の高さで最悪月を補えるか」への答えは、口座単位では「補える」だった。日次ガード(−dll クリップ)が 2024-08-05 型の 1 日を止めるため、研究系列の最悪月悪化が MC では失格に直結しない。
2. **しかしその優位の大半は週明け寄りのスプレッドを無視した分**。実スプレッドでは同倍率の改善は 30 か月出金で +0〜15%・失格 −0〜5pt に縮み、最悪月・MDD は配備形より悪化(1-Step は出金 157 → 155 で改悪)。規約揃えでは日次限度に当たる最悪日が −1.93% と深いため倍率が配備形の 0.65 倍に縮み、FTMO 50k ×2・パール・宝くじ・ルビー・1-Step で**出金期待が半減以下**。改善が残るのは Mon レグの比重が小さいトパーズ・14074882 と Instant のみ。
3. Q165(docs/403)の IS Sharpe 2.78・OOS 2.77 は、**約 7 bps/週の寄りスプレッドを含まない数字**として読み直す必要がある。実スプレッドで配備形に対する Sharpe の優位は IS で +0.04、OOS で +0.44 に縮み、最悪月は 2 倍。改良系の判定(不成立)は変わらず、不成立の理由に「コスト」が加わる。先物向け紙上候補 MonJpySession6J(USDJPY・日曜 22 → 月曜 20 UTC)にも同じ注意が当たる(6J の週明け寄りも薄い)。
4. 配備形 Mon4 が月曜 4〜10 UTC 建てであることは、「月曜東京時間のギャップを避ける」(docs/404)に加えて「週明け寄りのスプレッドを払わない」点でも合理的で、Sun 22 UTC 系の建て時刻の再検定(docs/404 §4 (a)(b))は見込みが下がった。

## 5. 判定・提案
- 配備・config・CANDIDATES は変えない。Q165 置換の「切替」は推奨しない(実スプレッドで優位がほぼ消え、規約揃えでは不利)。
- docs/403・404 と docs/244 の「近い候補」一覧に、Q165 の数字が寄りスプレッド未反映である旨を注記する(本 docs で実施)。
- 以後の Sun 22 UTC 建て系(docs/404 §4 の 2 セル)を登録する場合は、**ask 建て(実スプレッド)で判定する**ことを事前固定にする。研究 Mon 形(4〜10 UTC)は日中スプレッドが 3pip 仮定の内側なので影響なし。
- 残る改善余地は Q162 E7(Mon ×0.7 + Hold UK100/WTI)の「切替」判断と、Mon4 の SL 幅(docs/405 §6 (a)・2 セル)。
