## 4.2 対照(G3)の読み — 検定の違いを正直に書く

docs/82 の G3 は「符号反転(H0: 平均 0)」で p=0.005 だった。同じ検定なら本データでも再現する
(2016〜: n=85、+20.6bps、符号反転 p=0.002)。しかし本 doc の検定は **同曜日の非事象日に同じ 24h 窓を置いた平均(≈+4bps = 株式プレミアム)との比較**で、
それだと p=0.18(2016〜)/0.12(2011〜)。**G3 の「FOMC 固有」成分(+13〜16bps)は点推定では大きいが、ばらつきが大きく単独では有意に届かない。**
ADOPT(docs/82 の 6 ゲート)は撤回しないが、期待値 +1.5%/年のうち FOMC 固有分は統計的には未確定、と注記する。
G3 の実質的な価値は「年 8 日しか市場に居ないのに、居る日の平均が無条件の 4〜5 倍」という**時間効率**にある。
