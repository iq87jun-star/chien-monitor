# 155.【計測】FN Stellar Instant $20k × 季節R4+G3 — 倍率別ステップアップ中央月

> ユーザー質問(2026-07-15)「リスク倍率を高めた場合のステップアップ中央月は?」への計測回答。
> `python3 research/instant20k_stepup_mc.py` の実出力(`results/instant20k_stepup.json`)からの転記のみ。
> ルール(docs/154 §5・公式Help確認済み): 失格=トレーリング−6%(建値ロック)。
> 昇格=現tierで累計出金10%+出金1回 → **「+10%初到達で一括出金」を代理指標**
> (1回で両条件充足・建値ロック下では中間出金しない方が合理的)。
> 同月内に昇格と失格が両成立の場合は日次先着・同日はfail優先(保守)。
> 方法: docs/111系の日次ブロックMC(月単位BS・シード7・2万パス・36ヶ月上限)。Yahoo=保守側。

## 2. 読み方(トレードオフの構造)

- **速度は買えるが確率は買えない**: 12ヶ月内昇格率は0.75xの76.5%が頂点で、以後は倍率を
  上げるほど**低下**する(2.5xで59.9%)。「速くしたつもりが失格で振り出し」が増えるため。
- 掛金$599は返金なし。昇格1回あたりの期待掛金 = $599/成功率:
  0.5x=$611 / 1.0x=$754 / 1.5x=$852 / 2.5x=$1,000。失格の度に買い直し+tier進捗リセット。
- チャレンジ系(静的DD・掛金返金)と違い、インスタントの高倍率は**失格コストが実費**になる。

## 3. 目安(どうしても使う場合)

- 生存重視(docs/154の運用結論と同じ): **0.5x** — 昇格98%だが中央11ヶ月と遅い。
- 昇格レース重視の妥協点: **0.75〜1.0x** — 中央6〜8ヶ月・12ヶ月内昇格率が最大帯(76%)。
- 1.5x超は非推奨: 中央3〜4ヶ月に対し失格30〜40%=$20k口座で買い直し前提の賭けになる。
