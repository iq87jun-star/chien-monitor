## 0. なぜこのバッチか(「検証は出尽くしたか?」への回答の一部)

ユーザー問い「全ての可能性を考慮しているか」に対する棚卸し(2026-07-11):

| 未検定の方向 | 入手可能性(本環境で実測) | 扱い |
|---|---|---|
| **ポジショニング(COT)** | ✅ CFTC Socrata API 疎通確認済・JPY/金とも**1986年〜**(pre-2016耐久ゲート可能) | **本バッチで検定** |
| **OpEx満期週カレンダー** | ✅ 価格データのみで検定可(Yahoo ^GSPC) | **本バッチで検定** |
| オーダーフロー/板 | ❌ 歴史データが無償で存在しない | 検定不能(扉は開けない) |
| FXオプションIVサーフェス/リスクリバーサル | ❌ 有償のみ(VIX系期間構造は F2 で棄却済) | 検定不能 |
| 限月別先物の基差/キャリー | △ Yahoo個別限月は欠損が多く信頼不能。FXキャリー自体は edge17 で棄却済 | データ品質不足で見送り |
| 個別株CFD | △ 価格はYahooで取れるが、FN/FTMOで取引可能な銘柄集合が未確認 | ユーザーが取引可能銘柄を確認した場合のみ将来バッチ |
| センチメント調査(AAII等) | ❌ 歴史データはログイン/有償 | 検定不能 |

→ **無償・再現可能な形で入手できる未検定データはCOTが最後**。OpExは「同じ価格宇宙」だが、
docs/113 L3 が許す「既存エッジ(E-Mon=株カレンダー・フロー)の機序から演繹される隣接仮説」であり、
棄却済み領域(月末月初=edge8 / 9月=edge15 / ハロウィーン・発表日=edge16 / 非JPY曜日=edge4)の
いずれとも別物(月中のデリバティブ満期イベント週)。本バッチが REJECT なら、
**リテールで実装可能な検定手段は文字通り消尽**となり「出尽くした」が確定する。

## 3. ゲートと判定(docs/80 §5 標準+edge19の9ゲート型・機械適用)

**独立仮説(H23a/c/d)**: α = **0.0025**(Bonferroni 0.01/4)

| ゲート | 基準 |
|---|---|
| G1 経済性 | 主窓(2016-01〜2025-12)net>0 かつ Sharpe≥0.3 |
| G2 頑健p | 符号置換 p < 0.0025 |
| G3 年次JK | 全year-out p<0.05 かつ 最悪year-out net>0 |
| G4 プラセボ | **ドリフト保存**(ポジション列の資産内シャッフル=ON比率・L/S構成保存)。H23dは「月内ランダム週」プラセボ(月1週ON保存)。実net>placebo p95 かつ p<0.05 |
| G5 コスト2倍 | net>0 |
| G6 IS/OOS | 70/30分割で両方net>0 |
| G7 pre-2016 | net>0 かつ p<0.05(耐久クラス判定・コアゲート外) |
| G8 相関 | 既存4スリーブ(v4/v7/E-Mon/E5)と全て\|ρ\|<0.5 |
| G9 ポート寄与 | 新スリーブ15%追加(既存×0.85)でポートCalmar改善 |

- 判定: コア(G1-G6,G8)全合格 → G7合格なら **ADOPT候補(長期構造)**/G7不合格なら **LEAD**。
  コア1つでも不合格 → **REJECT**。
- **H23b(ゲート型)は相対規則**: 2016-2025を3等分し、**全ブロックでゲート後Sharpe>ゲート前Sharpe**
  かつ ON比率保存ランダムゲートのプラセボ p<0.05 → LEAD(デモ前提)。それ以外 → 現行v7維持。
