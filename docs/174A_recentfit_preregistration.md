# 174.【設計登録】直近フィット・トラック — 意図的レジームベットの別枠運用

> 発端: ユーザー指示(2026-07-30)「過去検証から安定しているEAを作るのは正攻法だが、**過去1年
> (極論半年)だけ伸びているEA**を作りたい。本番口座まで行けば元が取れるので、数回の報酬でも御の字。
> **正攻法とは別で**考えたい」。
> 本docはそのトラックの設計登録。⚠ 通常の事前登録(コミット後に実行)と異なり、本件は設計を
> `research/recentfit_sweep.py` のヘッダに凍結してから同一セッション内で実行した(弱い形式の事前固定)。
> 選定フィルタ・窓・グリッドは実行前に固定し、実行後の変更はしていない。

## 1. トラックの定義(正攻法との違いを明文化)

| 項目 | 正攻法トラック(季節RG3/PD系) | **直近フィット・トラック(本doc)** |
|---|---|---|
| 検証基準 | 10年+LOYO+Dukascopy追試 | **直近12ヶ月のみ**(REF窓は開示のみ) |
| 多重検定 | Bonferroni等で統制 | **意図的に受容**(直近1位を取りに行く) |
| 期待寿命 | レジーム転換まで数年単位 | **数ヶ月〜1年で剥落する前提** |
| 成功条件 | 長期の複利 | **チャレンジ通過→報酬数回で元回収** |
| 口座 | 現行3口座(docs/172) | **別口座のみ**(混ぜない) |
| 撤退規律 | フォワード採点(docs/103) | **月次R<0が2ヶ月連続で停止・再スイープ**(§5) |

- 賭けの構造: チャレンジ費用(数百ドル)を掛金に、直近レジーム継続へベット。外れた場合の目標は
  「**失格せず時間切れ/小損で終わる**」こと(ガードが担保)。当たれば数ヶ月で通過し報酬で回収。
- ⚠ 誇張しない: これは統計的エッジの主張ではない。「直近に効いた型が当面続く」という
  **明示的な仮定**であり、REF窓(前年)成績がマイナスのスリーブも採用しうる。

## 2. データと窓(実行前固定)

- データ: Yahoo H1+日足(`research/fetch_recent.py`、凍結窓 2024-08-01..2026-07-24 UTC)。
  Yahoo H1は730日制限があるため再現実行が遅れると先頭が欠ける(結果JSONに実範囲を記録)。
- **FIT(選定)**: 2025-07-01..2026-04-30(10ヶ月)
- **HOLDOUT(サニティ)**: 2026-05-01..2026-07-24(約12週) — 符号確認のみ。最適化には不使用
- **REF(開示)**: 2024-08-01..2025-06-30 — 採用判断に**不使用**。レジーム依存度の開示専用
- 実行系: ノールックアヘッド(確定足→次バー始値)・実コスト(スプレッド半値+スリッページ0.5pips往復)。
  正攻法と同一の原則。ここは緩めない。

## 3. 候補グリッド(実行前固定・1602本)

全て既存EA群で実装済みの「型」に限定(実装リスクを増やさない):

| 族 | 型 | グリッド |
|---|---|---|
| A | 曜日×時刻エントリー・k時間保有(H1) | 曜日5×時刻{0,4,8,12,16}UTC×保有{6,12,24}h×売買2 ×9ペア |
| B | 日足TSMOM(n日リターン符号)・1日保有 | n{3,5,10,20,60}×順張り/逆張り ×9ペア |
| C | 日足RSI逆張り・h日保有 | RSI{2,14}×閾値{10/90,20/80,30/70}×保有{1,3,5}日 ×9ペア |

- R換算: R = 純変化率 / (3×ATR14(D1)%)、−1クリップ(=EAの3×ATR災害SLと一致)。選定指標もR基準。

## 4. 選定規則(実行前固定)

1. FIT窓で 取引数≥25(頻度が低すぎる型は運用に乗らない)
2. FIT窓で PF≥1.3 かつ t値≥2.0
3. HOLDOUT窓で 取引数≥3 かつ 合計R>0(符号サニティ。量は問わない)
4. t値降順に並べ、**ペア×族の重複を排除**して上位から最大5本
5. 採用スリーブ間の日次R相関(FIT窓)を開示(選定には使わない)

## 5. 運用・撤退規律(実行前固定)

- リスク/トレードはMC(`research/recentfit_mc.py`)で較正。**規則失格確率を最小化する側**に丸める。
- ガードは現行v1.44系をそのまま継承: balance基準日次−4%/tick・月3回で月末停止・フロア−8%恒久停止・
  利益ロック(P1: +8.0%arm/+8.5%close)。
- フォワード採点: 月次でスリーブ別合計Rを記録(docs/103の枠組み)。**月次合計R<0が2ヶ月連続で
  トラック停止**→データ更新して再スイープ(スリーブ総入替を許容。正攻法と違い「守る」対象ではない)。
- 資金化後: 倍率を0.5〜0.68xに減率(正攻法の資金化減率と同思想)し、報酬確定を優先。
