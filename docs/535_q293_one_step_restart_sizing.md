## 0. 結論
1. **先に決めた選び方の結論: いまの設定(満額・金そのまま)のまま再開。** 数量を下げる 3 つの形・金を外す形は、14 件すべてが「悪化」の判定(2 期間のどこかで到達が 1 ポイントを超えて下がる)。
2. **ただし、口座そのものの見込みが悪い。** いまの設定で再開した場合の 52 週は、金が実績どおりなら 到達 61% / 失格(全停止)38%(2021-08 以降の開始)・22% / 74%(古い期間)。金が横ばいなら 39% / 56%・21% / 78%。**8 週以内に全停止する割合は 33〜43%(金が横ばいなら 45〜49%)。** 11/20 の計算(docs/511: 93% / 7%・31% / 55%)から、11/24 のガード発動で大きく悪化した。
3. **数量を下げる形は「延命と引き換えに到達を失う」。** 金そのまま + 下限 0.5 は、8 週以内の全停止が 33 / 43% → 25 / 30% に下がり、古い期間の失格が 74% → 56% に下がるが、2021-08 以降の到達が 61% → 57% に下がる。金が横ばいの場面では合計点が基準と同じ(−74.4)。
4. **「金なし + 下限 0.25」は別の性質の形**: 8 週以内の全停止は 1〜2%、52 週の失格は 9% / 39% まで下がるが、52 週の到達も 15% / 9% しかない(口座は残るが 1 年では通らない)。金の値動きに左右されない(2 場面で同じ)。
5. **金を外すと到達が大きく下がる**(満額で 61% → 30%)。この口座の到達は、金の値上がり(2021〜2026 年の実績)に強く頼っている。金が横ばいなら、金を持つ形の失格は外す形より高い(56% 対 38%)。
6. **判断の材料**: 通過をねらうなら、いまのまま再開(規則どおり)。口座を残すことを優先するなら「金なし + 下限 0.25」だが、1 年以内の通過はほぼ諦める形になる。どちらにするかはユーザーの判断(替えるなら「切替」)。

## 2. 「年明けまで休む」について
この枠組みでは、休んでも開始が遅れるだけで確率は変わらない(1-Step に期限は無い)。計算はしていない。金も月曜も建てない間は、損も得もしない。

## 3. 限界
- 夜の指数(v1.10)・年末年始の休止は入れていない。NAS100 の 1 時間足の欠け。
- 過去の各週から 52 週の再現で、開始の週が重なる(独立な標本は少ない)。古い期間の数字は金の値動きが弱かった時期のもの。
- 判定の線(到達 −1 で悪化)は、延命型の形には厳しい物差し。合計点と 8 週以内の全停止を併記した。
