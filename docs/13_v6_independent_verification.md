## 0. 一行結論
**月曜シーズナリティ・エッジは独立再現で「本物」と確認された。だが v6 EA の既定設定
(3ペア同時・各0.40%)は FundedNext Phase1 を FAIL する。** 原因はエッジの不在では
なく、(a) 相関したJPYクロス3本の合算DDが10%制限を超える、(b) スワップ符号への
致命的依存。**単一ペア運用かつスワップ確認を前提にすれば現実的に通せる。**

## 1. エッジの健全性 — 独立検証は CONFIRM(私の結論を支持)

### 1-1. 曜日プラセボ(最重要・順列p値)
各ペアで月曜が最小p、他曜日は全て非有意。シーズナリティの主張を支持。
| pair | Mon | Tue | Wed | Thu | Fri |
|---|--:|--:|--:|--:|--:|
| EURJPY | **0.0000** | 0.378 | 0.366 | 0.888 | 1.000 |
| GBPJPY | **0.0050** | 0.201 | 0.456 | 0.437 | 1.000 |
| USDJPY | **0.0340** | 0.095 | 0.554 | 0.726 | 0.968 |

### 1-2. 時刻プラセボ(04-10UTC帯 vs 全時刻平均pip)
| pair | 04-10帯 | 全時刻 |
|---|--:|--:|
| EURJPY | +7.73 | +3.64 |
| GBPJPY | +9.46 | +5.34 |
| USDJPY | +3.32 | +1.39 |
EURJPYは時刻02/04/06/08で順列p=0.0000、10で0.0013、12で0.0025、14時以降は非有意。
→ 朝方の帯に局在する構造で、ランダムな時刻選択では出ない。

### 1-3. Hold-Out(前半5年IS / 後半5年OOS, 分割2021-01-01)
| pair | IS 平均pip / PF | OOS 平均pip / PF | 判定 |
|---|--:|--:|---|
| EURJPY | +5.71 / 1.21 | **+8.64 / 1.34** | OOS増強 |
| GBPJPY | +2.04 / 1.04 | **+10.78 / 1.32** | OOS強く増強 |
| USDJPY | **−0.09 / 1.00** | +4.84 / 1.23 | ⚠ ISはほぼゼロ。直近偏重 |

### 1-4. ジャックナイフ(各年1つ除外, leave-one-out 平均pip範囲)
| pair | 範囲 | 全てプラス |
|---|--|--|
| EURJPY | [+3.12, +11.74] | ✅ True |
| GBPJPY | [+2.70, +7.74] | ✅ True |
| USDJPY | [+1.14, +3.21] | ✅ True |
単一年への依存なし。

### 1-5. Bonferroni(多重検定補正)
試行数 = 曜日5×3ペア + 時刻12×3ペア = 51、補正後 α ≈ 0.05/51 ≈ **0.00098**。
- EURJPY 月曜朝(02-08UTC)は p=0.0000 で**補正後も生存**。
- GBPJPY 月曜08は生p=0.0037 で**Bonferroni後は脱落**(ただし時刻04/06は0.0000で生存)。
- USDJPY 月曜は生p=0.034 で**脱落**。
- (注: surv出力テーブル自体はPDFで途切れており、上記はemp_p表からの読み取り。)
→ **EURJPYは最も厳格な補正でも有意。GBPJPY/USDJPYは生pでは有意だが補正で弱る** =
強さに序列がある(EUR > GBP > USD)。USDの単体エッジは脆い、という私の指摘を補強。

**小括: エッジは EURJPY を主軸に確実に存在。v1〜v5の方向予測とは別物。**

## 2. ★致命的欠陥①: 3ペア合算は FundedNext Phase1 を FAIL

ガード有効・各0.40%リスクで3ペアを同一口座で同時運用したときの合算判定:

| 区間 | n | 純益 | 最大DD | Phase1 |
|---|--:|--:|--:|---|
| EURJPY 単体 | 139* | +8.12% | **4.42%** | ✅ PASS |
| GBPJPY 単体 | 348* | +8.20% | 9.83% | ✅ PASS(辛勝) |
| USDJPY 単体 | 427* | +8.46% | 8.18% | ✅ PASS |
| **3ペア合算** | 914 | +24.78% | **11.81%** | ❌ **FAIL(DD抵触)** |

\* +8%目標到達でガードが新規停止するため件数が異なる(EURは早期到達)。

相関(月曜トレードpip): EUR-GBP **0.68** / EUR-USD 0.55 / GBP-USD 0.51。
→ 3本は独立しておらず「円の週明け」1現象。**損失日が重なり、合算DDが個別の最悪
(9.83%)をさらに超えて11.81%**まで膨らみ、10%制限に抵触。到達/失効まで14.9ヶ月。

> **つまり docs/12 の「3ペアのチャートに1つずつアタッチして3ペア同時運用を推奨」は誤り。**
> 分散効果を期待した3本同時が、相関ゆえに逆にDDを増幅し失格を招く。

### 運用上の落としどころ
- **EURJPY 単体**(最良: maxDD 4.42%, p=0.0000, OOS増強, Bonferroni生存)を主軸にする。
- 複数運用するなら**各リスクを大幅に下げる**(例: 0.15-0.20%)か、ペア間で**同時保有を
  制限**して合算DDを10%の十分内側に抑える設計が必須。現行の各0.40%×3は不可。

## 3. ★致命的欠陥②: スワップ符号への依存(合算純益・DD)

月曜LONGを火曜まで1泊するため、スワップ(1泊あたりpip)が結果を支配する。検証:
| swap pip/泊 | 合算純益 | 最大DD |
|--:|--:|--:|
| +2.0(受取) | +24.89% | 8.54% |
| +1.0 | +25.27% | 9.80% |
| 0.0(中立) | +24.78% | 11.81% |
| **−1.0(支払)** | **+8.68%** | **18.40%** ❌ |
| −2.0 | −8.35% | 21.59% ❌ |
| −3.0 | −8.40% | 23.17% ❌ |

→ **わずか −1pip/泊の支払いで純益が +24.78% → +8.68% に半減、DDは18.4%で失格圏。
−2pipで完全に負け。** 検証の好成績は「スワップが中立〜プラス」を暗黙の前提にしている。

**現実のリスク**: JPYクロスLONGのスワップは、日本がゼロ金利だった時代は受取(+)だったが、
**日銀の利上げ局面では縮小・反転**しうる。ブローカーによっても符号が異なる。
→ **ライブ投入前に、使用ブローカーの3ペアLONGスワップが現在プラスか必ず確認**。
マイナスなら、このエッジ(時間決済で1泊保有)は成立しない。

## 4. 総合判定(v6)

| 観点 | 結果 |
|---|---|
| エッジの統計的実在 | ✅ 確認(EURJPY主軸, 曜日/時刻/OOS/JK/Bonferroni) |
| v1〜v5(方向予測)との差 | ✅ 別系統。初めて独立再現に耐えた |
| 既定設定(3ペア×0.40%)で Phase1 | ❌ **FAIL(合算DD 11.81%)** |
| スワップ堅牢性 | ❌ 脆弱(−1pip/泊で失格圏) |
| **運用可否** | ⚠ **条件付き**: 単一ペア(EURJPY)+ スワップがプラス + 低リスク なら可 |

**結論**: 「エッジは本物だが、現状のEA設定では prop を通らない」。これは v1〜v5 の
「エッジ不在」とは質的に異なる、**初めて『実装と資金管理の問題』に到達した段階**。
方向予測の壁は越えた。残る壁は (a) 相関ポートフォリオのDD設計、(b) スワップという
実コスト ── どちらも工学的に対処可能。

## 5. 次アクション(推奨順)
1. **EAを単一ペア前提に再設定**: 既定を EURJPY 単体・`InpMaxOpenPositions=1`、
   3ペア運用する場合の `InpRiskPerTradePct` を 0.15% 程度に下げる版を用意。
   合算DDが10%の十分内側(目安<6%)に収まることを再検証してからプリセット化。
2. **スワップ実値の確認**: 使用予定ブローカーの USD/EUR/GBPJPY LONG スワップを取得し、
   検証に実スワップを注入して純益・DDを再計算。プラスでなければ投入見送り。
3. **デモ前進検証**: 上記2点クリア後、EURJPY デモで実エントリー時刻(TimeGMT)・実
   スプレッド・実スワップ込みで数ヶ月。+8%/DD<10% が再現したら少額funded。
4. (任意)**円依存の希薄化**: 非JPYメジャー(EURUSD等)で月曜効果を追試。残れば相関の
   低い分散先になり、合算DD問題が緩和しうる。
