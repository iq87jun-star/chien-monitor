## 判定
「到達も失格も両方良くなる」倍率があるのは 3 口座:
1. **#14074882: 5.0 → 4.0**(到達 84.7 → 85.0、失格 13.9 → 10.8、中央 73 → 96 日)。
2. **EA3: 2.5 → 3.3**(到達 92.1 → 95.3、失格 0.0 → 0.1、中央 88 → 66 日)。校正倍率(docs/308 §2)とも一致。
3. **Instant G: 4.0 → 3.0**(到達 79.7 → 82.1、失格 20.2 → 16.6)。ただし中央 58 → 84 日で、年率も 37 → 27%。「年率を上げたい」という当初の狙い(docs/298)とは逆方向なので、失格率を優先する場合のみ。
他は配備倍率が最適か、倍率では改善しない。
