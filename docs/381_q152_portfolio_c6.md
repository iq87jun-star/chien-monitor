## 3. 判定と提案
1. **C6 への切替は維持(docs/241 §1ae の事前承認どおり)**。根拠は期待値ではなく、FN 口座の失格を 34% → 13% に下げること(期待の差 −4 万/年は誤差の範囲)。期待値最大だけで選ぶなら現行のままだが、現行は Q85/Q97 で「最悪年失格 40〜53%」と出ており、失格すれば FN の出金 0 と再購入費が掛かる。
2. config(`portfolio_current.json`)の FN は、P2 口座が発行されて C6 を配備した時点で `eval`・`funded` を C6・`dll` 0.03 に更新する(本書では変更しない)。
3. Mon2 CADJPY/CHFJPY の 10.6 年の弱さ(年率 0.8%)は、前窓(2016〜2021)で Mon 円クロス全体が弱かったことと同根(docs/290)。C6 の中核は GER40 Mon(年率 3.6〜3.9%)で、GER40 の FN 銘柄名・スプレッド(docs/380 §2)の確認が実効上の鍵。
4. 11 月改訂への含意: Hold の受け皿が帳簿から消える。Hold を続けるなら新規口座(EA10S の XAU 0.18)で。
