## 3. 読み取り(確定事実)

1. **0.70はゼロ回答**: 増えるのはUSDCADのみで、そのv4セルは12mフィルタを通らない。
2. **0.85(中相関)で初めて構造が変わる**: UK100(Hold)が主役で入り倍率が0.12→0.28へ。
   ただしEVは楽観+$324/悲観トントン — 「損はしないが買う理由も薄い」水準。
   CADJPY/CHFJPYのMonセルは12m成績がフィルタを通らず、実際に効いたのはUK100だけ。
3. **1.00(未採用銘柄なら相関不問)で配備圏に入る**: Mon NZDJPY+Hold UK100が主役、
   mult 0.8、FN資金化46%/20%・EV両バウンドでプラス。
4. **最重要**: 銘柄レベル相関0.87のNZDJPYを入れても、**構成レベルの相関は最大0.31**
   (v7 0.31/B 0.26/C 0.26/D 0.20)。分散目的なら**銘柄相関で縛るより
   「未採用銘柄で組んで構成レベル相関を検証する」方が効率が良い** —
   トラックEシリーズの主発見。低相関の建付け(≤0.55)は代償(暗号限定→倍率崩壊)が
   便益(ρ 0.13 vs 0.31)に見合わない。

## 4. 位置づけと推奨

- 中相関(0.85)そのものは**まだ見送り水準**(悲観EVトントン・FTMOならマイナス)。
- 配備を検討する価値があるのは**TH1.0相当=「未採用銘柄・構成レベル相関≤0.31」構成**
  (FN Stellar限定・悲観でもEV+$287)。それでもC/Dの1/4以下のEVであり、
  「C/D系の再スクリーニング枠を1枚増やす」方がEV効率は上、という比較は残る。
- 採用するなら: ①閾値と構成レベル相関上限(例0.35)を**新規事前登録**(閾値後選びのバイアスを
  明記)、②FN Stellarの暗号・UK100取扱とシンボル確認、③TSMOMレッグEA実装(ADA/LTCが残るため。
  docs/180 §4)、④Mon NZDJPYは配備中の円クロス月曜と同日同方向になり得る
  (別業者=規約可・docs/176 §7.8.3の整理を流用)。
