## 3. 判定と読み
- **成立 0 / 2**。K1・K2 とも Sharpe が 3 窓すべてで下がる。
- CADJPY の月曜(24 時間)と 4 本の束の週次の相関は 0.85 / 0.90 / 0.91(全期間 0.87)。同じ動きをするので分散にならず、週次のばらつきも減らない(38.4 → 39.2 bps)。
- CADJPY 単独の土台は Sharpe 0.17 / 0.95 / 0.18 で 4 本の束より弱い。同じ動きで弱いものを 5 分の 1 混ぜるので、その分だけ薄まる。
- 最悪月は前窓で少し浅くなる(−3.07 → −2.94、E1 で −1.41 → −1.21)が、探索では深くなる(−0.75 → −0.76、E1 で −0.63 → −0.68)。
