## 2. 読み方

1. **コストを実測値(仮定の 1/3〜1/10)に下げても通過 0。** p < 0.05 が偶然期待 86 に対し 15 本しか無いのは、コスト後の IS +月率の分布が 5 割より下に寄っているため(LONG 中央値 0.462・SHORT 0.419)。つまり H1 の時間帯セルの粗利は、コストの大小以前に「月次で正に偏る」性質を持っていない。
2. 上位には **Mon 円クロス LONG(USDJPY Mon 12-16・EURJPY Mon 08-16・AUDJPY Mon 08-16)** が並ぶ。これは稼働中の Mon 族(docs/09 系・10 年検証)そのもので、格子が既知の族を拾えていることの確認になる。単独セルの p は 0.005〜0.012 で、累積 Bonferroni の閾値には遠い(Mon 族の採用根拠は本格子ではなく docs/09〜 の別経路)。
3. 最良の AUDJPY WedS 20-00(p=0.0017・IS 29/39・OOS 14/20)は前窓 0.46 で基準未達。SHORT 側の上位は 20-00 UTC に集中し、これは docs/249 で無効化した Sess 族の窓と同じ。実測コストでも Sess の 8 セルは上位に入らない(docs/262 §B と整合)。
4. **結論: H1 の時間帯格子は、コストモデルを最も有利にしても閉じる。** 累積 8,259 セル。docs/252 §3 の「H1 の新規探索は一巡」は実測コスト版でも変わらない。残る余地は ①M15 以下のデータ(未取得)②既存レグの改良(A 案 S3 の出口 20 UTC・docs/262 §B.3)③長寿命トラック(TSMOM・Q1)。
