## 0. 結論
1. **順位は docs/383 と同じ。** 参考扱いの旧指定(FTMO Std 100k + EA10 ×3.3・失格 35%)を除くと、首位は The5ers High Stakes 100k + A 案 ×1.5(純益 176.2 万・到達 81.0% / 失格 16.2%)、同じ規則の CTI が同値、FTMO Std 100k + EA10S ×2.0 は 146.2 万(到達 79.4% / 失格 12.3%)。首位の純益の変化は docs/383 の 167 万に対して +5%(20% 未満)。
2. **倍率を変えずにガードを足す形は、どの候補でも採用にならない(改善 0・差なし 4・悪化 14)。** 月曜の円クロスだけの候補(FN Stellar・The5ers の Mon4 ×3.3)は、失格が 20〜23% → 1% 以下に下がるが、数量が半分〜7 割になるので 36 か月の純益も 84〜93 万 → 2〜26 万に落ちる。A 案(金 + GBPJPY 月曜 + NAS100 月曜)は円クロスが 3 分の 1 しか無いので、ほとんど変わらない(差なし〜小幅減)。
3. **読み方**: ガードは「失格を減らす道具」で、同じ倍率のままでは稼ぎも減らす。新しく買う口座でガードを生かすには、ガードを入れた上で倍率を上げる形(例: Mon4 を G2 のまま ×3.3 より高く)を別に確かめる必要がある。今回は対象外(登録の範囲外)。
4. **買うかどうかの判断材料は 11 月初めから実質的に変わっていない。** 料金・規則・クーポンは 10/28 時点のままで、再確認していない。

## 2. 再現について(登録外の注記)
- 「Q88 再現(全期間・G0)」の行は、いまのリポジトリで Q88 のスクリプトをそのまま動かした値と一致する(本スクリプトの中で照合)。ただし docs/383 の表の値とは一致しない(例: FTMO Std 100k + EA10S ×2.0 は 74.2 / 17.1・純益 116 万 → 71.4 / 21.1・114 万、The5ers + A 案は 81.3 / 15.0・167 万 → 81.2 / 15.0・172 万)。docs/383 の後に、帳簿の月曜レグを EA の実際の時刻(1 時間足)に置き換えたため(docs/411 Q176)。
- 同じ期間の G0 が全期間より良く出る候補があるのは、2016 年 1〜10 月(英国の国民投票の週を含む)が外れるため。型どうしの比較は同じ期間で行っている。

## 3. 限界
- 日次の帳簿(1 日 1 本)・日次ガードの発動にすべりなし(Q88 と同じ)。損失枠の縮小は毎日の残高で計算(EA は月曜の建玉時)。
- 口座モデル(1 時間足・52 週の到達と失格)では 3 つのガードは「到達 − 失格」を良くした(docs/528)。今回は 36 か月の金額で比べており、物差しが違う。矛盾ではなく、ガードは失格を減らす代わりに速さを落とす、という同じ性質を別の面から見ている。
