# 493.【Q253】金の保有の含み損の持ち越しを日次ガードの余地から引くと、ガードの発動は 2〜3 倍に増える。ただし合格・失格の割合はほとんど変わらず、金を外す・半分にする案は 11 件とも現行どおり(セル +21)

## 1. 何を確かめたか
- EA の日次ガードは「現在の equity ≤ 当日開始時点の balance ×(1 − g)」。balance に含み損益は入らないので、金の保有の含み損はその日の余地を最初から削る(含み益は逆に余地を広げる)。
- 従来の口座モデルは月曜のレグだけを g と比べていた。金の保有は入れないか、日次の系列として独立に足すだけだった。
- 対象は金の保有がある評価中の 3 口座。1-Step(金 = 元本の 0.36 倍・g 2.4%)、宝くじ(0.9 倍・g 4%・決済は採用済みの E1)、FN 14074882(0.4 倍・g 4%)。

## 2. 方法
- 金の建値は経路で決まるので、週の無作為抽出は使わない。評価の開始週を 1 週ずつずらし、実際の週の並びで 52 週まで進めて、到達・失格・未決を数える。
- 週 = 月曜のサーバー日の開始から 5 日。日ごとに「月曜レグの当日損益 + 金の含み損益(建値から・スワップ込み)」≤ −g を時間順に判定する。
- 発動したら全決済(当日損益 −g × 1.1・従来と同じ約束)。その日は建てず、金は翌サーバー日の開始で建て直す。暦の月内 2 回の発動で月末まで新規停止(月曜も金も)。災害 SL(建値 −15%)も入れた(発動 0 回)。
- 金の値動きは日足(2016〜2026。日中は前日終値のまま、その日の最後に終値 / 安値を反映)。1 時間足(2021〜2025)で照合した(§6)。
- 開始週: 2021-08 以降 210 週、2016-11〜2020-07 が 196 週。開始残高は 2026-11-16 21:22 UTC の equity。
- 「現状」= いまの建玉と含み損から始め、建て直しは EA の設定どおりの大きさ。宝くじはいま 0.29 倍(倍率を上げる前に建てたもの・含み損 −2.3%)で、建て直すと 0.9 倍になる。1-Step は 11/16 のガードで決済済みで、建て直すと 0.36 倍(これまでは 0.17 倍)。FN は 0.39 倍(含み損 −0.6%)。

- **含み損の持ち越しを数えても、到達・失格はほとんど変わらない。** 「現状」と「金を独立に足す(従来の扱い)」の差は、同じ出発点で比べられる 1-Step・宝くじ 次・FN 次で 0〜3 ポイント。発動は増えるが、1 回あたりの損は −g × 1.1 から含み損の分だけ小さく(含み損はすでに equity に入っている)、発動後は金の建値が切り直されて余地が戻るため。
- **金を外す案は、どの口座でも到達が下がる。** 失格が下がるのは宝くじ(30 → 20%・2021-08 以降)と宝くじ 次(5 → 0%、12 → 0%)だけで、到達の下げ(−24 / −14 ポイント、−13 / −25 ポイント)の方が大きい。

## 5. 判定(事前固定 = Q233 の ev_ok。基準は「現状」)
両期間で到達 −1 ポイント以内・失格 +1 ポイント以内、かつどちらかの期間で到達 +2 ポイント以上か失格 −2 ポイント以下。

- 11 件とも **現行どおり**: 1-Step(金なし・半分)、宝くじ いま(金なし・半分・いまの大きさ)、宝くじ 次(金なし・半分)、FN いま(金なし・半分)、FN 次(金なし・半分)。
- いちばん近いのは宝くじ 次の「建て直しを半分に」(2021-08 以降は 100 / 0 で現状より良いが、2016-11〜2020-07 の到達が 85.7 → 79.1%)。

## 6. 照合
- 金の 1 時間足と日足の近似を、同じ開始週(2021-01〜2024-12・209 週)で比べた。現状の到達 / 失格: 1-Step 100.0 / 0.0 と 100.0 / 0.0、宝くじ いま 56.5 / 34.9 と 57.9 / 34.9、宝くじ 次 90.4 / 8.6 と 92.3 / 7.7、FN いま 39.7 / 44.0 と 37.8 / 43.5、FN 次 95.2 / 0.0 と 95.2 / 0.5(1 時間足 / 日足)。発動は 1-Step で年 2.61 回と 2.42 回。日足の近似で結論は変わらない。
- 月曜レグだけの月曜ガード率は従来の run_guard と同じ値を再現(1-Step 2.2%・宝くじ いま 3.2%・FN 0%)。

## 7. 限界
- **金はどちらの期間も上がっている**(2016-11〜2021-07 に +41%、2021-08〜2026-07 に +122%)。金を持つ型の到達が高いのは、この値上がりを含んだ結果。金が横ばい・下落の時期の成績は、このデータからは分からない。
- 開始週は 1 週ずつ重なる。割合は独立な試行の数ではなく、幅は見かけより広い。従来の方法(週の無作為抽出)とは水準が合わない(金なしの 1-Step: 無作為抽出 77.9 / 9.1・48.0 / 25.4、この方法 81.4 / 0.0・35.2 / 34.7)。比較はこの文書の中だけで行う。
- 発動時の損は「当日 −g × 1.1」の約束のまま。金が週明けに大きく窓を開けた場合の超過は入っていない。
- 宝くじの GER40 ブレイクアウト(試験運用)は入れていない。停止線は従来どおり −10% で統一。
- 業者の日次ルールそのものではなく、EA のガードの式を再現したもの。

## 8. 手順の開示
- 最初は「週の表を作って無作為抽出する」設計で実行した。金を何年も持ち続ける前提になり、含み益がガードを隠す誤りに気づいたため、結果は採らずに §2 の方法へ組み替えた。この時に候補 10 件の判定行(うち 2 件が変更候補)を見ている。
- 組み替えた後、いまの含み損を開始時点で二重に引く誤りを 1 件直した(宝くじ いま・FN いま の数字に影響)。
- セルは、最初の設計の 10 件と組み替え後の 11 件を合わせて +21 と数える(累積 10,329 → 10,350)。
