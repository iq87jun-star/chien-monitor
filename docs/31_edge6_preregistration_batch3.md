# 31. 6本目探索の【事前登録 第3弾】(pre-registration) — 未踏土俵

> 第1弾 E3-E6・第2弾 F1-F3 は本資金採用ゼロ（F2 は脆弱）。本ドキュメントは**別バッチ**。
> これまで触れていない **株式の分散リスクプレミアム／金利カーブの傾き／金の日内シーズナリティ**を、
> v7（円の週明け季節性）と駆動因子が別になるよう設計。N 固定・Bonferroni 補正。

## 固定パラメータ（検定前に確定）

- **候補数 N = 3**（H1/H2/H3）。**増やさない。**
- **有意水準 α = 0.05 / 3 = 0.0167**（Bonferroni、別バッチ別補正）。
- **期間**: 2016-2025 の10年実データ（Dukascopy 実 H1 / FRED / Yahoo）。
- **判定**: 6 ゲート（lib/evaluate）**＋ 分割標本 both_significant**（前後半とも p≤0.10）を
  本資金 ADOPT の必要条件とする（docs/30 で F2 が前半非有意＝脆弱だった教訓）。
- 本資金即投入禁止。ADOPT かつ頑健でも -10% 枠で縮小サイズ実測 → デモ前進検証。

## 候補（各々 事前仮説つき）

| ID | 土俵 | 事前仮説（方向つき） | v7 と別な駆動因子 | 既検との違い |
