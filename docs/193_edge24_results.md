## 2. 読み

1. **X1 は当リポで docs/126 の消尽宣言以降、初のゲート通過候補。** プラセボp=0.000 は
   「ランダム10銘柄ポートフォリオ1,000本のどれよりも良い」であり、edge11-F2 型の
   「市場ベータの言い換え」では説明できない(プラセボも同じベータを持つため)。
   学術上最も頑健とされるクロスセクション・モメンタムの既知の性質とも整合的。
2. **X2(低ボラ)の全面的な負けも情報**: 2016-2026 のメガキャップ強気相場では低ボラは
   一貫して劣後。学術アノマリーでも「この宇宙・この期間には無い」ものは無い、の実例。
3. **X3(結合)の不合格は X1 の希釈**: 低ボラ順位を混ぜると優位が消える。
   結合の妙味なし。X1 単体が登録勝者(事後の重み変更はしない=docs/165)。
4. 警戒点(正直に):
   - **生存者バイアスは相対評価でも完全には消えない**。特にモメンタムは「生き残った勝者」を
     選びやすい方向のバイアス。docs/192 §5 の通り、主張は「生存者集合内での相対優位」に留める。
   - 負け年3はゲート上限ちょうど(2021 −14.7% / 2025 −8.8%)。モメンタム・クラッシュの
     既知のリスクが本ユニバースでも現れており、サイズ設計時は左尾を織り込む。
   - 超過の相当部分が 2020/2024/2026 に集中(メガキャップ・テック集中の regime)。
