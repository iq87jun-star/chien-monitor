### 読み取れること
1. **停止線を失格線に近づけるほど残る**(S0 → S1 → S2 で 10 年存続 +1〜7 ポイント)。出金はほぼ同じか少し増える。止まった口座はそこで終わりなので、手前で止める利点は「失格線を割らない」ことだけ。
2. **一番効くのは縮小の下限(S4)**。現行の停止線のまま下限を 0.5 → 0.25 にすると、10 年存続は FTMO 50k 84 → 96%・1-Step 89 → 98%・ルビー / パール 92 → 96%(2016〜21 年のみ 78 → 92%)・FN 14074882 85 → 96%・宝くじ 96 → 100%・トパーズ 96 → 98%。累計出金は ±1 ポイント以内で変わらない。逆に下限 0.75(S5)は大きく悪化する(FTMO 50k 84 → 58%)。
   - **S4 は登録時に「比べる形」には入れたが、推奨の規則の候補の列(S1 → S2 → S3)には入れていなかった。** 形式判定の外の所見として記録する。EA の変更は入力 1 つ(`InpBufShrinkMin`)で済み、停止線を動かすより単純。
3. **止めずに絞る(S3・S6)は、試算上は一度も失格線を割らない**(存続 100%)。ただし (i) 累計出金は 1〜2 ポイント減る(残りの枠が 4% 台に入った時点から絞るため)、(ii) 10 年後に生きている口座の 0.3〜3.7% は残りの枠が 2% 未満で動けない、(iii) 100% は「この試算の中では割らなかった」という意味で、ガードが効かない窓開けや滑りは入っていない、(iv) EA の改修が大きい(数量の上限と日次ガードを残りの枠に連動させる)。
4. 参考(1 段上の倍率): S4 なら FTMO 50k 4.5 倍で 86%・+73%、宝くじ 5.0 倍で 97%・+71%、トパーズ 4.0 倍 + ロールで 91%・+115%、ルビー / パール 3.13 倍 + ロールで 93%・+99%。下限を 0.25 にすれば、§1bb で下げる前の倍率でも残る水準になる。

## 4. 判定と提案(「切替」事項)
- 形式判定: FTMO 50k ×2 と FN 14074882 は「−9.8% で停止」、ルビー / パールは「止めずに絞る」が変更候補。宝くじ・1-Step・トパーズ・FN 14166201 は現行どおり。
- 私の見方: 停止線を動かすより、**本口座用の EA で縮小の下限を 0.25 にする**ほうが単純で、全口座に同じ向きで効き、失格線に近づく危険も増やさない。形式判定の候補の列に入れていなかったので、採用するかはユーザーの判断。本口座用の EA はまだ作っていないので、いま決めれば作る時に反映できる。
- 本番中の FN Instant(縮小の下限 0.5・幅 6%)は今回の対象外。下限 0.25 が Instant でも効くかは未計算。
- 評価中の EA(縮小の下限 0.5 の宝くじ・ルビー)は対象外: 評価中は到達の速さも要るので、下限を下げる効果は別に確かめる必要がある。
