# 29. 5本目探索の【事前登録 第2弾】(pre-registration) — 未踏土俵

> docs/27 の第1弾（E3-E6）は全 REJECT。本ドキュメントは**別バッチの新規事前登録**。
> docs/26「未踏の土俵」のうち、第1弾で触れていない**セッション・ブレイクアウト／キャリー／
> 安全資産フロー**を、駆動因子が v7（円の週明け季節性）と別になるよう設計する。
> N を先に固定し、当たるまで増やさない。Bonferroni 補正。

## 固定パラメータ（検定前に確定）

- **候補数 N = 3**（F1/F2/F3）。**増やさない。**
- **有意水準 α = 0.05 / 3 = 0.0167**（Bonferroni）。第1弾(E3-E6)とは別バッチなので別補正。
- **期間**: 2016-01〜2025-12 の10年実データ（Dukascopy 実 H1 / FRED / Yahoo）。
- **検定統計量**: 日次 R 系列の Sharpe、月次ブロック符号シャッフルの順列検定。
- **6 ゲート全通過で ADOPT**（lib/evaluate）。p が 0.0167〜0.10 の惜しい圏で G1・G3・G6 通過なら LEAD。
- 本資金即投入禁止。ADOPT が出ても -10% 枠での縮小サイズ実測 → デモ前進検証。
