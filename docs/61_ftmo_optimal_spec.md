## 2. 銘柄レベルの構成比（各手法の中身）

### v4（55%）— FX 9ペア・k≥4合議・両建て可
等加重（各ペア ≈ 55%/9 ≈ **6.1%/銘柄**のリスク寄与）。1ペア1ポジ（同一ペアの反対同時なし）。

| 区分 | 銘柄 |
|---|---|
| 円クロス | EURJPY / GBPJPY / USDJPY |
| ドルストレート | EURUSD / GBPUSD / AUDUSD / NZDUSD / USDCHF / USDCAD |

ロジック: RSI(14)<35/>65・BBz(20)±1.5・連続3日・当日±0.5% の4条件 k≥4 で逆張り。SL=1.5ATR(D1) / TP=RR1.2 / 8日時間切れ。

### E-Mon（45%）— 株価指数3つ・月曜LONG・24h
等加重（各指数 = 45%/3 = **15%/銘柄**）。月曜の指定時刻にLONG、24h時間決済。**指数SHORTは一切作らない**（準拠の要）。

| 銘柄 | 単体Sharpe(参考) |
|---|--:|
| NAS100 | 1.06（最強） |
| US500 | 0.86 |
| GER40 | 0.79 |

（NAS100が最強だが、頑健性のため**等加重**を既定とする。攻めるならNAS100をやや厚くも可＝任意）

### （任意）暗号衛星（≤8%）— BTC/ETH 月曜LONG
各4%。**暗号可のFTMO口座のみ**。単体maxDD−55%ゆえ衛星上限8%厳守・ガード必須。

## 4. 規約準拠ガード（FTMO・必須）

1. **同一/高相関銘柄の反対両建てを作らない**: v4=1ペア1ポジ・E-Mon=指数LONGのみ・**指数SHORT禁止**。
   （v4が高相関ペアの反対を同時に持つ可能性はグレー＝気になれば抑制ガード追加・最終はFTMO規約準拠）
2. **損失ガードを高頻度で**(docs/60): **日次ストップ−3%**(FTMO−5%の内側)・**サイクル−4%打ち切り**・
   **総合フロア−8%で全停止**・**各ポジ災害SL(2.5ATR)**。←失格率の決定的な低減手段。
3. **ニュース2分制限**: エントリーにニュースフィルタON、または**FTMO Swing口座**(ニュース制限なし＋週末持ち越し可＝v4の数日保有/暗号に好相性)。
4. **最大割当 $400k/戦略・顧客**: スケール時はFN/FTMO合算で管理(docs/58)。
5. **EA自体は許可**(MT4/5/cTrader・事前承認不要)。
