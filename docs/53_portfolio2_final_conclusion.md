## 1. C案(リラティブバリュー=統計的ペア)結果 ★実10年

機構: `log-spread = logA − β·logB`(β=過去120日回帰・t−1) の zスコア平均回帰(z>±2でエントリー/|z|<0.5で手仕舞い)。
事前登録7ペア・Bonferroni α=0.05/7≈0.00714。

- **計測5ペア全てで G4プラセボ不合格**＝スプレッドの方向シグナルが「同機会・ランダム符号」に勝てない。
  **perm_p も 0.20〜0.99 で α(0.007)に全く届かない**＝統計的有意性ゼロ。**流動的な主要ペアは裁定済み**。
- **対現行相関は軒並み低い**(cmax 0.11〜0.24)＝枠組みとしては独立だが、**そもそもエッジが無いので無意味**。
- ⚠ **注記(誠実な記録)**: US500/GER40・XAUUSD/AUDUSD は **Yahooの取引所間で日足タイムスタンプがずれて整列せず
  n=0**(戦略の良し悪しではなくデータ不具合)。ただし計測5本が全てプラセボで決定的に落ちており、この2本に
  救済の見込みは薄い。厳密化するなら日付正規化で再計測可能だが、結論は変わらないと判断。

## 2. なぜ3度とも落ちたか(市場効率の壁)

- **方向性エッジ(v1/A)**: v4のMRは"メジャー固有"、E5のトレンドは"金+米独株の上昇相場固有"で、別ユニバースへ
  汎化しなかった。トレンド持続資産(国債/暗号)は高netに見えても**OOS消滅 or プラセボ落ち(βを拾うだけ)**。
- **相対価値エッジ(C)**: 主要ペアのスプレッド平均回帰は**裁定で消えており**、プラセボに勝てない。
  金銀比・US500/NAS100のように**スプレッドが"反転"せず"トレンド"した**ケースは大損。
- 共通項: **v7(円月曜)・v4(メジャーMR)・E5(多資産トレンド)は、この10年で"たまたま"生き残った特異点**であり、
  同種の独立エッジが他に都合よく転がってはいない——という市場効率の素直な帰結。

## 4. 最終結論・推奨

- **第2ポートを"新しい独立エッジ"で作るのは、このデータ範囲では不可**(v1＋A＋Cで実証)。これ以上の同種探索は
  期待逓減＋多重検定コスト増で**非推奨**。
- **並走を実現する確実な道＝B案: 実証済みエッジ(v7/v4/E5)を第2口座で運用し、設定で脱相関**:
  1. 円レッグを **v9(同日決済・swap防御)** に差し替え(v7と同エッジ・約定時刻/オーバーナイトが別)
  2. v4 の**ペアを2口座で分割**(口座1=メジャー前半／口座2=後半 等)で建玉重複を削減
  3. E5 は片方のみ、または legRisk を口座間で変える
  - エッジは確証済み=「同レベル検証」は自明に満たし、**取引重複を減らして口座分散(共倒れ確率↓)**を得る。
    相関は完全ゼロにはならないが、独立エッジが無い以上これが実利的な最善(プロップ複数口座運用の定石)。
- **あるいは現行(Portfolio3=v7+v4+E5)に集中**し、第2口座は作らない判断も合理的(docs/44-46の単口座運用)。
