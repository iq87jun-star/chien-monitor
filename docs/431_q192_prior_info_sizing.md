- 事前に決めた規則(到達率 +2 pt 以上)での「変更候補」は 宝くじのいま(下限 0.5)と トパーズ P2(下限 0.25)の 2 件。ほかの口座は到達率の差が 2 pt 未満のため規則上は「現行維持」だが、**失格だけが大きく下がる「参考」**に当たる(登録時に区別すると決めたとおり)。

1. **損失枠の残りに比例(下限 0.5)を、次の段階の EA から入れる**のが第一候補。対象はトパーズ・ルビー・パール・FTMO 50k の 2 口座・宝くじ。EA には余裕比例サイジング(`DynFactor`)の計算が既にあり、余裕が損失枠を下回る側にも同じ式を延ばすだけで実装できる(入力 1 個の追加)。
2. **宝くじは今から入れてよい**(規則上の変更候補・いま −2.65% で数量は約 0.7 倍から始まる)。
3. **FN 14074882 には今は入れない**(到達率が半減する)。
4. SKEW の段階化は行わない(現行の見送りのまま)。
