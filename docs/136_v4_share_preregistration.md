# 136.【事前登録】PDのv4配分は必要か — v4比率0%/15%/30%の同土俵比較

> ユーザー質問(2026-07-11)「v4は入れる必要はあるか。他の手法の割合に当てた方がよいのでは」。
> 事後の配分変更提案なので事前登録で決定規則を固定してから実行する。
> 実行: `research/portfolio_D_v4share.py` → `results/portfolio_D_v4share.json` → docs/137。

## 1. 既知の事実(実行前に記録)

- v4はDukascopy実データで **Sharpe 0.83 / net +151.8%(2016-2025)** = PDスリーブ中の最強格
  (docs/134 §1のユーザーColab実測)。Yahoo近似では控えめに出る(docs/76 §0)。
- v4↔v7 相関 **−0.10**(docs/76)= 唯一の負相関ペア。分散上は「削る」より「混ぜる」が有利な事前分布。
- ただし2024/8/5型の円急騰でv4は単日テールが太い(docs/87 §2)= v4を削ると**テールが軽くなる**仮説にも
  一理ある。→ 検定で決める。

## 2. 方法(固定)

- ベース = PD間引き版(docs/135採用: v7 2クロス/E5 2資産/v4 9ペア/E-Mon現行)。
- 変種(3つのみ): v4比率 x ∈ {30%(基準・現行), 15%, 0%}。残り3スリーブは比例再配分
  (係数 (1−x)/0.70 を v7 .25 / E-Mon .25 / E5 .20 に乗じる)。
- 各変種を median3_calibrate_compare の日次ブロックMC(2万パス・FN P1+8%・シード7)で
  **中央3ヶ月へ校正**し、失格%(楽観/悲観)・平均月利・最悪単日・月次Sharpeを比較。
- ⚠ Yahoo日次の土俵(相対比較が主眼)。v4がYahooで過小評価される既知バイアスは**v4に不利**に働くため、
  それでもv4=30%が勝つなら結論は頑健。逆に「v4削減が勝つ」場合はDukascopy再確認を必須とする(非対称ゲート)。

## 3. 決定規則(機械適用・固定)

- v4削減(15%または0%)の採用条件: **失格%(楽観・悲観とも)が基準(30%)より改善** かつ
  **平均月利が基準の90%以上**。両変種が合格なら失格%(楽観)の低い方。
- 上記を満たしても**即実装しない**: §2の注のとおりYahooはv4に不利なので、削減採用の場合は
  ユーザーColabでのDukascopy同構成比較を最終関門とする(docs/131 §4と同じ建付け)。
- 不合格 → **v4 30%維持**(docs/135のプリセットのまま)。
