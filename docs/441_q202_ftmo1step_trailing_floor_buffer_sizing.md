- 「損失枠比例・4.9 倍」は、現行と同じ速さで、失格をおよそ 3 分の 2(W1)〜半分強(W2)に減らす代わりに、1 年以内の到達が 2〜4 ポイント下がる。「損失枠比例・3.9 倍」は失格を 3 分の 1〜4 分の 1 にするが、到達が 6〜8 ポイント下がり、1 年たっても決着しない経路が W2 で 4 割残る。

## 5. 判定と提案
- **1-Step: 現行維持**(規則どおり)。Q201 §4 の「損失枠比例 + 4.9 倍は机上では現行を上回る」は取り下げる。
- 失格率を優先するなら「損失枠比例の縮小を入れて 4.9 倍」が選択肢(失格 7 / 22% → 5 / 13%・到達 86 / 61% → 84 / 57%・速さは同じ)。採用は「切替」事項で、EA9 への実装が要る。
- 1-Step の失格率は、今後は追随型 + 全停止線の数字(7% / 22%)で示す。月曜レグの口座モデル(Q187 以降)で 1-Step を扱うときは、失格線を追随型にする。
- docs/437・docs/440 の 1-Step の失格率には本稿への注記を付ける。
