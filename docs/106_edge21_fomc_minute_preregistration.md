# 106.【事前登録】edge21 — FOMC発表後ドリフトの分足検定(新解像度・確認的N=1)

> **位置づけ**: 残存新データ全消化の第2批次。**Dukascopy分足**は本プロジェクト未投入の
> 新解像度(docs/80 §4 が再開条件の例として明記した「ティックデータ」の実用形)。
> 対象は既存ADOPTのG3(FOMC**前**日足ドリフト)が触っていない**発表後の日中構造**。
> 発表日リストは docs/81 §5 の定例82回(2016-2026)を逐語流用=事後選別なし。
> 数字を見る前に本docを固定・コミット。

## 1. 凍結ルール

- **データ**: Dukascopy `USA500IDXUSD` 分足BIDキャンドル(発表日82日分のみ取得)。
  価格スケール1000・行形式 [秒offset, o, c, l, h, vol](フォーマット検証済)。
- **発表時刻**: 14:00 ET(米国夏時間規則=3月第2日曜〜11月第1日曜でUTC−4、他UTC−5に自動変換)。
- **仮説 H21a POST-DRIFT(N=1)**: 初動15分リターン r0 = close(14:14 ET) / close(13:59 ET) − 1。
  **r0>0 → LONG / r0<0 → SHORT** を 14:14 ETバー終値で建て、**15:44 ETバー終値で決済**(90分)。
  r0=0 または分足欠損の日はスキップ(記録)。
- **コスト**: 片道1.5bp(指数CFDスプレッド0.4pt+手数料相当)。ストレス2×。

## 2. 採点ゲート(確認的N=1)

- **G-dir**: net(基本コスト)> 0
- **G-p**: 符号反転順列(±|r_i|, 2000draw)p ≤ 0.05
- **G-placebo-time**: 同じ82日に**11:00 ETで同一エンジン**(11:14建て12:44決済)を当てると
  非有意(p>0.05)かつ合計が実測の半分未満 — 「FOMC時刻固有」であることの確認
- **G-split**: 2016-2020 と 2021-2026 の両方で net > 0
- **G-cost**: 2×コストで net > 0 / **G-dd**: イベント連結エクイティのmaxDD ≥ −20%(レバ1)
- **判定**: 全通過かつ p≤0.01=**STRONG-LEAD** / 全通過(p≤0.05)=**LEAD** /
  dir+p≤0.10=参考 / 他=**REJECT**。イベント数82は少ないため、STRONG-LEADでも
  EA化前に**デモでのイベント3回以上の前進確認**を必須とする。
