# 206.【事前登録】宝くじトラックの選抜指標 — 「期間成績トップ」以外で組んだらどうなるか

> 2026-09-03作成。費用ゼロ(docs/185 §5適合)。ユーザー問「宝くじの構成は現在のもので良いか。
> 別指標で組むとどうなるか」への実測。本docのルールは`research/selection_metric_walkforward.py`の
> 実行**前**に凍結した。実行後の変更禁止。枠組みは docs/186(ウォークフォワード)を継承する。

## 1. 動機

現行の直近フィット(B/C/D案・Instant・速攻プロ)は全て **`score = mean/std×√n`(選抜窓の活動日ベース)の
降順 Top-4** で組まれている(docs/174 §3)。これは「その窓で最も安定して稼いだセル」の順位であり、
**プロップ規則(日次−5%・静的−10%・目標+8/10%)とは無関係な指標**である。

docs/187 は「選抜すること自体」の価値を検証し、H0を棄却できなかった(BROAD_IV が全SELを支配)。
本docはその一段手前、**「選抜するなら何で選ぶか」**を問う。指標を変えても価値が出ないなら、
docs/187 の結論(選抜に価値なし)がさらに強まる。

## 2. 変えるもの・変えないもの(実行前固定)

**変えるのはスコア関数だけ。** 以下は全アームで docs/174 §3 と同一:
母集団34セル(TSMOM含む・docs/186と同一) / フィルタ(活動日≥15・12m累積>0・6m累積>0) /
銘柄1・族2制約 / Top-4 / 12m逆ボラ加重 cap40% / 倍率 `0.8×min(m*_sel, m*_12m)` cap6.0 /
月次入替・保有1ヶ月 / リバランス 2019-01-31〜2026-07-31 / 凍結窓 2016-01-01..2026-08-31。

## 3. アーム(スコア関数・実行前固定)

| アーム | スコア(選抜窓=直近12ヶ月・活動日ベース) | 何を選ぶか |
|---|---|---|
| `SEL12`(現行) | `mean/std×√n` | 安定して稼いだセル(ベースライン) |
| `RET` | 累積リターン | 単純に最も稼いだセル |
| `CALMAR` | 累積リターン ÷ \|月中最大DD\| | DDあたりの稼ぎ(静的−10%枠に対応) |
| `WORSTDAY` | 累積リターン ÷ \|最悪単日\| | 最悪日あたりの稼ぎ(日次−5%規則に対応) |
| **`LEVRET`** | 累積リターン × 校正倍率 `0.8×min(0.04/\|最悪日\|, 0.08/\|月中DD\|)`(cap 6) | **倍率規則を通した後に実際に得られるリターン**=プロップ規則に最も忠実 |
| `CONSIST` | 選抜窓のプラス月比率(同点は累積で) | 勝ち月の多さ(安定性) |
| `DIVERSE` | `SEL12`のスコアを、既に選んだセルとの最大相関で減点(λ=1.0)して逐次選抜 | 口座内の分散(docs/197の口座内版) |
| `BROAD_IV`(参考) | 選抜なし・全セル逆ボラ | docs/187の支配アーム |

- `LEVRET`の倍率は**閉形式の近似**(月中DDの倍率非線形性を無視)。順位付けの指標としてのみ用い、
  配備倍率は全アーム共通の厳密規則(`mult_at`)で別途計算する。
- λ・cap・閾値は現行値を継承し**最適化しない**。

## 4. 評価(docs/186 §5と同一)

OOS年率・ボラ・シャープ・最大DD・回転率 / **OOS系列へのMC**(FTMO 10/5・FN 8/5・暦地平365日で正規化) /
月次リターン差の対応ありt検定+ブロックブートストラップ95%CI(各アーム − SEL12)。

## 5. 判定(実行前固定・後知恵の禁止)

| 結果 | 判定 |
|---|---|
| あるアームが SEL12 を **OOS資金化率↑かつ失格率↓** の両方で上回り、月次差の95%CIが0を跨がない | **採用候補**。次回再スクリーニングから指標を差し替える提案 |
| 両方で上回るが有意でない | **記録**。docs/187 と同様「指標にコストを払う根拠なし」 |
| どれも上回らない | 現行維持。docs/187 の結論を強化 |

- 稼働中口座には適用しない。適用先は期限到来時の再スクリーニングのみ。
- 7アーム同時比較のため、有意判定は Bonferroni(α=0.05/6=0.0083)で読む。

# 7.【結果 2026-09-03】「期間成績トップ」は最悪の指標。DDあたりの稼ぎ(CALMAR)が最良 — ただしBonferroni僅差未達

> `research/results/selection_metric_walkforward.json`・シード7・月次入替 2019-01〜2026-07(91ヶ月)。
> **判定(§5): CALMAR は SEL12 を資金化↑・失格↓の両方で上回り、月次差の95%CIも0を跨がない
> (p=0.0135)。しかし Bonferroni α=0.0083 には届かない → 「両方で上回るが有意でない=記録」。**

## 7.2 読み

1. **「期間成績トップ(RET)」は6指標の中で最悪。** 年率11.8%・最大DD −29.8%・失格32.8%。
   最も稼いだセルは最もボラの高いセルであり、倍率規則がそれを1.91倍まで削るため、通過は遅く失格は多い。
   現行のSEL12(mean/std)は、RETよりは良いが**中位**である。
2. **プロップ規則に対応した指標(CALMAR・WORSTDAY・LEVRET)が上位3つを占める。**
   静的−10%枠と日次−5%規則が拘束条件である以上、「DDあたり・最悪日あたりの稼ぎ」で選ぶのは理にかなう。
   中でも **CALMAR は資金化 +13.5pt・失格 −12.1pt・年率 +8.2pt・最大DD改善** と全軸で SEL12 を上回り、
   選抜4セルでありながら資金化率は BROAD_IV(34セル)と同水準(76.6 vs 77.1)に達する。
3. **それでも失格率は BROAD_IV(13.6%)に届かない(19.8%)。** 4セルへの集中は、どの指標で選んでも
   分散の不足を埋められない。docs/187 の結論(幅>選抜)は、指標を変えても崩れない。
4. CALMAR の p=0.0135 は単独では有意だが、6比較の Bonferroni(0.0083)を通らない。
   §5 で事前に固定した通り**採用候補にはしない**。同じデータで閾値を緩めて採用するのは後知恵である。

## 7.3 帰結

- **現行の宝くじ構成(SEL12)は「良くない」。** ただし「もっと悪い指標(RET・CONSIST)」もある。
- **次回の再スクリーニング(C案9/30・非FX/Instant 10/31)で、SEL12 版と CALMAR 版を併記**して提示する
  (docs/187 §5 のブロード併記と同じ扱い・費用ゼロ・規則変更なし)。どちらを配備するかはユーザー決定。
- CALMAR を規則として採用するには、**別の土俵での確認**(docs/199 の口座別倍率ブックMC、または
  OOS延長)が必要。同一データで再検定しても確認にはならない。
- **稼働中口座には適用しない。**

## 7.4 「別指標で組む要素」の整理(ユーザー問への回答)

本docで測ったのは「セルの並べ方」だけである。選抜を変える要素は他に3層ある:

| 層 | 要素 | 本セッションでの証拠 |
|---|---|---|
| **指標**(本doc) | 目的関数をプロップ規則に合わせる(DD・最悪日・倍率通過後) | CALMAR が最良。RET は最悪 |
| **幅** | 選抜しない(BROAD) | docs/187: 失格率で常に最良 |
| **条件付け** | 外部状態で見送る(VIX_TERM) | docs/204: LEAD。失格 −7%・遅れ +0.5ヶ月 |
| **口座間** | 重複検知(docs/197 §9)・期限付き口座の別扱い(docs/200) | 重複時のみ効く |

**「何で選ぶか」より「何セル持つか」の方が効く**、というのが3つの実験に共通する結論である。
