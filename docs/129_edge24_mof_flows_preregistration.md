- 列(左から): 対外証券投資[居住者] 株式(取得/処分/ネット)・中長期債(同)・小計・短期債(同)・**合計ネット**、
  対内証券投資[非居住者] 株式(取得/処分/**ネット**)・中長期債(同)・小計・短期債(同)・合計ネット。
- **公表ラグの遵守(look-ahead排除)**: 対象週=日曜〜土曜S。公表=翌週木曜8:50 JST。

## 1. 仮説(3本固定・α=0.01/3=0.0033)

**機序の事前分布**: 居住者の対外証券投資(+)は円売りフロー。v7(円クロス月曜LONG=円ショート)の
機序候補「本邦勢の構造的な週初め円売り」をフローの実測値で直接検定する(L3)。
非居住者の対内株式フローは日本株の需給(L2)。事前分布: M1=中(v7機序の本命候補)・M2/M3=低中。

| ID | 仮説(1文) | ルール(逐語・固定) |
|---|---|---|
| M1 | **v7は居住者の対外投資が多い週に強い**(円売りフローの直接検証) | v7週次PnL(月曜d)を「dで利用可能な最新週の対外合計ネットが直近52レポート中央値**超**/以下」で分割。採用形=超の週のみ取引するフィルタ版 |
| M2 | **フロー継続**: 対外投資の4週合計が高水準なら翌週も円安が続く | 4週合計が直近52週の同4週合計中央値**超** → 翌有効週の月曜open USDJPY **LONG** 5営業日(翌月曜open決済)。以下 → SHORT。全週アクティブ・週次 |
| M3 | **対内株式フロー継続**: 非居住者の日本株買い越し4週合計が高水準なら翌週も日本株高 | M2と同ルールで JP225(^N225) LONG/SHORT |

- コスト: USDJPY往復2pip(週)・JP225往復3bps(週)。感応×2。
- 中央値分割・4週合計・52週窓は**本docで固定**(チューニング禁止)。

## 2. 決定規則(edge23と同一系・docs/127 §1-1準拠)

- M2/M3: G1 net>0(2016-01〜2026-06) / G2 順列p<α(符号シャッフル) / G3 年次JK 9/10+ /
  G4 ドリフト保存プラセボ(ポジション列シャッフル500回)p95超え / G5 コスト×2 / G6 IS(16-20)・OOS(21-26)両正 /
  G7 pre-2016(2006-01〜2015-12)同方向(参考・耐久級判定) / G8 既存エッジ月次|ρ|<0.4。
  **ADOPT候補 = G1-G6+G8 全通過**。
- M1: ①フィルタ版net > v7素通しnet(2016+) ②分割差の順列p<α の**両方**で採用。
  どちらか不成立 → v7は素通し維持(ただし分割の実測値は機序情報として docs/130 に記録)。
- 全滅の場合: **フロー宇宙(公的週次)も閉鎖**し、docs/128 §5 の消尽宣言に
  「+MOF週次フロー」を追記する。
