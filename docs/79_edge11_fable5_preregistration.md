## 3. 採点ゲート（edge6 と同一の6ゲート＋DD注記）

`research/edge11_fable5_batch_10y.py` に edge6/edge5 と同じ統計関数（perm_p 頑健版・JK・IS/OOS・プラセボ・コスト感応）を実装。

- **G_perm**: 月次集計符号順列 p ≤ 0.01（n=3000, seed=13）
- **G_jk**: 年次ジャックナイフ max p ≤ 0.10
- **G_oos**: 前半/後半 両方プラス
- **G_indep**: v7（円月曜・日足近似バスケット）との月次相関 |ρ| ≤ 0.4
- **G_plac**: 整合プラセボに勝ち、プラセボ自体は非有意
  - F1/F5（LONGドリフト系）= **同方向・同件数のランダム・カレンダー配置**（「銘柄の素のドリフトを拾っただけ」を棄却する。edge6 E2 の教訓）
  - F2 = ON比率を保ったランダム・レジームマスク
  - F3/F4 = 同機会・ランダム方向
- **G_cost**: 2-20bps 全水準で純益プラス
- 判定: **ADOPT** = G_perm/G_jk/G_oos/G_indep/G_plac 全通過 ／ **LEAD** = 純益>0 かつ頑健p≤0.10 ／ 他 **REJECT**
- maxDD < −10% は素サイズ不可の注記（プロップ枠 docs/40 規律）

## 5. 本バッチの新規性（なぜ「Fable 5 の新手法」と言えるか）

1. **新データ宇宙**: VIX 期間構造・米金利系列は本プロジェクト初投入（過去は価格系列のみで探索）。
2. **レジーム・キャリー型**: F2 は「方向予測」でも「カレンダー」でもない第3系統 ＝
   *条件付き保有*（リスクプレミアムの収穫）。買い持ちの**ON/OFF構造**なので売買頻度が極小で、
   edge10 で確定した「高頻度はコストで必敗」の制約を構造的に回避する。
3. **negative space の活用**: F3/F4 は docs/73 が名指しした白地をそのまま検定（思いつきではなく系譜の続き）。
4. **プラセボ設計の強化**: LONGドリフト系に「ランダム・カレンダー配置」帰無を導入（E2/E6 の偽陽性が
   再発しない設計）。
