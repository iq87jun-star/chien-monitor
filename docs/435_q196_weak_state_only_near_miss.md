## 6. 判定と含意
- **Q196 は成立 2 / 9**。`paper_forward.py` の CANDIDATES に MonWeakOnlySMA200(NZDJPY・US30)を追加(紙上フォワードのみ)。
- **配備の提案はしない**。足す形では口座モデルで改善しない(Q195 と同じ壁 = 日次の損失規則)。
- 知見(Q194〜Q196 の 3 本で一貫): 月曜の買いの利益は、円クロスと株価指数では「200 日線の下にいる銘柄」に集中する。金・暗号資産には当てはまらない。
- 使い道として残るのは「足す・増やす」ではなく「入れ替える」形。月曜に建てる通貨を固定せず、その週に 200 日線の下にいる通貨へ既存の数量を振り向ける(合計の数量は増やさない)。これは未登録・未検証。
