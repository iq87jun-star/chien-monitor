## 3. 読み方

1. p < 0.05 が 2 本で偶然期待 13 を大きく下回る。10 bps のコスト後では暗号資産の H1 窓も月次で正に偏らない。
2. 最良は BTCUSD 月曜 20-00 UTC LONG(IS 28/39・+12.7 bps・p=0.005)だが OOS −5.2 bps・前窓 0.47。ETHUSD 同窓は OOS +4.3・前窓 0.56 で全窓正だが p=0.027 で偶然水準。月曜 20-00 UTC = 米国株クローズ後の「週明けの上げ」で、IS(2023〜24 の上昇相場)の射影。
3. **週末効果(土日の窓)は無い。** 土日 72 セルの IS +月率中央値は平日と同水準。「週末の流動性低下・資金調達率」の物語は H1 の始値→始値では検出できない。
4. Q12(38 銘柄)・Q19(実測コスト)に続き、暗号資産でも時間帯格子は閉じる。docs/264 の Q20〜Q26 は 7 族すべて棄却。

## 4. 判定

**棄却**(基準どおり)。累積 **8,762** セル → 閾値 p < 5.71e-6。
