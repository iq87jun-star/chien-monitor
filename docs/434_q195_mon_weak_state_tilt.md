## 5. なぜ口座モデルでは伸びないか(登録外・参考)
損切り込みのショット単位(口座モデルの期間・Mon4 の 4 通貨)でも、弱い状態のほうが平均は高い。

| 弱い状態 | 弱い状態の平均 / 損切り率 | それ以外の平均 / 損切り率 |
|---|---|---|
| 20 日線の下 | +11.0 bps / 24.9% | +4.2 bps / 26.8% |
| 200 日線の下 | +13.9 bps / 21.9% | +4.4 bps / 27.5% |
| 前週下落 | +9.0 bps / 26.0% | +5.4 bps / 26.0% |

- 損切りは原因ではない。伸びないのは次の 2 点による。
  1. 2021〜2026 年は円安の上昇局面で、200 日線の下にいる建ては全体の 26% しかない。残りの 74% を 0.75 / 0.5 倍に減らすため、月曜 1 回の平均が下がる(FTMO 50k: 35.7 → 33.6 / 28.4 bps)。
  2. 弱い状態の月曜は値動きが大きく、1.5 倍にすると全決済ガードの発動が増える(FTMO 50k の発動: 8 → 13 回。1 回で約 −4.4%)。増えた利益をガードの損失が打ち消す。
- つまり素の系列では成立するが、日次の損失規則がある口座では数量を増やす側が使いにくい。

> 【2026-11-13 追記・docs/436 §4】§5 の「弱い状態の月曜はガードの発動が増える」は 2021-08〜2026-07 に限った傾向。2016-11〜2021-07 では、ルビー・トパーズ・パール・宝くじ・1-Step でそれ以外の月曜のほうが発動率が高い。

## 6. 判定と含意
- **Q195 は成立 2 / 6**。`paper_forward.py` の CANDIDATES に MonWeakSMA200A・MonWeakSMA200B を追加(紙上フォワードのみ)。
- **配備の提案はしない**。口座モデルで到達率が上がらないため。ルビー・パールの「20 日線 B」は改良系で不成立のため見送り。
- 得られた知見: 月曜の円クロスの利益は、直前に下げていた通貨に集中する(10 年・3 窓で一貫)。逆に、上げ続けた後の月曜は平均がほぼゼロ〜マイナス(前窓)。
- 未登録の派生案: 数量を増やさず、強い状態(200 日線の上)の通貨だけ減らす形。ガードの発動を増やさずに済むが、平均も下がる。口座モデルの B の結果から見て、到達率の改善は見込みにくい。
