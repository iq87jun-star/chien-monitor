> 規則(docs/220 §2〜4 の書面): フラット化から次のフラット化までを 1 グループとし、窓内の「確定損失 + 含み損」の合計が初期資金の 3% を超えた瞬間があれば警告(失格ではない)。フラット化でリセット。

## 1. 測り方(3 つの量・毎時)

| 量 | 定義 | 意味 |
|---|---|---|
| (a) グループ損益 | `equity(h) − 窓開始時の残高` = 含み(h) + 窓内に決済した net の合計 | Fintokei の判定量そのもの。毎時の分解能(時間内の極値は拾えない) |
| (b) SL 到達時の最悪 | 窓内の確定 net − Σ(建玉ごとの SL までの損失) | 時間内に全建玉が同時に SL へ達した場合の下限(ギャップ除く)。これが −3% の内側なら警告は原理的に出ない |
| (c) EA の警告線 | `equity(h) − サーバー日(UTC 21:00 区切り)開始時の残高` | `InpBalGuardPct`(トパーズ・ルビー 2.8 / パール 4.0)で全決済 + 当日停止 |

契約値は JPY クロス 100,000 円/lot/円、UK100p・USOILp は決済済み取引から推定(209 円/pt・157,761 円/ドル)。サーバー時刻は UTC+3(h4 ショットの 07:00 = 13:00 JST)。

## 3. EA の警告線との整合 — どこに隙間があるか

- 同日内では (a) = (c)(窓開始 = 日開始)。トパーズ・ルビーの −2.8% ガードは 3% 警告の内側にあり、**月曜に全ショットが同時に沈む形は EA が先に止める**(10/26 の SL 合計 2.84% でも、全 SL 到達前に equity が −2.8% に触れて全決済される)。
- 隙間 = **前日に確定した損**。(c) は日が変わると残高(確定済み)から測り直すが、(a) は窓が続く限り確定損を持ち越す。例: 月曜に FX ショットが SL で −2.5% 確定(ガード未満)→ 火曜に 24h 保有の指数 Mon が −0.6% 含み → (a) −3.1% で警告、(c) は −0.6% で未発動。
- 10/28 までのトパーズには旧 Hold が 1 か月窓を作っていたので構造上は隙間があったが、実損が小さく(最悪 −0.84%)発生しなかった。**10/29 以降の窓は ≤ 1.5 日**(Mon 24h・指数 Mon 24h)で、隙間が成立するのは「月曜 FX の確定損が −2.4% 以上(= 12〜16 本のほぼ全 SL)」かつ「火曜の指数 Mon が −0.6% 以上の含み損」の重なりだけ。過去 13 週(パール 8/3〜)で全 SL の月曜は 1 回(9/7・−1.32%)、ショット SL 合計が 2.4% を超えた月曜はトパーズ 10/26 の 1 回。
- ルビー(Mon のみ・24h)・パール(Mon 4 本・24h)は窓が 1 日なので (a) ≡ (c) に近く、隙間は無い。

## 4. 判定と提案

| 項目 | 判定 | 理由 |
|---|---|---|
| EA の警告線(`InpBalGuardPct` 2.8 / 4.0) | **変更しない** | 実損 (a) の最悪 −0.84%・警告相当 0 時間。同日内は EA が先に止める |
| グループガード(docs/176 §7.5.2: 窓内 確定+含み −2.5% で全決済) | **今は入れない(11 月改訂の候補に留める)** | 隙間は「前日確定損 −2.4% 以上 + 翌日含み損」の重なりに限られ、過去 2 か月で 0。入れるなら v+0.01(入力 `InpGroupGuardPct`・既定 0=無効)で、トパーズの指数 Mon が実際に建ち始めた後(11/9 以降)の (b) を見てから |
| ダイジェスト | **追加する(本コミット)** | `ops_ingest.py` の末尾で `q106 --snapshot` を呼び、Fintokei 3 口座の「グループ損益 / SL 到達時 / 警告 −3% までの距離 / EA 日次指標」を毎朝 1 行ずつ出す。SL 到達時が −3% を下回る日が出たら本書 §4 の候補を再評価 |
| 旧 Hold のような長期建玉 | 注意 | 窓が長くなる建玉(Hold)を Fintokei 口座に置く時は、その SL 幅だけで 3% を食う(今回 4.8%)。C6/Hold 系を Fintokei に置く設計(docs/276)では SL 幅を 3% 以内に収めること |

## 5. なぜ偽陽性でないと言えるか・限界

- (a) は口座の equity/balance そのものから計算しており、価格推定を含まない。欠けるのは毎時の間の極値だけで、それは (b) が上から抑える。
- (b) の契約値は決済済み取引の実損益から推定(UK100p 209 円/pt は 3.88 lot の +24,125 円 / +29.61pt と一致)。
- 期間は 5 週(ルビー・パールは実質 2〜3 週の建玉)で短い。結論は「構造(§3)」に依っており、頻度の推定(§3 の 1/13 週)は参考値。
- 累積セル 10,060(変更なし・閾値不変)。

## 6. 11 月の改訂への含意
