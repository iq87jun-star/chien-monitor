## 事前登録の固定パラメータ

- **候補数 N = 4**（下の E3〜E6）。**これ以上増やさない。**
- **多重比較補正**: Bonferroni。各候補の有意水準 **α = 0.05 / 4 = 0.0125**。
- **検定期間**: 2016-01 〜 2025-12 の**10年実データ**（Dukascopy H1 FX / 日足・多資産）。
  短期サンプルは "楽観側" として扱い、結論には使わない。
- **検定統計量**: 日次 R 系列の Sharpe。帰無は**月次ブロック符号シャッフル**（自己相関頑健、両側）。
- **採否ゲート（6つ全通過で ADOPT）**:
  1. 純益 > 0
  2. 順列 p < α(=0.0125)
  3. ジャックナイフ（1年抜き）最大 p ≤ 0.10
  4. プラセボ/対照で対象だけ突出
  5. 往復スプレッド＋スワップ計上後も純益 > 0
  6. v7 との10年相関が低/負（|corr| ≤ 0.30 を目安、負ならなお良し）
- **LEAD**: G2 未達だが p が 0.0125〜0.10 の "惜しい" 圏で G1・G3・G6 を満たすもの。
- **本資金即投入は禁止**。ADOPT が出ても -10% / -10%トレーリング枠に収まる縮小サイズで
  DD・合格率を実測し、デモ前進検証計画を出してから。
