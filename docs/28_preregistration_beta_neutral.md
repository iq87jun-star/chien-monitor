## 2. 事前登録パラメータ（★固定）
- **候補数 N = 3**（B1/B2/B3）。当たるまで増やさない。
- **有意水準 α = 0.05 / 3 = 0.0167**（順列p・残差alpha t の閾値に適用）。
- **検定期間 = 10年（2016-01..2025-12）**。短期は楽観側上限としてのみ併記。
- 全候補 **ドル中立 or スプレッド構成**で、**市場方向（ベータ）を設計で相殺**する。

## 3. 候補（すべてベータ非依存・全滅領域と非重複）

### B1 — コインテグレーション・スプレッド平均回帰（ペア・スタットアーブ）
- **事前仮説**: 経済的に近い通貨ペア同士はコインテグレートし、スプレッドは平均回帰する。
  FX単体のMR（docs/21 REJECT）とは別物＝**2本のスプレッド**で市場方向に非依存。
- **対象ペア（固定）**: (AUDUSD, NZDUSD) / (USDSEK, USDNOK) / (EURUSD, GBPUSD)。
- **ルール（固定）**: 各ペアで **過去250営業日**の OLS ヘッジ比 β を**ローリング推定（先読みなし）**、
  残差 z = (spread − μ)/σ（μ,σ も同じ窓）。**|z|>2 でスプレッド逆張りエントリ、z が 0 を跨ぐ or
  10営業日で決済**。建玉は β で量を合わせ**ドル/エクスポージャ中立**。
- **想定 v7 相関**: 低（スプレッドMR・別機構）。**コスト**: 2本分の往復を厳格計上。

### B2 — 横断バリュー（実質為替の長期回帰）・ドル中立ロングショート
- **事前仮説**: 実質実効ベースで割安な通貨は割高な通貨に対し長期で回帰する（バリュー・プレミアム）。
  キャリー（E3C）・モメンタムとは独立の機構。
- **対象**: G10 対USD（既存9ペア）。**バリュー指標（固定）**: 各通貨の対USD実質レート乖離を
  **名目スポットの5年移動平均からの乖離**で代理（CPIが無くても回帰の符号は保たれる近似。
  CPI入手可なら実質に置換可だが本登録は名目MA基準で固定）。
- **ルール（固定）**: 毎月末、乖離で順位付け。**割安上位3をロング・割高下位3をショート**、
  ドル中立、月次リバランス、保有1ヶ月。
- **想定 v7 相関**: 低〜負。

### B3 — 横断・短期リバーサル（共通ドル要因を除去した残差）・ドル中立
- **事前仮説**: 共通ドル要因を除いた**残差**の直近リターンは短期で反転する（過剰反応の修正）。
  時系列モメンタム（docs/22 REJECT）・単体MR（docs/21）とは別＝**横断残差の相対反転**。
- **対象**: G10 対USD。**ルール（固定）**: 毎週月曜、各通貨の先週リターンから**その週の横断平均
  （=共通ドル要因）を控除**した残差を計算。残差**下位3をロング・上位3をショート**（1週反転）、
  ドル中立、保有1週間。
- **想定 v7 相関**: 低。

> 除外（後出し防止の明記）: 受取スワップ依存のキャリー（broker依存で脆弱）、ML系（説明責任と
> 過剰適合）、イベント系（検出力不足）。

## 4. 判定ゲート（★強化版・全通過のみ ADOPT）
docs/26 の6ゲートに加え、(A) の検証を**必須化**:

| # | ゲート | 合格条件 |
|---|---|---|
| ① | 純益 | 10年コスト後 > 0 |
| ② | 順列p（月次ブロック符号シャッフル） | < α=0.0167 |
| ③ | ジャックナイフ（1年除外）最大p | ≤ 0.10 |
| ④ | **ベータ中立化** | 適切な市場/ファクターで回帰した**残差alphaの t > 2.5**（≒α0.0167両側）。ベータで説明され尽くさない |
| ⑤ | コスト生存 | 往復スプレッド計上後も①②生存 |
| ⑥ | v7独立性 | 10年相関 |ρ|≤0.30 |
| ⑦ | **Deflated Sharpe** | N_trials≥40 で **DSR ≥ 0.95** |
| ⑧ | **PBO** | CSCV の過剰適合確率 **≤ 0.20**（パラメータ変種で評価） |
| ⑨ | **器(II) DD** | 予算較正後の10年maxDDが −10%枠に収まるサイズが存在 |

**結論の正直さ**: 1つも通らなければ「ベータ非依存エッジも無し」と結論。誇張しない。
