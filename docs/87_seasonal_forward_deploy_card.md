## 2. 10年実績(素データ→倍率適用後・シミュレーション)

| | JUNE_TOP5(2.0x) | JULY_TOP2(1.3x) | AUG_V4ONLY(0.4x) |
|---|--:|--:|--:|
| 平均月利 | **+3.05%** | **+3.81%** | **+0.79%** |
| 勝ち年 | 8/10 | **10/10** | 7/10 |

| 上限倍率(ガード逆算) | 2.5x(日次−4%拘束) | 1.6x(フロア拘束) | **0.5x(日次拘束)** |

推奨倍率=上限×0.8(安全率)。**倍率は上げない**(7月版1.6xは最悪DD−9.2%でフロア踏み抜き)。
**8月の上限が1倍未満である理由**: **2024/8/5の円急騰ショック**でv4のFXレッグが同日複数SLを踏み、
素サイズの最悪単日が**−8.88%**と日次ガード−4%を大きく超えるため(逆算0.5x×安全率0.8=0.4x)。
v4単独はDDこそ最浅(−1.7%)だが、集中ゆえ単日テールが太い=倍率で盛らずに受け入れる。
参考: 分散版(top4: v4 66/E-Mon横 19/E-Mon 8/E5 7, 0.6x)は平均月利+0.94%とガード調整後で単独版を
上回っていた(分散の価値)。単独版はユーザー指定による。

## 3. 手順

1. MetaEditorでコンパイル → デモ口座の任意チャート(例: US500)に1枚ずつ挿す
   (口座A: `InpScenario=SCN_JUNE_TOP5` / 口座B: `SCN_JULY_TOP2`。同一口座ならMagic重複なしで共存可)
2. 銘柄名が業者と違う場合のみ Inp*** の銘柄リストを修正(自動解決が先に試行される)
3. 初日に確認: ①全レッグの約定ログ ②ノーショナル(建玉額≈equity×weight×mult) ③スプレッドスキップの頻度
4. ガード: 日次−4%(当日停止)/フロア−8%(恒久停止)— 発動したらいじらず原因確認
5. 月末: 月ゲートが自動で全決済 → 月利を記録し、本カードの想定(平均±σ)と比較

## 4. 規律(誠実な位置づけ)

- 月別配分は**10年の記述統計(in-sample重み)**であり検証級ではない。各レッグの級は docs/86 §4 の通り。
- フォワードの目的=「実測月利が想定分布内か」の確認。**1ヶ月の結果で配分の良し悪しは判定できない**。
- 横展開レッグ(4クロス/3指数)はEA初実装・実績ゼロ。デモ必須の主因。
- 本資金投入はこのEAでは行わない(本資金はdocs/78の確定プラン=PortfolioD_Prop3/FTMO3のみ)。
