# 52. ポートフォリオ比較 — 既存A(v7+v4+E5) vs 並行B(E-Mon+E5) vs 両方並走(A+B)

> 方法: 4成分(v7/v4/E5/E-Mon)の月次リターンを実データ(Yahoo日足10年・研究用)で再構築し、リスク加重で合成して比較。
> ⚠ 規律: 数字は盛らない。Yahoo日足は配当除く近似・v4は日足SL/TP簡易再現＝Dukascopy確定値とは差。最終はDrive+デモ。

## 0. 一行結論

> **並行ポートB(E-Mon+E5)は"単体の収益効率"では既存A(v7+v4+E5)に劣る**(Bはv4=ADOPTを欠くため)。
> **だがA⇄B相関は0.28(純コアは0.12)と低く、A+B並走はSharpe最良(1.35→1.41)・同時マイナス月15%**
> (複製なら100%共倒れ)。**∴ 並行ポートの価値は『高収益』ではなく『分散・別業者での全損回避(頑健性)』。**
> 収益最優先なら A単体。**口座総量を増やしつつ"共倒れ"を避けたいなら A+B 並走**(別口座/別業者)が正解。

## 3. ポートフォリオ比較(リスク加重・共通目標DD−6%に揃えた年率)

| 構成 | Sharpe | Calmar | 年率@−6% | 同時マイナス月 |
|---|--:|--:|--:|--:|
| **A 既存(v7:v4:E5 = 40:40:20)** | 1.35 | **1.53** | **9.2%** | — |
| **B 並行(E-Mon:E5 = 65:35)** | 0.94 | 0.45 | 2.7% | — |
| **A+B 並走(等資本・2口座)** | **1.41** | 1.12 | 6.7% | **15%** |
| (参考)A を 2口座に複製 | 1.35 | 1.54 | 9.2% | 100%(常に共倒れ) |

**3つの軸で読み分ける(誠実に)**:
1. **収益効率(年率@−6%)**: **A単体(9.2%)** > A+B(6.7%) > B単体(2.7%)。
   → **Bが単体でAに劣るのは v4(ADOPT・Calmar0.85)を欠くから**。Bは2レッグ(E-Mon+E5)で、Aの3レッグより分散が浅い。
2. **リスク調整後(Sharpe)**: **A+B(1.41)** > A単体(1.35) > B単体(0.94)。
   → **並走でSharpeが最良**。A⇄B=0.28の分散効果で、合成の効率がA単体すら僅かに上回る。
3. **全損回避(同時マイナス月)**: 並走A+B = **15%**(独立仮定11%) vs **複製 = 100%(常に共倒れ)**。
   → これが**並行の本質的価値**。同じ資金を「同一ポートの2口座複製」に置くと相関1で共倒れ、片や
   **相関0.28のA+Bなら、片方が沈む月でも他方が支える**。別業者に分ければ業者破綻リスクも分離。

## 4. なぜ「複製」でなく「並行(B)」なのか

| 観点 | A を2口座に複製 | A + B 並走(並行) |
|---|---|---|
| 収益効率(Calmar) | 1.54(高い) | 1.12(中・Bが薄める) |
| Sharpe | 1.35 | **1.41(最良)** |
| 口座間相関 | **1.0(完全共倒れ)** | **0.28(低)** |
| 業者破綻/規約変更 | 同一戦略→両方同時に被弾 | 別業者なら片方生存 |
| エッジ劣化耐性 | 円月曜が死ねば両方死ぬ | 円月曜が死んでも株指月曜(E-Mon)が別機序で生存可 |

→ **「総量を増やす」だけなら複製で収益効率は高い。だが"全部いっぺんに飛ぶ"リスクを負う。**
**「総量を増やしつつ全損確率を下げる」なら A+B 並走**——これがユーザーの当初要望(別口座・同レベル検証・無相関)の狙いそのもの。

## 5. 推奨(誠実な使い分け)

- **収益だけを最大化したい / 口座は1つ**: → **既存A(v7+v4+E5)単体**が最良(年率@−6%=9.2%)。並行は不要。
- **口座/資金を増やしたい・かつ"共倒れ"を避けたい(別業者でリスク分散したい)**: → **A + B 並走**。
  Sharpeは寧ろ向上(1.41)、同時マイナス月15%(複製100%)。B は別口座/別業者(FTMO等)で。
- **B を少しでもA並みに引き上げたい**: B に v4 を足す手はあるが、v4 は A と共有ゆえ A⇄B 相関が上がり
  "並行"の意味が薄れる(トレードオフ)。**Bは"無相関の第2エッジ E-Mon を核に据える"こと自体に価値**がある
  と割り切るのが筋(収益はAに任せ、Bは分散・頑健性担当)。

## 6. 限界(盛らない)

- すべて**Yahoo日足10年の再構築・概算**(配当除く指数・v4は日足OHLCでSL/TP簡易再現)。**絶対値はDriveで要確定**
  (`notebooks/parallel_emon.ipynb` + 既存 `firms_2v3_compare.ipynb`)。本書の価値は**相対比較と構造**にある。
- 「リスク加重40:40:20 / 65:35」は各レッグを等ボラ標準化して比率を掛けた近似。厳密な配分は足内エンジン+デモで。
- E5 は A と B で**共有**。A⇄B=0.28 はその共有分だけ上振れしており、**純コア(v7+v4 ⇄ E-Mon)は0.12**＝
  本質的な分散はさらに高い。並走時に E5 を片側だけにすれば相関はさらに下がる(運用で選択可)。
