# 98. フォワード検証ログ — 実運用の月次成績 vs バックテスト分布

> 目的: ライブ口座の**実測月次成績**を記録し、バックテストの同月分布の何パーセンタイルかを採点する。
> これがプロジェクトで最も価値あるデータ(実測がモデル分布内か=エッジの生存確認)。
> ⚠ 手決済・部分決済を含む場合は「manual-adjusted(EA純粋でない)」と明記する。

## 0. 記録方法(MT5)

1. MT5「履歴」タブ → 期間を当月1日〜末日に指定 → 上部の**「損益」合計**を読む
2. 口座サイズ・倍率・手決済の有無を併記
3. 下表に転記 → バックテスト分布列と比較
4. **スワップ実測**(2026-07〜): EAが `MQL5/Files/ChienSwapLog_<口座>.csv` に自動記録(docs/100 §4)。
   月初にMONTHLY行のスリーブ別 swap 合計を下表「スワップ$」として併記(E5/S-Julの持越しコスト監視)。
   採点の自動化は `research/forward_scoring_mt5.py`(docs/103)。

## 3. 判定基準(記入後)

- 実測が **25〜75%レンジ内** → ✅ エッジ生存(モデル通り)
- 実測が **最小未満** → ⚠ 要注意(2ヶ月連続なら倍率ダウン検討)
- 実測が **最大超** → ⚪ 上振れ(出来すぎ・次月の平均回帰に注意)
- ⚠ 手決済が混じる月は「参考」扱い。EA純粋の生存確認には自動決済month が必要

> 規律: 単月で一喜一憂しない。フォワードは最低6ヶ月積んで「分布内に収まり続けるか」で判断(docs/40)。
