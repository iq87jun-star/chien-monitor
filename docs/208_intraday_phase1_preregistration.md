# 208.【事前登録】日中 Phase 1 — 円クロス月曜レッグの「4/6/8/10 UTC・24h」は H1 で支持されるか

> 2026-09-03作成。費用ゼロ。docs/195 §4 の Phase 1(「既存の型の解像度を上げるだけ・新しい型は作らない」)。
> データは Yahoo H1(約2年)であり、docs/37/48 の前例どおり **LEAD級スクリーニング**。10年追認(Dukascopy H1)なしに
> 配備仕様を変更しない。本docのルールは`research/intraday_phase1.py`の実行**前**に凍結した。

## 1. 問い

稼働5口座が共有する円クロス月曜レッグは、EA では **4/6/8/10 UTC の4ショット・24h保有**で建てている
(docs/09系パリティ・研究は日足 o2o 近似)。この時刻窓と保有時間は、直近2年の H1 実データで
**(a) 月曜に固有か(火〜金プラセボ)、(b) 他の時刻窓・保有時間より劣っていないか**。

## 2. データ(実行前固定)

- Yahoo H1・凍結窓 **2024-09-01..2026-08-31**(取得上限≈730日)。円クロス7本(GBPJPY/AUDJPY/USDJPY/EURJPY/NZDJPY/CADJPY/CHFJPY)。
- 指数は Yahoo H1 が現物時間のみで 4 UTC 建てを再現できないため**対象外**(限界として記録)。
- コスト: 2pip 往復(docs/174 と同一)を各ショットに計上。

## 3. 候補(N=8・実行前固定)

4ショット窓 × 保有時間。**B が配備仕様。**

| 窓 | エントリ時刻(UTC) | 保有 |
|---|---|---|
| A 早朝 | 0/2/4/6 | 12h・24h |
| **B 配備** | **4/6/8/10** | **12h(=v9)・24h(=v7)** |
| C 欧州 | 8/10/12/14 | 12h・24h |
| D 米国 | 12/14/16/18 | 12h・24h |

- 各候補のリターン = 7銘柄等加重・4ショット平均の月曜1回分。約100回の月曜。
- Bonferroni: α = 0.05/8 = **0.00625**。
- **プラセボ**: 同じ窓・同じ保有を火〜金に適用(曜日プラセボ・docs/40 と同型)。月曜だけが有意で他が非有意なら「月曜固有」。

## 4. 判定(実行前固定)

| 結果 | 判定 |
|---|---|
| B が月曜で有意(p<0.00625)かつ火〜金で非有意、かつ他窓に有意に劣らない | **配備仕様を H1 で支持**(LEAD級確認)。変更なし |
| 別の窓が B を有意に上回る | **LEAD として記録**。配備変更は Dukascopy H1 10年での追認後(docs/195 §4 Phase 1 完了条件) |
| B が月曜で非有意 | 直近2年で月曜エッジが弱まっている可能性を記録。docs/179 の月次採点で監視 |

- 稼働中口座は変更しない。
- 付随して、各時刻の **H1 レンジ(高値−安値)の中央値**を執行コストの代理指標として記録する(B-2 のスプレッド実測が来るまでの仮置き)。
