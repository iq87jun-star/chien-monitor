## 2. 読み方
1. 指数 Mon(月曜 o2o・NAS100 / US500)は円クロスの Mon4 と相関が低く、足すほど到達率が上がり失格が下がる(各 2.0 で 89 / 9%)。帳簿の中で最も「効く」追加。
2. ただし各 2.0 は指数に額面の 4 倍 + FX 8 倍 = グロス 12 倍。Fintokei の指数レバレッジ(要確認・1:20 前後)だと証拠金が額面の 4〜5 割。**各 1.0(グロス 10 倍・証拠金 3 割台)を候補**にする。
3. **指数 Mon は Q92(6 本の継続判定・docs/276 停止規則)が未実施。** 10.6 年では強いが、docs/322 で「外す/残す」を判定する予定の系列なので、Q92 を先に通してから採用する。
4. 指数 Mon の建て時刻は EA の Mon 機構(Instant G v1.16 と同型・月曜の日足 o2o)で既に動く。EA11 の `InpMonLegs` に `NAS100:x,US500:x` を足すだけ(Fintokei の銘柄名は要確認・接尾辞 p)。

## 3. 提案
- 11/1 改正案のトパーズ候補: **Mon4 ×8 + 指数 Mon 各 1.0**(Roll・Hold は外す)。Q92 が「残す」なら採用、「外す」なら Mon4 ×8 のみ。
- 10/17 の切替は現行案(EA11 v1.14 ×6・Roll ×3・非FX ×1.5・ETH なし)のまま。docs/349 §8e の「Mon4 ×8 のみ」を選ぶなら「切替」で指定。
