## 3. 読み方
1. 集中の効果は「失格の本数が両極に寄る」こと。期待値は変わらないが、**全部無事(29%)と 5 本以上失う(12%)の両方が独立の場合の 2〜5 倍**。Mon4 への集中を強める §8e の案は、この形をさらに尖らせる。
2. 合算の最悪日 −3.3% は 1 口座の床(10%)の 1/3。1 日で全滅はしないが、悪い月曜が 3 回続く月(最悪月 −953 万円 = −7.2%)は宝くじ・14074882・Instant の 3 本を同時に失う。
3. 対策は「分散」ではなく「許容」の問題: 同時失格 5 本以上(12%)を許容できるなら §8e をそのまま、できないなら高倍率の口座(宝くじ ×10・トパーズ ×8)を 1 段下げる(トパーズ ×6 で失格 33 → 15% の効果は docs/349 §8e)。
4. MFFU(指数・日中)は円クロスの月曜と相関が低く、唯一の分散源。
