## 0. 一行結論（どれを使う？）

> - **既存口座の主力 = `Chien_Portfolio3_AllInOne_PROP/INSTANT`**(v7+v4+E5)。3戦略・1チャート・相互低相関。
> - **並行口座(新) = `Chien_Parallel_AllInOne_PROP/INSTANT`**(E-Mon+E5)。既存と相関0.28＝別口座/別業者で並走(docs/52)。
> - **スワップ不利業者・低DD志向 = `FundedNext_Stellar_EA_v9`**(円月曜を12h intradayで・DDほぼ半減)。
> - **v1/v2/v3/v4(file)/v5/v6 = 参照・棄却・置換済み**(本資金に載せない)。下表の「採否」を厳守。

## 1. ★最重要の注意 — 「v4」の二義性

| 名前 | 実体 | 検証級 | 在処 |
|---|---|---|---|
| **v4(file) `FundedNext_Stellar_EA_v4.mq5`** | **H4 順張り(モメンタム継続)** | **検証段階**(IS負・レジーム罠未排除) | 単体ファイル |
| **v4(portfolioレッグ) = "D1 k≥4 合議"** | **D1 4条件 k≥4 の平均回帰** | **ADOPT(実Dukascopy 6/6, docs/42)** | `Portfolio3` 内部レッグのみ(専用単体なし) |

→ **ADOPTの「v4」は Portfolio3 の中だけに在る**。単体 `_v4.mq5`(H4モメンタム)は**別物で未採用**。
混同して `_v4.mq5` を本番に載せないこと(v4の真価=k≥4合議は Portfolio3 で稼働する)。

## 6. 使い分け早見

| 目的 | 使うEA |
|---|---|
| 既存口座で収益効率最大(1口座) | `Chien_Portfolio3_AllInOne_*`(v7+v4+E5) |
| 口座/業者を増やし"共倒れ"回避(分散) | + `Chien_Parallel_AllInOne_*`(E-Mon+E5)を別口座/別業者で並走(docs/52) |
| スワップ不利・低DD志向で円月曜だけ | `_v9`(intraday 12h) |
| v7を業者別サイズで単体運用 | `_v8_dualfirm` |
| E5/v7を個別チャートで微調整 | `Chien_E5_RP_Trend_EA` / `_v7` |
| 学習・ガード実装の参照 | `_v1`(ガード階層が最も詳しい) |
| 載せてはいけない | `_v1/_v2/_v3/_v4(file)/_v5/_v6`(本番) |
