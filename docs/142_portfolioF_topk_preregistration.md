> できますか」。事後選別の器なので docs/131 と同じ厳格ゲート(LOYO+ブラインドプラセボ+安定性)を課し、

> 実行: `research/portfolio_F_topk.py` → `results/portfolio_F_topk.json` → docs/143。

## 1. レッグ・プール(19本・固定)

- v7: EURJPY/GBPJPY/USDJPY(3)、v7横: AUDJPY/NZDJPY/CADJPY/CHFJPY(4)
- E-Mon: NAS100/US500/GER40(3)、E-Mon横: JP225/UK100/FR40(3)
- E5: XAUUSD/US500/NAS100/GER40(4)、G3 US500(1)、**v4はバスケット1本として参加**
  (ペア単位のYahoo成績は歪みが実証済み=docs/138。ペア単位選別はしない)
- **除外**: S-Jul通年(=素の買い持ち。エッジではなく市場ベータであり、入れると「レバレッジ付き
  NAS100買い持ち」に退化する。ベータの言い換え排除はF2以来の恒久規律)

## 2. 方法(固定)

1. **LOYO選別**: 各年y(2016-2025)について、y以外の9年の月次Sharpe上位**K=6**本を選び等ノーショナル
   合成 → 除外年yのOOSを記録 → 10年連結。感応(記録のみ・昇格不可): K=4, 8。
2. **ブラインドプラセボ**: 無作為な固定6本サブセット400通り(シード123)の全期間Sharpe分布。
3. **安定性**: 全期間選別セットとの平均一致本数(10フォールド)。
4. **チャレンジ比較**: LOYO選別を凍結した「全期間版セット」で日次合成し、median3機械(2万パス・
   シード7)で中央3ヶ月へ校正 → PD間引き版(docs/135: 19.6/26.7%)と失格%を比較。

## 3. 決定規則(機械適用・固定)

採用候補 = 以下**全て**成立:
- **F1**: LOYO-OOS Sharpe > プラセボp80
- **F2**: 安定性 平均一致 ≥ 5/6本
- **F3**: 中央3ヶ月で失格%(楽観・悲観とも) < PD間引き版
- **F4**: 既存3器(季節/PD間引き/PE v2)との月次|ρ|を記録し、最大|ρ| > 0.8 なら
  「既存の複製」として採用しない

合格しても**即実装しない**: v4/v7系を含むため docs/138 恒久規則により **Dukascopy確認 → デモ**が最終関門。

## 4. 事前の期待(盛らない)

- 上位レッグはE-Mon系+E5 XAUに集中する見込み=**E-Mon/季節EAとの重複が最大の懸念**(F4)。
- v7横(AUDJPY/NZDJPY)はYahooが甘く出る銘柄群で、edge18の実H1検定では「薄い写し」確定済み。
  LOYOで選ばれてもDukascopyで剥落する公算が高い(逆転4例目の候補)。
- 最尤シナリオ: F1-F2は通るがF3(PD間引き超え)またはF4(重複)で不合格、あるいはDukascopyで剥落。
  それでも「抜粋ポートフォリオはこの手順で作る」という型を残す価値がある。
