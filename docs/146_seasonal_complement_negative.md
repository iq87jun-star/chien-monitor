# 146.【記録・見送り】季節補集合ポートフォリオ — LOYOで質が2/3消滅・PE v2の下位互換

> ユーザー発案(2026-07-11)「月別で季節採用以外を用いて、(季節と)相関性が低くなるものを
> 作成できないか」。構造検討+LOYO確認の記録(事前登録前のスクリーニング段階で結論が出たため
> 本docは記録のみ・ハーネスは対話セッション内で実行)。

## 1. 構造的な壁

季節R4は毎月「訓練平均月利≥0.5%のスリーブを**全部**」採用する規則(docs/105)。
∴ 各月の「不採用側」= μ<0.5%の残り物。補集合ポートフォリオ(各月、R4不採用かつμ>0のスリーブ等重み)を
組むと:

| 版 | 平均月利 | Sharpe |
|---|--:|--:|
| 全期間(in-sample) | +0.22% | 0.69 |
| **LOYO(その年を知らずに選ぶ)** | **+0.10%** | **0.23** |

**見かけの質の2/3がin-sample選択の産物**。LOYO後のSharpe 0.23は運用に値しない
(同じ枠のPE v2は0.87・26年構造・デモ準備済み)。

## 2. 相関の観点でも既存3器で充足(月次ρ・2016-2025)

| | 季節 | PD間引き | PE v2 |
|---|--:|--:|--:|
| 季節R4+G3 | 1 | 0.39 | **0.12** |
| PD間引き | | 1 | 0.42 |
| PE v2 | | | 1 |

「季節と低相関の相棒」はPE v2(ρ=0.12)が既に担っており、補集合(ρ=0.15)は
相関でほぼ同等・質(LOYO 0.23 vs 0.87)で大きく劣後=**下位互換**。

## 3. 決定

見送り。月別ローテで季節と低相関の器は「作れるが作る価値がない」— 低相関は
カレンダーの補集合からではなく**機序の違い**(E5=長期TSMOM)から取る方が質が落ちない、
という設計原理を再確認した(docs/143/145の「分散>選別」と同根)。
