## 1. 問いと答え

**問い**: ロジックが分かれば、以前からのプロップ規則の枠(2段階・日次5%・最大10%)にはめて
「使用可能か」を、自EAと同じ水準で検証できるか。

**答え**: 検証可能。ただし「ロジックがどこまで分かるか」で3段階に分かれる:

| Tier | 前提 | できる検証 | 水準 |
|---|---|---|---|
| **A** | ロジック完全開示(ソース/規則書) | 自前再実装 → 10年BT → LOYO → コスト感度 → 規則MC → 事前登録 | **自EAと完全同水準** |
| **B** | 取引履歴のみ(Darwinex/GGJ CSV) | docs/176 逆解析で型仮説 → 自前実装 → 履歴と挙動照合(再現できたらAへ昇格) | 仮説検証。再現不能なら断念 |
| **C** | 統計プロファイルのみ(μ/σ) | 統計過程近似で規則適合性MC(通過率・失格率・期待出金) | 一次判定。**今すぐ実行可能 → 実行した** |

## 2. Tier C 実行結果(FN 2-step型・20,000パス・テール保守化込み)

| 戦略 | 倍率 | 通過率 | 資金化後12Mで口座喪失 | 無条件EV/12M |
|---|---|---|---|---|
| ELW | 1.0x | 33.8%(期限切れ49%) | 14.5% | ¥106万 |
| **ELW** | **1.5x** | **46.6%** | **58.4%** | **¥159万(最良)** |
| ELW | 2.0x | 47.1% | 88.9% | ¥136万 |
| ELW | 3.0x | 33.5%(日次失格47%) | 100% | ¥42万 |
| PKR | 1.5x | 37.0% | 65.4% | ¥105万(最良) |
| **自EA(参考)** | — | **~93%** | **0.9%/年** | **¥186万** |

## 3. 読み(本書の核心)

1. **「良い戦略」と「プロップ規則に合う戦略」は別物である。** ELW は本物の優位
   (SR1.14・4年)を持つが、規則にはめると最良設定でも通過46%・1年以内喪失58%。
   プロップ規則は「そこそこの速度で+8%に到達し、かつDDがほぼ出ない」という
   **特殊な形状**を要求しており、汎用の優良戦略はこの形状を持たない。
2. **自EAの優位は「リターンの優位」以上に「形状の優位」。** 通過93%・年失格0.9%は、
   ガード(-4%日次停止/-8%フロア)と低DD設計でプロップ規則に**合わせて作った**結果。
   EV でも自EA(¥186万)は ELW 最良(¥159万)を上回る。
3. **倍率カーブの形も自EAの研究(PD倍率)と同型**: 1.5x が EV 最大、2x 以上は失格が
   食い潰す。外部戦略にも「規則が許す最適レバレッジ」が存在し、それでも足りない。
4. よって外部戦略の現実的価値は(docs/184 の結論を強化して):
   **プロップ口座に載せる価値: 現状なし** / 実弾口座での分散部品: 相関次第 /
   勝ち型の観察による仮説生成: あり。

## 4. Tier B/A に進む場合の手順(必要になったら)

1. 対象の取引履歴CSVを取得(Darwinex口座/GGJページ)
2. docs/176 逆解析: 保有時間・時刻規則性・勝率×RR・銘柄 → 型仮説(例: OXTIは
   平均5h保有・勝率41% → 短期モメンタム系と推定できる)
3. 仮説を自前実装し、同期間の実価格でBT → 履歴とリターン相関・エントリ一致率で照合
4. 再現度が高ければ Tier A パイプライン(事前登録→LOYO→規則MC)に載せ、
   自EAポートフォリオへの追加是非を相関込みで判定(docs/165 の多重検定割引を適用)

## 5. 限界

- Tier C は正規+テール近似(歪度・自己相関なし)、日次損失は終値評価。
  実際の失格率はこれより悪い方向に外れうる(= 結論は保守側に頑健)。
- Darwinex のVaR標準化はDarwinex口座上の姿。プロップ口座への移植コストは未考慮。
