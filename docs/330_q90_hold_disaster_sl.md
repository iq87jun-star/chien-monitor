## 1. 問い・構成
EA の Hold レッグは連続 LONG に **建値 −15% の固定 SL**(`InpHoldCatSLPct=15`・追随しない・ヒット後はフラット → 次の機会に再建て)を保険として付けている(研究系列 `hold_cell` は SL なし)。この水準を {10%, 20%, なし} に変えると改良系基準(IS・OOS 両方で Sharpe 改善 かつ 最悪月が悪化しない)で現行 15% を上回るか。
- 日足(Hold 6 と同じ Yahoo・凍結窓 2016-01〜2026-07)。SL は安値で判定、約定は SL 価格(始値が SL を割る日は始値)、再建ては翌日始値(EA はガード当日は建てない)に往復 5 bps。建値は前窓・IS・OOS の各初日に置き直す(= 窓開始に配備した EA。SL は建値固定)。SL なしは `hold_cell` と一致することを自己検証。
- セル = 銘柄 6(US500 / NAS100 / GER40 / JP225 / XAUUSD / BTCUSD)。水準 3 本は同一セル内の比較。累積 9,625 → **9,631**。
- 最初の実装は建値を 2016 年初日に固定していたため SL が常に遠く「水準を変えても同じ」になった。窓初日に建て直す形に直して再実行(本書の数値はその結果)。

## 3. 読み
- **指数と金では 15% 固定 SL の有無で結果がほとんど変わらない**。10 年でヒット 0〜3 回。ヒットは 2020-03(COVID)・2022(NAS100・GER40 の弱気相場)・2025-04(US500・JP225 の関税ショック)で、ヒット後に翌日始値で再建てするため、V 字回復の局面(2020・2025)では SL が損を確定させる(US500 の OOS Sharpe 0.68 vs なし 0.87)。逆に 2022 のようにだらだら下げる局面では SL が利く(NAS100 の 5 年累積 76.5 vs なし 64.3)。両方の窓で同時に改善する水準はない。
- 10% に締めるとヒットが倍増し、指数では IS が悪化。20% に緩めると 2022 の保護が薄れ NAS100 の OOS が落ちる。
- BTCUSD 10% は IS・OOS とも Sharpe +0.01〜0.02・最悪月 +0.8〜1.2 pt の改善で基準は満たすが、差は誤差の範囲。BTC の Hold 自体が OOS で負(−0.2)で、現在配備している EA に BTC の Hold はない(14166201 の BTCUSD は v4 レッグ)。
- 配備中の Hold 銘柄(UK100 / WTI / XAU)のうち本項で見たのは XAU のみ(ヒット 0 = 設定の影響なし)。UK100・WTI は Q89 と同じ理由で Hold 6 の外にあり、本項の事前登録外。
