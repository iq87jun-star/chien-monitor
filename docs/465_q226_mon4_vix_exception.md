## 1. 方法(事前固定)

- 判定 = 基準に対して、前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しない。

## 3. 診断: VIX が高い週明けの強さは、どの通貨に出ているか(V25・通貨 × 月曜のプール・1 倍あたり)
| 通貨の状態 | 期間 | VIX > 25 の週明け(回数) | それ以外(回数) | 差 |
|---|---|---|---|---|
| 200 日線の下 | 前窓 | +23.5 bps(101) | +3.0 bps(548) | +20.5 |
| | 探索 | +26.0(22) | +17.9(148) | +8.1 |
| | OOS | +35.0(10) | +10.8(86) | +24.2 |

| | 探索 | +12.2(94) | +4.8(412) | +7.4 |
| | OOS | **−3.6**(18) | +2.5(230) | **−6.1** |

- **荒れた後の強さは、線より下にいる通貨で大きく、3 つの期間でそろっている**(+8〜+24 bps)。ここは配備中の形ですでに 1.0 倍で建てている部分。
- **線より上の通貨では、前窓と探索はプラスだが OOS で逆向き**(回数 18)。例外で 1.0 倍に戻す対象はこちらなので、OOS が下がった。
- 区切りを変えても同じ形(V30 の OOS: 線の下 +57 bps・線の上 −28 bps。回数は 7 と 5)。
- VIX が高い週のうち、通貨が線の下にいた割合は前窓 68%・探索 19%・OOS 36%。前窓では 200 日線と重なりが大きく、探索では重なりが小さい。

## 4. 判定と含意
- **棄却 0 / 4**(正常な結果)。配備中の形を変えない。紙上フォワードにも入れない。
- 「荒れた後の週明けは強い」は本物に見えるが、強さが出るのは『下げていて、かつ荒れた後』の通貨で、そこはもう通常の数量で建てている。「減らすだけ」の枠の中では、これ以上取り込む余地がない。
- 取り込むには『線の下 × VIX が高い』ときに数量を 1.0 倍より増やす形になる。該当は通貨 × 週の約 5%(OOS は 10 回)と少なく、相場が荒れている週に数量を増やすことになるため、口座の失格率を上げるおそれがある(Q197)。結果を見てからの着想でもあり、登録しない。
- 200 日線まわり・VIX の組合せを含め、配備中の『単純な 1 本』を上回る形は見つかっていない。
