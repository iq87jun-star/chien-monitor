## 0. 一行（事前登録の主張）

> **新エッジを"発明"しない。市場は1クラス1機序しかくれなかった(docs/14)という確定事実を尊重する。**
> 代わりに **「検証済みの月曜エッジ(E-Mon/v7)を、ボラ/トレンドのレジームで ON/OFF する手法 = RG」** を事前登録する。
> 目的は α追加ではなく **左尾(クラッシュ・ギャップ)の除去 → 合算maxDD圧縮 → 失格率低下**＝本プロジェクトの設計原則
> 「**退場しない > 速度**」(docs/02)に最も整合する一手。
> 副候補として **リスクオフ時だけ建てる金(XAUUSD)ロング衛星** を、ポートの潜在的な"ロング・リスクオン偏り"を相殺する
> 構造ヘッジとして事前登録する（こちらは低確度・小サイズ前提）。

## 1. なぜこの土俵か — docs/26 が残した唯一の未踏宿題

docs/14/17/20/21/22/23/27/42/50 で、**カレンダー / 順方向ドリフト / 平均回帰 / モメンタム / リードラグ /
多資産トレンド / セッション / 相対価値** は十分な検出力で検定し、**生き残りは「週明けリスクプレミアム(円=v7・指数=E-Mon)」
と「FX平均回帰合議(v4)」のみ**と確定した。新しい無相関エッジを足すことはもう期待できない。

しかし docs/26 の「未踏=次に試す価値のある土俵」には、まだ手を付けていない一行が残っている:

> 「ボラティリティ・レジーム条件付け（VIX/ATR分位で **月曜エッジ** や他系統をオン/オフ）。」

### ★ edge6 の E1 とは違う（重要・自己批正の継承）

docs/27 の **E1(VOLREGIME_TREND)** は「**多資産トレンド(LEAD級)** を低ボラ時だけON」にして **REJECT**(頑健p0.203)だった。
だが E1 が条件付けた土台は **そもそも有意水準未達の弱いトレンド**である。**docs/26 が指していたのは「月曜エッジ」**＝
**ADOPT/STRONG-LEAD の検証済みエッジ(E-Mon/v7)** をゲートすることであり、**それはまだ誰もやっていない**。

- E1（済・REJECT）: 弱いトレンドにレジームを足して α を作ろうとした → 土台が弱く失敗。
- **RG（本書・未踏）**: **強い月曜エッジ**にレジームを足し、**α追加ではなく左尾除去（失格率低下）** を狙う。
  土台は検証済みゆえ、ゲートの仕事は「リターン創出」ではなく「**最悪のギャップ週を踏まない**」純粋な防御。役割が根本的に違う。

### 機序（なぜ効きうるか・なぜ効かないかもしれないか、両論併記）

- **効きうる側**: 規約違反(日次−5%/最大−10%)を起こす破壊的な逆行は、**高ボラ/リスクオフ・レジームの月曜ギャップ**に集中する
  （2018Q4・2020 COVID・2024/8 円キャリー巻き戻し）。そこを ON/OFF で踏み外せば、**素のエッジを保ったまま合算maxDDだけ削れる**。
- **効かない/逆効果になりうる側**: docs/50 G5 は **E-Mon の有意性が 2020(COVID) を含むときに支えられている**ことを示した
  （2020除外でJK 0.125に悪化）。**高ボラの月曜は"暴落"だけでなく"急反発(リスクプレミアムの源泉)"も含む**。
  もし高ボラ月曜が**ネットでプラス**なら、それをゲートすると**リターンとエッジの根拠まで削ってしまう**。
  → **どちらが支配するかは仮定せず、データで決める。** これが本事前登録の核心的な実証問題である。

## 2. 事前登録した候補（N=6 固定・当たるまで増やさない・Bonferroni α=0.05/6=0.0083）

| ID | 手法 | レジーム信号(no-lookahead) | 仮説 |
|---|---|---|---|
| **RG1** | E-Mon 月曜LONG を**トレンド・ゲート** | 各指数 前営業日Close > SMA200 のときだけ建てる | 上昇局面の週明けだけ取る＝下落相場のギャップを回避 |
| **RG2** | E-Mon 月曜LONG を**ボラ・ゲート** | バスケット実現ボラ(20d)が自身の**ローリング80分位以下**のときだけ建てる | ボラ急騰週を見送る＝テール除去 |
| **RG3** | E-Mon 月曜LONG を**非対称リスクオフ・ゲート** | **SMA200割れ かつ 高ボラ**(真のリスクオフ下落)のときだけ**見送り**、他は建てる | クラッシュ尾だけ抜き、高ボラでも上昇局面の反発は残す |
| **RG4** | **v7(円月曜LONG)** に同じ最良ゲート(暫定=RG3)を適用 | 円側の risk-off ゲート | 円月曜にも同じ防御が効くか（横展開の検証） |
| **RG5** | **金(XAUUSD)ロング衛星**＝リスクオフ時だけ建てる | 株価指数が RG3 で OFF の週に XAU を週次LONG | ロング偏りのポートに**負相関の安全資産脚**を足す（構造ヘッジ） |
| **RG6** | **ボラ・ターゲティング**(ポート全体) | 直近実現ボラの逆数でポート週次リスク予算をスケール(上限あり) | 固定%より p95DD/失格を下げられるか（サイズ手法） |

各候補に **整合プラセボ**を必ず付ける（ゲートの"信号価値"を分離する帰無仮説）:
- RG1–4: **同じ割合の週をランダムに間引く**プラセボ。ゲート版が**ランダム間引き**を有意に上回らなければ、改善の正体は
  「ただ取引を減らしただけ」＝**採用しない**。
- RG5: **ランダム曜日/ランダム週**の金ロング（docs/50 F4 で金の曜日エッジは既に NEGATIVE。素の金ロングを拾うだけなら棄却）。
- RG6: **ランダム・リスケール**（同じ平均サイズ・ランダムな週次倍率）。

## 3. ハーネス（docs/26/40/50 と同一の最厳基準・10年実データ）

- データ: `research/data/*_d.csv`（FX/指数/金 日足10年, 2016–2026）。**拘束力ある検定はユーザーの Google Drive 実10年**で実行。
- 取引: 月曜(or リスクオフ週) open → 翌営業日 open、往復コストを bps 控除。レジーム信号は**前足までで確定**（no-lookahead）。
- 採点ゲート:

| # | ゲート | 合格条件 |
|---|---|---|
| G1 | 10年実データ | span ≥ ~9y・件数併記（2.8年の楽観を上限扱いしない） |
| G2 | ノールック＋実コスト | open→翌open・bps控除・信号は前足確定 |
| G3 | 順列p（自己相関頑健版＝月次ブロック符号シャッフル） | ゲート版 perm_p < Bonferroni 0.0083 |
| G4 | **対プラセボ識別** | ゲート版が**ランダム間引き/リスケール・プラセボを有意に上回る** |
| G5 | 年次ジャックナイフ | max_p ≤ 0.10（特定年依存でない） |
| G6 | IS/OOS 両方+ | 70:30 で減衰なし |
| G7 | コスト頑健 | 2×〜20bps でも改善が残る |
| G8 | −10%枠適合 | p95 maxDD が枠内・v4/E-Mon との10年相関が低/負 |

- **ゲート系(RG1–4,6)の成功指標は α ではなく防御**: 「ゲート版が**素版を OOS で Calmar かつ p95 maxDD の両方で優越（パレート支配）**」かつ
  「**ランダム間引きプラセボを上回る**」を満たして初めて **ADOPT**。満たさなければ **LEAD/REJECT** と正直に書く。

## 4. ★ KILL 基準（先に明文化＝結果を見てから言い訳しない）

1. **プラセボに負けたら棄却**: ゲート版 ≦ ランダム間引き → 「取引を減らしただけ」＝**価値なし**。
2. **OOS で素版に勝てなければ棄却**: IS だけの改善は過剰最適化（docs/55 の規律）。
3. **高ボラ月曜がネット+なら RG2/RG3 は素版を下回る** → その事実をそのまま記し、**「ゲートは不要」と結論する**（それも価値ある NEGATIVE）。
4. RG5 の金が **プラセボ(ランダム金ロング)を超えない**、または maxDD が衛星枠(≤8%)に収まらない → 棄却。
5. **1つも通らなければ「RG は不採用・確定スペックのまま」と誠実に結論**（docs/14/27 と同じ姿勢）。

## 5. 規約準拠（構造的に違反不可能）

- RG1–4,6 は **新規エントリーを"見送る/縮小する"だけ**＝**両建て・ナンピン・HFT・コピー・マーチンゲールのいずれも生み出さない**。
  ゲートは露出を**減らす方向にしか働かない**ため、FundedNext/FTMO の禁止手法(docs/01 §4)に**原理的に抵触しない**。
- RG5 の金は **別銘柄・ロングのみ・週次保有(2分超)・SL必須**＝指数/FX と**同一銘柄の反対両建てを作らない**（docs/61 §4 の準拠条件を満たす）。
- 日次−4%/フロア−8%/災害SL の既存ガード(docs/02/60)は**そのまま上位に維持**。RG はその**内側で更に左尾を削る**追加層。
- 暗号は不要。**暗号不可の業者でも全 RG が稼働**（金CFDは多くの業者で可。銘柄名 XAUUSD=GOLD 等は業者仕様に合わせる, docs/36）。

## 6. ポートフォリオ統合（採用された場合の置き場所・確証前の暫定）

- RG は**新しい器ではなく、確定スペック(v4 55 : E-Mon 45)の E-Mon 脚と衛星 v7 に被せるフィルタ層**。比率は変えない。
- 採用時の期待効果（**仮説であり数値未確定**）: 合算 p95 maxDD の低下 → 同じ目標DD(−8%)に対し**サイズをわずかに上げられる**
  か、同サイズで**失格率を下げられる**かのどちらか。**速度ではなく生存に効く**のが狙い（docs/62 の中庸−8%を、より低い失格で実現）。
- RG5 採用時のみ、衛星枠の一部(≤8%)を「リスクオフ金」に割り当てる新パターン **P-RG** を docs/65 に定義（暗号衛星の代替・補完）。
- **確証されるまでは確定スペックを一切変更しない。** RG は **デモで素版と並走**させ、合算maxDD と失格の実測差が出てから本番へ。
