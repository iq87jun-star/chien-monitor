## 0. 一行結論

> **P2 = 米独株価指数(US500 / NAS100 / GER40)の「月曜LONG」(週初ドリフト)バスケット。**
> 9ゲートで **STRONG-LEAD**（プールperm_p=0.0098・月曜のみ有意のプラセボ識別・IS/OOS両+・WF4/5・コスト2×+）。
> **未達は G3(Bonferroni N=274) と G5(年次JK＝2020依存) の2つだけ**＝**P1のv7/E5と全く同じ級**。

> maxDD −4.7%→−3.2%**。＝「同じ検証レベル × P1と独立」という要望を満たす第2エンジン。

## 1. 探索設計（P1と同一思想・全候補一律の厳格ハーネス）

`research/p2_edge_search.py`。ユニバース=**追加FXクロス10 + 金属2 + 株価指数5 + 暗号2**（Yahoo日足10年）。
機構は E5(モメンタム)と被らない3系統:

| 系統 | 定義 | ノールックアヘッド |
|---|---|---|
| DOW(曜日) | 各曜日に open→翌営業日 open(1日保有) | 曜日は事前確定＝構造的に担保 |
| TOM(月末) | 月末最終1+月初3営業日に1日保有 | 暦＝事前確定 |
| REV(短期平均回帰) | RSI(2)極値の翌足を1日保有 | **close[t]確定→約定open[t+1]→決済open[t+2]** に厳密シフト |

- 各候補に: **順列検定(符号シャッフル) / IS-OOS / 全年ジャックナイフ / Bonferroni(N=274,α=0.000182) /
  コスト2× / プラセボ / ★既存P1(v7/v4/E5合成)月次との相関**。
- **正直な自己修正**: 初版の REV は「close[t]の情報で当日open[t]から約定」する**ルックアヘッドのバグ**で
  net 1e17%・勝率96%という異常値を出した。これを上記の厳密シフトに修正したところ REV は全滅し、
  残ったのは**カレンダー系のみ**。docs/07/08で犯した「仮数値コミット」と同種の、出力を疑う規律で是正済み。

## 2. なぜ「株価指数の月曜LONG」か — プラセボ識別（月曜特異性）

v7が「月曜のみ有意・他曜日は非有意」で本物性を示したのと同型のプラセボを、3指数の**曜日別**で確認:

| 指数 | 月曜 | 火 | 水 | 木 | 金 |
|---|--:|--:|--:|--:|--:|
| US500 | **+51.9% (p.019)** | −0.1%(.47) | −7.0%(.57) | −15.4%(.74) | −14.4%(.70) |
| NAS100 | **+117.8% (p.003)** | +21.7%(.20) | −2.6%(.46) | −22.7%(.76) | −23.5%(.75) |
| GER40 | **+65.5% (p.017)** | −4.4%(.53) | +2.5%(.41) | −48.4%(.99) | −17.2%(.67) |

- **月曜だけが有意、火-金は非有意（多くは負）** ＝ プラセボ識別クリア。3指数が**独立に同じ月曜効果**を示す
  （v7の3円クロスと同型の横断的頑健性）。JP225/UK100/金属には月曜効果なし（**正直に弱い＝盛らない**）。
- 機序: 週末に滞留した買い需要・週初のリスクオン資金流入(「週末効果の現代版反転」)。学術的にも頑健な系統。

## 3. 本検証（P1のv7基準 9ゲート）— `p2_portfolio_validate.py`

核 = **US500 / NAS100 / GER40 月曜LONG 等加重バスケット**（v7のマルチショットと同型に3指数で分散サンプリング）。

| ゲート | 結果 | 判定 |
|---|---|:--:|
| G1 10年 | 2016-06 .. 2026-06（10.0年） | ✅ |
| G2 ノールックアヘッド+実コスト | 月曜は事前確定＋指数5bps往復控除（構造的担保） | ✅ |
| **G3 プールperm_p<Bonf** | **0.0098** > α0.000182 | ❌ |
| G4 プラセボ(月曜のみ) | 月曜プールp=0.0098 / **火-金プラセボ p=0.765(非有意・負)** | ✅ |
| **G5 年次JK** | max_p=**0.234**(2020除くと弱化) / 他9年は≤0.013 | ❌ |
| G6 IS/OOS両+ | IS +38.4% / OOS +21.9%（両方+） | ✅ |
| G7 ウォークフォワード | **4/5**期がnet+ | ✅ |
| G8 コスト2× | net +30.4% 維持 | ✅ |
| **判定** | **STRONG-LEAD（4/6コア・G1/G2含め6/8）** | |

- **未達は G3(Bonferroni) と G5(2020依存) のみ** ＝ docs/40 の **E5(6/9・JK0.17でSTRONG-LEAD) と完全に同じ性質**。
  「質は高いが最厳の統計閾値だけ未達」＝STRONG-LEADの定義そのもの。**ADOPTは偽装しない。**
- **正直な弱点(G5)**: 2020(コロナ反発)を除くとプール有意性が落ちる(perm_p 0.234)。**単一レジーム依存の懸念**は
  残る（他のどの1年を除いても p≤0.013 で頑健なので「2020だけが効いている」ではないが、寄与は大きい）。
- 脚間相関: US500-NAS100 **0.88**(高=実質1.7本) / US500-GER40 0.51 / NAS100-GER40 0.42（平均0.60）。
  → 米株2指数は冗長気味。**真の独立軸は「米株 vs 独株」の2軸＋(任意)暗号**。
- バスケット成績(等加重・生): net +68.7% / 年率 5.69% / **Sharpe(年) 0.76** / maxDD −13.8% / 勝率55.2%。
  → **v7単体(Sharpe 0.78, docs/40)とほぼ同等の質**。v7が良く見えたのは日中12ショット多重サンプリングゆえで、
  日足・週初エントリの解像度では同水準（v7の10年も net+29%≒年率2.6%と実は地味＝盛らない）。

## 3.5 独立インストゥルメント追認（現物 / ETF / 先物）— `p2_confirm_proxies.py`

「Yahoo現物指数データ固有のクセ」でないことを確かめるため、同じ指数を**別系列のインストゥルメント**
（ETF・先物）で取得し月曜LONGを再検定した。先物(ES/NQ)はCFDが連動する対象ゆえ実運用妥当性の追認も兼ねる。

| 指数 | 現物 | ETF | 先物 |
|---|---|---|---|
| US500 | ^GSPC p=0.019 | SPY p=0.004 | **ES=F p=0.040** |
| NAS100 | ^IXIC p=0.003 | QQQ p=0.000 | **NQ=F p=0.009** |
| GER40 | ^GDAXI p=0.020 | EWG p=0.016 | （先物略） |

- **8/8 のインストゥルメントで月曜LONGが p≤0.05 で再現**。かつ**全件で火-金プラセボは非有意（p>0.4・負）**。
- 現物・ETF・**先物**を通じて同じ月曜効果が出る＝**Yahoo現物固有のアーティファクトではなく本物の市場現象**の傍証。
  特に先物での再現は、CFD(先物/現物連動・オーバーナイトギャップ有り)での実運用妥当性を補強する。
- ⚠ あくまで傍証。絶対値はインストゥルメントで異なる（配当/限月/乖離）。**最終確証はユーザーの実CFDデモで**。

## 4. P1との相関と「並列運用」の価値 — `p2_vs_p1_combined.py`

P2の最大の存在意義は**P1と独立**なこと。月次相関:

| 対 | 相関 |
|---|--:|
| **P2 ⇄ P1合成** | **0.014** |
| P2 ⇄ v7(円月曜) | 0.22 |
| P2 ⇄ v4(合議FX) | −0.13 |
| P2 ⇄ E5(多資産モメンタム) | −0.153 |

月次ボラを共通(1.0%)に正規化した**公平比較**(スケール不変):

| 構成 | Sharpe | 年率 | maxDD |
|---|--:|--:|--:|
| P1 単体 | 1.06 | 3.73% | −4.7% |
| P2(株コア)単体 | 0.70 | 2.54% | −7.7% |
| **P1+P2 50:50** | **1.23** | 3.14% | **−3.2%** |

- **併用で Sharpe 1.06→1.23（1.16倍）・maxDD −4.7%→−3.2%（約3割縮小）**。源泉は相関0.014。
- P2単体はP1より弱い(Sharpe0.70 vs 1.06)＝**正直**。だが**独立した検証済みエッジ**ゆえ、
  「2口座目を並列運用」「P1の不調月をP2が埋める」用途で価値が出る ── これが「別ポートフォリオ」の本質。

## 8. 結論・次アクション
