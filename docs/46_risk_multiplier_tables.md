# 46. リスク倍率ごとの比較表 — プロップ/インスタント・現状(2種) vs 推奨(3種)

> ユーザー要望「リスク倍率ごとの表をプロップとインスタントで、現状と推奨の比較」への回答。
> ツール: `research/colab_firms_2v3_compare.py` / `notebooks/firms_2v3_compare.ipynb`（★リスク倍率表セクション）。
> **倍率の定義**: 1.0x = 現状(v7+E5 75:25)の口座hist maxDD が約10%になる総リスク。docs/25「リスク1.5倍
> ≒maxDD15.3%」と整合（1.5x≒15%）。**maxDDは倍率に線形・口座共通**（プロップ/インスタントで同じ）。
> **絶対値はユーザーの確定10年Drive実行にアンカー**（✔印）。インスタント側は確定、プロップ側の失格/手取りは
> 要Drive確定（静的枠ゆえ概算は低め）。

## 0. 一行結論

**どのリスク倍率でも 推奨3種(v7+v4+E5 40:40:20) は 現状2種(v7+E5 75:25) の約半分のmaxDD**。
→ 現状は約**0.9倍**で−10%枠超過するが、推奨は約**1.9倍**まで枠内＝**同じ枠で2倍のサイズを許容**。
あなたの現状(インスタント)は「同倍率なら5年失格 31.5%→1.0%」「同失格なら手取りほぼ倍」。

## 2. ① インスタント（Blueberry $50k・−10%トレーリング・分配80%）

*✔=確定10年Drive実行値、他は倍率比例の概算。*

| 倍率 | 現状 5年失格 / 手取り | 推奨 5年失格 / 手取り |
|---|--:|--:|
| 0.5x | ~3% / ¥311k | ~0% / ¥327k |
| **1.0x** | **31.5%✔ / ¥622k✔** | **1.0%✔ / ¥654k✔** |
| ~1.5x(安全) | ~50% / ¥933k | **9.6%✔ / ¥938k✔** |
| ~1.9x(同失格) | ~70% / ¥1.18M | **28.7%✔ / ¥1.20M✔** |

- **同倍率(1.0x): 5年失格 31.5%→1.0%（手取りほぼ同額）**。
- **同失格(~30%): 推奨は約1.9倍で 手取り¥1.2M（ほぼ倍）**。
- 現実的狙い目 = **推奨 1.0〜1.5x（5年失格1〜10%・手取り¥654k〜¥938k）**。

## 4. 推奨

| 局面 | 倍率の置き所 |
|---|---|
| **インスタント(あなたの現状)** | **推奨3種で 1.0〜1.5x**。現状(2種)はトレーリング枠で同倍率でも失格が急増ゆえ非推奨。 |
| **プロップ審査** | 推奨3種で 1.0〜1.5x（静的枠で失格ほぼ0・$100kで手取り大）。突破後は守りに倍率↓。 |
| 共通 | **どの倍率でも推奨>現状**（DD半分）。攻めるほど差が拡大。 |

## 5. ★推奨倍率の候補（3戦略EAの予算入力に直結）

倍率 = 3戦略EA(`Chien_Portfolio3_AllInOne_*`)の3予算を**一括スケール**。下記INSTANT既定(v7 0.60/v4 0.15/
E5 0.30)が **守り(≈maxDD5%)** の出発点。中庸/攻めは全予算を比例倍する。値は確定10年(Blueberry$50k)アンカー。

### インスタント（Blueberry $50k・あなたの現状の業者）
| 候補 | 倍率 | EA予算 v7/v4/E5(週次/トレード/legRisk) | maxDD | 5年失格 | 手取り/年 |
|---|---|---|--:|--:|--:|
| **守り** | 1.0x | 0.60 / 0.15 / 0.30 (=INSTANT既定) | −5.2% | **1.0%** | ¥654k |
| **中庸(推奨)** | **1.5x** | 0.90 / 0.225 / 0.45 | −7.8% | ~9.6% | **¥938k** |
| 攻め | 1.9x | 1.14 / 0.285 / 0.57 | −10.4% | ~28.7% | ¥1.20M |

→ **本命=中庸1.5x**（5年失格1桁%で手取り+50%）。Blueberryは返金なし＝**守り1.0xから始め、建値ロック後に
中庸へ上げる**のが安全（docs/25の段階引き上げと同じ）。攻め1.9xはmaxDDが枠際＝非推奨。

### プロップ（FundedNext $100k・静的枠）※失格/手取りはDrive確定
| 候補 | 倍率 | EA予算 v7/v4/E5 | maxDD | 5年失格(概算) |
|---|---|---|--:|--:|
| 守り | 1.0x | 1.00 / 0.25 / 0.50 (=PROP既定) | −5.2% | ~0% |
| **突破(推奨)** | **1.5x** | 1.50 / 0.375 / 0.75 | −7.8% | ~0% |
| 攻め | 2.0x | 2.00 / 0.50 / 1.00 | −10.4% | ~17% |

→ 静的枠ゆえ**突破狙いは1.5x**が安全に速い（失格ほぼ0・$100kで手取り大）。**審査突破後は守り1.0xへ落とす**
（資金化後は生存優先）。攻め2.0xはmaxDD枠際。

### 一言でいう推奨
- **インスタント(現状)**: 推奨3種で **守り1.0x→建値ロック後1.5x**。
- **プロップ**: 推奨3種で **突破1.5x→資金化後1.0x**。
- いずれも **v4のEA化済み3戦略統合EA(docs/45)＋デモ前進検証**が前提。攻め(>1.9x)はDD枠際で非推奨。
