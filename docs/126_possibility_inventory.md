# 126. 「出尽くしたか?」の全数棚卸し — 未検定方向の正直なインベントリ

> 目的: ユーザー質問「プロップのロジック検証は出尽くしたという結論だが、**全ての可能性を考慮したか?**」への
> 体系的な回答。検定済み領域の地図(negative space)を確定し、**構造的に残っている未検定方向**を
> 入手可能性込みで列挙する。結論だけ先に: **価格系列(日足/H1)宇宙は消尽。ただし非価格データに
> 未検定の扉が1つ残っており(CFTC COTポジショニング)、本セッションで事前登録の上検定する**(docs/127-128)。

## 2. 構造的に残っている未検定方向(正直な全列挙)

docs/113 のL2レーン(新データ源)基準=「入手手順まで書けるもののみ有効」で採点:

| # | 方向 | データ入手 | 判定 |
|---|---|---|---|
| **D1** | **CFTC COT(投機筋ポジショニング)** | **無償・即時**(cftc.gov 年次zip, 1986年〜, 本環境から到達確認済み) | **検定可能 → edge23として本セッションで実行**(docs/127) |
| D2 | オプションIV(FXリスクリバーサル/IVサーフェス) | 有償(Bloomberg/Refinitiv級)。無償で使えるのは指数系VIX/SKEW程度(VIXは検定済みF2) | 現時点で不可(入手できたら再開可) |
| D3 | オーダーフロー/板情報 | MT5のCFDには板なし。FNサーバーのティック=EURJPY 2.5年のみ | 検定力不足(低頻度エッジには標本不足)。ティック蓄積を継続し2028年頃に再評価 |
| D4 | 限月別先物(基差・ロールイールド) | CME個別限月は有償。Yahoo継続足では edge19 で閉鎖済み | 不可(継続足での再挑戦はF2型の罠として禁止済み) |
| D5 | センチメント(小口比率・SNS) | ブローカーの小口ポジ比率はAPI不安定・履歴なし | 不可(検証可能な履歴が存在しない) |
| D6 | 個別株・クロスセクション | プロップのMT5に個別株CFDは限定的・実装先がない | 対象外(実装手段がない) |
| D7 | 暗号資産 | edge6-E6(BTC回転)でベータの言い換えとしてREJECT済み。プロップ規約でも制約 | 閉鎖済み |

**∴ 「出尽くした」は価格系列宇宙については正しい。ただし D1(COT)だけは docs/113 が
L2の筆頭例として名指ししながら、edge11〜22のどのバッチでも一度も検定されていない。**
(edge11-F3は「金利水準→JPY」でありポジショニングデータは未投入。リードラグ棄却済み領域とは
データ種が異なる=価格から価格ではなく、建玉統計から価格。)

## 3. なぜCOTが「最後の正規ルート」か

1. **再開条件に適合**: docs/80 §4「新しいデータ解像度か新しい資産クラス」— COTは価格ではない
   **新データ種**(週次・建玉統計)であり、同じ日足宇宙の再探索に当たらない。
2. **機序の連続性(L3)**: 生存5エッジは全て「低頻度フロー・カレンダー」族。COTは
   まさにフロー(投機筋の建玉変化)の直接観測であり、機序的に隣接する。
3. **文献的事前分布**: ポジショニング極値の逆張り・スペックフロー持続は先物文献で古典
   (ただし公表後減衰の可能性が高い=edge16と同じ結末が最尤、と事前に明記しておく)。
4. **無償・再現可能・長履歴**(1986年〜)=pre-2016耐久検定まで一気通貫で可能。

## 4. 事前の期待値(盛らない)

- **最尤シナリオ**: edge16/17型 —「歴史的には有意・現行レジームでは減衰」→ EA化なし。
- 採用に至る確率は主観で1〜2割。ただし**検定せずに「出尽くした」と言い切ることはできない**ため、
  ここを潰して初めて「フリーで入手可能な全データ宇宙を消尽」と宣言できる。
- 本検定がREJECTなら、残る扉は D2(有償IV)と D3(ティック蓄積待ち)のみ=
  **探索は名実ともに完全終了**となり、以後は運用最適化・フォワード監視だけが正当な資源投下先。
