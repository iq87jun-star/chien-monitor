## 2. 読み

- 「FOMC初動の方向に発表後ドリフトが続く」は、US500分足では**存在しない**(グロスですらマイナス、
  勝率はコイン投げ)。初動15分で価格発見がほぼ完了し、その後は双方向ノイズ。
- G3(既存ADOPT)は発表**前**24時間のドリフトであり、本結果はG3と矛盾しない
  (発表前の上昇バイアス ≠ 発表後の継続)。G3の優位性が発表後に及ばないことの確認にもなった。
- 新解像度(分足)の初投入だったが、イベント系で最も有望と考えた仮説がこの結果である以上、
  **分足での追加スキャンはしない**(時間帯・保有時間をいじれば何かは「見つかる」が、それは
  探索でなくデータマイニング)。分足データの残る正当な用途は既存ADOPT EAの執行検証のみ。
