## 1. 定義(1 取引あたり bps・方向込み)

| 量 | 式 | 意味 |
|---|---|---|
| 実 純 | sign×(決済値/建て値 − 1) + (手数料+スワップ)/名目 | 実口座が得た値幅(名目 = 損益 ÷ 値幅) |
| 紙上(モデル) | sign×(予定出口時刻の中値/建て時刻の中値 − 1) − モデルコスト | 研究系列の約束(同じ時刻の時間足始値・コスト定数 FX 2pip / 指数 IDX_COST / ETH 15 bps / BTC 10 bps) |
| 差 | 実 純 − 紙上 = 建て滑り + 手仕舞い滑り + (実コスト − モデルコスト) + 時刻差 | |
| 建て滑り / 手仕舞い滑り | 約定値と同時刻の中値の差(負 = 不利) | スプレッド + 約定遅れ |
| 時刻差 | 実際の出口時刻の中値 − 予定出口時刻の中値 | SL・早期手仕舞い・EA 切替時の決済(執行品質ではなく運の成分) |
| 建て損ね率 | 1 − 実建て本数 / 予定本数 | 予定表 `SCHEDULE`(docs/241 から転記。EA 切替時に since/until/skip を更新) |

分解が意味を持つのは**定時に建てて定時に手仕舞うレグ**(Mon・Roll・Sess・A案 S1〜S3)。Hold・v4・RSI2(S4/S5)は分単位の SL/TP/RSI 出口なので時間足基準では分解できず「参考」。サーバ時刻は EET/EEST(3 社とも)。時間足は Dukascopy(9 月分は月次取得・UK100/WTI は 503 で取得できず Yahoo 代替 → WTI の値はズレる)。

## 3. 読み

1. **定時レグの執行は紙上と ±2 bps/取引で一致**。Roll(トパーズ・9/30・5 本)の差 −0.2〜−1.4 bps、A案 S1/S2(FTMO)+0.8 / −0.5 bps、Sess(FN・9/14〜18 の旧レグ 18 本)+0.1〜+1.9 bps。滑りは建て 0〜1 bps・手仕舞い 1〜2.4 bps(Roll の 00:00 UTC 出口はロールオーバーでスプレッドが広い)。S3 の 9 月 −11.9 bps は n=1(手仕舞い 22:00 UTC の足の問題を含む)。
2. **モデルコストは実測より保守的**。FX 主要通貨の実コスト(手数料+スワップ)は 0.4〜0.9 bps/取引に対しモデルは 1.0〜3.5 bps(2 pip)。ETHUSD は建て滑り −10〜−11 + 手数料 −4 = −14〜−15 bps で**モデル 15 bps とほぼ同じ**。つまり研究系列の月次(docs/321)は実口座より控えめに出る。docs/244 §1 の定数は変えない(緩めない)。
3. **Mon ETHUSD の実 純 +96 bps/取引(9 月)が紙上 +38 を上回るのは時刻差 +48 の運**。9/14 18:20 UTC に 4 本が同時決済(EA 切替時の決済と整合)され、その後の下落を免れた。執行品質の成分(滑り+コスト−モデル)は +0.8 bps で中立。8 月は SL 4 本(25%)で時刻差 +23。
4. **設定の不一致を発見**: FN v1.30 の Roll スキップ表には `2026.09.30` が残っている(9/25 作成)が、EA11 v1.10 は 9/27 のユーザー決定(docs/308)で 9/30 を解除している。結果として 9/30 の Roll は FN では建たず、トパーズでは建って 5 本とも負(平均 −13 bps・Q61 の「月末最終 JP 営業日の水曜は −2.9 bps」と同方向)。どちらが正しいかはユーザー判断(§4)。
5. Hold / v4 は参考値。トパーズ WTI の滑り ±500 bps は Yahoo 先物(CL=F)と CFD スポットの基差で、執行の数字ではない。Dukascopy の 9 月分(LIGHTCMDUSD / GBRIDXGBP)が取得できたら再計算される。
6. **Q83 の規則(2 か月連続で Mon −5 / Roll −3 bps 未満 → 縮小案)に該当するレグは無し**。Mon ETHUSD の執行成分 +0.8 bps、Roll −0.2〜−1.4 bps(1 か月目)。
