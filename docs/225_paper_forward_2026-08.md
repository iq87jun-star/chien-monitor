## 4. 運用

- **毎月 1 日に `python3 research/forward/paper_forward.py YYYY-MM` を回し、本書の形式で docs に追記する**。これで全レグの「生存記録」は無料で継続する。
- 実口座フォワード記録(docs/224 §6b・22 レグ)は**執行差の測定**に目的を絞る。入金が用意できるまで保留しても、手法の追跡は止まらない。
