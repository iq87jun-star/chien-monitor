## 1. 対象・データ(固定)

- **土台**: v7間引き後(EURJPY+GBPJPY等加重・月曜04/06/08/10UTCの4ショット・各24時間保有)。
  3ペア版(+USDJPY)は参考欄。コスト往復2pip(感応1/3pip)。
- データ: Drive `dukascopy_data_h1/{PAIR}_h1.csv`(10年・UTC)。SHA-256は環境上取れないため
  行数・期間をJSONに記録。
- 窓: 2016-01〜データ末尾。週次リターン = その週の全ショット合算。

## 2. ゲート(N=1固定・逐語再利用)

`edge_regime_gate_10y.py` のRG3型を円バスケットに適用(no-lookahead・前日足まで確定):
- up_maj: 各ペア close > SMA200 の**過半**
- hv: バスケット実現ボラ(20d, 年率化)が自身のローリング252d **80分位超**
- **リスクオフ週 = (過半がSMA200割れ) かつ (高ボラ) → その週の全ショット見送り**。他は全て建てる。
- 判定信号は**前週金曜closeまでの日足**で確定(月曜00UTC時点で既知)。

対称トレンドゲート(SMA上のみ建てる)は検定しない(docs/66でOOS破壊が確認済みの型)。
ただし診断欄に参考値として1行併記する(採否には使わない)。

## 3. 判定ゲート(docs/64 §3の防御バーを逐語適用・機械判定)

| ゲート | 合格条件 |
|---|---|
| G_perm | ゲート版の週次ブロック順列p ≤ **0.05**(主候補N=1・事前固定) |
| G_plac | **同率ランダム間引き200rep**にCalmarとmaxDDの**両方**で優越 |
| G_pareto | 70:30 OOSで素版をCalmar・maxDDの**両方**で優越(パレート支配) |
| G_crisis(診断) | 危機を含む分割(2016-21をOOS側/2022-26をOOS側の2通り)でmaxDD改善が再現するか併記。docs/66 §4(c)の「無危機OOS交絡」を外す目的。**採否はG_paretoで機械判定**し、G_crisisは解釈にのみ使う |

- **ADOPT** = G_perm+G_plac+G_pareto全通過 → EA実装(季節/PD共通: `InpV7RiskoffGate`・**既定OFF**)+デモ必須。
- **LEAD** = G_plac+G_pareto通過・G_permのみ未達 → 記録のみ(年次再測・デモ並走候補)。
- それ以外 **REJECT** → RG4を正式閉鎖(docs/66の保留を解消)。

## 4. 事前の期待値(盛らない)

- 主観2〜3割。E-MonのRG3ですらYahoo全期間で「危機期間はDD半減・無危機OOSでは出番なし」で最厳バー
  未達だった(docs/66)。v7の最大逆風(2024-08円キャリー巻き戻し)は**週内の急変**であり、
  週次・SMA200ベースの信号では**遅れて反応する可能性が高い**ことを事前に明記する。
- 狙いはα追加ではなく左尾防御(失格率低下)。ゲートで年率が下がってもmaxDD/失格が十分下がれば
  倍率再校正で回収できる——が、それはADOPT後の校正段階の話であり判定には使わない。
