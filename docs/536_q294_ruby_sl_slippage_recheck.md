## 0. 結論
1. **先に決めた選び方の結論: ルビーはいまのまま(EA の移植はしない)。** すべての損切りに 95% 点のすべり(9%)を当てると、V3・V5・ガード 2.0% のどれも「2 場面とも悪化でなく 1 場面以上で改善」を満たさない。セルは 改善 4・影響なし 2・悪化 12 / 18。
2. **実測の中央(0.6%)なら、Q290 の改善はそのまま残る。** V3 は score 合計 275.6 → 295.4、V5 は 284.1。数字は σ = 0 とほぼ同じ。
3. **9% で落ちる理由**: V3 は損切りを狭めるので損切りにかかる回数が増え、すべりの影響を基準より強く受ける。① の到達が「いま」で 88.0 → 84.1(−3.9)、「次」で 87.7 → 85.9(−1.8)に下がる。一方で ② の失格は 20.7 → 11.0・10.6 → 4.0 と低いままで、score の合計は基準より高い(271.2 対 260.2)。「失格を減らす代わりに到達が少し下がる」形に変わる。
4. **読み方**: V3 の効き目(古い期間の失格を半分にする)は、すべりを入れても消えない。ただし「到達を落とさずに」という条件は、すべりが大きいと満たせない。全部の損切りに 9% を当てるのは厳しめの仮定で、実際は 0.6% と 9% の間。規則は先に 9% と決めたので、結論は「いまのまま」とする。
5. **ガード 2.0% は、どのすべりでも基準とほぼ同じ**(場面ごとの score の差 −1.9〜+2.3)。注意 2 回目で 2.0% に下げる規則(Q289)は、ルビーでは費用がほぼ無いことを再確認した。
