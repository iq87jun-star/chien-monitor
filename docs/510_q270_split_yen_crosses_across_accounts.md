## 1. 定義(事前固定どおり)
- 全口座の同時シミュレーション(`forward/portfolio_sim`・同じ相場経路・6,000 本・共通の乱数)。月曜の円クロス 4 本を等分に持つ口座(mon4)を 2 通貨ずつに分ける。A 組 = GBPJPY + EURJPY、B 組 = AUDJPY + USDJPY。各口座の月曜の名目の合計は変えない。
- S1: FTMO 0397 = A・FTMO 7058 = B・宝くじ = A・トパーズ = B・1-Step の mon4 部分 = B・FN 6201(本口座後)= A。S2 = A と B を入れ替え。ルビー・パール・FN 4882・Instant は変えない。
- 変更候補の条件: S1・S2 の両方で (1) 期待が現行の −2% 以内 (2) 0 になる確率が 2 ポイント以上下がる または −1σ が上がる (3) どの口座も評価中の失格が +2 ポイントを超えて増えない。
- この再現は日足で、日中のガード・2 つの縮小・SKEW の見送り・決済の切り替えを表現していない。到達・失格の水準は口座ごとの精密な再現(Q233 の型)とは違う。ここでは設計どうしの差だけを読む。

## 3. 読み方
- **同時に 3 口座以上が失格する週は 13.9 → 11.2% に下がるが、下がり幅は小さい。** 2 口座以上はほぼ変わらない(39.1 → 38.9%)。
- **失格する口座の総数はむしろ増える**(平均 3.92 → 4.05 口座・5 口座以上が失格する確率 34.4 → 37.2%)。口座の中の分散が減るため。
- **結果は「どの口座にどちらの組を割り当てたか」で決まる。** A 組(GBPJPY + EURJPY)を割り当てた口座は良くなり、B 組(AUDJPY + USDJPY)の口座は悪くなる。S2 の期待 +13% は、最大口座のトパーズが A 組になったためで、分けた効果ではない(S1 は −3%)。
- 2 組の月曜の系列の相関は 0.82。4 本が悪い 1 割の日は A 組 −80 bps・B 組 −82 bps で、どちらも同じだけ下げる。悪い月曜は円クロス全体が動く日なので、通貨を分けても逃げ場にならない。
- 過去は A 組の平均(+5.4 bps)が B 組(+3.6 bps)より高かったが、これを根拠に「全口座を A 組に寄せる」のは通貨の後からの選別になる(通貨を絞る形は Q231 ほかで不成立)。
- 実行前の読み(五分五分より下・同時に傷む度合いはあまり下がらず、口座の中の分散が減る分だけ失格が増える)は当たり。

## 4. 結論と提案
- 口座ごとに通貨を分ける形は採らない。**現行どおり(4 本を等分)。** EA・manifest・config は変えない。
- 月曜の集中による「同時に傷む」問題は、通貨の分け方では解けない。効くのは、これまでどおり (a) 月曜 1 回の負け方を小さくする形(2 つの縮小・SKEW の見送り・決済の切り替え)を次の段階の EA に入れること、(b) 月曜と重ならない水曜のロールを使える口座に入れること、(c) PC が止まったときの被害を抑えること。
- 11 月の改訂・新規口座への含意: なし(現行の 4 本等分を続ける)。
