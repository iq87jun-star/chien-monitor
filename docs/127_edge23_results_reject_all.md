## 2. H23d の解剖 — 本バッチ最大の知見(文献エッジの死亡診断書)

OpEx週効果(Stivers-Sun系: 米大型株はオプション満期週に高リターン)は**過去には本物だった**:

| 窓 | net | 頑健p | 解釈 |
|---|--:|--:|---|
| pre-2016(1990-2015, 312ヶ月) | **+130.9%** | **0.0165** | 文献の主張どおり実在 |
| 主窓(2016-2025, 120ヶ月) | **−5.5%** | 0.551 | 消滅どころか**月内ランダム週にp=0.95で負ける**(=月内で最悪級の週) |

プラセボ(同月内ランダム週・月1週ON保存)の平均が+38.5%なので、現行レジームのOpEx週は
株ドリフトの取り分すら取れていない。0DTE台頭・満期分散(週次オプション)でフローが月1回の
第3金曜に集中しなくなった構造変化と整合的。**「文献にある=今も使える」ではない**ことの実測例として、
E-Mon(同じ株カレンダー族で今も生存)との対比で記録価値が高い。

## 4. メタ結論 — 「全ての可能性を考慮したか」への最終回答

docs/126 §0 の棚卸しに本結果を重ねると:

| 方向 | 状態 |
|---|---|
| 価格(日足/H1, FX9+指数+金) | 16バッチで消尽(docs/80) |
| 新資産クラス(商品・債券先物) | edge19でREJECT・閉鎖(docs/107) |
| 新解像度(ティック/実行) | edge20で消化・執行は現行設定が最適(docs/109) |
| **ポジショニング(COT)** | **本バッチでREJECT・閉鎖**(週次百分位族・パラメータ再走禁止) |
| **満期カレンダー(OpEx)** | **本バッチでREJECT・閉鎖**(現行レジームで死亡を実測) |
| オーダーフロー/板・オプションIVサーフェス・センチメント調査 | **無償データが存在せず検定不能**(扉は開けられない) |
| 限月別基差 | 無償データ品質不足で検定不能 |
| 個別株CFD | ユーザーがFN/FTMOの取引可能銘柄を確認した場合のみ将来バッチ(唯一の残り札) |

∴ **入手可能なデータで開けられる扉は全て開けて検定し終えた**。「出尽くした」は
本バッチ実行前は「価格宇宙+再開条件2つで出尽くした」だったが、いまや
**「無償で入手可能な全データ源で出尽くした」**である。以後の探索再開条件(事前固定)は:
①有償データ(オプションIV・オーダーフロー等)への投資をユーザーが決めた時
②個別株CFDの取引可能銘柄集合をユーザーが確認した時
③年1回の生存確認で既存エッジが死んだ時(代替探索として)— の3つのみ。
