# docs/175: 運営参入の難易度評価 — 課題のランク付けと突破順序

日付: 2026-07-29
関連: docs/174(運営側収支モデル)
性質: 定性評価(数値は目安)。docs/174 が「経済面は成立するか」、本書は「実行は何が難しいか」。

---

## 1. 総合評価

**総合難易度: S(個人事業としては最高難度クラス)**。
ただし難しさの内訳は均一ではない。「技術・商品設計は易しく、法務・決済・集客が難しい」という
**逆三角形の構造**であり、自分の強み(EA研究資産)が活きる領域は難易度が低い側に偏っている。
→ フル自社運営に一足飛びせず、難易度の低い中間形態から段階的に登るのが合理的。

## 2. 課題ランク表(S=最難関 → C=金と手間で解決可能)

| ランク | 課題 | 何が難しいか | 費用目安 | 自分の現状での有利/不利 |
|---|---|---|---|---|
| **S** | ①法務・規制 | 日本居住者向けは金商法該当性・賭博罪該当性のグレーゾーン。海外法人(UAE/キプロス等)設立・維持が事実上前提。CFTC の MyForexFunds 閉鎖(2023)以降、規制強化は世界的トレンドで「今合法でも将来閉鎖」リスクが恒久的に残る | 弁護士+法人設立・維持で初年度 ¥500万〜1,500万 | **不利**。個人では解決不能。専門家依存かつ費用が先行 |
| **S** | ②決済インフラ | プロップはカード会社分類で高リスク業種(チャージバック多発)。国内アクワイアラはほぼ通らず、海外PSP でも審査落ち・凍結・保証金(rolling reserve 5〜10%)が常態。決済停止=即死 | 保証金として売上の5〜10%拘束+手数料5〜8% | **不利**。実績ゼロの新規法人は最も審査に落ちやすい |
| **A** | ③集客・信頼獲得 | 競合数百社のレッドオーシャン。新興ファームへの最大の不信は「本当に出金されるか」で、実績が無いほど広告費が嵩む(CAC ¥1.5万〜4万/購入)。アフィリエイト網の構築には報酬率競争(10〜25%)が必要 | 月¥100万〜(広告+アフィ報酬) | **不利〜中立**。攻略側の発信実績をメディア資産に転換できれば緩和可 |
| **A** | ④資本・キャッシュフロー | docs/174: retail中心なら初期 ¥785万で回るが、sharp比率を1%読み違えるだけで必要資本が ¥5,582万(s=3%)〜数億円に跳ねる。②の保証金拘束と重なると黒字倒産があり得る | 安全圏 ¥5,000万〜1億 | **不利**。資本余力は読み違え保険であり削れない |
| **A−** | ⑤アドバースセレクション管理 | sharp(系統的トレーダー)の検知・制御。損益分岐 s*=1.84%(対策なし)→3.78%(防衛あり)。取引パターン監視・整合性ルール・スケーリング制の設計と、紛争(失格クレーム)対応の両立が難しい | 監視ツール内製 or 月数十万 | **有利**。攻略側の手口(本リポ全体)を知り尽くしているのは業界でも稀な強み |
| **B** | ⑥テック・プラットフォーム | ホワイトレーベル(FPFX Tech / Match-Trade 等)で金で解決可能。MT4/5 新規ライセンスは実質困難で Match-Trader / cTrader / DXtrade 前提。ベンダーロックインと月額固定費が残る | 初期 ¥240万〜1,600万+月¥50万〜 | **中立**。選定眼はあるが特別な優位もない |
| **B** | ⑦運営オペレーション | KYC/AML、多言語サポート、失格判定の紛争処理、出金処理SLA。1人では回らず、最低2〜3名体制。判定の一貫性を欠くと SNS で炎上→③に跳ね返る | 人件費 月¥100万〜 | **中立**。ルール判定の設計自体は⑤の強みで補える |
| **C** | ⑧商品設計 | チャレンジルール・価格・スケーリング制の設計。業界標準の模倣から開始でき、本リポの研究資産(通過率MC・ガード設計・規約の穴の知見)がそのまま設計根拠になる | ほぼゼロ | **大きく有利**。docs/174 のモデルで価格×ルール×採算を事前検証可能 |

## 3. 構造のまとめ

- **死因になり得るのは S の2つ(法務・決済)**。どちらも「自分の能力で解けない・金と専門家で緩和するしかない」型。
- **A 群(集客・資本・sharp管理)は経営の恒常課題**。うち⑤だけは自分の研究資産で明確に有利。
- **B/C 群は金で買える**。難易度表の下半分は参入障壁ではない。

## 4. 段階別の現実的ルート(難易度昇順)

| 段階 | 形態 | 難易度 | 塞がる課題 | 目安 |
|---|---|---|---|---|
| 0 | 既存プロップのアフィリエイト/IB | C | ①②④⑥⑦が不要 | 初期費用ほぼゼロ。攻略発信と相性良 |
| 1 | EA販売・攻略情報の商品化 | C+ | 同上(投資助言該当性のみ法務確認) | 本リポ資産の直接収益化 |
| 2 | 既存ファームとのホワイトレーベル提携(自ブランドのチャレンジ) | B+ | ②⑥⑦をパートナーが負担。①も部分緩和 | 初期 ¥300万〜 |
| 3 | フル自社運営 | S | 全課題を自己負担 | 初期 ¥3,000万〜+①②の恒久リスク |

**結論**: フル運営(段階3)は S 級で、法務・決済という自力で解けない2課題が先頭に立つ。
一方、段階0〜2 は難易度 C〜B+ で、自分の最大の強み(⑤⑧)を活かしながら
運営側のデータ(実際の顧客分布=sharp比率の実測)を得られる。
**docs/174 の最重要未知数 s を実測できるのは段階2以降**であり、
段階2までを踏んでから3を判断するのが期待値的に正しい順序。

## 5. 注意

- 費用目安は 2026年時点の業界相場感による概算。見積もりは FPFX Tech / Match-Trade 等への直接照会が必要。
- ①の法的評価は本書の範囲外(弁護士マター)。「S=最難関」という難易度評価のみを行い、適法性の結論は出していない。
