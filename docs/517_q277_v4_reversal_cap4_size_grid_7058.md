- 原因(追加の確認): 失格した開始週は、すべて 2020 年 2〜3 月に失格している。上限 4 本の逆張りは、2019-07 から 2020-03-19 までに累積 −29.4%(1 倍あたり)落ち込んだ。0.375 倍でも −11% で、口座の枠(−9%)を超える。月曜の枠の縮小は逆張りには掛からない。
- 第 1 段階(いまの状態)で改善するのは、口座が +5.4% から始まり、中央 5〜8 週で決着するため。長く持つほど、2020 年 3 月のような局面に当たる。

## 6. 判定
- **変更候補 4 / 5**(× 0.0625〜0.15625 が連続して通過・× 0.1875 は現行どおり)。**提案に進める条件(連続 3 つ以上)を満たす。**
- 改善の大きさ: 2021-08 以降の開始で到達 96.2 → 99〜100%(失格 0 → 0〜1%)、2016-11〜2020-07 の開始で到達 67.9 → 74〜79%・失格 26.0 → 18〜23%。

## 7. 読み方
1. **FTMO 7058 のいまの段階に限れば、小さい逆張り(0.375〜0.94 倍)は幅を持って改善する。** Q276 の 1 点だけの通過ではなかった。
2. **改善は「すぐ決着する口座」だから起きている。** 逆張りは平均では稼ぐが、2020 年 3 月のように大きく長く負ける局面がある(1 倍あたり −29%)。目標まで 4.6% で、中央 5 週で終わる口座は、その局面に当たる前に抜けやすい。
3. **次の段階には持ち込めない。** 開始 0 から +5% を狙う段階では、月曜の枠だけなら失格 0% のところに、逆張りが 23〜25% の失格を足す。合格したら外す前提になる。
4. 対象の口座は「Q276 で通った口座」を後から選んだもの。大きさの幅は確かめたが、別の口座での再現(同じ作りの FTMO 0397 など)は見ていない。

## 8. 限界
- Q276 と同じ: 逆張りは日足の近似(その日の最悪を月曜の枠の最悪と同時と置く)。発動した日の損失はガード幅の 1.1 倍。夜の指数・GER40 ブレイクは入れていない。
- 次の段階の設定は、雛形(v1.25)の方針に基づく近似。
- 2021-08 以降の改善は 3〜4 ポイントで、開始週が重なり合う 210 本の割合。差は大きくない。
- 逆張りを実口座で 9 ペア動かした記録は、いまの EA の系統には無い(パールの USDJPY 1 本だけ)。
