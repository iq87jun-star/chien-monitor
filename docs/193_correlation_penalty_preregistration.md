# 193.【事前登録】相関ペナルティ付き選抜 — 口座横断の同時失格リスクを事前に下げる

> 2026-09-01作成。docs/185 §5に適合する**費用ゼロの研究**。
> 本docのルールは`research/correlation_penalty_wf.py`の実行**前**に凍結した。実行後の変更禁止。

## 1. 動機 — サーキットブレーカーは事後にしか効かない

docs/185 §2は「30日以内に2口座以上が失格したら全トラック凍結」というサーキットブレーカーを
定めた。これは**発火してから**効く仕組みである。一方、同じdocs/185 §2は発火の事前確率が
高い理由も明記している:

> FX系口座間の実測相関0.5〜0.85(2026-08計測)では、複数同時失格は「個別の不運」ではなく
> 共通要因(円急騰・リスクオフ・レジーム転換)の顕在化とみなすのが正しい事前確率

さらに現状、**Mon GBPJPY は A案・B案・C案・Instant・速攻プロの最大5口座で並走**している
(docs/181 §3が「FTMO 3口座間で重複」として記録し、規約上はクリアと判定した件)。
規約上は問題なくとも、**ある月曜の朝に5口座が同時に傷つく**というポートフォリオ構造は残る。

**本研究は、選抜規則そのものに重複ペナルティを1項加えることで、この構造を事前に緩和できるかを
測る。** 実装コストは極小で、次回の再スクリーニング(C案9/30・非FX 10/31)から適用できる。

## 2. ルール(実行前固定)

口座Aを先に選抜済みとし、口座Bの選抜時にスコアを調整する:

```
score_adj(cell) = score(cell) × ( 1 − λ · max(0, ρ_A(cell)) )
```

- `ρ_A(cell)` = 当該セルの**選抜窓**日次リターンと、その時点の**口座A合成**(倍率抜き)との相関
- `max(0, ·)` により負相関は罰しない(むしろ望ましいため、加点もしない=中立)
- λ=1.0 かつ ρ=1.0 なら score_adj=0 となり事実上除外される

### アーム(4本)

| アーム | 内容 |
|---|---|
| `LAM0` | λ=0。**現行規則そのもの**(ベースライン) |
| `EXCL` | λ=0 + **口座Aが採用しているセルそのものを候補から除外**(重複の完全禁止のみ) |
| `LAM05` | λ=0.5 |
| `LAM10` | λ=1.0 |

- 口座Aの選抜規則は全アームで`SEL12`(docs/174規則)に固定し、変更しない。
  変えるのは口座B側だけである(2口座目を買うときに何をすべきかが実務上の問い)。
- 銘柄1/ファミリー2制約・逆ボラ加重cap40%・Top-4・倍率規則は**全アームで現行のまま**。
  加えるのはペナルティ1項だけである。

## 4. ペア同時MC(本研究の中核・実行前固定)

2口座の**クロス相関を保存**するため、両口座に**同一のブートストラップ・ブロック**を適用する
(独立に2回引くと相関がゼロになり、測りたいものが消える):

- 5日ブロック・シード7・1万パス・FTMO 2-Step(P1+10%→P2+5%)とFN(P1+8%→P2+5%)の両土俵
- 静的−10%・EAガード−4%クリップ
- 各パスで両口座の**失格日**を記録する

出力する確率:

| 指標 | 定義 |
|---|---|
| `P_both_fail` | 両口座とも失格 |
| **`P_circuit_breaker`** | **両口座が失格し、かつ失格日の差が30日以内**(= docs/185 §2の発火条件) |
| `P_any_funded` | 少なくとも1口座が資金化 |
| `E_funded_accounts` | 資金化口座数の期待値(0〜2) |

## 5. 判定基準(実行前固定・後知恵の禁止)

| 結果 | 判定 |
|---|---|
| あるλで **`P_circuit_breaker` が LAM0 比で相対20%以上低下し、かつ `P_any_funded` が低下しない** | **採用候補**。次回再スクリーニング(C案9/30・非FX 10/31)から選抜規則に追加 |
| `P_circuit_breaker` は下がるが `P_any_funded` も下がる | **トレードオフとして両方を併記し、ユーザー決定に付す**(採否を当方で決めない) |
| どちらも改善しない | 不採用。選抜規則は現行のまま |

- 採用候補となった場合でも、**稼働中の口座には適用しない**(docs/174 §1・docs/179 §4)。
  適用先は期限到来時の再スクリーニングのみ。
- λの値は {0, 0.5, 1.0} の3点のみ評価する。**細かいグリッドで最良λを探索しない** —
  それはdocs/184で問題になった選抜ノイズを規則設計の階層で再生産する行為である。

## 6. 承知している限界

- 本研究は「2口座」の単純化であり、実際は8口座が相互に相関している。2口座で効果が
  出なければ8口座でも出ないと考えるのが自然だが、逆は必ずしも成立しない。
- ρの推定は選抜窓(12ヶ月)の日次相関であり、**危機時に相関が1へ収束する**性質
  (docs/185 §2が言う共通要因)は捉えられない。したがって本ペナルティは
  平常時の分散を改善するものであって、**サーキットブレーカーを不要にするものではない**。

# 8.【結果 2026-09-01】採用候補 — 3アームとも判定基準を満たした

> `research/results/correlation_penalty_wf.json`・シード7・凍結窓2016-01-01..2026-08-31
> (docs/192の窓truncateバグ修正後のデータ)。

## 8.1 結論(先に書く)

**docs/193 §5の採用基準(`P_circuit_breaker`が相対20%以上低下 かつ `P_any_funded`が低下しない)を
`EXCL`・`LAM05`・`LAM10` の3アームすべてが満たした。** 本セッションで唯一の明確な採用候補である。

| アーム | ρ(日次) | 平均重複セル | **CB発火** | LAM0比 | いずれか資金化 | E[資金化口座数] |
|---|--:|--:|--:|--:|--:|--:|
| `LAM0`(ペナルティなし) | **1.000** | 3.97 | **20.85%** | — | 72.0% | 1.440 |
| `EXCL`(重複セル禁止のみ) | 0.552 | 0.00 | 4.77% | **−77.1%** | 83.0% | 1.423 |
| `LAM05`(λ=0.5) | 0.732 | 2.08 | 5.71% | **−72.6%** | 85.5% | 1.511 |
| **`LAM10`(λ=1.0)** | **0.368** | 0.79 | **2.82%** | **−86.5%** | **86.5%** | 1.423 |

(FTMO 10/5。FN 8/5でも同順・同水準: LAM10のCB発火2.69%・いずれか資金化90.1%)

**同時失格を大幅に減らしながら、資金化の期待値をまったく失っていない。**
E[資金化口座数]は全アームで1.42〜1.51とほぼ不変である一方、CB発火は20.85%→2.82%まで下がる。

## 8.2 なぜコストなしで効くのか

2口座の資金化は**どちらか一方でも成功すればよい**(報酬は口座ごとに独立に発生する)。
一方で失格は**共通要因で同時に起きる**。したがって:

- 相関を下げても E[資金化口座数] は落ちない(各口座の単体成功率は保たれる)
- 相関を下げると P(両方失格) は急速に落ちる(20.8% → 6.3%)

**分散の利益がほぼ一方通行で乗る構造**であり、docs/187 §2.2で見た
「分散はプロップにおいて攻めの変数」という性質の、ポートフォリオ層での現れである。

## 8.3 ⚠ ベースラインが極端であることの明示(結果の割り引き)

`LAM0`は口座Aと**完全に同一の規則**であるため ρ=1.000 となり、
「同じ戦略を2口座に複製した場合」を表す。これは現実のブックより極端である
(実測は docs/182 §1 の B-C 0.85 / C-D 0.79、docs/187の SEL12-SEL6 0.65 等)。
したがって **−86.5% という数字をそのまま現行ブックへの改善量と読んではいけない。**

現行ブックに近い水準からの改善量として、ρ=0.732(≈現行B-C 0.85)の`LAM05`を基準にすると:

| | CB発火 | いずれか資金化 |
|---|--:|--:|
| LAM05(ρ=0.732) | 5.71% | 85.5% |
| **LAM10(ρ=0.368)** | **2.82%(−50.6%)** | **86.5%(+1.0pt)** |

→ **現実的な改善量の目安は「サーキットブレーカー発火をおよそ半減」**である。
これでも十分に大きく、かつ資金化を犠牲にしていない。

## 8.4 読んではいけない数字

`LAM05`の口座B単体成績(OOS年率 **22.20%**・シャープ1.30)は他アーム(12.4〜13.0%)より
突出している。**これはノイズであり、λ=0.5を選ぶ理由にしてはいけない。**
本実験の主指標は §5で事前に固定した `P_circuit_breaker` と `P_any_funded` の2つであり、
単体成績は評価軸に含めていない。結果を見てから軸を足すのは後知恵である。

## 8.5 帰結(docs/193 §5の事前登録に従う)

- **採用候補として記録する。適用先は期限到来時の再スクリーニングのみ**
  (C案9/30・非FX 10/31・Instant 10/31)。**稼働中の8口座には適用しない**
  (docs/174 §1・docs/179 §4)。
- 推奨は **λ=1.0(`LAM10`)**: CB発火が最小・いずれか資金化が最大・
  ρ=0.368は現行ブックのどのペアより低い。
- 実装は極小である(選抜スコアに1項掛けるだけ・母集団も制約も加重規則も不変)。
  10月の再スクリーニング用スクリプトに、**基準となる「既存配備ブック合成」の定義とともに**
  事前登録する必要がある(本実験の口座Aに相当するものを、実運用では
  「その時点で稼働中の全口座の合成」とするか「同一業者内の口座のみ」とするかは未決定)。

## 8.6 限界(docs/193 §6の再掲+実測後の追記)

1. **2口座への単純化。** 実際は8口座が相互に相関している。8口座版では
   「何を基準に相関を測るか」(全口座合成か・業者内か・同一土俵か)の設計が必要になる。
2. **危機時の相関収斂を捉えていない。** ρは平常時の12ヶ月推定であり、
   docs/185 §2が言う共通要因(円急騰・リスクオフ)の顕在化時には相関は1へ寄る。
   **本ペナルティはサーキットブレーカーを不要にするものではない。** 両方が必要である。
3. λは {0, 0.5, 1.0} の3点のみ評価した(§5の事前登録通り)。
   細かいグリッドで最良λを探索していない — それ自体が選抜ノイズになるため。
