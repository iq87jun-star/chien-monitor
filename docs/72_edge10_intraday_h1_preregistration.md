# 72.【事前登録】edge10 — 10年H1 日中構造エッジ探索（ADOPT を狙える唯一の高検出力領域）

> **位置づけ**: 新規EAの母体探索。本docは「数字を覗く前」に仮説・資産・ゲート・Bonferroni試行数・
> 採否規則を固定する**事前登録**。結果は別doc（07/13/18の流儀＝Colab実出力JSONの転記）で報告する。
> 事後解釈で仮説を増やさない（docs/15 の捏造事件以降の規律）。

## 0. 動機（なぜ日中H1か）
過去のLEAD群（v4/E5/E-Mon/S-Jul）が ADOPT に届かない主因は **検出力不足（G3 Bonferroni / G5 JK 未達）**。
- 日足DOW=年~520標本、月次季節性=年~12標本 → Bonferroniを抜けない。
- **H1日中**=10年で数万本、各「時刻×条件」で数百ショット → **検出力が桁違い**。
- かつ最良データ（Dukascopy 10年H1）は edge7 で 2.76年しか回せず**明示的に保留**のまま。

→ **新エッジが本当に ADOPT に到達し得る唯一の白地**。ここを正しく1回叩く。

## 1. 資産・データ（固定）
- **EURJPY / GBPJPY / USDJPY**（Dukascopy H1・実bid/ask・spread列、2016-01-01〜2025-12-31）。
- ローダ・コスト・ATRストップは既存 `colab_v7_confidence.py` の `load_pair / shot_returns` 規約を流用。
- 統計関数は `colab_validate_all_v7standard.py` の `perm_p / jackknife / walkforward / block_bootstrap / p95_maxdd / grade` を**逐語流用**（再実装しない＝バグと恣意を排除）。

## 2. 事前登録した仮説（これ以外は ADOPT 主張に使わない）
経済的合理性のある**確認的仮説のみ**を少数登録（Bonferroni試行数 N を小さく保つ）。各仮説は
「1ショット＝建値→Hホールド→足内SL」の per-trade pips 系列を3ペアでプール集計する。

| ID | 仮説（経済的根拠） | エントリ | 方向 | ホールド |
|---|---|---|---|---|
| **H1_gapfade6** | 週末ギャップ回帰：月曜窓のオーバーシュートは部分回帰する | 月曜最初のH1足 | gap符号の**逆**(fade) | 6h |
| **H2_gapfadeEOD** | 同上・1日で回帰 | 月曜最初のH1足 | gap符号の逆 | 24h |
| **H3_tokyofix** | 東京仲値フロー：仲値(09:55 JST=00:55 UTC)に向けクロス上昇 | 23:00 UTC | LONG | 4h |
| **H4_londonfix** | ロンドン16:00fixのリバランス・フロー | 14:00 UTC | LONG | 4h |

- **確認的試行数 N_conf = 4** → **G3 Bonferroni α = 0.05/4 = 0.0125**。
- 方向（LONG/fade）は上表で**事前固定**。後から逆向きを採用しない。

### 2.1 探索的スキャン（参考のみ・ADOPT判定に使わない）
時刻 h∈0..23 × 方向{L,S} の無条件ドリフトのヒートマップを併記。Bonferroni は 48 試行で評価し、
**「探索」ラベルを明示**。ここで光った点は「次サイクルの事前登録候補」に回す（今回は採用しない）。

## 3. 採点（v7基準と同一の9ゲート）
`grade()` をそのまま使用。ADOPT 条件は G3,G4,G5,G6,G7,G8,G9 全通過。
- **G3** perm_p < 0.0125（上記Bonferroni, sign-flip順列 n=4000, seed=13）
- **G4 プラセボ**: 各仮説につき「同設計で対象時刻/曜日をずらすと有意性が消える」ことを示す
  （H1/H2=gap符号をシャッフルして消滅、H3/H4=±2時間ずらしで消滅）
- **G5** 年次JK 最大p ≤ 0.10
- **G6** IS/OOS（前後半）両正
- **G7** ウォークフォワード ≥ 4/5
- **G8** 2×コストで net>0
- **G9** ブロックブートストラップ p95 maxDD ≥ −10%（予算0.6%相当）

## 4. 分散価値の要件（採用の追加条件）
新エッジは**既存v7（月曜LONG）と低相関**でなければポートフォリオ価値が無い。
- 週次集計リターンで v7 月曜系列との相関 ρ を測定。
- **|ρ| < 0.5** を「真の分散ショット」、0.5〜0.8 を「条件付き採用」、>0.8 を「v7の言い換え＝不採用」とする。
- 特に H1/H2(週末ギャップ) は月曜に発火するため**v7との相関を最重要チェック**（同一現象の可能性を排除）。

## 5. 採否規則（事前固定）
- **ADOPT (v7同格)**: 9ゲート全通過 かつ |ρ|<0.8 → `mql5/` でEA化（次doc）。
- **STRONG-LEAD**: G4/G6/G7/G8 通過・G3かG5のみ未達 → デモ前進検証へ（EA化は保留）。
- **REJECT**: 上記未満 → docへ「否定」を記録し、探索的スキャンの上位を次サイクルへ。
- 数字は **Colab実出力JSONのみ**を転記。スクリーンは `save_result("edge10_intraday_h1", ...)` で
  入力CSVのSHA-256・環境バージョン付きで保存（手転記しない）。

## 6. 失敗時の備え（事前の想定）
- 全滅もあり得る（過去の日中=edge7は2.76yで否定的）。その場合は**正直にREJECT**を記録し、
  次は §2.1 探索上位 or 別白地（FX年度末季節性／金利→JPYリード）へ。
- 「Bonferroni未達だが単体p<0.05」はSTRONG-LEAD止まり＝**数字を盛らない**。
