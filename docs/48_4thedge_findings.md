## 0. 一行結論

**docs/47 で事前登録した未踏 intraday 3構造（C1 インパルス・フェード / C2 圧縮ブレイク /
C3 アジア→ロンドン反転）は、予備 Yahoo H1 2年で 3つとも明確に棄却。プールで負・ペアPF>1 ほぼ無し・
プラセボでも崩壊。第4の独立エッジは現データに見つからなかった。** → **Portfolio3（v7+v4+E5）が現時点の最終形**。

`boot_p(mean≤0)` = 移動ブロック・ブートストラップ（自己相関頑健）で平均リターンが0以下となる確率。
**3候補とも boot_p ≈ 1.0**＝「正のエッジ」とは逆に「有意に負」。G3（perm_p < α_family=0.0167）は論外。

## 2. 各候補の正直な評価

### C1 インパルス・フェード（足内平均回帰）→ コスト破壊・方向エッジ無し
- 純 **−430.6%** / 勝率 28.5% / **0/9ペア**。プラセボ＝**継続(順張り)も −432.9%**（コスト正規控除）。
- **フェードも継続も大敗**＝方向にエッジが無く、**20,044回(2年・~4.5回/日/ペア)の往復コストとSL(2.0ATR)
  到達が損益を支配**しているだけ。「2×中央値の足は巻き戻す/続く」という単純トリガに価値は無い。
- v4(日足8日MR)が機能するのと矛盾しない：**平均回帰は日足解像度では残るが、H1の単発インパルスでは
  コストに食われて消える**。edge7(セッション無条件ドリフト棄却)と同じ「足内の単純構造は死ぬ」描像。

### C2 圧縮ブレイク（ロンドン始値・条件付き）→ サンプル希少・プールで負
- 純 −15.0% / n=230（圧縮＋ブレイク両条件で希少）。**ペアPF>1 は USDJPY(1.63)・EURJPY(2.00) の2件のみ**だが
  各 n≈25 と過少で、v3a(無条件ORB)棄却・docs/14(円以外に曜日エッジ無し)と整合する範囲のノイズ。
- 「圧縮を条件にすればORBが蘇る」という仮説は**支持されず**。JPY2本の弱陽性は10年で要再検だが優先度低。

### C3 アジア→ロンドン反転 → 反転も継続も負
- 純 −45.2% / **0/9** / 反転 boot_p 0.998。プラセボ＝**継続も −69.3%**＝アジアの過大変位は
  ロンドンで反転も継続もしない（方向情報なし、コスト負け）。edge7(無条件ドリフト)に条件を足しても復活せず。

## 3. メタ結論（v1–v9 + E1–6 + edge2–9 + 本探索の通算）

本プロジェクトが**棄却**してきたもの（再掲＋今回）:
- 価格方向予測（トレンド/MR/ORB/極値/TSMOM方向）、曜日(非JPY)、ターン・オブ・マンス、
  リードラグ（株→円・金→CHF）、多資産MR、ボラ条件トレンド、相対強さ回転、セッション無条件ドリフト、
  **そして今回：足内インパルスMR・圧縮ブレイク・前セッション反転**。
- **生き残り = v7/v9（円月曜）・v4（日足k≥4 MR）・E5（多資産月次トレンド）の3つだけ**。
- **∴ 「現データに第4の独立エッジは無い」という描像が、足内解像度の条件付き構造でも再確認された。**
  これは失敗ではなく、**過剰最適化を拒否し続けた規律の当然の帰結**（docs/14 と同じ誠実な NEGATIVE）。

## 4. 推奨（誠実な選択）

1. **Portfolio3（v7+v4+E5）を最終形とする**のが、現データで支持される最も誠実な結論。
   3本は互いに低/負相関（v7⇄v4 −0.13 / v7⇄E5 −0.18 / v4⇄E5 −0.05）で、同攻めの2本化比5年失格
   31.5%→1.0%（docs/44）＝**分散は既に十分**。無理に4本目を足すと過剰最適化リスクのみ増える。
2. **どうしても10年で確定したい場合**のみ、`research/colab_edge10_4thedge_10y.py` を Drive(10年H1 Dukascopy)で
   実行 → 本予備の NEGATIVE を10年・厳密 perm + v7/v4/E5相関で**正式に確定**する（予備が決定的に負なので
   優先度は低い。"NEGATIVE を記録に残す"価値のためのオプション）。
3. **収益拡大は『4本目探索』でなく Portfolio3 のサイズ最適化＋デモ前進検証**（docs/29/44）で行うのが
   期待値最大。新エッジ探索の限界効用は、本探索群が示す通り低い。
