# 成果物③ 検証レポート（モンテカルロ通過確率 ＋ 実価格BTの設計 ＋ 過剰最適化点検）

> **重要・正直な前提**: 本サンドボックスでは MT5 ストラテジーテスターと実ティック価格データに直接アクセスできない。
> そこで本レポートは2部構成とする:
> - **A. チャレンジ動態モンテカルロ**（実施済み・実数値）: EAのリスクガードとコストを織り込み、想定エッジ別に
>   「日次/最大DDを一度も割らずに +8% へ到達できる確率」を50,000回×シナリオで推計。
> - **B. 実価格バックテスト/ウォークフォワードの設計**（手順提供）: ユーザーが MT5 で実行するための
>   イン/アウトオブサンプル分割・WFA・合否判定基準を定義。
>
> **モンテカルロはライブ約定を保証しない。** これは「リスク制御が機能するか」と「エッジ依存の通過確率」を
> 評価する確率実験であり、実ヒストリカルの値動き再現ではない。

### A-2. 解釈（合否と限界の正直な提示）

1. **設計原則#1「退場しない」は完全達成**: 全シナリオ・全勝率で **日次DD失格＝0.000%、最大DD失格＝0.000%**。
   テール損失（3%の損失トレードが2倍化）を入れても、固定%リスク（0.4%）＋当日−4%ストップ＋−8%フロアの
   多層ガードにより、**規則ラインへの到達は構造的に起こらない**。失敗は常に「時間切れ（到達できない）」であって
   「失格（退場）」ではない。これは「割れない経路」を最優先する本設計の核心的成果。

2. **通過はエッジ依存（誇張しない）**: 「必ず通る手法」は存在しない。現実コスト下で
   **勝率45%以上(RR1.8)なら通過率80%超**、勝率50%で約98%。勝率40%（E[R]=+0.12）でも約39%は通過するが、
   過半は時間切れ。→ EAの実エッジが勝率45%以上/RR1.8 を満たすかが鍵で、それは**実価格BT（B章）で要検証**。

3. **コストの効き（楽観BT禁止の実証）**: 同じエッジでも $105/lot の保守コストでは通過率が激減
   （勝率50%: 97.8% → 21.9%）。**固定額手数料はロット数で効く**ため、SLを28→60pipsに広げてロットを
   減らす（スイング化）と回復（勝率50%: 21.9% → 81.5%）。
   → **実運用前に必ず実際の往復コストを確認**し、高コストなら `InpMinStopPips` を上げてスイング寄りに調整すべき。
   なお FundedNext FX の実コストは概ね $7前後/lot で、その場合は28pips設定で問題ない。

4. **Phase2(+5%)**: 目標が緩い分、同条件で通過確率は Phase1 以上。Phase1 を満たすエッジなら Phase2 も同等以上に通過見込み。

### A-3. モンテカルロのモデル限界

- 取引結果を勝率×固定RRのベルヌーイで近似（実際は利益が連続分布・部分利確・トレール変動）。
- 連敗のクラスタリング（自己相関）は単純化。実相場のレジーム持続はこれより不利にも有利にも振れる。
- スリッページ/ギャップは p=3%・2倍損失の単純テール。重大イベントの飛びはニュースフィルタで別途緩和を想定。
- → だからこそ「失格0%」は**ガードの構造的帰結**として頑健だが、「通過率」は実エッジ次第であり B章で確かめる必要がある。
- A章の追補（2フェーズ連続＋連敗自己相関ストレス）は次セクション A' を参照。

## B. 実価格バックテスト ＆ ウォークフォワードの設計（MT5で実施）

### B-1. 環境
- MT5 ストラテジーテスター、`Every tick based on real ticks`（最高精度）。
- 銘柄: EURUSD。手数料・スワップを口座条件に合わせて設定（**Commissionをテスター設定に必ず入力**）。
- スプレッド: `Current` ではなく実測可変、または保守的固定（2pips相当）でストレス。
- 初期証拠金 100,000、レバレッジは口座条件に合わせる。

### B-2. 期間分割（イン/アウト＋ウォークフォワード）
直近3年を6四半期ブロックに分割し、アンカー付きWFAで評価:

| 区分 | 用途 |
|---|---|
| 2023 H1–H2 | In-Sample（IS）#1 で初期パラメータ確認 |
| 2024 H1 | Out-of-Sample（OOS）#1 |
| 2024 H2 | OOS #2 |
| 2025 H1 | OOS #3 |
| 2025 H2 | OOS #4 |
| 2026 直近 | 最終フォワード確認 |

- **ウォークフォワード効率 (WFE) = OOS純益 / IS純益**。0.5 未満なら過剰最適化を疑う。
- 各OOSブロック単独でも「日次−5%/最大−10%を一度も割らないか」を**最優先で確認**。

### B-3. 合否判定基準（このEAに対する明確なゴール）
各OOS期間について以下を**すべて**満たせば「審査適合」と判定:
1. 期間中、**日次DD・最大DDの規則ラインに一度も触れない**（EAガードが−4%/−8%で先に作動していること）。
2. シミュレーション上、**+8%（Phase1）に到達**し、その後 +5%（Phase2）も別途到達できる。
3. 勝率 ≥ 45% または 期待値 ≥ +0.20R（A章の通過率閾値に整合）。
4. プロフィットファクタ ≥ 1.2、最大連敗 × 0.4% < 4%（＝連敗でも日次ストップに先に守られる）。

### B-4. 実行手順（要約）
1. `mql5/FundedNext_Stellar_EA.mq5` を MetaEditor でコンパイル（エラー0）。
2. `mql5/presets/EURUSD_default.set` を読み込み。
3. 上記ブロックごとにテスト→レポート保存。`Drawdown`・`Balance/Equity`曲線・取引履歴を確認。
4. 必要なら最適化は**IS区間のみ**で行い、OOSは触らない（カーブフィット防止）。最適化対象は最大3–4パラメータに限定。

## C. 過剰最適化（カーブフィット）自己点検

| 点検項目 | 状態 | 評価 |
|---|---|---|
| 自由パラメータ数（戦略コア） | EMA50/200, EMA20, RSI14, ATR14, RR1.8 ＝ ほぼ標準値・少数 | 良。マジックナンバー的な微調整値を持たない |
| パラメータの素性 | すべて一般的なテクニカル定番値（恣意的でない） | 良 |
| アウトオブサンプル劣化 | B章WFAで WFE≥0.5 を要確認（未実施） | **要検証** |
| サンプル数 | 1日最大3回・数十回/月。OOS各期で最低30トレード以上を確保すること | 注意 |
| ガードのロバスト性 | エッジが負(−0.02R)でも失格0%（A章） | 非常に良 |
| データスヌーピング | 過去個人戦略を排除し白紙設計。曜日/日付アノマリー不使用 | 良 |

**結論（正直な総括）**:
- **「退場しない」という第一目標は、モンテカルロ上で全シナリオ失格率0%として実証された**。これはエッジに依存しないガードの構造的成果。
- **「+8%通過」はエッジ依存**。現実コスト・勝率45%/RR1.8 以上なら高確率（80%+）で通過見込みだが、**その実エッジは B章の実価格WFAで確認するまで保証できない**。
- 推奨運用フロー: ①実価格WFAでエッジ閾値クリアを確認 → ②デモ/小ロットで前進検証 → ③本番チャレンジ。コストが高い口座なら `InpMinStopPips` を上げてスイング寄りに。

> 免責: 本検証はシミュレーションであり、将来の成績・ライブ約定・スリッページ・約定拒否を保証しない。
> リスクを誇張も過小評価もせず、上記の通り「ガードは堅牢／通過はエッジ依存」と報告する。
