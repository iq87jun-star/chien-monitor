## 2. 相関フィルタ(実行前に計算・凍結)

- 尺度: 日足クローズ対数近似リターンの相関。**全期間(2016-01-01..2026-07-29)と直近12ヶ月の
  両方**で、採用13銘柄それぞれとのρを計算し、max(|ρ|全期間, |ρ|12m) の最大値で判定。
- **閾値: max|ρ| < 0.55 で通過**。

- 0.53と0.63の間に明確なギャップがあり、**「低相関」の実体は暗号資産クラスのみ**。
  FX・指数の未採用銘柄は全て採用銘柄の親戚(同一通貨・同一地域指数)で要件を満たさない。
- 閾値0.55はこのギャップ内に置いた(0.40では12mのBTC/ETHすら落ち、ユニバースが空になる)。

## 4. セル母集団(構築式はB案と同一・新しい型は追加しない)

- 暗号資産クラスに適用可能な既存ファミリーは**Hold(連続保有)とTSMOM(月次E5型)のみ**
  (docs/174 §2のクラス域: Mon=FX円クロス+指数の場中アノマリー、v4=FXコスト模型のため対象外)。
- セル: 生存銘柄 × {Hold, TSMOM} = 最大14セル。構築式は`recentfit_screen.py`の
  `hold_cell`/`tsmom_cell`をそのまま使用。
- **コスト上乗せ(基準式からの保守的変更・唯一の差分)**: 基準式の月初摩擦5bpに対し、
  本トラックは**月初摩擦 = max(5bp, 銘柄別想定コスト)**(BTC 10bp/ETH 15bp/§3の表)。
  アルトの広いスプレッドを5bpで甘く見ない事前措置。
