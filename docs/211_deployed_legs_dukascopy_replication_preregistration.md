## 4.3 読み

1. **Mon(月曜 open→open)と Hold(終値)はデータ源に依存しない。** 現ブックの重みの大半(Mon 55〜75%)はこの上に乗っている。
2. **v4 と RSI2 は日中の高値/安値・バンド接触・RSI 閾値で建てるため、日足の H/L と日付境界が違うと別の取引列になる**(ρ日 ≈ 0.1)。
   累積の符号が窓によって逆転する(v4 GBPJPY +13.8 vs −1.4)。つまり **v4 の選抜スコア(直近 mean/std)はデータ源のノイズを含む**。
   これは「v4 が効かない」ではなく「Yahoo の日足で見た v4 の成績を、ブローカーの足で同じ数字だと思ってはいけない」という意味。
3. 口座合成は D案・C案・速攻プロが再現、A案が部分再現(RSI2 2 レグ = 40% の重み)。**A案の RF5 は 5 レグ中 2 レグが源依存**であり、
   8 月の −1.73% と合わせて 9 月末の見直し優先度が最も高い。
4. 実際の EA は**ブローカーの MT5 足**で動くので、第三のソースが本命。

## 4.4 提案(実行はユーザー判断)

- **ユーザー側**: MT5 から D1 履歴を CSV 出力(GBPJPY / USDJPY / NZDUSD / AUDUSD / GBPUSD、2024-01〜、各口座のブローカー)。
  これで v4/RSI2 の「ブローカー足での成績」を出し、選抜スコアをブローカー足で再計算できる(docs/184 の 9 月末再スクリーニングに間に合う)。
- **規則への反映案**(9 月末の再スクリーニング時に検討): v4/RSI2 レグは Yahoo と Dukascopy の**両方で cum6>0** を満たすものだけ採用(二重ソース条件)。
  Mon/Hold には不要。
