# 35. 比率最適化のスコープ（正直な整理）— 運用は最適化済み／突破は未最適化

> ユーザー質問「E5とv7の比率は最適化されているか」への正直な回答。

## 0. 結論
- **運用（失格率最小）の比率 = 最適化済み**: docs/32 で Drive10年・各目標DDについて比率 0/15/25/35/50% を
  スイープし、**65:35 が 5年累積失格 最小**（かつ高Calmar）を確認済み。
- **審査突破（最速・審査中失格最小）の比率 = 未最適化**: 倍率1.5〜3.5の突破表は **65:35を固定で流用**しただけ。
  突破専用には比率を振っていない。下記スイープで「突破は別の比率が速い」ことが判明。

## 1. 審査突破の比率スイープ（Phase1 +8%中央到達月数 / 局所指標）
| 比率 v7:E5 | 倍率2.5 P1中央 | 倍率1.5 P1中央 | 傾向 |
|---|--:|--:|---|
| 100:0(v7単体) | 5ヶ月 | 10ヶ月 | 遅い |
| 75:25 | 4ヶ月 | 7ヶ月 | |
| 65:35（現行採用） | 3ヶ月 | 6ヶ月 | |
| 50:50 | 3ヶ月 | 4ヶ月 | **速い** |

- **突破"速度"は E5比率が高いほど速い**（E5がドリフトを足すため）。純速度なら 50:50 以上が有利。
- ⇒ **突破の最適比率は 65:35 ではなく、より E5 寄り**（速度目的なら）。65:35 は速度では準最適。

## 2. ただし2つの重大な留保
1. **上記スイープは local 34ヶ月（相関+0.07）の局所指標**で、審査中失格の絶対値は不正確。
   Drive10年（相関−0.17）では E5寄りでも失格が抑えられ、**E5寄りの優位はむしろ拡大**する見込み。
   → 正確な突破最適比率は **Driveでの比率×倍率スイープが必要**（未実施）。
2. **E5はSTRONG-LEAD（未検証）**。速度のためにE5比率を上げる＝**未検証戦略への依存を増やす**。
   規律上、E5比率は上げ過ぎない（デモ合格まで65:35上限が妥当）。

## 3. 実務上の整理（目的別の最適比率）
| 目的 | 口座 | 最適比率 | 状態 |
|---|---|---|---|
| 運用（失格率最小×収益） | インスタント | **65:35** | ✅ Drive最適化済(docs/32) |
| 突破（最速） | プロップ | **E5寄り(50:50〜)が速い** | ⚠ 局所指標のみ・Drive要確定・E5未検証で上限あり |

- **保守的な実務解**: 両目的とも **65:35** を使う（運用は最適、突破は"準最適だが十分速い＝約8ヶ月"、
  かつE5依存を抑えられる）。**速度を最優先するなら突破時のみ E5比率を上げる**選択肢はある（要Driveスイープ）。
