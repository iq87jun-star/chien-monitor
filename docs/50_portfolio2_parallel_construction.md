# 50. 第2(並走)ポートフォリオ構築 — 同じ9ゲートで検証する「現行と非重複」の独立口座

> ユーザー要望「**現行ポートフォリオとは別に、同じレベルの検証を通ったポートフォリオを作りたい**」への回答。
> ユーザー選択 = **既存エッジ再構成型**(検証済みの『機構』を別ユニバースへ展開) / 運用先 = **PROP・INSTANT両対応**。
> 成果物: `mql5/Chien_Portfolio2_AllInOne_{INSTANT,PROP}.mq5` ＋ プリセット ＋
> `research/colab_portfolio2_validate.py` / `notebooks/portfolio2_validate.ipynb`。

## 0. 一行結論

**v7/v4/E5 を2口座で重ねても"並走"にはならない**(同じ取引＝相関＝共倒れ・プロップは相関/コピー口座を嫌う)。
そこで **検証済みの"機構"を、現行が触らない"別ユニバース"へ移して** 第2口座を作る:

| レッグ | 機構(検証済み) | 現行ユニバース | **第2(並走)ユニバース＝非重複** |
|---|---|---|---|
| **MR** | v4 = 日足k≥4合議・平均回帰(現行**ADOPT** 6/6, docs/42) | メジャー9(EURUSD…GBPJPY) | **クロス9本** EURGBP,EURAUD,EURCHF,EURCAD,GBPAUD,AUDCAD,AUDNZD,GBPCHF,CADJPY |
| **RP** | E5 = 月次リスクパリティTSMOM(現行**STRONG-LEAD** 6/9, docs/40) | 金+米独指数(XAUUSD,US500,NAS100,GER40) | **別バスケット** XAGUSD(銀),USOIL(WTI),UK100(FTSE),JP225(日経) |
| ~~core~~ | ~~v7 = 円月曜~~ | 円3クロス | **意図的に非搭載**(複製すると現行と相関＝並走の意味が消える) |

→ **2口座が同じトレードを一切共有しない**＝真に並走できる第2ポートフォリオ。
検証は現行と**全く同じ9ゲート**で採点し、かつ**現行との相関**も測る(相関が低いほど並走の価値が高い)。

> ⚠ **本書は『設計＋事前登録＋検証ハーネス』であり、合格判定の確定値はまだ入っていない**。
> 本プロジェクトの規律(数字は盛らない)に従い、級(ADOPT/STRONG-LEAD/LEAD)・相関・p95DD の**実数は
> ユーザーの10年Colab実行(`notebooks/portfolio2_validate.ipynb`)で確定**する。これは v4/v7/E5 を含む
> 全エッジに課してきたのと同じ手順(docs/40)であり、第2ポートフォリオだけ特別扱いはしない。

## 1. なぜ「別ユニバースへの再構成」なのか(設計の根拠)

docs/40・42 の正直な結論: **9ゲートを通った無相関エッジは v7/v4/E5 の3つだけ**で、その他(v2/v3/v5/v8/
edge2-4/edge6-9)は棄却、v9 は v7と相関0.73で冗長。**"未使用の検証済みエッジ"は在庫ゼロ**。
したがって第2ポートフォリオの選択肢は実質3つ(ユーザーへ提示済み):

1. **新エッジ探索型** — 新土俵を一から9ゲート。真に独立だが過去同様**多くは棄却**され得る。
2. **既存エッジ再構成型(本書・採用)** — 検証済み"機構"を別ユニバースへ。同基準で**合格しやすい**。
3. 別業者・別リスク型 — 同じエッジを別枠へ再調整(=並走だが取引は共有=相関は残る)。

採用した②の核心は「**機構の汎化**」:
- **v4(合議MR)** は単一銘柄の偶然でなく「複数の売られ過ぎ条件の合議」という**汎用ロジック**。
  メジャーで効くなら、**同じ平均回帰性を持つクロス**でも機能する仮説は妥当(クロスはレンジ性が強い)。
- **E5(多資産RPトレンド)** は docs/22 の教訓「時系列モメンタムは**分散バスケット**でこそ機能」。
  **金+米独指数**で効くなら、**銀+原油+英日指数**の別バスケットでも同じ分散トレンドが期待できる。
- **取引の非重複**: クロス9本はメジャー9と銘柄が重ならず、バスケットも資産が重ならない。
  → 第2口座は第1口座と**同じ建玉を一度も持たない**=プロップの相関/コピー規約に抵触しにくく、
    片方が悪い月でももう片方が連動しにくい(共倒れ回避)。

> ⚠ ただし「機構が汎化する」は**仮説**。クロスはメジャーとUSD/EUR factorを共有し、相関が残る可能性がある。
> **だからこそ §3 の検証で相関とゲートを実測し、ダメなら別ユニバースを再選定する**(数字を盛らない)。

## 2. 第2ポートフォリオの構成(2レッグ)

| 戦略 | 銘柄 | ロジック(現行と同一) | 決済 | Magic |
|---|---|---|---|---|
| **MR** | 別クロス9本 | 日足 4条件合議 k≥4 で両建て(RSI<35/>65・BB z±1.5・連続3日・当日±0.5%) | SL=1.5ATR_D1 / TP=RR1.2 / 8日時間切れ | base+1 |
| **RP** | 銀/原油/FTSE/日経 | 月初 TSMOM(過去1/3/6/12ヶ月符号多数決) 逆ボラ加重で両建て | 翌月反転で入替(SL=2.5ATR_MN1) | base+2 |
| 口座ガード | 全体 | 総合−10%枠の内側(既定−9%)で全停止 | — | — |

- **2レッグはMagic分離**(base+1/+2)。Magicベースは **INSTANT=940730 / PROP=940740** で、
  現行 Portfolio(940710系)・Portfolio3(940710/940720系)と**衝突しない**。
- 内部分散: MR(平均回帰)とRP(トレンド)は**機構が逆**ゆえ相互に低相関の見込み
  (現行でも v4⇄E5 = −0.05)。比率は **MR:RP ≈ 50:50(リスク等配)** を既定とする。

## 3. 検証 — 現行と同一の9ゲート ＋ 相関(`notebooks/portfolio2_validate.ipynb`)

各レッグを**現行と全く同じ9ゲート**で採点する(`colab_validate_all_v7standard.py`と同一の
perm_p/jackknife/walkforward/block_bootstrap/grade/finalize_grade を流用):

| # | ゲート | 合格条件 |
|---|---|---|
| G1 | 10年実データ | span ≥ 8.5年 |
| G2 | ノールックアヘッド＋実コスト | 構造的に担保(t−1足シグナル→t始値約定・spread/2+slippage計上) |
| G3 | 主signのperm_p < Bonferroni α | **MR: N=18→α≈0.00278**(v4継承) / **RP: N=6→α≈0.00833**(E5継承) |
| G4 | プラセボ識別 | 方向ランダム(同機会)でnetが本物の半分未満に崩壊 |
| G5 | 年次ジャックナイフ | leave-one-year-out の perm_p max ≤ 0.10 |
| G6 | IS/OOS 両方+ | 前半・後半とも net>0(減衰なし) |
| G7 | ウォークフォワード | 5分割で ≥4 期が+ |
| G8 | コスト頑健 | 2×コストでも net>0 |
| G9 | −10%枠適合 | 代表サイズ(MR risk/trade 0.15% / RP legRisk 0.30%)で p95 maxDD ≥ −10% |

**判定ロジックも現行と同一**:
- **ADOPT** = G3・G4・G5・G6・G7・G8・G9 すべて合格(=v7と同格の確認済みエッジ)。
- **STRONG-LEAD** = G4・G6・G7・G8 合格だが G3(Bonf) か G5 のみ未達(質は高いが確証のみ不足→デモで埋める)。
- **LEAD** = それ未満。

さらに本ノートは**並走可否の核心=相関**を出す:

| 出力 | 意味 |
|---|---|
| `corr(P2_MRcross, P1_v4maj)` | MRレッグが現行v4とどれだけ独立か |
| `corr(P2_RPalt, P1_E5base)` | RPレッグが現行E5とどれだけ独立か |
| `corr(P2_combo, {P1_v7,v4,E5})` | **第2ポート全体が現行とどれだけ独立か**(低いほど並走価値大) |
| `corr(P2_MRcross, P2_RPalt)` | 第2ポート**内部**の分散(低/負なら良い) |

### 事前登録された期待と合格基準(後付けで緩めない)
- **MR(別クロス)**: v4機構は現行ADOPT。クロスでも平均回帰が残れば **STRONG-LEAD〜ADOPT** を期待。
  ただしクロスの流動性/スプレッドはメジャーより不利 → G8(コスト2×)が効くか要確認。
- **RP(別バスケット)**: E5機構は現行STRONG-LEAD(月次108点の検出力でBonf/JKが上限)。
  別バスケットでも **STRONG-LEAD** 圏が現実的。原油のロール/スワップは G8/デモで要確認。
- **合格の定義**: 「現行と**同じ級以上** かつ `corr(P2_combo, P1) < ~0.3`」を満たせば
  「**同じレベルの検証を通った並走ポートフォリオ**」として採用候補。**未達なら別ユニバースを再選定**
  (例: MRをCAD/NZD系クロスへ、RPを債券/天然ガスへ)して本ノートを再実行する。

> データが無く、Yahooも取得制限のため)。**ユーザーがColabで `portfolio2_validate.ipynb` を実行すると
> 上記すべての実数が確定**する。数字は盛らない=ここに架空の合格値は書かない。

3. それだけ。残高自動・比率/ルールは既定で入る。**1チャートに1つだけ**(Magic衝突回避)。
4. **業者で銘柄名が違う場合のみ** `InpMRSymbols` / `InpRPSymbols` を実銘柄名に
   (XAGUSD=SILVER, USOIL=WTI/CRUDE, UK100=FTSE100, JP225=JPN225/NIKKEI 等。EA内に別名総当りも内蔵)。

### 現行口座との併用(並走)
- **第2EAは別口座(または別ターミナル)で動かす**のが本来の趣旨(口座ごとに独立してDDを管理)。
- 同一口座に現行(Portfolio3)と本EAを同居させる場合でも **Magicベースが別**(940730/940740 vs 940710/720)
  ゆえ建玉は混線しない。ただし**DD枠は口座単位**なので、同居時は両者合算でのリスク管理が必要
  (推奨はやはり**口座を分ける**=並走の本来の形)。

- ⚠ **攻めの代償**は現行と同様(数年に一度の口座喪失を織り込む前傾運用)。利益は毎サイクル出金。
