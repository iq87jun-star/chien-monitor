## 3. 判定
- 通過 0 / 18。EA の設定変更を要するものはない。
- **災害 SL(Mon)は「利益を削る保険」**: 5 年で 22.5 → 20.5%(Mon4)、OOS Sharpe 2.44 → 1.67。ただし §4 の通り最悪日を −6.9% → −1.7%(×2.5)に抑え、失格確率をほぼ 0 にする。撤去は勧めない。緩和するなら 3.0×ATR(発動 34 → 27%、5 年 20.5 → 21.0%、最悪月同じ)。これはユーザー決定(§5)。
- 台帳(docs/308・309・稼働台帳ページ)の MC は SL なしの研究系列で計算している。実 EA は SL 付きなので、到達は 2〜3 pt 低く、失格は 0.5〜1 pt 低い方向にずれる(§4)。
