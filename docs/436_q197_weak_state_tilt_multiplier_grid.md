- T1 を 1.2 倍にすると、平均の建玉は現行とほぼ同じになる。この点でも FTMO 50k 次の段階は W1 90 / 8・W2 82 / 16 と、現行(89 / 11・77 / 21)より両窓で良い。ただし到達率の差は W1 で +1 ポイントにとどまり、登録の基準(+2 ポイント)には届かない。
- T2(寄せる 1.5 / 0.5)は窓によって結果が割れる(W2 では ×1.0 が良いが、倍率を上げると急に悪化)。T1 のほうが安定。
- 1-Step は W1 では現行のほうが良く(T1 は平均が下がる)、W2 では T1 × 1.4 が同じ失格率で到達 +4 ポイント。窓で逆なので見送り。

## 5. 判定と提案
- **倍率の引き上げは提案しない**。両窓で失格率が上がる。
- **変更候補(登録の規則どおり)**: FTMO 50k × 2 の次の段階、ルビーの次の段階に「T1 減らすだけ × 現行の倍率」。失格率が FTMO 50k で 10.8 → 5.6%(W1)・21.4 → 11.7%(W2)、ルビーで 20.3 → 15.0%・33.2 → 29.9%。代償は進みの遅さ(中央 6 → 9 週、4 → 6 週)。
- 参考(片方の窓のみ): 宝くじ・パール・トパーズの次の段階も W2 では失格率が 6〜8 ポイント下がるが、W1 では到達率の基準に届かないか悪化する。
- 入れない口座: 1-Step(W1 で到達率が下がる)、14074882(大きく下がる)、いまの段階で目標に近い口座(差が出ない)。
- 実装は EA の改修(通貨ごとに日足の 200 日線を見て、上にいる通貨の月曜の数量を半分にする)で「切替」事項。対象はいずれも次の段階なので、段階が進む時の EA に入れる形になる。
- 未評価: 損失枠の残りに比例する縮小(Q192・次の段階の EA に入れる予定)と同時に使った場合。両方とも数量を減らす規則なので、重ねると進みがさらに遅くなる。採用前に組み合わせの確認が要る。
- 注意: 月曜レグのみのモデル。W2 は現行の到達率そのものが W1 より 10〜25 ポイント低い(2016〜21 年は月曜の効果が弱い)。
