# docs/186: プロップ用EAの販売・開示市場 — 存在するが「クラスタリスク」を買う行為

日付: 2026-07-29
関連: docs/170(DLL失格)、docs/176(運営の相関検出)、docs/185(Tier A には開示ロジックが必要)
問い: プロップ用EAを開示・販売しているところはあるか。

---

## 1. ある。4形態に分類できる

| 形態 | 例 | ロジック開示 | 評価 |
|---|---|---|---|
| a. 汎用EA市場の「プロップ対応」版 | MQL5 Market の prop firm EA 群、GogoJungle のプロップ対応表記EA、Nordman 等の専業ベンダー | ほぼ非開示(コンパイル済み) | 使用は下記クラスタリスク。検証は Tier B 止まり |
| b. チャレンジ突破専用EA(HFT/瞬間突破系) | 「HFT passing EA」系 | 非開示 | デモ環境の穴の搾取。大半のファームが禁止・発覚で失格/没収 |
| c. 合格代行サービス | 「challenge passing service」 | — | 規約違反そのもの。BAN+出金拒否+ブラックリスト |
| d. 無料/オープンソースEA | GitHub、MQL5 CodeBase、フォーラム公開ロジック | **完全開示** | **唯一 Tier A(自EA同水準検証)に載せられる素材** |

日本語圏では Fintokei 向け「EA活用ガイド+推奨EA」を載せるアフィサイト群が多数
(fintokei-strategy.com 等)。GogoJungle 経由の販売が中心で、ロジックは非開示が通例。

## 2. 構造分析 — なぜ「勝てるEA」が売られるのか(docs/174-176 の応用)

1. **ファーム側の戦略別資本上限**: FTMO は明文で「第三者EAは他人と同一戦略になり得る。
   1トレーダー/1戦略あたり最大$400,000 の資本配分上限を超えると Rewards Account を
   拒否しうる」と警告している。**つまり本当に勝てるEAほど、売れた瞬間に
   1人あたりの取り分が消える** → 開発者の合理行動は「使う」より「売る」(シャベル売り)。
2. **購入EA使用 = 検出可能クラスタへの自発的参加**: docs/176 で見た通り、運営は口座間
   相関でコピー集団を最優先検出する。市販プロップEAの使用者は、数百人と同一シグネチャを
   共有する「最も見つけやすい sharp」になる。docs/174 の防衛シナリオが最初に切るのは
   まさにこの層(規約の group trading / copy trading 条項)。
3. **禁止事項との接触面**: Fintokei はマルチンゲールを計算機基準で禁止、DLL で失格例
   (docs/170 = 自分)。市販EAは内部実装が見えないため、**知らずに規約抵触する
   リスクを外注できない**。

## 3. 結論

- 「販売している場所」は多数あるが、**買って使う価値はほぼ負**(クラスタ検出+規約抵触+
  docs/185 の通り形状適合も未保証)。
- 価値があるのは **d. ロジック開示されている無料/OSS EA を Tier A 検証素材として使う**こと。
  「プロップで使えるか」は買うものではなく、開示ロジック × 自分の検証パイプライン
  (BT→LOYO→規則MC→事前登録)で自分で判定するもの。自EA(通過93%/失格0.9%)を
  上回る候補が市販品に存在する構造的理由がない(あれば売られていない)。
- 探索の実務: GitHub / MQL5 CodeBase で「ロジック全文が読めるもの」だけを対象に
  スクリーニング → docs/185 §4 の手順へ。
