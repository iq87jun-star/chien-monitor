## 補足の推奨設定

- **アイコン/ヘッダー**: 既存の青髪キャラクターの新規イラスト(チャート画面やデスク背景など「トレーダー感」のあるシチュエーション)にすると、ブランド統一と用途の区別が両立できる
- **固定ツイート**: 挑戦するプロップファーム名・口座サイズ・ルール(最大DD等)・記録の更新頻度を宣言する自己紹介ポスト
- **運用上の注意**:
  - 投資助言・代理業の登録なしに個別の売買推奨や有料情報提供と受け取れる発信をしない
  - 実績のスクリーンショットは誇大にならないよう期間・条件を明記
  - 「必ず儲かる」等の断定表現は避ける
