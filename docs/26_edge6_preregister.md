## 事前登録パラメータ（固定）

- 多重比較補正: **Bonferroni α = 0.05 / 6 ≒ 0.0083**。
- 検定データ: **10年実データのみ**。FX H1 = `dukascopy_data_h1/`、多資産日足 = `multiasset_daily/`（Yahoo）。

- v7相関は v7（円・月曜04/06/08/10 UTC LONG・24h）の月次リターンを FX H1 から再現して算出。

## 6ゲート（全通過のみ ADOPT。★edge5 と異なり cost も ADOPT 必須）
1. **G_perm**: 順列p（月次ブロック符号シャッフル=自己相関頑健版） ≤ α(0.0083)
2. **G_jk**: ジャックナイフ（各年除外）最大p ≤ 0.10
3. **G_oos**: 前半IS純益 > 0 かつ 後半OOS純益 > 0
4. **G_indep**: v7との10年月次相関 |corr| ≤ 0.4
5. **G_plac**: プラセボ（方向ランダム化）が非有意(p>0.05) かつ 対象純益 > プラセボ純益
6. **G_cost**: 往復1〜4pip 全てで純益 > 0

判定: 6/6 → **ADOPT** / それ未満で（純益>0 かつ p≤0.10）→ **LEAD** / それ以外 → **REJECT**。
