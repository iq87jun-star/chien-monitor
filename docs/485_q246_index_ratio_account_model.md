## 4. 読み
- **6 場面すべて現行どおり。** 指数を減らす変更候補は出なかった。
- 指数を減らすと週のばらつきは 1〜3 割下がり、2021 年以降の窓では存続・到達が少し上がる(FN Instant の 10 年存続 92.6 → 95.4 → 96.2%、トパーズ・次の到達 78.8 → 84.2 → 87.6%)。
- その代わり出金が減る(トパーズ 10 年 +110.5 → +94.1%、FN Instant +36.6 → +29.5%)。存続はもともと高いので、減った出金を補えない。
- 2016〜21 年だけの窓では逆に悪くなる(トパーズ・次の到達 80.9 → 65.6%、1-Step・いまの到達 60.9 → 52.7%、FN Instant の 5 年存続 84.9 → 79.1%)。この時期は月曜の円クロスが弱く、指数が成績を支えていた。
- Q245(単純な足し算)で見えた「指数は最悪月と下げ幅を深くする」は、口座では数量の自動調整とガードで吸収されていて、失格の増加としては小さい。指数は「円クロスが弱い時期の支え」として働いている。
- FN Instant の「半分」は 10 年存続が +2.8 ポイントで、基準(+3.0)にわずかに届かず、出金も現行を下回る。
- 限界: 2016〜21 年の指数は米国株の強い上昇期。同じ支えが今後も出る保証はない。モデルは週を無作為に引き直すので、荒れた週が続く並びは実際より少なく出る。
