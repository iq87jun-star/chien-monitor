# docs/176: 運営側から「勝つEA」はどこまで見えるか — フローデータの価値と限界

日付: 2026-07-29
関連: docs/174(運営収支モデル)、docs/175(難易度評価)
問い: 運営側に回れば勝っているEA/トレーダーの中身を確認できるのか。それが運営参入の最大の果実ではないか。

---

## 1. 結論(先出し)

**見える。ただし見えるのは「注文の痕跡」であってEAのコードではない。**
得られる最大の果実は「コピーできるアルファ」よりも、
(a) **勝ちフローの型の分類**(何が実際に勝っているかの全数観測)と
(b) **デモ環境の穴の発見**(=防衛設計、docs/174 の s* を守る材料)である。
これは業界でブローカー/プロップだけが持つ本物の情報優位であり、参入動機として合理的。
一方で、顧客データの自己利用には契約・評判上の強い制約があり、白紙の権利ではない。

## 2. 何が見えるか(プラットフォーム側の生データ)

運営者は全顧客口座の取引をサーバー側でリアルタイムに全数観測できる:

| 見えるもの | 粒度 | そこから推定できること |
|---|---|---|
| 全注文(時刻・銘柄・方向・ロット・SL/TP・約定価格) | ティック精度 | 戦略の型(トレンド/平均回帰/ニュース/裁定系)、保有時間分布、リスク管理の規律 |
| エクイティカーブ・日次損益 | 全期間 | 実現シャープ、DD特性、ガードの有無(本リポのEAのような −4%停止は一目で分かる) |
| 口座間の相関 | 全顧客横断 | コピーグループ検出(合格代行・シグナル配信の同一クラスタ)、sharp比率 s の実測 |
| 発注の癖(指値/成行、発注間隔、ニュース前後の挙動) | ミリ秒 | EA/手動の判別、レイテンシ裁定・ギャップ取りの検出 |
| **見えないもの** | — | EAのコード・ロジックそのもの、シグナルの生成根拠、パラメータ |

テックプロバイダ(FPFX / Match-Trade 等)はこの用途のリスク管理ダッシュボードを標準装備しており、
「勝ち口座の抽出と挙動分析」は運営の通常業務(リスク部門の仕事)そのものである。

## 3. 「勝つEAのコピー」としての価値は割り引くべき

1. **注文列から戦略の型は分類できるが、シグナルは復元できない。** 参入時刻の規則性(例: 本リポの季節性EAなら月初/曜日パターンが露骨に出る)から仮説は立つが、検証は結局自前のバックテスト(本リポの通常業務)に戻る。
2. **プロップで勝つEAの相当部分は「実市場で勝つEA」ではない。** デモフィードのレイテンシ裁定、配信停止中のギャップ取り、週明け窓埋め特化など、環境の穴の搾取が多い。これはコピーする価値が薄い一方、**防衛設計には最重要情報**(docs/175 ⑤で有利と評価した能力の入力データ)。
3. **生存者バイアスと標本不足。** 資金化6ヶ月の勝者でも取引数百件程度では運と実力を分離できない。多重検定の規律(docs/165 等で自分に課してきたもの)を他人の口座にも適用する必要がある。
4. つまり価値の序列は: **s の実測 > 穴の発見(防衛) > 勝ち型の分類(研究仮説の源泉) > 個別EAの複製(ほぼ幻想)**。

## 4. 制約(ここを軽く見ると評判ごと死ぬ)

- **契約・法務**: 顧客取引データの分析利用は ToS/プライバシーポリシーで明示的に権利確保が必要。「運営が顧客の戦略を盗んで自己勘定で使う」は業界で最も燃える告発テーマであり、疑惑だけで docs/175 ③(信頼獲得)が崩壊する。B-book ブローカーが勝ちフローをプロファイルするのは業界慣行だが、慣行と評判リスクは別物。
- **白レーベル(段階2)ではデータの帰属が契約次第。** パートナーのプラットフォームに載る場合、生の取引データへのアクセス権が制限されることが多い。**段階2の契約交渉では「全顧客の生取引データへのアクセス権」を必須条件にすべき**——本問いの果実はここで確保される。
- 個人データ保護法制(GDPR等、法人所在地による)への適合。

## 5. 含意

- 「勝つEAが見える」は運営参入の実利として**本物**。ただしその実体は「コピー素材」ではなく、
  ①docs/174 最大の未知数 s の実測、②防衛ルールの入力、③研究仮説の全数スクリーニング装置。
- 特に③は本リポの研究プロセスと直結する: 現状は仮説を自力で発案→検証しているが、
  運営データは「市場で現に機能している型の一覧」を仮説源として与える。検証規律はそのまま使える。
- 段階2(白レーベル)交渉時のチェックリストに追加: 生取引データアクセス / データ利用条項 / 自己勘定利用の可否と開示。
