## 1. なぜ「新土俵」が要るのか — 既存の探索は出尽くしている

「並走」の価値は **既存A・Bの両方と低相関な新しい核**を立てることにある(docs/50,52)。だが本プロジェクトは
すでに広範に汲み尽くしている:

| 土俵 | どこで | 検定数 | survivor |
|---|---|--:|---|
| FX 曜日 / 月末(TOM) | docs/14 | 全数 | 円月曜(v7)のみ |
| 指数/暗号/コモ 曜日 / 指数TOM / 相対価値 | docs/50 | N=130 | 指数月曜(E-Mon)のみ |
| プレ祝日 / 年末年始 / 月別 | docs/64 | N=164 | 指数7月(S-Jul)のみ(SEASONAL-LEAD) |
| H1足内セッション(ORB/フェード/初動/overnight/東京) | docs/28(edge7) | N=6・Drive10年 | **全REJECT** |

→ 「曜日・月末・月別・プレ祝日・年末年始・足内」は天井。**残る未踏=イベント条件付け と クロスアセット先行遅行**。

## 2. 事前登録した2系統(実行前に固定 = `build_candidates()`)

### G. マクロ・イベント・ドリフト(曜日でなく"イベント日"で条件付け = 月曜効果と機序が直交)
| ID | 内容 | 対象 | 根拠 |
|---|---|---|---|
| G1 PreFOMC1 | FOMC公表 **前営業日**に建て→公表当日寄付で決済(24h) | 指数4 × L/S | Lucca&Moench(2015) pre-FOMC drift |
| G2 PreFOMC2 | 公表 **2営業日前**から保有 | 指数4 × L/S | 同(窓を広げた頑健性) |
| G3 PostFOMC | 公表 **当日**建て→翌営業日決済 | 指数4 × L/S | Savor&Wilson(2013) announcement premium |
| G4 PreNFP | 雇用統計(第1金曜) **前営業日**に建て | 指数4 × L/S | イベント前ポジション調整 |
| G5 PostNFP | NFP当日建て→翌営業日決済 | 指数4 × L/S | サプライズ後ドリフト |

### L. インターマーケット先行遅行(前日の他資産符号で当日を建てる = 第3系統)
| ID | 内容 | 機序 |
|---|---|---|
| L1 gold→AUD | 金(t-1)符号で AUDUSD(t) | コモディティ通貨リンク |
| L2 oil→CAD | WTI(t-1)符号で USDCAD(t) を逆建て | 原油高=CAD高=USDCAD安 |
| L3 dxy→EUR | ドル指数(t-1)符号で EURUSD(t) を逆建て | USD先行 |
| L4 spx→JP225 | 米国(t-1)符号で 日経(t) | オーバーナイト・スピルオーバー |
| L5 spx→GER40 | 米国(t-1)符号で 独DAX(t) | 欧州への波及 |
| L6 volreg→idx | 指数20日実現ボラ下位33%の翌日に指数LONG | 低ボラ持続=リスクオン |

合計 **N ≈ 4×5×2 + 5×2 + 4 = 54 候補** → Bonferroni α = 0.05/N ≈ 0.0009(v7のN=54と同等の厳しさ)。
全候補に v1-v6/E-Mon/S-Jul を裁いたのと**同一の二次ハーネス**:
順列p / **★年次ブロックp(年=独立サンプル)** / IS-OOS(プール半割) / 全年ジャックナイフ / Bonferroni /
コスト感応(1x/2x/3x) / **★★既存4成分すべて(v7・E-Mon・E5・v4)との月次相関**。

> **なぜ4成分すべてと相関を測るか**: 口座C は **A(v7+v4+E5)とB(E-Mon+E5)の"両方"と低相関**でなければ
> 「第3の並走」の意味が無い。docs/50 は v7 のみ、docs/64 は v7+E-Mon と相関を見たが、本書は **v4・E5 も含めた4成分**で
> 「A・B どちらに対しても |corr|≤0.3」を survivor 条件に課す(より厳しい=誠実)。

## 3. 最有力 deploy 候補 = E-FOMC(pre-FOMC drift 指数バスケット)

なぜ E-FOMC を EA 化の筆頭に置くか(他候補より deploy 適性が高い):
- **クリーンな建玉ルール**: FOMC公表(年8回)の前営業日に指数LONG→公表当日決済。**E-Mon と同型**(時間/イベント
  ゲートの指数LONG)で、既存のオールインワン設計・ガードをそのまま流用できる。
- **機序が直交**: FOMC はほぼ水曜=「月曜効果(v7/E-Mon)」と曜日が重ならない。為替の平均回帰(v4)・月次TSMOM(E5)
  とも駆動因が別。**A・B両方と低相関が期待できる**(確定はDrive相関で要確認)。
- **発火が希少(年8回・24h保有)= 低DD・低スワップ**。サテライト/第3系統に向く。
- **再現性**: FOMC公表日は公開情報。ハーネスは定例会合日を表で持ち、EAも `InpFomcDates` で明示(緊急会合は除外)。

> **正直な注意**: pre-FOMC drift は2010年代後半に**減衰したとの報告**もある(レジーム依存疑い)。
> ∴ 派手な過去純益でなく **年次ブロックp・OOS・JK** で生存を判定する(docs/07,08 の仮数値の轍を踏まない)。
> L系(先行遅行)も候補。Drive結果次第で E-FOMC でなく L系が核になることもある(事前登録ゆえどちらでも記録に残す)。

## 6. 口座C の構築方針(survivor 確定後)

- **核 = E-FOMC(または L系 survivor)**。E-Mon が v7 の役を担ったように、口座C では新核が主役。
- **衛星**: A・B と相関の低い既存脚(E5 は両方で共有=相関上げ要因ゆえ、口座C では**入れない**選択も妥当)。
  むしろ docs/64 の **S-Jul(E-Mon相関−0.31)** を季節オーバーレイに足すと、指数スリーブの分散が更に深まる。
- **サイズ**: 候補/サテライト=小サイズ(既定 1イベント1%)。主軸(収益)はあくまで A(v4 ADOPT 主軸)。
  口座C の価値は docs/52 の結論通り **"高収益"ではなく"3つ目の無相関な器=全損回避と総量拡大"**。
- **Magic帯**: E-FOMC=950740系(既存 950710/950720/950730/940710/940720 と非衝突)。**別口座**で運用。

## 7. 限界(盛らない)

- **一次値すら無い**(本環境制約)。本書の価値は **事前登録の枠組みと deploy 設計**であって、エッジの実在証明ではない。

- Yahoo日足は配当除く指数・OHLC概算・bps単純化。指数CFDの実スプレッド/スワップ/取引時間は業者差大→**デモで実測**。
