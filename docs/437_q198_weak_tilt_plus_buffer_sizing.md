## 4. 推奨と含意
- **次の段階の EA には「減らすだけ(200 日線)」+「損失枠比例(下限 0.5)」の併用を入れる**: FTMO 50k × 2・ルビー・パール・トパーズ・宝くじ。全体の倍率は現行のまま(上げない)。
- いまの段階にも入れてよい候補: ルビー・パール・FTMO 50k(7058)。ただし目標が近い口座は差が小さく、いま切り替える利点は主にルビー(失格 12 → 4%・W2 23 → 15%)。
- 入れない: 1-Step、14074882(いま・次の段階とも)、宝くじのいま(配備中の損失枠比例のみを維持)。
- 実装は EA の改修で「切替」事項。必要な変更は 2 点: (1) 通貨ごとに日足の 200 日移動平均を読み、金曜終値がその上にある通貨の月曜の数量を 0.5 倍にする入力(既定は無効)、(2) 損失枠比例(宝くじ v1.11 の BufShrink と同じ仕組み)の移植。
- 注意: 月曜レグのみのモデル。W1 は規則を作った期間と重なる(W2 が独立の確認)。失格が減る代わりに、52 週以内に終わらない経路が増える(期限のないチャレンジなので実害は小さいが、月額費用やロールの手数料がある口座では遅さが費用になる)。Fintokei のロール枠・金の保有などの月曜以外のレグは含めていない。
