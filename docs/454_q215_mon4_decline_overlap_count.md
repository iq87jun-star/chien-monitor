## 1. 方法(事前固定)
- 通貨ごとに、月曜より前の最後の確定日足で 4 条件を判定: 終値 < 50 日線 / 終値 < 200 日線 / 13 週前(65 営業日前)より安い / 1 年(252 営業日)の高値から 5% 以上下。k = 当てはまる数(0〜4)。
- W1: k = 0 → 0.5 倍・1〜2 → 0.75 倍・3〜4 → 1.0 倍。W2: 0.5 + 0.125 × k。W3: k = 4 だけ 1.0 倍・ほかは 0.5 倍。W4: k ≥ 1 なら 1.0 倍・k = 0 は 0.5 倍。
- 判定 = 配備中の形(200 日線の下 1.0 倍・上 0.5 倍)に対して、前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しない。

- **重なるほど月曜の平均が高い傾向は、3 つの期間すべてで確認できる**(順位相関はどれも正で p ≤ 0.011)。0〜1 個のときは平均がほぼゼロかマイナス、4 個そろったときが前窓と探索で最大。
- ただし並びはきれいな階段ではない(OOS は 2 個が最大、前窓は 3 個が 2 個より低い)。回数の少ない区分(OOS の 2〜3 個は 23〜39 回)で大きく振れる。

## 4. 判定と含意
- **棄却 0 / 4**(正常な結果)。配備中の形(200 日線の下はそのまま・上は半分)を変えない。紙上フォワードにも入れない。
- 「重なるほど強い」は傾向としては本物に見えるが、4 条件は互いに重なりが大きく(200 日線の下にいる通貨は多くが他の条件にも当てはまる)、数えて刻んでも 200 日線 1 本で分けるのと選ぶ週がほとんど変わらない。規則を細かくした分だけ期間ごとの振れが増え、結果は基準に届かなかった。
- 下げの条件が 1 つも無い(0 個)ときの月曜は、前窓と OOS で平均がゼロ以下。配備中の形がこの状態を半分にしていることと整合する。『0 個のときは建てない』は結果を見てから出てくる案で、建てる回数が半分以下になり評価中の到達が遅れるため登録しない。
- 200 日線まわりの検証(Q194〜Q198・Q213〜Q215)は一巡。定義の入れ替え・深さ・日数・重なりのどれでも、配備中の形を 3 つの期間で上回るものは無かった。
