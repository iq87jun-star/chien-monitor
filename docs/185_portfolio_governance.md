# 185.【事前登録】ポートフォリオ・ガバナンス — 失格対応・再起プロトコルとサーキットブレーカー

> 2026-09-01作成。2026-08の議論(失格対応の汎用+個別2層設計・丁半博打の定量却下・
> リスク分散評価)を事前登録として確定。**失格が起きる前に決めておく**ことが本docの目的。
> 適用対象: 全稼働口座(docs/179 §1の採点表に載る口座)。

## 1. 汎用層 — 全トラック共通プロトコル(失格・口座喪失時)

1. **48時間冷却**: 失格後48時間は買い直し・構成変更・倍率変更を禁止。診断のみ。
   例外: 期限24時間のリトライクーポン(速攻プロのセカンドチャンス等)は、
   **購入前に事前登録した基準がある場合のみ**24時間以内の機械的判断を許可(docs/183 §6)。
2. **型診断**(ログ+業者通知で判定):
   - **型(a) モデル内の不運**: ガード正常動作・負け方が悲観MC分布の範囲内
   - **型(b) モデル外の事象**: MC前提外のギャップ・相関収斂・マイナス価格級の構造イベント
   - **型(c) 実装・運用欠陥**: ガード不発・日次基準ズレ・発注異常・規約解釈ミス
3. **型(c)は全口座に波及させる**: 共通コードベースのため、原因修正+全EAへの横展開が
   完了するまで**全トラックの再起を凍結**。
4. **型(b)は同族トラック全部に波及チェック**: 同じ要因に晒される構成の倍率・継続を再評価。
5. **再起の共通形式**: 旧構成の買い直し禁止。その時点の最新データで**同一固定規則**の
   再スクリーニングを実行し、サイズは原則半減から。
6. **記録義務**: 失格ログ・診断結果・再起判断をdocsに追記してから購入。

## 2. ポートフォリオ・サーキットブレーカー

> **⚠ 2026-09-01改訂: 本節の発火条件は docs/200 が上書きする。**
> 実測(docs/199 §8)で本節の規定が悲観バウンドで54.33%発火し、その原因が共通要因ではなく
> 短命設計の2口座(速攻プロ90.1%・Instant 77.8%)の寿命到達であることが判明したため、
> **発火カウント対象を通常のチャレンジ/資金化口座に限定**する改訂を行った(発火16.85%へ)。
> 以下の本文は改訂前の記録として残す。

**30日以内に2口座以上が失格した場合、原因を問わず全トラックの再起・新規購入を凍結**し、
全体postmortem(相関・レジーム・実装の3面)を完了するまで解除しない。
根拠: FX系口座間の実測相関0.5〜0.85(2026-08計測)では、複数同時失格は「個別の不運」ではなく
共通要因(円急騰・リスクオフ・レジーム転換)の顕在化とみなすのが正しい事前確率。
凍結中も**既存の生存口座は通常運用を継続**(EAガードに任せる。手動介入はしない)。

## 追記(2026-09-12): FundedNext の EA・VPS 利用規約変更(2026-09-08 施行)— 稼働中3口座は経過措置、ただし**リセットで失効**

> 出所: FundedNext からのメール「Important Update: EA & VPS Usage Policy」(updates@fundednext.com・2026-09-08 08:40 UTC)。
> 参照先: https://help.fundednext.com/en/articles/8223809-can-i-use-a-vpn-or-vps

### 変更内容

- **2026-09-08 施行。EA と VPS の利用は口座サイズ $50,000 未満に限定。**
  対象は FundedNext CFD の全プラン(Stellar 1-Step / 2-Step / Lite)。
- **9/8 より前に購入した口座は経過措置**。従来の EA・VPS 規約を守る限り継続利用可。手続き不要。
  ただし **口座がリセットされた場合は新規約が適用される**。
- 9/8 以降に購入した $50,000 以上の口座は **EA・VPS 不可**。全て手動。アドオンも購入不可。
- 変更なし: $50,000 未満はアドオン料金で継続利用可。カスタマイズ・戦略の独自性・**$300,000 の配分上限**・禁止 EA の規定は従来どおり。

### 帰結(重要)

1. **FN で $50k 以上の新規口座を EA で回す道は塞がった。** docs/194 の長寿命トラック再建や案1の FN 配置は、
   $50k 未満に分割するか、別ファームを使うかの二択になる。
2. **14074882 のリセットは EA 権利の喪失を意味する。** 9/4 時点で残高 −6.09%、FN 静的 −10% まで余白 3.9%。
   失格→リセットのコストが「チャレンジ費用」だけでなく「その口座で EA を使う権利」に拡大した。
   → docs/217 で G3 のサイズを US500 0.5% / EURUSD 0.25% に下げた判断は、この観点からも正しい。
   **今後この口座は保守側に倒す**(倍率を上げない・余白が戻るまで新規スリーブを足さない)。
3. $300,000 配分上限が本メールで明文確認された(docs/185 §5 の前提と整合)。
4. **FNmarkets(ブローカー)にはこの制限は無い。** docs/218 の記録用口座を FNmarkets 実弾に置く案の相対価値が上がった。
