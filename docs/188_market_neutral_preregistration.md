## 1. 動機 — 8口座あるが収益源の型は1つしかない

配備中の全トラック(A/B/C/D案・Instant・非FX・速攻プロ・季節RG3)は、
4つのセル構築式(Mon / Hold / TSMOM / v4)+ A案のRSI2 で構成されている。
**この5つは全て「単一銘柄の絶対方向ベット」である。** その帰結が
`recentfit_portfolio_compare.json` の相関表:

| 組 | 12ヶ月日次相関 |
|---|--:|
| B案 ↔ C案 | **0.85** |
| C案 ↔ D案 | **0.79** |
| A案 ↔ C案 | 0.53 |

docs/182の非FXトラックは相関0.10を達成したが、中身は
**Hold UK100 + Hold WTI = 64.4% が連続ロング=ベータ**、残35.6%が暗号のベータである。
つまり「FXのベータ」を「株・原油・暗号のベータ」に置き換えたにすぎず、**型は増えていない**。
全期間バウンドで失格52.9%、Hold WTIが2020-04マイナス価格級の尾を抱える(docs/182 §2)のは、
ベータをレバレッジで保有する以上は当然の帰結である。

**本トラックは「2銘柄の相対」という、現ブックに1つも存在しない型を追加する。**

## 2. なぜプロップの土俵と相性が良いか(設計の根拠)

1. **プロップの制約は絶対損失(日次−5%・静的−10%)であり、ボラではない。**
   したがって効率を決めるのは *ボラあたりのリスク調整後リターン*。方向性ベータは
   年率ボラ10〜18%(compare結果)を消費してシャープ2〜4を得ている。中立スプレッドは
   ボラが数分の一になるため、**同じ日次制約の下でより高い倍率を許容できる**。
   C案が倍率キャップ6.0で頭打ち(m*=8.0)なのは、ボラを消費しすぎているためである。
2. **選抜ノイズが構造的に小さい。** ペア母集団は「経済的に結びついた組」に限定され、
   探索空間が34セルよりさらに小さい。docs/184のD案型劣化が起きにくい。
3. **Fintokeiの「トレードグループ3%」(同時保有全体の実現損+含み損・docs/176 §7.5.1)と
   相性が良い。** 両脚が逆方向のためグループ合計の実損が構造的に小さい。
   B案が「グループ3%に常時接触圏=Fintokei不適」と判定された問題が中立構成では逆転する。
4. **相関が選抜結果に依存せずゼロになる。** 非FXの0.10は「たまたま今の選抜がそうなった」値で
   次回再スクリーニングで崩れ得る。中立ペアは設計上ゼロである。

### 3.1 セル構築式(2型・実行前固定)

各ペア(X,Y)について、**ボラ調整済みスプレッド**を作る:

```
spread_t = ret_X,t / σ_X,t−1  −  ret_Y,t / σ_Y,t−1      (σ = 過去60日の日次std・t−1で確定)
```

σをt−1で確定させることで**look-aheadを排除**する。この定義により両脚の名目は
ボラ逆比で決まり、ベータ中立に近くなる。この spread に対し2つの型を作る:

| 型 | シグナル | 決済 | 根拠 |
|---|---|---|---|
| `RVMR`(平均回帰) | スプレッド累積のzスコア(過去60日)が **z < −1.5 → LONG / z > +1.5 → SHORT** | z が0を跨ぐ、または**10営業日**で時間決済 | 相対価格の平均回帰 |
| `RVMOM`(相対モメンタム) | スプレッド累積の**過去60日符号**でLONG/SHORT・月次判定 | 翌月次判定まで保有 | 相対モメンタム |

- コスト: 両脚それぞれに`IDX_COST`(FXは`2×pip/price`)を**エントリー時に往復分**計上する。
  中立戦略はコスト感応度が高いため、**片脚ずつ独立に課す**(=単銘柄セルの2倍のコスト)。
- 両型・全11ペア = **22セル**が母集団。

## 5. 倍率規則(実行前固定)— 現行規則に2つの安全条件を追加

中立ペアはボラが低いため、現行の`0.8×min(m*)`規則をそのまま当てると
m*が15〜30に達し得る。**低ボラは低リスクではない**(テールが薄いだけで消えていない)ため、
本トラック専用に条件を追加する:

```
mult = min( 0.8 × min(m*_sel, m*_12m),          # 現行規則(docs/180 §1)
            8.0,                                  # ハードキャップ(現行6.0より緩めるが無制限にしない)
            m_stress,                             # ★新規: ストレス条件
            m_notional )                          # ★新規: 名目レバレッジ条件
```

- **`m_stress`(新規)**: **全期間の最悪単日の3倍**が発生しても静的−10%枠を割らないこと。
  `m_stress = 0.10 / (3 × |全期間最悪単日|)`。中立戦略の主要リスクは
  「片脚だけがギャップする」(指数の祝日ズレ・暗号の週末・個別イベント)であり、
  観測された最悪日はテールを過小評価している前提を置く。
  docs/176のA案「エッジ消滅ストレス」の思想を相対価値に翻訳したもの。
- **`m_notional`(新規)**: 両脚合計の名目総額が口座残高の**10倍以内**。
  Fintokeiのレバレッジ1:25(docs/183 §1)で必要証拠金40%に相当し、余裕を持つ。
  中立戦略は名目が膨らみやすいため明示的に上限を課す。

## 6. 採否の判定基準(実行前固定・後知恵の禁止)

以下を**全て**満たさない限り配備提案を出さない:

| # | 条件 | 根拠 |
|---|---|---|
| 1 | 現ブック近似(`recentfit_nonfx_screen.py`のBOOK_CELLS)との12ヶ月日次相関が **\|ρ\| ≤ 0.25** | 分散が本トラックの存在理由。満たさないなら型が増えていない |
| 2 | US500(市場ベータ)との12ヶ月日次相関が **\|ρ\| ≤ 0.25** | 「中立」の名に値するかの直接検証 |
| 3 | **全期間(悲観)バウンド**のMCで資金化率 > 失格率 | 悲観側で負けている構成は配備しない |
| 4 | 全期間の年率シャープ > 0.5 | 10年通してエッジの符号が正であること。直近フィット系と違い**耐久性を要求する**(中立戦略の売りは構造であり、レジームではない) |

- 条件4は本トラックが**docs/174系の「宝くじ」ではなく構造ベット**であることの表明である。
  直近だけ良い中立ペアは、単に片脚のベータが漏れているだけである可能性が高い。
- 条件1〜4を満たさない場合の帰結: **本トラックは不採用**とし、docs/189に不採用理由を記録して閉じる。
  無理に配備しない(docs/165の月別1位スクリーニング閉鎖の前例に倣う)。
