# 15. v6の抽象化拡張 → 第2エッジ候補「火曜NY午後 USD安ドリフト」(LEAD)

> **出所**: `research/edge_search_session.py`(発見)+ `research/lead_tuesday_usd.py`(性格づけ)。
> 数値は `research/results/lead_tuesday_usd.json` の実値(表示破損を避け、Python内の
> 単一スカラ抽出で検証済み)。data = committed H1(2023-08〜2026-05, **2.8年のみ**)。
>
> ⚠ **本ファイルは「検証済みエッジ」ではなく「リード(有望な手掛かり)」の記録。**
> 短期データゆえ Bonferroni 生存せず。**要・10年H1での追認**(下記§4)。

## 0. 経緯 — 「生きた部分を抽象化して拡張」
ユーザー方針: docs/14 の NEGATIVE(曜日/月末の日足スキャンで新エッジ無し)を受け、
**「今回生きたエッジ(v6)を抽象化して、利益が出そうな手法を探す」**。

v6の本質を抽象化: **「特定の(曜日 × セッション時刻)セルに集中する、価格予測ではない
フロー由来の方向ドリフト」**。円月曜08UTCはその1例にすぎない。
docs/14の日足スキャンは1日を平均して**時刻情報を潰した**ため非JPYで何も出なかった
(解像度の誤り)。そこで **H1で 全9ペア×曜日5×時刻24×方向 = 1080セル** を走査。

## 1. 発見(edge_search_session.py)
- **陽性対照**: EURJPY 月曜 06/07/08 UTC LONG が検出(p≈0.02-0.04, 帯)→ 手法は妥当。
- **新リード**: **火曜 18-19 UTC に AUD/NZD/GBP/EUR USD が同時LONG**(=USD安)。
  複数の相関ペアが同一(曜日×時刻)セルに集中し、隣接時刻(18&19)でも出る = フローらしい。

## 2. 性格づけ(lead_tuesday_usd.py)— 「USD安バスケット」
構成: USDがquoteのペアをLONG(EUR/GBP/AUD/NZD USD)+ USDがbaseをSHORT(USDCHF/USDCAD)、
火曜19UTCにエントリ、24h保有、往復2pip、等加重。

| 指標 | 値 |
|---|--:|
| 純益(2.8年) | **+34.2%** |
| 勝率 | 55% |
| 最大DD | **−5.6%** |
| n(火曜数) | 144 |
| 順列 p | **0.022** |
| 前後半とも+ | ✅ True |

### ゲート結果
- **曜日プラセボ@19UTC**: Mon +5.9%(p.262) / **Tue +34.2%(p.022)** / Wed +7.7%(.288) /
  Thu −1.0%(.516) / Fri +13.7%(.115)。→ **火曜だけが有意**(v6で月曜だけ突出したのと同型)。
- **時刻局在(火曜)**: 17時 p.107 → **18時 +24.8%(p.018)・19時 +34.2%(p.024)** → 20時 p.114。
  → NY午後 18-19 UTC に局在(帯で出る)。
- **コスト感応**: 1pip +39.7% / 2pip +34.2% / 3pip +28.9% / 4pip +23.7%。→ 4pipまで頑健。
- **構成ペア内部相関 0.43**(=主に1つのUSDフロー。6独立証拠ではない)。
- ★**円月曜エッジとの相関 0.17**(低)→ **本物の分散先候補**。
- **2エッジ合算(円月曜+火曜USD)**: 純益 +63.5% / 最大DD **−5.0%**(各単独DD −5.6%/−5.9%より
  改善)→ 相関0.17ゆえ合算でDDが下がる = ポートフォリオ効果の予感。

## 3. これは何か / 機序仮説
NY午後(18-19 UTC)は、ロンドンフィックス(16 UTC)後・米株引け前後のフロー帯。
火曜に系統的なUSD売り(リスクテイク/リバランス)が出ていた可能性。**ただし仮説**。

## 4. ★正直な限界(EAにする前に必ず潰す)
1. **データが2.8年しかない**(火曜144回)。**Bonferroni(α=0.00005, 1080セル)は生存ゼロ。**
   単一セルの p=0.02 は1080回走査では偶然でも多数出る水準。**単体p値は証拠にならない。**
   拠り所は「曜日特異性 × 時刻帯 × 複数ペア整合 × 既存エッジと無相関」の同時成立だが、
   それでも2.8年は短い。
2. **レジーム・アーティファクトの疑い**: 2023-2026はFed利上げ→利下げの特定局面。
   「火曜USD安」がこの3年の地合いの産物で、持続性が無い可能性が十分ある。
3. **構成ペアは相関0.43**=実質1つのUSDフロー。分散の主役はあくまで「曜日が円月曜と違う」点。
4. **要・10年H1での追認**(このコンテナには無い)。10年で曜日プラセボ・時刻帯・OOSが
   再現して初めて「第2エッジ」と認定し、EA化に進む。今EAを書くのはv5の轍(未確認エッジの
   早すぎる実装)。**今回はLEADの記録に留める。**

## 5. 次アクション(推奨)
1. **10年H1データの取得**(`research/fetch_data.py` 拡張 or ユーザー提供)→ 火曜USD安リードを
   本検証ハーネス(順列+OOS+全年JK+Bonferroni)に通す。**ポートフォリオ化の最重要ステップ。**
2. 追認できれば: 円月曜(v6, EURJPY主軸)+ 火曜USD安(EURUSD等)の **2エッジ・ポートフォリオ**
   を、各リスクを合算DD<6%に予算化してEA化。相関0.17なら真の分散になる。
3. 追認できなければ: レジーム・アーティファクトと結論し破棄(docs/14と同じ規律)。
