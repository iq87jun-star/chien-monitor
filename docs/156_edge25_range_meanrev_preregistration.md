## 1. 対象・データ(固定)

- FX 9ペア(v4宇宙): EURUSD/GBPUSD/AUDUSD/NZDUSD/USDCAD/USDCHF/EURJPY/GBPJPY/USDJPY
- `research/data/*_d.csv`(日足OHLC・2016-01〜2026-07)。SHA-256を出力JSONに記録。
- pre-2016参考: 円3クロス+lh系(close-only・2003〜2015)で**close系候補のみ**追試
  (ADXはH/Lが無いため物理的に不可=参考欄に明記)。

## 2. 候補(N=6固定・Bonferroni α=0.05/6=0.0083・グリッド事後選択なし)

レンジ定義(いずれも前日closeまでで確定=no-lookahead):
- **R1**: ADX(14) < 20
- **R2**: BB(20,2σ)相対幅(=(上限−下限)/中心)が過去252日の**20分位以下**
- **R3**: 実現ボラ(20日)が過去252日の**20分位以下**

平均回帰戦略(シグナル=当日close・建て=翌日open・**固定3営業日**後のopenで決済・重複許容):
- **S1**: RSI(2) ≤10 → LONG / ≥90 → SHORT
- **S2**: close < BB(20,2σ)下限 → LONG / 上限超 → SHORT

候補 = {R1,R2,R3}×{S1,S2}の6通り。**レンジON日のシグナルのみ**建てる。
9ペア等加重。コスト=往復2pip基準(感応1/4pip)。

## 3. 判定ゲート(機械適用・全通過でのみADOPT)

| ゲート | 合格条件 |
|---|---|
| G_perm | 月次符号シャッフル順列p < **0.0083** |
| **G_plac(核心)** | **ONマスク円環シフト・プラセボ500draw**(クラスタ構造保存・整列破壊)の**95分位超**。ゲート版≦プラセボ=「レンジ定義に信号価値なし」で棄却 |
| G_base | ゲート版 > 素版(ゲートなし同戦略)。条件付けの寄与そのものの確認 |
| G_loyo | 各暦年除外で符号維持(全year-removedで正) |
| G_oos | IS/OOS(70:30)両方で正 |
| G_cost | 往復4pipでも正 |
| G_pre2016 | close系候補(R2/R3×S1/S2)はlh追試(2003-2015)が非負(参考・ADX系は適用不可と明記) |

- **LEAD** = G_perm+G_plac通過だが他が欠ける場合(記録のみ・年次再測)。それ以外**REJECT**。
- ADOPTの場合もEA化前にデモ必須+Dukascopy確認(docs/138の恒久規則に準拠)。

## 4. KILL基準(先に明文化)

1. プラセボ(円環シフト)に勝てない → 「レンジ定義はただの間引き」=価値なしで棄却。
2. 素版に勝てない → 条件付けの意味なしで棄却。
3. OOSで消える → 過剰適合(E1と同じ墓)。
4. 全滅なら「①×②の複合も閉鎖」とdocs/126の地図に追記し、探索は再び完全終了状態に戻る。
