# 291.【Q1・パリティ A 段】TSMOM 符号一致 — MT5(FN #14074882)vs Python

2026-09-25。ユーザーが `Chien_TsmomSignalDump.mq5` を FN の MT5(口座 14074882 チャート)で実行した CSV(`research/results/tsmom_signals_mt5.csv`)と、研究側 `research/results/tsmom_signals_python.csv`(Yahoo 月足)を突き合わせ。設計 docs/247 §4・実装 docs/253。

## 1. 整列
- MT5 の `month` 列は**符号を計算した月**(`c_last` = その月の終値)、Python の `month` は**建玉を持つ月**。MT5 月 +1 で整列すると符号一致 97.5%、同月では 64% なので、EA の「直近確定月で符号を決めて翌月建てる」実装は研究と同じ時間構造になっている。
- 同月終値の差(データ源の違い): 中央値 0.49%。US500 0.11% / XAUUSD 0.39% / BTCUSD 0.47% / ETHUSD 0.57%。NAS100 だけ **FN の NDX100 が Yahoo ^NDX より恒常的に +9〜15% 高い**(指数の定義差・配当込み等。リターンは一致するので符号には影響なし)。暗号資産は月末クローズ時刻の差で月によって 3〜12% ずれる。

## 3. 判定
- **A 段(符号一致)は通過**(基準: 一致 ≥ 95%・docs/247 §4)。XAUUSD 95.5% と ETHUSD 95.7% は境界だが、不一致の中身が境界事例のみなので実装差ではない。
- FN の月足履歴は US500/NAS100 が 2023-11 から、XAUUSD が 2021-01 からしか無い。テスター(B 段)は 2024-01〜2026-08 なので足りるが、**12 ヶ月ルックバックの初回符号は 2024-12 まで揃わない**(履歴の先頭 15 ヶ月は符号 0 = 建てない)。B 段の比較は 2025-01 以降で行う。
- GER40 は FN の銘柄名を確認して再実行(1 銘柄だけで済む)。
