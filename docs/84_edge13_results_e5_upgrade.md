## 2. E5 — 検証級の正式昇格(本プロジェクトで最長の証拠を持つエッジに)

- **26年(2000-2026)で perm p=0.0007**: docs/40 で唯一の未達だった G3(Bonferroni 0.0083)と
  G5(JK 0.10)を**両方クリア**(JKmax 0.004)。10年でのSTRONG-LEAD止まりは検出力の問題だったと確定。
- **5年ブロック全勝**: 2000-04 +85.4% / 05-09 +69.3% / 10-14 +32.7% / 15-19 +10.4% / 20-24 +29.7%。
  ドットコム崩壊・リーマン・コロナを含む全レジームで正(最弱は2015-19=TSMOM冬の時代、その後回復)。
- **DD懸念への回答(ユーザー質問の核心)**: 26年でも maxDD **−21.7%**(10年の−17.8%と同オーダー)=
  「長期で隠れた更に深いDD」は無い。素のDDが大きいのは事実だが、PortfolioDではE5は
  **リスク予算20%のスリーブ**(プリセットx1.56)に縮小済みで、口座DDに直結しない。
  **導入可否は「E5を入れるか」ではなく「E5レッグの倍率をいくつにするか」の問題**。
- 級の表記: **STRONG-LEAD → ADOPT候補(Yahoo26年)**。確定には (a)別ソース(Dukascopy日足/Stooq等)での
  同窓再現 (b)デモ前進検証、のいずれは引き続き必要(docs/53 §5 規律)。

## 3. v7/E-Mon — 昇格なし+重要な新事実「2016年以前には存在しない」

- v7(円月曜): pre-2016は19年間で**−46.6%**(5年ブロック: 1995-99 −20.3 / 2000-04 −11.9 / 2010-14 −29.0)。
  **エッジは2015年以降に出現**(2015-19 +1.6 / 2020-24 +21.2)。
- E-Mon(株指月曜): 20世紀の文献的「月曜効果」は**負**で、LONGが効くのは2010年代以降
  (2010-14 +31.9 / 2020-24 +19.7)。pre-2016合算は−7.0%。
- **解釈(正直に)**: 両者は v2(レジーム依存で棄却)と違い**直近10年のDukascopy検証は独立に成立**
  しており棄却はしない。だが「**100年級の構造(E5)ではなく、現行レジームの現象**」であることが
  確定した。∴ (a)検証級はこれ以上バックテストでは上がらない=**残る昇格手段はデモ前進検証のみ**
  (b)docs/78 フェーズ5-21 の年次生存確認が v7/E-Mon には特に重要(レジーム転換=死亡があり得る)
  (c)ポートフォリオがE5・v4・G3という別機序を併せ持つ意義が改めて裏付けられた。
