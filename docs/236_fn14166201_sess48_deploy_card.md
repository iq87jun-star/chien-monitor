## 3. リスク(配備前に承知しておくこと)

1. **倍率 4.8 は校正上限に張り付いた値**で、窓内に裾が来ていないことの反映(docs/235 §3)。1 日 −3% 級の事故(2016-10 型)で −14% 換算は起きないが、SL が滑る形の損失は紙上に無い。
2. **FN の指標時間取引規則**は未確認(docs/224 §7 の残件)。16-20 UTC 窓は FOMC(18/19 UTC)を含む。規則が「±2 分禁止」型なら EA 側で回避が要る → 確認するまで **FOMC 当日は `InpSessEnable=false`** を推奨。
3. 20-00 UTC の 3 本同時 $318k は口座の 3.2 倍名目。FX レバレッジ 1:100 なら証拠金 $3.2k で問題ないが、**FN のダイナミックレバレッジ/ティアが 100k 口座に適用されるか**は口座のスペックで確認(証拠金率が 100% を割れば建たないだけで、失格にはならない)。
4. 既存レグ(Hold UK100 72.7%・WTI 22.6%)との合算で、口座全体の日次 σ が上がる。日次 −4% ガードは合算 equity で判定される = **Sess の損失が Hold の建玉を全決済させ得る**(balance ガード)。逆も同じ。

## 4. 手順

1. MT5(#14166201)で既存 EA をチャートから外す → v1.10 をコンパイル → 同じチャートに付ける(`InpInitialBalance` は端末保存値が復元される。`InpBaselineReset=false` のまま)
2. ログに `[INIT Sess v1.10] legs=5 Σw=0.999 mult=4.8 ...` が出ることを確認。`⚠ Sess: 銘柄'EURGBP'を解決できず` が出たら気配値表示に追加
3. 初回の 16:00 UTC(月〜木)で `[Sess ENTRY] SHORT EURGBP h16UTC` を確認。20:00 に 3 本、翌 00:00 に USDCHF
4. 1 週間後にログの `spread=` を集計 → 平均 ≤ 1.0pip なら継続、1.5pip 近辺が多いなら `InpSessMult` を 3.3 に落とす
