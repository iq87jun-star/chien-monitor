## 3. 読み
1. **SKEW(S&P 500 の下方テールの価格)が高い週の月曜は、円クロスの週明け上昇が弱い**(+3.4 対 +11.4 bps)。株式のテールヘッジ需要が強い = リスク回避で円が買われやすい、という仕組みと整合する。Mon4 の月曜の利益を 25% の週で諦める代わりに、分散と最悪月が改善する。累積は IS で 19.9 → 17.5% と**期待は 12% 下がる**(Sharpe 改善は分散縮小による)。OOS は 5.3 → 5.2% で同等。
2. VVIX(VIX の不確実性)は Mon4 では最悪月を悪化させる。「ボラが高い」ではなく「下方テールが高い」ことが円クロスの弱さに対応する。VIX>25 門(Q121 で指数日中版に効いた)も Mon4 では不成立。
3. 指数 Mon は門で改善しない。リスク指標の高い週明けは米指数の反発が大きく、見送ると利益を落とす。Q121 の VIX 門が日中版(13→20 UTC)でだけ効いたことと整合する(翌朝までの保有が反発を拾う)。
4. 運用上の制約: EA は MT5 内で SKEW を参照できない。採用するなら、運用側(手元 PC エージェントや VPS の週次設定)で前金曜の SKEW 分位を計算し、EA の「今週の Mon を見送る」フラグ(`InpSkipThisMonday` 相当・新設)を日曜に書き込む形になる。自動化の経路を 1 本増やす代わりに得るのは期待 −12%・Sharpe +0.5 で、**切替の価値は高くない**。

## 4. 判定・提案
