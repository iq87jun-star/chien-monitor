## 1. 事前固定(docs/244 Q175 の note どおり)
- 基準 = Q176 の EA 実時刻 Mon4(AUDJPY/EURJPY/GBPJPY/USDJPY 等ウェイト・月曜 4/6/8/10 UTC 建て → +24h・往復 3pip・docs/411)。
- 変種 = `data_ext/events_boj.csv` の決定日が火曜である週(2016〜2026-07 で 20 週)の月曜ショットだけ同日 20 UTC 決済(`q114.shot(sym,h,20)`)。他の週は基準と同一。
- 判定 = 改良系(IS 2021-10〜2024-12 と OOS 2025〜 の両方で Sharpe が基準を上回り、最悪月が悪化しない)。

## 3. 中身 — 改善の大半は 2022-12-19 の 1 事象
対象 20 週の夜間(20 UTC → 翌日の建て時刻・手仕舞いで切れる部分)の bps:
- 全 20 週の平均 **−8.9**、うち 2022-12-19(−320)を抜くと **+7.5**。夜間が負だったのは 10/20 週。
- 窓別: 前窓 11 週(夜間 −64.5 / +20.1 / +36.1 / −3.7 / −6.6 / −30.0 / +29.0 / −30.9 / −19.2 / +28.7 / +0.4)、IS 6 週(+10.9 / **−320.3** / +71.1 / +89.5 / +1.1 / +48.5)、OOS 3 週(−11.1 / −15.6 / −10.6)。
- IS の改善(1.38 → 1.67)は 2022-12-19 を切った分であり、他の IS 5 週では夜間は平均 +44 bps で手仕舞いは**損**。OOS の 3 週は全て夜間が負(小幅)で、方向は合うが n=3。
- 参照: 夜間の平均は 全週 +0.6 bps(n=553)・火曜決定週 −8.8(n=20)・水〜金決定週 +0.3(n=64)・日銀なし週 +1.1。火曜決定週だけが負だが、それも 1 事象で決まっている。
- 同じ置換を Mon3(14074882)・Mon2 instG(11988011)に掛けても形式は改善(IS 1.10→1.38・1.27→1.52)。全日銀週(水〜金も)に広げると IS 累積は落ち OOS は上がる(参考・対象外)。

## 4. 読み
- 「日銀火曜の前夜は危ない」という一般則の証拠は弱い(20 週中 10 週は夜間がプラス・2022-12 を抜けば平均プラス)。通過は形式上で、**本質は 2022-12-19 型の事象に対する保険**。
- 保険の値段: 夜間を捨てる費用は 2022-12 抜きで +7.5 bps × 年 2 週程度 = 倍率 1 で年 10〜15 bps(Mon4 の年 230 bps の 5% 前後)。守る側は 10 年に 1 度級の −320 bps(倍率 4〜8 の口座で −13〜−26%、日次限度 5% を 1 日で超える)。期待はほぼ中立、尾部だけ切る形で、docs/411 §8 の「門で最悪日を切れるのは日銀火曜だけ」と整合。
- 日銀の決定日は近年ほとんど木〜金(2016〜 で火曜 20 週・水〜金 64 週)で、OOS に火曜決定は 2025-06-17・2026-04-28・2026-06-16 の 3 回。発動は年 1〜3 回。
