# 359.【Q138】Q137 の型を銘柄別に — 各市場の先物満期週(前半・満期後)と現地の季節イベント(新規 40 セル)
> 2026-10-12(ユーザー「同じ様に銘柄別で試作できますか。現状で網羅してるかもしれませんが」)。docs/357(日本の暦)の横展開。docs/244 §1 のプロトコル(変更しない)。スクリプト `research/queue/q138_local_calendar.py`、結果 `research/results/q138_local_calendar.csv`・`q138_local_calendar_events.csv`。累積 9,710 → **9,750**。

## 0. 既存との重複確認
- docs/251 Q8 は「米祝日の前後・月末最終営業日・第 3 金曜」を **その日 1 日の寄り→寄り**(12 銘柄・日足)で検定済み。満期**当日**はここでは数えない(Q137 の A2・A3 に当たる型は除外)。
- 満期**週の前半**と**満期後 5 営業日**、春節・豪州の会計年度末は、キュー全体(Q1〜Q137)で未検定。
- 各国の祝日 × 採用レグ(Q53・Q56・Q62)は「既存レグのフィルター」で、本項の「指数そのもののドリフト」とは別。

## 1. 事前登録(結果を見る前に固定)
共通: Dukascopy H1 bid・各時刻のバー始値(欠けたら 3 時間以内の次のバー)・コスト `q_common.cost`・L/S を両方セルとして数える。現地の寄り / 引けは UTC 固定の近似(docs/266 と同じ): 米 14 / 20、欧 08 / 16、香港 02 / 08、豪 00 / 06。営業日は現地の祝日表(米 NYSE・英 UK・豪 AU・香港 HK、欧州 2 指数は UK 表で近似)。

### 判定
- E: §1 標準(IS 二項 p < 0.05/9,750 = 5.13e-6・IS 月数 ≥ 24・OOS 平均 > 0・前窓 +月率 ≥ 50%)。前窓は銘柄のデータ開始(2016-01 または 2018-01)〜2021-09。
- S: 年 1 回で IS が 3〜4 回しかなく、**設計上判定不能**。参照としてイベント単位の全期間平均・t・勝率を出す(紙上候補の条件は Q137 と同じ「全期間 t > 3 かつ 3 窓とも同符号」)。
- 上昇相場のベータを除く対照(満期週 vs 他の週)を、通過・有望なセルにだけ出す(セルに数えない)。
- 先物プロップで持てるのは日中だけなので、E・S はどれも CFD のスイング口座向け(日をまたぐ)。

## 3. 読み
- **満期週の型は銘柄間でそろわない。** Q137 の日本(SQ 週前半 L)に当たる E1 は、米・欧・香港・豪のどれでも対照を安定して上回らない。NAS100 E1 は前窓だけ。
- **NAS100 の満期後 L は 3 窓とも対照を上回る**(+27 / +43 / +18 bps)が、同じ満期を持つ US500 は前窓と OOS で対照以下、US30 は前窓 0.44。機構が満期なら 3 指数に出るはずなので、NAS100 だけの上振れはベータ(ハイテクの上昇)とばらつきの範囲と読む。
- **HK50 の春節明け L は 3 窓とも対照を大きく上回る**唯一の季節型(n = 8・t 1.91)。休暇明けの資金回帰という説明はあるが、Q137 の B1(権利取り)と同じく回数が少なく統計的には区別できない。
- AUS200 の 7 月(節税売りの買い戻し)は 9 年全勝だが、上回るのは IS だけで前窓・OOS は他の月以下。
- 欧州 3 指数(Eurex・ICE の満期)には何も無い。

## 4. 判定・次
- **通過 0 / 40。紙上候補の追加なし。配備・EA・先物ボットは不変。** 累積 **9,750**。
- 「各市場の満期週・現地の季節」は、Q8(満期当日・祝日・月末)と合わせて**ほぼ網羅**。残るのは年 1〜2 回の型だけで、どれも回数不足で判定できない。
