# 21. 3本目候補【平均回帰族】10年検定

> docs/20 で2本目(順方向系)が全滅。ユーザー判断で「もう1系統だけ」=構造が直交する**平均回帰**を検定。
> ツール: `research/edge3_meanrev_10y.py` / `notebooks/edge3_meanrev_10y.ipynb`。

## なぜ平均回帰か
v7・gotobi・TOM は全て**順方向ドリフト**系。次に意味があるのは**逆構造=行き過ぎの反動**。
生き残れば v7 と**低/負相関**＝初めての真の分散先になる(順方向をいくら足しても分散にならない)。

## 事前登録(N=4, Bonferroni α=0.0125)
z_t=(r_t−mean_20)/std_20、閾値**1.5σ固定**(チューニングしない)。
| ID | 内容 |
|---|---|
| MR1 | 日次・円3クロス・双方向(z≤−1.5→翌日LONG / z≥+1.5→翌日SHORT) |
| MR2 | 日次・majors(EURUSD/GBPUSD/AUDUSD/USDCHF/USDCAD)・双方向 |
| MR3 | 週次・円・双方向 |
| MR4 | 日次・円・押し目買いのみ(LONG only, ショートswap回避) |
| PLC | プラセボ=ランダム日・**ランダム方向**(双方向の正しい帰無) |

## ゲート(全て10年・採用は全通過)
順列p≤0.0125 / ジャックナイフ≤0.10 / IS・OOS両符号維持 / v7月次相関≤0.4 / プラセボ超え(p非有意かつ候補>プラセボ) / 往復1-4pipで純益+。

## 判定方針
- 10年ADOPTがあれば→デモ前進検証を経て**極小サイズの衛星**として採用検討(v7と負相関なら価値大)。
- ADOPT無しなら→**3本目も見送り。v7一本で確定**し、`v7_budget_resize.ipynb`の実行へ。
- ⚠ 終値モデル探索。DD/合格率はユーザー足内エンジンで別途実測。

### 教訓
- 2.8年のMR1「+5.1%・v7相関−0.21」は**直近サンプルのノイズ**だった。10年フルで−15.2%/DD−20%に反転。
- 平均回帰は円・majorsのこの時間スケールでは順方向ドリフトに負ける(効かない)。
- MR3週次は**ランダム売買(+61.3%, p=0.0)がシグナル(+4.6%)を圧倒** = 反転シグナルは逆効果。
  プラセボ・ゲートと事前登録が無ければ+4.6%だけ見て採用していた罠。**規律が機能した好例**。
