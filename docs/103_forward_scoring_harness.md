# 103. フォワード採点ハーネス — MT5レポート→docs/98分布との自動照合

> docs/99 依頼C-7。docs/96 §3「v7の次のアクション=フォワード採点ハーネス」の実装。
> スクリプト: `research/forward_scoring_mt5.py`(セルフテスト付き・ALL PASS)。

## 1. 使い方(月初のルーチン)

```
# MT5「履歴」→ 期間=前月 → 右クリック「レポート」保存(HTML) → 実行:
python3 research/forward_scoring_mt5.py --file ReportHistory.html --month 2026-06 \
    --balance 100000 --mult 2.0 --dist seasonal:06 [--manual]

# レポートを取らない月は損益$の直接指定でも可:
python3 research/forward_scoring_mt5.py --pl 1211.75 --month 2026-06 --balance 100000 --mult 2.0 --manual
```

- HTML(UTF-16対応)/CSVエクスポート両対応。**Balance/入金行は自動除外**、損益+スワップ+手数料を合算。
- `--mult` で実測を素サイズ1xに換算してから docs/98 §1 の分布と照合(分布は1x基準のため)。
- `--manual` = 手決済が混じる月。判定に「参考: manual-adjusted」ラベルが付く(docs/98 §2の規律)。
- 出力: 分位(%ile)・q25/中央/q75・判定(docs/98 §3 の基準をそのまま実装) →
  `research/results/forward_score_<YYYY-MM>.json` → **docs/98 §2 へ転記**。

## 2. 内蔵分布(docs/98 §1 の転記・1x)

| キー | 分布 | 備考 |
|---|---|---|
| `seasonal:06` | 6月 JUNE_TOP5: 10年サンプル全点 | 分位まで計算可 |
| `portfolioD:06` | 6月 PortfolioD: min/中央/max のみ | 粗判定のみ(docs/98に3点しか無い) |

- **不明月の分布は追加しない**(数字を盛らない)。7月(JULY_TOP2)以降はdocs/87 §2の月次実績を
  年別サンプルとして確定・転記した時点で `DISTS` に追記する(このdocも改訂)。

## 3. 2026-06 の試走(確定分のみ・参考)

docs/98 §2 メモの確定分 **+$1,211.75($100k・2.0x・手決済あり)** を採点:

```
実測+1.212% → 1x換算+0.606% → 分位30%ile
✅ 25-75%レンジ内=エッジ生存(モデル通り)【参考: manual-adjusted】
```

- ⚠ これは**6/9週の確定分のみ**であり6月の月次確定値ではない(docs/98の「記入待ち」は継続)。
  MT5で6月全体の損益合計を出したら本ハーネスで再採点し、docs/98 §2 に確定転記する。

## 4. 規律

- 単月で一喜一憂しない。**最低6ヶ月**積んで「分布内に収まり続けるか」で判断(docs/40)。
- 手決済が混じる月は永続的に「参考」。EA純粋の生存確認には自動決済monthが必要(docs/98)。
- 分布は素サイズ1x・Yahoo近似(2016-2025)。倍率換算は線形近似=大倍率では日次ガードの
  非線形が効くため、実測が系統的に下振れする可能性を頭に入れて読む。

> 免責: 採点は「モデル分布との整合確認」であり将来の性能保証ではない。
