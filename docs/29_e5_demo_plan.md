  XAUUSD/US500/NAS100/GER40 の**各チャートに1つずつ**アタッチ。`InpLegMonthlyRiskPct=0.55`。

### 合格（本資金衛星に昇格）ゲート — 全て満たすこと
1. **期待値**: デモ期間の純益 > 0（コスト/スワップ/配当調整・実約定込み）。
2. **DD**: 実現maxDD ≤ 想定の1.5倍（≦ −9%）。超えたら即減量または停止。
3. **相関**: v7との月次相関 ≤ +0.3（分散先である前提が崩れていない）。
4. **整合**: 方向シグナルの勝率・挙動がバックテスト（勝率66%近辺）と乖離しない。
5. **約定健全**: 指数/金CFDのスプレッド・スワップ・ギャップが想定を致命的に悪化させない。

### 不合格 → 見送り（v7一本に戻す）
- いずれか1つでも明確に外れたら**本資金投入しない**。LEADを無理に採らない（docs全体の規律）。
