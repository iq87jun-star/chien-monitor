# 174.【新トラック・事前登録】直近特化(RecentFit) — 正攻法と別枠の明示的EVベット

> ユーザー方針(2026-07-30):「過去検証から安定しているEA(正攻法)は続けるが、それとは別に、
> **過去1年(極論半年)だけ伸びているEA**を作りたい。本番口座まで到達すれば元が取れるので、
> 数回の報酬でも御の字」。本docはそのトラックの設計・選抜ルール・停止規則の事前登録。
> 実行スクリプト: `research/recentfit_screen.py` / 結果: docs/175。

## 1. このトラックは何であって何でないか(規律の宣言)

- **何であるか**: チャレンジの非対称ペイオフ(費用$549・通過で返金+資金口座の報酬)に対する
  **有償の宝くじ**。直近12/6ヶ月のレジームが**あと数ヶ月続く**ことに張る。
- **何でないか**: 耐久エッジの主張ではない。docs/140-145/165で「事後選抜はLOYOで崩壊する」
  ことを7例連続で実証済み — 本トラックはそれを**否定しない**。LOYO正直値が悪いことを
  **承知の上で**、選抜の後知恵バイアスが「直近レジーム継続」という一点賭けに変わることを許容する。
- **正攻法(docs/172体制)との関係**: 完全分離。別口座・**別業者推奨**。正攻法の配分・倍率・
  ガード思想には一切影響させない。本トラックの成否は正攻法の評価に使わない(逆も同様)。

## 2. なぜEVが立ち得るか(構造)

FN100k基準(docs/24 §): 手数料$549(通過で返金)・資金口座報酬80-95%+通過時一時金15%。

```
EV ≈ p(資金化) × [返金$549 + 初回サイクル報酬] − (1−p(資金化)) × $549
```

docs/175の計測では p(資金化) は直近サンプルで99%・全期間サンプルで65%。真値がその間の
どこにあっても、資金口座で**1回でも**報酬(例: 100kの+4%×80%=$3,200)を取れば
費用2回分($1,098)を大きく上回る。つまり **p(資金化)が5割を切ってもEVは正**になり得る —
これが「過去1年だけ伸びている構成」に張る合理性の全て。逆に言えば、
**費用の上限管理(§5)を破った瞬間にこの合理性は消える**。

## 3. 選抜ルール(実行前に固定・違反したら結果は無効)

1. **データ**: Yahoo日足・凍結窓 2016-01-01〜2026-07-29。直近12ヶ月=2025-08-01〜 /
   直近6ヶ月=2026-02-01〜。
2. **セル母集団**(全て既存スリーブdocs/139と同一構築式・同一コスト):
   Mon(月曜o2o単銘柄: 円クロス7+指数6) / Hold(連続保有: 指数4+金+BTC) /
   TSMOM(月次E5型単銘柄: 6) / v4(日足k≥4合議単ペア: 9) = 計32セル。
3. **フィルタ**: 直近12ヶ月活動日≥15 / 12ヶ月累積>0 / **6ヶ月累積>0**(=直近「も」伸びている)。
4. **ランキング**: score = mean/std×√n(活動日ベース・12ヶ月窓)降順。
5. **選抜**: Top-4。制約=同一銘柄1セル・同一ファミリー2セルまで。加重=逆ボラ(12ヶ月)・上限40%。
6. **倍率**: 0.8 × max{m: 直近12ヶ月の最悪単日×m≥−4% かつ 月中DD×m≥−8%}。速攻変種=×1.5。
7. **MC**: FN Stellar P1+8%→P2+5%・静的−10%・日次はEAガード−4%クリップ・5日ブロックBS・
   シード7・1万パス。**直近12ヶ月サンプルと全期間サンプルの両方を必ず併記**(楽観/悲観バウンド)。

## 4. docs/165(事後選抜の閉鎖)との整合

docs/165が閉鎖したのは「**正攻法の土俵で**月別ランキング上位を採る」こと(=耐久エッジとして
現行より優れると主張する行為)。本トラックの主張は「直近レジームが数ヶ月続くならこの構成が
最速」であり、土俵が違う。ただし docs/165 の教訓は本トラックの**期待値の下限**として生きる:
選抜がノイズなら全期間サンプルの数字(失格25%前後)に収束する — それでも§2のEVは立つ、
という設計にしてある。**「直近で選んだのだから直近の数字が実力」とは決して読まない。**

## 5. 停止規則(事前登録・変更はここへの追記でのみ)

| 規則 | 値 | 根拠 |
|---|---|---|
| 費用予算 | チャレンジ**2回分**で打ち止め | §2のEV計算が成立する上限 |
| 撤退条件 | 失格2回 → トラック終了(再開は新たな事前登録から) | 同上 |
| 賞味期限 | **3ヶ月**(EAに有効期限を焼き込み・期限後は新規停止) | 直近12ヶ月窓の鮮度 |
| 更新手続き | §3のルールを**そのまま**再実行し構成を差し替える(ルール変更は不可) | 選抜の後知恵防止 |
| 資金化後 | 倍率を即座に下げる(標準→0.7x目安)・報酬は都度出金 | 宝くじの当たりを守る |

## 6. 運用上の注意(重複取引・規約)

- 選抜構成(docs/175)の**GBPJPY月曜LONGはFTMO PD口座のv7と同一日・同方向**になり得る。
  同一業者内の複数口座で同一取引を並走させると整合性規則(コピー取引扱い)に触れる業者がある。
  → **正攻法が動いていない業者**で走らせるのが最も安全(例: FN・FTMO・Fintokei以外か、
  FN規則の書面確認(docs/161/173の様式)を先に取る)。
- インスタント口座との同一取引禁止(FN docs/161 §4③)にも留意。
- EAはv1.44系ガード(balance基準−4%ティック評価・フロア−9%・利益ロック)を全て継承済み。
