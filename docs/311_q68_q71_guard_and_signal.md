## 2. 結果(新規通過 0・改良 0)
### Q68(16): 0
| ペア | 東京窓 陰線の週(n / 07→翌07 bps) | 陽線の週 |
|---|---|---|
| GBPJPY | 262 / +8.2 | 290 / +5.0 |
| AUDJPY | 265 / +9.0 | 287 / +7.3 |
| EURJPY | 266 / +6.6 | 287 / +5.7 |
| USDJPY | 273 / +3.7 | 280 / +4.1 |
東京窓の符号は翌日までの利益を予測しない(陰線の週の方がやや良い = 軽い逆張り)。−1×ATR で手仕舞うガードは 5 年で 120〜137 週が該当し、Sharpe を大きく下げる(Mon4 IS 3.10 → 2.23、OOS 2.44 → 1.86)。**東京で下げた週ほど欧州で戻る**ので、途中手仕舞いは逆効果。

### Q69(14): 0
| ペア | キャリー ≥1pp(n / bps) | <1pp(n / bps) |
|---|---|---|
| GBPJPY | 220 / **+13.5** | 300 / −0.8 |
| USDJPY | 376 / +3.4 | 168 / −0.6 |
| EURJPY | 194 / +7.4 | 346 / +4.6 |
| CHFJPY | 93 / +9.1 | 451 / +1.1 |
| AUDJPY | 389 / +6.5 | 144 / **+12.0** |
| NZDJPY | 439 / +6.2 | 102 / +9.7 |
GBPJPY・USDJPY・CHFJPY は高キャリー期に効き、AUDJPY・NZDJPY は逆。キャリーが機構ではなく、時期(2022 年以降の円安局面 = 高キャリー期)の代理変数。門としては使えない(2022 年以降はほぼ全ペアが ≥1pp で OOS の判定材料が無い)。

### Q70(9): 0
ガード日の SHORT は IS で 7 ペア中 5 が +2〜+10 bps だが月数 22〜33 で OOS はまちまち(GBPJPY はマイナス)。3pip コスト後の期待値が小さく、年 10 日前後では p が積めない。「建てない」が正解で「逆に建てる」は不成立。

### Q71(4): 0
ギャップ幅上位 10% の週(162 週)を除外すると IS Sharpe 3.58 → 4.24 だが **OOS は 2.15 → −1.03**。2025〜26 の月曜の利益は大きなギャップの週に集中(のみセル OOS +23 bps)。ギャップ幅ガードは OOS を壊す。順張り・逆張りとも効果なし。

## 3. 判定
- ガードと探索を兼ねる条件は 4 家族すべて不成立。**Mon の途中で判断する材料(東京窓・ギャップ)は無く、建てたら 24h 持ち切るのが最良**。キャリーは時期の代理でしかない。
- 累積 9,185。参加者フィルター(祝日系)以外に月曜レグを改良する条件は見つからない。探索は打ち止めとし、Q1 TSMOM の EA 化と紙上フォワードに戻る。
