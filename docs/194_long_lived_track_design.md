## 2. 目的関数が違う — 「宝くじ」と「年金」を混ぜてはいけない

docs/174 §1は直近フィットトラックを「耐久エッジの主張はしない/有償の宝くじ」と定義した。
その目的関数は:

```
EV_宝くじ = 資金化確率 × 初回サイクル報酬 − 掛金        … 速度が効く・失格は掛金の喪失で有限
```

長寿命トラックの目的関数はこれではない:

```
EV_年金 = 資金化確率 × 期待寿命(サイクル数) × サイクル報酬 − 掛金   … 失格が寿命を切るため失格率が支配的
```

**現行8口座の設計は全部が前者に最適化されている。** 所要日数の中央値を短くし、
失格率20〜35%を受容している(docs/187 §3)。後者では失格率がそのまま期待寿命を切るため、
同じ設計を流用してはいけない。

docs/191 §5は「時間制限が拘束条件の口座(速攻プロ60日)では速度に価値がある」と記録したが、
長寿命トラックはその**正反対の象限**にある。

## 3. docs/187が与えた設計指針 — ブロード配分は長寿命の目的関数に直接刺さる

| アーム | OOS年率 | シャープ | **失格率(FTMO)** | 資金化率 | 回転率 |
|---|--:|--:|--:|--:|--:|
| SEL12(現行B案系の規則) | 14.55% | 0.89 | **31.7%** | 60.8% | 0.371 |
| **BROAD_IV** | **17.36%** | **1.25** | **11.9%** | 65.9% | **0.027** |

1. **失格率が1/2.7になる。** これは長寿命トラックの目的関数そのものである。
   宝くじ枠では「掛金が消えるだけ」だった失格が、年金枠では「寿命の切断」になる。
2. **回転率2.7%** = 月次でほぼ入れ替えない。長期保有・低運用負荷と整合する。
3. 資金化率も年率もシャープも上。つまり長寿命枠に限れば**トレードオフが無い**。
4. docs/187 §2.2の通り、分散が倍率規則を通じて自動的に高い倍率を許す(4.30 vs 2.99)。
   長寿命枠ではこの余地を**レバレッジではなく安全余裕として使う**(§4)。

## 4. 設計案(10月に事前登録する内容の骨子)

| 項目 | 案 | 根拠 |
|---|---|---|
| 母集団 | 34セル(Mon 13 / Hold 6 / TSMOM 6 / v4 9) | docs/174と同一。新しい型を追加しない |
| 選抜 | **なし**(BROAD_IV) | docs/187 §1。選抜にコストを払う根拠がない |
| 除外 | **実装可否・規約適合のみ**で除外し、事前登録に明記 | docs/184 §1・docs/178 §2の前例。**成績を見てからの除外は禁止** |
| 加重 | 逆ボラ・cap40% | docs/187でBROAD_EW(等加重)は倍率2.10まで落ちる=逆ボラは効いている |
| 倍率 | `0.8×min(m*)` 規則の **0.5〜0.7倍** | docs/174 §5の「資金化後は0.5〜0.7xへ減率」を**最初から**適用。§3.4の倍率余地を安全余裕に回す |
| 入替 | **年1回**(または入替なし) | 回転率が低いほど良いという docs/187 §2.1 の含意 |
| 期限焼き込み | **なし** | 期限焼き込みは「賞味期限」がある直近フィット固有の装置。ブロードは特定レジームに賭けていない |
| 停止規則 | 期限ではなく**成績基準**で定義する(月次R<0の連続月数など。具体値は事前登録時に固定) | 期限が無い以上、撤退条件は別途必要 |

### 4.1 倍率を下げる方向に使う理由

docs/187 §2.2でBROAD_IVは倍率4.30まで許された。しかしこれは
「−4%/日・−8%月中DDに収まる最大」であり、**失格率11.9%を前提とした値**である。
長寿命枠では0.5〜0.7倍(実効2.2〜3.0)へ落とし、失格率をさらに下げて寿命を買う。
**同じ分散を、宝くじ枠は速度に、年金枠は寿命に変換する** — これが2つの枠の設計上の分岐点である。
