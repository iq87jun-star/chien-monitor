## A. 2本目=多資産トレンド(edge5) — 未トライ唯一の土俵を検定

### なぜ多資産トレンドか
FX内の2本目はv8/gotobi/TOM/平均回帰/モメンタム系まで全滅(docs/14,17,20,21,22)。docs/22の教訓
=「時系列モメンタムは**複数資産クラスの分散バスケット**でこそ機能し、FX単体は不振」。その唯一の
未トライ土俵=**金・株価指数・暗号の多資産トレンド**を、edge4と同一規律(事前登録N=6・Bonferroni
α=0.0083・順列・ジャックナイフ・プラセボ・v7相関・コスト)で検定。
データ: XAUUSD(金GC=F)/US500/NAS100/GER40/BTCUSD/ETHUSD 日足10年。

### ★方法論の修正(重要・自己批正)
初回実行でMA5 Donchianが「ADOPT 6/6・p=0.007」と出たが、**経路依存系(同一建玉を数週間保有)は
日次リターンが正に自己相関し順列pが過大評価**になる。月次集約してブロック単位で符号シャッフルする
**自己相関頑健版**に是正したところ **p=0.007→0.023**(Bonferroni 0.0083を外す)。
→ ジャックナイフも頑健版に変更。**gateは頑健pを使用**。これがなければ偽ADOPTを採るところだった。

### 10年実測結果(2026-06-02・Drive実行=v7基準120ヶ月・頑健版・ADOPTゼロ)
**※下表はユーザーDrive(FX=10年Dukascopy, 多資産=Yahoo日足10年)での確定値。** v7相関は10年120ヶ月で算出。

> (2)**MA6がLEAD→REJECTに降格**。MA6=多資産＋FX8だが、Driveの**FX8がフル10年(Dukascopy)**になると、死んでいる
> FXトレンド(docs/22)がクラス横断バスケットを薄め、頑健p=0.20・純益+31%へ悪化=正しい降格。LEADは**3本に確定**。

### 解釈(誠実に)
- **これはedge2/3/4(全て一律マイナス)より明確に前進**。多資産トレンドは**プラス期待値＋v7と独立
  (相関−0.17〜+0.06)**=初めて「正の方向かつ分散先になりうる」兆候。だが**どれも事前登録の厳格な
  有意水準(Bonferroni 0.0083, JK≤0.10)を満たさない**=LEAD止まり。
- **MA5(Donchian)**: 純益+1723%は派手だが、(a)頑健p=0.023でBonferroni非通過、(b)maxDD−78%、
  (c)利益はBTC/ETHの上昇トレンド支配・年次−27/−33/−40%の暴れ。**素サイズはプロップ−10%口座で不可**。
- **MA2(金+指数, 暗号除外)が実質最良のLEAD**: maxDD−19.9%と相対的に正気、**OOS+28.4>IS+18.6で
  減衰なし**、勝率63%、コスト20bpsまで+。有意水準は未達だが性質が最も健全。
- **全候補に共通の致命点**: maxDD が −20〜−94%で**FundedNext −10%上限と非両立**。採るなら
  大幅縮小サイズの衛星＋デモ前進検証が前提。本資金即投入は不可。

### 結論・次アクション
- **クリーンなADOPTは無い → 本資金の2本目はまだ無い。v7が引き続き唯一の検証済みエッジ。**
- ただしMA2/MA5は**「破棄」ではなく追検すべきLEAD**(edge2/3/4とは質が違う)。次段:
  1. MA2を主対象に**デモ前進検証**(小サイズ)で正の期待値が前進で再現するか。
  2. 足内エンジンで**−10%口座に収まる縮小サイズ**でのDD/合格率を実測。
  3. 暗号を含む系(MA5)は約定/スプレッド/ギャップが過酷=慎重に。
- 規律: LEADを「有意」と誇張しない。当たるまで候補を増やさない(N=6で確定)。

### A.2 v7 vs MA2 比較(`compare_v7_ma2()` / ノート②セル)
「2本目候補MA2はv7とどう違い、足し合わせる価値があるか」を月次リターンで直接比較。
サイジングの恣意性を消すため**ボラ10%/年に正規化した素の質**で比較する。

| 指標(ボラ10%正規化) | **v7**(円月曜LONG) | **MA2**(金+指数TSMOM) |
|---|--:|--:|
| Sharpe | **1.47** | 0.45 |
| CAGR | **+15.2%** | +4.1% |
| maxDD | **−3.7%** | −16.6% |
| 勝率 | 62% | 63% |

- **素の質はv7が約3倍**(Sharpe1.47 vs 0.45)・DDも浅い。コアは断然v7。
- ただし**v7の数値はローカル2.8年=直近の好レジーム**で楽観寄り。MA2は弱い2019〜2023を含む10年フル。
  **公正な10年同士はDriveで`compare_v7_ma2()`を実行**(v7=120ヶ月)して確定すること。
- **相関は10年で−0.16(負)** = MA2はv7とほぼ逆方向に動く=**分散先として有効**。
- ブレンド(ボラ正規化, ローカル重複でも): v7:MA2を 100:0→70:30 にすると Sharpe 1.47→1.72 へ上昇。
  相関が負(Drive)ならさらに効く。**ただしMA2はLEAD(未検証)=配分はデモ追検後に少量から**。
- **検証ステータスの差を忘れない**: v7=全ゲート通過＋WF頑健の**検証済みエッジ**、MA2=有意水準未達の**LEAD**。
  相関が良くてもMA2に等加重は時期尚早。順序は「v7主力 → MA2デモ追検 → 再現したら小ウェイト衛星」。

## B. v7確度検証 — 過去データで埋められる確度を測る

### 方法(`colab_v7_confidence.py`)
固定予算 週次0.6%(DD安全帯)で:
- (A) **ウォークフォワード**: 10年を時間等分割し各サブ期間の net/maxDD/Phase1合格率。符号の安定性
  =レジーム非依存の証拠。
- (B) **パラメータ頑健性**: 入口時刻/ATR係数/ペア除外/曜日 をずらしてもnet>0・低DD維持か。
- (C) **別ベンダー照合**: Dukascopy vs 研究データで結論一致を確認(節で手順案内)。

### ★10年Drive実測結果(2026-06-02・9.97年6209ショット・予算0.6%) — 確定値
**全期間: net+28.6% / maxDD 6.13%(−10%内) / Phase1合格 62.6%(中央20.0ヶ月)。**

(A) ウォークフォワード5分割(黒字 **4/5**):
| 期間 | net | maxDD | P1合格 | P1中央月 |
|---|--:|--:|--:|--:|
| 2016-01..2018-01 | **−2.6%** | 5.37% | 6.4% | 18.6 ✗ |
| 2018-01..2020-01 | +4.8% | 4.44% | 53.1% | 20.3 ✓ |
| 2020-01..2022-01 | +9.7% | 3.41% | 90.0% | 15.7 ✓ |
| 2022-01..2024-01 | +11.1% | 2.57% | 96.0% | 15.7 ✓ |
| 2024-01..2025-12 | +5.6% | 2.20% | 64.5% | 21.2 ✓ |

(B) 頑健性(全て黒字維持):
- 入口時刻4変種 net **+20.2〜+33.9%** / maxDD 5.3〜6.1%(基準依存でない)
- ATR×{2.0,2.5,3.0} net **+24.7〜+32.6%**(SL幅に過敏でない)
- ペア除外(各1) net **+17.2〜+21.8%**(単一ペアが牽引してない)
- **曜日プラセボ: 月曜+28.6%(DD6.1%)だけが黒字**。火−7.4/水−6.2/木−14.7/**金−61.8%(DD63%)**
  =他曜日は壊滅。**v7の月曜特異性が10年で決定的に確認**(過剰最適化でない最強の証拠)。

### 解釈(10年確定)
- **v7の確度は高い**: 10年で予算0.6%なら **net+28.6%・maxDD6.13%(−10%内に収まる)・Phase1合格62.6%・
  合格中央20ヶ月**。時刻/ATR/ペアの摂動に頑健、**月曜特異性は他曜日全敗(金−61.8%)で決定的**。
  これまでのETA/合格率の数値は10年で裏付けられた=**相応以上に信用してよい**。
- 唯一の留意: **最古の2016-2018サブ期間のみ−2.6%/合格6.4%**(直近8年は全て黒字)。エッジが近年強まった
  のか初期のデータ品質か。いずれにせよ直近レジームは強い。最終確度は(C)別ベンダー＋デモ前進で確定。

## 総括
- **②2本目**: 多資産トレンドに**正の兆候(LEAD×3: MA1/MA2/MA5)**=FXより筋が良い。ただし有意水準未達＋
  DD過大(−20〜−94%)で**本資金採用は不可**。MA2(v7と10年相関−0.16・DD−19.9%)を主対象にデモ追検する
  価値あり。**現時点の確定はv7一本**。
- **①確度**: v7は10年で**net+28.6%・maxDD6.13%(−10%内)・合格62.6%**、頑健性・月曜特異性(他曜日全敗)で
  **高い確度**を確定。残る不確実性は別ベンダー＋デモでのみ埋まる(最古2016-18期だけ弱い点に留意)。
- 次: (1)v7運用化(予算0.6%・サイズ確定)を主、(2)MA2をデモ衛星で小さく追検、(3)結果次第で再評価。
