問い: 季節・PortfolioD と X_MOM を並走させた場合のポートフォリオ効果(自己口座・規制なしで比較)。
方法: docs/101 と同一の意味論(各スリーブを月次vol1%にz正規化した系列上のリスク予算)。

  114共通月(2016-07〜2026-06)。X_MOM は「絶対(現物ロングのみ)」と「超過(指数先物ヘッジ版)」の2形態。

## 3. 読み(本書の核心)

1. **効果は本物**: 絶対版20%で Sharpe 1.41→1.67(+18%)。30%で+21%だがDD悪化が始まる。
   **リスク予算20%前後が効率の膝**。
2. **ただし絶対版の改善の相当部分は「株ベータの追加」**: 現行4スリーブは株ベータをほぼ
   持たないため、単に指数を足しても Sharpe は上がる(edge11-F2 の教訓と同じ構図)。
   **検証済みアルファ純度の高い効果はヘッジ版10%の +0.06(1.41→1.47)と、
   DD/最悪月の改善(−1.10→−0.95 / −1.00→−0.87)** = ヘッジ版はリスク低減部品。
3. 使い分けの含意(自己口座・規制なし):
   - 「リターンを足したい」→ 絶対版 20%(ベータ込みと自覚して保有。暴落時は指数と同時に沈む)
   - 「安定性を足したい」→ ヘッジ版 10%(現物10銘柄ロング+MES先物ショート。ρ≈0.03の純アルファ)
4. プロップ規制なし前提の注記: 本計算に日次ガード・失格・整合性ルールの影響は無い。
   プロップ内では X_MOM は不適合のまま(docs/185)。この効果は自己口座レーン専用。

## 4. 制約

- z空間(リスク予算)の比較であり、実弾の絶対額はスリーブごとの実効レバに依存。
- 絶対版の水準には生存者バイアス+強気10年が乗る(docs/193 §2)。Sharpe比較の相対構造が主結論。
- 実装判断は X_MOM 前進検証(docs/194)の合格後。配分変更は docs/101 の規律
  (ユーザー承認→審査MC→デモ)に従う。
