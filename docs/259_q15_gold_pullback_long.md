## 3. 読み方

1. 16 セルすべて IS 平均が負(最良 XAGUSD 門なし k=1 24h の −0.04 bps)。IS で押し目は戻らず、コストだけ残る。
2. OOS(2025〜)は XAGUSD 24h で +22〜+32 bps と大きく正だが、これは 2025 年の銀の一方向上昇(常時 LONG でも同じ)で、押し目の効果ではない。IS で負・OOS で正はレジームの射影。
3. XAUUSD は前窓なし(データ 2021-01〜)のため IS/OOS のみで判定(docs/256 §4)。門ありは月数 30〜31 で判定可能だが、IS 14/30。

## 4. 判定
