## 1. 仮説と設計
- 対象: Mon ETHUSD(EA11 トパーズの Mon レグ .036、14166201 G 案の ETHUSD レグ)。現行の出口は建てから 24h(研究セル `mon_cell` = 日足 o2o)。
- 変種(事前固定・格子探索なし): 12h / 36h / 翌日 NY 引け(火曜 16:00 ET)/ 24h+トレイル(直前 24 本 ATR × 1.0 を高値から割ったら引ける、それ以外は 24h)。
- データ: Dukascopy H1 ETHUSD 2018-01〜2026-08、月曜 00:00 UTC 始値で建て、往復 15 bps(基準と同じ)。H1 で作った基準 24h は日足 `mon_cell` と相関 0.996(n=443)。
- 判定: docs/244 §1 改良系 = IS(2021-10〜2024-12)と OOS(2025-01〜)の**両方で Sharpe が基準を上回り、最悪月が悪化しない**。有意性検定はしない。セル 4 を累積に加算。

## 3. 判定
4 セルとも棄却(正常)。累積セル 9,688 → **9,692**(Bonferroni 閾値 0.05 / 9,692 = 5.16e-6・本項は改良系で非適用)。現行 24h を維持。

## 4. 提案(11 月の EA 改訂への含意)
- 出口の変更で ETHUSD Mon は改善しない。**基準そのものが弱い**(IS Sharpe 0.26・OOS −0.06・前窓 0.03)ので、論点は出口ではなく「レグを残すか」。Q92(指数 Mon の継続判定)と同じ停止規則(docs/276)を ETHUSD Mon にも当てて、11 月改訂で EA11 の `InpMonLegs` から ETHUSD:0.036 を外す案を比較する(重み 3.6% なので帳簿への影響は小さい)。
- トレイルは最悪月を −14% → −5% に縮めるが Sharpe を壊す。ガードとしての価値は口座ルール(日次 5%)の内側に既にあるので採らない。
