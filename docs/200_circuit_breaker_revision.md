# 200.【事前登録・改訂】サーキットブレーカーの発火条件 — 短命設計の口座を発火カウントから除外

> 2026-09-01。**ユーザー決定「短命口座を発火カウントから除外」**(docs/199 §8.5の提起への回答)。
> docs/185 §2 を本docで改訂する。実行前(=次の失格発生前)にルールを凍結する。

## 1. 何が問題だったか

docs/185 §2の現行規定:

> **30日以内に2口座以上が失格した場合、原因を問わず全トラックの再起・新規購入を凍結**し、
> 全体postmortem(相関・レジーム・実装の3面)を完了するまで解除しない。
> 根拠: FX系口座間の実測相関0.5〜0.85では、複数同時失格は「個別の不運」ではなく
> **共通要因(円急騰・リスクオフ・レジーム転換)の顕在化**とみなすのが正しい事前確率。

docs/199 §8で現ブックを実測したところ、**この装置は悲観バウンドで54.33%の確率で発火する**。
しかも発火の原因は共通要因ではない:

| 口座 | 悲観バウンドでの失格率 | 性質 |
|---|--:|---|
| **Fintokei速攻プロ2000万** | **90.1%** | 静的−3% + **60営業日で時間切れ=失格**(docs/183 §1) |
| **FN Instant 20k** | **77.8%** | トレーリング−6%・**目標が無いため走り続ける**(docs/177 §1) |
| FN100k(非FX) | 36.5% | 通常のチャレンジ |
| FTMO100k(A案) | 29.7% | 同 |
| FTMO50k(D案) | 19.9% | 同 |
| FTMO50k(C案) | 11.6% | 同 |
| Fintokeiパール(B案) | 11.0% | 同 |

上位2口座だけで P(2件以上) ≈ 0.901 × 0.778 ≈ **70%**。
**共通要因が何も起きなくても、この2口座の寿命が30日以内に重なれば発火する。**

これは誤検知ではなく**設計の不一致**である。両口座とも短命・口座喪失を**承知の上で**配備している:

- docs/183 §2「悲観の中央値はゼロ(73%は掛金全損)・昇格後も−3%静的が永続する**短命設計**」
- docs/177「最悪ケースはトレーリングMLL−6%接触=口座喪失(掛金$599+将来収益)を承知の上での決定」

**装置が検知したい事象(共通要因の顕在化)と、実際に発火させる事象(短命口座の寿命到達)が
一致していない。** 発火すれば「全トラックの再起・新規購入を凍結」が起動するため実害がある。

## 2. 改訂(docs/185 §2を上書き・実行前固定)

> **30日以内に、`発火カウント対象口座`のうち2口座以上が失格した場合**、原因を問わず
> 全トラックの再起・新規購入を凍結し、全体postmortemを完了するまで解除しない。

### 2.1 発火カウント対象口座(実行前固定)

**対象**: 通常のチャレンジ/資金化口座。2026-09-01時点では次の5口座:

| 口座 | 根拠 |
|---|---|
| FN100k #14074882(季節RG3) | 通常のチャレンジ |
| FTMO100k #531343523(A案) | 同 |
| FTMO50k #531407058(C案) | 同 |
| FTMO50k #521100397(D案) | 同 |
| FN100k #14166201(非FX) | 同 |
| Fintokeiパール500万(B案) | 同 |

**除外**(短命設計を事前に承知して配備した口座):

| 口座 | 除外理由(配備時の記録) |
|---|---|
| **Fintokei速攻プロ2000万 #6078225** | docs/183 §2「悲観の中央値はゼロ(73%は掛金全損)・**短命設計**」。60日時間切れが失格扱い |
| **FN Instant 20k #11988011** | docs/177「最悪ケースは**トレーリングMLL−6%接触=口座喪失**を承知の上での決定」 |

### 2.2 除外口座の失格は無視するのではない

除外は**サーキットブレーカーの発火カウント**からのみである。以下は従来通り適用する:

1. **docs/185 §1の汎用プロトコル**(48時間冷却・型診断・記録義務)は**全口座に適用**する。
2. **型(c)(実装・運用欠陥)と判定された場合は、除外口座であっても
   docs/185 §1.3により全トラックの再起を凍結する**(共通コードベースのため)。
   除外はあくまで「型(a)=モデル内の不運」に対してのみ意味を持つ。
3. 除外口座の個別撤退規則(docs/183 §6の24hフロー・docs/177 §4のトラック終了)は不変。

### 2.3 新規口座の分類

新規に口座を購入する際は、**配備カードに`発火カウント対象=Yes/No`を明記する**。
Noとするのは次のいずれかを満たす場合に限る:

- 配備カードに**短命設計であること**が明記されている(掛金全損が中央シナリオ)
- **時間切れが失格扱い**の評価期間を持つ
- **目標が無く、トレーリングDDのみで終了する**口座

分類は**購入前**に決める。失格が起きてから分類を変えてはならない。

## 3. 改訂の効果(docs/199 §8.3の実測)

| | 発火確率(悲観バウンド・250日地平) |
|---|--:|
| 旧規定(7口座すべてをカウント) | **54.33%** |
| **新規定(5口座をカウント)** | **16.85%** |

**発火が「ほぼ確実」から「起これば異常」へ戻る。** 16.85%は依然として低くないが、
これは現ブックが実際にFX集中している(docs/199 §8のρ 0.42〜1.00)ことの反映であり、
装置が検知すべき事象そのものである。

## 4. 承知している限界

1. 16.85%は**悲観バウンド(全期間サンプル)**の値である。直近12ヶ月サンプルではより低い。
2. FN100k #14074882(季節RG3)は生成式が再構築できずMCに含まれていない(docs/199 §6.1)。
   実際の発火確率は本doc §3の数値と異なり得る。**§2.1では発火カウント対象に含める**
   (MCに含められないことと、規則の対象であることは別問題である)。
3. 短命口座の除外は「型(a)の不運」に対してのみ有効であり、**型(b)(モデル外の事象)が
   短命口座を巻き込んだ場合を見逃す**可能性がある。docs/185 §1.4の
   「型(b)は同族トラック全部に波及チェック」がその補完として機能する前提とする。

## 5. 適用

- 本docは**docs/185 §2を上書き**する。docs/185本体には本docへの参照を追記する。
- 2026-09-01以降に発生する失格から適用する。
