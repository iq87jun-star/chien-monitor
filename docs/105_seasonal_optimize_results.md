## 0. 一行結論

**現行YEARROUND_05(R1)の月別性は本物(プラセボp=0.035で合格)だが、そのまま使うのは非効率。
「月別重みを25〜50%だけ使い、残りを年間固定配分(v4 30/v7 25/E-Mon 25/E5 20)に収縮」した
R3a/R3b が LOYO OOSで Sharpe 1.33前後・maxDD半減以下を達成し、決定規則を満たした。**
実装は事前登録どおり: ユーザー承認 → 倍率校正 → EA新シナリオ追加 → デモ並走の後のみ。

## 2. 読み方(誠実に)

1. **現行R1の弱点は「集中月のテール」**: 月別比例は強い月に全振りするため、maxDD−13.5%・
   最悪月−6.3%と重い(R2a top-1はさらに極端で−28.6%=集中の害の実証)。
2. **収縮(R3)は月別情報の「量」を落とさず「濃度」を薄める**: 月別性の価値(プラセボ合格)を
   固定配分の分散に乗せることで、**リターンを2〜7割保ちつつDDを1/2〜1/3に圧縮**。
   FN審査(+8% vs −10%・日次−4%ガード)は**Calmar競争**なので、この形が構造的に向く。
3. **タイブレークの正直な開示**: 事前登録(docs/104 §4)は「合格候補が複数の場合」の優先順位を
   固定していなかった。合格は R3a/R3b/R4 の3つ。機械選択(スクリプトの列挙順)はR3aだが、
   **これは事後選択になるためここで確定させない**。差は小さく、性格は
   R3a=最防御(DD−4.5%・Calmar1.37) / R3b=バランス(月利+0.64%) / R4=最リターン寄り(+0.85%)。
4. 2026H1参考(LOYO外・訓練2016-2025): R1 +16.4% / R3a +6.0% / R3b +9.4%(2026H1は月別選択に
   有利な半年だった=単期間で判断しない)。
5. ⚠ 限界(docs/104 §5): スリーブ候補集合自体の選択バイアスは消えない。Yahoo近似。
   合格しても検証級は各エッジ個別のまま=**デモ前進検証が最終判定**。
