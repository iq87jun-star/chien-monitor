## 2. 事前登録する3候補（パラメータは本書で確定・以後変更しない）

時刻は全てUTC。pip往復コスト = スプレッド + 2×スリッページ（`research_backtester.py` と同表）。
ATR%(h) = 直近 `VOLWIN=24` 本のH1リターン絶対値の中央値（足内ボラの頑健尺度）。エントリは確定足の
**次足始値**、約定は始値（ノールックアヘッド）。SLは足内で触れたら即決済。全候補**同日内で必ずクローズ**。

### C1 — Intraday Impulse Fade（足内インパルス・フェード＝足内平均回帰）
- **仮説**: 流動時間帯で1本のH1が過大に動いた直後は、同日内で一部巻き戻す（マイクロストラクチャの行き過ぎ）。
- **構造（v4=日足8日MRとは別物。こちらは時間単位・同日完結）**:
  - 監視窓: entry_hour ∈ {8,9,…,17}（ロンドン〜NY前半）。
  - トリガ: 直前確定足の \|return\| ≥ **θ=2.0 × ATR%**。
  - エントリ: その**逆方向**に次足始値で建てる（方向は構造で決定＝後付けでない）。
  - 決済: **H=4時間**保有 か SL=**2.0×ATR%** 到達、または **20:00 までに強制クローズ**。
- **固定パラメータ**: θ=2.0, H=4, SL=2.0×ATR%, 監視窓 08–17, 強制クローズ 20:00。

### C2 — Compression Breakout（ボラ圧縮ブレイク・ロンドン始値・条件付き）
- **仮説**: アジア終盤にレンジが圧縮した日は、ロンドン序盤に圧縮レンジを抜けた方向へ短時間続伸する。
- **構造（無条件ORB=v3a棄却済みとの差＝「事前の圧縮」を必須条件にした点）**:
  - 圧縮判定: 直前6時間(01–07)のレンジ幅 < **0.5 × (24h ATRレンジ)**。
  - エントリ: 07–10 の各足で、圧縮レンジ上限/下限を**先に抜けた方向**へ建てる（方向は値が決める＝後付けでない）。
  - 決済: **16:00 強制クローズ** か SL=反対側レンジ境界。
- **固定パラメータ**: 圧縮比 0.5, 圧縮窓 01–07, ブレイク監視 07–10, クローズ 16:00。

### C3 — Asia→London Conditional Reversal（前セッション過大→ロンドンで反転）
- **仮説**: アジア時間に過大に動いた通貨は、ロンドンでその一部を戻す（オーバーナイト・フローの反転）。
- **構造（edge7=無条件ドリフトとの差＝「アジアの過大変位」を条件にし、方向を反転に固定）**:
  - 条件: アジア(00–07)の変位 \|Δ\| ≥ **0.4 × (24h ATRレンジ)**。
  - エントリ: 07:00 始値で**アジアと逆方向**に建てる。
  - 決済: **13:00 強制クローズ**（同日・ロンドン内）か SL=2.0×ATR%。
  - **プラセボ**: 同条件で「アジアと**同方向**（継続）」を別途記録するが、これは検定ではなく **G4プラセボ**
    （反転の符号が偶然でないことの確認）に使う。継続が反転より良ければC3は棄却。
- **固定パラメータ**: 閾値 0.4, アジア窓 00–07, エントリ 07, クローズ 13:00, 方向=反転。

## 3. 多重検定の母数（Bonferroni）を**事前確定**

- パラメータは各候補で**固定**（グリッドサーチ無）。よって検定数は構造的に:
  - **主検定 = 3候補のプール検定**（各候補・全9ペア合算のOOS perm_p）。**α_family = 0.05/3 = 0.0167**。
  - **副次 = 9ペア個別**（3×9=27 ペア検定）。保守的全体補正 **α_strict = 0.05/27 ≈ 0.00185**。
- 採用ヘッドラインは**プール検定 perm_p < 0.0167**（G3）。ペア個別は頑健性（一貫性）確認用。
- **過去探索の通算**: 本プロジェクトは延べ多数（v1-v9, E1-6, edge2-9）を試行済み。プロジェクト通算の
  Bonferroniは更に厳しい＝**本書3候補が予備で当たっても「LEAD候補」止まり**とし、確証は10年Dukascopy
  ＋デモ前進検証(docs/29)で埋める（v7/v4にも課した規律）。

## 4. 採点ゲート（v7基準9ゲート・docs/40 と同一）

| # | ゲート | 合格条件 |
|---|---|---|
| G1 | 実データ span | 予備=Yahoo〜2年（**LEAD上限**）/ 確定=10年Dukascopy |
| G2 | ノールックアヘッド＋実コスト | 構造的に担保（確定足→次足始値・往復コスト） |
| G3 | プールperm_p < α_family(0.0167) | 循環シフト順列（自己相関頑健）・**OOS** |
| G4 | プラセボ識別 | C1/C3=逆方向(継続)で崩壊・C2=ランダム時刻で崩壊 |
| G5 | 年次ジャックナイフ | max_p ≤ 0.10（特定年依存でない） |
| G6 | IS/OOS 両方 + | 70:30 で両方プラス（直近減衰なし） |
| G7 | ウォークフォワード | ≥4/5 期が PF>1 |
| G8 | コスト 2× | 2倍コストでも net>0・期待値>0 |
| G9 | −10%枠適合 | 代表サイズ p95 maxDD ≥ −10% |
| R1 | **既存3本と低相関** | \|月次相関\| ≤ ~0.3（v7/v4/E5 すべてに対し）|

**判定**: ADOPT = G3＋G4–G9＋R1 全合格（10年）。STRONG-LEAD = G4・G6・G7・G8・R1 合格で G3 か G5 未達。
LEAD = それ未満。**予備Yahoo段は最大 LEAD**（span不足。docs/18でv8がYahooで良く見え10年で消えた前例＝Yahoo単独で採用しない）。

## 5. 想定される結末（誇張しない事前表明）

過去の枯渇実績（§0）から、**3候補とも REJECT/LEAD止まりの確率が高い**と正直に予想する。本書の価値は
「当てる」ことではなく **(1) 4本目探索を過剰最適化なしに厳格化** し、**(2) 仮に1つでもプール有意かつ
低相関が出れば、それは v7/v4/E5 と機構が独立な"真の第4分散源"候補**になる点にある。
**出なければ「現データに第4エッジ無し」を確定**＝Portfolio3（3本）で打ち止めという誠実な結論を補強する。
