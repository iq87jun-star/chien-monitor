## 3. 移行手順(2026-08 月初・docs/172 §4と同形式)

1. **旧EA停止**: Instant 20kチャートからPD_noV4 1.0x(Magic 761230系)を外す。
2. **残存建玉の手動クローズ**: 旧Magicの建玉(v7/EMon/E5)を全て手動決済
   (新EAは旧建玉を引き継がない)。フラット化を口座履歴で確認。
3. **HWM引継ぎの確認(重要)**: FNダッシュボードで現在のMLLフロア(またはbalance最高値)を確認。
   - 口座残高がPD稼働期に$20,000超の高値をつけている場合 → その値を `InpHwmOverride` に入力。
   - 高値が初期残高以下なら 0(自動)のまま。
   ⚠ これを怠るとEAのフロアがFN実フロアより低くなり、**FN側で先に失格し得る**。
4. **新EA装着**: 任意のチャート(例 GBPJPY H1)に `Chien_RecentFit_2026H2_Instant` を適用。
   [INIT RecentFit INSTANT]行で initBal・Σw=1.000・グロス≈4.0x・trail=6.0%・expiry を確認。
   [HWM]行のFNフロア値がダッシュボードの表示と一致することを確認。
5. **初週確認**: 月曜に[Mon ENTRY]がGBPJPY/AUDJPY×4時刻(4/6/8/10 UTC)で出ること・
   ロットが想定元本(初期残高×重み×4.0÷4ショット)と整合すること・TRAIL関連の誤発動なし。
6. スワップフリー口座であること(docs/154推奨)を確認。v4 USDJPYは最大8日保有がある。
