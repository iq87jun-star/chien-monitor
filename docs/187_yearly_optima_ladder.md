> 可能に出来ますか」への検証記録
> (`research/yearly_optima_ladder.py`・`results/yearly_optima_ladder.json`・シード7)。

> 最適解等ブレンド(ラダー)**をアウトオブサンプル比較。セル母集団はB/C/D系34セル+

## 2. ヘッジ検定(OOS・テスト7年: Y2019〜Y2025)

各テスト年で「前年の最適解だけ持つ」vs「直前3年の最適解を等分で持つ(ラダー)」(倍率なし生値):

| テスト年 | 前年単独 cum/MDD | 3年ラダー cum/MDD |
|---|---|---|
| Y2019 | +9.5% / −4.7% | +12.2% / −5.3% |
| Y2020 | +0.5% / −2.2% | +3.9% / −1.2% |
| **Y2021** | **−6.1% / −31.5%**(暗号崩壊を直撃) | **+0.7% / −11.7%** |
| Y2022 | +4.4% / −0.8% | +2.4% / −5.4% |
| Y2023 | +7.3% / −2.4% | +35.3% / −7.8% |
| **Y2024** | **−7.3% / −9.9%** | **+1.0% / −4.3%** |
| Y2025 | +4.4% / −4.3% | +2.3% / −5.1% |
| **平均** | **+1.8% / −8.0%(最悪単日−3.3%)** | **+8.3% / −5.8%(最悪単日−2.4%)** |
| **マイナス年** | **2回**(うち1回はMDD−31%) | **0回** |

**判定: ヘッジ効果はOOSで実証された。**
- マイナス年2→0。単年特化の破綻年(Y2021暗号崩壊−31%MDD・Y2024)をラダーが両方救済。
- 平均MDD −8.0%→−5.8%・最悪単日−3.3%→−2.4%。
- ただし正直な注記: **平均リターン+8.3%はY2023の+35%(暗号)1年に依存**。中央値は
  前年単独4.4% vs ラダー2.4%で**ラダーの方が低い**。ラダーの本質は「平均を上げる」でなく
  **「破綻年を消す」**(=まさにリスクヘッジ)。

## 4. 結論と用途の整理

1. **「1年ずつの最適解を並べて持つ」はリスクヘッジとして機能する**(マイナス年ゼロ化・
   テール半減)。docs/185の懸念(単一クラスタ集中)への構造的な答えになっている。
2. ただし**チャレンジ用途には不向き**: ラダーの価値=レジーム転換時の破綻回避であり、
   平時のリターンは単年特化より薄い(中央値2%台)。期限・目標があるチャレンジは
   「今のレジームに全乗りして速く駆け抜ける」C/D型が構造的に有利なまま。
3. **最適な使い分け(提案)**:
   - チャレンジ(期限あり): 単年〜短窓特化(C/D型)を継続
   - **資金化後の口座(期限なし・資金保全が最優先)**: 年次ラダー構成へ移行
   - 現在のFN Instant/FN100k(恒久・正攻法)の隣に「ラダー枠」を作る場合も同様の性格
4. 運用形態: 毎年8月に最新窓の最適解を追加し最古を落とす**ローリング3年ラダー**
   (再スクリーニング頻度は年1回=C/Dの月次〜四半期より軽い)。
5. 採用する場合の残タスク: 事前登録doc(ローリング規則・倍率規則・停止規則)、
   TSMOM/Hold暗号レッグのEA実装、FN/FTMOの暗号取扱確認(docs/184 §4と共通)。
