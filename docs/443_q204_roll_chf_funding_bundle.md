## 1. 定義(事前固定どおり)
- 建て = 水曜 20:00 UTC の H1 足始値、決済 = 木曜 00:00 UTC の足始値(4 時間・Roll5 と同じ窓)。USDCHF・GBPCHF・AUDCHF・NZDCHF・CADCHF を SHORT。
- 門 = 相手通貨と CHF の政策金利差(Q20 の金利表)が 2.0pp 以上の週のみ。束 = その週に門を満たし、20 時・24 時の足がある銘柄の等加重。該当 0 本の週は取引なし。
- コスト = 往復 3pip(銘柄ごと)。判定 = docs/244 §1 標準基準(閾値 0.05 / 10,142 = 4.93e-6)。
- データ: USDCHF・GBPCHF・CADCHF = Dukascopy(〜2026-08)+ FXCM 継ぎ足し、AUDCHF・NZDCHF = FXCM 公開アーカイブ(2016-01〜2026-11・今回取得)。末尾は 2026-11-04 の水曜。
- 2026 年の政策金利: 金利表は 2025-12 まで。2026 年は SNB 0% 据え置き(3・6・9 月)、FRB 9/16 +0.25、カナダ銀行 10/28 +0.25、RBNZ 2.25 → 2.75%(引き上げの時期は未確認)。英国・豪州の 2026 年分は未確認。相手通貨の最低は 2.25%(NZD・CAD)で CHF は 0% なので、どの場合も 5 本とも全週で門を満たし、金利表を直しても結果は変わらない(表は変更していない)。
