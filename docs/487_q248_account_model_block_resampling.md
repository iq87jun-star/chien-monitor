## 4. 読み
- **本口座後・本番中は、引き方を変えても結論は同じ。** FN Instant とルビー / パールは 3 つの引き方すべてで E1 が変更候補。トパーズは差が基準未満だが、E1 が現行を下回る項目は無い。
- **評価中は、E1 が失格を下げる点は変わらない。** 7 場面 × 3 つの引き方 × 2 つの窓 = 42 通りのうち、E1 の失格が現行より高いのはトパーズ・いまの 3 通りだけ(差は 0.2〜0.6 ポイント)。
- **長い並び(13 週)では、E1 の到達が現行を下回る場面が出る。** トパーズ・次の W1(76.3 → 72.9%)、ルビー・次(6.3 倍)の W2(62.7 → 59.4%)、パール・次の W2(66.4 → 64.7%)など。良い週が続く並びでは、24 時間持つほうが目標に早く届くためと読める(E1 は中央の週数が 1〜2 週長い)。
- 判定が「変更候補」から「現行どおり」に変わるのは、7 場面のうち L = 13 で 3 場面(トパーズ・次、ルビー・いま、パール・次)、L = 4 で 1 場面(ルビー・次 6.3 倍)。逆にパール・いまは L = 4・13 で変更候補になる。どれも到達の差が基準の 1 ポイントをわずかに超えるかどうかの違い。
- まとめ: E1 は「失格を減らす代わりに、到達が少し遅くなる」形で、独立に引くモデルは到達の遅れを小さめに見ていた。11/18 の切替を取りやめる理由にはならないが、評価中の口座での利点は Q233 の数字より小さい。
- 独立に引くモデルの他の結論(倍率・縮小・停止線)は、今回は確かめていない。
