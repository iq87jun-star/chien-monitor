  balance基準の日次−5%は、複数日保有のレッグにとって**「累積含み損キャップ」**として機能する。

## 3. EA側の構造欠陥(コード実査)

1. **基準線の不一致(主因)**: EAガードは`g_dayStartEq`=日開始**equity**基準。7/24朝の時点でEAの見る「本日」は−1.3%であり、−4%トリガーは発動しない。17:46の決済は**FN側の強制クローズ**(EAログにDAILY_STOPは出ていないはず・2本1秒差)。
2. ガード評価は`OnTimer(60秒)`のみ(`OnTick`空)。今回は主因でないが、滝相場では独立の欠陥。
3. S-Jul/月間保有レッグは`OpenNotional(...,0,0,...)`=**ブローカー側SLなし**。日次ガードが唯一の防衛だった。
4. シミュレーション(docs/97/111/169系)はFN日次を「日開始equity−5%」でモデル化しており、
   **balance基準より甘い**。docs/169の「破れは全て指数月間保有型」という結論は方向として正しかったが、
   失格率は過小推定側だった(特に季節・E5系の多日保有構成)。
