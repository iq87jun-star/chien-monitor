## 3. 判定
1. **仮説は棄却。出金を細かくするほど失格が増え、出金合計も減る**(残し 5%: 月次 3,377 → 隔週 2,519 → 毎日 1,712 万。失格は FTMO 50k 17.5 → 33.0%、1-Step 49.6 → 93.5%)。残し 20% でも向きは同じで幅が小さい(4,497 → 3,932 万・失格 +0.1〜10pt)。
2. 理由: Q134(docs/352・固定倍率 k=0)では頻度の差が +0.5pt と小さかったが、Q131 の余裕比例 k を併用すると「余裕」がそのまま倍率になる。出金のたびに余裕を基準残高 +5% まで削ると倍率が常に 1 倍付近に張り付き、静的な床までの距離も増えない。月次なら 1 か月分の利益が出金日まで倍率と緩衝の両方に働く。つまり **出金頻度は Q131 と干渉する**(docs/370 §5 A の「露出が減る」は固定倍率の直感)。
3. 残し 5% 自体も現行の 20% より悪い(月次で 3,377 vs 4,497・失格 2〜3 倍)。これは docs/349 §9c(「1 番数値が良い手段で」保持 20%)の再確認。
4. 1-Step(トレーリング型・資金化後 ×1.56)は残しが薄いと 1 年失格が 50〜94% に跳ねる。この口座は特に「残す」ことが前提。
5. なぜ偽陽性でないか: 診断(同じ乱数・同じ帳簿)で変形間の差のみを見ており、方向が 8 変形で単調(頻度↑ → 悪化、残し↓ → 悪化、pay_frac↑ → 悪化)。コスト感度は無関係(出金規則は取引コストに触れない)。

## 4. 提案(11/1 改正案・運用への含意)
- **出金規則は変更しない**: 毎月 1 日・基準残高 × 1.20 を超えた分の半分を出金(docs/349 §9c・§9f-3)。業者の最短サイクル(FN 24h・Fintokei 即時・FTMO 14 日)は「使える」だけで、使うべきではない。
- docs/370 §2 の「出金頻度が上がる分だけ露出が減る」の行は本結果で上書き(Q131 併用下では逆)。
- FN 14166201 の P2 通過後(C6・docs/381)も同じ月次規則。1-Step 資金化後は残し 20% を必ず守る(EA9 の `InpKeepPct` = 20)。
- Q154(分配アドオン)・Q155(FTMO スケーリング)は本結果の月次規則を前提に計算する。
