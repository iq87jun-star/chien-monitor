# 成果物⑨ v3 EA（多信号アンサンブル）— Python研究との一致性 と 検証手順

## 1. このEAは何か
`research/ensemble_meanrev.py` の `signals_confluence`（k≥4合議）を MQL5 に**忠実移植**したEA。
研究で唯一「プールOOSでブートストラップP値が有意(0.006<0.05)」に到達した戦略。
リスクガード（日次-4%/累積-8%/固定%リスク/SL必須/ニュース・セッション）はv1から継承。

## 2. ロジック（4条件の合議・日足・逆張り）
直近確定足で、以下4条件のうち **K個以上（既定K=4）** が同方向に一致したら逆張りエントリー:
1. RSI(14) < 35（買い）/ > 65（売り）
2. 終値のボリンジャーZスコア(20本, ddof=1) < −1.5（買い）/ > +1.5（売り）
3. 連続下落 ≥ 3日（買い）/ 連続上昇 ≥ 3日（売り）
4. 当日リターン < −0.5%（買い）/ > +0.5%（売り）

SL=1.5×ATR(14)、TP=SL×1.2、8本（日）で時間切れ、+1RでBE。1日最大3回・同時1ポジ・0.4%リスク。

## 3. Python ↔ MQL5 インデックス一致性（検証済み）
ノールックアヘッドの整合を確認した（`research/`上で数値照合）:
- Python: シグナルは足 `i`（`rsi[i],z[i],down[i],ret[i]`）で立ち、約定は `o[i+1]`（翌足始値）。
- MQL5: 判定は直近**確定足** index=1、約定は形成中の現足始値。→ Python の `i` = MQL の確定足[1]。
- ボリンジャー母集団: Python `c[i-20:i]`（i除く20本） = MQL `close[2..21]`、対象 `close[1]`。**一致**。
- 連続日数・当日リターンも添字対応を確認。

具体例（EURUSD, i=100）: Python z=−3.1431 と手計算一致、down=1、ret=−0.00741。MQL同式。

## 4. ★必ず守る限界（過信禁物 / docs/08 と同じ）
- **探索の生存者**: k=2/3/4 を試した中で k=4 だけが有意。本研究全体では v1〜v4 で延べ十数戦略。
  Bonferroni補正（α=0.05/試行数）では 0.006 でも**有意と断定できない水準**。
- **直近で減衰**: OOS後半(直近) は PF1.21・P=0.198 で非有意。2026開始のチャレンジで効く保証はない。
- **取引が希少**: 10年・9ペアで OOS 203件（年20件程度）。時間制限なしなので致命的ではないが薄い。
