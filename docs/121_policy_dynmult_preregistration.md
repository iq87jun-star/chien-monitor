# 121.【事前登録】動的倍率ポリシー — 到達率(現在gain)に応じたサイズ変更 vs 固定倍率

> ユーザー提案「現在の到達率に応じて倍率を変更する」。docs/80 §4(b)の**サイズ政策の最適化**
> (新エッジ探索ではない)。既知の関連結果: 目標接近デリスクは失格にほぼ無効(docs/60 D)、
> ハード損失ガードが最強(docs/60 G・実装済み)。未検証なのは**静的フロアの非対称性**
> (gainが乗るほどフロアまでの距離=使える損失予算が広がる)を使う**上方向の増し**と、
> ドローダウン時の縮小(FNは時間無制限=「縮んで生き延びる」コストが低い)。
> ⚠ 本docは `research/policy_dynmult_pd.py` の**実行前**にコミット。結果はdocs/122へ転記のみ。

## 1. 政策族(これで固定・追加は再登録)

状態変数 g = チャレンジ開始からの口座gain%(対初期残高)。m0 = 基準倍率(研究1x比)。

| ID | 政策 | 式(cap [0.3, 1.5]×m0) |
|---|---|---|
| **P0(対照)** | 固定(現行) | m = m0 |
| P1 | クッション比例(両方向) | m = m0×(10+g)/10 |
| P1d | 防御のみ(下で縮小・上で据置) | m = m0×min(1, (10+g)/10) |
| P1u | 増しのみ(上で拡大・下で据置) | m = m0×max(1, (10+g)/10) |
| P2 | 段階版(EA実装容易) | g≤−4: 0.5m0 / g≥+4: 1.5m0 / 他: m0 |

- 分解目的でP1d/P1uを含める(効くのが防御側か増し側かを特定する)。
- 上限1.5×m0は日次規約(−5%)の踏み抜き防止のためのハードキャップ(事前固定)。

## 2. 判定環境(固定)

- 系列: PD日次1x合成(docs/114検証と同一構築・2016-2025)。
- ルール: FN Stellar P1 = 目標+8% / 静的フロア−10% / 日次2バウンド
  (悲観=素の日次≤−5%で即失格・楽観=EA日次ガードで−4%打ち切り)。時間無制限(シミュ上限36ヶ月)。
- サイズ更新: 日次(EAはタイマーで毎日gainを見て倍率スケール)。損益は対初期残高の加算
  (EAのリスク%が初期残高基準であることに合わせる)。
- 経路: 歴史経路(各月開始・120本) + ブロック・ブートストラップ(3ヶ月ブロック×2000パス, seed=7)。
- m0グリッド(固定): {2, 3, 4, 5, 6}×研究1x。
- 指標: 通過% / 失格%(日次・フロア別) / 通過の中央・p75月数 / 36ヶ月未決着%。

## 3. 採否の決定規則(事前固定)

政策P(P1/P1d/P1u/P2)を**採用**するのは以下全てを満たす時のみ:

1. **同一m0での支配**: m0グリッド5点中4点以上で「fail%(P) ≤ fail%(P0) かつ 通過中央月(P) ≤ P0」
   (楽観バウンド・歴史経路)、かつ少なくとも1点で **fail%が相対10%以上改善 または 中央月0.5ヶ月以上短縮**
2. **悲観バウンドでも fail%(P) が P0+1pt を超えて悪化しない**(全m0点)
3. **ブートストラップ2000パスでも1.の支配が再現**する
4. 複数政策が合格した場合は「fail%改善幅(楽観・m0=4)」最大のものを勝者とする

- どれも不成立なら**固定倍率(現行)維持**(docs/60の結論の再確認=それも価値)。
- 採用時の実装: EA(PortfolioD_Prop3等)に倍率スケーラ入力(既定=固定动作不変)として追加。
  デモ並走→次フェーズから適用(docs/104 §4と同順)。

## 4. 既知の限界(先に書く)

- 日次解像度: 日中のgain変動による倍率変化は捉えない(EAは日内も追従可能=実装は保守側に日次更新)。
- 加算近似: 複利でなく対初期残高加算(EAのサイジング仕様に整合だが、深いDDでの乖離は数%)。
- PD合成はYahoo近似・E-MonのRG3ゲートなし(docs/114 §6と同じプロキシ)。**相対比較が主眼**。
- 政策のパラメータ(閾値±4%・cap1.5等)はフィットせず事前固定。グリッドの事後変更はしない。
- Phase2(+5%)は対象外(P1が主戦場)。合格時に別途同手順で確認する。
