1. `Chien_Seasonal_Top_EA` / `Chien_PortfolioD_Prop3` に **+7%利益ロック**(口座がフェーズ目標+8%の
   手前+7%に達したら新規停止・+7.5%で全決済して通過確定)を追加

- **数字を盛らない**。全ての性能主張は「事前登録→実行→実出力JSONの転記」の順(docs/72の流儀)
- バックテストを伴う変更は必ず: ドリフト保存プラセボ/コスト・スワップ感応/pre-2016との
  レジーム分割/対B&H診断(docs/80 §5の標準ゲート)を通す

  ハロウィーン・発表日等, docs/14〜93)に**戻らない**

  デモ専用ラベル(docs/53 §5: ADOPTでも本資金前デモ必須)
