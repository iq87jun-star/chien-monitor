## 読み

1. **「全部」は成り立つ**。A〜D はどれもサンプル外 +10〜12%・失格 ≤ 1% で、5 本(基準)より良い。分散は本物で、最悪月が −2.7% → −1.7〜−2.0% に縮む。
2. **しかし 7 本(5 + 候補 2)に届かない**。理由は**倍率の上限**: 分散でボラが落ちると校正倍率が 4.8(= 0.8 × 6.0 の探索上限)に張り付き、それ以上レバレッジを掛けられない。7 本は 3.48 でまだ上限に余裕があり、1 本あたりの効きが大きい。
3. **足しすぎると薄まる**: E(75 本・p<0.20 まで)は DD −2.0% と最も浅いが、リターンも +6.9% に落ちる。F(412 本)は同じ銘柄の LONG と SHORT が相殺して**ゼロ**。「全て」を文字どおり取ると何も残らない。
4. A(Hold・暗号入り)は窓内 DD −10.9% で静的 −10% を割る。**Hold と暗号は「全部」に入れない**(docs/227 §6 と同じ)。

## 実装上の制約(紙上では見えないもの)

| 制約 | 内容 |

| 最小ロット | 37 本 × 逆ボラ重み 2〜5% → 1 レグ名目が小さすぎ、$60k 基準でも 0.01 lot 未満になるレグが出る。小口座では **20 本前後が上限** |
| EA | 記録用 EA の `MAXLEG` は 16。曜日 × 方向セル(MonS/FriS/WedS/TueS/Thu)は**未実装**。RF5 EA の S3 型スリーブを汎用化する改修が要る |
| FundedNext | EA は 1 口座 1 本(docs/185 §10b-2)→ 1 本の EA に全レグを入れる設計にする |

## 帰結

- **やるなら D 型(26 + 探索 p<0.05 の 11 本 = 37 本)**。サンプル外 +10.8%・DD −2.6%・失格 0%。これは「口座を失わない」ことを最優先にした構成で、7 本(+14.1%・失格 0.4%)より **安全側に 3〜4% を払う**形。
- 7 本と D の差は倍率上限で決まっているので、**同じ口座で両方を持つ意味は無い**(D の中に 7 本は含まれている)。口座を分けるなら「7 本 = 攻め」「D = 守り」。
- 順序は変えない: 候補 5 本の 6 ヶ月紙上判定(docs/229 §4)→ 曜日セル EA 化 → 実口座記録 → 採用。D 型は EA 改修(MAXLEG 拡張 + 曜日×方向スリーブ)が前提なので、**判定期間中に EA を書いておく**のが時間の使い方として正しい。
