## 2. F2 の解剖 — 「Bonferroni通過」でも採用しない理由（本バッチ最大の教訓）

F2 は perm_p=0.0023・JKmax=0.015・IS/OOS両正・コスト2-20bps全勝と、**従来基準なら ADOPT 一直線の数字**。
だが事前登録した強化プラセボ（ON比率92%を保ったランダムマスク）が **+171.1%・p=0.009 で「有意」**
＝ランダムに92%株を持つだけで利益が出る。さらに事後診断（採用判定外・JSON `f2_diagnostics_posthoc`）:

| 指標 | 値 | 意味 |
|---|--:|---|
| 買い持ち(B&H) 純益 | **+276.6%** | ゲート(+199.3%)は **B&Hに−77pt劣後** |
| B&H maxDD | −33.9% | ゲートのDD改善は僅か（−30.0%）＝暴落回避に失敗 |
| ON日（コンタンゴ）平均 | +5.07bps/日 | — |
| OFF日（バックワーデーション）平均 | **+13.36bps/日** | **回避した日の方がリターンが高い**（リバウンド日を逃す） |

∴ **F2の利益の100%超が株ベータ。VIX期間構造シグナルの付加価値は負。** edge6 の E6（回転=BTCベータ）と
同じ構造の罠を、今回は事前登録段階で仕込んだ「ドリフト保存プラセボ」（docs/79 §3）が一発で捕捉した。
**「p値が小さい」と「エッジがある」は別物** — この区別こそ本バッチで最も価値ある確認。

## 3. その他の候補の正直な評価

- **F1 株式ToM**: 唯一プラセボに勝った（+33.3 vs +28.9）が、差分＝ToM固有の価値は10年で**+4.4ptしかなく**
  p=0.106。株カレンダーで生き残るのは E-Mon（月曜, Sharpe0.91, docs/53）だけ、が再確認された。
- **F3 金利→JPYリード**: docs/73 §3-2 の白地。**−30%・全ゲート崩壊で完全閉鎖**。金利差の方向は
  翌月のUSDJPYを予測しない（情報は即日織り込み済み、という教科書通りの結果）。
- **F4 年度末リパトリ**: docs/73 §3-1 の白地。勝率27%（11標本中3勝）・純益−4.3%で**閉鎖**。
  「3月後半円高」は最近10年のデータに存在しない（事前分布が強くても市場は従わない）。
- **F5 金の週末**: OOSで−13.5%・コスト10bpsで−30%。**v7の『週末リスクプレミアム』は金には無い**
  （円Monday＝フロー由来であり、汎資産の地政学プレミアムではない、の傍証）。
