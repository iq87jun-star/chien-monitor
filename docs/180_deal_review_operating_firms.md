## 2. 評価

### B(¥1.41億)— 3案件で最も筋が良い
- 5年生存(MyForexFunds閉鎖後の規制強化期を生き延びた選抜済み個体)、リピート70%は
  本物なら極めて良い数字、実利益の開示あり、価格≒3.2年分は業界リスク込みで妥当圏。
- 実市場執行型+複数法域ライセンス法人群は docs/175 のS課題①(法務)の部分的な緩和を
  「買える」ことを意味し、シェルやWLでは手に入らない価値。
- 難点: 価格が現実的な資本レンジを超える。また「純収益(net revenue)」の定義が曖昧
  (粗利か純利か)で、ここの確認が価格評価の分水嶺。

### A(¥5,180万)— 価格帯は合うが、開示が最低水準
- 課金者数も売上も非開示で「月次成長率100%」という無意味な宣伝文のみ。2024年開始で
  実績1〜2年。「潜在顧客2,500+」は課金数ではない。
- ⚠「Pay as You Pass」(合格時払い)モデルは、docs/174 の収益構造(不合格者の参加費が
  収益源)と根本的に異なる。字義通りなら失敗者から収益が取れず、単体経済性の
  作り直しが必要。DDの最初の質問はこのモデルの実際のキャッシュフロー。
- 判定: **現状開示では買えないが、価格帯・チャレンジ型(土俵が近い)ゆえ
  「DD要求リストを送る価値がある唯一の案件」**。

### C(¥1.02億)— 割高で見送り
- 利益≒¥1,727万/年に対し価格5.9倍は B(3.2倍)と比べ正当化できない。
- 掲載文が2024年時点のまま=約2年売れ残っている可能性が高く、それ自体が価格シグナル。
- 「4万トレーダー」は docs/179 で規律化した虚栄指標。

## 3. A に送るべきDD要求(docs/177/178 の実装)

1. 月次の課金購入数 N・商品別単価・返金率(直近12ヶ月、決済明細ベース)
2. **全口座の生取引データ**(sharp 比率 s を sim/operator_economics.py で実測するため)
3. 未払い出金残高・出金処理の平均日数・過去の出金拒否件数と理由
4. PSP契約の名義・チャージバック率・**株式譲渡時の契約存続可否**
5. 「Pay as You Pass」の正確な課金フロー(誰がいつ何を払うか)
6. 「月次成長率100%」の定義と裏付け(何が2倍になっているのか)

→ 2と4を拒否したら見送り(docs/179 の規律: 翻訳に必要なデータを出さない案件は評価不能=見送り)。

## 4. まとめ

- 買う価値の序列: **B > A >> C ≈ 先物49k(docs/179)**。
- ただし B は資本レンジ外、A は開示不足。**現時点で「そのまま買って良い」案件は無い。**
- 市場の実勢として「まともな開示のある5年生存ファームは利益の3年分強」という
  価格アンカーが得られたのは収穫(docs/178 のROI表と整合的: 成立条件下なら3年分は割安)。
