> **規制報告ベースのポジショニングデータ**(1986年〜)は本プロジェクト未投入の新データ型であり、

## 1. 凍結ルール

- **CoTデータ**: CFTC legacy形式(`deacot1986_2016.zip` + `deacot2017..2026.zip`)。
  市場はCFTC契約コードで固定: JPY=097741 / EUR=099741 / GBP=096742 / AUD=232741 /
  CAD=090741 / CHF=092741 / WTI原油=067651(**7市場**)。
  金(088691)・S&P500は無料の長期日次価格が現在入手不可のため**対象外**(理由の事前明記)。
- **価格**: FRED日次(DEXJPUS等6系列+DCOILWTICO)。全て「外貨のUSDに対するロング」=
  先物ロングと同方向に揃える(JPY/CHF/CADは逆数)。
- **シグナル**: 投機筋(noncommercial)ネット枚数 ÷ OI = **specratio**(火曜時点)。
  金曜15:30 ET公表 → **公表金曜の終値で建て、翌週金曜終値まで保有**(週次リバランス)。
- **仮説(N=2・ポートフォリオ水準が主検定・市場別は内訳のみ)**:

| ID | ルール(全て凍結) | ポジション |
|---|---|---|
| **H20a SPEC-CONTRA** | specratio の156週ローリング分位 ≥90% → SHORT / ≤10% → LONG(逆張り)。ON市場の等ウェイト合成 | 翌週保有 |
| **H20b POS-MOM** | specratio の13週変化の符号に順張り(+→LONG / −→SHORT)。全市場等ウェイト合成 | 翌週保有 |

- **コスト**: リバランス時の売買回転に片道5bp。ストレス2×。保有コストストレス5%/年(FXスワップ相当)。

## 2. 採点ゲート(判定はしごは docs/100 と同一)

- G-dir / **G-p**: プラセボ=各市場のポジション系列を**独立な円環シフト**でランダム化(ON比率・
  自己相関・L/S混合を保存する週次版ドリフト保存プラセボ, 2000draw)p≤0.05。Bonferroni(N=2)α=0.025。
- **G-split**: **pre-2016 と 2016以降の両方で net > 0**(本プロジェクト最強のレジームゲート)
- G-cost(2×)/ G-hold(5%/年)/ G-beta(平均ポジション×市場リターンの合算を控除して超過+)/
  G-dd(レバ1でmaxDD≥−20%)
- **判定**: 全通過=STRONG-LEAD(Bonferroni未達は1段下げ)/ G-p含む過半=LEAD /
  dir+p≤0.10=参考 / 他=REJECT。
- **STRONG-LEADの場合のみ** EA化(デモ専用)に進める。ADOPT候補昇格はデモ前進後(E5と同じ扱い)。
