## 4. 実装メモ

- **P-A / P-C / P-E**(単一口座) = 既存 `Chien_Portfolio3_AllInOne` に **E-Mon を加える**形。E-Mon は
  `Chien_Parallel_AllInOne_*`(本ブランチ) の E-Mon レッグ、または別ブランチ `Chien_P2_TurnOfWeek_AllInOne` が該当。
  比率は各EAの週次リスク%/legRisk%で調整(例: P-Cは v4を厚く=v4/trade↑・E5を0に)。
- **2口座並走** = 口座1に `Chien_Portfolio3_AllInOne_*`、口座2に `Chien_Parallel_AllInOne_*`(または P2 EA)。Magic系列は分離済。
- **暗号衛星**(P-D) = 暗号可業者のみ。EAの `InpEnableCrypto=true`/小サイズ。多くのプロップは暗号不可/別ルールに注意。
- v9(低DD・swap無し)は v7 の代替として、トレーリングDD業者・スワップ不利業者で使う。

## 5. 正直な限界

- 全て **Yahoo日足10年のリスク加重・等ボラ標準化の相対比較**(配当除く指数・v4は日足SL/TP簡易再現・
  暗号はYahoo)。**絶対の年率/失格率は Drive(Dukascopy/実CFD)＋デモで要確定**。
- **暗号は単体maxDD−55%**＝期待Sharpeは高いが**テールが極端**。衛星(≤8%)以上にしない。プロップ規約も要確認。
- **E5 は単体最弱**(Sharpe0.36・本proxyで非有意)。無相関ゆえ衛星価値はあるが、P-C のように**外す選択**も妥当。
- **v4(ADOPT)厚めのP-Cが最良効率だが、単一エッジ依存が増す**(ADOPTでも本資金前デモ必須)。分散を優先するなら P-A/P-E。
- E-Mon/CRYPTO は **STRONG-LEAD/候補＝未確証**。本資金前にデモ前進検証(docs/29)必須(v4=ADOPTにも課す規律)。
