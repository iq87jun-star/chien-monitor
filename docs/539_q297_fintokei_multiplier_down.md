## 0. 結論
1. **先に決めた選び方の結論: 3 口座とも、いまの倍率のまま。** 倍率を 0.9・0.8・0.7 倍にした 18 件は、判定では 16 件が悪化(到達が 1 ポイントを超えて下がる、主に古い期間)。「2 場面とも悪化でない」型は無い。
2. **惜しい点: 合計点(到達 − 失格)はほとんど変わらない。** 倍率を 0.8 倍にすると、score の 2 場面合計は トパーズ 326.6 → 329.7・ルビー 277.0 → 280.0・パール 333.7 → 334.9。到達が 0〜4 ポイント下がる分、失格が同じくらい下がる。通過までの中央は 1〜4 週延びる。
3. **ガードの発動回数は大きく減る。** 0.8 倍で、年あたり トパーズ 3.65 → 1.40 回・ルビー 5.75 → 3.65 回・パール 2.20 → 1.00 回。発動 1 回ごとに Fintokei の 3% を超える危険があるので、注意の回数を増やさない効果は「幅を 2.0% に狭める」(Q289: 発動はむしろ増える・合計点は トパーズ 311.2・ルビー 276.9・パール 313.9)より筋が良い可能性がある。
4. **扱い**: いまは変えない(規則どおり)。注意が 2 回目になった時の形として、「幅 2.0%」と「倍率 0.8 倍」と「両方」を、すべりの置き方を先に固定して比べ直す案を、待ちの案(I-10)に足した。

## 3. 限界
