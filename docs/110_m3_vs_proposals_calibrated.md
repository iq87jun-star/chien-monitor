# 110.【比較】現行M3 vs 提案R3a/R4 — 倍率をガード逆算で校正した公平比較 + G3オーバーレイ

> ユーザー依頼「リスク倍率を調整して比較・現状のものにFOMCも入れて」。
> 出所: `python3 research/portfolio_daily_compare.py`(`results/portfolio_daily_compare.json`)。
> 手法: 各スリーブを**日次解像度**で再構築(v4=トレード日次時価評価/G3=FOMC前日の日足プロキシ)し、
> 倍率を **docs/87規律=min(単日−4%, 月中−8%)逆算×0.8** で校正して横並び。窓2016-01〜2026-06(126ヶ月)。
> ⚠ G3日足プロキシは実測(H1)の約2割しか捉えない(docs/86 H14b)=G3寄与は**控えめ側**の表示。Yahoo近似。

- **同じ「絶対に踏まない」テールでR4はM3の約1.9倍の年率**。docs/105のLOYO優位が日次でも再現。
- **★重要な正直な発見**: 現行M3の配備倍率2.0xは、この厳格規律だと**0.60xが上限**。
  つまり**2.0xは安全倍率の約3.3倍を踏み込んだ「速攻設定」**である(2024/8/5型の単日が2.0xで−10.1%相当
  =日次ガードの執行とギャップ次第でFN日次−5%を踏み抜く尾)。これはdocs/87が「失格1.5%は楽観・実効1.5〜5%」
  と注記していた内容の日次定量化であり、新しい悪材料ではない(承知の上の設計)。

## 3. G3オーバーレイの寄与

日足プロキシ(実測の~2割)でも +0.05%/月・Sharpe+0.04・maxDD改善(−4.5→−3.3)。実H1捕捉ではこの数倍が
期待値(ただし主張はしない=デモ実測で確認)。**コストほぼゼロの分散**なので「現状のものに入れる」判断は妥当。

## 4. 実装(Chien_Seasonal_Top_EA v1.30)

1. **G3 FOMCオーバーレイ**(`InpG3Enable`・既定OFF): FOMC EAのET/DST/窓ロジックを逐語移植。
   声明24h前にUS500ロング(リスク1%/event・SL2.5×ATR(D1))→声明5分前に手仕舞い。Magic=base+8。
   **月ゲートの対象外**(イベント建玉)・フロア/日次/ロック/リスクガードの**対象**。2026年日程内蔵(毎年更新)。
2. **SCN_YEARROUND_R4**: R4月別テーブル(§本doc・全期間訓練)を新シナリオとして追加。既定倍率2.27x
   (=現行M3と同じ踏み込み係数。**ガード安全倍率は0.68x**・`InpMultOverride`で変更可)。既存シナリオ不変。
