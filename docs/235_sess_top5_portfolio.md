## 3. これをどう読むか — 数字より重要

1. **紙上の Sharpe 7 は「コストを 2pip と置いた結果」**。往復 3pip にすると年率 +27.6% → +12.3%、Sharpe 7.1 → 3.4 と**半減**。1 トレードの粗利が 5〜6bps で、1pip ≈ 1.2〜1.7bps だから。**この本の実力は執行コストで決まり、バックテストでは決まらない**。
2. 校正倍率が上限(4.8)に張り付くのは、合成のボラが極端に小さいから。これは「裾が無い」のではなく「**窓内に裾が来ていない**」(最悪日 −0.21%)。2016-10 の GBP 急落でも −0.61% に収まったのは事実だが、21 UTC 前後は流動性が最も薄く、**SL が滑る形の損失は H1 bid データに現れない**。倍率は docs/228 §2 の **3.3 を上限**にする(×3.3・3pip で年率 +8%・DD −2.6% が現実的な下限見積り)。
3. NZD/AUD の 20-00 は相関 0.73 で 1 本扱い。実質 4 本の分散。
4. スワップは EURGBP 20-00 で +0.1pip/日の受取、他は ≈0。反映すると 2pip 側に少し寄る。
