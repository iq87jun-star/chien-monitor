# キャラクター口調版(メルルver.)プロフィール&固定ツイート案

ヘッダー画像の世界観(青い髪・セーラー服・海と灯台・夕焼け)に合わせて、
「メルル」が一人称で語るキャラクター性のある文面にしたバージョン。

キャラ設定の軸:
- 一人称は「メルル」or「わたし」。やわらかい口調だけど、トレードの話になると急に真面目になるギャップ
- モチーフは「海・波・灯台」→ 相場=海、リスク管理=灯台、に喩える
- 絵文字は 🌊⚓️🕯️💙 系で統一(既存の🔥📈と混ぜてもOK)

## 表記ゆれ・使い分けメモ

- キャラ口調版と真面目版(docs/twitter-pinned-tweet.md)はどちらを固定にしてもOK。
  フォロワー層を見て、堅い反応が多ければ真面目版に差し替えられるよう両方保管
- 「航海」比喩の対応表: 相場=海/EA=船・相棒/日次ガード=灯台・港/失格ライン=岩礁/検証=海図
- キャラ口調でも守ること:
  - 損益・検証値の誇張をしない(かわいい口調でも数字は正確に)
  - ※注意書き(投資助言・販売なし)はどの版でも削らない
  - 口座番号などの識別子は出さない
