# 119.【事前登録】edge22: E-Mon夜間限定エントリー — 月曜close→火曜open(HNO) vs 現行24h(H24)

> 動機: edge21(docs/118)の分解で、E-Mon月曜LONGの10年利益の約87%が**月曜夜間パート**
> (close→翌open)に出ることを確認した。ならば**エントリーを月曜引けにずらして夜間だけ持つ**
> 方が、日中パートのDDを抱えず校正倍率(docs/87)を上げられるのではないか、という事後仮説の検証。
> ⚠ 事後仮説ゆえ判定は通常より厳しく置く(下記§4・月曜特異性プラセボ必須)。
> ⚠ 本docは `research/edge22_emon_night_10y.py` の**実行前**にコミットする。結果はdocs/120へ転記のみ。

## 1. 候補(これで固定・追加は再登録)

対象: E-Monスリーブ(NAS100/US500/GER40・月曜LONG・往復3bps・3銘柄平均)。

| ID | 保有 | 日足実装 | 想定保有時間 |
|---|---|---|---|
| **H24(現行)** | 月曜open→火曜open | o2o(現行スリーブ定義) | 24h |
| **HNO(夜間限定)** | 月曜close→火曜open | c2o | 銘柄セッション外≈14〜17.5h |

- HDC(日中のみ)はdocs/118で棄却済み=参考表示のみ。
- 夜越しファイナンス: **両候補とも夜越しは1夜で同一**のため感応シナリオは不要(コストは相殺)。
- パラメータのフィットなし(二値比較)。

## 2. 月曜特異性プラセボ(必須)

HNO(c2o)を**火〜金の各曜日**でも計測し、月曜が5曜日中**score 1位**であることを要求する。
(v7の曜日プラセボ docs/37 §0 と同旨。「どの夜でも上がる」なら月曜エッジではなく
単なる株式オーバーナイト・プレミアムで、E-Monの枠組みで持つ理由が弱い=不採用。)

## 3. 手順(固定)

1. データ: 既存固定窓 日足 2015-01-01〜2026-06-30(docs/114検証と同一CSV)。
   H1副確認: Yahoo 1h 2024-07-09〜2026-07-07(ES=F/NQ=F/^GDAXI・SHA記録)。
2. 系列: 月曜の o2o / c2o(往復3bps控除・3銘柄平均)。2016-2025の週次系列で採点。2026H1参考。
3. 指標: edge21と同一 — net/年率/Sharpe/maxDD/最悪週 + **score = docs/87式mult×平均週次**
   (mult = min(4%/最悪週, 8%/maxDD)×0.8)。
4. 頑健性: 年次ジャックナイフ(除外年別のscore順位) / IS:OOS 70:30 / コスト2倍。
5. H1副確認(約2年): 実装可能な時刻で再現 — GER40=月曜最終バー(≈15:00UTC)→火曜初バー(07:00)、
   US2銘柄=月曜20:00UTC→火曜13:00UTC。**HNOの2年netの符号**を確認する。

## 4. 採否の決定規則(事前固定・事後仮説ゆえ全条件必須)

**HNOを採用**するのは以下**全て**を満たす時のみ:

1. **score(HNO) ≥ 1.1 × score(H24)**(10年日足)
2. **net(HNO) ≥ 0.8 × net(H24)**(絶対リターンを2割超捨てない)
3. **月曜特異性プラセボ合格**(c2oのscoreで月曜が5曜日中1位)
4. **年次JK: 10フォールド中8以上で score(HNO) ≥ score(H24)**
5. **コスト2倍で順位維持**
6. **H1副確認: HNOの直近2年netが正**(夜間パートが直近レジームで死んでいない)

- 1つでも不成立なら**現行H24維持**。
- 採用時の実装: E-Mon系EAに**銘柄別セッション引け建て→翌現物オープン決済**の専用ロジックを
  入力パラメータ(既定=現行)として追加。デモ並走→次フェーズから適用(docs/104 §4と同順)。

## 5. 既知の限界(先に書く)

- **事後仮説**(edge21の分解を見てから立てた)。§4を全て通っても級は「LEAD」止まりで、
  デモ前進検証が最終判定(docs/104と同じ)。
- 日足c2oは現物指数のセッション定義(GER=欧州引け→翌欧州寄り=米国午後を跨ぐ)。銘柄ごとに
  「夜」の意味が違う。CFD実装時の執行時刻はH1副確認とデモで詰める。
- 配当落ちは夜間パートに乗る(現物指数は配当分だけc2oを過小評価=HNOに不利方向のバイアス。
  CFDは配当調整で概ね中立なので、合格すれば実運用はやや有利側)。
- H1は約2年=1レジーム。主判定は10年日足。
