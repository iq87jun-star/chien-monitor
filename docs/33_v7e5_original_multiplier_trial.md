# 33. v7+E5（65:35）× 当初意向リスク倍率 試算

> ユーザー要望「比率は推奨(65:35)、リスク倍率は当初意向で試算」。
> 当初意向 = 現行プロップ FundedNext **2.5倍(週次2.5%)** / インスタント Blueberry **1.5倍(週次1.5%)**。
> 前提: USDJPY=159・分配80%・10年アンカー(docs/18,24,25)。E5寄与=CAGR×1.345・maxDD×1.02。
> ⚠ E5はSTRONG-LEAD(未検証)。これは"試算"であり本資金前にデモ(docs/29)。

## 0. 一行結論
**E5を65:35で足すと、相関−0.15でE5の追加リスクが相殺され『最大DD・失格率はほぼ不変のまま
期待収益 約+34%』。** ただし当初倍率は最大DDが−10%枠を大きく超過＝**失格率は高いまま**
（インスタント年9%/プロップ年38%）。合成は"収益を底上げ"するが"攻め過ぎのDD"は直さない。

## 1. 試算表
| 口座 / 設定 | 期待年率 | 合成最大DD | 年次失格率 | 手取り/年 |
|---|--:|--:|--:|--:|
| Blueberry $50k ・ v7単体 1.5倍 | 6.4% | −14.8% | 9% | ¥406,404 |
| **Blueberry $50k ・ v7+E5 65:35 1.5倍** | **8.6%** | −15.1% | 9% | **¥546,613** |
| FundedNext $100k ・ v7単体 2.5倍 | 10.7% | −24.6% | 38% | ¥1,354,680 |
| **FundedNext $100k ・ v7+E5 65:35 2.5倍** | **14.3%** | −25.1% | 38% | **¥1,822,045** |

- **インスタント(1.5倍)**: ¥406k → **¥547k（+34%）**。最大DD・失格率はほぼ不変。
- **プロップ(2.5倍)**: ¥1.35M → **¥1.82M（+34%）**。同上。

## 2. なぜ最大DD・失格率がほぼ不変なのか
65:35（E5リスク = v7の35/65）で E5 を足すと、合成ボラ ≈ √(1+0.538²+2·(−0.15)·0.538)·σ_v7 = **1.06·σ_v7**。
E5の追加リスクが**負相関で相殺され、合成ボラは6%しか増えない**。よって最大DD・失格率はほぼ据え置きで、
**期待リターンだけが E5 の分（約+34%）上乗せ**される。＝当初倍率でも合成は"純粋な上乗せ"になる。

## 3. ★重要な但し書き（攻め vs 安全）
- 当初倍率は**最大DDが−10%枠を大幅超過**（インスタント約15%/プロップ約25%）＝**失格率が高い**
  （年9%/38%、5年累積でインスタント約37%・プロップ約90%）。**合成してもこれは直らない。**
- **失格率を下げたいなら docs/32 の中庸サイズ**（目標DD−6%・65:35）＝年次失格 ≈ **0.5%**。
  ただし手取りは下がる（インスタントで年率6.7%≈¥426k相当 / 攻めの¥547kより低い）。
- つまり選択は **「攻め(当初倍率)＝高収益・高失格」 vs 「中庸(docs/32)＝低収益・低失格」**。
  E5合成は**どちらの土俵でも単体より有利**（攻めでは+34%収益、中庸では失格1/10）だが、
  土俵そのもの（倍率）の攻守はユーザーの選択。
