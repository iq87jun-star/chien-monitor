## 2. 判定 — **6.0 で開始、9/21 の実測コスト ≤ 3pip なら 8.0、8 超は不可**

1. 1-Step は「速さ」だけが利点。目標 +10% を 1 段で取るので、倍率は資金化までの日数に直結する(4.8: 149 日 / 6.0: 118 日 / 8.0: 88 日)。期限はないが、資金化が 1 ヶ月早いと 90% 分配の受取が 1 ヶ月分増える。
2. 6.0 = 校正生値。他口座の 4.8 は「生値 × 0.8」だが、ここでは生値自体が探索上限で、データ上の縛り(×12)から 2 倍の余白がある。0.8 の値引きは「モデル外の裾(21 UTC の滑り)」のためのもので、その分は SL 合計リスク上限(2.0% / 2.4%)と日次ガード 2.4% で受ける。
3. 8.0 を上限にする理由: 3.5pip ストレスで失格が 0.3% に留まり、最大 DD −6.1%・最悪日 −1.7% でまだ規則の内側。10 以上は最悪日 −2.0% がガード 2.4% に接近し、3.5pip で DD −7.6% がトレーリング床に近づく。
4. コストが 3.5pip 側なら 6.0 のまま(資金化 97%・206 日)。docs/238 §4 の「Sess 単独は倍率半減」は 2-Step 向けの規則で、1-Step では速度を捨てると参加費の非返金が重くなるため、6.0 を維持して様子を見る。
