# 174.【事前登録】直近特化トラック(Recency Track) — 「過去6〜12ヶ月だけ伸びている」構成の別枠検証

> ユーザー指示(2026-07-30)「過去検証から安定しているEA(正攻法)とは**別枠**で、過去1年
> (極論半年)だけ伸びているEAを作りたい。本番口座まで行けば元が取れるので、本番まで行けて
> 数回の報酬でも御の字」。
> 本トラックは docs/140-145/165 で7例連続閉鎖した「事後選択系」と手続きが近いことを
> 認識した上で、**判断基準を変えて**(10年頑健性ではなく「チャレンジ1回あたりのEV」)
> 正式に別トラックとして検証する。実行前に本書で選択規則・変種・判定基準を凍結する。

## 0. 正攻法トラックとの関係(閉鎖判断と矛盾しない理由)

- docs/165系の閉鎖は「**暦月セルの事後ランキング選択**が現行WR4を置き換える価値がない」という
  判断。本トラックは置き換えを主張しない。**別口座・別枠**で、直近レジームへの追随
  (strategy momentum)に賭ける独立の玉として運用する。
- 判定に使う土俵は共通(docs/111 中央3ヶ月機械)。数字は IS(直近窓の見かけ) と
  WF(ウォークフォワード=実力) を必ず併記し、盛らない。
- 本トラックの結論が負(WFで現行に全面劣後)でも、ユーザー判断でEA化まで行う
  (経済性の最終判断はユーザー・docs/47のEV式で正直に提示する)。

## 2. 選択規則(凍結)

毎月月初に、直近W暦月(選択月を含まない)のデータだけでユニットを採点し翌1ヶ月保有:

1. **スコア** = 窓内の合計ネットリターン(主要)。参考変種としてSharpe版(k=3のみ)。
2. **採用** = スコア上位k本。ただし**スコア>0のユニットのみ**(正が k 本未満ならその本数、
   全滅なら当月ノーポジ)。
3. **重み** = 窓内日次ボラの逆数比例(合計1に正規化)。
4. 変種グリッド(これで全部・追加しない):
   W∈{6,12} × k∈{2,3,5} の6変種 + Sharpe版(W=12,k=3 / W=6,k=3)の2変種 = **8変種**。

## 3. 検証プロトコル(凍結)

- データ: Yahoo日足 2015-01-01〜2026-07-31(取得日2026-07-30・7月は月途中まで。SHA-256記録)。
  取得・スリーブ構築は既存モジュール(`parallel_vs_existing_compare` / `portfolio_daily_compare`)
  を逐語再利用し、窓のみ2026-07-31へ延長。
- ウォークフォワード適用期間: **2017-01〜2026-07**(115ヶ月)。選択に使うのは常に過去データのみ。
- 土俵: docs/111機械を逐語再利用(日次ブロックMC・FN P1+8%・フロア−8%・日次−5%・
  ガード−4%楽観/素の悲観2バウンド・fail優先・シード7・最終2万パス)。
  各変種のWF日次系列を**中央3ヶ月通過**に倍率校正して失格率を比較。
- 対照: 季節R4+G3(現行標準)を**同一窓(2017-01〜2026-07)**で再校正した行。
- 追加表示(参考): 各変種の直近12ヶ月(2025-08〜2026-07)のIS成績
  (=「過去1年だけ伸びている」見かけの数字。選択バイアス込みであることを明記して提示)。

## 4. 判定基準(凍結)

1. **採用変種** = 中央3ヶ月土俵で `fail_pct_optimistic` 最小
   (同率は fail_pct_raw → 月次Sharpe の順)。
2. **チャレンジEV(報告義務)**: FN100k想定(docs/24/47の凍結値: 手数料$549・通過で返金・
   通過時15%報酬+分配80%)で
   `EV/挑戦 ≈ P(pass)×(15%報酬+資金化後期待) − P(fail)×手数料` を採用変種と現行対照で併記。
3. **EA化**: 判定1の変種の選択規則を「2026-07末までの直近窓」に適用した重みを
   焼き込んだ専用EA(プロジェクト標準ガード一式・重みの**有効期限=3ヶ月**を実装、
   期限後は月初に警告通知)。結果が現行に劣後してもEA化は実施(ユーザー決定)。
   ただし倍率は土俵校正値を上限とし、docs/172の配置(正攻法トラック)は変更しない。

## 5. 事前に明記するリスク(結果を見る前に書く)

- docs/165追補2の教訓: 直近窓の採点は「ノイズを拾って平均回帰の反動を食らう」のが
  このデータでの繰り返しパターン。WF失格率が現行(5.7/8.5%@1.5x)より**大幅に悪い**
  可能性が高い、というのが事前の期待値。
- 7月データが月途中(30日まで)= 直近窓スコアに1営業日分の欠け。翌月更新で解消。
- 選択が指数月間保有に集中した場合、2024/8/5型の単日ギャップに対して分散がない
  (docs/169)。倍率校正がこれを織り込んで自動的に絞る設計だが、悲観バウンドを必ず見ること。
