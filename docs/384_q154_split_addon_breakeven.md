分配 80 → 90% は出金 ×1.125。月次の期待増分 = 月平均出金 × 0.125。一時払いの価格 P に対する回収月数 = P ÷ 増分。

## 4. 提案(11/1 改正案)
1. **新規 FN 購入時は Lifetime Reward 95% を必ず付ける**(価値 8 倍)。Q88 の FN 25k ×3(年価値 95)は、アドオン込みで年価値 ≈113 と FTMO Std(128)に近づく。Double Up(+40% で 2 口座目)は 25k ×2 を $224 で買える = 単価 −30%。ただし FN は Mon 族の比率上限(docs/318 §2)とアドオン後も EA 可否(公式ページの「EA/VPS はアドオン」表記)の書面確認が先。
2. **Fintokei**: サポートに「ProTrader / スイングの分配を 90% にする有料オプションの有無」を書面で質問(ユーザー操作)。あれば §3 の上限価格で即採用。
3. 既存口座の分配は変えられないので、分配の改善は **FTMO スケーリング(Q155)** と **FN の Tier 制(Instant 70 → 80%)** に委ねる。
