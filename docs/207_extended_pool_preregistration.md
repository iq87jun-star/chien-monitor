# 207.【事前登録】拡張母集団 — 新しい族(E5・RSI2)を選抜母集団に加えると幅と選抜はどう変わるか

> 2026-09-03作成。費用ゼロ。ユーザー問「新しい手法を含めて検証できないか」への実測。
> 本docのルールは`research/extended_pool_walkforward.py`の実行**前**に凍結した。実行後の変更禁止。

## 1. 問い

docs/187(幅>選抜)・docs/206(指標)は34セル固定で測った。**母集団に族を足したとき**、
(a) 選抜なし(BROAD_IV)の OOS は良くなるか(=幅の価値が増えるか)、
(b) 選抜(SEL12/CALMAR)の OOS は良くなるか、それとも選抜ノイズが増えて悪くなるか。

## 2. 追加する族(実行前固定・日足で因果的に構築でき、リポジトリに既存の生成式があるもの)

| 族 | 生成式 | セル | 級 |
|---|---|---|---|
| **E5** | `recentfit_screen.e5_composite`(金+US500/NAS100/GER40 月次TSMOM・逆ボラ加重) | 1(バスケット) | ADOPT候補(docs/84) |
| **RSI2** | `recentfit_portfolio_compare.rsi2_cell(pair, 30, 70, 5)`(RSI(2)<30→翌始値L / >70→S・5日保有・単玉) | FX 9ペア | A案 S4 と同一パラメータ。単独の級は未確定 |

- パラメータは A案 S4 の値を**そのまま**使い、最適化しない。S5 の(20,80,3)は採らない(候補の増殖を避ける)。
- 母集団: **BASE=34セル**(docs/186と同一・TSMOM含む) / **EXT=44セル**(BASE+E5+RSI2×9)。
- G3 FOMC は年8回で活動日フィルタを通らないため対象外(オーバーレイとして別建て・docs/203系)。

## 3. アーム(実行前固定)

BASE と EXT のそれぞれで `SEL12` / `CALMAR` / `BROAD_IV` を走らせる(計6本)。
規則はすべて docs/206 と同一(フィルタ・銘柄1/族2・Top-4・逆ボラcap40%・倍率規則・月次入替・2019-01〜2026-07)。

## 4. 評価・判定(実行前固定)

docs/206 §4 と同一(OOS年率・SR・maxDD・回転率・暦正規化MC・月次差の対応ありt検定+ブロックBS 95%CI)。
比較は **同じアームの BASE vs EXT**(3組)。

| 結果 | 判定 |
|---|---|
| EXT が BASE を **OOS資金化↑かつ失格↓**で上回り、月次差の95%CIが0を跨がない(Bonferroni α=0.05/3) | その族を母集団に追加する提案(適用は次回再スクリーニングから) |
| 上回るが有意でない | 記録 |
| 下回る | 族の追加は選抜ノイズの増加として却下 |

- 新族の**採用頻度**(何回選ばれたか)と、選ばれた月の寄与も記録する。
- 稼働中口座には適用しない。
