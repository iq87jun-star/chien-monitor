# 29. v7 改良 (C) — 予算較正シミュレータ・レジーム条件付け・重要な較正注意

> データ: `research/data/*_h1.csv`（10年）。実装: `research/v7_sim.py`。出力: `reports/v7_sim.json`。
> 期間: 2016-01..2025-12（v7ショット 6,189本）。

## 1. 予算スイープ（自前・透明・再現可能なエンジン）
サイズ較正: perShot = 週次予算/12、ストップ = 2.5×日次ATR（EAの記述通り）。
DD は **realized（終値）** と **floating（含み損込み・FundedNextのequity基準）** の両方。

| 週次予算% | DD realized | DD floating | Phase1合格率(BB) | 年率 |
|---|---|---|---|---|
| 0.50 | 1.07% | 1.34% | 100% | 0.87% |
| 0.60 | 1.28% | 1.61% | 100% | 1.04% |
| 0.75 | 1.60% | 2.01% | 100% | 1.30% |
| 1.00 | 2.13% | 2.68% | 100% | 1.74% |
| 1.50 | 3.19% | 4.02% | 99.8% | 2.61% |
| 2.50 | 5.31% | 6.67% | 98.0% | 4.34% |

合格率はブロック・ブートストラップ（+8%到達 vs −8%失格、時間無制限）。

## 2. ★最重要：handoff の数値との 3〜4倍ギャップ（正直な記録）

handoff PDF は「0.6%→maxDD~5.9% / 純益+28.6%」「1.5%→~14.8%」「2.5%→~24%」とする。
本エンジンは **DDも年率も一様に約3〜4倍小さい**:
- 0.6%: 本=DD1.6%・10年~10% / handoff=DD5.9%・+28.6%（比 ~3.7×・~2.8×）
- 1.5%: 本=DD4.0% / handoff=14.8%（~3.7×）
- 2.5%: 本=DD6.7% / handoff=24%（~3.6×）

**DDと収益が同じ倍率でズレている＝形状（Sharpe）は一致し、サイズ単位だけが違う。**
原因はほぼ確実に**サイズ較正の規約差**（最有力: ストップ幅／サイズの分母）。本エンジンは
documented の 2.5×ATR ストップを使うが、もし原典が実効的に ~3倍大きいサイズ（例: 約0.7–0.9×ATR
相当のストップ、または別のリスク分母）なら、収益もDDも約3倍になり handoff と一致する。

⇒ **エッジ自体は健在**（形状一致）。ただし **DD/収益の絶対水準はサイズ規約に完全依存**。
**本資金のサイズ決定前に、原典 v7 が使った正確な較正規約を確定する必要がある**（下記§4で要確認）。
どちらが正しいか未確定のうちは、**保守的（=高い方のDD想定）でサイズを決める**のが安全側。

## 3. レジーム条件付け（walk-forward, 先読みなし）— 改善せず
ボラ代理（JPYバスケット週次リターンの8週std）で、前半でしきい値を決め、**後半OOSのみ**で
「低ボラ週だけ稼働」を検証:

| | mean | maxDD | Sharpe(年) | 稼働週 |
|---|---|---|---|---|
| baseline OOS | +0.00028 | 0.69% | 1.46 | 259 |
| 低ボラのみ OOS | +0.00021 | 0.60% | **1.29** | 164 |

→ DDは僅かに下がるが Sharpe も収益も下がる。**OOSで改善とは言えない**。レジーム・オーバーレイは
採用しない（規律通り正直に否定）。他のレジーム定義で将来試すなら**新規事前登録**で。

## 4. 結論と要確認
- **採用すべき改良は今回なし**（レジーム条件付けはOOSで無効）。v7 はそのままで Phase1合格率は
  全予算で ~98–100%（本エンジン基準）。
- **アクションが必要なのは "改良" ではなく "較正規約の確定"**。handoff と本エンジンの3–4倍差は、
  本資金サイズを左右する重大事項。**確認したい**: 原典 v7 のDD算出は
  (a) ストップ幅は本当に 2.5×ATR か（もっとタイトでは？）、(b) perShot は 週次予算/12 か、
  (c) DDは equity(floating) か balance(closed) か。これらが分かれば即座に一致させられる。
- それまでの実務指針: **保守側（高DD想定）でサイズ決定**。例えば「真のDDが本エンジンの約4倍」
  と仮定するなら、−10%枠に収めるには週次予算を控えめ（~0.6%前後）に置くのが妥当。
