## 4. 判定

- 記録しておく事実: 指数 0.5 倍の 2 つ(幅 2.6%・2.4%)と 0.75 倍・2.4% は、提案に対して 2 場面とも ev_ok。

## 5. 読み方
1. **指数を半分にすると、失格が大きく減る。** いまの段階で、失格は提案の 11.5% / 9.1% に対して 2.8% / 4.6%。到達は ① で 75.5 → 83.6%、② で 77.0 → 79.2%。次の段階も 6.3% / 4.1% → 1.2% / 2.4%。
2. **指数を減らしすぎると、古い期間の到達が下がる。** 0.25 倍・0 倍は ① では最も良いが、② の到達が 66〜75% まで落ちる。指数の利益が古い期間の到達を支えていた。0.5 倍が両方の期間の釣り合いが良い。
3. **ガードが動く回数も減る。** 満額の月曜のうちガードが動く割合は、いまの段階で 9.9%(いま)→ 提案 14.2% に対して、0.5 倍・2.6% は 7.3%。発動が減れば、3% を超える機会そのものが減る。
4. **いまの形(1.0 倍・2.8%)と比べた 0.5 倍・2.6%**: いまの段階は ① 到達 +5.9・失格 −8.1、② 到達 −2.1・失格 −2.8。次の段階は ① 到達 +5.8・失格 −4.1、② 到達 +0.4・失格 −1.9。到達までの週数は 10〜11 週 → 13 週。
5. **以前の判断との関係。** 11/16 に「指数は現行の数量のまま」と決めている(Q247: NAS100 のデータの欠けを補うと危険が試算より大きい、という結果を見たうえでの判断)。今回は Fintokei の注意という新しい事情がある。NAS100 のデータの欠けは「指数の危険を小さく見ている」方向なので、指数を減らす側の結論を弱めない。
6. **後づけの面がある。** 次点を取り上げるのは結果を見た後の判断。指数 0.5 倍が良いという向きは 2 場面・2 期間・幅 3 通りで一貫しているが、選び方そのものは先に決めた手順ではない。

## 6. 限界
- すべりの見込み(0.4% × 指数の倍率 + 0.1%)は実測 1 回からの仮定。「収まる」の線引きはこの仮定に依存する。
- NAS100 の 1 時間足の欠け(Q247)。モデルは 1 時間足・発動時の損失は幅 × 1.1。ロールは入れていない。
- 同じ 10 年のデータ。指数の数量は 11/16 にも一度検討している(Q247)ので、これが 2 回目の検討になる。
- 本口座後の構成(指数 0.375 倍)は対象外。
