## 1. 方法(事前固定)
- 通貨ごと・月曜ごとに、z1 = 200 日線からの下方乖離(その通貨の過去だけで標準化)、z2 = 前金曜の VIX(過去だけで標準化)。合計の点数 = z1 + z2、そろいの点数 = min(z1, z2)。順位 p = それ以前の全通貨の点数の中での位置(0〜1)。
- G1 = 合計の順位で 0.5〜1.0 倍、G2 = 同 0.25〜1.0 倍、G3 = そろいの順位で 0.5〜1.0 倍。1.0 倍は超えない。履歴不足の間は配備形。
- 判定 = 配備中の形(線の下 1.0・上 0.5)に対して、前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しない。

## 5. 判定と含意
- **棄却 0 / 3**(正常な結果)。配備中の形を変えない。紙上フォワードにも入れない。
- 数値化の答え: 2 つを掛け合わせると、平均の並びははっきり出る(全期間で右下ほど高い・点数の上位 20% は +19〜27 bps)。ただし点数が高い週は相場が荒れている週なので値動きも大きく、利益の大きさに対して振れも大きい。数量の規則にすると、200 日線 1 本で分ける形より安定しない。
- 一番高い角(深く下げていて VIX も高い)は回数が少なく(10 年半で 32)、数量を増やして取りに行く形は失格率の面で採れない(Q197・Q226 と同じ)。
- 200 日線・VIX・その組合せを、定義・深さ・日数・重なり・線の種類・例外・点数化と 9 項目試し、配備中の単純な形を 3 つの期間で上回るものは無かった。この方向は打ち切る。
