## 2. 読み方

1. **含めた場合の効果は「収益」より「分散」に出る。** 年率は +1.0pp(16.3 → 17.4%)で統計的にはノイズの範囲だが、最悪月中 DD が −17.9% → −12.6% と 5pp 縮む。相関 0.25 の 6 セルが 34 セルの 1/6 の重みを持つことで、円クロス Mon と指数 Hold に偏った 28 セルの「同時に崩れる月」が薄まる。
2. **TSMOM 単独では弱い**(Sharpe 0.38・失格 36%)。単独の EA として走らせる価値は無く、ブロード配分の一部としてのみ意味がある。docs/194 §4 の設計(選抜なし・逆ボラ・倍率 0.5〜0.7 倍)はこの前提。
3. 倍率 4.30 は「−4%/日・−8%月中 DD に収まる最大」の校正値で、長寿命枠では 0.5〜0.7 倍(実効 2.2〜3.0)に落とす(docs/194 §4.1)。その場合の目安: 年率 9〜12%・最大 DD −10〜−14%・失格率は 1 桁前半。
4. MC の資金化率が docs/187(65.9%)より高いのは、本書の MC が `max_days` を暦日換算で長く取っているため(同一設定内の比較にのみ使う)。
