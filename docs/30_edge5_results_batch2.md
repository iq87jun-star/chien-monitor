## F2 を採用しない理由（重要・規律の核心）

F2 は6ゲート（純益・有意性 p=0.0026・1年抜きジャックナイフ・プラセボ・コスト・v7相関）を**すべて通過**した。
しかし**新設の分割標本テスト**で馬脚を現した：

- **前半 2016-2020: Sharpe 0.68 / perm_p=0.233（非有意）**。しかも前半の利益はほぼ **2016年だけ
  （81日・Sharpe4.92＝小標本フレ）**で、2017≈0・2019/2020は負。
- **後半 2021-2025: Sharpe 1.77 / perm_p=0.005（有意）**。

→ F2 の全期間 ADOPT は **2021-2024 の「米利上げ→円安」レジームに集中した見かけ**。
1年抜きジャックナイフが通ったのは円安が3年連続だったため（1年抜いても残る）。これは
docs/26 規律2「短期の好成績は楽観側」「期間を必ず併記」が警告した典型的な罠で、
**自動6ゲートの盲点を分割標本が暴いた**。

さらに運用上の懸念:
- F2 は USDJPY ロング＝**v7 と同じ円ショート方向**。週次相関は −0.01 と低く出るが、これは v7 が
  月曜のみの疎な系列だから。**円急騰局面（2024/8 のキャリー巻き戻し等）では v7 と F2 が同時に
  ドローダウンしうる**＝テールでの分散効果は見かけ倒れの恐れ。
- 既知のマクロ関係（金利差キャリー）であり「新規の独立エッジ」とは言い難い。

**判定: F2 は本資金不可。** やるとしてもデモ前進で「次の利上げ/円安局面でのみ機能するか」を
別途確認する“衛星のさらに候補”止まり。急いで本資金に足さない（規律）。

## 副産物: ハーネス改良

- `lib/stats.split_half_pvalues` を追加（前半/後半の順列 p）。`lib/evaluate` が `robust_split_half` と
  `final`(ADOPT_BUT_FRAGILE) を出力。**多年レジーム集中を1年抜きジャックナイフより確実に検出**。
- 今後の ADOPT 判定は「6ゲート ∧ 分割標本 both_significant」を本資金の必要条件とする。

## 全体結論（3本目・4本目・5本目探索を通じて）

- 第1弾 E3-E6（ボラ・レジーム/金利先行/イベント/指数平均回帰）= 全 REJECT。
- 第2弾 F1-F3（セッション/キャリー/安全資産）= F1・F3 REJECT、F2 は脆弱で本資金不可。
- **検証済みコアは依然 v7 のみ。MA2 は LEAD のまま。新規の独立エッジは見つからず。**
- これは失敗ではなく、**十分な検出力をかけて「無い」を確認できた**こと。誇張せず v7/MA2 に集中するのが規律的に正しい。
