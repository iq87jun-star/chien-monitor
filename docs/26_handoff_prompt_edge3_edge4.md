```

(chien-monitor)で1つの検証済みエッジ(v7)を本番運用しており、独立性の高い
「3本目・4本目」のエッジを追加したい。下記の現状・規律・禁止事項を厳守すること。

【運用中の業者・プラン（実運用）】
- 現行プロップ: FundedNext「Stellar(2-Step)」。最大損失-10%(静的)/日次-5%/+8%目標。
  時間無制限・一貫性ルールなし。v7を週次リスク2.5%(=社内呼称2.5倍)で運用中。

【★既に探索し尽くして全滅した領域（重複厳禁。同じ土俵を再探索しないこと）】

→ FX内のカレンダー・順方向ドリフト・平均回帰・モメンタムは検出力十分で全て否定済み。

【厳守する研究規律（過去に捏造・過小評価で失敗した。再発防止が最優先）】
1. 事前登録: 候補数Nを先に固定し、当たるまで増やさない。Bonferroni補正(α=0.05/N)。
2. 検定は必ず【10年実データ】で。短期(2.8年)の好成績は"上限"でなく"楽観側"として扱う。
   ※過去にv7の最大DDを2.8年で-4.9%と過小評価→10年で実は-14.8%。期間を必ず併記。
3. 全主要ゲート通過のみADOPT: ①純益>0 ②順列p(自己相関頑健版=月次ブロック符号シャッフル)
   <α ③ジャックナイフ最大p≤0.10 ④曜日/プラセボで対象だけ突出 ⑤コスト(往復スプレッド・
   スワップ)計上後も生存 ⑥v7との10年相関が低/負(順方向を足しても分散にならない)。
4. 数値は実行出力をJSON直読/単一スカラで検証して転記。表示破損のまま転記しない。
5. 1つも通らなければ「3本目なし」と正直に結論する。それも価値ある結果。
6. -10%(および-10%トレーリング)口座に収まるサイズ/DDか足内エンジンで実測。本資金即投入禁止。

【未踏=次に試す価値のある土俵（事前登録の出発点。ここから3-6個に絞って登録せよ）】
- ボラティリティ・レジーム条件付け（VIX/ATR分位で月曜エッジや他系統をオン/オフ）。
- キャリー/金利差（実需・スワップ由来）を明示シグナル化（v7のスワップ依存と要分離）。
- クロスアセットのリード・ラグ（指数→FX、金利→円 等の先行性。docs/15でUSD先行は弱だった）。
- イベント・ドリブン（指標/中銀の前後の定型反応。ニュースフィルタの裏返し）。

- 多資産の別構造（金・指数の平均回帰、相対モメンタム、ボラ・ターゲティング)。
※「v7と無相関 or 負相関」かつ「-10%枠に収まるDD」を満たさないものは衛星にもしない。
```
