## 2. 結論

1. **スイングプランは選ばない**(FN型のbalance基準=docs/170で失格実証済みの構造)。
2. **通常チャレンジプランをパイロット採用候補に確定**。equity基準日次(−5%)は当方採用倍率では
   単日で届く歴史日が存在せず(1.8x相当まで無風)、実質「静的−10%のみ」の世界に近い。
   適用成績はdocs/172系グリッドの「自由業者」列: **季節RG3 1.25x = 到達96.5%/中央8ヶ月/失格3.5%**。
3. 留意: 日次リセットは**UTC0時(JST9時)** — MT5サーバー日と異なる場合はEAのガード日界とズレる
   (緩衝1%で吸収可・初週ログで確認)。両建て禁止はEA仕様上、非該当。
