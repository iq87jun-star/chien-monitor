## 1. 方法(事前固定)
- 形 = 配備形 Mon4(4 通貨各 0.25・EA 実時刻・コスト後)の「減らすだけ」: 弱い通貨 1.0 倍・それ以外 0.5 倍。通貨ごとに、月曜より前の最後の確定日足で判定。
- 基準 = 配備中の定義(金曜終値が 200 日線の下)。
- V1 = 13 週前(65 営業日前)の終値より安い。V2 = 直近 252 営業日の終値の高値から 5% 以上下。V3 = 深さ 3 段階(線の上 0.5・浅い下 0.75・深い下 1.0。深い = 乖離が過去の「線の下の日」の乖離の中央値以下)。
- 判定 = 基準に対して、前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しない。

- **「下げた後のほうが強い」は、どの定義でも 3 つの期間すべてで同じ向き。** 線の上・高値の近く・13 週前より高い、のときは平均が小さい(前窓ではマイナス)。
- **深いほど強いか**: 1 年の高値からの下げ幅で見ると、3 つの期間とも深い区分ほど平均が高い並びになっている。一方、200 日線の下の中での深い / 浅いは OOS で逆転(浅い +20.7・深い +6.8)し、線の下だけの順位相関も前窓 −0.04(p 0.33)・探索 −0.16(p 0.04)・OOS +0.14(p 0.18)で一定しない。深さで数量を刻むだけの安定した差は確認できない。

## 4. 判定と含意
- **棄却 0 / 3**(正常な結果)。配備中の定義(200 日線の下はそのまま・上は半分)を変えない。
- 「下げた後に取る」のテクニカルな定義は、200 日線・13 週前比・1 年の高値からの下げ幅のどれでも表せ、同じ現象を別の物差しで見ている。その中で 200 日線が 3 つの期間を通して最も安定(前窓の Sharpe・最悪月が最良)。
- 1 年の高値からの下げ幅の並び(深いほど高い)は目に留まるが、5% の線引きでは基準に届かず、線引きを探し直すのは事後選択になるので登録しない。
