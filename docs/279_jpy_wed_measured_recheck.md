## 3. 解釈: 機構は「キャリーのロール」ではなく「JPY 固有の水曜要因」

1. **CHFJPY**(金利差 0.45pp・理論ロール 0.4 bps)で水曜粗利 +4.6 bps が出ており、高キャリーの USDJPY(+7.1)と同じ桁。ロールなら 1/10 のはず。
2. EM ペア(金利差 3〜45pp)ではロールが観測されない(docs/278)。
3. 非 JPY メジャーには水曜効果が無い。
4. CHFJPY の bid のみ全期間: 2018-19 Wed +2.4(Tue −0.2 / Thu −1.3)、2020-21 −1.0、2022-23 +3.4、2024-26 +4.9。2020-21(全通貨ゼロ金利)を除き水曜だけ正で、**円高方向の水曜要因は 2018 年以降ほぼ一貫**、ただし大きさは変動。

したがって効果の担い手は「水曜 20-00 UTC(木曜 5-9 時 JST)の JPY 買い」という共通因子で、クロスの通貨側は関係が薄い。**7 クロスは分散になっておらず、実質 1 本の JPY ベット**(相関は同じ JPY レグゆえ高い)。docs/272 §5 の「受渡日ロール」説明は撤回し、「機構未特定の JPY 固有カレンダー効果(2018〜、2024〜 で強い)」に改める。

## 4. Q28 / EA7 への含意

- **金利差の門(`InpRollMinCarryPp`)は機構と無関係**。門は CHFJPY を除外する一方で効果とは独立なので、EA7 の門は「安全弁(金利差が消えたら止める)」としての意味しか持たない。docs/276 の停止規則は「実測月次が 3 か月連続負」を主とする。
- **5 レグ × 0.2 × 3 倍 = 名目 3 倍の単一 JPY ベット**として扱う。docs/276 の MC は合成系列で回しており相関は織り込み済みだが、日次損失ガード(4%)の想定は「1 本が同時に逆行する」前提で見ること。1 回の最悪(docs/273 §2 の −153 bps × 3 倍 ≈ −4.6%)は Fintokei の日次 −5% に近い。**倍率は 3 倍を上限とし、4 倍は不可**(docs/273 の 4 倍上限を引き下げ)。
- 2026 年は +2.6 bps/取引と 2025 年の半分。**10/1 の月次監視(forward/q20_monitor.py 2026-09)が正であることに加え、2026-09 と 2026-10 の 2 か月連続で正を確認してから購入**に改める(1 か月遅らせる価値はある: 機構が未特定なので減衰の早期検知が唯一の防御)。
- swap-free 口座が必要という条件は変わらない(通常口座では 3 日分スワップが差し引かれ、観測 +4.5 bps の大半を失う。docs/272 §5)。
