# 88.【事前登録】edge15 — 月次季節性(ユーザー指示・9月特化の確認的検定)

> **位置づけ**: ユーザー指示「月毎で優位性が取れるエッジを探したい。特に9月」。docs/80 の探索終了宣言の
> 例外として**ユーザー指示による限定再開**。総当たりはせず、**文献的事前分布が強い9月仮説3本のみ**を
> 確認的に登録(N=3, Bonferroni α=0.0167)。全月×資産×方向スキャンは**探索ラベル**(採否に不使用・
> 次サイクル候補の参考のみ)。数字を見る前に本docを固定。結果は docs/89 に実出力のみ転記。

## 1. 確認的仮説(N=3・方向と窓を固定)

| ID | 仮説(事前分布) | 取引 | 窓 |
|---|---|---|---|
| **S1_SEP_EQ_SHORT** | **株の9月安**: S&P500の9月は100年級で唯一平均が負の月(最も再現報告の多い月次アノマリー) | US500/NAS100/GER40 を9月SHORT(バスケット) | 8月末終値→9月末終値 |
| **S2_SEP_GOLD_LONG** | **金の9月高**: インド婚礼・祭事需要の仕入れ期。文献で9月が金の最強月(2011年以降減衰の報告もあり=それごと検定) | XAUUSD を9月LONG | 同 |
| **S3_SEP_JPY** | 本邦中間決算(9月末)のリパトリ円高。⚠ 3月本決算版(edge11 F4)は死亡済み=事前分布は弱い、と認めた上で登録 | USDJPY を9/15以降SHORT | 9/15以降初営業日終値→9月末終値 |

- データ: ローカルキャッシュ(Yahoo日足: 指数1985〜/金2000〜/USDJPY 1996〜)。コスト: 指数金5bps・FX2pip。
- **主窓=全履歴**(検出力最大・レジームつまみ食い防止)。2016年以降サブ窓を併記(現行レジーム該当性)。

## 2. ゲート(各仮説)

1. **G_dir**: 全履歴で登録方向の net>0
2. **G_perm**: 年次系列の符号順列 p ≤ 0.0167(n=3000, seed=13)
3. **G_split**: pre-2016 / 2016+ の両方で net>0(レジーム耐久)
4. **G_month_rank**: 同戦略を他の11ヶ月に当てたとき、9月が**1-2位**(月シフト・プラセボ。
   「どの月でも勝てる=月の情報ゼロ」を排除。docs/81 G4と同型)
- 判定: 4ゲート全通過=**SEP-LEAD**(EA組込み・デモへ) / G_perm のみ未達=参考記録 / 他=REJECT。
- 月次季節性は年1標本ゆえ ADOPT 級(Bonferroni+JK全装備)は構造的に不可能、と事前に認める
  (docs/73 §3-1 と同じ制約)。**SEP-LEAD はデモ専用ラベル**。

## 3. 探索スキャン(参考のみ・採否に不使用)

全資産(指数3+金+JPYクロス3)×12ヶ月×{L,S} = 168セルの全履歴 net/perm_p ヒートマップを併記。
Bonferroni α=0.05/168=0.0003 を明示し、生存セルのみ「次サイクルの事前登録候補」として列挙する。
