## 1. 方法(事前固定)
- 形 = 配備形 Mon4(4 通貨各 0.25・EA 実時刻・コスト後)の「減らすだけ」: 金曜終値が N 日線の下の通貨 1.0 倍・上の通貨 0.5 倍。N ∈ {50, 100, 150, 200(配備中), 250, 300}。
- 各 N を「縮小なしの Mon4」と比べ、前窓・探索・OOS の 3 つすべてで Sharpe 改善 かつ 最悪月が悪化しないか。
- 読み方: 「丈夫」= 150 日と 250 日の両方が満たす /「孤立」= どちらも満たさない。結果にかかわらず配備の 200 は変えない。

- **読み方の結果 = 丈夫**(150 日・250 日とも満たす)。50〜250 日の 5 つすべてが、3 つの期間で縮小なしより良い。300 日だけ OOS が 1.10 → 1.07 でわずかに届かない。
- **一番の日数は期間ごとに違う**: 前窓は 200 日、探索は 250 日、OOS は 50 日。200 日が山の頂点というわけではなく、どの期間でも上位〜中位にいる。

- 150〜250 日は 200 日の判定と 92〜94% 一致しており、ほぼ同じ週を選んでいる。

## 4. 判定と含意
- 200 日線の縮小の効果は、日数に左右されない。「200」は偶然当たった数字ではなく、長めの移動平均ならどれでも同じ現象を拾う。
- 200 日がベストとは言えない(期間ごとに一番が入れ替わる)が、乗り換える理由になる日数も無い。**配備は 200 日のまま**。
- OOS で 50 日が良いのは 86 週の結果で、探索では縮小なしと同じ(1.39 対 1.38)。短い日数への乗り換えは登録しない。
