## 固定パラメータ

- **フィルタ候補 N = 3**（VF1/VF2/VF3）。**増やさない（最適化禁止）。**
- 評価予算: **weekly 1.5%**（funded 運用想定）固定で比較。
- **成功条件（事前定義）**: ベースライン比で
  1. **maxDD を有意に縮小**（例 −17%→ −10%枠内）、かつ
  2. **Calmar 改善**（リターン取りこぼしが DD 縮小に見合う）、かつ
  3. **MC 合格率(Phase1 +8%/-10%) 向上**、かつ
  4. **前後半とも改善が出る**（分割標本で頑健・片肺でない）。
  → 4条件すべてを満たすフィルタのみ「採用候補」。トレード数を削るだけで DD が下がっても
  Calmar が落ちれば不採用。
- 採用候補が出ても本資金即適用せず、デモ前進検証へ。
