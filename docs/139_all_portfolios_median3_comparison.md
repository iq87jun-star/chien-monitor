## 2. 読み方(重要な但し書き)

1. **絶対値は保守側の物差し**(docs/111 §3): Yahoo日足・fail優先・月単位i.i.d.ブートストラップ。
   PD現行のDrive確定値(失格4.9%・月次MC)とは物差しが違う。**行間の相対比較が主眼**。
2. **v4を含む行(季節/PD系)はYahooで過小評価される**(docs/138)。実データでは改善方向
   (実測例: PD間引き+v4 30%はDukascopyで22.4/26.8 = Yahooの25.4/31.2より良い)。
3. **季節R4+G3の圧勝には in-sampleバイアスの割引が必要**: R4の月別重みは同じ10年で訓練した
   記述統計(LOYO合格だが配備テーブルは全期間訓練, docs/105/111)。他の構成は通年固定=バイアス最小。
   割引後も失格1桁%は他と一線を画すが、「2.24のSharpe」を額面で信じない。
4. **PortfolioE v2をこの表で評価しないこと**: 中央3ヶ月へ無理に踏むと(1.45x)失格24%になるが、
   これは設計外の使い方。PEの本来の運用は**0.68x・中央13ヶ月・失格4.8%(FTMO)**の
   低速・低失格・レジーム保険(docs/133)。この表は「速攻の器としては不向き」の確認に使う。

## 3. 含意(役割分担の確認)

- **審査の速攻**: 季節R4+G3(稼働中)が最適のまま。次点=PD間引き(現行PDの上位互換・デモ待ち)。
- **通年の主力**: PD間引き版がPD現行を全指標で上回る(同速度で失格−5.8pt・月利+0.16pt)。
- **保険**: PortfolioE v2は速攻に使わず、0.68xの長期口座として運用(docs/133)。
- PE v1(4資産)は全面的にv2に劣後=docs/133の置換判断を再確認。
