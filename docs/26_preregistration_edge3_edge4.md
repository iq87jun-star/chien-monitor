- **候補数 N = 4**（下記 E3A〜E3D）。**当たるまで増やさない。**

- **検定期間 = 10年（2016-01 〜 2025-12）固定**。短期（2.8年等）は「楽観側の上限」としてのみ併記、
  単独で結論に使わない（規律 2／v7 のDD過小評価の教訓）。

全滅領域と被らない**4本を選定:

## 3. 各候補の事前仮説とルール（完全固定）

すべて: H1（必要に応じ M15/日足）バー終値ベース、UTC、往復スプレッド＋スワップ計上後で評価。
サイズは「週次リスク予算 ÷ その候補の週あたりショット数」（v7 と同じ予算配分思想）。
初期 risk 予算は **0.6%/週**（v7 既定）を基準に、DD が −10% 枠に収まるかを事後に確認。

### E3A — 株価指数 短期平均回帰（gap-fade / 終値オシレータ逆張り）
- **事前仮説**: 株価指数は短期で平均回帰する（オーバーナイト・ギャップや過熱の戻し）。これは
  FX の MR（封鎖済）とも多資産*トレンド*（封鎖済）とも機構が異なる、別資産クラスの逆張り。
- **シグナル（固定）**: 各指数で、(a) 前日終値→当日寄りの**下方ギャップが −1.0σ 超**なら寄りで LONG・
  当日引けで決済（gap fade）。(b) あるいは 2日RSI(終値) < 10 で翌日 LONG・RSI>50 or 2日経過で決済。
  両ルールを別シグナルとして併走（v7 の多ショット思想：1機構を分散サンプリング）。SHORT は対称に
  ギャップ +1.0σ / RSI>90 で（指数は上方バイアスがあるため SHORT は別途プラセボ扱いで弱くてよい）。
- **対象**: US500, NAS100, JP225（プロップが提供する指数CFD）。
- **災害ストップ**: 2.5×日次ATR。**左テール対策に必須**（暴落での「押し目買い」リスク）。
- **想定 v7 相関**: ≈0（別資産・逆張り）。**DD 懸念**: 危機時の連続逆張りで太い左テール → 器(II)の主検査対象。

### E3B — クロスアセット・リードラグ（株リスクオン → 商品系JPYクロス）
- **事前仮説**: 米株の大引けのリスクオン/オフが、翌アジア時間の*商品系*円クロスに先行する
  （リスクオン→AUD/CAD高・円安）。docs/15 は「USD 先行」を見て弱だったが、**先行変数=株指数、
  対象=v7非採用ペア**で未検証。
- **シグナル（固定）**: 米株指数（US500）の前日 16:00–21:00 UTC リターンが **+0.5σ 超**なら、当日
  00:00 UTC（東京寄り）に AUDJPY・CADJPY を LONG、当日 08:00 UTC（ロンドン寄り）で時間決済。
  −0.5σ 未満なら見送り（SHORT は対称・プラセボ）。
- **対象**: AUDJPY, CADJPY（**v7 は EUR/GBP/USD-JPY なので非重複**）。
- **想定 v7 相関**: 低（先行条件付き・別ペア・別時刻）。要ゲート⑥で実測。

### E3C — 横断キャリー（金利差ランク → *スポット*超過収益）
- **事前仮説**: 金利差は将来スポット収益の横断的予測力を持つ（キャリー・プレミアム）。**ただし
  スワップ受取そのものは除外**し、価格（スポット）だけで超過収益が出るかを検定 → v7 のスワップ
  依存と明確に分離（引き継ぎの要請）。
- **シグナル（固定）**: G10 FX を毎週月曜に「対USD政策金利差」で順位付け、上位3通貨を LONG・
  下位3通貨を SHORT（対USD）、週次リバランス、保有1週間。**PnL はスポット価格変化のみ**で集計
  （受取スワップを0扱い）。受取スワップ込みの結果も*参考*併記するが判定はスポットで行う。
- **対象**: G10（USD, EUR, JPY, GBP, AUD, NZD, CAD, CHF, SEK, NOK）の対USDペア。
- **想定 v7 相関**: 低〜負（要実測）。**注意**: JPY が下位（低金利）で常時 SHORT になりがち →
  v7 の JPY-LONG と**負相関**になる可能性（＝分散に良い）。ゲート⑥で符号確認。

### E3D — ボラレジーム条件付きセッション・ブレイクアウト（東京→ロンドン）
- **事前仮説**: 東京時間に作ったレンジを、ロンドン寄りがブレイクして追随する。proto_session が
  弱かったのは無条件適用のため。**高ボラ分位（日次ATRが過去60日中位より上）に限定**すると
  ブレイクの follow-through が出る、という条件付き仮説。
- **シグナル（固定）**: 00:00–07:00 UTC（東京）の高安レンジを記録。07:00 UTC 以降、当日ATRが
  **過去60日ATRの上位50%分位**のときのみ、レンジ上抜けで LONG／下抜けで SHORT（ストップ＆リバース
  なし、1日1回・先に出た方）。決済は 15:00 UTC 時間決済 or 0.8×レンジ幅の逆行ストップ。
- **対象**: EURUSD, GBPUSD（**非JPY**で v7 と通貨が直交）。
- **想定 v7 相関**: 低（非JPY・ブレイク機構）。コスト厳格計上（往復スプレッド超過は見送り）。

## 4. 判定ゲート（全6通過のみ ADOPT。引き継ぎ規律 3）

各候補について、10年実データで以下を**全て**満たすときのみ **ADOPT**。
1つでも欠けるが純益>0かつ筋が良い → **LEAD**（デモ前進検証へ）。純益≤0 or 機構崩壊 → **REJECT**。

| # | ゲート | 合格条件 |
|---|---|---|
| ① | 純益 | 10年・コスト後の純益 > 0 |
| ② | 順列p（自己相関頑健） | **月次ブロック符号シャッフル**の片側 p < **α=0.0125** |
| ③ | ジャックナイフ | 1年ずつ除外して再検定した**最大p ≤ 0.10**（特定年依存でない） |
| ④ | プラセボ/対象特異性 | 曜日・他資産・SHORT対称等のプラセボで、登録した対象**だけ**が突出 |
| ⑤ | コスト生存 | 往復スプレッド＋スワップ計上後も①②が生存 |
| ⑥ | v7 独立性 | v7 週次リターンとの10年相関が**低（|ρ|小）or 負** |

**器(II) DD スクリーン（2段階・正直な区分）**:
- *stage-1（ハーネスが自動出力）*: `max_dd_equal_notional` = 等名目アグリゲートのDD。**形状の目安**で
  あって予算較正ではない（per-trade のストップ距離でサイズ較正していないため絶対%は意味を持たない）。
- *stage-2（ゲート①②③⑥ を通過した候補のみ実施）*: 各 runner に per-trade ストップ距離を与えて
  **週次リスク予算でサイズ較正**し、10年 maxDD を実測。−10%（静的）/−10%トレーリング双方で
  **失格しないサイズが存在**することを確認（v7 同様 DD はほぼ予算線形と仮定し外挿）。存在しなければ
  「衛星にもしない」（引き継ぎ）。REJECT 候補に stage-2 は行わない（労力節約）。

**転記規律（規律 4）**: 全数値はハーネスの **JSON 出力を単一スカラで直読**して docs に転記。
表示破損のまま転記しない。期間（10年／サブ期間）を必ず併記。

**結論の正直さ（規律 5）**: 4本いずれも全ゲートを通らなければ「**3本目なし**」と結論する。
それも価値ある結果として記録する。
