## 3. 見落としやすい2点

1. **PSP保証金(rolling reserve)**: 売上の5〜10%が常時数ヶ月拘束される。売上が伸びるほど
   拘束額も伸びる「成長するほど現金が要る」構造。運転資金に必ず織り込む。
2. **保険資本は使う金ではなく置いておく金**。docs/178 の「初年度黒字の罠」により、
   序盤の黒字を見て保険資本を取り崩す誘惑が最大の自滅パターン。
   sharp 負債は後から来る。

## 4. 現有リソースとの接続

- 挑戦者側EV ¥278万/年(docs/46/47)だけで①の推奨額を作るには約8年。
  → ①に進むなら、資金源は挑戦者収益ではなく別途調達(貯蓄・事業・共同出資)が前提になる。
- 逆に①で CAC と s の実測が取れれば、②③の判断は docs/178 のモデルに実数を入れるだけになり、
  「¥5,000万〜1億を張るに値するか」が推測でなく計算で決まる。
  **総額の大きさそのものより、大金を張る前に未知数を潰せる順序(docs/175 の段階制)が本体。**
