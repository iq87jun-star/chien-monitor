# 64. 現在使用中の業者の規約レビュー（FundedNext / Blueberry / 参考FTMO）

> ユーザー要望「現在使用中の業者も規約を見てほしい」。現用＝**FundedNext(プロップ・15%アドオン)** と
> **Blueberry Funded(インスタント・EAで強制退去歴)**。両社規約を最新確認し、確定スペックの当てはめ可否を判定。
> 出所: 各社ヘルプセンター/2026年レビュー(本doc末尾)。⚠ 規約は改定され得る・最終は各社公式と決済画面で確認。

## 0. 一行結論

> **3社で"ヘッジの扱い"が決定的に違う**:
> - **FundedNext = 同一口座内のヘッジOK** → **フルP★(v7+v4+E5+E-Mon)を1口座でそのまま運用可**(準拠制限不要・最強)。
> - **FTMO / Blueberry = ヘッジ不可**(口座間も) → **準拠版 v4+E-Mon 55:45**(docs/61・指数SHORT無)を使う。
> - **Blueberryの退去は「EA使用」自体ではない**(現行規約はEA許可)。**最有力容疑＝日次DD4%(業界最タイト)抵触** か
>   ニュース2分/リバースヘッジ。**確定スペック＋日次−2.5%ガード**で再発を防げる。

## 2. ★Blueberry強制退去の原因推定（EA許可なのに、なぜ）

**現行Blueberry規約はEAを明確に許可**。∴「EAを使ったから」ではなく**特定の違反**で退去した可能性が高い。容疑:

| 容疑 | 根拠・該当度 |
|---|---|
| **① 日次DD 4%抵触（最有力）** | Blueberryの日次4%は**業界最タイト**。レビューも「**勝ち日でも intraday スイングで4%を超え得る**」と明記。 |
| | 旧構成(v7+E5 攻め1.5%)は月曜に複数ショット＋E5が同時に動くと日内で−4%を突きやすい。 |
| ② ニュース2分 | v7/E-Monは月曜固定時刻エントリー→指標と重なれば違反。 |
| ③ リバースヘッジ/アービ判定 | 同一/相関銘柄の反対同時(旧構成にE5の指数ショート等)が「reverse hedge」と判定された可能性。 |
| ④ Instant Elite固有/規約改定 | 当時のInstant商品の個別条項・運用時点の規約。 |

> ⚠ **正確な理由は退去通知(メール)に書かれているはず**。まずそれを確認するのが確実。だが上記①が最有力。
> 対策＝**日次ストップを4%の内側(−2.5%推奨)に設定・ニュースフィルタON・ヘッジ(同一/相関の反対)を作らない**。
> ＝**確定スペックの準拠版(v4+E-Mon・指数SHORT無)＋日次−2.5%**ならBlueberryでも再発を防げる。

## 3. 業者別 推奨構成（確定スペックの当てはめ）

| 業者 | 推奨構成 | 理由・設定 |
|---|---|---|
| **FundedNext(プロップ)** | **フルP★(v7+v4+E5+E-Mon)を1口座** | 同一口座ヘッジOK→準拠制限不要・**Calmar1.66の最強構成が使える**。ニュースは利益capのみ(回避不要)。日次−4%ガード。一貫性ルール→EA固定。 |
| **FTMO(プロップ・並行用)** | **準拠版 v4+E-Mon 55:45** | ヘッジ不可(口座間も)→指数SHORT無の準拠版。`Chien_FTMO_Compliant_AllInOne`。Swing口座ならニュース制限なし。 |
| **Blueberry(インスタント)** | **準拠版 v4+E-Mon 55:45＋日次−2.5%** | EA可だが**日次4%が鍵**→日次ストップを−2.5%に。ニュースフィルタON。reverse hedge回避。static DDで予測しやすい。 |

- **準拠版(v4+E-Mon)は3社すべてで安全に動く"universal"構成**。FundedNextだけは更にフルP★も許される(上振れ)。
- `Chien_FTMO_Compliant_AllInOne` の `InpDailyStopPct` を **Blueberryは2.5、FTMO/FNは3.0** に変えるだけで全社対応。

## 4. 実務チェック（再発防止）

1. **Blueberryの退去通知を確認**（正確な違反項目を特定）。不明なら日次4%が最有力。
2. **日次ストップ**: Blueberry=−2.5% / FTMO・FN=−3%（いずれも各社の日次制限の内側）。
3. **ニュースフィルタON**（FTMO/Blueberryは2分必須）。FN・FTMO Swingは緩い/不要。
4. **ヘッジ**: FN=同一口座内OK / FTMO・Blueberry=**同一・相関の反対同時を作らない**(準拠版でクリア)。
5. **一貫性(FN)**: 審査と本番で同じEA/戦略を維持（途中で別物に変えない）。
6. **最大割当・口座数**は各社別途（スケール時, docs/58）。

## 5. 限界
- 規約は**頻繁に改定**される。本docは2026年時点の公開情報ベース。**最終は各社公式ヘルプ＋決済画面＋(退去なら)通知で確認**。
- 「相関銘柄の反対同時」の判定は各社の運用次第のグレー領域＝**保守的に避ける**のが安全。
