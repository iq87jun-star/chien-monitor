## 0. 仮説（機構）
本邦機関投資家は**3月期末（会計年度末）に向けて外貨建て資産を本国回帰**させ、JPY 買い圧力が出る、
という実需仮説（folk だが経済的根拠は明確）。**JPY 高＝JPYクロスをショート**。v7（JPYクロス・ロング、
月曜04-10UTC）とは**方向が逆かつ時期が3月限定**なので、機構・タイミングが直交し独立性が期待できる。

## 1. 正直な検出力の限界（最重要）
**年1サイクル×10年＝独立イベントは実質10**。イベント系（docs/26で検出力不足として非登録）と同じ
弱点を持つ。これを承知の上で、**window 内の日次に展開**して観測を増やし、**年ブロック符号順列**で
自己相関に頑健に検定する。DSR は**累積試行 ≥ 60**で割り引く。当てに行って甘く数えない。

## 2. 事前登録パラメータ（★固定）
- **候補数 N = 1**（3月レパトリのみ）。α = 0.05（単一仮説）。順列p・年ブロック。
- **期間 = 2016..2025（10年・10サイクル）**。
- **対象**: USDJPY / EURJPY / GBPJPY を**ショート（＝JPYロング）**、等加重。
- **window（固定）**: 各年の**3月の最終10営業日**（≈3/18–3/31）。各営業日 daily 終値リターンで保有。
- **方向は事前に固定（JPY高＝クロス・ショート）**。データを見て符号を選ばない。

## 3. 判定ゲート（v7型の季節特異性 + 強化）
① 純益>0（コスト後・10年） ② **年ブロック符号順列 p < 0.05** ③ ジャックナイフ（1年除外）最大p≤0.10
④ **月特異性プラセボ**: 同じ「最終10営業日」を**全12ヶ月**で実行し、**3月だけが突出**（3月平均 >
他月平均、かつ3月が上位） ⑤ コスト（往復スプレッド）後も生存 ⑥ v7独立性 |ρ|≤0.30
⑦ **Deflated Sharpe ≥0.95（N_trials≥60）** ⑧ **PBO≤0.20**（window長 8/10/12/15 営業日の変種で）
