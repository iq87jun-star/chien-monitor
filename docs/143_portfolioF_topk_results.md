# 143.【結果・REJECT】PortfolioF「トップレッグ抜粋」— 無作為な6本にすら負ける(分散>選別の教科書例)

> docs/142(事前登録)の実行結果。`python3 research/portfolio_F_topk.py` の実出力
> (`results/portfolio_F_topk.json`)からの転記。決定規則は機械適用。

## 0. 一行結論

**REJECT。** LOYO選別した上位6レッグのOOS Sharpe **0.61** は、無作為に固定6本を選ぶプラセボ分布の
p80 = **0.96 を大きく下回った**(F1✗)。さらに上位6本の等ノーショナル合成は倍率4xまで踏んでも
中央3ヶ月に到達しない(F3✗)。**「良いレッグを集める」は「バラバラのレッグを混ぜる」に負ける** —
理由は下記のとおり構造的で、既存ポートフォリオ設計(機序の分散)の優位を実証した。

## 2. なぜ「良いものを集める」と悪くなるのか(本docの主眼)

1. **上位レッグは全部「同じ賭け」**: 選ばれた6本は全て**月曜リスクオン系**(指数月曜×2+円月曜×4)。
   単体Sharpeが高いのは同じ機序が強いからで、束ねても**有効ベット数がほぼ1**。
   一方、無作為の6本はE5/G3/v4/E-Mon横などの**異機序が混ざり、合成Sharpeが上がる**。
   プラセボp80(0.96)>選別(0.61)はこの分散効果の直接の実測値。
2. **月曜集中は速度も出ない**: 週1日しか市場に居ないため、等ノーショナルでは
   倍率を4倍にしても+8%到達の中央値が3ヶ月に届かない(F3)。
3. これは docs/76 の設計原理(v4↔v7 −0.10 の負相関を混ぜる)と、docs/14 §3の教訓
   (「無相関エッジが並べられないなら1本を正しくリスク予算化」)の再確認である。

## 3. 決定

- **PortfolioFは作らない**。「良いものの抜粋」は正規ゲートで棄却された(Dukascopy確認にも進まない)。
- 現行の器(季節R4+G3 / PD間引き版 / PortfolioE v2)が引き続き最適解。
  ランキング表(等ノーショナル通年)は**観察用**であり、ポートフォリオ構築の道具ではないことを
  negative spaceとして記録する。
