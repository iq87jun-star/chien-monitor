## 0. 設計方針 — なぜこの3本か

docs/73 §4 の教訓「**低頻度 × 強いマクロ事前分布 × 有利なコスト構造**」と、edge11（docs/80）で
昇格させた「**ドリフト保存プラセボ**」「**対B&H事後診断**」を全候補に標準装備する。
候補は学術文献で繰り返し報告され、かつ本プロジェクトで一度も検定していない**セッション配分系**に限定:

- 株式リターンの大半が**オーバーナイト**（現物クローズ→翌オープン）に集中し、日中はほぼゼロ、
  という「overnight/intraday divergence」は米株で最も再現報告が多いアノマリーの一つ。
- 金も同型（NY時間帯に軟調・アジア〜ロンドンAMで堅調）の報告がある。
- **FOMC声明前24時間の株高ドリフト**（Lucca–Moench, pre-FOMC announcement drift）は
  年8回・1晩保有のみ＝本プロジェクトの教訓に最も合致する「低頻度×強事前分布×低コスト」。

いずれも「方向予測」ではなく**ドリフトの時間帯配分**を取る第3系統（edge10で全滅した
無条件時刻ドリフトとは、資産クラス（ゼロドリフトFX→正ドリフト株/金）が決定的に違う）。

## 3. 採点ゲート（edge11 と同一の6ゲート + 金融コスト + 独立性2系統）

- **G_perm**: 月次集計符号順列 p ≤ 0.0167（n=3000, seed=13）
- **G_jk**: 年次ジャックナイフ max p ≤ 0.10
- **G_oos**: 前半/後半 両方プラス
- **G_indep**: v7（円月曜・FX H1から再現）と **|ρ| ≤ 0.4** かつ E-Mon（株指月曜・同一H1から再現）と
  **|ρ| ≤ 0.5**（同じ株資産ゆえ E-Mon との独立性を明示的に要求。>0.8 は「E-Monの言い換え」で不採用）
- **G_plac**: ドリフト保存プラセボ（docs/80 §5 標準）に勝ち、プラセボ自体は非有意
  - G1/G2 = **同方向・同保有時間・ランダム開始時刻**の窓（「銘柄の素のドリフト」帰無）
  - G3 = **同窓・ランダム非FOMC日**（火/水から年間同数を抽出。Lucca–Moench 標準プラセボ）
- **G_cost**: 取引コスト×0.5〜×4 の全水準で純益プラス（金融コストは基準2.5bps/晩で評価）
- **事後診断（採用判定外・必須記録）**: 対B&H純益/maxDD、オーバーナイト vs 日中の条件付き平均bps、
  （G3）FOMC日 vs 非FOMC日。**B&Hに劣後する候補はp値に関わらず実質REJECT**（F2の教訓, docs/80 §2）。
- 判定: **ADOPT** = G_perm/G_jk/G_oos/G_indep/G_plac 全通過＋対B&H診断クリア ／
  **LEAD** = 純益>0 かつ頑健p≤0.10（スワップ依存なら条件付きLEAD）／ 他 **REJECT**

## 4. 採否規則（事前固定）

- **ADOPT**: `mql5/` で EA 化（セッション時刻・スワップ回避はEA内でサーバ時刻→現地時間変換）。
