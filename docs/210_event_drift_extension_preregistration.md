## 0. 位置づけと正直な事前分布

- 文献の事前分布は**否定的**: Lucca–Moench(2015)のドリフトは FOMC 固有で、CPI/NFP 等の前には無い。
  Brusa–Savor–Wilson(2020)は ECB/BoJ/BoE の前には(自国株にも)ドリフトが無いと報告。
  一方 Savor–Wilson(2013)は **発表当日**(CPI/NFP/FOMC)の株式リターンが非発表日より高い(発表日プレミアム)。
- したがって本検定は「見つかれば衛星、見つからなくても白地を閉じる」**反証型**。
  仮に LEAD が出ても規模は G3 級(年 8〜12 イベント × 10〜20bps ≒ **+1〜2%/年**)で、主力にはならない。
- G3 は H1 で 14:00ET→14:00ET の 24h 窓だった。ここは**日足の代理窓**(§2)なので、通過しても
  「H1 で再検証してから G3 と同じ EA 型へ」の 2 段階(docs/82 の手順)。日足だけで ADOPT はしない。

## 2. 窓の定義(日足の代理・固定)

イベント日 D(GMT 日付。D が非取引日なら除外)に対して
- **PRE** = D の**前取引日**のリターン(close(D−2)→close(D−1))。BoJ は決定の約 3 時間前で終わる=24h 前窓の最良代理。
  ECB は約 13h 前、CPI/NFP は約 13h 前、FOMC は約 19h 前で終わる(FOMC は当日 14:00ET までの分が EVT に混ざる)。
- **EVT** = D 当日のリターン(close(D−1)→close(D))。CPI/NFP/FOMC は発表と反応を含む=発表日プレミアムの窓。

## 4. 合格条件(LEAD の付与・全て満たす)

1. 一次 p < 0.0125
2. 年次ジャックナイフ(1 年抜き)で全ての p < 0.05
3. IS(〜2015)/OOS(2016〜)ともに平均が正
4. 往復コスト控除後(指数 2bps・FX 1bp)も平均が正

→ LEAD(日足代理)。次段は H1 で G3 と同じ 24h 窓を再検証してから EA。
一次 p < 0.05 だが Bonferroni 未達 → 「弱い兆候・据え置き」。それ以外 → REJECT(白地を閉じた記録)。
探索で両側 p < 0.0125 かつ条件 2〜4 を満たすものは「探索 LEAD 候補」として次回の一次に昇格(本 doc では採用しない)。
