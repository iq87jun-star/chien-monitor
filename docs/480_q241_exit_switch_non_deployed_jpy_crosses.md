## 4. 判定と扱い
- **成立 3 / 12(CADJPY の E1・G1・G3)**。束は不成立なので、登録どおり紙上フォワードには追加しない。
- 読み: 「荒れた週に安く始まった通貨が火曜の朝まで戻す」という値動きは、選んでいない円クロスでも同じ大きさで出る。採用 4 本に合わせて作った形ではない、という裏付けになる。
- 一方、規則として基準を満たすかは通貨ごとにばらつく。決済の切り替えは束で使う形で、通貨を 1 本ずつ選んで当てるものではない。
- この 3 本を月曜の買いに足す話にはならない(足す形は Q231 で不成立。決済を切り替えても束の最悪月が基準を超える)。配備・11/18 の切替は不変。
