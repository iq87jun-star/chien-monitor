## 2. 手順（MT5）

1. `Chien_Portfolio3_AllInOne_INSTANT.mq5`（または `_PROP.mq5`）を MetaEditor でコンパイル(F7)。
2. 「アルゴリズム取引」ON。**どれでもいいチャート1枚**に該当EBをドラッグ → 「Allow Algo Trading」✓ → OK。
3. それだけ。残高自動・倍率/比率/ルールは既定で入る。**1チャートに1つだけ**（複数や他EAと同口座でMagic衝突回避）。

### 業者で銘柄名が違う場合のみ編集
- `InpYenSymbols` / `InpV4Symbols` / `InpE5Symbols` を実銘柄名に（US500=SPX500, NAS100=USTEC, GER40=DE40,
  XAUUSD=GOLD 等）。指数/金は別名総当りも内蔵だが、確実を期すなら明示。
