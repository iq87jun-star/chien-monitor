## 6. エントリー通知（スマホPush / メール）＝タイミングのカレンダー同期

各戦略の**エントリー時・ガード作動時**に通知を送る機能を追加（v3.00）。起動時にもテスト通知が出る。

| 入力 | 既定 | 説明 |
|---|---|---|
| `InpNotifyPush` | true | MetaTraderスマホアプリへPush通知 |
| `InpNotifyEmail` | false | メール通知 |
| `InpNotifyEntries` | true | v7/v4/E5 のエントリー時に通知 |
| `InpNotifyGuards` | true | 全停止/日次停止の作動時に通知 |

### セットアップ
- **Push（推奨）**: スマホに「MetaTrader 5」アプリ→ 設定→ メッセージ→ **MetaQuotes ID** を確認 →
  PC版 MT5「ツール→オプション→通知」に同IDを入力＋有効化。これで `[INSTANT_2.0x/...] ENTRY v7 LONG ...`
  のようにエントリーが**即スマホに届く**。
- **メール**: 「ツール→オプション→Eメール」でSMTP設定→ `InpNotifyEmail=true`。

### カレンダー同期の実務
- **v7は定刻（毎週 月曜 JST 13/15/17/19時）** ＝ Googleカレンダー等に**繰り返し予定**を手動登録すれば事前同期可能。
  通知も同時刻に届くので二重で把握できる。
- **v4（日足確定時・JST早朝6-7時頃）/ E5（月初）は条件成立時のみ** ＝ 事前予定化は不可。**Push通知で都度把握**するのが最適。
- メール通知をGoogleカレンダーの「予定の自動作成」やIFTTT/Zapier等に連携すれば、約定を予定表へ自動転記も可能（任意）。

> 注: MT5の通知はEAが送信。EA自体は出金や予定表書込みはできない（取引専用）。通知の中継で予定表連携する。
