**設計どおりの非対称性を確認**: エッジが完全に消えても規則失格は0%(ガードが先に止める)。

→ **標準=1.25%を採用**(速度優先したい場合のみ2.0%を自己責任で)。

## 3. 実装(焼き込み済み)

- EA: `mql5/Chien_RecentFit5_EA.mq5` v1.0(5スリーブ焼き込み・Magic 941201..941205)
- プリセット: `mql5/presets/recentfit5_default.set`(リスク1.25%・P1ロック8.0/8.5)
- ガード: v1.44系を継承(balance基準日次−4%/tick・GlobalVariable永続・月3回で月末停止・
  フロア−8%恒久停止・災害SL=3×ATR(D1)・最短保有150秒・スプレッド10bps上限)
- 時刻: エントリーはUTC基準(`TimeGMT()`)。**MT5テスターではTimeGMTがサーバ時刻になる**ため、
  テスト時のみ `InpServerToUtcHours` にサーバのUTCオフセット(FN系: 夏3/冬2)を設定すること。
- 日足RSI(S4/S5)はブローカーD1(サーバ日界)で計算。研究のUTC日界と最大2〜3時間ずれる近似を含む。

## 4. 運用手順

1. **別口座で購入**(正攻法3口座 docs/172 とは混ぜない。FN既存口座とのコピー取引規則にも抵触させない)。
2. 任意のチャート(例 GBPUSD H1)に本EA+`recentfit5_default.set`を適用。[INIT]行で
   5スリーブの銘柄解決とガード値を確認。
3. P1通過(PASS_LOCK)後、P2では `InpLockArmPct=5.0 / InpLockClosePct=5.5` に変更し
   `InpBaselineReset=true` で基準残高を取り直す(1回だけ・その後falseに戻す)。
4. 資金化後: `InpMultOverride=0.5` に減率し報酬確定を優先。報酬2回で掛金回収が本トラックのゴール。

## 5. 撤退規律(docs/174 §5の再掲・厳守)

- 月次でスリーブ別合計Rを記録(フォワード採点 docs/103 の枠組みに追加)。
- **月次合計R<0が2ヶ月連続 → トラック停止**。データを更新して再スイープ(総入替を許容)。
- 本トラックの成績を根拠に正攻法口座の倍率を上げない(トラック間の資金・判断の混線禁止)。
