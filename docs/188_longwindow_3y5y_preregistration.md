# 188.【事前登録】3年特化・5年特化トラック(トラックG「LT3y」・トラックH「LT5y」)

> ユーザー指示(2026-08-05)「採用物の解釈で、3年特化と5年特化を作成出来ますか」。
> 採用済みトラック群(D=3ヶ月・C=6ヶ月・B案=12ヶ月)の**同一の解釈(選抜ルール・セル母集団・
> 構築式・コスト)を、選抜窓だけ3年/5年に伸ばして**適用する。新しい型・新しいフィルタは
> 一切追加しない — 既存ラダーの上方向への延長のみ。
> docs/174「耐久エッジの主張はしない」・docs/180の楽観/悲観併記・docs/182の凍結規律を継承。
> 本docのルールは`research/recentfit_long_screen.py`の実行**前**に凍結した。実行後の変更禁止。

## 1. 位置づけ — 特化窓ラダーの上方向延長

| トラック | 選抜窓 | 状態 |
|---|---|---|
| D | 3ヶ月 | 配備中(FTMO 50k, docs/181) |
| C | 6ヶ月 | 配備中(FTMO 50k, docs/181) |
| B案 | 12ヶ月 | 配備中(Fintokei, docs/178) |
| **G「LT3y」** | **36ヶ月** | 本doc |
| **H「LT5y」** | **60ヶ月** | 本doc |

- 窓が長いほど「直近レジーム全乗り」から「複数レジーム平均」へ性格が移る。
  docs/187(年次ラダー)との違い: ラダーは「単年最適解を並べて持つ」、本トラックは
  「長窓で一発選抜」。**どちらが優るかは実行前に主張しない**。
- 予想される論点(実行前に明記): 長窓選抜は直近12ヶ月では既にフェードした
  レジームのセルを拾い得る。これは3年/5年特化の定義そのものであり、事後に
  「直近が悪いから」と選抜をやり直すことは**禁止**(記録して判断のみ)。

「採用物の解釈」の純粋な窓延長であり、母集団をいじると比較が汚れる)。

## 3. 窓・フィルタ・倍率(既存トラックの比率でスケール・新規裁量なし)

スケール規則: 確認窓=選抜窓の1/2(B: 12m→6m, C: 6m→3m)。
最小活動日=15日/12ヶ月比例(B:15, C:8, D:5)。有効期限=選抜窓の1/4(B: 12m→3ヶ月)。

| 項目 | G「LT3y」 | H「LT5y」 |
|---|---|---|
| 選抜窓(SEL) | 2023-08-01..2026-07-29(36ヶ月) | 2021-08-01..2026-07-29(60ヶ月) |
| 確認窓(CONF) | 2025-02-01..(18ヶ月)累積>0 | 2024-02-01..(30ヶ月)累積>0 |
| フィルタ | SEL活動日≥45 / SEL累積>0 / CONF累積>0 | SEL活動日≥75 / SEL累積>0 / CONF累積>0 |
| スコア | mean/std×√n(SEL活動日ベース)降順 | 同左 |
| 制約 | Top-4・銘柄1セル・ファミリー2セル | 同左 |
| 加重 | 逆ボラ(SEL活動日)・上限40% | 同左 |
| 倍率 | **0.8×min(m\*[SEL], m\*[12m])・上限6.0**(C/D規則と同一。m\*: 最悪単日×m≥−4% ∧ 月中DD×m≥−8%) | 同左 |
| 有効期限 | **2027-04-30**(9ヶ月) | **2027-10-31**(15ヶ月) |

- 倍率にm\*[12m]を噛ませるのはC/D規則の継承(直近の荒れを無視して長窓平均で
  レバを盛らないための保守側ミニマム)。
- MC: 5日ブロックBS・シード7・1万パス・静的−10%・−4%クリップ。
  **FN Stellar(8/5)とFTMO(10/5)の両土俵**。サンプルは選抜窓/直近12ヶ月/全期間の3本併記。
  ⚠ 長窓では「選抜窓サンプル」の楽観バイアスは短窓より弱いが**ゼロではない**
  (選抜窓で選び選抜窓で測る構造は同じ)。全期間が正直な悲観バウンド。

## 4. 検証出力(選抜性能とは独立に必ず出す)

1. 選抜セルごとの**直近12ヶ月累積**を併記(長窓選抜が「死んだレジーム」を
   拾っていないかの可視化。拾っていても選抜は変えない — 記録して判断)。
2. 合成系列と配備中構成(v7/EMon/E5/B案/C/D)の日次相関。長窓選抜は現行採用セルと
   重複する可能性が高く、**重複したら「新しい分散」ではなく「既存ベットの倍積み」**である
   ことを結果カードで明示する。
3. B/C/Dとの同一物差し比較(倍率込み12mリターン・資金化率)を結果カードに併記。
