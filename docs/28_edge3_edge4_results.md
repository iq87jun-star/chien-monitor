## 候補ごとの所見

- **E3（最も「惜しい」が REJECT）**: グロスでは黒字（net_R=35, Sharpe1.13）、プラセボも対象だけ突出
  （リスクオフ +1.13 vs 低ボラ −1.39）、v7相関も低い（+0.04）。**しかし**:
  - G2 順列 p=0.096（>0.0125、0.05 でも不通過）= 統計的有意でない。
  - G3 ジャックナイフ最大 p=0.283 = **特定年（おそらく2020/2022の危機局面）依存**で頑健でない。
  - G5 コスト後に **net_R=−3.68 で赤転** = 金スプレッドを払うとエッジが消える。
  - → 「リスクオフで金が上がる」傾向は方向としては妥当だが、**数撃てる持続エッジではない**。LEAD にも満たない（G3不通過）。
- **E4（金利→円）**: perm_p=0.76、Sharpe 負。**先行性なし**。docs/15 の「USD先行は弱」を金利水準でも追認。
- **E5（中銀イベント）**: perm_p=0.115、Sharpe **−2.07（負）**。**FOMC/BOJ 翌日に決定日符号への
  定型ドリフトは無い**（むしろ弱い逆行だが仮説は明確に否定）。ニュースフィルタ（v7のイベント回避）の妥当性を裏から支持。
  ※イベント = **FOMC 87日（federalreserve.gov）+ BOJ 81日（boj.or.jp 議事要旨 minu_{year} の全会合・決定日=2日目、
  2020緊急会合含む）= 計164日**。両中銀とも一次ソースから網羅取得（捏造なし）。
- **E6（指数の平均回帰）**: perm_p=0.29、Sharpe 負。順張りプラセボの方がマシ（+0.15）。
  **指数オーバーナイトに回帰エッジなし**。docs/21（FX平均回帰全滅）を指数でも追認。

## E3 再評価（Dukascopy 実データ・事後ロバストネス確認）

「最も惜しい」E3 が**データ出典とコスト精度のせいで落ちたのでは**という疑いを潰すため、
出典を **Dukascopy 金スポット(XAUUSD)実 H1→日足**、金スプレッドを**実測値**、v7 相関を
**精密(実 H1)版**に替えて再走（`research/edge3_revalidate.py`）。※判定 docs/27 は変えない事後分析。

- 金スプレッド実測（Dukascopy bid/ask 2022-2023 中央値）= **0.347 USD = 1.84bp/片道**。
  事前登録のコスト 5bp は約 2.7 倍過大だった。
- v7 相関: 精密版 **+0.072**（日足プロキシ +0.039 と整合 → プロキシは妥当な近似だった）。

| ゲート | 事前登録(Yahoo・5bp・proxy) | 再評価(Dukascopy・実1.84bp・精密) |
|--------|------|------|
| G1 純益>0 | PASS | PASS（net_R=28.2） |
| **G2 有意性** perm_p | FAIL 0.096 | **FAIL 0.156（むしろ悪化）** |
| **G3 頑健性** jackknife | FAIL 0.283 | **FAIL 0.369** |
| G4 プラセボ | PASS | PASS |
| G5 コスト後 | **FAIL（−3.7）** | **PASS（+12.6）** |
| G6 v7相関 | PASS 0.039 | PASS 0.072 |

**結論（重要）**: コストを正しく実測すると G5 は通る。**しかし肝心の G2(有意性)・G3(頑健性)は
依然 FAIL で、綺麗なスポットデータでは有意性はむしろ悪化**。
→ E3 の REJECT は「コストや出典の都合」ではなく**本質的に統計的有意性が無い**ことが原因と確定。
危機年（2020/2022）依存の見かけ上のリターンで、数撃てる持続エッジではない。**REJECT は出典に頑健**。
