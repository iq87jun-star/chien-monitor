## 4. docs/279 §4 の解禁条件(10 月の水曜監視)

- `forward/q20_monitor.py 2026-09 2026-10` を 06:15 JST から実行。Dukascopy の 2026-10 の時間足は USDJPY(bid/ask)・EURJPY(bid)まで取得できたが、以後 `Connection reset` → 503 → 429 で止まっている(当方の proxy 経由の既知事象・docs/389 §3 の exec_gap と同じ)。取得できた分は `forward/q20_monitor_data/` に月単位で保存されるので再実行で続きから取れる。
