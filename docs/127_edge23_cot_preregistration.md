## 2. 仮説(主要3本・実行前固定。グリッドは感応のみ=昇格不可)

### H23a — 投機筋極値の逆張り(標準の文献仮説)
- シグナル: net_spec の **52週ローリングz値**(最低40観測)。
- **主要パラメタ(固定)**: z ≤ −2.0 → JPY LONG(USDJPY SHORT)を**20営業日**保有 / z ≥ +2.0 → 対称SHORT。
  ポジション保有中の新シグナルは無視(state machine・ピラミッディングなし)。
- 感応(記録のみ・昇格不可): 閾値{1.5, 2.5} × 保有{5, 10営業日}。
- 機序: 投機筋の混雑ポジションの巻き戻し(unwind)リスク。

### H23b — スペックフローの持続(モメンタム側)
- シグナル: net_spec の**4週変化**の符号。
- **主要パラメタ(固定)**: Δ4w > 0(投機筋がJPY買い越し中)→ JPY LONG(USDJPY SHORT)を翌週
  月曜終値→翌月曜終値の**1週間**保有。毎週リバランス。Δ4w < 0 → 対称。
- 感応: Δ{1週, 13週}。
- 機序: 大口フローは複数週かけて構築される(フロー持続)。

### H23c — v7円月曜のCOT条件付け(L3・機序深掘り)
- 条件: v7日足近似の月曜レッグ(edge13 `v7_proxy()`)を「**直近有効COTで net_spec < 0**
  (投機筋がJPYネットショート)の週」に限定 = ON群。残り = OFF群。
- 検定: ON群平均−OFF群平均の順列p(ラベルシャッフル3000回)。
- **プラセボ(F2教訓・必須)**: ON比率を保存したランダム月曜マスク400本 — 実ON選択のnetが
  プラセボ分布のp95を超えること。
- 機序: 円月曜(JPY売りフロー)は投機筋ショート構築期に強い、の直接検証。
