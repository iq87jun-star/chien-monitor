## 1. edge23 — COT建玉の3仮説(C1/C2/C3)

**機序の事前分布**: 生存5エッジは全て「低頻度フロー・カレンダー」族。COTはそのフローを
直接測る唯一の無料データ。文献: Sanders&Irwin(混在)・DeRoon+(先物リスクプレミアム)。
事前分布は**中**(高くない。文献が混在のため)。

| ID | 仮説(1文) | ルール(逐語・固定) |
|---|---|---|
| C1 | 投機筋の**極端な円ショートは巻き戻る** | JPYネット/OIの156週ローリング百分位が≤10% → 翌週月曜openからUSDJPY **SHORT** 5営業日保有(翌月曜open決済)。≥90% → LONG。それ以外ノーポジ。週次リバランス |
| C2 | 極値巻き戻しは**通貨横断で存在する** | C1と同ルールを6通貨(JPY/EUR/GBP/CHF/AUD/CAD, 対USD)に適用・等ウェイト平均 |
| C3 | **v7は投機筋が円ショートの週に強い**(キャリー勢の週末プレミアム=機序の直接検証) | v7(円3クロス月曜LONG)の週次PnLを「直前金曜公表のJPYネット/OI<0(ショート)」週と「≥0」週に分割。採用形=ネットショート週のみ取引するフィルタ版v7 |

**取引コスト**: 往復2pip相当(USDJPY 1.4bps, EURUSD 1.8bps級=docs/14と同一系)、感応×2。
C1/C2は週次(年約52判定・ポジション率は百分位閾値により約20%)。

### 1-1. 決定規則(α: C1-C3の3検定 → **α=0.0033**(0.01/3) Bonferroni)

| ゲート | 基準 |
|---|---|
| G1 経済性 | 2016-01〜2026-06 net>0 |
| G2 頑健p | 順列検定(4000回・シグナル週シャッフル) p<α |
| G3 年次JK | 全year-out net>0 が9/10以上 |

## 2. R1 — E5の別ソース再現(docs/86 §4 の残存昇格手段の消化)

- E5逐語ロジック(1/3/6/12ヶ月リターン符号合議・月末判定→翌月適用, colab_e5_reality_10y.py準拠)を
  **Dukascopy BID日足**(XAUUSD / USA500IDXUSD / USATECHIDXUSD / DEUIDXEUR)の月末終値で再実行。
- 窓 = 4資産の共通利用可能期間(2013-01頃〜2026-06を想定・実測で確定)。
- **PASS基準(固定)**: ①Dukascopy窓で net>0 ②同一窓のYahoo実行との月次戦略リターン相関 ρ≥0.6。
  PASS → E5の検証級に「別ソース再現✔」を付記(残るはデモのみ)。FAIL → E5の級を1段階降格し
  配分見直しを docs/128 で提起。
- 注: Dukascopy NAS100=USATECH(NASDAQ100)はYahoo ^IXIC(総合)と指数が異なる。これは
  「同一ソースのコピー」でなく**独立ソース再現**の趣旨に合致(機構レベルの再現を測る)。

## 3. R2 — G3 FOMCドリフトの2011-2015延長(docs/86 §3 の宿題)

- 対象: 定例FOMC 40回(2011-2015・Fed公式カレンダーで確認済み・臨時会合は除外)。
- ルール(edge12逐語+声明時刻適合): 前営業日ET **H時台**バー終値→当日**H時台**バー終値 LONG。
  **H=13**(声明14:00/14:15 ETの会合=2013年以降全部+2011/2012の非会見会合)、
  **H=11**(声明12:30 ETの会合=2011: 4/27, 6/22, 11/2、2012: 1/25, 4/25, 6/20, 9/13, 12/12)。
- コスト: edge12と同一(US500往復1.0bps+金融2.5bps/晩×晩数)。
- **判定(固定)**: PASS = ①net>0 ②順列p(4000回)<0.10(片側・n=40の検出力を正直に反映)
  ③プラセボ(非FOMC火水・年同数・500回)の中央値を上回る。
  PASS → G3の耐久級を「現行レジーム」→「**2011年以降の構造**」へ更新(docs/86 §4表の改訂)。
  FAIL → G3はADOPTのまま・耐久級を「現行レジーム」と確定(docs/86 §3の保留を解消)。
