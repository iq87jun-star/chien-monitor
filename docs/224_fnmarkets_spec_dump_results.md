## 3. スワップ実額 — docs/182 の「年約 6%」は指数には大幅に甘かった

**帰結:**

- **Hold(指数の連続 LONG)を FNmarkets 実弾で記録する案は数値で確定的に否定**。docs/182 は「年 6% 減衰でエッジが消える」と書いたが、実際は SPX500 −20% / UK100 −31% / GER40 −10% で、**Hold の年率(docs/182: WTI 15%・指数 5〜9%)を全て上回る**。docs/223 §5.6 の除外判断を数値で裏付けた。
- 例外は **WTI LONG(+1.7%/年・受取)**と **NDX100(−4.7%)**。Hold WTI だけは FN 実弾でも成立しうるが、1 レグのために Hold 族を残す価値は無い(既存プロップ口座 #14166201 で記録中)。
- 指数の 3 倍日が**金曜**なので、v4 指数レグ(最長 8 日保有)は週末を跨ぐと 3 日分が乗る。季節RG3 の v4 指数系は FN 実弾の対象外(docs/223 §5.6)のため影響なし。プロップ口座はスワップフリー。
- 円クロス LONG は受取(+1.9%/年)。Mon レッグ(月→火・1 ロール)では **手数料をほぼ相殺**する(§5)。

指数のスワップ値が名目比で銘柄ごとに 4〜42% とばらつくのは、FN 側の per-lot 設定が名目と整合していないため(FRA40 が 1 lot €8,169 に対し −€9.27/日)。**MT5 が課金する値そのもの**なので、モデルにはこの値を使う。初回の月曜ロールオーバーで 0.1 lot の実課金額と照合する(§7)。

RAW 手数料 往復 USD 7/lot を pip 換算し、1 日分スワップ(LONG・§3 実測)を加減。Mon レッグ直近 12 ヶ月(2025-08〜2026-07)平均・Yahoo 日足・docs/216 と同式。

- 手数料 USD 7 は円クロスで **1.08 pip**、GBPUSD で 0.70 pip。docs/223 §1 の「0.7bps」は 10 万ドル名目基準の値で、円クロスの pip 換算では約 1 pip と見るのが正しい。
- **円クロス LONG の 1 日スワップ受取が手数料をほぼ打ち消す**(GBPJPY +1.06 vs −1.08)。実効コストは Dukascopy p90 とほぼ同じ。
- GBPJPY の「往復 4pip」提案(docs/216 §4.3)は、手数料込み 4.81pip・スワップ込み 3.76pip → **4pip 定数のまま妥当**。9 月末再スクリーニングでそのまま使う。
- 順位: AUDJPY > GBPUSD > GBPJPY > EURJPY > USDJPY。全列で不変。
