## 3. 読み取れたこと

### 3.1 `VOLTGT`は明確に有害(0/16)

**実現ボラが低いときに倍率を上げる**という動作が、そのまま「静かな期間の直後に来る
ボラ急騰で大きく張っている」状態を作る。平均Δ失格が **+1.19pt** で唯一プラス、
16セル全てで不合格。ボラターゲティング一般が悪いのではなく、
**プロップの「絶対損失制約」の下では、低ボラ時の増し玉はテールに対して無防備**という
構造的な理由と読める。docs/190 §1で挙げた動機のうち「静かな窓で選んで荒れた窓で走る事故の
緩和」は、少なくともこの実装では**達成できない**。

### 3.2 `BUFFER`は「速く・安全に・当たりにくく」する

全構成で**所要日数が一貫して短縮**した(C 34→31 / D 84→67 / B 49→44 / 非FX 63→51)。
失格率も多くのセルで低下する。しかし資金化率が下がる。機序は明快で、
負けている局面で縮めるため**一度沈んだパスが復帰して資金化に至る確率が下がる**一方、
勝っている局面で伸ばすため**当たるパスは速く当たる**。

**これは改善ではなく交換である。** docs/190 §4で「1軸だけ良くなる案は採らない」と
事前に宣言した通り、交換は採用理由にならない。

### 3.3 効果が最も大きいのは最も脆い構成(D案)

D案の直近12ヶ月バウンドで失格が **16.0% → 6.7%**(−9.3pt)と最大の改善を示した。
「バッファが薄い構成ほどバッファ依存サイジングが効く」という直感通りの結果である。

⚠ **しかしこれを根拠に「D案だけに適用する」ことはしない。** docs/190 §5は
「一部でしか改善しない → 不採用。構成依存の改良は選抜ノイズと同種の後知恵になる」と
**実行前に宣言済み**であり、結果を見てから適用範囲を狭めるのは、まさにその後知恵である。

## 4. 事前登録した判定基準の欠陥(自己申告)

docs/190 §5の基準「**失格率が下がり**、かつ資金化率が下がらない」は、
**FIXEDが既に失格0.0%のセルでは定義上達成不可能**である。実際、B案の直近12ヶ月2セルは
FIXED が f100.0/x0.0 であり、Δ失格=0.0・Δ資金化=0.0 で機械的に不合格になった。
基準の設計ミスであり、記録しておく。

**ただし結論は変わらない。** この2セルを除外しても、`BUFFER`は
D案 全期間(Δ資金化 **−4.0pt**)・非FX 全期間(**−4.3pt**)で実質的に不合格であり、
「失格を減らす代わりに資金化を減らす」という §3.2 の性質がそのまま残る。

## 5. 死んでいない仮説(将来の事前登録の候補・本docでは採用しない)

§3.2の「速くなるが当たりにくくなる」は、**時間制限が拘束条件になっている口座では
評価が反転し得る**。具体的には:

- **Fintokei速攻プロ #6078225**: 評価期間 **最大60日・時間切れ=失格扱い**(docs/183 §1)。
  この口座では「所要日数の短縮」がそのまま失格回避に直結するため、
  本docの評価軸(時間制限なしのMC)では捉えられていない価値がある可能性がある。
- 同様に期限付きトラック(C案9/30・D案毎月・非FX 10/31)も、期限が近い局面では
  時間が拘束条件になる。

**この仮説を検証するには、時間制限を明示的に入れたMCで別途事前登録する必要がある。**
本docの結果を流用して速攻プロに適用することはしない(評価軸が違うため)。
