# 149.【事前登録】edge24 — v7執行の指値化(リミット注文エントリー)による実測コスト削減

> 位置づけ: docs/128以降「唯一残った統計リスクなしのEV改善=執行コスト」(2026-07-11セッションの
> 棚卸し)。edge20(執行実測)の後続。**市場を読む系ではなく執行系**=棄却済み領域に非該当。
> 本docコミット後、ユーザーの再エクスポート(v1.30・M1高安付き)を受けて

## 1. 仮説と機序

現行v7は月曜04/06/08/10UTCの時刻で**成行買い**(ask支払い=スプレッド全額負担)。
指値(BUY LIMIT)をミッド等に置き数分待てば、**片道0.3〜0.65pip級の執行改善**が期待できる。
対抗仮説(これを測る): 月曜朝は上方ドリフト(=エッジ本体)があるため、
①指値は「下がった時だけ」約定する逆選択 ②未約定時の成行フォールバックは高値掴み、
の2つが節約を食い潰す可能性。**フォールバック付き設計なら常にポジションは取れる**ため、
差は純粋に「取得価格の差」として測定できる。

## 2. データ(ユーザー再エクスポート・v1.30)

- `Chien_TickExport_Edge20 v1.30`(M1 **high/low付き**)で EURJPY/GBPJPY/USDJPY を再取得
  (`ChienRatesM1v2_*.csv`・FNサーバー・月火×サーバー4-16時・遡れる限界まで≈2.5-3年)。
- USDJPYは参考(間引き済み)。判定はEURJPY/GBPJPY。
- サーバー時刻→UTC変換はedge20実証済みのEETルールを逐語再利用。

## 3. 設計(固定)

- 対象ショット: 月曜 04/06/08/10 UTC の各時刻の最初のM1バー。
- ベースライン: そのバーのopenで成行買い(取得価格 = open_bid + spread_open)。
- 指値変種(グリッド固定・主要は**L_mid_15**):
  | 変種 | 指値 | 待ち時間W |
  |---|---|---|
  | **L_mid_15(主要)** | ミッド = open_bid + spread/2 | 15分 |
  | L_mid_5 | 同上 | 5分 |
  | L_bid_15 | open_bid(タッチ) | 15分 |
  | L_bid_5 | 同上 | 5分 |
- 約定判定(BUY LIMITはask≤指値で約定): W分以内のいずれかのM1で
  `low_bid + spread_open(そのバー) ≤ 指値` なら約定(価格=指値)。
  未約定ならW分後のバーopenで成行(= open_bid+spread)。
- 指標: **節約pips/ショット = ベースライン取得価格 − 実現取得価格**(正=改善)。
  約定率・年別・前半/後半(B1/B2)も記録。

## 4. 決定規則(機械適用・固定)

- **採用**: 主要変種L_mid_15が EURJPY・GBPJPY の両方で
  ①平均節約 ≥ **+0.3pip/ショット** ②B1/B2両半期で正 ③どの暦年も負にならない
  → EA実装へ(`Chien_PortfolioD_Prop3` v1.32: v7エントリーを「指値W分→成行」に変更・
  input切替可・既定は現行成行のまま)。実装後デモ必須。
- 上記未達だが全変種で正 → LEAD(記録のみ・年次再測)。それ以外 → REJECT(現行成行維持)。
- グリッドの事後選択なし(主要変種のみが採用判定対象)。

## 5. 期待値の桁(事前・盛らない)

実測スプレッド(edge20): EURJPY中央1.13pip。ミッド指値の理論上限節約 ≈ 0.5〜0.65pip/ショット。
v7は8ショット/週(2ペア×4時刻)≈ 年400ショット。仮に+0.4pip/ショットなら
素サイズで**年+0.10%前後、配備倍率2.9xで年+0.3%級**。地味だが統計的死のリスクゼロの改善。
逆選択が強ければゼロ〜negative — それを測るのが本検定。

## 6. 追記(2026-07-12・実行前修正): データ深度の現実への適合

初回エクスポート(2026-07-12・ユーザーログ)で判明した事実:
①旧v1.20が実行された(v1.30の再コンパイル漏れ・出力に高安なし) ②**FNサーバーのM1保持は約3ヶ月**
(2026-04-06〜07-07・21,624行)= §2の想定「2.5-3年」はM1方式では物理的に不可能。
対策と規則修正(いずれも実行前に固定):
- エクスポートを**v1.40(ティック履歴→M1再構築)**に変更。edge20実績でEURJPYはティックが2.5年
  遡れたため、こちらが正規ルート。週単位遡行・8週連続空で終端判定。
- **判定規則の適合**: 取得深度が**1年未満のペアは参考扱い**(採用判定から除外)。
  主判定はEURJPY(深度2.5年見込み)。GBPJPYは取得できた深度で併記し、1年以上あれば判定に含める
  (§4の「両ペア」要件はこの規則で読み替える)。深度3ヶ月しか取れない場合のB1/B2は前半/後半、
  「暦年」条件は「取得期間内の各四半期非負」に読み替え。
