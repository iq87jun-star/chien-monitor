# docs/190: 新レーンL4の登録 — 検証済み勝ちフロー観察による仮説生成(優れたEAの一歩目)

日付: 2026-07-29
前提: docs/126(価格系列宇宙の消尽)、docs/128(無償データ宇宙の消尽)、docs/113(仮説レーンL1-L3)、
      docs/183/184(Darwinex 検証済み勝ち組の存在確認)、docs/189(優位の源泉②)
問い: 優位の源泉から「優れたEA」の一歩目を始められるか。

---

## 1. 位置づけ — なぜこれが正当な「一歩目」か

- docs/126 の結論により、**発明による新仮説**(価格系列からのひねり出し)は閉鎖済み。
  再開には新データ・新メカニズムが必要(docs/80 §4)。
- docs/183 で確認した通り、Darwinex には**リスク標準化・検証済みの「現に勝っている」戦略群**が
  公開されている。これは「思いついた仮説」ではなく「**市場で現に機能していることが観測された型**」
  という、L1-L3 のどれとも異なる証拠チャネル = 新レーン **L4** として登録する。
- L4 は docs/176(運営のデータ優位)の無料代替でもある: 運営にならずに勝ちフローを観察する。

## 2. L4 観察プロトコル(事前定義 — 恣意的なつまみ食いを防ぐ)

### 2-1. 観察対象と頻度
- 対象: docs/184 の定量ゲート通過者(現在: **ELW, PKR**)+ 四半期ごとの DarwinIA GOLD 上位で
  **実績36ヶ月以上**のもの(短期実績はdocs/184の通り運と区別できないため観察対象外)。
- 頻度: 四半期1回。各DARWINページの公開行動統計を記録:
  保有時間分布 / 勝率 / 取引頻度 / 主要銘柄 / 時間帯規則性 / DD形状。

### 2-2. 型の照合(docs/126 マップとの突き合わせ)
観察された型を docs/126 §1-1 の検定済みファミリーに分類し:
- **既REJECTファミリー** → 記録のみ。再開しない(観察1件は再開条件を満たさない)。
- **既ADOPTファミリー** → 現行エッジの傍証として記録(自信の更新のみ、変更なし)。
- **どのファミリーにも該当しない型** → edge24+ 候補。docs/113 の型で事前登録へ。

### 2-3. 事前登録のトリガー(これを満たすまで登録しない)
1. 同一の未検定型が**独立した2口座以上**(相関で同一戦略でないことを確認)で観察される
2. 型を自前ロジックとして仕様化できる(エントリ/エグジット/対象を文章で一意に書ける)
3. 検定に必要なデータが手元にある(Drive 10年 H1/D の範囲)
→ 3条件成立で edge24 として事前登録(ゲートは docs/187 型を踏襲)。

### 2-4. 多重検定の会計
- 観察由来であることは**事前確率のボーナスにしない**(生存者バイアス込みの観察のため)。
  ゲートは発明由来仮説と同一水準。試行数は「登録した仮説数」でカウント(観察数ではない)。

## 3. 初回観察スナップショット(2026-07-29)

| 観察 | 型分類 | 処置 |
|---|---|---|
| OXTI: 平均保有5h・勝率41.4%・556取引/2.5年 | H4/日中ブレイクアウト・モメンタム族 = **v4系(ADOPT済)** | 現行v4の傍証として記録。新登録なし。※OXTI自体はdocs/184でFAIL(実績不足)だが型情報としては利用可 |
| ELW(SR1.14/4年)・PKR(SR0.74/7年) | **行動統計未取得**(取引レベルデータはページ非公開) | 次回観察で取得を試行(無料口座で閲覧可能な範囲を確認)。取れなければ観察対象を公開統計のあるDARWINに限定 |

**∴ 現時点で登録可能な新仮説はまだ無い。** 一歩目=本プロトコルの登録(完了)。
二歩目=四半期観察の実行(次回: 2026-10)。仮説はトリガー条件成立時のみ登録する。
「観察が空振りでも損失ゼロ(無料)、当たれば運営データの無料代替」という非対称性がL4の価値。

## 4. 併記 — 源泉①(ルール・制度)からの「一歩目」は既に走っている

新EAだけが「優れたEA」への道ではない。docs/189 源泉①(ルール優位)による
**現行EAの規則適合の継続最適化**(ファーム選定・倍率・ガード帯)は、
docs/97/110/111/173 で現に進行中であり、期待値改善/労力比では L4 より確実。
L4 は「エッジ側の上限を上げる」長期投資として並走させる。
