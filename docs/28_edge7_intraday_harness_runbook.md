## 0. これは何か

### ★最重要の学び（短期サンプルの楽観バイアスが再実証された）
ローカル2.76年で**微益**だった I1(+4.8%)・I4(+1.4%)・I6(+1.8%) は、**10年では全て明確な負**
（I1 −20.6% / I4 −21.4% / I6 −21.8%）に反転した。**2.76年の微益は"上限側の錯覚"**であり、
docs/18でv7の最大DDを2.8年で過小評価したのと同じ罠。**足内ブレイクアウト/フェード/初動継続/
オーバーナイトは、メジャー通貨・10年・コスト後では一貫して負**＝この土俵に4本目は無い。

## 4. 結論と次アクション（確定）
- **4本目は無い。v7が引き続き唯一の検証済みエッジで確定。** 足内(セッション系)の探索は10年で終了。
- これで主要な土俵は出尽くした: FXカレンダー/順方向/平均回帰/モメンタム(docs14,17,20,21,22)、
  多資産トレンド(23)、未踏構造(27=E5のみLEAD)、足内(本doc=全滅)。**新規ネタの量産はここで止める。**
- リソース集中先（新規探索より価値が高い）:
  1. **v7の運用最適化**（現行プロップ2.5倍/インスタント1.5倍。docs/24,25・EA v8_dualfirm）。
  2. **E5(リスクパリティ多資産トレンド/docs27)のデモ追検**＝唯一筋の良いLEAD。−10%枠に収まる
     縮小サイズのDD/合格率を足内実測 → 良ければv7と低相関(+0.07)の衛星に少量から。
- 規律: 短期の微益は信用しない（本件で再確認）。コストに脆い足内系は採らない。誇張・捏造をしない。
