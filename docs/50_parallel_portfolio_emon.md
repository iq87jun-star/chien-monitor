# 50. 並行ポートフォリオ — 新エッジ一括探索 と 核「E-Mon(株価指数 月曜)」の v7基準9ゲート採点

> ユーザー要望: 「既存(v7主軸)とは別に、**同じレベルの検証を通った並行ポートフォリオ**を作りたい。
> 方針は**新しい無相関エッジを探索**・対象は**両業者(プロップ/インスタント/別業者)**」。
> ツール: `research/parallel_edge_hunt_10y.py`(探索N=130) / `research/parallel_emon_validate.py`(9ゲート) /
> `research/colab_parallel_emon.py` + `notebooks/parallel_emon.ipynb`(Drive確定)。
> 数値出所: `research/results/parallel_edge_hunt_10y.json` / `parallel_emon_validate.json`(Yahoo日足10年・一次)。
> ⚠ 規律(docs/14,15,18の系譜): **数字は盛らない。出なければ「出ない」。最終確証はDukascopy+デモ前進検証。**

## 0. 一行結論

> **新エッジ探索(N=130, Bonferroni)で唯一生き残った無相関の新エッジ＝『株価指数の月曜効果 E-Mon』。**
> E-Mon は v7 と全く同じ性格(STRONG-LEAD・7/9)で、しかも **v7(円月曜)と月次相関 +0.22(低)**。
> ∴ 既存の v7主軸ポートと**同時にDDしない第2の器**＝並行ポートフォリオが**誠実に**組める。
> 並行ポート = **E-Mon(核) + E5(衛星, 既存STRONG-LEAD, E-Monと相関 −0.06)**。

## 1. なぜ「新エッジ探索」なのか — docs/14 の宿題

docs/14 は **FXのみ**で 曜日/ターン・オブ・マンス(TOM)を全数検定し「円の月曜(v7)以外に無相関エッジ無し」と
正直に結論した。だが docs/14 自身が次の宿題を残していた:
- 選択肢2「**データ宇宙を拡張**(金/株価指数/暗号/H1)してエッジを探す」
- 選択肢3「**非カレンダー系**(相対価値/キャリー等)を厳格ハーネスで検定」

本書はその宿題を実行する。これまで**未トライの土俵**を一括事前登録(N=130)で検定:

| 系統 | 候補 | 動機(なぜ未トライか) |
|---|---|---|
| F1 株価指数TOM | US500/NAS100/GER40/UK100/JP225 + 金 × L/S | TOMは本来**株式**のアノマリー(月末リバランス/401k流入)。docs/14はFXのみ |
| F2 株価指数 曜日 | 5指数 × 5曜日 × L/S | 週末効果/月曜効果は**株式**の古典。指数で未検定 |
| F3 暗号 曜日 | BTC/ETH × 7曜日 × L/S | 暗号は**7日取引**=週末固有フロー。FXと別クラス=分散先候補 |
| F4 コモディティ 曜日 | 金/銀/WTI × 5曜日 × L/S | 金属・原油の曜日 |
| F5 相対価値ペア | US500-NAS100 / 金-銀 / EURUSD-GBPUSD / AUDUSD-NZDUSD / BTC-ETH × 平均回帰/モメンタム | 方向予測でもカレンダーでもない**第3の系統**(docs/14選択肢3) |

合計 **N=130** → Bonferroni α = 0.05/130 = **0.000385**(v7のN=54 α=0.00093 と同等以上に厳しい)。
ハーネスは v1-v6 を葬ったものと同一: 順列(符号シャッフル8000) / IS-OOS(70:30) / 全年ジャックナイフ /
Bonferroni / コスト感応(1×/2×/3×) / **★v7(円月曜)月次相関**(並行の肝)。

## 3. E-Mon の確定 — v7基準9ゲート採点(docs/40と同一ゲート)

**E-Mon = NAS100/US500/GER40 の月曜 open→翌open LONG を等加重**(円3クロスのv7と対称な"指数3つ"バスケット)。

| # | ゲート | 合格条件 | **E-Mon 実測** | 判定 |
|---|---|---|---|:--:|
| G1 | 10年実データ | span≥~9y | 2016–2026, n=516週 | ✅ |
| G2 | ノールック+実コスト | 構造的 | open→翌open・bps控除 | ✅ |
| G3 | perm_p<Bonferroni | <0.000385(N=130) | **0.0021** | ❌ |
| G4 | プラセボ識別 | 月曜のみ有意 | 月0.0021 / **火-金 0.19-0.83(全て非有意)** | ✅ |
| G5 | 年次ジャックナイフ | max_p≤0.10 | **0.125**(2020除外時のみ・他年≤0.004) | ❌ |
| G6 | IS/OOS 両方+ | 減衰なし | **IS+51.9% / OOS+23.2%**(両方+) | ✅ |
| G7 | ウォークフォワード | ≥4/5期+ | **5/5 が +** | ✅ |
| G8 | コスト頑健 | 2×でもnet>0 | **+60.2%** | ✅ |
| G9 | −10%枠適合 | p95 maxDD≥−10% | 素 p95 **−8.4%** / 1.15倍で−10% | ✅ |
| | **通過 / 判定** | | **7/9 / STRONG-LEAD** | |

**判定 = STRONG-LEAD(7/9)。docs/40 の v7(7/9)・v9(7/9)・E5(6/9) と同一級。**
- 落ちるのは **G3(Bonferroni)** ＝ **v7自身も落ちる壁**(統一・保守基準では誰も越えない)と、
  **G5(年次JK 0.125)** ＝ 2020(COVID)年を抜くと有意性が僅かに落ちる(他10年は全て p≤0.004 で頑健)。
  E5(JK 0.17)より良く、v7(JK 0.029)より僅かに弱い＝**E5と同質の僅差**。
- **クリーンな点**: G4プラセボが教科書的(月曜だけ有意・火〜金は完全に非有意)、G6でOOSも+、G7が5/5、
  G8でコスト2×でも頑健、G9で−10%枠に素で収まる。**質はv7と遜色ない。**

## 4. なぜ E-Mon は v7 と無相関なのか — 並行の肝

| 月次相関(10年) | 値 | 意味 |
|---|--:|---|
| **E-Mon ⇄ v7(円月曜)** | **+0.221** | 低い。同じ「月曜」でも機序が別(株式の週末リスクプレミアム vs JPYの週明けフロー)。**並行の核心** |
| E-Mon ⇄ E5(多資産TSMOM) | **−0.062** | 無相関〜微負。並行ポート内の衛星に最適 |
| v7 ⇄ E5 | +0.029 | (既存ポートの分散源・参考) |

- v7 は**為替**(円クロス)、E-Mon は**株式指数**。資産クラスが別＝マクロ駆動因が別。
  「月曜」という時間ラベルは共有するが、10年の月次リターンは **+0.22 しか連動しない**。
- ∴ **既存の v7主軸口座と、E-Mon主軸の並行口座は"同時に大負けしにくい"**。これが
  「別口座/別業者で並走させる」価値＝1つの業者が飛んでも、相関の低い2系統で**全体の生存性**が上がる。

## 5. 並行ポートフォリオの構築 — E-Mon(核) + E5(衛星)

既存ポートが v7(核)+v4+E5 なら、並行ポートは **E-Mon(核)+E5(衛星)** で組む(E-Mon が v7 の役を担う)。
E-Mon⇄E5 = −0.06 ゆえ、E5 を混ぜるほど同DDで Sharpe が上がる(既存 v7:E5=65:35 と対称・docs/32)。

等ボラ標準化での相対ブレンド(`parallel_emon_validate.py`):

| 比率 E-Mon:E5 | 相対maxDD | 相対Sharpe |
|---|--:|--:|
| 100:0 | −6.53 | 0.86 |
| **70:30(推奨開始)** | **−5.24** | **0.96** |
| 60:40 | −5.05 | 0.95 |
| 50:50 | −4.85 | 0.89 |

- **推奨 = E-Mon:E5 ≈ 70:30 〜 65:35**。Sharpe最良域かつ左尾が薄い。既存ポートの v7:E5=65:35 と対称。
- E5 は STRONG-LEAD(未確証)ゆえ、まず **70:30** で開始 → E5デモ合格(docs/29)後に **65:35** へ寄せる。
- 実装サイズは docs/51。核 E-Mon の素バスケット10年maxDD≈−15%(=v7と同じ"リスク予算化必須"の教訓, docs/18)
  ゆえ、**週次リスク予算で建てて合算DDを−10%枠の内側に収める**。

## 6. 残る正直な限界(盛らない)

- **E-Mon は STRONG-LEAD であって ADOPT ではない**。G3(Bonferroni)未達は v7 と同じ＝
  バックテスト単体で確証(ADOPT)に上げる手段は無い。**確証はデモ前進検証(docs/29)で埋める**——v7と同じ規律。
- **Yahoo日足は配当除く指数・OHLC概算・コストはbps控除の単純化**。指数CFDの実スプレッド/スワップ/配当/
  取引時間(月曜の建て時刻)は業者差が大きい → **Driveで多資産日足(またはDukascopy相当)再測＋デモで実測**。
- **3指数は相互に正相関**(同じ月曜効果)＝独立ではない。v7の円3クロスと同じ「1現象の多ショット」。
  分散は相関<1で実効だが、E-Mon単体は1エッジ集中＝E5衛星との併用が前提。
- G5(JK 0.125)が示すとおり、E-Mon の有意性は **2020(COVID)に幾分依存**。2020を含む全期間では頑健だが、
  「単一の極端年への依存」を完全には排除できていない＝デモで前向きに再現するか要確認。
