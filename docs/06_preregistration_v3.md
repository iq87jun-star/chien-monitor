> **目的**: p-hacking を避けるため、「データのOOS結果を見る前」に仮説・ルール・採用基準・試行数を固定する。
> 本文書をコミットした後にのみバックテストを実行する。事後の条件変更は禁止（変更する場合は新仮説として試行数に加算）。
>
> 背景: v1(トレンド押し目)・v2(RSI日足逆張り)は、ユーザーの厳密検証(Lv1-5)で共に棄却。
> 真因は (a) 単一指標・日足で取引数過少(10年で9-18件)＝検定不可能、(b) 値動き方向の予測のみに依存。
> → v3 は「日中セッション構造(マイクロストラクチャー)」に賭け、H1で高頻度化して検出力を確保する。

## 1. 仮説（confirmatory, 事前登録）

**H1（主仮説）: London Open Range Breakout (ORB)**
- 経済的根拠: ロンドン寄り付き(07:00 UTC前後)は欧州機関の参入で流動性・ボラが構造的に急増する実需イベント。
  寄り付き直後のレンジを抜けた方向に初動が伸びやすい。暦アノマリー(曜日・ゴトー日)とは別系統の構造要因。
- これは「アプローチの根本転換」(日足方向予測 → 日中イベント・ドリブン)である。

**H2（副仮説）: Asian Range Fade（平均回帰）**
- 経済的根拠: アジア時間(00:00-06:00 UTC)は低流動でレンジ化しやすく、行き過ぎは戻りやすい。
- H1 が棄却された場合の対照として同時に登録（試行数に計上）。

## 2. 厳密ルール（全パラメータを固定。データを見て調整しない）

### H1: London ORB
- データ: H1（時刻はUTC）。
- オープニングレンジ(OR): **07:00 UTC の1時間足**の高値/安値。
- ブレイク判定窓: **08:00–16:00 UTC**（ロンドン〜NY前場）。
- エントリー: 上記窓内で、ある確定H1足が OR高値を上抜けクローズ → **次のH1足始値でロング**／
  OR安値を下抜けクローズ → 次足始値でショート（**ノールックアヘッド**）。**1日1回・最初のブレイクのみ**。
- SL: OR の反対端（ロングなら OR安値、ショートなら OR高値）。リスク = OR幅。
- TP: **リスク × 1.5**（RR=1.5固定）。
- 時間切れ: **21:00 UTC（NYクローズ）**の足始値で成行手仕舞い（SL/TP未達時）。
- フィルタ: OR幅が極端な日を除外。**0.15×ATR(24) ≤ OR幅 ≤ 3.0×ATR(24)**（固定）。
- コスト: スプレッド/2 + 0.5pip スリッページ（既存テーブル）。

### H2: Asian Range Fade
- アジアレンジ: **00:00–06:00 UTC** の高値/安値。
- エントリー窓: **06:00–12:00 UTC**。レンジ上限を上抜け→**ショート(フェード)**／下限割れ→ロング。1日1回。
- SL: ブレイク方向へ OR幅×1.0。TP: レンジ中央（mid）またはリスク×1.0、近い方。
- 時間切れ: 16:00 UTC 手仕舞い。コスト同上。

## 3. 対象ペア（固定）
EURUSD, GBPUSD, USDJPY, EURJPY, GBPJPY（ロンドン活発な主要5通貨）。
※ プロトタイプでは当方サンドボックスの H1（約2年, Yahoo）を使用。**本番OOSはユーザーのDukascopy H1(2016-)で実施**。

## 4. 採用基準（事前登録。すべて満たして初めて「合格候補」）

ユーザーの Dukascopy 10年ハーネスで、以下を**すべて**満たすこと:
1. **プールOOS**: PF > 1 かつ bootstrap P(PF≤1) < α（Bonferroni補正後）。
2. **ペア一貫性**: 5ペア中 **≥4ペア**で OOS の PF > 1（プーリング人工物でないこと）。
3. **レジーム頑健性**: 期間前半・後半の**両方**で PF > 1（v2 が落ちた条件。時期依存でない）。
4. **検出力**: プールOOS の総取引数 **n ≥ 200**（薄すぎないこと）。
5. **実用性**: シミュ上、最大DDが FundedNext 規則内、かつ稼働日 ≥ 5。

## 5. 試行数の宣言（Bonferroni）
- 本事前登録での確証的試行 = **2**（H1 ORB, H2 Asian Fade）。
- ユーザーの累積カウンタ(現在21)に +2 して補正αを算出すること。
- プロトタイプ段階で複数パラメータを“探索”しない。**上記固定値で1回のみ**評価する。

## 6. 正直な事前の見込み
- ORB はリテールで有名 → 既に裁定で削られている可能性は十分ある。
- 本事前登録の価値は「**構造的根拠があり、かつ十分な取引数で白黒つけられる**」点であり、**合格は保証しない**。
- 棄却されれば「効率的市場で単純な技術的エッジは乏しい」という結論をさらに補強する（それも有益な科学的結果）。
