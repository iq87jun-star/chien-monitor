## 0. 一行結論

**新12資産(穀物・エネルギー・金属・債券・ソフト)のTSMOMは10年で−18.7%・p=0.84、pre-2016でも−14.4%と
全期間で機能せず(H19a: 1/9ゲート・REJECT)。既存E5への追加(16資産版)もE5を破壊する
(+60.7%→+4.7%)ため見送り(H19b: REJECT)。** 文献的事前分布(Moskowitz系のコモディティTSMOM支持)は
このデータ・この実装では再現されなかった。**商品・債券先物(日足)の扉はこれで閉鎖**。

## 3. 解釈(誠実に)

1. **無相関(G8合格)だが期待値が負** = 「分散になるから足す」が成立しない教科書例。
2. 文献との乖離の要因候補: ①Yahoo**継続足のロール歪み**(特にNGのコンタンゴ減価は継続足で増幅) —
   ただしCFD実運用でもファイナンス/ロールコストは実在するため「実装可能な形では存在しない」という
   結論は変わらない ②TSMOM文献の主停止期(2010年代の commodity momentum crash)と検定窓の重なり。
3. pre-2016(191ヶ月)でも負 = レジームの問題ではなく、この宇宙×この解像度×このコストで**構造的に不在**。
4. 探索再開1バッチ目の結果として、docs/80の「生存エッジは低頻度フロー・カレンダー族のみ」という
   結論を新資産クラス側から補強した(商品にもTSMOMの持ち出し可能な形は無かった)。

## 4. 決定(事前登録どおり)

- H19a/H19b とも **REJECT**。EA化・デモ・配分変更は一切行わない。
- **商品・債券先物(日足解像度)の扉は閉鎖**。同データでの再探索・パラメータ変更での再挑戦はしない
  (「チューニングすれば効くのでは」はF2型の罠)。
- 残る正規の再開ルートは **edge20: ティックデータ(新解像度・執行系)** のみ。着手する場合は
  別途事前登録(ユーザーColabでのDukascopyティック取得が前提)。
- 資源は引き続き運用最適化(R4/R3a新シナリオのデモ、G3展開、docs/78ロードマップ)へ。
