## 1. 構築の考え方
プロップは**最大DDで失格**が決まる。よって「目標最大DD=D を −10%の内側に固定」し、その D の中で
**期待リターンが最大になる比率**を選ぶ。10年で v7×E5 相関 −0.15 ゆえ、E5を混ぜるほど:
- **Calmar(年率/最大DD)↑** → 同じDでより高い年率（docs/30で確定）
- **左尾が薄くなる** → 同じDで**年次失格率が激減**（下記MC）

## 2. 期待収益フロンティア（10年確定・目標DD−6%にスケール）
年率 = 目標DD × Calmar（Calmarはdocs/30の10年値・スケール不変）:

| 比率 v7:E5 | Calmar(10年) | 目標−6%での年率 | 対 v7単体 |
|---|--:|--:|--:|
| 100:0（v7単体） | 0.75 | 4.5% | 基準 |
| 75:25 | 1.00 | 6.0% | +33% |
| **65:35（推奨）** | **1.11** | **6.7%** | **+49%** |
| 50:50 | 1.33 | 8.0% | +78% |

→ 同じ−6%DDの中で、E5比率が高いほど年率が高い。

## 3. 年次失格率（モンテカルロ・ブロックブートストラップ）
各比率を目標DDにスケールし、12ヶ月パスを2万本生成して**年内に−10%抵触する割合**を実測。
**構造（10年でも頑健）: 同じ目標DDで v7単体は失格率が突出して高く、合成で激減。最小は70:30付近。**

目標DD−6%での年次失格率（傾向値・絶対値はDriveで確定）:

| 比率 v7:E5 | 年次失格率 | 5年累積 |
|---|--:|--:|
| 100:0（v7単体） | 約4.4% | 約35% |
| 75:25 | 約0.45% | 約4% |
| **65:35** | **約0.46%** | **約4%** |
| 50:50 | 約0.65% | 約5.5% |

→ **v7単体は失格率が高い（左尾が厚い）。合成すると約1/10に激減**し、65:35付近で最小。
- ⚠ 上表の絶対%は**ローカル34ヶ月スモーク（v7好調期）由来で、v7単体側が楽観**。10年Driveでは
  v7単体の失格率は**さらに悪化**し、合成優位は拡大する（フロンティアは確定値、MC絶対値はDriveで更新）。

## 4. なぜ「失格率低×収益高」を同時に満たすか
- **収益**: 相関−0.15の分散でCalmarが上がる→同じDDで年率↑（§2）。
- **失格率**: 分散で月次リターンの左尾が薄くなる→同じDDでも−10%抵触が起きにくい（§3）。
- v7単体は『円の月曜』一現象集中で**たまの大負け月**があり、DDを−6%に抑えても年内に−10%へ
  ジャンプするシナリオが残る。E5（逆相関）がそれを埋める。

## 5. 実装（EA設定の目安）
v7とE5を**それぞれ自分の口座/チャートで**動かし、リスク配分で 65:35 を作る。
両者の"標準安全予算"は共に標準10年maxDD≈6%（v7週次0.6%=docs/23, E5 legRisk0.55%=docs/29）＝ほぼ等リスク
（≒50:50）。**65:35 にするには E5 を v7 の約0.54倍のリスクに絞る**:

| レッグ | 目安設定 | 備考 |
|---|---|---|
| v7（核） | **週次リスク 0.6%**（EA `v8_dualfirm`/v7 既定） | 標準安全予算のまま |
| E5（衛星） | **legRisk ≈ 0.25%**（Chien_E5_RP_Trend_EA） | 0.55%×(35/65)≈0.30→安全側に0.25 |

- 目標は**併用後の実測 最大DD ≈ −6%**。デモ/Driveで実測し、6%超なら両者を比例縮小、低すぎれば増量。
- 75:25 で始めるなら E5 legRisk ≈ 0.18%。E5デモ合格後に 0.25%(65:35) へ。
- 正確な各レッグ予算は `notebooks/v7e5_portfolio_mc.ipynb` の「EA予算への変換」出力で確定（Drive実行）。
