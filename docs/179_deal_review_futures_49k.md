# docs/179: 個別案件評価 — 先物プロップ基盤「登録49,000ユーザー」$200,000

関連: docs/177(DDチェックリスト)、docs/178(ROI基準)

## 1. 掲載詳細(2026-07-29 取得)

- 価格: $200,000(≒¥3,140万)
- **稼働状況: 未ローンチ**。「完成済み・ローンチ準備完了」だが公式ローンチ実績なし
- **売上・利益・月間販売数: 開示なし(実績ゼロ)**
- ユーザー: 「ダッシュボードに移行済み49,000登録」+ メールリスト10万件(アクティブ/課金の区別なし)
- 含まれるもの: React製自社スタック、CME/DX-Feed/Volumetrica/Platform5 API連携、
  ドメイン、SNSアカウント(YouTube/IG/X/Discord)、IT責任者の3ヶ月サポート(任意)
- 売却理由: 創業者が「オンラインギャンブル業界への投資に転じるため」

## 2. 評価: 見送り(現状情報では)

1. **docs/177 DDチェックリストの最重要項目(課金アクティブ数・月間購入数)がゼロの案件。**
   「登録49,000」はまさに警告した虚栄指標で、未ローンチなのに49,000ユーザーが
   「移行済み」という矛盾(移行元はどこか。自然獲得でないなら購入リストの可能性)。
2. **リード単価として見ても高い。** ¥3,140万/49,000 ≒ ¥640/登録。コンバージョン1%なら
   実質獲得単価 ¥64,000/購入者 — docs/178 の CAC 最悪ケース(¥40,000)を超え、しかも一回限り。
   docs/178 の基準では CAC ¥40,000 時点で損益分岐 s* が 1.32% まで縮み、経営余地がほぼ消える。
3. **土俵違い。** 先物プロップ(CME/Rithmic系エコシステム・トレーリングDD文化)は、
   本リポの資産(MT5/FX/CFD・EA・季節性研究・sharp検知知見)とのシナジーが薄い。
   自分のEAで自分のファームのルールを検証する、という最大の強みが使えない。
4. **価格の比較対象に負けている。** docs/178 のシェル+自力立上げ(¥1,649万・FX/CFD型・
   自分の土俵)の約2倍の価格で、営業実績は同じくゼロ。差分はテックスタックとリストだが、
   テックはホワイトレーベルで月額課金で借りられるもの(docs/175 ⑥=難易度B)。
5. 売り手のシグナル: 「プロップを出てオンラインギャンブルへ」は、業界の規制強化を見ての
   撤退の可能性がある(docs/175 課題①のトレンドと整合)。

## 3. 評価が覆る条件(もし交渉するなら)

- リストの出所と質の実証: オプトイン経緯、過去の課金実績、直近メール開封率の生データ
- CME/データフィード契約の承継可否と月額維持費(先物はデータ費用が重い)の開示
- 価格が大幅に下がる場合(リスト+スタックの実質価値は感覚的に $50k 以下)

## 4. 一般化(今後の案件審査への追加規律)

- **「未ローンチ+大きな登録数」の組合せは原則見送り**。数字が大きいほど出所を疑う。
- 案件は必ず docs/178 の3条件(実測N・CAC・s)に翻訳してから価格と比較する。
  翻訳に必要なデータを開示しない案件は、その時点で評価不能=見送り。
