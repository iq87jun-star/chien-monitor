## 2. 結果

### Q60(23 セル): 新規 0 通過・改良 1/2(Mon2 のみ)
月曜の時間帯別平均(2021-10〜2026-08・各窓 3pip 後・bps):
| ペア | 東京 00-07 | ロンドン 07-16 | NY 16-24 |
|---|--:|--:|--:|
| GBPJPY | −2.8 | **+9.0** | +2.3 |
| AUDJPY | −3.9 | **+8.0** | −0.8 |
| CADJPY | −5.3 | +7.2 | −1.9 |
| CHFJPY | −3.1 | +6.3 | −0.5 |
| EURJPY | −2.8 | +6.2 | +0.7 |
| USDJPY | −4.7 | +5.7 | −0.6 |
| NZDJPY | −3.7 | +3.9 | −1.1 |

**月曜の利益はロンドン時間(07〜16 UTC)に集中し、東京時間はコスト後マイナス、NY はゼロ。** 「東京の参加者がいる日にだけ出る」(docs/303・304)が「値動きは欧州時間に出る」= 東京発の注文フロー(あるいは週明けの円売り)を欧州勢が引き継いで動く形。ロンドン窓の LONG は 7 ペアとも IS 23〜28/39・OOS 全ペアプラスだが、新規基準(p<5.5e-6)には届かない(最良 EURJPY p=0.005)。
前倒し {0,2,4,6}: Mon2 は IS Sharpe 2.79 → 3.62・OOS 3.35 → 4.65・最悪月改善で通過、Mon4 は Sharpe は上がる(3.10 → 3.92 / 2.44 → 3.30)が最悪月が −1.49 → −1.60 / −0.45 → −0.49 で不通過。

### Q60b(4 セル): 改良 0/4
ロンドン窓だけ(07→16 単発)は IS Sharpe を上げる(Mon4 3.10 → 4.07)が OOS で下がる(2.44 → 2.04)。ショット {7,8,9,10} 24h は IS・OOS とも悪化。**現行の 4/6/8/10 UTC × 24h は、時刻をずらしても改善しない**(東京窓のマイナスは 24h 保有の中で薄まっており、ロンドン窓を切り出すとコスト比率が上がる)。Mon2 の前倒しは通過だが Mon4 で通らず、時間帯分解でも「早い方が良い」根拠が無いので、EA の時刻は変更しない。

### Q62(4 セル): 0 通過・改良 0/2
前金曜が JP 祝日の月曜(3 連休明け)は通常と同じ(+4.9 vs +4.4 bps)。翌火曜が豪NZ祝日(n=18)は平均 −21.9 bps と大きくマイナスだが、除外しても OOS Sharpe が 3.50 → 3.50 で「改善」にならず不通過(IS は 2.62 → 2.79)。

### Q63(2 セル・診断)
JP225 の日足(Yahoo)は JP 祝日に 1 行しか無い。Mon JP225 / Hold JP225 の研究系列は JP 休場日に建てていない = NYSE と同じパリティ問題。現行 EA に JP225 は無いので影響なし。BROAD_IV を EA 化するときは JP225 に JP 祝日スキップを入れる。

## 3. 判定と扱い
- 改良系通過 2: Mon2 の前倒し {0,2,4,6}(Mon4 で不通過・Q60b で時刻変更の一般性が否定されたため **EA 反映しない**・紙上候補は H1 系列のため別管理)、Roll5 の月末最終営業日水曜の除外(n=13・紙上候補・EA の `InpSessSkipDates` に月末水曜を入れれば実装可)。
- 機構の結論: 月曜効果 = 東京が開いている月曜に発生し、欧州時間に実現する。時刻の最適化余地は無い(現行の 4/6/8/10 × 24h が最良に近い)。
- 新規通過 0。累積 **9,120**。参加者フィルター系はこれで一巡。残る候補は「豪NZ祝日除外 → EA」「月末水曜除外 → EA」の 2 つの実装判断。
