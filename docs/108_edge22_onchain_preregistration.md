# 108.【事前登録】edge22 — BTCオンチェーン批次(新データ型・N=2)

> **位置づけ**: 残存新データ全消化の第3批次。**オンチェーン指標**(MVRV・ハッシュレート)は
> 価格OHLCにもデリバティブにも含まれない新データ型であり docs/80 §4 の再開条件を満たす。
> データ: CoinMetrics コミュニティ版 `btc.csv`(2009〜, `CapMVRVCur`/`HashRate`/`PriceUSD`)。
> **注意(事前明記)**: クリプト方向仮説は E6(ベータ罠)・edge19(再現失敗)で2敗しており事前確率は低い。
> MVRVの無料代替ソースは存在しないため、**H22aは合格しても別ソース再現不能=昇格不可**
> (検定はするが、その先が構造的に closed であることを数字を見る前に認める)。
> HashRate は blockchain.info で再現可能。数字を見る前に本docを固定・コミット。

## 1. 凍結ルール(サンプル 2011-01-01〜・日次・翌日リターン獲得)

| ID | シグナル(凍結) | ポジション | 機構 |
|---|---|---|---|
| **H22a MVRV-VALUE** | MVRV < 1.0 | 条件成立中 翌日LONG | 時価総額<実現時価総額=保有者平均が含み損の歴史的降伏域 |

- **コスト**: 片道10bp・ストレス2×。保有コストストレス15%/年(クリプトCFDスワップ相当)。

## 2. 採点ゲート(docs/100 と同一のはしご)

- G-dir / G-p(ドリフト保存プラセボ=ON日数保存ランダム配置, 2000draw, p≤0.05・Bonferroni α=0.025)/
  G-split(期間中央2分割で両半+)/ G-cost(2×)/ G-hold(15%/年)/ G-beta(対ベータ超過+)/
  G-dd(レバ1 maxDD≥−20%)
- **判定**: 全通過=STRONG-LEAD(Bonf未達は1段下げ)/ G-p含む過半=LEAD / dir+p≤0.10=参考 / 他REJECT。
- H22a はSTRONG-LEADでも**EA化・資金投入不可**(再現ソースなし=edge19bの教訓)。記録のみ。
  H22b がSTRONG-LEADの場合のみ blockchain.info 再現(edge22bとして別事前登録)に進める。
