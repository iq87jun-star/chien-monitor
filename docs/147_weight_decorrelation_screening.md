# 147.【記録】配分変更による器間相関の低減スクリーニング — 有効なのはPD側のE5重複解消のみ

> ユーザー発案(2026-07-11)「採用銘柄の比率変更で器間の相関を下げられるか」のスクリーニング記録
> (対話セッション内実行・採用提案なし=事前登録前段階)。窓2016-2025・Yahoo月次。

## 1. PD側(前段の結果): E5重複解消のみ構造的に有効

| PD配分(v4/v7/EMon/E5) | PD単体Sh | ρ(vs PE v2) | 3口座システムSh |
|---|--:|--:|--:|
| 現行 30/25/25/20 | 1.17 | 0.43 | 1.94 |
| E5ゼロ化 37.5/31/31/0 | 0.88 | **0.02** | 2.00 |

- PD↔PE相関の源=PD内のE5 20%(PEの中身と同一)。抜けばρはほぼ消える。
- ただしPD単体Sharpe低下=**チャレンジ段階では失格率悪化**(Sh→失格対応: 1.17→約20%, 0.88→約25%)。
- **結論: 「資金化後の複数口座同時運用」フェーズ限定の再配分案**として保留(発動時に事前登録
  +docs/138実データ関門)。チャレンジ段階では現行維持。

## 2. 季節側(本doc主題): 不成立

| 季節変種 | Sharpe | ρ(vs PD間引き) | 備考 |
|---|--:|--:|---|
| 現行R4+G3 | 2.24 | +0.41 | 基準 |
| v4抜き | 1.96 | +0.30 | 2月が休止月化 |
| EMon抜き | 1.76 | **+0.42** | 相関が下がらない |
| E5抜き | 2.19 | +0.42 | 同上 |

- 共分散の月別分解: 1月16%・2月16%・6月16%・3-5月11-12%と**上半期に広く分散**
  (7月は**−10%**=S-Jul月はむしろ逆相関で分散に寄与)。単一スリーブが原因ではない。
- ∴ 季節↔PDの相関は「広義のリスクオン露出」の共有であり、**どのスリーブを抜いても
  他スリーブ経由で戻ってくる**。唯一効くv4抜きも ρ−0.11 に対し Sharpe−0.28+休止月という
  割に合わない交換。PD↔PEのような「単一重複の外科的除去」の類例は季節側には存在しない。

## 3. 総括

器間相関の配分レバーは**PDのE5だけ**(資金化後案件として保留)。季節側は現行維持。
3器の相関構造(季節-PD 0.39/PD-PE 0.42/季節-PE 0.12)は、これ以上比率では圧縮できない
実務上の下限にあると記録する。
