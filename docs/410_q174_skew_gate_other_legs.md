## 2. 読み
1. **円クロスの月曜は形を問わず SKEW 門が効く**(Mon4・Mon3 で成立、instG も 90 分位なら成立)。見送り週の平均は +1.4〜6.5 bps 対 残り +9.7〜13.5 bps で、Q173 と同じ像。instG の 0.8 不成立は OOS 最悪月 1 か月(2025 年)の差で、GBPJPY 比重が高い形は門の外でも大きく動く。
2. **Roll は門の開いた週のほうが強い**(+3.8 対 +2.1 bps/週)。リスク回避の週の水曜は円買いが乗り、ロール(機械的な 2〜3 bps)に方向の追い風が加わる。ただし Roll の週あたり期待は小さく、門の週だけにすると年 10〜12 回・累積が 1/2 以下になるため採用しない。×2 は IS 最悪月が 0.01pt 悪化して形式上不成立だが、90 分位なら成立しており「増し玉条件」としての芽はある。swap-free 口座(14166201)限定の話で、日次限度(4%)に対して Roll ×4.5 → ×9 の週を作ることになるので、採用するなら口座 MC が要る。
3. 金(木曜)は SKEW と関係が薄い。90 分位の週だけ IS +35 bps だが本数が少なく、2025 年の金の上昇局面の寄与。
