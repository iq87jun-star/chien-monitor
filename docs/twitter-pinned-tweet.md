# 固定ツイート案(現在運用中のEA体制の紹介)

対象: プロップトレード記録アカウントの固定ツイート
元ネタ: docs/172(RG3補正+balance基準−4%ガード体制・3口座・2026-08〜)

## 作成方針

- **口座番号は公開しない**(悪用・特定リスクのため)
- 通過率99.4%等はモンテカルロ/バックテストの**研究値**なので、実績と誤解される形では書かない
- 投資助言・EA販売と受け取られる表現を避ける(勧誘なしを明記)
- 無印X(280字=全角約140字)向けの単発版と、詳細を伝えるツリー版の2パターン

## 運用メモ

- プロフィール文(docs/twitter-profile-proposal.md)とセットで使う想定
- 月次・週次の経過報告ポストをこの固定ツイートに返信でぶら下げると記録が一本に繋がる
- 口座番号・Magic番号・EAファイル名などリポジトリ内部の識別子はツイートに書かない
- 「通過率99.4%」等の研究値を出す場合は必ず「バックテスト/シミュレーション値」と明記する
