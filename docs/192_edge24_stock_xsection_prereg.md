学術で最も頑健とされる価格ベースの2系統+結合のみ。ファンダ系(クオリティ等)は
無料データの信頼性不足のため今回は登録しない(データが確保できたら別バッチ)。

| # | 仮説 | 規則(凍結) |
|---|---|---|
| X1 | 12-1モメンタム(Jegadeesh-Titman) | 月末に過去12ヶ月リターン(直近1ヶ月除外)で順位付け、上位10銘柄を等ウェイトLONG、翌月末リバランス |
| X2 | 低ボラティリティ | 月末に過去12ヶ月日次ボラで順位付け、下位(低ボラ)10銘柄を等ウェイトLONG、同上 |
| X3 | 結合(X1×X2の平均順位) | 平均順位上位10銘柄、同上 |

- ユニバース: S&P100 現構成銘柄(スクリプトに列挙・凍結)。取得失敗銘柄は除外して記録。
- ロングオンリー(自己口座の実務性。空売りコスト・貸株の壁を避ける)。
- コスト: 片道0.1%(往復0.2%)×回転率。リバランスは月次のみ。

## 2. 既知の罠への事前対処

1. **生存者バイアス**(現構成銘柄=生き残り): 絶対リターンでは評価しない。
   **同一ユニバースの等ウェイト・ベンチマークに対する超過**のみで評価する
   (戦略もベンチも同じ生存者集合から引く=バイアスを相対比較で相殺)。限界は§5に明記。
2. **「株ベータの言い換え」の罠**(edge11-F2の教訓): プラセボは
   「同一ユニバースからランダム10銘柄を毎月選ぶポートフォリオ1,000本」とし、
   その超過リターン分布の上位でなければ不合格。市場に乗っただけでは通らない設計。

## 3. 合否ゲート(全通過で「ペーパー運用前進検証候補」)

| ゲート | 基準 |
|---|---|
| G1 | 10年の対ベンチ超過リターン > 0(コスト込) |
| G2 | プラセボ p < 0.0167(=0.05/3、ランダム1,000本中上位1.7%) |
| G3 | LOYO: 超過ベースの負け年 ≤ 3 |
| G4 | コスト2倍(往復0.4%)で超過 > 0 |
| G5 | 自EAポートフォリオ月次との相関 \|ρ\| < 0.30(月次CSVが無ければ保留=採用禁止維持) |

**多重検定の申告**: 試行数3(X1-X3)。G2のαは0.05/3で運用。登録外のユニバース変更・
銘柄数変更・保有期間変更をした結果は無効(docs/165)。

## 4. 合格後の扱い

- 合格=ADOPTではない。次段は**ペーパー(またはIB最小単元)で3ヶ月前進検証**(docs/29 の慣例準用)。
- 用途は**自己口座の分散部品**。プロップ口座には載せない(docs/185/191 の結論を維持)。
- 税制上は申告分離20.315%レーン(docs/191 §4)。

## 5. 限界の申告

- 生存者バイアスは相対評価で軽減するが消えない(脱落銘柄のリターンは両側から欠落)。
  合格しても「歴史的にこの生存者集合内で相対優位があった」以上の主張はしない。
- 配当は含まない(調整済み終値を使用するが、Yahoo調整の精度に依存)。
- S&P100の現構成での検定であり、当時の構成の再現ではない(データ無料の制約)。
