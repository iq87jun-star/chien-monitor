## 2. 読み — なぜ再現しなかったか(事後観察・判定には影響しない)

- Deribit の funding は算出式が異なり(プレミアム連動・連続徴収)、**F3d<0 の発生頻度が
  Binance の2.4倍**(26.3% vs 11.0%)。「負ファンディング=ショート過密の極端な状態」という
  シグナルの意味が会場間で保存されておらず、薄まった条件では超過はプラセボと区別できない。
- net が大きく+なのは ON日数が多い分ドリフトを多く拾っただけ(対ベータ超過+35%は残るが非有意)。
- パーセンタイル合わせ等でシグナルを「揃え直す」ことは可能だが、それは**事後スキャン**であり
  規律違反なのでやらない(docs/102 §2「救済しない」)。

## 3. 処置(事前固定通り)

- H19a は **LEAD(単一ソース・再現失敗)** に降格。docs/98 §4 の四半期監視のみ継続。
  **EA化・デモ投入・資金投入はすべて不可**(単一取引所の期間固有パターンの可能性が高い)。
- edge19 批次はこれで完全終了。**探索は再閉鎖**。残る未投入データは Dukascopy 分足/ティック
  (入手確認済み)のみで、着手する場合は edge20 の新規事前登録から。
