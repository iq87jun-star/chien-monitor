## 2. 読み

- 店頭 FX の買い偏りは、円クロスではスワップ狙いの長期保有を多く含む「水準」の情報で、翌週の月曜の値動きを分ける力は無かった。月次・半月遅れという粗さも効いている。
- 建玉系の情報はこれで COT(門・単独)・SKEW・協会統計と 3 系統が不採用。**月曜手法の見送りフィルターとして建玉の偏りを使う方向は閉じる**。
- 最悪月(−1.4〜−1.6%)はどのセルでも変わらない。月曜手法の悪い月は、建玉の偏りとは別の要因(円の急騰)で起きている(docs/244 Q167 の診断と一致)。
