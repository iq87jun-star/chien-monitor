## 2. なぜこうなるか（バグではない）
- ゼロ・ドリフト銘柄に毎ショット spread/2＋slippage を払う。per-trade 純益の平均が僅かに負でも、
  乗算複利で n=7800 なら (1−0.0007)^7800 ≈ −99%。**高頻度ほどコストが効く構造**。
- 週末ギャップ回帰(n=1115)が−33%で相対的に軽いのも頻度差で説明がつく。
- → 「この頻度ではコストを越えられない」という**取引可能性の否定**であって、計算誤りではない。

## 4. 教訓（次の事前登録に反映）
- 高頻度・無条件方向の探索は**コスト後ではほぼ必敗**。次は**低頻度×強いマクロ事前分布**に絞る。
- 「Bonferroni未達でもp<0.05」すら今回は一つも無し＝白地の枯渇を示唆。新規探索は1サイクルに留め、
  ダメなら運用最適化へ切り替える。
