## 0. 背景(なぜ「保険」が第3の軸か)

docs/128で確定した事実: **E5以外の全エッジ(v4/v7/E-Mon/G3)は「2016年以降レジーム」現象**。
現行2本(季節R4+G3 / PortfolioD)は機序こそ別だが同じ耐久クラスに乗る。第3ポートフォリオの
目的は追加リターンではなく**失敗モードの独立性**(レジーム転換時の生存)と定義する。

## 1. P1 — Portfolio-I(nsurance): E5 60 / G3 20 / v4 20

- 構成(固定): **E5 60% / G3 20% / v4 20%**。月曜系(v7/E-Mon)を意図的に排除
  (現行2本との曜日重複・レジーム重複の最小化)。用途=**資金化後/Instant口座**(チャレンジ速攻用ではない)。
- 評価(docs/110と同一手法・同一窓2016-01〜2026-06): 日次再合成→安全倍率
  (min(単日−4%, 月中−8%)逆算×0.8)→年率/Sharpe/maxDD/最悪日・月。
  G3は日足プロキシ(実測H1の約2割しか捉えない=**控えめ側**、docs/110 ⚠)。
- 比較対象: PortfolioD(30/25/25/20)・R4+G3・**E5単体**(同じ安全倍率規律で並べる)。

### P1採用ゲート(全て固定)

| # | ゲート | 基準 |
|---|---|---|
| I-1 独立性 | 月次リターン相関 vs PortfolioD **かつ** vs R4+G3 が \|ρ\|<0.5 |
| I-2 分散便益 | 安全倍率でのSharpe > **E5単体**の安全倍率Sharpe(でなければE5単独で足りる) |
| I-3 実用性 | 安全倍率で年率 ≥ +4% |
| I-4 保険性能 | レジーム・ストレス(v4/G3の期待値を0に置換・ボラ維持、E5は実績)下の期待年率が、同ストレス下のPortfolioDの期待年率を上回る |

- 全通過 → 第3ポートフォリオとして**デモ前提の採用**を docs/132 で提起(配備先口座の選定込み)。
  1つでも不通過 → 不採用とし、代替(案3複製)を既定路線とする。

## 2. P2 — edge25: v7x(円月曜・新4クロス AUD/NZD/CAD/CHF-JPY)

docs/86 H14cで機構確認済み(+26.8%/p=0.0083/DD−7.3%)だが「配分・コスト・相関の事前登録が必要」
と保留された宿題の消化。**マイナークロスのコストが本丸**。

- ルール(v7逐語): 月曜open→火曜open LONG(円ショート)・4クロス等ウェイト。

- 窓: 2016-01〜2026-06(本判定)・データ利用可能なpre-2016(参考・耐久級)。
