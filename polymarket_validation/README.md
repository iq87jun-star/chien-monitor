theoption の検証(`theoption_validation/README.md`、ブランチ `claude/zaption-check-m776m7`)とは別系統として独立に記録する。
法的留意: 日本居住者の予測市場利用は賭博罪の適用があり得る領域で、金融庁の認可も無い。本ブランチは検証と実装の記録であり、運用を勧める立場は取らない(ユーザー決定 2026-11-04「Polymarketで進めて下さい」を受けて開始)。

## 追補1 (2026-11-04): 事前登録(データを見る前に固定)
- データ: Gamma API の解決済み市場(出来高 ≥ $10k)。一覧は offset 上限 2,000 のため end_date の月次窓(2024-01〜2026-12)で分割取得(38,415 件)。CLOB API の YES トークン時間別価格履歴(fidelity 60 分)。解決は outcomePrices(1/0)。
- H1 ロングショット過大評価: 解決の T 日前(T=1, 3, 7, 30)に YES 価格 p が 0.02〜0.10 の市場で実現 YES 率 q を測る。q < p なら NO 買い(費用 1−p、利益 p)に優位。
- H2 本命の過小評価: p ≥ 0.90 で q > p なら YES 買い。
- H3 時間減価: T=7→1 の価格推移を解決側別に。
- 判定: 全期間と前半/後半で符号・大きさが保たれ、カテゴリ(政治/スポーツ/暗号資産/他)別に崩れず、スプレッド(価格帯別の実測: 流動市場で 0.1〜0.7c、最大 1.5c)控除後も正であること。
- 実行面: 板の深さ(best±1c で $3,500〜4,600)、negRisk 市場の構造、UMA 解決の裁量リスク、USDC の入出金経路、税務(雑所得)。
- 段階: (1) 価格系列で H1〜H3 → (2) 合格なら紙上→$50 単位のフォワード → (3) 発注ボット(py-clob-client)。
- スクリプト: `scripts/collect.py`(一覧+履歴、初版)、`scripts/collect2.py`(月次窓で一覧を取り直し+残りの履歴)、`scripts/analyze.py`(H1〜H3)。データは scratchpad(`poly/markets.jsonl`、`poly/ph/*.json`)に置き、リポジトリには入れない。

## 追補2 (2026-11-04): 予備結果(2026-10〜11 の 2,044 市場のみ。全期間は収集後に差し替え)
- 2〜5c(T=7): p 0.032 / q 0.011 → NO 買い純益 +1.6%。方向は仮説どおりだが利幅は小さい。
- 95〜98c(T=7): n=192 全件 YES → YES 買い +3.0%/7 日、T=30 でも +3.3%。1 回の外れで −100% のため n=192・外れ 0 では裾を押さえられない。
- 20〜80c は前半/後半で符号が反転し優位なし。

## 追補3 (2026-11-04): 全期間結果(2024-01〜2026-11、101,559 市場) — H1 ロングショットは保留、H2 本命 95〜98c はスポーツ以外で合格候補、H3 は収穫なし

### データの取り直しと制約(追補1 からの変更点)
- **CLOB の価格履歴は、解決から約 1 か月を過ぎた市場では `interval=max` が空**を返す(予備結果 2,044 件が 2026-10〜11 に偏っていた原因)。`startTs/endTs` を指定した 15 日以内の窓なら 2024 年分も返るため、解決時刻 ref = min(closedTime, endDate) を基準に W1=[ref−14d, ref+1d]・W2=[ref−31d, ref−17d] の 60 分足 2 本で全市場を取り直した(`scripts/collect4.py`、`collect4b.py`)。
- Gamma の一覧は窓あたり 2,000 件が上限で、2024-11 以降は各窓の**サンプル**(closedTime 降順の上位 2,000。2026-06-21〜09-30 は `order=closedTime` が 500 を返すため id 降順・5 日窓)。2026-02〜06-20 は 10 日窓で補完(`collect5.py`、`collect5b.py`)。重複除去後 108,209 件、履歴 10 点以上・解決時刻あり・最終取引(0.02<p<0.98 の最後)ありの 101,559 件を分析。
- 構成: 暗号資産 46,938(短期「Up or Down」が大半、寿命 1 日未満のものは T≥1 の集計に入らない)、スポーツ 30,217、他 16,332、政治 8,072。解決 YES 率 0.414。**feesEnabled が 62.6%**(ほぼ暗号資産の短期市場。政治・他はほぼ無料)。
- 判定の前提は追補1 のまま: NO 買い = 1−p+0.005 で購入、YES 買い = p+0.005 で購入(スプレッド片道 0.5c)。n<30 は表示しない。前半/後半は解決時刻の中央値(2026-05-21)で分割。

### H1 ロングショット過大評価(2〜10c で NO 買い) → **保留**
| 断面 | 2〜5c T=1 | 5〜10c T=1 | 2〜5c T=7 | 5〜10c T=7 |
|---|---|---|---|---|
| 全期間 | n=6,259 q−p −0.8pp NO **+0.3%** | n=3,628 −0.3pp −0.2% | n=2,689 −1.0pp +0.6% | n=1,967 −1.3pp +0.9% |
| 2024 年 | +1.3% | +2.4% | +0.3% | +1.2% |
| 2025 年 | +0.9% | +1.5% | +0.3% | +0.7% |
| 2026 年 | **−0.8%** | **−2.5%** | +1.1% | +0.8% |
| 政治 | +0.6% | +1.1% | +1.0% | +0.5% |
| スポーツ | +0.0% | −0.6% | **−1.7%** | +0.6% |
| 暗号資産 | +1.6% | +2.5% | +0.5% | +3.0% |
| 他 | −0.2% | −1.2% | +0.6% | +0.7% |
| negRisk=True(T=7) | — | — | −0.3% | **−1.0%** |
| negRisk=False(T=7) | — | — | +1.3% | +2.8% |
- 符号は全期間・多くの断面で仮説どおり(q<p)だが、利幅は **0〜1% / 取引**で、2026 年の T=1(短期暗号資産市場が大量に入る)とスポーツ、negRisk(多候補の選挙など。候補間で確率が足し合わされるため裾が切り下がらない)で反転する。
- negRisk 以外に限ると全期間 +1.2〜2.8% と揃うが、後半(2026-05 以降)の T=1 は −0.4 / −2.1% で崩れる(n=266 / 233)。
- 判定: 事前登録の「前半/後半・カテゴリ別に崩れない」を満たさない → **保留**。歪みは存在するが小さく、短期市場の増えた 2026 年は手数料(feesEnabled)込みで消える水準。

### H2 本命の過小評価(≥0.90 で YES 買い) → **95〜98c・スポーツ以外に限り合格候補**(事後の絞り込みあり)
| 95〜98c、YES 買い | T=1 | T=3 | T=7 | T=30 |
|---|---|---|---|---|
| 全市場 | n=1,033 q=0.983 +1.0% | n=789 q=0.987 +1.5% | n=535 q=0.996 **+2.6%** | n=227 q=0.996 +2.7% |
| スポーツ以外 | n=936 外れ 9 **+1.8%** | n=737 外れ 8 +1.7% | n=502 外れ 2 **+2.6%** | n=225 外れ 1 +2.7% |
| 　前半 / 後半 | +1.4 / +2.6 | +1.1 / +2.7 | +2.1 / +3.0 | +1.3 / +3.3 |
| 　2024 / 2025 / 2026 | +1.2 / +1.1 / +2.5 | +0.7 / +0.8 / +2.5 | +2.8 / +2.1 / +2.6 | +2.4 / — / +3.3 |
| 　政治 / 暗号資産 / 他 | +0.9 / +2.4 / +2.2 | +2.1 / **−0.2** / +2.3 | +2.7 / — / +2.2 | +2.6 / — / — |
| 　negRisk あり / なし(T=7) | | | +2.7 / +2.2 | |
| スポーツのみ | n=97 外れ 9 **−6.5%** | n=52 外れ 2 −1.0% | n=33 外れ 0 +3.1% | — |
- 90〜95c は q≈p で優位なし(全市場 T=1 −0.4%、T=7 −0.3%)。98c 以上は +0.0〜+0.3% でスプレッド負け。優位は **95〜98c の帯だけ**。
- 外れゼロ区間の裾(Rule of three、3/n を外れ率の上限とした最悪値): スポーツ以外 T=7 は n=502・外れ 2 → 上限 0.6%、最悪でも +2.4%。年別でも 2024 T=7(n=108、最悪 −0.0%)を除き正。
- T=7 の外れ 2 件: 「Saquon Barkley がファンタジー RB 1 位か」(2025-01、分類は他だが実質スポーツ、negRisk)、「Trump が 3 月中に Rutte と話すか」(2026-03、p7=0.950)。
- 判定: 事前登録のゲート(全期間・前半/後半・カテゴリ別で符号と大きさが保たれ、スプレッド控除後も正)を、**スポーツを除く 95〜98c・T=7 以上**で満たす。**ただし「スポーツ除外」と「95〜98c に限定」はデータを見た後の絞り込み**(事前登録は ≥0.90 の全体)で、全体では 90〜95c と 98c 以上が優位ゼロのため、帯の選択は事後。スポーツの 95〜98c が負ける(T=1 で外れ 9/97)のは、試合中・直前の価格が 1 プレーで反転するためと解釈できるが、これも事後の説明。
- 機構の解釈: 96〜97c で 99.6% 当たるものが放置されるのは「3% の利益のために資金を 1〜4 週間ロックしたくない」資本コストの反映(解決 → UMA 確定 → 償還まで更に数時間〜数日)。したがって **歪みというより資金拘束のプレミアム**で、年率換算は保有期間と再投資速度に依存する(T=7 で +2.6% を週 1 回転できれば年率は高いが、該当市場は 2026 年で週 5〜6 件、best±1c の板は $3.5〜4.6k、feesEnabled 市場では別途手数料)。

### H3 時間減価 → **収穫なし**
- 7 日前 2〜10c で NO に終わる市場の平均変化は −0.6pp(n=4,483)。20〜70c 帯の −9pp は結果判明による収束で、H1/H2 以上の情報はない。

### 執行面の既知事項(追補1 の実測を再掲)と未測定
- 流動市場のスプレッド 0.1〜0.7c(最大 1.5c)、best±1c の深さ $3,500〜4,600。95〜98c の YES は売り板が薄いことが多く、$1,000 超は分割が要る。
- 未測定: 解決〜償還の実時間(UMA 2 時間の異議申立て窓 + 争議時は日単位)、negRisk 市場の YES 買いの実効コスト、feesEnabled 市場の手数料率(takerBaseFee)の分布。

### 次段階の提案(紙上フォワード。発注ボットは作らない)
1. 毎日 1 回(JST 09:00)、Gamma の active 市場(出来高 ≥ $10k、スポーツ正規表現に非該当、endDate が 7〜35 日先)で CLOB `/book` の YES best ask が 0.95〜0.98 のものを記録(市場 id、ask、ask の深さ、endDate、negRisk、feesEnabled)。
2. 解決後に outcomePrices で勝敗と、closedTime − endDate(解決遅延)を記録。損益は記録時の ask + 0.5c で計算。
3. 8 週間(目標 n≥150)で、実現 q ≥ 0.99 かつ 純益 ≥ +1.5% / 取引、外れの内訳に「規約の読み違い(UMA 裁定)」が含まれないこと、を合格条件とする。
4. 合格しても実資金に進むかは別途判断(法的留意は冒頭のとおり。運用を勧める立場は取らない)。
- スクリプト: `scripts/collect4.py`(窓取得)、`collect4b.py`(追加分)、`collect5.py`/`collect5b.py`(2026-02〜09 の一覧補完)、`analyze2.py`(H1〜H3、年別・カテゴリ別・negRisk 別)、`extra_cuts.py`(H2 スポーツ以外、H1 negRisk 以外、外れ一覧)。生データ(markets.jsonl 108,209 行、ph2/ 108,209 件 ≈ 180MB)は scratchpad のみ。
