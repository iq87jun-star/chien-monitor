# Chien Trend Rider — FX 自動売買 EA(GogoJungle 販売用)

MT4 / MT5 両対応のトレンドフォロー型 EA です。GogoJungle(ゴゴジャン)での
**販売用** に開発しており、プロップファーム検証用の規制ロジック
(日次ドローダウン強制停止・取引時間の強制制限・口座縛り等)は一切搭載していません。
口座制限・使用期限・外部 DLL なしの、どの証券会社でも動作する汎用構成です。

## ディレクトリ構成

```
fx-ea/
├── MQL5/ChienTrendRider.mq5   # MetaTrader 5 版ソース
├── MQL4/ChienTrendRider.mq4   # MetaTrader 4 版ソース
├── docs/sales-page-draft.md   # GogoJungle 販売ページの原稿ドラフト
└── README.md                  # このファイル
```

## ロジック概要

| 要素 | 内容 |
|---|---|
| トレンド判定 | EMA50 と EMA200 の位置関係(確定足のみ使用) |
| エントリー | トレンド方向への RSI 押し目/戻り回復(買い: RSI が 40 を下から上抜け、売り: 60 を上から下抜け) |
| 損切り | ATR × 2.0(可変) |
| 利確 | ATR × 3.0(可変、0 で無効化しトレーリングのみ運用可) |
| 建玉管理 | ブレークイーブン移動 + ATR トレーリングストップ(各 ON/OFF 可) |
| ロット | 固定ロット or 残高比リスク%(SL 幅から逆算) |
| ポジション | 同一通貨ペア・同一マジックナンバーで常に 1 ポジションまで |
| フィルター | 最大スプレッド、取引時間帯、曜日、金曜クローズ(全てオプション) |

推奨初期環境: **USDJPY / EURUSD の H1**(要バックテストで確認)。
エントリー判定は足確定時のみ行うため、ティックの揺らぎによる
バックテストとリアルの乖離が小さい設計です。

## 主要パラメータ

| パラメータ | 既定値 | 説明 |
|---|---|---|
| InpMagicNumber | 87001 | マジックナンバー(複数通貨で使う場合は変更) |
| InpFastEmaPeriod / InpSlowEmaPeriod | 50 / 200 | トレンド判定 EMA |
| InpRsiBuyLevel / InpRsiSellLevel | 40 / 60 | 押し目・戻り判定の RSI 水準 |
| InpAtrSlMult / InpAtrTpMult | 2.0 / 3.0 | SL / TP の ATR 倍率(TP は 0 で無効) |
| InpLotMode | RISK_PCT | 固定ロット or リスク%方式 |
| InpRiskPercent | 1.0 | 1 トレードあたりのリスク(残高比%) |
| InpUseBreakEven / InpUseTrailing | true / true | 建玉管理の ON/OFF |
| InpMaxSpreadPoints | 30 | エントリー時の最大許容スプレッド(0 で無効) |
| InpUseTimeFilter | false | 取引時間帯フィルター(サーバー時間) |
| InpCloseOnFriday | false | 金曜指定時刻に全決済して週末を跨がない |
| InpEcnMode(MT4 のみ) | false | ECN 口座向け: 約定後に SL/TP を後付け |

## コンパイル手順

- **MT5**: MetaEditor で `MQL5/ChienTrendRider.mq5` を開きコンパイル → `.ex5`
- **MT4**: MetaEditor で `MQL4/ChienTrendRider.mq4` を開きコンパイル → `.ex4`

外部インクルード(標準ライブラリ `Trade.mqh` のみ)・DLL 不要のため、
そのままコンパイルが通る構成です。

## 販売前に必須の検証

このリポジトリではバックテストは実行できません。販売前に必ず以下を実施してください。

1. **バックテスト**: MT4/MT5 ストラテジーテスターで 10 年以上・全ティック
   (MT5 は「実際のティックに基づいたすべてのティック」)で検証。
   スプレッド・手数料を実運用相当に設定する。
2. **パラメータの頑健性確認**: 最適化しすぎない。前半/後半分割
   (イン/アウトオブサンプル)で成績が崩れないかを確認。
3. **デモ or 少額リアルでのフォワード**: 最低 1〜3 ヶ月。GogoJungle は
   フォワード成績の公開システムがあり、成績表示が販売力に直結する。

## GogoJungle 出品の流れ(概要)

1. GogoJungle で販売者登録(本人確認あり)。
2. コンパイル済み `.ex4` / `.ex5` と商品説明を添えて商品登録・審査申請。
   販売するのはソースではなくコンパイル済みバイナリ。
3. GogoJungle 側のシステムでフォワードテスト(リアルトレード成績)を接続・公開。
4. 審査通過後に販売開始。バージョンアップは同商品ページから配布可能。

※ 手数料率・審査基準・必要素材(バナー画像等)は変わることがあるため、
出品時に GogoJungle の販売者向けガイドを必ず確認してください。
ライセンス管理(購入者以外の使用制限)は GogoJungle 側の仕組みで行われるため、
EA 本体に口座縛りを実装する必要はありません。

販売ページの原稿ドラフトは `docs/sales-page-draft.md` にあります。
