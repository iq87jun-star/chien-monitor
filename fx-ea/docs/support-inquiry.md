## 件名

```
EA出品の手順について(RealTrade審査・商品審査の確認)
```

## 本文

```
お世話になっております。

MetaTrader 5 用のEA(システムトレード)の出品を準備しております。
新規商品登録フォームおよび「EAご出品の流れ」を拝見しましたが、
進め方の確認をさせていただきたく、以下6点についてご教示ください。

■ 商品の概要
・プラットフォーム: MetaTrader 5
・取引通貨ペア: USD/JPY・EUR/JPY・GBP/JPY(3チャート同時稼働)
・取引頻度: 1チャートあたり週1回、3ペア合計で週3回程度
・バックテスト: 2016年1月からの10年6ヶ月・1,636取引


【1】RealTradeトレード結果審査の合否基準について

「RealTradeトレード結果審査(約1ヵ月)」につきまして、
「取引がないなどの理由で審査継続の場合は、取引が行われるまで審査は延期されます」
との記載がございます。

この審査は、期間中の取引実績が「存在すること」を確認するものでしょうか。
それとも、期間中の損益がプラスであることが合格条件に含まれますでしょうか。

弊方のEAは週1回のみ取引する低頻度・低リスクの設計のため、
1ヶ月という期間では損益が振れる可能性がございます。
判断基準を事前に把握しておきたく、お伺いいたします。


【2】RealTrade審査中の商品ページ作成について

「1. 商品ページの作成」→「2. RealTradeでトレードを公開」の順序と存じますが、
RealTradeアカウントIDが必須項目となっております。

RealTradeの設定・トレード公開を先に行い、アカウントIDを取得してから
商品ページを作成する流れでしょうか。
それとも、商品ページを先に作成・保存し、後からアカウントIDを追記する
ことも可能でしょうか。


【3】「特別バックアップ出品者」について

「※『特別バックアップ出品者様』はRealTrade審査は不要です」との記載がございます。
こちらに該当する条件、または申請方法がございましたらご教示ください。


【4】フォワードテストの「2トレード」の数え方について

商品審査のフォワードテストにつきまして、
「2トレード終了、および2週間経過後」との記載がございます。

弊方は3通貨ペアを3チャートで同時稼働させる想定です。
この「2トレード」は3チャート合計での2トレードでしょうか。
それとも、1チャート(1通貨ペア)あたり2トレードが必要でしょうか。


【5】提出ファイルについて

ソースコードチェックがあるとのことですので .mq5 ソースファイルを
提出する認識でおりますが、コンパイル済みの .ex5 ファイルも
併せて提出が必要でしょうか。


【6】バックテストレポートの提出範囲について

3通貨ペアでの稼働を推奨する商品ですが、バックテストレポート(HTML)は
3ペア分すべての提出が必要でしょうか。
1ペア分、または代表的な1ペアのみでも審査上問題ございませんでしょうか。


お忙しいところ恐れ入りますが、ご確認のほどよろしくお願いいたします。
```

# 各質問の意図(送信時には不要)

| # | 何が変わるか |
|---|---|
| 1 | **最重要。**損益で落ちる制度なら、稼働開始のタイミングと商品構成を見直す必要がある。損益を問わないなら「1ヶ月の成績がぶれる」という懸念自体が消える |
| 2 | 並行可能なら段取りが1週間以上短縮できる。RealTrade待ちの間にページを作れる |
| 3 | 該当すれば**約1ヶ月の審査を丸ごと省略**できる可能性がある |
| 4 | 3チャート合計なら1週間、1チャートあたりなら3週間かかる。日程が3倍変わる |
| 5 | 事前に用意するファイルが決まる |
| 6 | 3ペア分のテスターを回す手間が変わる(1ペア40分程度×3) |
