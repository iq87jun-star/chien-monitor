# ■ あなたの確認・作業が必要な項目

## 1. RealTradeアカウントID(必須・最大の障壁)

**これがないと商品登録を完了できません。**

出品の流れが変更されており、以下が必須になっています:

1. 商品ページを作成し、mq5ファイルをアップロード
2. **RealTradeにトレードを公開**(リアル口座・デモ口座どちらでも可)
3. **RealTradeトレード結果審査(約1ヶ月)**
4. 商品審査(ソースコードチェック2〜3営業日 + フォワードテスト:2トレード終了かつ2週間経過後)
5. 掲載開始

### 実施手順

1. フォーム内の「**トレードの公開方法について**」および
   「**Real-Tradeの設定マニュアルはこちら**」のリンクを開く
2. マニュアルに従って RealTrade アカウントを作成し、MT5口座を連携
3. その口座で ChienMondayYen v3.10 を **USD/JPY・GBP/JPY・EUR/JPY の3チャート**で稼働
4. 発行された **RealTradeアカウントID** をフォームに入力

### 注意

- **デモ口座でも可**とされています。リアル資金は不要です
- 本EAは**週1回しか取引しません**。3ペアで週3トレードのため、
  「2トレード終了」の条件は1週間で満たせますが、
  RealTrade審査の1ヶ月は待つ必要があります
- **VPSまたは常時起動PCが必須**です(月曜4時・翌2時に自動稼働するため)

## 2. バックテストHTMLファイル(必須)

どの画像を①〜④に割り当てるかは、レポートを見てから一緒に決めましょう。
