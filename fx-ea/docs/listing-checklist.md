# B. あなたの作業(必須)

## B1. RealTrade の設定とトレード公開 ★最優先

**これが最長の待ち時間を生むので、他より先に着手する。**

| 手順 | 内容 |
|---|---|
| 1 | 登録フォーム内の「Real-Tradeの設定マニュアルはこちら」を開く |
| 2 | マニュアルに従いRealTradeアカウントを作成、MT5口座を連携 |
| 3 | その口座で v3.10 を **USDJPY・GBPJPY・EURJPY の3チャート**で稼働 |
| 4 | 発行された **RealTradeアカウントID** を控える(フォームの必須項目) |

- **デモ口座で可。**リアル資金は不要
- **VPSまたは常時起動PCが必須**(月曜4時・翌2時に自動発注するため)
- 審査は約1ヶ月。「取引がない」場合は延期される

## B2. VPS または常時起動PCの用意

B1と同時に必要。EAはサーバー時間の月曜4時と翌営業日2時に動く。
PCが落ちていると発注されず、**RealTrade審査が「取引なし」で延期される。**

## B3. バックテストHTML(3ペア分)

MT5ストラテジーテスターで下記設定にて実行し、
「バックテスト」タブ右クリック →「レポート」でHTML保存。

| 項目 | 値 |
|---|---|
| EA | ChienMondayYen_v310 |
| 銘柄 | USDJPY / GBPJPY / EURJPY(3回に分けて実行) |
| 期間 | **H1** |
| モデル | 1分足OHLC |
| 日付 | 2016.01.01 – 2026.08.24 |
| 入金 | 10000 / USD / レバレッジ 1:25 |
| リスク | InpRiskPercent = **0.5** |

**保存時にモデリング品質(%)を控えること。** 販売ページに記載する。
品質80%以上なら2年以上、80%未満なら7年以上の期間が必要(今回は10年6ヶ月なので問題なし)。

## B4. 画像ファイル ①〜④

バックテストレポート内のグラフ、またはテスターの「グラフ」タブのスクリーンショット。

- 形式: jpeg / jpg / gif / webp、10MB以下
- **アニメーション画像・派手なバナーは不可**
- どれを①〜④に割り当てるかは、レポートを見てから相談

| 項目 | 選択肢 |

| **EA運用可能会社** | 下記参照 |

### EA運用可能会社の選び方

本EAは**往復2pips以内のスプレッドが前提**。
リストのうち、円クロス3ペアでその条件を満たす会社**だけ**にチェックする。

**全社にチェックしないこと。** スプレッドの広い会社で購入した人が
「動かない」と低評価をつける原因になる。

フォームに「海外の証券会社を推奨する内容はご遠慮ください」の注記があるため、
海外業者名は書かない。

## B6. プロフィール文の空欄を埋める

**未検証の実績や資格は書かないこと。**

# C. 順序

RealTrade審査に約1ヶ月かかるため、**待ち時間の中に他の作業を入れる**のが最短。

```
1日目      B1 RealTrade設定 + B2 VPS稼働開始   ← ここが起点
           B3 バックテストHTML(同日に可能)
           B4 画像作成
           B5 3項目の決定
           B6 プロフィール空欄

1週目      商品ページを作成し mq5 をアップロード
           A2〜A4 の文言をそのまま貼る
           RealTradeアカウントIDを入力して保存

1週目〜    RealTradeでトレードが記録され始める
           (3ペアで週3トレード)

約1ヶ月後  RealTradeトレード結果審査 完了

その後     商品審査
             ソースコードチェック  2〜3営業日
             フォワードテスト      2トレード終了 かつ 2週間経過

           掲載開始
```

**最短でも約1.5ヶ月。** RealTrade審査の1ヶ月は短縮できない。

# D. 確認しておくとよいこと

RealTrade審査の不合格要因として記載されているのは「**取引がない**」であり、
損失そのものではない。**1ヶ月の損益で落ちる制度なのか**は問い合わせる価値がある。

ここが確認できれば、「1ヶ月の成績がぶれる」という懸念の前提そのものが変わる。
