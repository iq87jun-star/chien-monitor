# B. あなたの作業(必須)

## B1. RealTrade の設定とトレード公開 ★最優先

**これが最長の待ち時間を生むので、他より先に着手する。**

| 手順 | 内容 |
|---|---|
| 1 | 登録フォーム内の「Real-Tradeの設定マニュアルはこちら」を開く |
| 2 | マニュアルに従いRealTradeアカウントを作成、MT5口座を連携 |
| 3 | その口座で v3.10 を **USDJPY・GBPJPY・EURJPY の3チャート**で稼働 |
| 4 | 発行された **RealTradeアカウントID** を控える(フォームの必須項目) |

- **デモ口座で可。**リアル資金は不要
- **VPSまたは常時起動PCが必須**(月曜4時・翌2時に自動発注するため)
- 審査は約1ヶ月。「取引がない」場合は延期される

## B2. VPS または常時起動PCの用意

B1と同時に必要。EAはサーバー時間の月曜4時と翌営業日2時に動く。
PCが落ちていると発注されず、**RealTrade審査が「取引なし」で延期される。**

## B3. バックテストHTML(**提出は1ペアのみで可**)

MT5ストラテジーテスターで下記設定にて実行し、
「バックテスト」タブ右クリック →「レポート」でHTML保存。

| 項目 | 値 |
|---|---|
| EA | ChienMondayYen_v310 |
| 銘柄 | **提出は USDJPY 1本で可**(運営確認済み)。ただし3ペアとも回すことを推奨 |
| 期間 | **H1** |
| モデル | 1分足OHLC |
| 日付 | 2016.01.01 – 2026.08.24 |
| 入金 | 10000 / USD / レバレッジ 1:25 |
| リスク | InpRiskPercent = **0.5** |

**保存時にモデリング品質(%)を控えること。** 販売ページに記載する。
品質80%以上なら2年以上、80%未満なら7年以上の期間が必要(今回は10年6ヶ月なので問題なし)。

**審査への提出は代表1ペアで足りる**が、3ペアとも回すことを推奨する理由:
- 画像①〜④の素材が必要
- 販売ページは3ペア合成の数値を掲げているため、裏付けを手元に持っておく
- 1ペアあたり40分程度

# C. 順序(運営回答により確定)

**RealTradeの設定・トレード公開が先。商品ページ作成は後。**(運営確認済み)

```
1日目      B1 RealTrade設定 → MT5口座を連携
           B2 VPS稼働開始、3チャートでEA稼働
           B3 バックテストHTML(1ペアで可)
           B4 画像 / B5 決定 / B6 プロフィール

           ↓ RealTradeアカウントID が発行される

数日以内   商品ページを作成
           mq5 をアップロード(ex5 は不要)
           A2〜A4 の文言を貼る
           RealTradeアカウントID を入力

1週目〜    RealTradeにトレードが記録され始める(3ペアで週3回)

約1ヶ月後  RealTradeトレード結果審査 完了
           判定は「取引の存在」が中心。ただし著しい損益マイナスは見られる

その後     商品審査
             ソースコードチェック  2〜3営業日
             フォワードテスト      2トレード終了(3チャート合計)かつ2週間経過
             → 壱は週3回なので、実質「2週間」が律速

           掲載開始
```

**最短で約1.5ヶ月。** RealTrade審査の1ヶ月は短縮できない。

## ★RealTrade稼働中のリスク設定について

運営回答: 審査は「**存在することが中心となりますが、著しい損益のマイナスも拝見します**」

したがって:

- **リスクは既定の 0.5% のまま動かすこと。**審査を通したいからと下げる必要も、
  見栄えのために上げる必要もない
- 販売ページが掲げる設定と、RealTradeで公開する設定を**一致させる**。
  公開実績と商品説明が食い違うと、審査でもレビューでも不利になる
- 壱は全期間10年6ヶ月で最大DD 3.06%(リスク0.5%・3ペア)。
  1ヶ月で「著しいマイナス」に至る設計ではない
