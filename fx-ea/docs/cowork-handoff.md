## プロンプト①: コンパイル & バックテスト(最初に Cowork へ貼る)

```
FX自動売買EA「Chien Trend Rider」のコンパイルとバックテストをお願いします。

【ソースの場所】
GitHubリポジトリ iq87jun-star/chien-monitor の
ブランチ claude/fx-ea-development-sales-bv3ub1 内:
- fx-ea/MQL5/ChienTrendRider.mq5(MT5用)
- fx-ea/MQL4/ChienTrendRider.mq4(MT4用)
リポジトリにアクセスできない場合は私に言ってください。ファイルを渡します。

【手順】
1. PCにインストール済みのMT5(あればMT4も)のデータフォルダを開き、
   MQL5/Experts(MT4はMQL4/Experts)にソースを配置してMetaEditorでコンパイル。
   エラーが出たらエラーメッセージ全文を報告して停止してください(勝手に修正しない)。
2. MT5ストラテジーテスターでバックテストを実行:
   - 通貨ペア: USDJPY と GBPJPY の2通り(10年検証で選定した推奨ペア)
   - 時間足: H1、モデル: 「実際のティックに基づいたすべてのティック」
   - 期間: カスタムで 2016.01.01〜現在(取れる最長)
   - 初期証拠金: 100万円(口座通貨に合わせて調整可)、レバレッジ25倍
   - パラメータ: すべて既定値のまま
   - 初回はティック履歴の自動ダウンロードが走ります(数GB・時間がかかる)。
     ディスク空きが10GB未満なら停止して報告してください。
   - 接続中の口座のティック履歴が浅くて2016年まで届かない場合は、
     MT5からMetaQuotes-Demo口座を新規開設して再実行。それでも届かない
     期間が残る場合は「1分足OHLCに基づいたすべてのティック」モードで
     全期間を実行し、使用モデル名を報告に明記してください。
3. 各テストのレポート(HTML)と損益グラフのスクリーンショットを
   デスクトップの「ChienTrendRider_backtest」フォルダに保存。
4. 結果の要約(通貨ペアごとの純益、プロフィットファクター、勝率、
   最大ドローダウン%、総取引数、**ヒストリー品質%と使用モデル名**)を
   表で報告してください。ヒストリー品質が90%未満の期間があれば
   その旨も添えてください。

【禁止事項】
- パラメータの最適化や変更はまだしない(まず既定値の素の成績を見る)
- 取引口座への接続・リアル発注は絶対にしない(テスターのみ)
```

  現れる場合があります。その場合はセッション間で直接連携できます
  (このリモートセッションの宛先名: `chien-monitor-a7`)。

  接続するのが理想です。デモ口座でのフォワード開始もプロンプト①の後に
  Cowork へ依頼できます。

## トラブルシューティング(実機で発生した事例)

### 症状: テスターが「アップデート待機中」のまま進まない

操作ログに次のエラーが出ている場合、ティック履歴のダウンロードが停止している:

```
Ticks | USDJPY: received too many containers without changes [51]
```

**原因**: MetaQuotes-Demo を含む多くのサーバーは 2016 年まで遡る実ティックを
保有していない。実ティックモードは無い履歴を生成できないため、要求が空振り
し続けてテスターがデータ待ちで固まる。待っても解決しない。

**対処**:

1. モデルを「**1分足OHLCに基づいたすべてのティック**」に変更して再実行する。
   本 EA はエントリー判定が足確定時のみ、決済も SL/TP 到達のため、ティック
   精度への感応度が低く、このモードで十分な信頼性がある。レポートにモデル名が
   記載されるので、販売ページにもそのまま明記すること。
2. **ビジュアルモードのチェックを外す**。レポート作成には不要で、10年分の
   テストでは速度が段違いになる。
3. 実ティックが必要な場合は期間を短くする(例: 2022.01.01〜現在)。
   1分足OHLCモードで10年分の全体像を取り、短期間の実ティックを補足として
   別途撮る二段構えが現実的。

### チェック: エキスパート欄にEAが入っているか

テスター設定の EA 指定欄が「インディケータ」表示になっている場合、
インディケータ検証モードになっている可能性がある。この状態では取引が
一切発生せず残高が動かない。ex5 が `MQL5/Experts` フォルダにあること、
テスターが「エキスパート」として EA を指定していることを確認する。

### 注意: テスターは前回のパラメータを保存している

EA を再コンパイルしても、ストラテジーテスターは**前回使ったパラメータセットを
保持したまま**で、新しい既定値に自動更新されない。バージョンを上げた EA を
テストするときは、必ず「パラメータ」タブの値を目視確認すること。

見分け方: 1トレードあたりの損失額が想定リスク%と合っているかを
レポートで確認する(例: 残高10,000で0.5%リスクなら損失は約50、
1%のままなら約100になる)。

**リセット方法**:

- 方法A: 「パラメータ」タブで該当パラメータを手入力する
- 方法B: データフォルダの `MQL5\Profiles\Tester\<EA名>.set` を削除して
  テスターを開き直す(EA の既定値が読み直される)

また、EA を入れ替えると「設定」タブの日付範囲がリセットされることがある。
実行前に期間・銘柄・時間足・モデル・ビジュアルモードもあわせて確認する。
