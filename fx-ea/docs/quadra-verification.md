# 定石 弐(QuadraReversal)MT5 検証手順

対象: `MQL5/ChienQuadraReversal_v320.mq5`(検証専用・マルチシンボル)
作成日: 2026-08-26

---

## なぜ専用ビルドを作ったか

壱(MondayYen)は3ペアを**個別に**テストして結果を合成した。同時建玉が
ほとんど起きない設計(週1回・同時刻)なので、それで実態と一致した。

弐は違う。4条件はいずれも「行き過ぎた動き」を表すため、**リスクオフ日に
全ドルペアで同時に成立しうる**。7ペアを個別にテストして足し合わせると、
同時建玉を一度も計上しないため**ドローダウンを過小評価する**。

v3.20 は7ペア全部を1チャートから発注する。**1回のテストで実際の合計DDが出る。**

リスクは 0.5%/取引 に固定してある。壱の検証と同じ基準なので、
2商品を合成したときの数値がそのまま出せる。

---

## 手順

### 1. コンパイル

`ChienQuadraReversal_v320.mq5` を **`MQL5\Experts`** に置いて
MetaEditor でコンパイル。`Indicators` に置くとテスターのEA一覧に出ない。

### 2. 気配値表示に7ペアを出す

MT5の「気配値表示」で右クリック →「すべて表示」、または個別に追加:

```
USDJPY  EURJPY  GBPJPY  GBPUSD  AUDUSD  USDCAD  USDCHF
```

**これをやらないと、EAが銘柄を解決できず取引数がゼロになる。**

### 3. ストラテジーテスターの設定

| 項目 | 値 |
|---|---|
| エキスパート | ChienQuadraReversal_v320 |
| 銘柄 | **USDJPY**(どれでもよいが、これで統一) |
| 期間 | **H1** |
| モデル | **1分足OHLC**(実際のティックでも可・時間はかかる) |
| 日付 | **2016.01.01 – 2026.08.24**(壱と同じ) |
| 入金 | **10000** |
| 通貨 | USD |
| レバレッジ | **1:25** |

パラメータタブは**触らない**。戦略の値はすべてコンパイル時定数で、
保存済みパラメータセットでは上書きできない。

### 4. 起動ログを必ず確認する

「エキスパート」タブの冒頭に次が出る:

```
QuadraReversal v3.20-MULTI-FIXED  (settings are compiled in)
Signal  : ALL 4 of  RSI(14)<35 / |z(20)|>1.5 / run>=3 / move>0.5%
Entry   : next trading day at 02:00 server time
Exits   : SL=dailyATR(14) x 1.5   TP=SL x 1.2   time exit 8 bars
Risk    : 0.50% of balance per trade, cap 10.00 lots
Symbols : 7 of 7 resolved
          USDJPY, EURJPY, GBPJPY, GBPUSD, AUDUSD, USDCAD, USDCHF
```

**`Symbols : 7 of 7 resolved` でなければ、そこで止めて連絡してください。**
業者が接尾辞を付けている場合は `[symbol] USDJPY -> USDJPY.a` のような行が出る。
これは正常。

終了時には銘柄別のシグナル数が出る:

```
[signals] USDJPY   62
[signals] EURJPY   58
...
[signals] TOTAL    435
```

## 期待値(シミュレーション予測)

開発時のシミュレーション(MT5実バー・実スプレッド・片道1pipスリッページ)の値。
**MT5実測がこれに近ければ検証成功、大きく外れれば実装かデータの問題。**

### 全体

| 指標 | 予測 |
|---|---|
| 取引数 | **420 〜 470**(シミュ 435) |
| PF | **1.35 〜 1.45**(シミュ 1.414〜1.435) |
| 勝率 | 52 〜 56%(シミュ 53.8%) |
| 負け年 | 0 〜 2 年(シミュ 0/11) |
| 最大DD | **未確定 — このテストで初めて測る** |

### ペア別 PF(シミュ)

| ペア | 予測PF |
|---|---|
| USDCAD | 1.99 |
| GBPUSD | 1.79 |
| USDJPY | 1.33 |
| AUDUSD | 1.33 |
| EURJPY | 1.32 |
| GBPJPY | 1.31 |
| USDCHF | 1.25 |

### 判定基準

壱では予測PF 1.270/1.348/1.393 に対し実測 1.263/1.291/1.354 で、
**乖離は 0.01〜0.06** だった。これが健全な範囲。

| 実測PF | 判定 |
|---|---|
| 1.30 〜 1.50 | ○ 予測どおり。販売ページに実測値を採用 |
| 1.20 〜 1.30 | △ 要因分析。コスト前提が甘かった可能性 |
| 1.20未満 | × 不採用。壱のみで進める |
| 1.55超 | × 疑う。約定が楽観的すぎる可能性 |

取引数が **300を切ったら実装の問題**(銘柄解決・エントリー時刻)。
`[signals] TOTAL` と実際の取引数を突き合わせること。

### 最大DDについて

シミュには DD 2.2% の記録があるが、**リスク基準が不明**なため採用しない。
今回のテストが 0.5%/取引・7ペア同時での**唯一の正しい数値**になる。

参考: 壱は 0.5%/チャート・3ペアで 直近5年 DD 1.44%、全期間 DD 3.06%。
弐は7ペアが同時に建つ可能性があるため、**壱より大きく出る想定**。

## テスト後にやること

1. 「バックテスト」タブを右クリック →「レポート」で HTML 保存
2. **モデリング品質(%)** を確認
3. 結果を共有 → 販売ページと商品登録フォームの数値を確定

## 販売ビルドとの関係

- 検証: `ChienQuadraReversal_v320.mq5`(7ペア・1チャート・リスク0.5%固定)
- 販売: `ChienQuadraReversal_v310.mq5`(1ペア・1チャート・ロット調整可)

購入者は v3.10 を**7チャートに載せる**。v3.20 が測る DD は、
その構成をリスク0.5%で動かしたときの値と一致する。

GogoJungle は「ロット設定できないEA」を出品不可としているため、
**販売するのは v3.10**。v3.20 は数値を確定させるためだけのもの。

## 留意点(先に把握しておくこと)

**取引頻度が低い。** 435取引 ÷ 10.6年 ÷ 7ペア = **1ペアあたり年約6回**。
7ペア合計でも月約3.4回。GogoJungle の商品審査は「2トレード終了かつ2週間経過」
が条件なので、**フォワードテストに3〜4週間かかる可能性がある**。
RealTrade審査(約1ヶ月)と並行させれば全体の遅延にはならない見込み。
