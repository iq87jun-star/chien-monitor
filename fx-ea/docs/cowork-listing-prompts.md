# Cowork に貼るプロンプト(商品登録・プロフィール記入)

**共通の前提**

- ブラウザ操作はすべて Cowork(あなたのPC・ログイン済みセッション)が担当
- **「販売開始」「保存して公開」等の確定ボタンは、あなた本人が押す**
- **個人情報(氏名・住所・電話・口座情報・本人確認書類)は入力しない**

---

# プロンプト①: 出品者プロフィールの記入

```
GogoJungleの出品者プロフィールを記入してください。保存はしますが、
公開の確定操作はしないでください。

【入力内容の場所】
GitHubリポジトリ iq87jun-star/chien-monitor
ブランチ claude/fx-ea-development-sales-bv3ub1 の
  fx-ea/docs/seller-profile-draft.md
の「そのまま貼れる最終版(プレースホルダーなし)」の節を使ってください。

リポジトリにアクセスできない場合は言ってください。内容を直接渡します。

【手順】
1. マイページ → 出品者情報 / プロフィール編集 を開く
2. 表示名に「定石ラボ」を入力
3. プロフィール本文に、上記ファイルの「プロフィール本文(コピー用)」の
   コードブロック内を、改行を保ったまま貼り付ける
4. 文字数制限で入りきらない場合は、勝手に要約せず、
   冒頭2段落 +「採用しなかった手法」1つ + 末尾2段落 に絞ってください
   (どの部分を残したか報告してください)
5. 箇条書きの「・」が使えない場合は「-」に置換して構いません
6. 保存して停止し、入力後の画面を報告してください

【守ってほしいこと】
- 氏名・住所・電話番号・生年月日・口座情報は入力しない
- プロフィール画像のアップロードはまだ行わない(別途決定します)
- 本文を独自に言い換えたり、実績や資格を足したりしない。
  書かれている内容がすべてです
- 本文に出てくる「採用しなかった手法」は自分たちが検証して落とした
  自分の手法です。他社商品への言及ではないので、そう読める表現に
  書き換えないでください
```

【守ってほしいこと】
- 「販売開始」ボタンは押さない。本人が内容を確認してから押します
- 氏名・住所・電話番号・口座情報などの個人情報は入力しない
- FORM-kankyokei.md に書かれていない必須項目が出てきたら、
