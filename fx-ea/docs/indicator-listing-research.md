# 調査: インジケーター出品の審査基準(EAとの比較)

調査日: 2026-08-27 / 出典は GogoJungle 公式FAQ・出品マニュアル

---

## 結論: インジケーターの審査はEAと別物で、はるかに軽い

| | EA(システムトレード) | **インジケーター** |
|---|---|---|
| RealTrade公開 | **必須**(アカウントID必須項目) | **記載なし** |
| RealTrade審査 | **約1ヶ月** | **記載なし** |
| バックテスト提出 | 必須(StrategyTester.HTM等) | **記載なし** |
| フォワードテスト | 必須(2トレード+2週間) | **記載なし** |
| ソースコード提出 | **必須**(MQ4/5・DLL含む) | **不要**(ex4/ex5のみ) |
| 出品数上限 | **月3個** | 記載なし |
| 販売手数料 | — | 売切15% / 月額20% |

**公式の一次情報(FAQ 405・出品マニュアル)のいずれにも、インジケーターに対する
RealTrade・バックテスト・フォワードテストの要件は記載がない。**

## インジケーターに必要なもの

| 項目 | 内容 |
|---|---|
| 商品ファイル | **ex4 / ex5(コンパイル済み)**。ソースコード提出は不要 |
| Web認証を使う場合 | mq4にWeb認証コードを挿入してコンパイル、**zip直下にex4を置く** |
| Web認証を使わない場合 | zip / rar / lzh で圧縮してアップロード |
| 商品バナー | 必要 |
| 商品概要 | HTML可。画像での説明が推奨されている |

## インジケーターの審査対象は限定的

FAQ 405 に「一定の審査がございます」とあり、対象として挙がっているのは:

1. **決済や発注に人手がかかわる自動売買機能を持つインジケータ**
2. **月額利用料設定のあるインジケータ**(有期は審査後に出品可能な場合あり)
   - **無期限の月額利用料設定は出品お断り**

つまり、**シグナル表示のみの通常のインジケーターは、これらに該当しない。**

## EAとインジケーターの境界

FAQ 405 の記載:

> 自動売買でも決済や発注において人出がかかわるものの出品であれば、
> インジケータのカテゴリでの販売は可能

**発注・決済に人の手が入るなら「インジケーター」カテゴリで出せる。**
完全自動 = EA、半自動 = インジケーター、という切り分け。

## インジケーター vs 電子書籍

違いは **Web認証プログラムの有無だけ**。

Web認証を組み込むと、購入者はリアル・デモ問わず**1口座でしか使えなくなる**。
電子書籍カテゴリにはこの制限機能がない。

# 副産物: EA側の出品条件(FAQ 281)— 要注意

インジケーターを調べる過程で、**EA出品で避けるべき条件**が明文化されているのを発見した。

> 以下のようなEAは出品を控えてください
> - **取引回数が著しく少ないもの**
> - 特定の会社や取引コースに限定されるもの
> - 初期パラメーター変更が前提のもの
> - 初期設定で100万円/1万ドルを超える証拠金想定
> - 外部サーバーAPI利用
> - 意図的なエラー表示
> - 検証目的のみの出品

## 弊方の商品への影響

| 条件 | 定石 壱 | 定石 弐 |
|---|---|---|
| **取引回数が著しく少ない** | 3ペアで**年156回**(1チャート年52回) | **年41回**(1ペア年約6回)**← 該当リスク高** |
| 特定の会社に限定 | 往復2pips条件の書き方次第で該当しうる | 同左 |
| 初期パラメーター変更が前提 | 既定0.5%で動く。該当しない | 同左 |
| 証拠金100万円超の想定 | **60万円**。該当しない | 未確定(MT5実測待ち) |
| 外部API・DLL | 不使用。該当しない | 同左 |

**弐は「取引回数が著しく少ない」に該当する可能性が高い。**
1ペアあたり年6回は、審査上の懸念になりうる。MT5実測の前に把握しておくべき点。

壱は年156回なので極端ではないが、1チャート単位では週1回である旨を
商品概要で明確に説明しておく必要がある(既に記載済み)。

## EA出品数の上限

> EA設置リソースの関係上、1か月単位で上限を設けております
> 基本的には**1か月単位で3個まで**
> 直近1か月のEA販売額が多い出品者様については上限を緩和いたしますので、ご相談ください

**複数商品を並行させる計画は、月3本が上限。**

# 戦略的な意味

インジケーターは **RealTradeの1ヶ月審査を経ずに出品できる可能性が高い**。

これが正しければ:

- **壱のRealTrade審査(約1ヶ月)を待つ間に、インジケーターを先に出品できる**
- 出品者としての実績・レビューを先に作れる
- 手数料は売切15%

ただし注意:

- **自社EAと同じシグナルを出すインジケーターは、EAの売上を食う**
- 出す場合は、EAの下位互換ではなく別の切り口にする必要がある
- 上記は公式FAQに「記載がない」ことの確認であり、
  **「不要である」と明記されているわけではない。問い合わせで確定させること**
