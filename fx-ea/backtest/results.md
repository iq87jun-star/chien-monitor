# 検証結果サマリー(2026-08-25 実施)

## データ

ユーザー提供の H1 OHLC データ(2016-01 〜 2025-12、約10年、各約62,000本):
USDJPY / EURJPY / GBPJPY。
バーベースのシミュレーション(`sweep.py` / `robust.py`)で検証。
ティック内の SL/TP 同時ヒットは **SL 優先(悲観側)**、
トレーリング更新は足確定時のみ(実運用よりやや不利な近似)。
スプレッドは USDJPY 0.4pips / EURJPY 0.6pips / GBPJPY 1.2pips 固定。
リスクは 1 トレードあたり残高の 1%(複利)。

## 結論

| 項目 | 内容 |
|---|---|
| 採用ロジック | **H1 ドンチャン(20)ブレイクアウト + EMA50/200 トレンドフィルター** |
| 決済 | SL=ATR×2.0 / TP=ATR×3.0 + ブレークイーブン + ATR×2.0 トレーリング(v1.00 と同一) |
| 不採用 | RSI 押し目回復エントリー(旧既定)は全ペアで PF 1 未満のため既定から降格(オプションとして残置) |
| 推奨ペア | **USDJPY・GBPJPY**(EURJPY は PF 1.04 と限界的、スプレッド増で赤字化するため非推奨) |

## 頑健性

- ドンチャン期間 10/15/20/25/30/40 のすべてで USDJPY・GBPJPY は PF ≥ 1.12
- スプレッド2倍ストレス: USDJPY PF 1.14 / GBPJPY PF 1.12 で黒字維持
- SL/TP 倍率(1.5〜3.0 / 2.25〜4.5)を振っても USDJPY・GBPJPY は全構成黒字
- 年次: USDJPY・GBPJPY とも負け年 3/10(最大の負け年 USDJPY 2018 -19.8%、
  GBPJPY 2025 -14.7%)
