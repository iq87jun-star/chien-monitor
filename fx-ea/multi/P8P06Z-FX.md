## 2. RecentFit5 の5スリーブ ─ EA本体が自己申告している成績

`mql5/Chien_RecentFit5_EA.mq5` のヘッダに、選抜窓(FIT)と
参考期間(REF)の両方が記載されている。**これが最も価値のある情報。**

| スリーブ | 内容 | FIT PF | REF PF | 評価 |
|---|---|--:|--:|---|
| S1 | GBPUSD 月曜00UTC LONG 12h | 3.38 | **1.59** | 参考期間でも生存 |
| S2 | GBPJPY 月曜08UTC LONG 12h | 2.79 | **1.99** | 参考期間でも生存 |
| **S3** | **USDCHF 木曜16UTC SHORT 6h** | 2.58 | **2.15** | **最も堅い。FIT≒REF** |
| S4 | GBPUSD D1 RSI(2) 30/70 逆張り 5日 | 2.98 | **0.71** | **参考期間で崩壊** |
| S5 | GBPJPY D1 RSI(2) 20/80 逆張り 3日 | 2.66 | **1.00** | **参考期間でゼロ** |

EAヘッダの自己記述:

> S4/S5は前年マイナス〜フラット=**純粋な直近レジームベット**。

**作成者自身が S4/S5 を「直近へのベット」と明記している。**
本会話で測った「短い窓での選抜は翌期に持たない」という結果と一致する。

### S3 が唯一の候補

FIT 2.58 に対し REF 2.15。**選抜窓と参考期間の差が最も小さい。**
S1/S2 は Mon 族(=壱)の時刻違いだが、S3 は別物である。

ただし本セッションでは検証できない:

- 6時間保有・16UTC建玉のため、**日足データでは再現できない**
- USDCHF の MT5 H1 実データが手元にない
- 選抜対象の全セル数が不明のため、**多重検定の規模が評価できない**

商品化を検討するなら、USDCHF の H1 実データで壱・弐と同じ手順
(全期間・IS/OOS・コスト控除)を通す必要がある。

## 3. ポートフォリオの数字の読み方

`research/results/recentfit_portfolio_compare.json` の値。

| 案 | cum_12m | cagr_full | Sharpe 12m | 倍率 |
|---|--:|--:|--:|--:|
| A案 RecentFit5 | 28.55% | 2.02% | 2.77 | 4.8x |
| B案 2026H2 | 27.95% | 8.98% | 5.84 | 4.0x |
| C案 6ヶ月 | 33.99% | 15.25% | 4.19 | 6.0x |
| **D案 3ヶ月** | **8.44%** | 7.21% | **1.43** | 5.52x |
| 非FX新案 | 42.61% | 4.63% | 2.76 | 1.56x |

### 注意すべき点

**① これは実口座成績ではない。** meta が自ら明記している。

> "Yahoo日足近似・実口座成績ではない"
> "S1/S2/Mon=月曜o2o(実EAは12h)" ← 近似
> "S4/S5=RSI2逆張りD1再現" ← 近似

**② 4〜6倍のレバレッジがかかっている。**
B案の cagr_full 8.98% は 4.0x での値。無レバレッジ換算では約2.2%/年。
本会話で実測した壱の年率2.87%(リスク0.5%)と同じ水準。

**③ cum_12m と cagr_full の乖離が大きい。**
12ヶ月で25〜42%に対し、全期間CAGRは2〜15%。
直近の窓が良く見えているだけの可能性がある。

**④ 選抜窓が最も短いD案が、12ヶ月成績で最下位。**
3ヶ月選抜のD案は cum_12m 8.44% / Sharpe 1.43 で、
6ヶ月選抜のC案(33.99% / 4.19)を大きく下回る。

本会話の追検証(`multi/RESULTS.md`)で得た
「選抜窓が長いほど翌年成績が良い(3年 t1.07 / 5年 t1.00 / 10年 t1.40)」
と同じ方向の結果が、別データ・別手法でも出ている。

## 4. 選抜そのものの性質

再スクリーニングの meta:

```

conf = 2026-07-21   (確認窓)
w12  = 2025-09-01   (12ヶ月窓)
```

採用された4セル:

| セル | cum_sel | cum_12m | 備考 |
|---|--:|--:|---|
| v4_GBPJPY | 2.20 | 2.00 | 一貫 |
| **Mon_USDJPY** | 1.78 | **−1.40** | **12ヶ月はマイナスだが採用** |
| Mon_EURJPY | 0.93 | 2.82 | |
| Hold_GER40 | 4.44 | 9.20 | 非FX |

**Mon_USDJPY は直近12ヶ月がマイナスなのに、3ヶ月窓の成績で採用されている。**
これが「直近特化=EVベット」の設計であり、prop用としては
一貫しているが、販売商品の根拠には使えない。

## 5. 商品化への示唆

| 対象 | 判断 |
|---|---|
| Mon 族 | **定石 壱 として商品化済み。**追加なし |
| v4 族 | **定石 弐 として商品化済み。**追加なし |
| S4/S5(RSI2逆張り) | **不可。**REF PF 0.71 / 1.00 で参考期間に崩壊 |
| S1/S2(時刻指定の月曜) | 壱の変種。別商品にはならない |
| **S3(USDCHF 木曜16UTC ショート6h)** | **唯一の候補。要MT5 H1検証** |

S3 を検証するには USDCHF の H1 実データ(2016年以降)が必要。
壱・弐と同じ手順で測り、PF・IS/OOS・コスト耐性を確認してからでないと
商品化の判断はできない。
