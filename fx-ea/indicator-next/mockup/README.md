商品ページに「実際の画面」として掲載しないこと。

|---|---|
| `mock-01-quiet.png` | 静穏度 0.72 倍 ─ 直近が平年より静かな局面 |

生成:

```
python3 gen.py
```

平均)。図と数字が食い違わないようにするため。文言は
