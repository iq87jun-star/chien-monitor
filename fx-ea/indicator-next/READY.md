## 環境計との関係

重複する表示は「想定変動幅」だけです。

| | 定石 零 ─ 環境計 | 定石 参 ─ 値幅計 |
|---|---|---|
| 答える問い | いま入ってよいコストか | どれだけ動きそうか |
| 中心 | スプレッドの時間帯別割高度 | 値幅の予測と自己採点 |
| 精度の主張 | しない | **する(20銘柄15年の実測)** |

商品概要に「両方を買う必要はない。どちらか一方で足りる」と明記してあります。
**これは意図的です。** 重複を隠して2本売ると、レビューで必ず指摘されます。

出す順番は、環境計 → 待ち伏せ → 値幅計 を推奨します。
値幅計は精度の主張がある分、レビューでの検証圧が高くなります。
実績とレビューがいくらか付いてからのほうが安全です。

および範囲の被覆率 FX 77.3% / 指数 76.2% / 最低 75.4%)は


**手で数値を書き換えないこと。** 出荷するコードが出していない数字を
販売ページに載せないための仕組みです。
