# 撮影用スクリプト

## 定石_画像保存 — チャートだけを画像として保存する

Windowsの画面キャプチャと違い、**タイトルバー(口座番号・業者名)・タスクバー・
受信トレイ・気配値表示が写りません。**チャート領域だけが保存されます。
トリミングも不要です。

### 置き場所

| ファイル | 置く場所 |
|---|---|
| `定石_画像保存.mq5` | `MQL5\Scripts` |
| `定石_画像保存.mq4` | `MQL4\Scripts` |

**Indicators ではなく Scripts です。**

### 使い方

1. MetaEditor でコンパイル(F7)
2. ナビゲータの「スクリプト」から、撮りたいチャートに**ドラッグ**
3. 大きさを聞かれるので、そのままOK(既定 1600 × 1000)
4. 保存先がアラートで出ます

### 保存先の開き方

MT5/MT4 の **ファイル → データフォルダを開く → MQL5(MQL4) → Files**

ファイル名は `chien_GBPJPY_M15_20260828_022100.png` のようになります。

### 設定

| 項目 | 既定 | 説明 |
|---|---|---|
| 横幅 | 1600 | 商品ページ用なら1280〜1920が扱いやすい |
| 高さ | 1000 | |
| ファイル名の先頭 | chien | |
| 銘柄・時間足・日時を入れる | true | 4枚撮っても取り違えません |

### 撮る前のひと手間

パネルが小さく写ると読めません。次のいずれかで大きくできます。

- インジケーターの設定で **文字サイズ**(既定9)を 11〜12 に上げる
- 出力の大きさを 1280×800 くらいに下げる(相対的にパネルが大きくなる)

**商品ページで一番大事なのはパネルが読めることです。**
チャートの本数は少なくて構いません。

## 撮る4枚

| # | 内容 | 銘柄・条件 |
|---|---|---|
| ① | 判定 ○ コスト条件は良好 | USDJPY H1 の通常時間帯 |
| ② | 判定 △ または × | **GBPJPY の0時前後**(中央値5.0pipsなので跳ねやすい) |
| ③ | 時間帯別一覧 | GBPJPY。**0時5.0 vs 他0.5の対比が主役** |
| ④ | 待ち伏せの待機中パネル | v1.01 に差し替えてから |

②と③は同じ画面で構いません。

---

## 2つを同じチャートに載せる場合

**既定ではどちらも左上に出るため重なります。** 位置をずらしてください。

| インジケーター | 設定 | 値 |
|---|---|---|
| 定石 零 環境計 | パネルの位置 | **右上** |
| 定石 弐 待ち伏せ | パネルの位置 | 左上(既定のまま) |

環境計は `InpCorner`、待ち伏せは `InpPanelCorner` で四隅から選べます。

### ただし商品ページの撮影では分けてください

**1商品につき1画面**です。両方写っていると、購入者が
「2つ付いてくる」と誤解します。
