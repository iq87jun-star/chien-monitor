## インストール

**MT5の場合**

1. MetaEditor で `ChienQuadraSignal.mq5` を開き、コンパイルします
2. できあがった ex5 を `MQL5\Indicators` に置きます
3. MT5を再起動するか、ナビゲータを右クリックして「更新」します
4. ナビゲータの「インディケータ」から、チャートにドラッグします

**MT4の場合**

1. MetaEditor で `ChienQuadraSignal.mq4` を開き、コンパイルします
2. できあがった ex4 を `MQL4\Indicators` に置きます
3. 以下同じです

※ コンパイル済みファイルが同梱されている場合は、1と2を飛ばして
ファイルを所定のフォルダに置くだけで使えます。

## この道具の性格

**年に数回しか鳴りません。**

1通貨ペアあたり、シグナルが出るのは年に数回です。
ほとんどの日は何も起きません。それが設計です。

**鳴らない日が続くことを、不具合と思わないでください。**
4つの条件がすべて揃うのは、それだけ稀な場面だからです。

複数の通貨ペアで並行して監視することを前提としています。
7ペア程度に入れておくと、月に数回は何かが動きます。

## 画面の読み方

### 条件パネル

```
定石 弐 ─ 待ち伏せ
GBPJPY  日足で判定中

買い方向の条件
  ● RSI       RSI(14) < 35
  ● 標準偏差   平均から 1.5 SD 以上
  ○ 連続本数   3本以上の連続陰線
  ● 当日変動   当日 0.5% 超の下落

3 / 4 成立 — 待機中
  4つすべてが揃うまで動きません
```

**● が成立、○ が未成立**です。

上の例では「あと連続陰線が1本増えれば揃う」状態だと分かります。
**明日どうなれば揃うのかが見えることが、この道具の中心**です。

パネルは常に**直近の確定した日足**を判定しています。
当日の途中経過ではありません。

### 買い方向と売り方向の切り替え

パネルは、成立数の多い側を自動で表示します。
買い側が2つ・売り側が0なら買い方向を、逆なら売り方向を出します。

### シグナル矢印

4条件がすべて揃うと、翌日のチャートに矢印が出ます。

- **水色の上向き** … 買いシグナル
- **橙色の下向き** … 売りシグナル

矢印は過去の履歴にも表示されます。
チャートを過去にスクロールすると、これまでの発生位置を確認できます。

### 目安ライン

シグナルが出ると、3本の水平線を引きます。

| 線 | 内容 |
|---|---|
| 実線(水色/橙) | 建値の目安 ─ 直近日足の終値 |
| 破線(赤) | 損切りの目安 ─ 日足ATR(14) × 1.5 |
| 破線(緑) | 利確の目安 ─ 損切り幅 × 1.2 |

**目安です。**発注はしません。実際の建値・損切り・利確はご自身で決めてください。

### 通知

4条件が揃うと知らせます。

| 設定 | 内容 |
|---|---|
| 画面にアラートを出す | MT4/MT5の画面にポップアップ |
| スマホにプッシュ通知する | MetaQuotes ID の設定が必要です |
| メールを送る | MT4/MT5のメール設定が必要です |

年に数回のシグナルを見逃さないための機能です。
チャートを開き続ける必要はありません。

**プッシュ通知の設定**
MT5 → ツール → オプション → 通知 → MetaQuotes ID を入力
(IDはスマホのMetaTraderアプリの設定画面で確認できます)

## 4つの条件について

| # | 条件 | 測っているもの |
|---|---|---|
| 1 | RSI(14) が 35 未満 / 65 超 | 相対的な過熱 |
| 2 | 終値が直前20本の平均から1.5標準偏差以上 | 統計的な乖離 |
| 3 | 3本以上の連続陰線 / 陽線 | 流れの持続 |
| 4 | その日の変動が0.5%超 | 勢いの大きさ |

**測っているものが違うからこそ、4つが同時に揃う場面は限られます。**

条件を3つに緩めると検出は一気に増えますが、そこから優位性は失われます。
「4つすべて」というフィルターそのものが中身です。

必要な条件数は設定で変更できますが、**4のまま使うことを前提に作られています。**

## よくあるご質問

**Q. まったく鳴りませんが、壊れていませんか?**
A. おそらく正常です。1通貨ペアあたり年に数回しか鳴りません。
条件パネルに「n / 4 成立」と数字が出ていれば動作しています。

**Q. どの時間足で使えばよいですか?**
A. どの時間足でも動きます。判定は常に日足で行うため、
表示している時間足に結果は左右されません。
日足を表示していると矢印とパネルの対応が分かりやすく、
1時間足を表示していると執行タイミングを計りやすくなります。

**Q. どの通貨ペアに入れればよいですか?**
A. 検証は USDJPY・EURJPY・GBPJPY・GBPUSD・AUDUSD・USDCAD・USDCHF の
7ペアで行っています。頻度が低いため、複数ペアに入れることを想定しています。

**Q. 自動で発注してくれますか?**
A. しません。このインジケーターは検出と通知のみです。
発注・決済はご自身で行ってください。

**Q. 矢印が出た日に入ればよいのですか?**
A. 矢印は「4条件が揃った翌日」に表示されます。
検証では翌営業日の寄り付き前後で建てています。

**Q. 条件を3つに緩めてもよいですか?**
A. 設定で変更はできますが、推奨しません。
検証では、3条件に緩めると損切り・利確の全9通りで優位性が消えました。

**Q. 複数のチャートに入れても大丈夫ですか?**
A. 大丈夫です。チャートごとに独立して動作します。

**Q. 動作が重くなりませんか?**
A. 判定結果は日足が変わるまで再利用するため、毎ティックの再計算はしません。
矢印の描画範囲にも上限を設けています。
