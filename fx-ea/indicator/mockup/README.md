# 表示イメージ図(実測スクリーンショットではない)

`gen.py` で生成した**説明用のイメージ図**。ローソク足も数値も作り物。

## これを何に使ってよいか

| 用途 | 可否 |
|---|---|
| コンパイル前のデザイン確認 | ○ |
| **販売ページの画像として使う** | ○(下記の条件つき) |
| 実際に撮影するときの構図の見本 | ○ |
| **実写のスクリーンショットとして提示する** | **× 不可** |

## 画像に表記を焼き込んである

各画像の右下に次の表記が入っている。**貼るだけで条件を満たす。**

```
表示イメージ ─ 実際の画面とは数値が異なります
```

利用者が毎回キャプションを付ける必要はない。表記ごと切り取らないこと。

## 実物と同じ描画に揃えてある

イメージ図が旧版の見た目のままだと、「表示イメージ」としても不正確になる。
そのため実装に合わせて更新している。

| | 実物 | イメージ図 |
|---|---|---|
| 版表示 | v1.09 | v1.09 |
| 時間帯の棒 | 矩形オブジェクト | 矩形 |
| 現在時刻の印 | 行頭の `> ` | 行頭の `> ` |
| 一覧の既定 | 上位5+現在 | 上位5+現在 |

実装を変えたら、このイメージ図も作り直すこと。

## このイメージ図が見つけた実装の欠陥

初回の生成で、**24行の時間帯一覧がローソク足に重なって読めない**ことが判明した。
実物でも同じことが起きるため、両インジケーターに**背景の下地**
(`OBJ_RECTANGLE_LABEL`)を追加した。

- `InpShowBackdrop` … 下地の表示(既定 true)
- `InpColBackdrop` … 下地の色
- `InpBackdropWidth` / `InpBackdropW` … 下地の幅

下地は文字より先に生成する必要がある(MT5はオブジェクトの作成順に描画するため)。

## 再生成

```
python3 gen.py    # 環境計
python3 gen2.py   # 待ち伏せ
```

ヘッドレスChromiumでHTMLを描画してPNG化する。外部ネットワークは使わない。
