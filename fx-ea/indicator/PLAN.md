## なぜインジケーターが先に出せるのか(調査済み)

| | EA | **インジケーター** |
|---|---|---|
| RealTrade公開・審査 | 必須・約1ヶ月 | **記載なし** |
| バックテスト提出 | 必須 | **記載なし** |
| フォワードテスト | 必須(2トレード+2週間) | **記載なし** |
| ソースコード提出 | 必須 | **不要**(ex4/ex5のみ) |
| 販売開始 | 運営の審査通過後 | **出品者自身が販売開始にする** |

> インジケーターは、出品様ご自身で販売開始にしていただく必要がございます
> 審査で販売不適切と判断された場合は予告なく出品が保留されることもあります

**事前の関門審査ではなく、事後の監視方式。** 準備が整えば即日公開できる。

審査対象として明記されているのは2つだけ:
1. 決済や発注に人手がかかわる自動売買機能を持つもの
2. 月額利用料設定のあるもの(**無期限の月額は出品不可**)

→ シグナル表示のみの通常インジケーターは、どちらにも該当しない。

## Web認証をどうするか

### 使う場合

- 購入者はリアル・デモ問わず**1口座でしか使えなくなる**(コピー対策)
- 手順: 商品を先に登録 → 商品ID確認 → 編集画面で【認証コード確認】
  → ソースコードを貼付 → 【認証コード挿入】 → 出力をコピー
  → MetaEditorでコンパイル
- **zipファイルの直下に ex4/ex5 を置くこと**(直下でないと認証失敗)

### 使わない場合

- zip / rar / lzh で圧縮してアップロードするだけ
- コピーされ得るが、**手順が1段階減り、依存が消える**

### 未確認事項

公式手順の記載が **mq4 / ex4 前提**で、**MQL5対応が明記されていない。**
明日の返信で確認すべき(質問文は下記)。

**判断:** MQ5のWeb認証が使えないなら、
- 案1: MT4版(mq4)にWeb認証を入れて出す
- 案2: Web認証なしでMT5版を出す

初回商品としては**案2(認証なし)でも構わない**。
出品実績を作ることが目的であり、認証の有無で審査は変わらない。
