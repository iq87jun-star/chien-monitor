## 商品概要(外部リンク禁止)

```
■ 年に数回しか鳴りません

このインジケーターは、日足の4つの条件が「すべて」揃った場面だけを検出します。

1通貨ペアあたり、シグナルが出るのは年に数回です。
ほとんどの日は何も起きません。それがこの道具の設計です。

3つ揃っただけでは鳴りません。「4つすべて」であることが本質だからです。


■ 4つの条件

  1. RSI(14) が 35 未満(売り側は 65 超)
  2. 終値が直前20本の平均から 1.5標準偏差 以上離れている
  3. 3本以上の連続陰線(売り側は連続陽線)
  4. その日の変動が 0.5% を超えている

いずれも、行き過ぎた動きを別々の角度から測る指標です。

RSIは相対的な過熱、標準偏差は統計的な乖離、連続本数は流れの持続、
当日変動は勢いの大きさ。測っているものが違うからこそ、
4つが同時に揃う場面は限られます。


■ なぜ「4つすべて」なのか

条件を3つに緩めると、検出される場面は一気に増えます。
そして、そこから優位性は失われます。

私たちの検証では、損切り幅と利確幅を9通りに変えて試したところ、

  4条件すべて  … 9通りすべてでプラス
  3条件に緩める … 9通り全滅

という差が出ました。「4つすべて」というフィルターそのものが中身です。

多く鳴るシグナルではなく、鳴らないことに耐えるためのシグナルです。


■ 表示するもの

【1】シグナル矢印

4条件がすべて揃った翌日のチャートに、矢印を表示します。
買いは水色の上向き、売りは橙色の下向きです。

【2】条件パネル ─ いま何が足りないか

これがこのインジケーターの中心です。

4つの条件それぞれについて、いま成立しているかを常時表示します。

  ● RSI       RSI(14) < 35
  ● 標準偏差   平均から 1.5 SD 以上
  ○ 連続本数   3本以上の連続陰線
  ● 当日変動   当日 0.5% 超の下落

  3 / 4 成立 — 待機中

「3つ揃っていて、あと連続本数だけ」という状態が見えます。
明日どうなれば揃うのかが分かるため、待ち構えることができます。

シグナルが出た後に気づくのではなく、
出る前から準備できることが、裁量トレードでの価値です。

【3】損切り・利確の目安ライン

シグナルが出ると、チャートに3本の水平線を引きます。

  建値の目安    ─ 直近日足の終値
  損切りの目安  ─ 日足ATR(14) × 1.5
  利確の目安    ─ 損切り幅 × 1.2

検証で使った水準です。この数値も設定で変更できます。

【4】通知

4条件が揃うと、画面のアラート・スマートフォンへのプッシュ通知・
メールで知らせます。それぞれ個別にオン/オフできます。

年に数回のシグナルを見逃さないための機能です。
チャートを開き続ける必要はありません。


■ 使い方

チャートにドラッグするだけです。時間足は問いません。
判定は常に日足で行うため、表示している時間足に結果は左右されません。

日足を表示していれば矢印とパネルの対応が分かりやすく、
1時間足を表示していれば執行タイミングを計りやすくなります。


■ 検証について

MT5のストラテジーテスターで、2016年1月からの10年8ヶ月・437取引を
実測しています。7通貨ペア(USD/JPY・EUR/JPY・GBP/JPY・GBP/USD・
AUD/USD・USD/CAD・USD/CHF)を同時に監視した場合の集計です。

【直近3年】2023.08 – 2026.08
  取引数 103 / 勝率 59.2% / プロフィットファクター 1.609
  負け年 1回(4年中)

【直近5年】2021.08 – 2026.08
  取引数 204 / 勝率 54.4% / プロフィットファクター 1.386
  負け年 2回(6年中)

【全期間】2016.01 – 2026.08(10年8ヶ月)
  取引数 437 / 勝率 53.1% / プロフィットファクター 1.307
  負け年 4回(11年中)

短い期間ほど数字が良く見えますが、それは近年の相場と相性が良かった
だけかもしれません。判断は全期間の数字を基準になさってください。

年別の損益を見ると、負けた4年はいずれも小幅です。

  2017年 −55  /  2018年 −67  /  2022年 −63  /  2024年 −13
  勝った年は +224 〜 +729(いずれもリスク0.5%設定での通貨単位)

**最大ドローダウンは、どの期間で切っても 6.95% で変わりません。**
最大の下落は直近の期間で起きています。期間を短く取っても
この数字は小さくなりません。

なお設定の頑健性として、エントリー時刻を 0時 / 2時 / 4時 / 8時 と変えても、
損切りを ATR 1.0〜2.0倍、利確を損切りの 1.0〜1.5倍と変えても
成立することを開発段階で確認しています。特定の設定に依存していません。

「4条件すべて」が本質である根拠も開発段階の検証によるものです。
3条件に緩めると、損切り・利確の全9通りで優位性が消えました。


■ 正直にお伝えする弱点

・鳴りません。1通貨ペアあたり年に数回です。
　毎日トレードしたい方には向きません。
　複数の通貨ペアで並行して監視することを前提とした設計です。

・逆張りです。行き過ぎた動きが戻ることに賭けます。
　戻らずにさらに伸びる場面では、素直に損切りになります。
　全期間の勝率は53.1%で、圧倒的に当たる類のものではありません。

・全期間11年のうち4年が負け越しています。

　これは直近の期間で発生したもので、古い話ではありません。
　複数ペアが同時にシグナルを出す局面があるためです。

・シグナルはあくまで検出です。発注はしません。
　執行の判断とタイミングはご自身で行っていただきます。

・条件のしきい値(RSI 35/65、1.5標準偏差、3連続、0.5%)は
　私たちが検証で使った値です。変更できますが、
　緩めると優位性が失われることは上記のとおりです。

・過去の検証結果は将来の成績を保証するものではありません。
```
