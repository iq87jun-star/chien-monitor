## 6. 認証コード設定(WEB認証)

**初回はチェックせずに進めてよい。**

WEB認証を使う場合は、商品を一度登録して商品IDを取得してから、
編集画面の【認証コード確認】→ ソースコード貼付 → 【認証コード挿入】
→ 出力をMetaEditorでコンパイル、という手順になる。

公式手順が mq4 / ex4 前提で MQL5 対応が明記されていないため、
**MQL5で認証が使えるかは運営に確認中。**回答が来るまでは認証なしで進める。

## 11. 商品ファイル

**認証なしの場合**
```
ChienConditionMeter.zip
  ├ ChienConditionMeter_v102.ex5   (MT5用・コンパイル済み)
  ├ ChienConditionMeter_v102.ex4   (MT4用・コンパイル済み)
  └ 取扱説明書.pdf                  (SALES.md の説明書をPDF化)
```

※ ソースのファイル名は `ChienConditionMeter_v102` です。
検証中に旧ビルドと区別するため版番号を付けています。
配布時に版番号なしの名前に戻すこともできます。ご希望があればお知らせください。

**認証ありの場合**
```
zipファイルの直下に ex5 を置くこと(直下でないと認証失敗)
```

## 12. 商品バナー / 画像

| # | 内容 | 撮影の難易度 |
|---|---|---|
| 1 | 判定が **○(良好)** のときのパネル | 通常時間帯ならいつでも |
| 2 | 判定が **×(割高)** のとき | サーバー時間0時前後を狙う |
| 3 | 時間帯別一覧に**割高な時間帯が並んでいる**画面 | いつでも |
| 4 | 別の銘柄(GBPJPY等)での表示 | いつでも |

**②が最も強い説得材料**です。ロールオーバー帯にスプレッドが跳ねている
実物の画面は、文章より効きます。

参考として `mockup/mock-01-good.png` `mockup/mock-02-avoid.png` に
表示イメージ図があります。**ただしこれは作り物なので、
「実際のスクリーンショット」として掲載しないでください。**

形式: jpeg / jpg / gif / webp、10MB以下。アニメーション不可。
