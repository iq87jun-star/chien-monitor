# ポケカ 国内→海外 価格差リスト

日本語版ポケカのうち、**国内(楽天市場)で買って海外で売ると手元にお金が残るカード**を毎朝リストにする。
過去の実績や評判がいらない「相場の差を読んで稼ぐ」型の副業の仕入れリストとして使う。

- 海外相場: Cardmarket(欧州)の取引平均。`toreca/` の取得処理(TCGdex・キー不要)をそのまま使い、毎回取り直す
- 国内相場: 楽天市場商品検索API。海外相場の円換算が ¥3,000 以上のカードを高い順に最大200枚、1枚ずつ検索する
- カードの照合: 拡張機能の `extension/src/matcher.js` の正規化を使い、**カード名と型番(例: 120/080)の両方が
  タイトルにある単品出品だけ**を比べる。鑑定品(PSA 等)・海外版・まとめ売り・オリパは除く
- 結果: `report.md`(人が読む表)と `data/latest.json`。Discord のウェブフックがあれば上位10枚を送る
- 実行: `.github/workflows/arbitrage.yml` が毎日 7:13(日本時間)に動く

## 手残りの計算

```
手残り = 海外の売値 × (1 − 売却手数料 15% − 為替の目減り 3%) − 国際送料 ¥1,500 − 国内の仕入れ値
```

国内の出品が送料別なら仕入れ値に ¥300 を足す。手残り ¥1,000 以上かつ仕入れ値の 10% 以上をリストに載せる。
数字はすべて `config.mjs` で変えられる。あわせて「国内の方が海外より高いカード」(手持ちを売るなら国内)も出す。

## 使い始めるには

1. 楽天ウェブサービスでアプリIDを発行し、Secrets に `RAKUTEN_APP_ID` を登録する
   (`LAUNCH-CHECKLIST.md` のフェーズ2と同じ。登録済みなら不要)
2. 通知が欲しければ、Discord のウェブフックURLを `ARBITRAGE_DISCORD_WEBHOOK` に登録する
3. main にマージする(定期実行は main のワークフローだけが動く)。すぐ試すなら Actions の
   `arbitrage` を「Run workflow」で手動実行する

## 注意

- Cardmarket は欧州の売り場で、日本からは出品できない。実際に売るのは eBay 等になるので、
  **仕入れる前に eBay の売れた価格(Sold)で必ず確かめる**。リストは「どれを調べるか」を絞るためのもの
- 楽天の出品は状態(美品・傷あり)や在庫が出品ごとに違う。出品ページで確かめる
- 最初は少ない枚数で、送料・手数料・届くまでの日数を実際に確かめてから広げる

## ローカル実行

```bash
cd arbitrage
npm test                                  # 計算の単体テスト(通信なし)
node ../toreca/pipeline/fetch-data.mjs    # 海外相場を取り直す(数分)
RAKUTEN_APP_ID=... node run.mjs           # リストを作る(200枚で約4分)
```
