## フィルター(filters.py)
17 種を発見期間(2016-21)の分位でしきい値を固定し、確認期間(2022-26.5)・未使用期間(2026.6-10)に持ち込んだ。

| フィルター | 2016-21 | 2022-26.5 | 2026.6-10 |
|---|---|---|---|
| 基準(下窓すべて) | 61.1% | 65.6% | 64.0% |
| **07 時までに窓を半分以上埋めたら見送る(採用)** | 62.9% | 69.4% | 75.0% |
| (見送った側) | 56.5% | 55.2% | 44.4% |
| 冬時間のみ | 64.5% | 72.4% | (該当なし) |
| 円の通貨ペアのみ | 60.2% | 70.8% | 66.1% |
| 窓 大 / 金曜・前週の向き / 下窓ペア数 / スプレッド | 期間ごとに上下が入れ替わる・差 ±2pt 前後 | | |

- 採用: 「07:00 時点で窓を 50% 以上埋めていたら見送る」(ボット v0.2 の `max_filled`)。3 期間とも同じ向きに効き、見送った側は損益分岐 55% 付近〜以下。冬時間は 07:00 が開場直後で埋まる時間が無いため、実際には夏時間だけに効く。
- 1 回 2 万円の仮想損益: 月平均 2022-26.5 +67,719 円(基準 +68,062 円)/ 2026.6-10 +93,091 円(基準 +65,455 円)、最大 DD 2022-26.5 −169,091 円(基準 −298,182 円)。回数は月 18 → 13 回。勝率は上がり、損益はほぼ同じで、落ち込みが浅くなる。
- 円の通貨ペアのみは 2016-21 で逆に下がるため不採用。冬時間の差は時期の性質で、絞ると夏の機会を失うため見るだけ。

- **IG バイナリーの取引時間**: 比較記事では「8:00〜翌 5:00」とある。月曜 07:00 に買えない場合、効果の大半(07→08)を取り逃がす。
- IG の第 4 回号(07:00→09:00)を月曜 07:00 直後に買えるか。冬時間は開場直後にあたる。
- その時の実際の購入価格(= 実際の損益分岐)。開場直後のスプレッド拡大で 550 円より高い可能性がある。
