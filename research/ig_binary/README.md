# IG 証券 国内バイナリー(2 時間判定)の検証と「月曜 窓埋め」ボット

データ: Dukascopy 1 時間足 BID / ASK(2016-01〜2026-10-13)。判定は **中値**(BID と ASK の平均)。損益分岐は 55%(ATM 購入価格 ≈ 550 円の想定・未実測)。

## 再現手順
```
cd research/ig_binary && mkdir -p data && cd data
python ../fetch_data.py                 # 7 ペア × BID/ASK
python ../verify_old_strategies.py      # 旧 v4.0 IG 10 戦略: BID 判定と中値判定の差・2026-06 以降の成績
python ../grid_search.py                # 834 パターン総当たり(発見 2016-21 / 確認 2022-26.5 / 未使用 2026.6-)
python ../monday_gap.py                 # 月曜 07→09 の週末窓別 上昇率
```

## 結果(2026-10-13)
1. **旧 IG 10 戦略は BID で判定していたため勝率が膨らんでいた。** 06〜07 時 JST はスプレッドが約 2 pips に広がり(普段の約 7 倍)、BID だけが下がるため、「07 時から HIGH」「07 時まで LOW」が勝ちに見える。中値で 55% を超えるのは S01・S02・S03 の 3 つだけ(S04・S05・S07・S09・A10 は 47〜55%)。
2. **総当たりでの拡張は不採用。** 834 パターンのうち、発見期間で p<0.01 は 1 件(偶然でも約 8 件は出る)で、確認期間では 0 件。
3. **月曜の下窓 → 07:00→09:00 HIGH**(全 7 ペア合算・中値)

| | 2016-21 | 2022-26.5 | 2026.6-10(未使用) |
|---|---|---|---|
| 下窓 | 61.1%(1,205) | 65.6%(936) | 64.0%(100) |
| 上窓 | 50.7% | 52.3% | 55.3% |

ペア別(下窓・全期間)は 58.7〜67.1%(円の通貨ペアが強い)。冬時間 68.0% / 夏時間 60.5%。
1 回 2 万円・損益分岐 55% の仮想損益: 2022-26.5 は月平均 +68,062 円(マイナス月 26%・最大 DD −292,727 円)、2026.6-10 は月平均 +65,455 円。
月別の勝率は 2026-06 81.8% / 07 66.7% / 08 75.0% / 09 50.0% / 10 33.3%(10/13 時点)と、直近で低下している。

## 未確認(本番前に必ず確かめる)
