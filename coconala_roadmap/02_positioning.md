# 02. 差別化ポジショニング（3パターン）

> **このファイルの前提・判断**
> `01_market_research.md` の空白ニッチ仮説に基づき、実績ゼロから参入できる差別化ポジショニングを3案提示する。3案は**排他ではなく、段階的に組み合わせられる**よう設計した（推奨はパターンA起点）。
> 各案の「想定単価」は手数料・税引前の販売価格。手取りは通常サービスで×0.78、ビデオチャットで×0.725。

---

## パターンA：「忙しい人の“やってあげる”AI代行」（成果物納品型）★推奨スタート

| 項目 | 内容 |
|---|---|
| キャッチ概念 | **「学ぶ時間がないあなたの代わりに、AIで“完成品”を作ります」** |
| ターゲット | 中小企業の経営者・個人事業主・士業・忙しい会社員。AIを使いたいが学習時間がない層。 |
| 訴求軸 | 「教わる手間ゼロ／完成品が手に入る／業務がすぐ軽くなる」 |
| 提供サービス例 | AIで業務マニュアル作成、提案書/企画書のたたき台作成、議事録整形、メール/文章作成代行、業務効率化テンプレ構築 |
| 想定単価 | 入口 ¥2,000〜5,000 → 主力 ¥8,000〜20,000（ボリューム・難易度で段階） |
| 競合状況 | 上位が「教える」型に集中しており、**「代わりにやる」型は手薄**（仮説1） |
| 実績ゼロでの戦い方 | 納品物のサンプル（ポートフォリオ）を自作して提示。「品質は現物で証明」できるため、レビューゼロの不利を補える。 |
| 強み | 納品物が残るので口コミ・再依頼につながりやすい。テキスト納品なら手数料22%で済む。 |
| 弱み | 1件ごとに工数が発生（フロー型）。単価上限がある。 |

**この案を推す理由**: 実績ゼロでも「サンプルの質」で勝負でき、初受注のハードルが最も低い。テキスト納品中心で手数料も低く、まず評価を貯めるフェーズに最適。

---

## パターンB：「○○業界専門のAIアシスタント設計」（業種特化・専門家ポジション）

| 項目 | 内容 |
|---|---|
| キャッチ概念 | **「あなたの業界の業務に合わせた“専用AI”を作ります」** |
| ターゲット | 特定業種（例: 美容サロン／不動産／飲食／士業／教育／EC など、本人が知見を持てる1業種に絞る） |
| 訴求軸 | 「業界の事情を分かっている人が作るから、すぐ実務で使える」 |
| 提供サービス例 | 業種特化GPTs構築、業務別プロンプト集、定型業務（予約対応文・接客文・契約書たたき台等）の自動化テンプレ |
| 想定単価 | ¥5,000〜30,000（GPTs構築＋使い方ガイド付き） |
| 競合状況 | 汎用プロンプトは飽和、**業種特化は競合が薄く検索上位を取りやすい**（仮説2） |
| 実績ゼロでの戦い方 | 「自分が詳しい/興味のある1業種」に絞り、その業界の言葉でページを書く。専門性で信頼を補完。 |
| 強み | キーワード競合が少なく検索流入を取りやすい。「○○業界の人」という独自ポジションでコピーされにくい。 |
| 弱み | 市場が業種サイズに依存。詳しくない業種を選ぶと刺さらない。 |

**この案を推す理由**: 本人に特定業界の経歴・知見がある場合は最有力。ニッチ独占で「指名買い」が起きやすい。

---

## パターンC：「AI伴走レクチャー＋運用サポート」（教育・継続型）

| 項目 | 内容 |
|---|---|
| キャッチ概念 | **「使えるようになるまで伴走します。導入後の運用相談もセット」** |
| ターゲット | 自社/自分でAIを使えるようになりたい初心者〜中級者、AI導入を検討する小規模事業者 |
| 訴求軸 | 「ひとりで挫折しない／自社業務に合わせて教える／導入後も相談できる」 |
| 提供サービス例 | 60〜90分のビデオレクチャー、AI導入相談、月額の運用サポート枠（リピート収益） |
| 想定単価 | レクチャー ¥7,000〜20,000（ビデオ：手数料27.5%）、月額保守 ¥5,000〜15,000 |
| 競合状況 | 上位が集中する激戦区だが**需要も最大**。「運用・保守の月額枠」は手薄（仮説4） |
| 実績ゼロでの戦い方 | 最初は低単価（¥3,000〜5,000の30分相談）で実績を作り、評価を貯めてから単価を上げる。 |
| 強み | 単価が高く、リピート/月額で安定収益化しやすい。月10万円目標に最短で効く。 |
| 弱み | 実績ゼロでは選ばれにくい（教える信頼の証明が必要）。ビデオ対応の時間拘束。手数料27.5%。 |

**この案を推す理由**: 月10万円の最終ゴールに最も効くが、実績が要る。**フェーズ3以降の主力**として育てる位置づけ。

---

## 推奨戦略：3案の組み合わせ（時系列）

実績ゼロから月10万円までは、3案を**フェーズで切り替える/重ねる**のが最も合理的。

```
フェーズ1（0-1ヶ月）  : パターンA（代行）の低単価で初受注・評価獲得
フェーズ2（1-3ヶ月）  : パターンA主力化 ＋ パターンB（業種特化）を1本投入
フェーズ3（3-5ヶ月）  : パターンC（レクチャー）を追加し単価を引き上げ
フェーズ4（5-6ヶ月〜）: パターンC＋月額保守でストック収益、Aのテンプレをコンテンツ販売化
```

- **理由**: 実績ゼロ期はA（現物で勝負）で評価を貯め、信用が付いた段階でC（高単価レクチャー）に移行するのが、リスク最小で単価最大化の王道。Bは検索流入の「入口」として常設する。
- 詳細な実行計画は `05_roadmap.md` を参照。

## ポジショニング・マップ（言語化）

- 横軸：**汎用 ←→ 特化**
- 縦軸：**教える（伴走） ←→ 代わりにやる（納品）**

| | 教える（伴走） | 代わりにやる（納品） |
|---|---|---|
| **汎用** | 競合密集（上位レクチャー群）＝避ける | パターンA（やや空白） |
| **特化** | パターンC＋業種特化（空白＝狙い目） | パターンB（空白＝狙い目） |

> **狙うべきは右下・左下・右上の「特化 or 代行」象限**。左上（汎用×教える）はレッドオーシャンなので正面衝突しない。
