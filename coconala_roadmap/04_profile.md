# 04. プロフィール・自己紹介・ビジュアル方向性

> **このファイルの前提・判断**
> 実績ゼロ（販売実績0・評価0）からでも信頼を獲得することを最優先に設計した。市場分析（`01_market_research.md`）で、上位出品者が「ターゲット明示」「実績/経歴の数値化」「伴走サポート」で信頼を補完していることが分かったため、**経歴・人柄・対応姿勢・具体的な対応範囲**で“レビューの不在”を埋める構成にする。
> 嘘の実績は書かない（規約違反・信頼毀損）。代わりに「準備の本気度」「明確な対応範囲」「レスポンスの速さ」「サンプルの質」で信頼を作る。

---

## 1. プロフィール文（自己紹介本文・そのまま転記可）

> ※ 〔　〕は各自の実情に置き換える。固有の経歴がある人はそれを最大の武器にする。

```
ご覧いただきありがとうございます。
生成AIを活用した「業務の効率化」と「文書・コンテンツ作成」を
サポートしています。

◆ できること
・AIを活用した業務文書/マニュアル/手順書の作成代行
・あなたの業務に合わせたプロンプト・カスタムGPTの設計
・「AIを使いたいが何から始めればいいか分からない」方への
  マンツーマン・レクチャー

◆ 私が大切にしていること
1. 専門用語を使わず、相手の立場で分かりやすく
2. AIに任せきりにせず、必ず人の目で品質を確認
3. レスポンスは早く、丁寧に。納期はお約束を守る

◆ 〔あなたの背景・強み〕
〔例：本業で〇〇の業務に△年携わり、現場の“面倒”を知っています。
その経験と最新の生成AIを掛け合わせ、現場で本当に使えるものを
お届けします。〕

◆ ご依頼の流れ
購入前のメッセージ相談を歓迎しています。
「こんなことできる？」という段階で構いません。
あなたの目的を伺い、最適なプランをご提案します。

まずはお気軽にご相談ください。
```

### 実績ゼロ期に「信頼」を作る5つの要素
1. **対応範囲を明確に書く**: 「何ができて／何ができないか」を正直に示すほど信頼される。
2. **経歴・本業スキルを具体的に**: 「〇〇歴△年」「現場を知っている」は実績ゼロの最強の代替。嘘は厳禁。
3. **対応姿勢を約束**: 「24時間以内に返信」「納期厳守」「修正対応」など、行動で示せる約束を書く。
4. **サンプル/ポートフォリオを用意**: 自作のマニュアル例・プロンプト例を画像やサンプルとして提示（後述）。
5. **モニター価格の理由を明記**: 「開始記念の特別価格」と理由を添えると、安さが不信ではなく“お得”に転換する。

## 3. アイコン画像の方向性

| 項目 | 指示 |
|---|---|
| 基本方針 | **顔出し可能なら実写の顔写真が最も信頼される**（清潔感・自然光・正面・笑顔）。 |
| 顔出ししない場合 | プロ品質のイラストアバター（AI生成可）。ただし「人物」が分かるものにする。抽象ロゴは避ける（人柄が伝わらず信頼が下がる）。 |
| 配色 | 信頼感のある青系 or 親しみのある暖色1色を基調。AIテーマなら知的な青×白。 |
| NG | 暗い・低解像度・無関係なフリー素材・過度な加工。 |
| 作り方 | 顔写真をCanvaで明るさ/トリミング調整、または生成AIでビジネス向けアバター作成（実物に近い印象で統一）。 |

## 4. カバー画像の方向性（プロフィール上部の横長画像）

| 項目 | 指示 |
|---|---|
| 目的 | 「誰の・何の課題を・どう解決するか」を3秒で伝える看板。 |
| 構成 | 左にキャッチコピー、右にアイコン/イメージ。文字は大きく少なく。 |
| 入れる文言例 | 「AI × 業務効率化 / 文書作成代行・プロンプト設計・使い方レクチャー」 |
| トーン | 清潔・余白多め・読みやすいゴシック体。色は2〜3色に抑える。 |
| 作り方 | Canvaの「ココナラ カバー」テンプレ or 横長バナーテンプレを使用。 |

## 5. サービス画像（出品ごとの1枚目）の方向性

> 検索一覧でクリックされるかは「サムネ画像」で大きく決まる。最重要ビジュアル。

| 要素 | 指示 |
|---|---|
| 1枚目（最重要） | **大きな文字で「ベネフィット＋ターゲット」**。例:「業務マニュアル、AIで最短3日」。背景はシンプル、文字は2〜3行・特大。 |
| 2枚目以降 | 提供物の例（マニュアルの紙面イメージ、プロンプト画面、ビフォーアフター）、料金プラン表、流れの図、自己紹介。 |
| 配色 | カテゴリで埋もれない色を選ぶ（一覧で周りと差がつく色）。 |
| 文字量 | 1枚に詰め込みすぎない。1枚＝1メッセージ。 |
| 作り方 | Canva無料テンプレ＋一貫したフォント/色でブランド統一。全出品で世界観を揃える。 |

## 6. ポートフォリオ／実績の代替コンテンツ（実績ゼロ対策）

レビューが貯まるまでは、以下を自作して「実力の証拠」にする：
- **サンプル成果物**: 架空のテーマで作ったマニュアル/手順書/プロンプト集（画像 or PDF抜粋）。
- **ビフォーアフター**: 「雑なメモ → 整った手順書」の対比画像。
- **対応の流れ図**: 購入から納品までの安心感を可視化。

> これらはサービス画像の2枚目以降・ポートフォリオ欄に配置する。「現物を見せる」ことが、評価ゼロの最大の弱点を補う。

## 7. 信頼性チェックリスト
- [ ] アイコンは人物が伝わる明るい画像か
- [ ] カバー/サービス画像で「誰の何を解決するか」が一目で分かるか
- [ ] プロフィールに「できること／できないこと」を明記したか
- [ ] 経歴・本業スキルを具体的に書いたか（嘘なし）
- [ ] 返信速度・納期・修正など「約束」を書いたか
- [ ] サンプル成果物を用意・掲載したか
- [ ] 全出品でビジュアルの世界観（色・フォント）を統一したか
