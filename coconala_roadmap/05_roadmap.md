# 05. 収益化ロードマップ（メイン成果物）

> **このファイルの前提・判断**
> - ゴール：`00_assumptions.md` の定義どおり「**6ヶ月で月次売上10万円（手取り約7.8万円）を安定達成**」。
> - 戦略：`02_positioning.md` の通り、パターンA（代行）で実績を作り→B（業種特化）で流入→C（高単価レクチャー）＋月額保守で単価とストックを積む。
> - 稼働前提：週10〜15時間。手数料は通常22%／ビデオ27.5%。**手取り＝売上×0.78（または×0.725）**。
> - 売上試算は前提が満たされた場合のシミュレーション。**保証ではない**。市場・競合・習熟度で変動する。
> - 数字の出どころ：単価は `03_service_listings.md` の価格、受注ペースは `01_market_research.md` の上位出品の評価件数推移から逆算した現実的な想定。

## 全体像（6ヶ月の流れ）

| フェーズ | 期間 | テーマ | 月次売上目標 | 主な武器 |
|---|---|---|---|---|
| **0** | 0〜2週目 | 準備（出品の土台づくり） | ¥0 | 出品ページ・プロフィール・サンプル |
| **1** | 3週目〜1ヶ月 | ゼロイチ（初受注・初評価） | 〜¥1万 | 入口商品①＋公開依頼提案 |
| **2** | 2〜3ヶ月 | 実績獲得（評価を貯める） | ¥3万 | 主力②＋業種特化③ |
| **3** | 4〜5ヶ月 | 単価アップ | ¥6万 | レクチャー④＋オプション拡充 |
| **4** | 6ヶ月〜 | 仕組み化・収益安定 | ¥10万 | 月額保守＋ストック商品⑤ |

> 進みが遅い場合は各フェーズを1〜2週間ずつ後ろ倒しして構わない。**順番（実績→単価→ストック）を守ること**が重要で、焦って高単価から始めない。

## フェーズ0：準備（0〜2週目）

**目的**：売れる土台を、初受注ゼロのうちに完成させる。

### 具体タスク（チェックリスト）
- [ ] ココナラ会員登録・本人確認・売上金受取口座の設定
- [ ] 生成AIの有料プラン契約（ChatGPT/Claude等、月3,000〜6,000円）
- [ ] Canvaでアイコン・カバー・サービス画像を作成（`04_profile.md` 準拠）
- [ ] プロフィール文を作成・公開（`04_profile.md` 準拠）
- [ ] **出品①（入口商品）と②（主力）を公開**（`03_service_listings.md` 準拠）
- [ ] サンプル成果物（架空テーマのマニュアル/プロンプト集）を2〜3点自作し画像化
- [ ] 競合上位10件をブックマークし、価格・コピー・画像を研究（丸パクリ厳禁、型を学ぶ）
- [ ] 「購入前メッセージ歓迎」「24時間以内返信」を各ページに明記

### 達成条件（KPI）
- 出品2本が公開済み／プロフィール完成度100%／サンプル2点以上掲載

### 売上試算

## フェーズ1：ゼロイチ（3週目〜1ヶ月）

**目的**：実績0→1。最初の受注と高評価を取り、検索順位の起点を作る。

### 戦略の核（市場分析より）
実績ゼロでは「待ち」では売れない。**(1) モニター/新規価格＋理由明記、(2) 公開依頼への積極提案、(3) 付加価値（速い納期/無料修正）**の3点で能動的に初受注を取る。

### 具体タスク
- [ ] 入口商品①を「開始記念価格 ¥2,000」で出し、理由を明記（「実績作りのため期間限定」）
- [ ] **ココナラの「公開依頼」に毎日チェックし、合致案件へ提案**（提案文テンプレを用意）
- [ ] 提案文は「相手の課題の言い換え＋具体的な進め方＋納期＋サンプル提示」で作る
- [ ] 初受注は**丁寧さ最優先**（即レス・期待を超える納品・1回無料修正）→★5評価を狙う
- [ ] 納品後、購入者へ自然な形で評価をお願い（規約内、強要しない）
- [ ] 受注のたびにサービスページのFAQ・説明文を実際の質問で改善

### 達成条件（KPI）
- **累計受注 1〜3件／評価 平均4.8以上を1件以上獲得**
- 公開依頼への提案 累計10件以上

### 売上試算
| 項目 | 想定 | 売上 | 手取り(×0.78) |
|---|---|---|---|
| 入口商品① ¥2,000 ×2〜3件 | 初受注 | ¥4,000〜6,000 | 約¥3,100〜4,700 |
| **月合計** | | **〜¥1万** | **〜¥7,800** |

## フェーズ2：実績獲得（2〜3ヶ月）

**目的**：評価件数を積み上げ、検索順位を上げ、主力②と業種特化③を回す。

### 具体タスク
- [ ] 入口商品①の価格を¥2,000→¥3,000へ（評価が付いたら徐々に正価へ）
- [ ] **主力商品②（マニュアル作成）を本格稼働**、サンプルを増やす
- [ ] **業種特化③を1本投入**（自分が詳しい/関心ある1業種に絞る）＝検索流入の入口に
- [ ] 公開依頼提案を継続（週5件以上）
- [ ] 評価5件達成を目標に、リピート依頼の打診（「次回もぜひ」と納品時に一言）
- [ ] KPIトラッカー（`06_kpi_tracker.md`）を毎週記入し、閲覧→お気に入り→問い合わせ→受注の歩留まりを確認
- [ ] 反応の悪い出品はタイトル/1枚目画像/キャッチを差し替えてA/Bテスト

### 達成条件（KPI）
- **累計評価 8〜12件／平均4.8以上維持**
- 月次受注 **4〜6件**／検索で主力キーワードの2ページ目以内に表示
- 問い合わせ→成約率 30%以上

## フェーズ3：単価アップ（4〜5ヶ月）

**目的**：実績を背景に高単価レクチャー④を投入し、平均単価を引き上げる。

### 具体タスク
- [ ] **レクチャー④を投入**。まず「お試し30分¥5,000」で実績を作り、評価が付いたら60分¥10,000を主力化
- [ ] 主力②をスタンダード/プレミアム中心に誘導（オプション提案で客単価UP）
- [ ] 全出品にオプション（お急ぎ便・追加・図解・サポート延長）を整備し、**1注文あたりの単価を底上げ**
- [ ] 既存購入者へリピート/紹介を打診（評価が貯まると指名・再依頼が増える）
- [ ] 出品を4〜5本に拡充し、検索の露出面を増やす
- [ ] 価格を段階的に正価へ（モニター価格を卒業）

### 達成条件（KPI）
- **累計評価 20件以上／平均4.8以上**
- 月次受注 **6〜8件**、うちレクチャー型を2件以上
- 平均客単価 ¥10,000以上、リピート率 20%以上

## フェーズ4：仕組み化・収益安定（6ヶ月〜）

**目的**：稼働に比例しない収益（月額・ストック）を加え、月10万円を安定軌道に乗せる。

### 具体タスク
- [ ] **月額保守/運用サポート枠**を販売（②③④のオプション→独立メニュー化）。継続収益の柱に
- [ ] **ストック商品⑤（プロンプト集PDF）を販売**。一度作れば稼働ゼロで売れる収益源に
- [ ] よく出る納品物をテンプレ化し、**1件あたりの工数を圧縮**（時給を上げる）
- [ ] 高評価の購入者導線を整理（プロフィール→人気出品→関連出品の回遊）
- [ ] レクチャー④のプレミアム（60分×3＝¥27,000）や導入相談（¥30,000）を主力化
- [ ] 稼働の上限が見えたら「単価を上げる」か「ストック比率を上げる」で月10万を維持
- [ ] 確定申告の準備（売上・経費の記録。年間所得20万円超は申告要）

### 達成条件（KPI）
- **月次売上 ¥10万円を2ヶ月連続で達成**
- 月額/ストック収益が売上の20%以上（稼働非依存の比率を確保）
- 平均評価4.8以上・累計評価30件以上・リピート率30%

### 売上試算（月次・安定期）
| 商品 | 単価 | 件数/月 | 売上 |
|---|---|---|---|
| レクチャー④（60分・プレミアム混在） | 平均¥13,000 | 3 | ¥39,000 |
| 主力②（スタンダード/プレミアム） | 平均¥18,000 | 2 | ¥36,000 |
| 業種特化③ | ¥10,000 | 1 | ¥10,000 |
| 月額保守枠 | ¥5,000 | 2 | ¥10,000 |
| ストック商品⑤（PDF） | ¥3,000 | 2 | ¥6,000 |

## つまずいた時の対処（トラブルシュート）

| 症状 | 主な原因 | 打ち手 |
|---|---|---|
| 閲覧はあるが問い合わせ0 | 1枚目画像/キャッチが弱い | サムネ・キャッチを「ターゲット＋ベネフィット」に作り直す |
| 問い合わせはあるが成約しない | 価格 or 信頼不足 | モニター価格・サンプル追加・FAQ拡充・即レス |
| そもそも閲覧されない | 検索順位が低い | キーワード見直し・公開依頼提案で実績を作る・更新頻度を上げる |
| 受注はあるが時給が低い | 工数過多/単価不足 | テンプレ化・オプション追加・単価改定・レクチャー型へ移行 |
| 低評価がついた | 期待値ずれ | 対応範囲・免責を明記、納品前確認を徹底、丁寧な再対応 |

## このフェーズ計画の根拠（再掲）
- 「実績→単価→ストック」の順序は、ココナラの検索順位が「販売実績＋高評価＋継続更新」に依存する実態（`01_market_research.md`）に基づく。実績ゼロで高単価から始めても選ばれない。
- 受注ペース（月1→4→6→10件）は、上位出品の評価件数が数ヶ月で2桁に達している実例から逆算した、無理のない現実値。
- 月10万円は単価×件数で算術的に到達可能な設計であり、精神論ではない。ただし達成は前提条件（稼働・品質・市場）に依存する。
