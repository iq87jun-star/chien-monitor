# ココナラ副業 収益化ロードマップ

ココナラ（https://coconala.com/）で副業として「実績ゼロから月次売上10万円（手取り約7.8万円）を6ヶ月で目指す」ための実行可能なロードマップ一式。

> **判断の前提**: 依頼主の希望・条件は与えられていないため、ココナラ市場の実態調査（2025〜2026年5月時点）に基づき、コンサルタントとして最も合理的と判断した前提を設定している。詳細と根拠は `00_assumptions.md` を参照。
> **免責**: 売上試算は前提条件が満たされた場合のシミュレーションであり、収益を保証するものではない。手数料・規約は改定され得るため、実行前に公式の最新情報を確認すること。

## 採用した主要な判断（要約）
- **稼ぐの定義**: 6ヶ月で月10万円（手取り約7.8万円）を安定達成。収益モデルはフロー型主軸＋段階的ストック化。
- **選定カテゴリ**: 生成AI活用支援（AIライティング/業務効率化/プロンプト・GPTs設計/レクチャー）。市場で最も伸びており、AIが生産手段になり、単価も比較的高く、独学で参入可能なため。
- **ターゲット**: AIを使いたいが自走できない中小企業経営者・個人事業主・士業、およびコンテンツ制作者。
- **戦略**: 代行（実績作り）→業種特化（流入）→高単価レクチャー＋月額/ストック（単価・安定化）の段階移行。
