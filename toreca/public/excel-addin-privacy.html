プライバシーポリシー(Excel アドイン「日本の計算関数」)

制定日: 2026年9月30日

収集する情報

本アドインは、個人を特定できる情報・ブックの内容・関数に入力した値を収集せず、外部に送信しません。

アドインの動作

  • セルに書かれた関数(=JP.TAKEHOME など)に渡された値だけを、お使いの Excel の中で計算し、結果をそのセルに返します。
  • Excel は起動時に、本アドインのプログラム(JavaScript)・関数の説明・アイコンを pokeca-kaigai.com から読み込みます。このとき、一般的なウェブサイトと同じく、配信サーバー(GitHub Pages)が IP アドレス等の接続情報を処理する場合があります。セルの値や計算の内容は送られません。
  • 計算に使う祝日や保険料率等のデータはプログラムに含まれており、計算のたびに外部から取得することはありません。
  • Cookie・広告・アクセス解析のツールは使いません。

要求する権限

Office アドインの標準の権限を使いますが、本アドインはブックのセルを読み書きしたり保存したりしません。 関数に渡された値の計算だけを行います。

第三者への提供

収集する情報がないため、第三者への提供・販売は行いません。

お問い合わせ

Microsoft AppSource の本アドインのページのサポート欄からご連絡ください。

Privacy Policy (English summary)
This add-in does not collect, store or transmit any personal information, workbook content or function inputs. All calculations run inside Excel and results are returned only to the calling cell. Excel downloads the add-in's code, function metadata and icons from pokeca-kaigai.com (hosted on GitHub Pages), which may process standard connection data such as IP addresses; cell values are never sent. No cookies, ads or analytics are used, and no data is shared or sold.
