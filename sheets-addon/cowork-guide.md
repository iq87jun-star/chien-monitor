# Cowork 用の作業指示(スプレッドシートのアドオン「日本の計算関数」を試す・公開の準備)

この文書を Cowork にそのまま渡して使う。人が行う作業(★)と、Cowork に任せる作業を分けてある。
Cowork は「止まる」と書かれた所で必ず作業を止め、人に確認すること。

| 作業 | 内容 | 必要な時間 |
|---|---|---|
| A | 新しいスプレッドシートにコードを入れる | 10分 |
| B | 17の関数を試して、正解の値と比べる | 15分 |
| C | ストア用のスクリーンショットを撮る | 5分 |
| D(後日) | Google Workspace Marketplace への申請の準備 | 30分〜 |

## 守ること(Cowork 向け)

- Google アカウントのパスワード・2段階認証コードを入力しない(ログインは人が行う)
- 「このアプリは Google で確認されていません」「アクセスを許可」などの**権限の確認画面が出たら止まり**、人に押してもらう
- **審査への提出・公開のボタンは押さない**。その画面に来たら止まって人に知らせる
- コードは受け取ったファイルの中身を**そのまま全部**貼る。自分で書き換えない・一部だけ貼らない
- 試すのは新しく作ったスプレッドシートだけ。人の既存のファイルは開かない・変更しない

## 事前準備(★人が行う)

1. Chrome で Google アカウントにログインしておく
2. Claude Code から受け取った次の5つのファイルをパソコンに保存し、保存場所を Cowork に伝える
   - `lib.js`・`functions.js`・`Code.js`・`Help.html`・`appsscript.json`

## 作業A: 新しいスプレッドシートにコードを入れる(Cowork)

1. https://sheets.new を開き、新しいスプレッドシートの名前を「日本の計算関数 テスト」にする
2. メニューの「拡張機能」→「Apps Script」を開く。プロジェクト名を「日本の計算関数」にする
3. 最初からある `コード.gs`(または `Code.gs`)を開き、中身を**全部消して**から `Code.js` の中身を全部貼る
4. 左の「ファイル」の「+」→「スクリプト」で次の2つを作り、それぞれ中身を全部貼る
   - 名前 `lib` → `lib.js` の中身(長いファイル。最後の行まで貼れているか、末尾が `})();` 付近で終わっているか確認する)
   - 名前 `functions` → `functions.js` の中身
5. 「+」→「HTML」で名前 `Help` を作り、`Help.html` の中身を全部貼る
6. 左の歯車「プロジェクトの設定」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック →
   エディタに戻り `appsscript.json` の中身を全部消してから、受け取った `appsscript.json` の中身を貼る
7. 上の保存ボタン(💾)を押す。赤いエラーが出たら**止まる**: エラーの文言をそのまま人に報告する
8. スプレッドシートのタブに戻り、ページを再読み込みする

## 作業B: 17の関数を試す(Cowork)

スプレッドシートの A 列に下の「入力する式」を1行に1つずつ入れ、B 列に「正解」を書き写す。
表示された値が正解と一致するか確かめる。日付は表示形式によって「2026/09/24」のように見えればよい。
初回は計算に数秒かかることがある(「読み込んでいます…」の表示は待つ)。

  右に説明の画面が出るか。**権限の確認画面が出たら止まり**、人に許可してもらってから続ける

## 作業C: ストア用のスクリーンショットを撮る(Cowork)

作業Bで**すべて一致した場合だけ**行う。ブラウザの窓を 1280x800 程度にして、次の3枚を撮って保存する。
画面に個人の情報(他のファイル名・メールアドレス等)が写らないようにする。

1. 手取りの内訳: A1 に「月給」、B1 に 300000、A3 に `=JP_TAKEHOME_DETAIL(B1)` を入れた画面
2. 営業日: 日付の列と `=JP_WORKDAY(…, 3)`・`=JP_HOLIDAY_NAME(…)` の列が並んだ画面(9月の連休をまたぐ日付を数行)
3. 和暦: 西暦の日付の列と `=JP_WAREKI(…)` の列が並んだ画面

保存したファイルの場所を人に報告する。

## 作業D(後日): Marketplace への申請の準備(Cowork・★の所は人)

作業A〜Cが問題なく終わってから行う。細かい手順は `sheets-addon/README.md` の「2. Google Workspace Marketplace に出す」。

1. ★ https://console.cloud.google.com で新しいプロジェクトを作る(初めての場合は利用規約への同意が必要)
2. Cowork: プロジェクト番号を控え、Apps Script の「プロジェクトの設定」→「Google Cloud Platform(GCP)プロジェクト」で変更する
   (公開用には、スプレッドシートに紐づかない単独のプロジェクトが必要な場合がある。その案内が出たら**止まる**)
3. Cowork: 「API とサービス」→「OAuth 同意画面」を `README.md` のとおりに入力する
   (プライバシーポリシー・利用規約の URL、承認済みドメイン `pokeca-kaigai.com`、スコープ2つ)。
   **ドメインの所有確認を求められたら止まる**: 表示された確認用のファイル名(または TXT レコード)を人に報告する
   (人がそれを Claude Code に渡すと、サイトに置いてもらえる)
4. Cowork: 「Google Workspace Marketplace SDK」を有効にし、「アプリの構成」「ストアの掲載情報」を
   `sheets-addon/listing/store.md` のとおりに入力する。アイコン・バナーは `sheets-addon/listing/`、
   スクリーンショットは作業Cで撮ったもの
5. **止まる**: 「公開」「審査に提出」は押さずに、入力した内容と警告を人に報告する

## 最終確認(★人が行う)

作業Bの報告で一致しないものがあれば、その表を Claude Code のセッションに貼って修正を依頼する。
作業Dの報告を確認し、問題がなければ Marketplace で「公開」を押して審査に出す(数日〜数週間)。
