# 剣華録 立ち絵ブリーフ（イラストレーター／画像生成向け）

ゲーム内の仮素材（SVG シルエット）を差し替えるための発注書です。
数値・名前・色は `src/data/characters.ts` が正です。食い違ったらそちらに合わせてください。

---

## 共通の指定

### 世界観とトーン
- 鬼と妖が溢れる架空の戦国「八洲（やしま）」。剣術流派から選ばれた少女剣士＝「剣華（けんか）」。
- 「夜の城下町に灯る提灯」。漆黒・金箔・朱の差し色・和紙の質感。
- 全体のモチーフは**金継ぎ**。衣装の縁取りや小物に「金で継いだひび」の線を一筋入れると統一感が出ます（必須ではありません）。
- 凛とした美しさ＋少しの遊び心。重すぎない表情に。

### 納品形式
| 用途 | サイズ | 備考 |
|---|---|---|
| 立ち絵（全身） | 1200×1600px（3:4）以上、透過PNG | 頭頂は上から約15%、足元は画面下で切れて可 |
| 表情差分 | 同キャンバス・同位置で顔のみ差し替え | 通常／笑顔／怒り・真剣／困り・負け の4種 |
| 背景 | 不要 | 背景はゲーム側で属性柄を描きます |

- 画面内では「全身」「胸から上（正方形）」「顔（正方形）」の3通りに切り抜いて使います。**顔が画像の横中央・上から約35%** に来るようにしてください（`src/ui/components/Portrait.tsx` の切り抜き位置と合わせるため）。
- 差し替えは `characters.ts` の `imageUrl` に画像パスを入れるだけで反映されます。

### 共通のNG
- 既存の商用ゲーム（特に同ジャンルの和風放置RPG）のキャラ・衣装・ロゴ・UIに似せない。
- 実在の歴史上の人物や、実在の家紋・神社の紋をそのまま使わない（紋は本ブリーフのオリジナルモチーフで）。
- 過度な露出、流血表現の強調（出血は「赤い桜の花びら」などで比喩的に）。
- 年齢感は各キャラの記載に合わせ、幼く見せすぎない／大人びさせすぎない。
- 文字（読める漢字・ロゴ）を絵の中に入れない。

### 属性とレアの色

|---|---|---|
| 炎 | `#e2543a` | 鱗文 |
| 潮 | `#3f9fd0` | 青海波 |
| 嵐 | `#4fb08a` | 矢絣 |

レア枠：UR 金 `#e3b34a`／SSR 紫 `#a46ad8`／SR 青 `#5b8fd9`（枠はゲーム側で描くので絵に入れない）
