# 主力EA（BreakoutPro）商品化計画

> 前提：既存稼働中EAのロジック流用は**全面承認済み**（Phase 0）。本計画は流用ロジックを安全に商品化する手順。
> ステータス：スキャフォールド作成済み → ロジック差し込み・検証は要・あなたの作業/承認。

## 1. 方針
- ブレイクアウト系（JPYクロス中心）を主力商品に。
- RiskGuard の **リスク%サイジング／SL・TP／建値移動／トレーリング／ライセンス層** を再利用し、開発を最小化。
- 価格帯：$99〜199（買い切り）を想定（最終承認）。

## 2. 成果物（現時点）
- `products/breakout-pro/src/BreakoutPro.mq5` — 商品化スキャフォールド。
  - リスク管理・執行・ライセンスは実装済み。
  - **`GenerateSignal()` に承認ロジックを差し込むだけ**で商品化できる構造。
  - 現在は仮のDonchianブレイクアウト（**プレースホルダ。販売前に必ず差し替え**）。
