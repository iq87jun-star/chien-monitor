# 顧客対応フロー（自動 → 人間エスカレーション）

```
問い合わせ受信
   │
   ├─ FAQで解決可能か？（テンプレ1〜3,5）
   │     └─ Yes → 自動/定型回答で返信（FAQボット or テンプレ）
   │
   ├─ 不具合報告（ログ・スクショ付き）
   │     └─ 再現性あり → 開発対応キューへ（Claude Codeで調査・修正）
   │
   ├─ 返金・金額・規約に関わる判断
   │     └─ 人間（あなた）へエスカレーション ★
   │
   ├─ ライセンス失効/不正利用の疑い
   │     └─ 人間へエスカレーション ★（口座紐付け・revoke判断）
   │
   └─ 投資助言・成績の問い合わせ
         └─ 定型の免責回答（助言はしない）
```

## エスカレーション基準（★＝人間必須）
- 返金可否・例外対応・規約解釈
- ライセンスの revoke / 再発行 / 紐付け変更
- 法務・税務・苦情・SNSでの公開クレーム
- 価格・キャンペーンの判断

## FAQボット用ナレッジベース
- ソース：各 `manual/faq-*.md` ＋ `support/templates.md`
- 回答に必ず免責フッターを付与。確証がない場合は「人間に確認します」と返す。
