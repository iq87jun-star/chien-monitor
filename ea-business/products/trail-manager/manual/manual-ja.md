# TrailManager ユーザーマニュアル（日本語）

**バージョン:** 1.00 ／ **対応:** MetaTrader 5 ／ **種別:** EA（ポジション管理 補助ツール）

---

## ⚠️ リスク開示・免責事項
レバレッジ取引には高いリスクが伴い、投資元本を上回る損失が生じる可能性があります。TrailManager は**既存ポジションのストップ管理（建値移動・トレーリング）を補助するユーティリティ**であり、新規エントリー・売買シグナルの生成・相場予測は行いません。利益を保証しません。**過去の成績は将来の結果を保証しません。** ご利用は自己責任でお願いします。

---

## 1. TrailManager とは
チャートに入れておくと、**あなたが（または他のツール・EA・手動で）既に建てたポジション**に対して、建値移動とトレーリングストップを自動で適用するツールです。新規エントリーはしません（ストップ管理に特化）。

### トレーリング3モード
| モード | 動作 |
|---|---|
| **FIXED** | 含み益が出たら固定pips距離でSLを追従 |
| **ATR** | ATR×倍率でSLを追従（ボラティリティに自動適応） |
| **STEP** | 一定step以上動いた時だけSLを更新（修正回数を抑制） |

### その他
- **建値移動**：含み益が閾値に達したらSLを建値（＋ロック）へ
- **初期SL付与**（任意）：SLが無いポジションに初期SLを設定
- **対象範囲フィルタ**：現在銘柄のみ／マジック一致
- **ON/OFFトグル**：パネルから管理を一時停止/再開

## 2. 入力パラメータ

### 対象範囲
| 項目 | 説明 |
|---|---|
| `InpCurrentSymbolOnly` | 現在チャートの銘柄のみ管理 |
| `InpFilterByMagic` | 指定マジックのポジションのみ管理 |
| `InpMagic` | 対象マジック（フィルタ時） |

### 建値移動
| 項目 | 説明 |
|---|---|
| `InpUseBreakEven` | 建値移動を使う |
| `InpBreakEvenPips` | 建値移動を発動する含み益（pips） |
| `InpBreakEvenLock` | 建値移動時に確保する利益（pips） |

### トレーリング
| 項目 | 説明 |
|---|---|
| `InpTrailMode` | FIXED / ATR / STEP |
| `InpTrailStartPips` | トレーリング開始の含み益（pips） |
| `InpTrailDistancePips` | FIXED/STEP：トレーリング距離（pips） |
| `InpTrailStepPips` | STEP：SLを動かす最小幅（pips） |
| `InpATRPeriod` | ATR：期間 |
| `InpATRMultiplier` | ATR：距離倍率 |
| `InpATRTF` | ATR：時間足 |

### 初期保護（任意）
| 項目 | 説明 |
|---|---|
| `InpSetSLIfMissing` | SLが無いポジションに初期SLを設定 |
| `InpInitialSLPips` | 初期SL距離（pips） |

### 執行・ライセンス
| 項目 | 説明 |
|---|---|
| `InpSlippagePts` | 許容スリッページ（ポイント） |
| `InpLicenseKey` / `InpLicenseServer` | 自前販売版のみ |

> MQL5 Market 版はライセンス入力不要。

---

## 3. 使い方
1. 対象範囲とモード（FIXED/ATR/STEP）を設定。
2. チャートにドラッグ → 既存ポジションが自動で管理対象に。
3. 含み益が `InpTrailStartPips` に達するとトレーリング開始、`InpBreakEvenPips` で建値移動。
4. パネルの **PAUSE/RESUME** で一時停止/再開。

---

## 4. 注意
- SLは**含み益方向にのみ**動かします（不利な方向には動かしません）。
- ATRモードはATRハンドル生成に失敗すると距離0＝トレーリングしません。期間/時間足を確認してください。
- 他のEAが同じポジションのSLを操作していると競合する場合があります。範囲フィルタで棲み分けを。
- まずデモ口座で挙動を確認してください。
