# RiskGuard ユーザーマニュアル（日本語）

**バージョン:** 1.00 ／ **対応:** MetaTrader 5 ／ **種別:** EA（手動トレード補助ツール）

---

## ⚠️ リスク開示・免責事項
レバレッジ取引には高いリスクが伴い、投資元本を上回る損失が生じる可能性があります。RiskGuard は **ポジションサイズ計算と注文管理を補助するツール** であり、売買シグナルの生成や相場予測は行いません。利益を保証するものではありません。**過去の成績は将来の結果を保証しません。** ご利用は自己責任でお願いします。

## 1. RiskGuard とは
RiskGuard は「ボタンを押すだけで、**口座残高に対するリスク％から自動でロットを計算**し、ストップロス（SL）／テイクプロフィット（TP）を付けて発注、その後ポジションを自動管理（建値移動・トレーリング）する」手動トレード補助 EA です。

自動売買 EA ではありません。**エントリー判断はあなた自身が行います。**

### 主な機能
- リスク％ベースのロット自動計算（または固定ロット）
- SL（pips）＋ R 倍での TP 自動設定
- ブレイクイーブン（建値移動）
- トレーリングストップ
- スプレッドフィルタ（広すぎる時はエントリーを抑止）
- チャート上のパネル（BUY / SELL / CLOSE ALL）

---

## 2. 入力パラメータ

### リスク・サイジング
| 項目 | 説明 |
|---|---|
| `InpRiskPercent` | 1トレードのリスク（残高に対する％）。例: 1.0 = 1% |
| `InpFixedLot` | 固定ロット。0より大きいとリスク％より優先 |
| `InpStopLossPips` | SL（pips）。**0だとリスク計算不可のため発注はブロックされます** |
| `InpRiskReward` | TP を SL の何倍に置くか（R倍）。0でTPなし |

### ポジション管理
| 項目 | 説明 |
|---|---|
| `InpUseBreakEven` | 建値移動を使うか |
| `InpBreakEvenPips` | 建値移動を発動する含み益（pips） |
| `InpBreakEvenLock` | 建値移動時に確保する利益（pips） |
| `InpUseTrailing` | トレーリングを使うか |
| `InpTrailStartPips` | トレーリング開始の含み益（pips） |
| `InpTrailStepPips` | トレーリング幅（pips） |

### フィルタ・執行
| 項目 | 説明 |
|---|---|
| `InpMaxSpreadPts` | 許容スプレッド（ポイント） |
| `InpSlippagePts` | 許容スリッページ（ポイント） |
| `InpMagic` | マジックナンバー |

### ライセンス（自前販売版のみ）
| 項目 | 説明 |
|---|---|
| `InpLicenseKey` | 購入時に発行されるライセンスキー |
| `InpLicenseServer` | ライセンス認証サーバのURL（販売者が指定） |

> MQL5 Market 版ではライセンス入力は不要です（プラットフォームが管理）。

---

## 3. 使い方
1. SL（`InpStopLossPips`）とリスク（`InpRiskPercent`）を設定。
2. チャート左上のパネル情報で、計算されたロットを確認。
3. **BUY / SELL** を押すと、計算ロットで SL/TP 付き発注。
4. 以降はブレイクイーブン／トレーリングが自動でポジションを管理。
5. **CLOSE ALL** で当該シンボル・マジックのポジションを全決済。

> pip 換算は 3桁/5桁クォートに対応（1 pip = 10 points）。

---

## 4. 注意
- SL を 0 にするとリスク計算ができないため発注しません（仕様）。
- スプレッドが `InpMaxSpreadPts` を超える場合はエントリーを見送ります。
- 計算ロットが業者の最小ロット未満の場合は最小ロットに丸められます。証拠金・リスク許容を必ず確認してください。

セットアップは `setup-ja.md`、よくある質問は `faq-ja.md` を参照。
