# インジ・EA 作成代行 — 募集要項 / 受付テンプレ

> X DM・ココナラで使う、作成代行の案内一式。コンプラ：利益保証なし／投資助言なし／動作保証はするが収益保証はしない。

---

## A. 募集要項（DM返信 or ココナラ説明用・コピペ可）

```
【MT5/MQL5｜インジ・EA作成代行】

「こんなインジ・ツールが欲しい」をMQL5で形にします。

■ 対応内容
・カスタムインジケーター作成
・EA作成（売買ロジックは依頼者ご提供のものを実装）
・既存インジ/EAの改造・不具合修正
・MT4→MT5移植 など

■ 料金の目安（内容により見積もり）
・シンプルなインジ：¥5,000〜
・標準的なインジ/ツール：¥10,000〜
・EA（ロジック実装）：¥20,000〜
・改造/移植：¥5,000〜

■ 納期
内容により3日〜2週間程度

■ 流れ
1. DMで要件をお知らせ（下記テンプレ）
2. 内容確認 → お見積もり・納期回答
3. 合意後に着手 → 納品（.ex5 / 必要なら .mq5）
4. 動作確認・軽微な修正対応

■ ご注意
・動作（仕様通りに動くこと）は保証しますが、収益は保証しません。
・投資助言は行いません。売買判断はご自身でお願いします。
・特定ブローカー規約・MQL5規約に反する依頼はお受けできません。
```

## C. 受注時チェックリスト（自分用）

- [ ] 要件が一意に決まっているか（曖昧なら確認質問）
- [ ] MQL5規約・ブローカー規約に抵触しないか
- [ ] 売買ロジックは「依頼者提供」になっているか（他者の有料ロジック流用でないか）
- [ ] 見積もり・納期・納品形態（.ex5/.mq5）を合意したか
- [ ] 動作保証の範囲・収益非保証を明記したか
- [ ] 着手金/支払いタイミングの取り決め（ココナラ経由なら同サービスの決済に従う）

## D. よくある断り文句（トラブル予防・定型）

- 「必ず勝てるEAを作って」→
  「収益を保証する開発はお受けできません。ロジックを指定いただければ“その通りに動くEA”は作成できます。」
- 「他社の有料インジと同じものを」→
  「第三者の有料・著作物の複製はお受けできません。オリジナルでの作成は可能です。」
- 「相場予測して」→「投資助言は行っていません。ツール開発のみ承ります。」

## 運用メモ
- 受付は当面 **X DM + ココナラ** の2窓口。ココナラは決済・トラブル仲介がある分、初回はそちらが安全。
- 実績が増えたら B のテンプレ回答を固定化し、対応工数を圧縮。
