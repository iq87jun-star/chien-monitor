# 中古ドメイン発掘パイプライン(domain scout)

自社サイト(7サイト目以降)用に、**テーマが一致し・過去に運用歴があり・現在未登録の
中古ドメイン**を発掘してスコアリングする社内ツール。pocketduel.tokyo で始めた
中古ドメイン実験(閉店したデュエルカフェの旧ドメイン再取得)を体系化したもの。

転売(ドメインフリッピング)ではなく「自社サイトの土台になる中古ドメイン探し」が目的。
良い候補は自分で使う。

## 仕組み

```
collect  候補収集   input/candidates.txt(手動貼り付け)
                    + シードページのリンク切れ発掘(Wikipedia等の外部リンク先を抽出)
check    空き判定   DNS over HTTPS → NSなしなら JPRS whois(.jp)/ RDAP(gTLD)で確定
enrich   価値評価   Wayback Machineで運用歴(初出年・最終年・スナップ月数)
                    + Open PageRank(任意キー)で被リンクランク
aggregate 採点      運用歴35 + 被リンク30 + 名前の質25 + ニッチ一致10 − リスク減点
```

結果は `data/site/report.json` / `report.js` に出力され、`index.html` をブラウザで
開くとダッシュボード表示(ビルド不要・file://直接でも動く)。GitHub Actionsが
1日1回自動実行してデータをコミットする。依存パッケージなし(Node 22標準のみ)。

## 使い方

- **候補を足す**: `input/candidates.txt` に1行1ドメインで貼り付け
  (ExpiredDomains.net・お名前.comオークション等で見つけたもの。URLのままでも可)
- **ドロップ待ち**: `input/watchlist.txt` に登録済みドメインを書くと毎回チェックし、
  空きに変わった時に `DROP検知` として通知(Actionsログとダッシュボード)
- **手動実行**: `cd domains && npm run pipeline`
- **シード追加**: `pipeline/config.mjs` の `SEED_URLS` に「古い外部リンクを多く含む
  ページ」を足すと、リンク先の失効ドメイン(=被リンク付き中古)を自動発掘する

## Open PageRank(任意)

https://www.domcop.com/openpagerank/ で無料APIキーを取得し、リポジトリSecretsに
`OPR_API_KEY` を登録すると被リンク評価(最大30点)が有効になる。未設定でも動く
(運用歴と名前の質だけで採点)。

## 取得前チェックリスト(必ず手動で)

1. **Waybackで過去サイトを目視** — スパム・アダルト・海外薬品系の履歴があるドメインは
   SEO上マイナスになり得る(スコアの「要履歴確認」フラグはヒューリスティックにすぎない)
2. **商標確認** — 企業名・商品名を含むドメインはUDRP/JP-DRP(移転裁定)のリスク。
   「商標」フラグが無くても、固有名詞っぽい名前は J-PlatPat で確認する
3. **レジストラで最終確認** — 本ツールの空き判定は実行時点のスナップショット。
   取得はお名前.com等で空きを再確認してから

## 注意事項

- 外部サービス(Cloudflare DoH / JPRS whois / rdap.org / Wayback)への負荷を抑えるため、
  1回の実行あたりのチェック数を制限し(150件)、結果を長期キャッシュしている。
  候補を大量に貼った場合は数日かけて消化される
- JPRS whoisはport 43を使うため、ローカル環境によっては届かず「判定不能」になる
  (GitHub Actions上では動く)
- Wayback Machineはデータセンター系IPをブロックすることがあり、その場合は運用歴が
  「履歴なし」のまま採点される(次回実行で自動リトライ。Actions上では概ね動く)
- 日本語ドメイン(xn--)とco.jp等の属性型JPは対象外
