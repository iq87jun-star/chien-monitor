# Chrome ウェブストア掲載情報(下書き)

ダッシュボードの各欄にそのまま貼り付けて使う。

## 基本情報

- **名前**: ポケカ海外相場チェッカー(manifest.json の name と同じ)
- **カテゴリ**: ショッピング
- **言語**: 日本語
- **概要(132文字以内・manifest.json の description と同じ)**:
  メルカリ・ヤフオク・ラクマ・駿河屋の商品ページに、そのポケカ(日本語版)の海外相場(Cardmarket・円換算)を表示します。

## 説明

```
フリマ・通販サイトでポケモンカード(日本語版)の商品ページを開くと、
画面右下に「そのカードが海外でいくらで取引されているか」を表示します。

■ できること
・欧州最大のトレカ市場 Cardmarket の取引平均価格を、最新の為替レートで円換算して表示
・7日平均との比較で、海外で値上がり中/値下がり中かがひと目でわかる
・型番(例: 120/080)やセット名がタイトルにあれば、該当の1枚に絞り込んで表示
・型番がない出品では、同名カードの価格幅と候補を表示

■ 対応サイト
メルカリ / ヤフオク! / ラクマ / 駿河屋

■ 対象カード
直近に発売されたセットと、151・VSTARユニバース・テラスタルフェスex・シャイニートレジャーex・
VMAXクライマックスなどの人気セット、計22セット(約4,000枚)。データは1日2回自動更新されます。
高騰・下落ランキングは「ポケカ海外相場モニター」(pokeca-kaigai.com)で公開しています。

■ プライバシー
閲覧中のページの商品名はブラウザ内だけで照合し、外部に送信しません。
個人情報・閲覧履歴は一切収集しません。

■ ご注意
・表示価格は欧州市場の取引平均を円換算した参考値で、国内の販売・買取価格ではありません。
・本拡張は株式会社ポケモン、Cardmarket、各フリマ・通販サイトとは無関係の非公式ツールです。
```

## プライバシーへの取り組み(Privacy practices タブ)

- **単一用途の説明**:
  フリマ・通販サイトの商品ページに、ポケモンカード(日本語版)の海外相場を表示すること。
- **storage 権限が必要な理由**:
  相場データのキャッシュ(数時間おきの再取得まで保持)と、表示のON/OFF設定の保存に使用します。
- **ホスト権限(pokeca-kaigai.com)が必要な理由**:
  相場データ(カード名と価格の一覧のJSON)を取得するためです。閲覧中のページの情報は送信しません。
- **コンテンツスクリプト(対応サイト)が必要な理由**:
  商品ページの商品名を読み取ってカード名と照合し、相場を画面右下に表示するためです。
  照合はブラウザ内で完結し、読み取った内容は送信しません。
- **リモートコードの使用**: いいえ(取得するのはJSONデータのみ)
- **データの使用**: 収集するデータの種類はすべて「いいえ」。
  下部の3項目(第三者への販売をしない等)にチェック。
- **プライバシーポリシーURL**: https://pokeca-kaigai.com/extension-privacy.html
