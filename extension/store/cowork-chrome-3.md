# Cowork 用の作業指示(Chrome ウェブストア: 3つの拡張の提出準備と動作確認)

この文書を Cowork にそのまま渡して使う。人が行う作業(★)と、Cowork に任せる作業を分けてある。
Cowork は「止まる」と書かれた所で必ず作業を止め、人に確認すること。

| 作業 | 拡張 | 内容 |
|---|---|---|
| A | トレカ海外相場チェッカー | 更新版(v0.3.1)の zip をアップロード |
| B | 求人 年収チェッカー | 却下された説明文を貼り替え(キーワード スパム対策) |
| C | 物件 単価・月額チェッカー | 新しいアイテムとして掲載情報をすべて入力 |
| D(任意) | 求人・物件 | まだ確かめていないサイトで表示を確認 |

## 守ること(Cowork 向け)

- 支払い情報の入力・規約への同意・**審査への提出は絶対に行わない**。その画面に来たら止まって人に知らせる
- Google アカウントのパスワード・2段階認証コードを入力しない(ログインは人が行う)
- 求人サイト・不動産サイトでは**閲覧だけ**を行う。応募・問い合わせ・会員登録・ログイン・お気に入り登録はしない
- 入力内容はこの文書と各拡張の `store/listing.md` に書かれた文章だけを使い、自分で文章を作らない。
  特に**説明文にサイト名(求人サイト・不動産サイトの名前)を書き足さない**(キーワード スパムで却下される)

## 事前準備(★人が行う)

1. Chrome で、デベロッパー登録済みの Google アカウントにログインしておく
2. Chrome で GitHub にログインしておく
3. Cowork に「https://github.com/iq87jun-star/chien-monitor/blob/main/extension/store/cowork-chrome-3.md の作業を
   A〜C(と D)までして」と伝える

ファイルは Cowork が GitHub から取る([cowork/README.md](../../cowork/README.md) の「ファイルの取り方」):

- `cowork-files` の `chrome/` にある zip(展開せずにそのままアップロードする)
  - `pokeca-kaigai-checker-0.3.1.zip`(トレカ)・`job-salary-checker-0.1.0.zip`(求人)・`realty-price-checker-0.1.0.zip`(物件)
  - バージョン番号は更新で変わることがある。`chrome/` にある最新のものを使う
- 掲載文・スクリーンショット・アイコンは、リポジトリ全体(「Code」→「Download ZIP」)の中

## 作業A: トレカ海外相場チェッカーの更新版をアップロード(Cowork)

1. [デベロッパーダッシュボード](https://chrome.google.com/webstore/devconsole)で「トレカ海外相場チェッカー」を開く
2. 「パッケージ」タブ →「新しいパッケージをアップロード」で `chrome/pokeca-kaigai-checker-0.3.1.zip` を選ぶ
3. 「ストアの掲載情報」タブの「説明」欄を、`extension/store/listing.md` の「説明」の ``` で囲まれた部分に
   置き換える(``` の行自体は貼らない)。現在の内容と同じなら変更しない
4. 「下書きを保存」を押す
5. **止まる**: 「審査に提出」は押さずに、アップロードされたバージョン番号(0.3.1 になっているか)と、
   警告が出ていればその内容を人に報告する

## 作業B: 求人 年収チェッカーの説明文を貼り替え(Cowork)

1. ダッシュボードで「求人 年収チェッカー」を開く
2. 却下の理由(「キーワード スパム」等)が表示されていれば、その文言をそのまま控える
3. 「ストアの掲載情報」タブの「説明」欄を**全部消してから**、`job-extension/store/listing.md` の「説明」の
   ``` で囲まれた部分を貼る。貼った後、説明欄に「■ 対応サイト」や求人サイトの名前が**残っていないか**確認する
4. 概要(短い説明)が `listing.md` の「概要」と同じか確認し、違えば置き換える
5. 「下書きを保存」を押す
6. **止まる**: 「審査に提出」は押さずに、控えた却下の理由と、貼り替えた説明文の最初の3行を人に報告する

## 作業C: 物件 単価・月額チェッカーを新しく登録(Cowork)

入力内容はすべて `realty-extension/store/listing.md` にある。

1. ダッシュボードで「新しいアイテム」を押し、`chrome/realty-price-checker-0.1.0.zip` をアップロードする
2. 「ストアの掲載情報」タブ:
   - 説明: `listing.md` の「説明」の ``` で囲まれた部分をそのまま貼る(``` の行自体は貼らない)
   - カテゴリ: 「仕事効率化」、言語: 「日本語」
   - アイコン: `realty-extension/icons/icon128.png`
   - スクリーンショット: `realty-extension/store/screenshots/` の `1-rent.png`・`2-sale.png`・`3-investment.png`(1280x800)
3. 「プライバシーへの取り組み」タブ: `listing.md` の同名の節のとおりに入力する
   - 単一用途の説明、storage 権限が必要な理由、コンテンツスクリプト(対応サイト)が必要な理由
   - リモートコードの使用: いいえ
   - データの使用: 収集するデータの種類はすべて「いいえ」、下部の3項目にチェック
   - プライバシーポリシーURL: `https://pokeca-kaigai.com/realty-extension-privacy.html`
4. 「配布」タブ(表示される場合): 公開、すべての地域(または日本)
5. 「下書きを保存」を押す
6. **止まる**: 「審査に提出」は押さずに、入力した内容の一覧と、エラーや未入力の警告が表示されていれば
   その内容を人に報告する

## 作業D(任意): まだ確かめていないサイトで表示を確認(Cowork・拡張の読み込みは★人が行う)

事前に(★人が)`chrome://extensions` でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を
読み込む」で、展開したフォルダの `job-extension` と `realty-extension` をそれぞれ選んでおく。

### 求人 年収チェッカー

次の各サイトで職種(例: 「営業」「エンジニア」「事務」)を検索し、**求人の詳細ページ**を各サイト2〜3件開いて、
画面右下に「💴 年収チェック」と書かれた白い枠が出るか確認する。検索結果の一覧ページには出ないのが正しい。

- doda、マイナビ転職、リクナビNEXT、Indeed、ハローワークインターネットサービス

| サイト | 求人のタイトル | 表示された? | 表示された年収の目安 | 給与欄に書かれていた内容(そのまま) | おかしい点 |
|---|---|---|---|---|---|

### 物件 単価・月額チェッカー

次の各サイトで賃貸・中古マンション・投資物件を検索し、**物件の詳細ページ**を各サイト2〜3件開いて、
画面右下に「🏠 家賃チェック」または「🏠 価格チェック」と書かれた白い枠が出るか確認する。検索結果の一覧ページには出ないのが正しい。

- LIFULL HOME'S、アットホーム、CHINTAI、Yahoo!不動産、楽待

| サイト | 物件名 | 種類(賃貸/売買/投資) | 表示された? | 表示された月額・単価 | ページの賃料・価格・面積(そのまま) | おかしい点 |
|---|---|---|---|---|---|---|

- 「おかしい点」には、表示が出ない・金額が違う・一覧ページで出てしまう、などを書く
- **表示が出ないページがあれば**、そのページの賃料(給与)欄の見出しの文字(例: 「賃料」「給与」)を書き添える
- この表は Issue の「報告の表」に書く(下の「報告」)

## 報告(Cowork)

作業が終わった時・止まった時は、人に知らせるのに加えて、[cowork/README.md](../../cowork/README.md) の
「報告の出し方」のとおり GitHub の Issue(「Cowork の作業報告」)に結果と報告の表を書き、Issue の番号を人に伝える。

## 最終提出(★人が行う)

作業A〜Cの報告を確認し、問題がなければ、ダッシュボードでそれぞれ「審査に提出」を押す(審査は通常数日)。
作業Dで直すところが見つかった場合は、Claude Code に「Issue #番号 に報告を出しました」と伝えて修正版を作ってもらい、
それから提出した方が、却下や低評価を避けられる。
