# Cowork 用の作業指示(トレカ海外相場チェッカーのストア登録・動作確認)

この文書を Cowork にそのまま渡して使う。人が行う作業(★)と、Cowork に任せる作業を分けてある。
Cowork は「止まる」と書かれた所で必ず作業を止め、人に確認すること。

## 守ること(Cowork 向け)

- 支払い情報の入力・規約への同意・審査への提出は**絶対に行わない**。その画面に来たら止まって人に知らせる
- Google アカウントのパスワード・2段階認証コードを入力しない(ログインは人が行う)
- メルカリ等では**閲覧だけ**を行う。購入・いいね・コメント・ログインはしない
- 入力内容はこの文書と `extension/store/listing.md` に書かれた文章だけを使い、自分で文章を作らない

## 事前準備(★人が行う)

1. Chrome で Google アカウントにログインしておく
2. [Chrome Web Store デベロッパーダッシュボード](https://chrome.google.com/webstore/devconsole)で
   デベロッパー登録をし、登録料5ドルを支払う(2段階認証が必要)
3. 提出用 zip(`pokeca-kaigai-checker-0.3.0.zip`)をパソコンに保存しておき、保存場所を Cowork に伝える
4. リポジトリの `extension/store/` フォルダ(listing.md とスクリーンショット4枚)をパソコンに保存し、
   保存場所を Cowork に伝える
   (GitHub のリポジトリ画面の「Code」→「Download ZIP」で全体をダウンロードして展開すればよい)

## 作業A: ストアの掲載情報を入力する(Cowork)

1. デベロッパーダッシュボードで「新しいアイテム」を押し、提出用 zip をアップロードする
2. 「ストアの掲載情報」タブを開き、`listing.md` の「基本情報」「説明」の内容を各欄に貼る
   - 説明欄には ``` で囲まれた部分をそのまま貼る(``` の行自体は貼らない)
   - カテゴリは「ショッピング」、言語は「日本語」
3. 画像をアップロードする
   - アイコン: 展開したフォルダの `extension/icons/icon128.png`
   - スクリーンショット: `extension/store/screenshots/` の 1〜4 の4枚(1280x800)
4. 「プライバシーへの取り組み」タブを開き、`listing.md` の同名の節の内容を各欄に入力する
   - 単一用途の説明、各権限が必要な理由、リモートコードの使用(いいえ)、
     データの使用(すべて「いいえ」、下部の3項目にチェック)、プライバシーポリシーURL
5. 「下書きを保存」を押す
6. **止まる**: 「審査に提出」は押さずに、入力した内容の一覧と、エラーや未入力の警告が
   表示されていればその内容を人に報告する

## 作業B: 実際のフリマで表示を確認する(Cowork・拡張の読み込みは★人が行う)

事前に(★人が)`chrome://extensions` でデベロッパーモードをオンにし、「パッケージ化されていない
拡張機能を読み込む」で展開したフォルダの `extension` を選んでおく。

1. メルカリ(jp.mercari.com)で次の語を検索し、それぞれ出品を2〜3件開く
   - ポケカ: 「リザードンex SAR 201/165」「ピカチュウ 151」「テラスタルフェス ブラッキーex」
   - 遊戯王: 「遊戯王 灰流うらら」「遊戯王 増殖するG」
   - ワンピース: 「OP05-119 パラレル」「OP01-120 コミパラ」
   - 表示されないはずの例: 「ピカチュウ ぬいぐるみ」「ポケカ スリーブ」
2. 開いた出品ごとに、画面右下に相場の表示(紺色の枠)が出たかを確認する
3. 結果を次の表にまとめて人に報告する(出品タイトルは省略せずそのまま書く)

| 出品タイトル | 表示された? | 表示されたカード名 | 表示価格 | おかしい点 |
|---|---|---|---|---|

- 「おかしい点」には、別のカードが出た・版(パラレル等)が違う・出るはずなのに出ない、などを書く
- 報告を受けたら、その表を Claude Code のセッションに貼って修正を依頼する

## 最終提出(★人が行う)

作業Aの報告を確認し、問題がなければダッシュボードで「審査に提出」を押す(審査は通常数日)。
