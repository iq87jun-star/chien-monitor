# 求人 年収チェッカー(Chrome拡張)

求人サイトの求人詳細ページで、給与欄の記載から **年収の目安・時給換算・固定残業代** を計算して
画面右下に表示するブラウザ拡張。外部サーバーとは通信せず、計算はすべてブラウザ内で行う。

狙い: 求人の給与は「月給30万円～＋賞与年2回（4.65ヶ月分）」「固定残業代40時間分を含む」のように
書き方がばらばらで、比べにくい。年収・時給に揃えて見せる。収益は、年収目安に合わせて
転職エージェントを「PR」として紹介するアフィリエイト(`src/offers.js`・提携承認後に設定)。

## 仕組み

```
content.js: 「給与」「勤務時間」「休日」等の見出し(th / dt / 見出しタグ)を探し、隣の本文を読む
   │         (サイトごとのHTML構造に依存しない。給与欄が4つ以上ある一覧ページでは表示しない)
   ▼
parser.js: 本文から金額・賞与の月数・固定残業代・実働時間・年間休日を読み取り、年収目安と時給換算を計算
   ▼
画面右下にバッジ表示(+ offers.js に設定があれば「PR」枠で紹介リンク)
```

- **年収目安**: 年俸があれば年俸。無ければ 月額×12＋賞与(月額×記載の月数)。賞与の月数が
  無い時は賞与を含めず、その旨を表示する。日給・時給は月の労働時間で月額に直す
- **記載の年収**: 「想定年収」＞「年収例」＞「年収」の順で、この求人の年収に近いものを優先する。
  「平均年収」は会社全体の平均なので、他に記載が無い時だけ「会社の平均年収」として出す
- **時給換算**: 月額 ÷ (月の労働日数 × 1日の実働時間)。年間休日・実働時間の記載が無ければ
  「年間休日120日・1日8時間」と仮定し、仮定したことをバッジに明記する
- **固定残業代**: 「固定残業代」「みなし残業」を検出して警告し、金額が書かれていれば除いた月給・時給を出す。
  「みなし残業はありません」等の否定文は検出しない
- 表記揺れ: 「30万4,240円」「24万2000円」「23.85万円」「300,000円」、全角数字、「～〜~」に対応

## 検証の状況

- en転職の実際の求人詳細ページ5件(保存したHTML)に拡張を読み込んで、全件で正しく表示されること、
  一覧ページで表示されないことを確認済み(2026-09-23)
- **doda・マイナビ転職・リクナビNEXT・Indeed・ハローワークは、この開発環境から実ページを取得できず未検証**。
  見出し+本文の一般的な構造(表・定義リスト・見出し)には対応しているが、実際に動くかは要確認。
  動かないサイトがあれば、そのページの給与欄の見出しの書き方を `SALARY_LABELS` に足すか、
  サイト固有の取り出し方を追加する

## 開発

```bash
cd job-extension
npm ci
npm test                      # 単体テスト(給与の文章の解析。実例は en転職の給与欄の表記)
npm run test:e2e              # 実Chromiumに拡張を読み込み、3種類のレイアウトと一覧ページで確認
npm run test:e2e -- --shots   # 上記+ストア用スクリーンショットを store/screenshots/ に更新
npm run pack                  # ストア提出用zipを dist/ に作成
npm run icons                 # アイコンを再生成
```

手元のChromeで試す: `chrome://extensions` → デベロッパーモードON →
「パッケージ化されていない拡張機能を読み込む」→ この `job-extension/` フォルダを選択。

## 公開手順

トレカ拡張(`extension/README.md`)と同じ。違いは次のとおり。

- 掲載文は `store/listing.md`、プライバシーポリシーは
  https://pokeca-kaigai.com/job-extension-privacy.html(`toreca/public/` に同居)
- 自動提出のタグは `job-v0.1.1` 形式、Secrets のアイテムIDは `JOB_CWS_EXTENSION_ID`
  (OAuth の `CWS_CLIENT_ID` 等はトレカ拡張と共用できる)

## Edge・Firefox への出品

`npm run pack` で Chrome・Edge 用のzip(`dist/*.zip`)と Firefox 用のzip(`dist/firefox/*.zip`)が両方できる。
手順は [edge-firefox.md](../extension/store/edge-firefox.md) を参照(3つの拡張で共通)。

## 収益化(紹介リンク)

1. A8.net・afb 等のASPに登録し、転職エージェント・転職サイトの広告に提携申請する
2. 承認されたら、発行された広告リンクを `src/offers.js` に追加する
   (`minAnnual` で「年収目安がこの額以上の求人でだけ出す」を指定でき、ハイクラス向けと一般向けを分けられる)
3. version を上げてストアに提出(掲載文に「広告リンクを表示する場合がある」旨は記載済み)

Chrome ウェブストアのアフィリエイト方針に沿って、リンクは「PR」と明記した枠に出し、
ページ内のリンクの書き換えやクッキーの上書きはしない。
