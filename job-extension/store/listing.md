# Chrome ウェブストア掲載情報(下書き)

ダッシュボードの各欄にそのまま貼り付けて使う。Cowork に任せる場合は、トレカ拡張の
`extension/store/cowork-guide.md` と同じ手順で、このファイルの内容を入力してもらう
(zip は `job-salary-checker-<version>.zip`、スクリーンショットは `job-extension/store/screenshots/`)。

## 基本情報

- **名前**: 求人 年収チェッカー(manifest.json の name と同じ)
- **カテゴリ**: 仕事効率化
- **言語**: 日本語
- **概要(132文字以内・manifest.json の description と同じ)**:
  求人ページの給与欄から、年収の目安・時給換算・固定残業代を自動で計算して表示します。

## 説明

```
求人サイトの求人ページを開くと、画面右下に「この求人の年収はいくらくらいか」を自動で計算して表示します。

■ できること
・月給・日給・時給から年収の目安を計算(賞与の月数が書かれていれば含めて計算)
・求人に書かれた年収例・想定年収をまとめて表示(会社全体の平均年収は区別して表示)
・所定労働時間と年間休日から、時給に換算した金額を表示
・固定残業代(みなし残業代)を含む求人を警告し、それを除いた月給・時給を計算

■ 対応サイト
en転職 / doda / マイナビ転職 / リクナビNEXT / Indeed / ハローワークインターネットサービス

■ プライバシー
計算はすべてお使いのブラウザ内で行い、閲覧内容は外部に送信しません。
個人情報・閲覧履歴は一切収集しません。

■ ご注意
・表示する金額は求人の記載から機械的に計算した概算です。実際の条件は求人元に確認してください。
・勤務時間・休日の記載がない場合は「1日8時間・年間休日120日」と仮定して計算します(表示内に明記)。
・本拡張は各求人サイトの運営会社とは無関係の非公式ツールです。
```

## プライバシーへの取り組み(Privacy practices タブ)

- **単一用途の説明**:
  求人サイトの求人ページで、給与の記載から年収の目安・時給換算・固定残業代を計算して表示すること。
- **storage 権限が必要な理由**:
  表示のON/OFF設定を保存するためだけに使用します。
- **コンテンツスクリプト(対応サイト)が必要な理由**:
  求人ページの給与・勤務時間・休日の欄を読み取り、計算結果を画面右下に表示するためです。
  処理はブラウザ内で完結し、読み取った内容は送信しません。
- **リモートコードの使用**: いいえ
- **データの使用**: 収集するデータの種類はすべて「いいえ」。下部の3項目にチェック。
- **プライバシーポリシーURL**: https://pokeca-kaigai.com/job-extension-privacy.html
  (ポケカ海外相場モニターのサイトに同居させている。専用サイトを作ったら移す)
