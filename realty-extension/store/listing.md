# Chrome ウェブストア掲載情報(下書き)

ダッシュボードの各欄にそのまま貼り付けて使う。
注意: 説明文にサイト名を並べると「キーワード スパム」で却下される(求人 年収チェッカーで実際に却下された)。
対応サイトの一覧は説明文に書かない。

## 基本情報

- **名前**: 物件 単価・月額チェッカー(manifest.json の name と同じ)
- **カテゴリ**: 仕事効率化
- **言語**: 日本語
- **概要(132文字以内・manifest.json の description と同じ)**:
  物件ページの記載から、㎡・坪単価、実質の月額、初期費用の目安、ローン返済額、利回りを計算して表示します。

## 説明

```
不動産ポータルの物件ページを開くと、画面右下に「広さあたりいくらか」「毎月いくらかかるか」を自動で計算して表示します。

■ 賃貸物件
・賃料と管理費・共益費を合わせた実質の月額
・1㎡あたり・1坪あたりの月額(広さの違う部屋どうしを比べやすく)
・敷金・礼金・仲介手数料・前家賃から、初期費用の最低限の目安

■ 購入物件
・1㎡あたり・1坪あたりの価格
・ローン返済額に管理費・修繕積立金を足した、月々の支払いの目安
  (金利と返済期間は拡張機能のボタンから変更できます)

■ 投資物件
・表面利回りと年間収入(どちらか一方の記載から、もう一方を計算)
・管理費・修繕積立金を差し引いた簡易の実質利回り

■ 広告について
計算結果の下に、「PR」と明記した引越し・保険・住宅ローン等のサービスの紹介リンク(広告)を表示する場合があります。
リンクはクリックした時だけ移動し、閲覧中のページ内のリンクを書き換えることはありません。

■ プライバシー
計算はすべてお使いのブラウザ内で行い、閲覧内容は外部に送信しません。
個人情報・閲覧履歴は一切収集しません。

■ ご注意
・表示する金額・利回りは物件ページの記載から機械的に計算した概算です。実際の条件は不動産会社に確認してください。
・初期費用には保証会社・火災保険・鍵交換等の費用は含みません。
・簡易の実質利回りには固定資産税・空室・修繕費等は含みません。
・本拡張は各不動産ポータルの運営会社とは無関係の非公式ツールです。
```

## プライバシーへの取り組み(Privacy practices タブ)

- **単一用途の説明**:
  不動産ポータルの物件ページで、記載された賃料・価格・面積等から単価・月額・利回りを計算して表示すること。
- **storage 権限が必要な理由**:
  表示のON/OFFと、ローン試算の条件(金利・返済期間)の設定を保存するためだけに使用します。
- **コンテンツスクリプト(対応サイト)が必要な理由**:
  物件ページの賃料・価格・面積等の欄を読み取り、計算結果を画面右下に表示するためです。
  処理はブラウザ内で完結し、読み取った内容は送信しません。
- **リモートコードの使用**: いいえ
- **データの使用**: 収集するデータの種類はすべて「いいえ」。下部の3項目にチェック。
- **プライバシーポリシーURL**: https://pokeca-kaigai.com/realty-extension-privacy.html
  (ポケカ海外相場モニターのサイトに同居させている)
