# 物件 単価・月額チェッカー(Chrome拡張)

不動産ポータルの物件詳細ページで、記載された賃料・価格・面積・管理費・利回りから
**㎡・坪単価、実質の月額、初期費用の目安、ローン返済額、利回り** を計算して画面右下に表示する
ブラウザ拡張。外部サーバーとは通信せず、計算はすべてブラウザ内で行う。

狙い: 物件ページは「賃料」「管理費」「敷金/礼金」「専有面積」がばらばらに書かれていて、
広さの違う部屋どうしや、実際に毎月いくらかかるかを比べにくい。収益は、賃貸ページでは引越し見積もり、
購入ページでは住宅ローン比較等の紹介リンク(アフィリエイト・`src/offers.js`・提携承認後に設定)。

## 仕組み

```
content.js: 「賃料」「価格」「専有面積」「管理費」「利回り」等の見出し(th / dt / 見出しっぽい要素)を探し、
   │         隣の本文を読む(サイトごとのHTML構造に依存しない)。
   │         用語解説の長い文章・一覧ページの検索条件(「3万円以下」「下限なし」)は値とみなさず、
   │         賃料・価格の値が4つ以上あるページ(一覧ページ)では表示しない
   ▼
parser.js: 金額・面積・利回りを読み取り、賃貸/売買に分けて計算
   ▼
画面右下にバッジ表示(+ offers.js に設定があれば「PR」枠で紹介リンク)
```

- **賃貸**: 実質月額 = 賃料+管理費・共益費。単価 = 実質月額 ÷ 面積(㎡・坪)。
  初期費用の目安 = 敷金+礼金+仲介手数料(賃料1ヶ月+税)+前家賃1ヶ月。敷金・礼金の「1ヶ月」「なし」「-」表記に対応。
  保証会社・火災保険・鍵交換は物件ごとに違うので含めず、その旨を表示する
- **売買**: 単価 = 価格 ÷ 面積。月々の支払い = 価格の全額を元利均等で借りた返済額+管理費+修繕積立金。
  金利・返済期間はポップアップで変更できる(既定は年1%・35年)
- **投資**: 年間収入があれば表面利回り、利回りしか無ければ年間収入を逆算。簡易の実質利回り =
  (年間収入 − 管理費・修繕積立金×12) ÷ 価格(固定資産税・空室等は含まない)
- 表記揺れ: 「14万円」「1万4800円」「3,230万円」「1億2000万円」「20m2」「56.88m²」「51.58㎡(壁芯)」「10坪」、
  管理費と修繕積立金が1欄(「6,000円 / 8,870円」)、SUUMO の見出しの「ヒント」ボタン

## 検証の状況

- 実際の物件詳細ページ6件(SUUMO 賃貸2件・SUUMO 中古マンション2件・健美家の投資物件2件、保存したHTML)に
  拡張を読み込んで、全件で正しく計算・表示されること、一覧ページ3件で表示されないことを確認済み(2026-09-23)
- **LIFULL HOME'S・アットホーム・楽待・CHINTAI・Yahoo!不動産は、この開発環境から実ページを取得できず未検証**。
  表・定義リスト等の一般的な構造には対応しているが、実際に動くかは要確認。動かないサイトがあれば、
  そのページの見出しの書き方を `FIELDS` に足す

## 開発

```bash
cd realty-extension
npm ci
npm test                      # 単体テスト(実例は物件詳細ページの項目の表記)
npm run test:e2e              # 実Chromiumに拡張を読み込み、賃貸・売買・投資・一覧ページとポップアップ設定を確認
npm run test:e2e -- --shots   # 上記+ストア用スクリーンショットを store/screenshots/ に更新
npm run pack                  # ストア提出用zipを dist/ に作成
npm run icons                 # アイコンを再生成
```

## 公開手順

トレカ拡張(`extension/README.md`)と同じ。違いは次のとおり。

- 掲載文は `store/listing.md`(**説明文にサイト名を並べない**: キーワード スパムで却下されるため)、
  プライバシーポリシーは https://pokeca-kaigai.com/realty-extension-privacy.html(`toreca/public/` に同居)
- 自動提出のタグは `realty-v0.1.1` 形式、Secrets のアイテムIDは `REALTY_CWS_EXTENSION_ID`

## Edge・Firefox への出品

`npm run pack` で Chrome・Edge 用のzip(`dist/*.zip`)と Firefox 用のzip(`dist/firefox/*.zip`)が両方できる。
手順は [edge-firefox.md](../extension/store/edge-firefox.md) を参照(3つの拡張で共通)。

## 収益化(紹介リンク)

A8.net 等で引越し一括見積もり(賃貸向け)・住宅ローン比較・火災保険(購入向け)の広告に提携申請し、
承認されたら広告リンクを `src/offers.js` に `kind: "rent"` / `"sale"` を付けて追加する。
リンクは「PR」と明記した枠に出し、ページ内のリンクの書き換え等はしない。
