# べんぴモニター

毎日の排便記録と腸活習慣のチェックで、便秘改善をサポートするアプリです。

## 機能

- **ステータス表示** — 最後の排便からの日数で「快調 / 便秘気味 / 便秘」を自動判定
- **排便記録** — ブリストルスケール(タイプ1〜7)とメモで記録、履歴の確認・削除
- **1週間ビュー** — 直近7日間の排便の有無をひと目で確認
- **腸活チェックリスト** — 水分・食物繊維・運動など、毎日の習慣をチェック
- **改善のヒント** — 便秘改善に役立つ生活習慣のアドバイス

データはブラウザの localStorage にのみ保存されます(外部送信なし)。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
```

⚠️ 本アプリは医療機器ではありません。血便・激しい腹痛・便秘が長く続く場合は医療機関を受診してください。
